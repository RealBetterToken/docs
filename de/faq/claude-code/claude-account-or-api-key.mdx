## Kurzantwort

Claude Code kann sich auf mehr als eine Weise authentifizieren. Einzelne Nutzer melden sich häufig mit einem Claude.ai-Konto an. API-Nutzer oder Teams können Claude Console, Cloud-Provider oder einen unterstützten Provider-Weg von Drittanbietern verwenden.

Ein Claude.ai-Konto und ein API Key sind nicht dasselbe. Die Claude.ai-Anmeldung ist für die offizielle Produkterfahrung. Ein API Key wird für Modell-API-Requests verwendet und normalerweise mit einer Base URL und Provider-Konfiguration kombiniert.

Wenn du ein API-Gateway eines Drittanbieters verwendest, sind API Key und Base URL die wichtigen Felder. Du musst außerdem bestätigen, ob das Tool ein Anthropic-kompatibles oder OpenAI-kompatibles Protokoll erwartet.

## Wann das wichtig ist

- Du siehst während der Claude-Code-Einrichtung eine Anmeldeaufforderung
- Du bist nicht sicher, ob Claude Pro oder Max dir einen API Key gibt
- Du möchtest Claude Code über ein eigenes API-Gateway leiten
- Du musst zwischen offizieller Anmeldung und einem Drittanbieter-Provider wählen
- Ein Team benötigt ein einheitliches Authentifizierungsmuster

## Wichtige Konzepte

| Konzept | Bedeutung |
| --- | --- |
| Claude.ai-Konto | Offizielle Produktanmeldung für Claude-Erfahrungen |
| Claude Console API | Entwicklerseitiger API-Zugriff und Nutzungsverwaltung |
| API Key | Zugangsdaten für Modell-API-Requests |
| Base URL | Der Endpunkt, an den Requests gesendet werden |
| Provider | Die Quelle für Authentifizierung und Modell-Requests, die Claude Code verwendet |
| API-Gateway eines Drittanbieters | Kompatibilitäts-, Routing-, Abrechnungs- oder Observability-Schicht zwischen Tool und Modell-Providern |

## Empfohlener Entscheidungsablauf

1. Wenn du nur die offizielle Claude-Code-Erfahrung möchtest und einen Claude.ai-Plan verwendest, beginne mit der offiziellen Anmeldung.
2. Wenn du API-Abrechnung oder teamverwalteten API-Zugriff benötigst, prüfe Claude Console oder den Provider deines Teams.
3. Wenn du ein eigenes API-Gateway benötigst, bestätige, dass Claude Code den Provider-Weg unterstützt, und konfiguriere dann API Key und Base URL.
4. Wenn du offizielle App-Funktionen zusammen mit einem Inferenz-Provider eines Drittanbieters benötigst, entscheide, ob du den offiziellen Anmeldestatus behalten musst.

In dieser Dokumentation lautet die Anthropic-kompatible Claude-Code-Base-URL `{{anthropic-base-url}}`.

## Häufige Fehler

- Ein Claude.ai-Abonnement als API Key behandeln.
- Zugangsdaten für ChatGPT Plus oder ein anderes Abonnement in Claude Code einfügen.
- Nur den API Key kopieren und vergessen, die Base URL zu ändern.
- Eine OpenAI-kompatible Base URL in die Anthropic-kompatible Konfiguration von Claude Code eintragen.
- `auth.json`, Refresh-Tokens oder Sitzungszugangsdaten teilen, als wären sie API Keys.

## Über BetterToken

Wenn du den Weg über API Key + Base URL wählst, kann BetterToken den kompatiblen Endpunkt und ein Dashboard für API Keys, Guthaben und Nutzungsverlauf bereitstellen.

BetterToken ersetzt die Claude.ai-Anmeldung nicht und wandelt kein Claude.ai-Abonnement in einen API Key um. Es stellt nur die Modell-API-Schicht bereit.
