## Kurzantwort

Wenn du Sonnet, Opus oder ein anderes Modell in Claude Code wechselst, verwende bevorzugt den unterstützten Einstiegspunkt `/model` oder den offiziellen Weg zur Modellkonfiguration.

Modell-Aliase, vollständige Model IDs und Provider-Zuordnungen sind nicht immer identisch. Ein in einer Web-UI angezeigter Marketingname ist nicht immer die von der API erkannte Model ID.

Wenn du ein Drittanbieter-Gateway verwendest, verwende die in diesem Gateway oder in der Provider-Dokumentation angezeigte Model ID.

## Wann das wichtig ist

- Du möchtest zwischen günstigeren und leistungsstärkeren Modellen wechseln
- Du siehst Sonnet-/Opus-/Haiku-Aliase, weißt aber nicht, was du eingeben sollst
- Du verwendest eine Base URL oder ein Modell-Gateway eines Drittanbieters
- Du möchtest die Token-Kosten von Claude Code steuern
- Du siehst „Modell nicht gefunden“ oder die Modellauswahl wird nicht übernommen

## Drei Ebenen von Modellnamen

| Ebene | Bedeutung |
| --- | --- |
| Anzeigename | Menschenlesbarer Name in einer UI |
| Alias | Kurzer Name oder Kürzel innerhalb eines Tools |
| Model ID | Die tatsächlich von der API erkannte Kennung |

Für einen erfolgreichen Request ist entscheidend, ob der aktuelle Provider die Model ID erkennt.

## Empfohlene Vorgehensweise

1. Bestätige, welche Modelle der aktuelle Provider unterstützt.
2. Verwende Claude Code `/model` oder den offiziellen Weg zur Modellkonfiguration.
3. Wenn du ein Drittanbieter-Gateway verwendest, kopiere die verfügbare Model ID aus dessen model plaza.
4. Betrachte Modellauswahl und Kosten gemeinsam.
5. Rate Modellnamen nicht manuell.

## Über BetterToken

Wenn du Claude Code über BetterToken verbindest, kopiere die aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>. Claude-Provider- und GPT-Provider-Modelle gehören zu unterschiedlichen Protokollpfaden; mische sie daher nicht.

Die Modellauswahl beeinflusst Qualität, Geschwindigkeit und Kosten. Nutzungsaufzeichnungen helfen dir, den tatsächlichen Verbrauch zwischen Modellen zu vergleichen.
