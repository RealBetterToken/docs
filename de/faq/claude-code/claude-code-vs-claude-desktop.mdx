## Kurzantwort

Claude Code ist ein Coding-Agent für die Arbeit mit einer Codebasis. Sein Workflow basiert auf dem Lesen eines Projekts, dem Bearbeiten von Dateien, dem Ausführen von Befehlen und der Ergebnisprüfung.

Claude Desktop ist die Desktop-App für Claude. Sie ist ein grafischer Einstiegspunkt für Unterhaltungen, Desktop-Erweiterungen, lokale MCP-Server und einige Desktop-Workflows wie Cowork- oder Code-Funktionen.

Sie können einige Fähigkeiten teilen, sind aber nicht dieselbe Produktoberfläche. Ihre Einrichtung, ihr Berechtigungsmodell, ihr MCP-Verhalten und ihre Gateway-Konfiguration können sich unterscheiden.

## Wann das wichtig ist

- Du wählst zwischen Claude Code CLI und Claude Desktop
- Du möchtest, dass Claude ein Repository bearbeitet
- Du konfigurierst Claude Desktop Gateway oder MCP
- Du verwendest Claude Code über ein Terminal, eine IDE, Desktop-App oder das Web
- Du untersuchst einen Unterschied zwischen Desktop- und CLI-Verhalten

## Wichtige Konzepte

| Bereich | Claude Code | Claude Desktop |
| --- | --- | --- |
| Hauptaufgabe | Coding-Agent | Desktop-App |
| Üblicher Einstieg | Terminal, IDE, Desktop, Web | macOS- oder Windows-Desktop-App |
| Codebasis-Arbeit | Für das Lesen und Bearbeiten von Dateien sowie Befehle vorgesehen | Hängt von Desktop-Funktionen, Erweiterungen, Cowork oder Code-Modus ab |
| Fokus der Einrichtung | Projektverzeichnis, Berechtigungen, `CLAUDE.md`, API-Provider | Anmeldung, Desktop-Erweiterungen, MCP, Gateway |
| Am besten geeignet für | Codeänderungen, Tests, Review, Automatisierung | Unterhaltungen, Desktop-Konnektoren, visuelle Workflows |

## Empfohlene Wahl

Verwende Claude Code, wenn ein Agent direkt innerhalb einer Codebasis arbeiten soll. Sein Workflow basiert auf Projektverzeichnis, Dateiänderungen, Befehlen und Verifikation.

Verwende Claude Desktop, wenn du eine grafische Claude-App, Desktop-Erweiterungen, lokale MCP-Server oder Desktop-spezifische Workflows möchtest. Wenn du Code oder Cowork in Desktop nutzt, prüfe dennoch, ob du gebündeltes Claude-Code-Verhalten oder eine separate Claude Code CLI-Einrichtung verwendest.

Befolge bei Drittanbieter-APIs das von der aktuellen Oberfläche unterstützte Protokoll. In dieser Dokumentation verwendet Claude Code `{{anthropic-base-url}}`. Trage die OpenAI-kompatible `{{openai-base-url}}` nicht direkt in ein Anthropic-kompatibles Gateway-Feld ein.

## Häufige Fehler

- Annehmen, dass Claude Desktop Claude Code CLI automatisch installiert oder ersetzt.
- Desktop-MCP-Einstellungen in Claude Code kopieren oder umgekehrt.
- Ein Claude.ai-Abonnement als API Key behandeln.
- Eine OpenAI-kompatible Base URL in einem Claude-Desktop-Gateway-Feld verwenden, das Anthropic-kompatiblen Traffic erwartet.
- Annehmen, dass Desktop-Funktionen Claude-Code-Berechtigungen, Hooks oder Befehlsrichtlinien ersetzen.

## Über BetterToken

BetterToken ist Teil der Modell-API-Schicht. Es kann kompatible Endpunkte bereitstellen, wenn das Tool einen eigenen API Key und eine eigene Base URL unterstützt.

Es führt Claude Code und Claude Desktop nicht zu einer einzigen Einrichtung zusammen. Du musst weiterhin Protokoll, Gateway, MCP und Berechtigungsmodell der verwendeten Oberfläche befolgen.
