Claude Desktop unterstützt nur Claude-Modelle. Dies ist eine Einschränkung des Claude Desktop-Clients.

Kopieren Sie eine verfügbare Claude Model ID aus der model plaza, speichern Sie und starten Sie Claude Desktop neu.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude |

## Voraussetzungen

- <a href={"{{register-url}}"}>Erstelle und kopiere einen BetterToken API Key</a>
- Kopieren Sie die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Abonnement und API-Abrechnung trennen

Gateway-Anfragen verwenden deinen BetterToken API Key und dein BetterToken-Guthaben. Sie verbrauchen oder erweitern kein Kontingent eines Claude-Abonnements. Behandle Abonnement und API als getrennte Zugriffs- und Abrechnungswege.

Bevor du die Einrichtung produktiv verwendest:

1. Erstelle einen eigenen BetterToken API Key für Claude Desktop.
2. Sende über **Gateway** eine kurze Testnachricht ohne vertrauliche Daten.
3. Öffne das BetterToken Dashboard und prüfe Modell, Status, input, output, cache Token und Belastung.
4. Widerrufe den Key und erstelle einen neuen, falls er in einem Screenshot, Repository oder öffentlichen Log erscheint.

## Installation

Installiere oder aktualisiere auf die neueste Version von der [Claude-Desktop-Website](https://claude.ai/download) und starte dann Claude Desktop.

## Verbindung überprüfen

Klicke auf **Save & Restart**. Wähle **Continue with Gateway** und sende dann eine kurze Nachricht. Die Einrichtung ist aktiv, wenn **Gateway** unten links erscheint und die Nachricht normal beantwortet wird.

## Modelle wechseln

Öffne die Modellauswahl und wähle ein anderes vom Gateway zurückgegebenes Claude-Modell. Falls das Modell fehlt, öffne **Configure Third-Party Inference...** erneut, klicke auf **Apply locally** und starte Claude Desktop neu.

## Häufige Fehler

| Problem | Lösung |
| --- | --- |
| Gateway kann keine Verbindung herstellen | Verwende genau `{{anthropic-base-url}}` für **Gateway base URL**. Hänge nicht `/v1` an. |
| Request gibt `401` zurück | Kopiere den BetterToken API Key erneut und bestätige, dass das Authentifizierungsschema `x-api-key` ist. |
| Keine Claude-Modelle erscheinen | Kopieren Sie eine verfügbare Claude Model ID aus der model plaza, speichern Sie und starten Sie Claude Desktop neu. |
| Konfiguration wird nicht übernommen | Beende Claude Desktop vollständig, öffne es erneut und wähle **Continue with Gateway**. |
