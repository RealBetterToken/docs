Claude Desktop unterstützt nur Claude-Modelle. Dies ist eine Einschränkung des Claude Desktop-Clients.

## Einrichtung

Folgen Sie der [Claude Desktop-Anleitung](/de/faq/claude-desktop-bettertoken-api): Wählen Sie **Gateway**, die Base URL `{{anthropic-base-url}}`, Ihren BetterToken API Key und **Gateway auth scheme** `x-api-key`. Klicken Sie auf **Apply locally** und starten Sie Claude Desktop vollständig neu.

Kopieren Sie die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Fehlerbehebung

### 401 / Unauthorized

Prüfen Sie, ob der API Key vollständig und noch gültig ist. Verwenden Sie für dieses Gateway `x-api-key`, speichern Sie und starten Sie Claude Desktop neu.

### Modell

Kopieren Sie eine verfügbare Claude Model ID aus der model plaza, speichern Sie und starten Sie Claude Desktop neu.
