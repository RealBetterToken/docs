## Kurzantwort

Claude Desktop kann sich über MCP-Server mit lokalen Tools und Datenquellen verbinden. Du deklarierst den Server in der MCP-Konfiguration von Claude Desktop, startest die Verbindung neu oder aktualisierst sie und prüfst den Verbindungsstatus in der App.

MCP ist keine Modell-API. Es ermöglicht Claude Desktop Zugriff auf Tools oder Kontext. Modell-Requests hängen weiterhin vom Modell und Kontoweg ab, den Claude Desktop aktuell verwendet.

## Wann du es benötigst

- Du möchtest, dass Claude Desktop auf lokale Dateien, Datenbanken oder Entwicklungstools zugreift
- Du siehst eine MCP-Server-Konfiguration, weißt aber nicht, wo sie hingehört
- Du vergleichst lokales MCP und Remote-MCP
- Du denkst, MCP könne API Key / Base URL ersetzen
- Du musst prüfen, ob MCP verbunden ist

## Lokales MCP und Remote-MCP im Vergleich

| Typ | Bedeutung |
| --- | --- |
| Lokales MCP | Führt einen Server auf deinem Rechner aus, oft für lokale Tools, Dateien oder Entwicklungsumgebungen |
| Remote-MCP | Verbindet sich mit einem Remote-Dienst, oft für Cloud-Tools oder Teamdienste |
| Desktop-Erweiterung | Ein stärker auf Desktop ausgerichtetes Installations- und Verteilungsformat |

## Empfohlene Einrichtung

1. Bestätige, dass du einen MCP-Server und keinen Modell-Provider verbindest.
2. Füge die lokale oder Remote-MCP-Konfiguration entsprechend der Claude-Desktop-Dokumentation hinzu.
3. Starte Claude Desktop neu oder aktualisiere es.
4. Prüfe den MCP-Verbindungsstatus in Claude Desktop.
5. Gib dem MCP-Server nur die Berechtigungen und Umgebungsvariablen, die er benötigt.

## Häufige Fehler

- Einen MCP-Server als Base URL behandeln.
- Einen Modell-API-Key in die MCP-Konfiguration einfügen.
- Annehmen, dass MCP Modellkosten ändert.
- Vergessen, dass ein MCP-Server auf sensible lokale Daten zugreifen kann.
- Nur die Claude-Desktop-UI prüfen, wenn der lokale Server nicht läuft.

## Über BetterToken

BetterToken übernimmt Modell-API-Zugriff, nicht MCP-Server. Claude Desktop MCP verbindet Tools. API-Schichten wie BetterToken behandeln Modell-Requests, Guthaben und Nutzung.

Wenn du sowohl Tool-Zugriff als auch einheitliches Modellrouting benötigst, konfiguriere MCP und API-Zugriff getrennt.
