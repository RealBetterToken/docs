Nachdem du das BetterToken Gateway in Claude Desktop konfiguriert hast, bedeuten die folgenden Symptome normalerweise nicht, dass der API Key selbst ungültig ist:

- Cowork-Modus funktioniert nicht
- Code-Modus zeigt `Claude Code process exited with code 1`
- Derselbe API Key funktioniert in Claude Code CLI über ein Terminal

Wenn du das Gateway noch nicht konfiguriert hast, beginne mit [BetterToken API in Claude Desktop verwenden](/de/faq/claude-desktop-bettertoken-api).

## Zuerst Cowork-Modus beheben

Claude Desktop unterstützt nur Claude-Modelle. Dies ist eine Einschränkung des Claude Desktop-Clients.

Prüfen Sie, ob der API Key vollständig und noch gültig ist. Verwenden Sie für dieses Gateway `x-api-key`, speichern Sie und starten Sie Claude Desktop neu.

Folgen Sie der [Claude Desktop-Anleitung](/de/faq/claude-desktop-bettertoken-api): Wählen Sie **Gateway**, die Base URL `{{anthropic-base-url}}`, Ihren BetterToken API Key und **Gateway auth scheme** `x-api-key`. Klicken Sie auf **Apply locally** und starten Sie Claude Desktop vollständig neu.

## Danach Exit-Fehler im Code-Modus beheben

Wenn Cowork funktioniert, der Code-Modus im Tab `</>` aber weiterhin `Claude Code process exited with code 1` zeigt, prüfe, ob Claude Desktop noch eine ältere gebündelte Claude-Code-Version verwendet.

**Grundursache**: Claude Desktop lädt möglicherweise im Hintergrund eine neuere Claude-Code-Version herunter. Bevor der Download abgeschlossen ist, kann der Code-Modus auf eine ältere installierte Claude-Code-Version zurückfallen. Diese ältere Version ist möglicherweise nicht mit der Nutzung eines Drittanbieter-Gateways im Code-Modus kompatibel, sodass der Prozess sofort endet.

**So behebst du es:**

<Steps>
  <Step title="Warte, bis der Download der neueren Claude-Code-Version abgeschlossen ist">
    Lasse Claude Desktop eine Weile geöffnet, damit die Claude-Code-Aktualisierung im Hintergrund abgeschlossen werden kann.
  </Step>

  <Step title="Claude Desktop vollständig beenden">
    Verwende **Cmd+Q**, um die App vollständig zu beenden. Schließe nicht nur das Fenster.
  </Step>

  <Step title="Erneut öffnen und eine neue Code-Sitzung starten">
    Öffne Claude Desktop erneut, wechsle in den Code-Modus und starte eine neue Sitzung.
  </Step>
</Steps>

<Note>
  Wenn Logs zeigen, dass Claude Desktop auf eine ältere Claude-Code-Version wie `2.1.111` zurückfällt, während eine neuere Version wie `2.1.119` noch nicht bereit ist, warte auf den Abschluss des Downloads und starte die App dann neu.
</Note>

## Schnellübersicht

| Symptom | Häufige Grundursache | Lösung |
|---------|-------------------|-----|
| Cowork | Gateway auth scheme | Prüfen Sie, ob der API Key vollständig und noch gültig ist. Verwenden Sie für dieses Gateway `x-api-key`, speichern Sie und starten Sie Claude Desktop neu. |
| Code-Modus zeigt `Claude Code process exited with code 1` | Claude Desktop fällt auf eine ältere Claude-Code-Version zurück | Warte auf den Abschluss des Downloads der neueren Version, beende mit **Cmd+Q** vollständig und öffne die App erneut |
