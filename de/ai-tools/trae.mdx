Um TRAE mit BetterToken zu verbinden, bereite einen API Key vor, trage die unten angezeigte Base URL ein und wähle eine aktuelle Model ID aus der model plaza.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Vollständige Request-URL | `{{chat-completions-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

## Installation

Installiere oder öffne TRAE und fahre dann mit der manuellen Einrichtung unten fort.

## Manuelle Einrichtung

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Vollständige Request-URL | `{{chat-completions-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Einrichtung

<Steps>
  <Step title="Einstellungen öffnen">
    Klicke im **IDE**-Modus oben rechts auf das Symbol **Settings**, um das Einstellungszentrum zu öffnen.

    Du kannst auch den **SOLO**-Modus öffnen und oben rechts im Chatbereich auf **Settings** klicken.
  </Step>

  <Step title="Modellbereich öffnen">
    Wähle in der linken Navigation **Model**, um den Bereich **Model** zu öffnen.
  </Step>

  <Step title="Modell hinzufügen">
    Klicke auf **+ Add model**.

    ![TRAE-Modellbereich mit hervorgehobenem Einstellungszugang, Navigationseintrag für Modelle und Schaltfläche zum Hinzufügen eines Modells.](/images/trae/add-model.png)
  </Step>

  <Step title="Modellkonfiguration ausfüllen">
    Wenn das Fenster **Add model** erscheint, fülle die Felder wie folgt aus:

    | Feld | Wert |
    |-------|-------|
    | Provider | `OpenAI` |
    | Model | `Custom model` |
    | Model ID | eine **Model ID eines unterstützten Providers** aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | API key | dein aus der BetterToken-Konsole kopierter API Key |
    | Custom request URL | `{{chat-completions-url}}` |

    ![TRAE-Fenster zum Hinzufügen eines Modells mit ausgewähltem OpenAI, ausgewähltem eigenen Modell und Feldern für Model ID, API Key und eigene Request-URL.](/images/trae/model-config.png)
  </Step>

  <Step title="Speichern und verwenden">
    Klicke auf **Confirm**, um die Konfiguration zu speichern, und wähle dann das neue Modell eines unterstützten Providers aus.
  </Step>
</Steps>

<Note>
  BetterToken unterstützt TRAE nur über **Modelle eines unterstützten Providers**. Verwende keine festgelegten Claude-Modellnamen und setze die eigene Request-URL nicht auf `{{openai-base-url}}`.
</Note>

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfung |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne vorangestellte oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen bestimmten Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht übernommen | Speichere die Konfiguration und starte das Tool vollständig neu. |
