Um Roo Code mit BetterToken zu verbinden, bereite einen API Key vor, trage die unten angezeigte Base URL ein und wähle eine aktuelle Model ID aus der model plaza.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

- VS Code ist installiert

## Installation

### Roo Code installieren

Öffne VS Code, suche im Erweiterungs-Marktplatz nach **Roo Code** und installiere es.

## Manuelle Einrichtung

Führe diese Einrichtung in der Roo-Code-Einstellungsoberfläche durch. Du musst keine Konfigurationsdatei bearbeiten.

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Einrichtung

<Steps>
  <Step title="Konfligierende Umgebungsvariablen löschen">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Roo-Code-Einstellungen öffnen">
    Öffne den Bereich **Settings** von Roo Code.
  </Step>

  <Step title="API-Provider konfigurieren">
    Trage Folgendes ein:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → dein BetterToken API Key
    - **Model** → eine **Model ID eines unterstützten Providers** aus der <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Zusätzliche Header nur konfigurieren, wenn die offizielle Dokumentation sie ausdrücklich verlangt">
    Die geprüfte offizielle Roo-Code-Dokumentation behandelt OpenAI-kompatible oder eigene API-Einrichtungen, nennt aber keinen zusätzlichen `User-Agent` als erforderlichen BetterToken-Schritt.

    Wenn du zusätzlich ein eigenes Gateway, Tenant-Routing, Observability oder eine Caching-Schicht verwendest, füge Header nur entsprechend der offiziellen Dokumentation dieses Upstream-Dienstes hinzu.
  </Step>

  <Step title="Speichern und verwenden">
    Klicke auf **Save** und **Done** und wähle dann das konfigurierte Modell aus.
  </Step>

  <Step title="Roo Code neu starten">
    Starte nach dem Speichern der Konfiguration VS Code neu oder lade die Roo-Code-Erweiterung neu, bevor du das konfigurierte Modell auswählst.
  </Step>
</Steps>

<Note>
  Der OpenAI-Compatible-Provider von Roo Code hängt weiterhin von Tool-Calls im OpenAI-Stil ab. Falls du zusätzliche Header brauchst, folge der aktuellen Roo-Code-Dokumentation oder den Anforderungen deines Upstream-Gateways, statt anzunehmen, dass `User-Agent` für BetterToken erforderlich ist.
</Note>

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfung |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne vorangestellte oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen bestimmten Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht übernommen | Speichere die Konfiguration und starte das Tool vollständig neu. |

## Technische Details

<Accordion title="Protokoll, Endpunkt und interne Provider-Felder">
  Diese Einrichtung verwendet `{{openai-base-url}}`. Das Tool hängt den OpenAI-kompatiblen Endpunktpfad an. Füge `/chat/completions` oder `/responses` nicht hinzu, sofern ein bestimmtes Feld dies nicht ausdrücklich verlangt.
</Accordion>
