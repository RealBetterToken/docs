Um Kilo Code mit BetterToken zu verbinden, bereite einen API Key vor, trage die unten angezeigte Base URL ein und wähle eine aktuelle Model ID aus der model plaza.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

- VS Code installiert

## Installation

Installiere oder öffne Kilo Code und fahre dann mit der manuellen Einrichtung unten fort.

## Manuelle Einrichtung

Führe diese Einrichtung in der Kilo-Code-Einstellungsoberfläche durch. Du musst keine Konfigurationsdatei bearbeiten.

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Einrichtung

<Steps>
  <Step title="Konfliktierende Umgebungsvariablen löschen">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Kilo-Code-Einstellungen öffnen">
    Öffne die Kilo-Code-Einstellungsoberfläche.
  </Step>

  <Step title="API Provider konfigurieren">
    Gib Folgendes ein:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → dein BetterToken API Key
    - **Model** → eine **Model ID eines unterstützten Providers** aus der <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Zusätzliche Header nur bei ausdrücklicher Anforderung der offiziellen Dokumentation konfigurieren">
    Die geprüften offiziellen Kilo-Code-Unterlagen erwähnen optionale eigene Header für OpenAI-kompatible Provider, behandeln `User-Agent` jedoch nicht als erforderlichen BetterToken-Einrichtungsschritt.

    Wenn du zusätzlich ein eigenes Gateway, Tenant-Routing, Observability oder eine Caching-Schicht verwendest, füge Header nur gemäß der offiziellen Dokumentation dieses Upstream-Dienstes hinzu.
  </Step>

  <Step title="Kilo Code neu starten">
    Starte nach der Konfigurationsänderung VS Code neu oder lade die Kilo-Code-Extension erneut, damit die neuen Einstellungen wirksam werden.
  </Step>
</Steps>

<Note>
  Wenn du zusätzliche Header benötigst, folge der aktuellen Kilo-Code-Dokumentation oder den Anforderungen deines Upstream-Gateways, statt anzunehmen, dass `User-Agent` für BetterToken obligatorisch ist.
</Note>

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfen |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne führende oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen spezifischen Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht angewendet | Speichere die Konfiguration und starte das Tool vollständig neu. |

## Technische Details

<Accordion title="Protokoll, Endpunkt und interne Provider-Felder">
  Diese Einrichtung verwendet `{{openai-base-url}}`. Das Tool hängt den OpenAI-kompatiblen Endpunktpfad an. Füge `/chat/completions` oder `/responses` nicht hinzu, sofern ein bestimmtes Feld dies nicht ausdrücklich verlangt.
</Accordion>
