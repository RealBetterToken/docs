CC Switch ist eine plattformübergreifende Desktop-App zur Verwaltung von Providern für Claude Code, Claude Desktop, Codex, OpenCode und OpenClaw. Diese Seite bündelt die erweiterte Einrichtung. Beginne mit der direkten Einrichtungsseite des jeweiligen Tools und verwende CC Switch nur, wenn du Provider wechseln oder ein nicht natives Modell verwenden musst.

## CC Switch installieren

<Tabs>
  <Tab title="macOS">
    Homebrew ist die einfachste Option. Du kannst auch die neueste `.dmg`- oder `.zip`-Datei aus den [GitHub Releases](https://github.com/farion1231/cc-switch/releases) herunterladen.

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    Lade das neueste Installationsprogramm `CC-Switch-v{version}-Windows.msi` oder die portable `.zip`-Version aus den [GitHub Releases](https://github.com/farion1231/cc-switch/releases) herunter.
  </Tab>
  <Tab title="Linux">
    Lade die neueste `.deb`-, `.rpm`- oder `.AppImage`-Version aus den [GitHub Releases](https://github.com/farion1231/cc-switch/releases) herunter.
  </Tab>
</Tabs>

## Was du vorbereiten musst

- BetterToken API Key (<a href={"{{register-url}}"}>hier registrieren</a>)
- Claude Code verwendet das Anthropic-Protokoll, daher ist seine `Base URL` `{{anthropic-base-url}}`
- Claude Desktop mit einem nicht-Claude Provider erfordert die neueste Version von Claude Desktop und CC Switch `v3.16.5` oder höher
- Codex, OpenCode und OpenClaw verwenden das OpenAI-kompatible Protokoll, daher ist ihre `Base URL` `{{openai-base-url}}`
- Bereite eine aktuelle Modell-ID des **GPT Providers** für Codex, OpenCode und OpenClaw vor. Du kannst sie aus der <a href={"{{model-plaza-url}}"}>BetterToken model plaza</a> kopieren oder von CC Switch über `/v1/models` abrufen lassen

<Info>
  Beim ersten Start importiert CC Switch automatisch die bereits auf deinem Rechner gefundenen Konfigurationen. Du kannst deinen offiziellen Provider als Fallback behalten und BetterToken zusätzlich hinzufügen.
</Info>

<Note>
  BetterToken verwendet zwei Zugriffsmodi: Anthropic und OpenAI-kompatibel. Um `{{anthropic-base-url}}` und `{{openai-base-url}}` nicht zu vermischen, solltest du Provider pro App erstellen, statt Claude Code und die OpenAI-kompatiblen Tools in einen universellen Provider zu zwingen.
</Note>

## BetterToken Provider hinzufügen

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    <Steps>
      <Step title="Claude Code in CC Switch öffnen und Provider hinzufügen">
        Öffne CC Switch, wechsle zu **Claude Code** und klicke auf **Add Provider**.

        <Frame>
          <img
            src="/images/cc-switch/claude-code-add-provider.png"
            alt="Die Claude-Code-Seite in CC Switch mit der Schaltfläche oben rechts zum Erstellen eines neuen Providers."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Grundfelder ausfüllen">
        - **Provider Name**: `BetterToken-claude` (oder ein anderer leicht erkennbarer Name)
        - **Base URL**: `{{anthropic-base-url}}`
        - **API Key**: dein BetterToken API Key
        - **API Format**: `OpenAI Responses API`

        Die nummerierten Markierungen im Screenshot entsprechen diesen Feldern:

        1. **Provider Name**
        2. **API Key**
        3. **Base URL**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-basic-fields.png"
            alt="Die Bearbeitungsseite des Claude-Code-Providers in CC Switch mit den Feldern Provider Name, API Key und API Endpoint."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Modellzuordnung je nach Provider einrichten">
        - Wenn du den **Claude Provider** verwendest, musst du die erweiterten Optionen oder Modellzuordnung normalerweise nicht ändern
        - Wenn du den **GPT Provider** verwendest, führe die zusätzliche Einrichtung unten durch:

        1. Öffne **Advanced Options**
        2. Setze **API Format** auf **OpenAI Responses API**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-api-format.png"
            alt="Der Bereich für erweiterte Optionen in CC Switch mit API Format auf OpenAI Responses API."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        3. Klicke in **Model Mapping** auf **Fetch Model List**
        4. Wähle Werte aus den Dropdowns für **Primary Model**, **Thinking Model**, **Haiku Default Model**, **Sonnet Default Model** und **Opus Default Model** ausdrücklich aus

        <Frame>
          <img
            src="/images/cc-switch/claude-code-model-mapping.png"
            alt="Der Bereich für Modellzuordnung in CC Switch mit Fetch Model List und Zuordnungen für Primary-, Thinking-, Haiku-, Sonnet- und Opus-Modelle."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Für alle diese Modelle sollten aktuelle Modell-IDs des **GPT Providers** aus der <a href={"{{model-plaza-url}}"}>BetterToken model plaza</a> verwendet werden.
      </Step>

      <Step title="Speichern, wechseln und über Proxy-Aktivierung entscheiden">
        Gehe nach dem Speichern zurück zur Provider-Liste:

        1. Markiere den BetterToken Provider als aktiv
        2. Wenn du den **Claude Provider** verwendest, musst du den **CC Switch proxy** oben links nicht aktivieren
        3. Wenn du den **GPT Provider** verwendest, aktiviere den **CC Switch proxy**

        Der Screenshot unten zeigt BetterToken-claude in der Provider-Liste aktiviert. Aktiviere den **CC Switch proxy** oben links nur, wenn du den **GPT Provider** verwendest.

        <Frame>
          <img
            src="/images/cc-switch/claude-code-enable-proxy.png"
            alt="Die CC-Switch-Provider-Liste mit ausgewähltem und als In Use markiertem BetterToken-claude."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

          <img

        | Fable | `YOUR_MODEL_ID` |
        | Haiku | `YOUR_MODEL_ID` |

        <Frame>

## Gespeicherte Änderungen anwenden

Starte nach dem Speichern und Wechseln des Providers den betroffenen Client oder das Gateway neu, bevor du die Einrichtung überprüfst.

- Claude Code: Beende die aktuelle Claude-Code-Sitzung vollständig und starte sie erneut.
- Claude Desktop: Beende die App vollständig, öffne sie erneut und bestätige, dass **Gateway** unten links erscheint.
- Codex: Starte den aktuellen Codex-Prozess neu oder öffne eine neue Terminal-Sitzung.
- OpenCode: Beende die aktuelle OpenCode-Sitzung und starte sie erneut.
- OpenClaw: Führe `openclaw gateway restart` aus und verwende dann `/new`, `/status` und `/model` in Discord.

## Erweiterte CC-Switch-Funktionen

CC Switch kann beim Wechsel zu einem Drittanbieter die offizielle Codex-Anmeldung beibehalten und offizielle sowie Drittanbieter-Sitzungen in einem Verlauf zusammenführen. Starte Codex nach der Aktivierung dieser Optionen neu. Siehe [offizielle Codex-Anmeldung und einheitlichen Sitzungsverlauf beibehalten](/de/faq/codex/official-login-third-party-api).

## Häufige Probleme

- Füge `/v1` nicht zur Claude-Code-`Base URL` hinzu
- Wenn Claude Code den **GPT Provider** verwendet, setze **API Format** unter **Advanced Options** auf **OpenAI Responses API**
- Wenn Claude Code den **Claude Provider** verwendet, musst du den **CC Switch proxy** nicht aktivieren
- Wenn Claude Desktop einen nicht-Claude Provider verwendet, aktiviere den **CC Switch proxy** und starte die App vollständig neu
- Codex, OpenCode und OpenClaw sollten `{{openai-base-url}}` verwenden
- Wenn Codex, OpenCode oder OpenClaw nach einem Modell fragt, verwende eine Modell-ID des **GPT Providers**
- Wenn **Fetch Models** fehlschlägt, prüfe den API Key und die `Base URL` und füge die Model ID anschließend manuell ein
- Wenn der Wechsel nicht wirksam wird, bestätige, dass BetterToken der aktive Provider in CC Switch ist, und starte den betroffenen Client oder das Gateway wie oben beschrieben neu
