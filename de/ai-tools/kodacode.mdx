Um Kodacode mit BetterToken zu verbinden, bereite einen API Key vor, trage die unten angezeigte Base URL ein und wähle eine aktuelle Model ID aus der model plaza.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

- VS Code ist installiert
- Die Kodacode-/Koda-Extension ist installiert
- Die ausgewählte Model ID stammt vom **unterstützten Provider**

## Installation

Installiere oder öffne Kodacode und fahre dann mit der manuellen Einrichtung unten fort.

## Manuelle Einrichtung

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Beispiel für config.yaml

Verwende diese vollständige Struktur als Referenz. Ersetze `YOUR_API_KEY` durch deinen BetterToken API Key und committe keinen echten API Key in dein Repository.

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: YOUR_MODEL_ID
    provider: openai
    model: YOUR_MODEL_ID
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  Wenn du ein anderes Modell als `YOUR_MODEL_ID` verwendest, aktualisiere sowohl `name` als auch `model`, damit sie der Model ID eines unterstützten Providers aus der <a href={"{{model-plaza-url}}"}>model plaza</a> entsprechen.
</Note>

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfen |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne führende oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen spezifischen Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht angewendet | Speichere die Konfiguration und starte das Tool vollständig neu. |


- Wenn die Verbindung fehlschlägt, bestätige, dass **API Base** `{{openai-base-url}}/` ist, und behalte das abschließende `/` bei.
- Wenn das Modell nicht verfügbar ist, bestätige, dass **Model ID** vom unterstützten Provider stammt.
- Wenn die Authentifizierung fehlschlägt, kopiere den API Key erneut und vermeide zusätzliche Leerzeichen oder Zeilenumbrüche.
- Wenn Änderungen an `config.yaml` nicht angewendet werden, starte VS Code neu oder führe **Developer: Reload Window** aus.
- BetterToken benötigt normalerweise keinen zusätzlichen `User-Agent` oder eigene Header.

</Accordion>
