MonkeyCode ist ein KI-Coding-Tool, in dem du unter **AI Model** ein eigenes Modell hinzufügen kannst. Diese Seite erklärt nur, wie du die MonkeyCode-Oberfläche mit API Key, Base URL und Model ID an BetterToken anschließt; sie dokumentiert keine eigene offizielle MonkeyCode API. Betrifft das Problem Kodacode / Koda, nutze die [Anleitung zur Kodacode-Einrichtung und zu 429-Fehlern](/de/ai-tools/kodacode). Produktinformationen und Downloads findest du auf der [MonkeyCode-Website](https://monkeycode.ai).

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

- MonkeyCode-Konto ([bei MonkeyCode registrieren](https://monkeycode.ai))

## Installation

Installiere oder öffne MonkeyCode und fahre dann mit der manuellen Einrichtung unten fort.

## Manuelle Einrichtung

Führe diese Einrichtung in der MonkeyCode-Einstellungsoberfläche durch. Du musst keine Konfigurationsdatei bearbeiten.

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Einrichtung

<Steps>
  <Step title="Bei MonkeyCode anmelden">
    Besuche [MonkeyCode](https://monkeycode.ai) und melde dich an.
  </Step>

  <Step title="Systemeinstellungen öffnen">
    Öffne die Aufgabenseite und klicke dann unten rechts auf **Settings**.
  </Step>

  <Step title="KI-Modell verbinden">
    Klicke im Abschnitt **AI Model** auf **Bind**.
  </Step>

  <Step title="BetterToken-Konfiguration ausfüllen">

| Feld | Wert |
    |-------|-------|
    | Model API URL | `{{openai-base-url}}` |
| API Key | dein BetterToken API Key |
| API format | `OpenAI` oder `OpenAI Compatible` (folge der aktuellen UI-Bezeichnung) |
| Model name | eine **Model ID eines unterstützten Providers** aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Zusätzliche Header nur bei ausdrücklicher Anforderung der offiziellen Dokumentation konfigurieren">
    Wir haben keine offizielle MonkeyCode-Einrichtungsanforderung gefunden, die `User-Agent` für BetterToken obligatorisch macht. Beginne mit der auf dieser Seite gezeigten `Base URL`, API Key und Model ID.

    Wenn du zusätzlich ein eigenes Gateway, Tenant-Routing, Observability oder eine Caching-Schicht verwendest, füge Header nur gemäß der offiziellen Dokumentation dieses Upstream-Dienstes hinzu.
  </Step>

  <Step title="Speichern und verwenden">
    Klicke auf **Save**, kehre dann zur Hauptseite zurück und wähle das gerade konfigurierte Modell aus.
  </Step>

  <Step title="MonkeyCode neu starten">
    Aktualisiere nach dem Speichern der Konfiguration die Seite oder öffne MonkeyCode erneut, bevor du das neue Modell verwendest.
  </Step>
</Steps>

<Note>
  Wenn du zusätzliche Header benötigst, folge der aktuellen MonkeyCode-Dokumentation oder den Anforderungen deines Upstream-Gateways, statt anzunehmen, dass `User-Agent` für BetterToken obligatorisch ist.
</Note>

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfen |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne führende oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen spezifischen Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht angewendet | Speichere die Konfiguration und starte das Tool vollständig neu. |

## Technische Details

<Accordion title="Protokoll, Endpunkt und interne Provider-Felder">
  Diese Einrichtung verwendet `{{openai-base-url}}`. Das Tool hängt den OpenAI-kompatiblen Endpunktpfad an. Füge `/chat/completions` oder `/responses` nicht hinzu, sofern ein bestimmtes Feld dies nicht ausdrücklich verlangt.
</Accordion>
