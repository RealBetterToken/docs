Um Hermes Agent mit BetterToken zu verbinden, bereite einen API Key vor, trage die unten angezeigte Base URL ein und wähle eine aktuelle Model ID aus der model plaza.

## Wichtige Einstellungen

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Eine aktuelle Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Voraussetzungen

- Die aktuelle Version des Tools ist installiert
- Ein BetterToken API Key: <a href={"{{register-url}}"}>Registriere dich und erhalte einen</a>
- Eine Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a>

### Zusätzliche Anforderungen

- Die ausgewählte Model ID stammt vom **unterstützten Provider**
- macOS, Linux oder Windows WSL2

Verwende die interaktive Hermes-Agent-Modell-Einrichtung als primären Weg. Befehls- und Umgebungsvariablen-Optionen bleiben als Alternativen verfügbar.

| Feld | Wert |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |

### Einrichtung

<Tabs>
  <Tab title="Interactive setup">
    <Steps>
      <Step title="Modellauswahl ausführen">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="OpenAI- oder OpenAI-Compatible-Provider auswählen">
        Wähle **OpenAI** oder **OpenAI Compatible** aus der Provider-Liste.
      </Step>

      <Step title="BetterToken-Konfiguration ausfüllen">
        Gib Folgendes ein:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: dein BetterToken API Key
        - **Model**: eine **Model ID eines unterstützten Providers** aus der <a href={"{{model-plaza-url}}"}>model plaza</a>
      </Step>

      <Step title="Hermes Agent neu starten">
        Beende nach der Aktualisierung der Konfiguration die aktuelle Hermes-Agent-Sitzung und starte sie erneut.
      </Step>

      <Step title="Hermes Agent starten">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI config">
    Wenn du Befehle lieber kopierst und einfügst, schreibe die Hermes-Agent-Konfiguration direkt.

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_API_KEY"
    hermes config set llm.model "YOUR_MODEL_ID"
    ```

    Ersetze `YOUR_API_KEY` durch deinen BetterToken API Key und `YOUR_MODEL_ID` durch eine Model ID eines unterstützten Providers aus der <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Starte anschließend Hermes Agent:

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="Environment variables">
    Wenn du den API Key nicht in der Hermes-Agent-Konfiguration speichern möchtest, exportiere ihn in der aktuellen Shell.

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"
    export HERMES_MODEL="YOUR_MODEL_ID"
    hermes
    ```

    Diese Variablen gelten nur für die aktuelle Shell-Sitzung. Exportiere sie in einem neuen Terminal erneut oder füge sie deinem eigenen Shell-Profil hinzu.
  </Tab>
</Tabs>

### Von OpenClaw migrieren

Wenn du bereits OpenClaw verwendest, prüfe zuerst, ob deine aktuelle Hermes-Agent-Version den Migrationsbefehl bereitstellt. Führe vor jeder Änderung einen Testlauf durch.

```bash
hermes claw migrate --dry-run
```

Führe nach Bestätigung der Ausgabe die Migration aus:

```bash
hermes claw migrate
```

Prüfe nach der Migration weiterhin die Hermes-Agent-**Base URL**, API Key und Model ID. Sie sollten `{{openai-base-url}}`, deinem BetterToken API Key und einer Model ID eines unterstützten Providers entsprechen.

## Verbindung überprüfen

Sende eine kurze Testanweisung. Wenn das Tool ohne Authentifizierungs- oder Model-ID-Fehler antwortet, funktioniert die Verbindung. Starte das Tool nach einer Konfigurationsänderung vollständig neu.

## Modelle wechseln

Öffne die Modellauswahl oder ändere das Feld `Model` in der Konfiguration. Verwende die genaue Model ID aus der <a href={"{{model-plaza-url}}"}>model plaza</a> und starte dann die aktuelle Sitzung neu.

## Häufige Fehler

| Fehler | Prüfen |
| --- | --- |
| `401` oder `Unauthorized` | Prüfe den BetterToken API Key und entferne führende oder nachgestellte Leerzeichen. |
| `404` | Prüfe die Base URL und hänge keinen spezifischen Endpunktpfad an. |
| `model not found` | Kopiere eine aktuelle Model ID aus der model plaza. |
| Änderungen werden nicht angewendet | Speichere die Konfiguration und starte das Tool vollständig neu. |


### Fehlerbehebung

- Wenn Requests fehlschlagen oder keine Antwort zurückgeben, bestätige, dass **Base URL** genau `{{openai-base-url}}` ist. Hänge in diesem Feld nicht `/chat/completions` an.
- Wenn Hermes meldet, dass das Modell nicht existiert, bestätige, dass **Model** eine Model ID eines unterstützten Providers aus der <a href={"{{model-plaza-url}}"}>model plaza</a> ist.
- Wenn die Authentifizierung fehlschlägt, prüfe auf kopierte Leerzeichen und bestätige, dass die ausgewählte Model ID vom **unterstützten Provider** stammt.
- Wenn Hermes nach einer Änderung weiterhin das alte Modell verwendet, beende die aktuelle Hermes-Agent-Sitzung und führe `hermes` erneut aus.
- BetterToken benötigt normalerweise keinen zusätzlichen `User-Agent` oder eigene Header. Füge Header nur hinzu, wenn dein eigenes Gateway, Tenant-Routing, deine Observability- oder Caching-Schicht sie ausdrücklich verlangt.

<Note>
  Committe keine echten API Keys in dein Repository. Bevorzuge für teamübergreifende Einrichtung Umgebungsvariablen oder lokale Konfiguration.
</Note>
