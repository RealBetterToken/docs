Aktualisiert: 30. September 2026

**GPT-6.1 Sol** ist eine Weiterentwicklung von GPT-6 Sol. Laut OpenAI verbessert das Modell agentische Programmierung, Computerbedienung und professionelle Aufgaben und nähert sich in einzelnen Bewertungen GPT-6 Astra an. Vergleiche für anspruchsvolle Aufgaben Qualität, Latenz und Verbrauch in deinem eigenen Ablauf.

BetterToken bietet die Model ID `gpt-6.1-sol` an. Aktuelle Verfügbarkeit und BetterToken-Preise findest du auf der <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Wichtige Merkmale

- **Code und Agenten**: geeignet für Änderungen an mehreren Dateien, Debugging und längere Softwareentwicklungsaufgaben.
- **Anwendungen und Dokumente**: OpenAI berichtet über Verbesserungen gegenüber GPT-6 Sol.
- **Großer Kontext**: OpenAI nennt ein Kontextfenster von `1,050,000` Tokens und bis zu `128,000` Ausgabetokens. Client und Zugangsweg können niedrigere Grenzen setzen.
- **Anpassbares Reasoning**: `low`, `medium`, `high`, `xhigh` und `max` werden unterstützt; `none` und `minimal` nicht.

## Verbindung einrichten

1. <a href={"{{register-url}}"}>Erstelle einen BetterToken API Key</a>.
2. Verwende in Codex CLI oder einem anderen OpenAI-kompatiblen Client `{{openai-base-url}}` als Base URL und `gpt-6.1-sol` als Model ID.
3. Wenn du Tools aufrufen willst, nutze die [Responses API](/de/api-reference/responses). OpenAI dokumentiert Chat Completions für dieses Modell ohne Tool-Aufrufe.
4. Teste eine typische Aufgabe, bevor du einen bestehenden Ablauf umstellst.

Für Claude Code verwende die Base URL des Anthropic-Protokolls `{{anthropic-base-url}}` mit derselben Model ID. Siehe die Anleitungen für [Claude Code](/de/ai-tools/claude-code) und [Codex CLI](/de/ai-tools/codex).
