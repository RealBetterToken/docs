Aktualisiert: 5. September 2026

BetterToken unterstützt jetzt **GPT-6 Astra** mit der exakten Model ID `gpt-6-astra`. OpenAI beschreibt Astra als sein leistungsfähigstes Modell für anspruchsvolle End-to-End-Arbeit, darunter komplexes Schlussfolgern, Softwareentwicklung, Recherche, Computersteuerung und Dokumenterstellung. Aktuelle Verfügbarkeit und BetterToken-Preise findest du in der <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Highlights

- **End-to-End-Arbeit**: für komplexe, mehrstufige Aufgaben mit Code, Browsern, Werkzeugen und professionellen Anwendungen entwickelt
- **Softwareentwicklung**: OpenAI positioniert Astra als sein bisher stärkstes Modell für Programmierung und agentische Entwicklung
- **Großer Kontext**: OpenAI dokumentiert ein Kontextfenster von `1.050.000` Tokens und bis zu `128.000` Output-Tokens
- **Anpassbares Reasoning**: Die OpenAI API unterstützt `low`, `medium`, `high`, `xhigh` und `max`
- **Responses-API-Werkzeuge**: OpenAI dokumentiert Function Calling, strukturierte Ausgaben, Web- und Dateisuche, Code Interpreter, Computer Use und MCP

## Konfigurationsempfehlungen

- Nutze Astra für anspruchsvolle Programmierung, Recherche, Computer Use oder lang laufende Agentenaufgaben. Für Routinearbeiten solltest du es mit schnelleren oder günstigeren Modellen in der model plaza vergleichen.
- Teste vor der Umstellung von Produktionsverkehr eine repräsentative Aufgabe und vergleiche Qualität, Latenz und Tokenverbrauch.
- Wähle den **GPT provider**, verwende die Base URL `{{openai-base-url}}` und die exakte Model ID `gpt-6-astra`.
- Der Zugang kann schrittweise freigeschaltet werden. Für BetterToken-Verfügbarkeit und Preise ist die model plaza maßgeblich.

## Schnellstart

1. Erstelle eine BetterToken API Key oder öffne **Setup** für einen vorhandenen Key.
2. Prüfe in der model plaza, ob `gpt-6-astra` verfügbar ist.
3. Setze die Base URL auf `{{openai-base-url}}` und das Modell auf `gpt-6-astra`.
4. Starte den Client neu, wenn die Modellliste nicht automatisch aktualisiert wird.
5. Führe eine kleine Testaufgabe aus und prüfe die Anfrage im Dashboard.

## Häufige Fragen

### Wie lautet die Model ID von GPT-6 Astra?

Verwende `gpt-6-astra`. Nutze weder den Anzeigenamen `GPT-6 Astra` noch eine ID von einer anderen Plattform.

### Bietet BetterToken den vollständigen Kontext von 1.050.000 Tokens?

OpenAI gibt für GPT-6 Astra ein Kontextfenster von `1.050.000` Tokens an. Das nutzbare Limit kann außerdem vom Client, den Anfrageeinstellungen und dem aktuellen BetterToken-Routing abhängen. Prüfe vor sehr großen Prompts die model plaza und die Client-Dokumentation.

### Wie behebe ich Model not found?

Prüfe, ob die Model ID exakt `gpt-6-astra` lautet, die BetterToken API Key Zugriff hat, der **GPT provider** ausgewählt ist und die Base URL `{{openai-base-url}}` lautet. Starte den Client neu und teste erneut.

### Wo finde ich den aktuellen Preis?

Prüfe die <a href={"{{model-plaza-url}}"}>model plaza</a>. BetterToken-Preise können von den direkten OpenAI-API-Preisen abweichen und sich ändern.
