Veröffentlichungsdatum: 24. Juli 2026

BetterToken unterstützt jetzt `claude-opus-5`. Das Modell ist für komplexes Coding, langlaufende Agent-Workflows und mehrstufige Arbeit in großen Codebasen ausgelegt. Um es zu verbinden, erstelle einen BetterToken API Key, wähle den Provider `Claude`, verwende `{{anthropic-base-url}}` als Base URL und wähle `claude-opus-5` als Model ID.

Prüfe stets die <a href={"{{model-plaza-url}}"}>model plaza</a> auf aktuelle Verfügbarkeit und Preise.

## Highlights

- **Komplexe Coding-Workloads**: Anthropic empfiehlt Opus 5 für komplexes agentisches Coding und professionelle Arbeit, bei der Qualität und langfristige Zuverlässigkeit wichtig sind
- **Bis zu `1M tokens` Kontext**: Das Modell kann mit großen Repositories, langen Verläufen und umfangreichem Quellmaterial arbeiten
- **Bis zu `128K tokens` Ausgabe**: Dies unterstützt große Codeänderungen, Berichte und mehrstufige Ergebnisse
- **Adaptives Thinking standardmäßig**: Das Modell passt seine Reasoning-Tiefe an die Aufgabe an
- **Erweiterte Aufwandsteuerung**: Unterstützte Aufwandstufen sind `low`, `medium`, `high`, `xhigh` und `max`

## So verbindest du es

1. <a href={"{{register-url}}"}>Registriere dich und erstelle einen BetterToken API Key</a>, wähle dann den Provider `Claude`.
2. Setze die Base URL auf `{{anthropic-base-url}}`.
3. Wähle `claude-opus-5` als Modell.
4. Folge der [Claude-Code-Einrichtungsanleitung](/de/ai-tools/claude-code). Verwende zum Verwalten mehrerer Provider die [CC-Switch-Anleitung](/de/ai-tools/cc-switch).

Wenn du ein Modell für eine bestimmte Workload auswählst, vergleiche Opus 5 mit anderen Optionen in der [Anleitung zur Modellauswahl](/de/faq/model-calling/model-selection-guide).

## Was du beim Wechsel von Opus 4.8 prüfen solltest

Für die meisten Konfigurationen kannst du `claude-opus-4-8` durch `claude-opus-5` ersetzen. Prüfe diese beiden Verhaltensänderungen:

- **Thinking ist standardmäßig aktiviert**. Wenn der Aufwand auf `xhigh` oder `max` gesetzt ist, gibt das Deaktivieren von Thinking einen Fehler `400` zurück.
- **`max_tokens` umfasst Thinking und sichtbare Ausgabe**. Lasse genug Spielraum für Aufgaben, die langes Reasoning und eine große finale Antwort erfordern.

<Tip>
  Beginne mit einer echten Aufgabe aus deinem Workflow, etwa Repository-Analyse, einer Änderung in mehreren Dateien oder einer langlaufenden Agent-Aufgabe. So kannst du Qualität, Latenz und Token-Nutzung leichter bewerten, bevor du weitere Workloads wechselst.
</Tip>
