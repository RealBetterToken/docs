## Schnellstart

1. <a href={"{{register-url}}"}>Erstellen Sie einen BetterToken API Key</a> oder öffnen Sie **Setup** für einen vorhandenen Schlüssel.
2. Prüfen Sie in der model plaza, ob `deepseek-v4.1-flash-expires-on-0910` noch verfügbar ist.
3. Wählen Sie den **Provider DeepSeek**.
4. Verwenden Sie die Base URL Ihres Protokolls aus der Tabelle oben und die vollständige Model ID.
5. Senden Sie eine kleine Anfrage, bevor Sie eine längere Bewertung starten.

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-v4.1-flash-expires-on-0910",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

Eine erfolgreiche Antwort enthält die Modellausgabe unter `choices[0].message.content`. SDK-Beispiele und das vollständige Anfrageformat finden Sie in der [Chat Completions API-Referenz](/de/api-reference/chat-completions).

## Häufige Fragen

### Kann ich diese Model ID in der Produktion verwenden?

Sie können Anfragen senden, solange der Eintrag verfügbar ist. Er sollte jedoch nicht das einzige Modell in einer langfristigen Produktionskonfiguration sein. Nach dem geplanten Ablauf können Anfragen fehlschlagen.

### Kann ich es mit Claude Code oder der Anthropic Messages API verwenden?

Ja. Verwenden Sie für Claude Code oder Anthropic Messages die Base URL `{{anthropic-base-url}}` und die Model ID `deepseek-v4.1-flash-expires-on-0910`. Direkte Messages-Anfragen verwenden `POST /v1/messages` mit dem BetterToken API Key im Header `x-api-key`.

### Wo finde ich den aktuellen Preis?

Prüfen Sie die aktuelle <a href={"{{model-plaza-url}}"}>model plaza</a>. Verfügbarkeit und Preis des temporären Modells können sich während des Tests ändern.
