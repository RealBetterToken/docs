**DeepSeek V4.1 Flash** ist jetzt offiziell auf BetterToken verfügbar. Verwenden Sie die exakte Model ID `deepseek-flash`. Prüfen Sie vor einer Anfrage den aktuellen Zugang und Preis in der <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Check>
  Setzen Sie `model` auf `deepseek-flash`. Die vorherige Model ID des begrenzten Tests ist nicht mehr der aktuelle Eintrag.
</Check>

## Was jetzt verfügbar ist

| Einstellung | Wert |
| --- | --- |
| Provider | **DeepSeek** |
| Model ID | `deepseek-flash` |
| OpenAI Base URL | `{{openai-base-url}}` |
| OpenAI Chat Completions | `POST /v1/chat/completions` |
| Anthropic Base URL | `{{anthropic-base-url}}` |
| Anthropic Messages | `POST /v1/messages` |
| BetterToken-Status | Verfügbar |

Wählen Sie je nach Client OpenAI Chat Completions oder Anthropic Messages. Beide Protokolle verwenden denselben BetterToken API Key und dieselbe Model ID.

## Nutzungshinweise

Vergleichen Sie DeepSeek V4.1 Flash mit einem anderen verfügbaren Modell anhand von Aufgaben aus Ihrem eigenen Workflow:

- **Codeänderungen**: Geben Sie beiden Modellen dieselbe Repository-Aufgabe und vergleichen Sie Korrektheit, Qualität der Änderungen und notwendigen Nachbesserungsaufwand
- **Agenten-Workflows**: Messen Sie, wie zuverlässig jedes Modell mehrstufige Anweisungen befolgt und die Tools Ihres Clients verwendet
- **Qualität der Schlussfolgerungen**: Vergleichen Sie schwierige Debugging-, Planungs- und Analyseaufgaben mit demselben Prompt und denselben Kriterien
- **Latenz und Kosten**: Erfassen Sie die Zeit bis zum ersten Token, die Gesamtdauer, den Tokenverbrauch und den aktuellen BetterToken-Preis

Führen Sie mehrere repräsentative Prompts aus, statt sich auf ein einzelnes Ergebnis zu verlassen. Verwenden Sie für einen fairen Vergleich denselben Client, System-Prompt, dieselben Tool-Definitionen und Sampling-Einstellungen.

## Schnellstart

1. <a href={"{{register-url}}"}>Erstellen Sie einen BetterToken API Key</a> oder öffnen Sie **Setup** für einen vorhandenen Schlüssel.
2. Prüfen Sie in der model plaza, ob `deepseek-flash` verfügbar ist.
3. Wählen Sie den **Provider DeepSeek**.
4. Verwenden Sie die Base URL Ihres Protokolls aus der Tabelle oben und die vollständige Model ID.
5. Senden Sie eine kleine Anfrage, bevor Sie eine längere Bewertung starten.

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

Eine erfolgreiche Antwort enthält die Modellausgabe unter `choices[0].message.content`. SDK-Beispiele und das vollständige Anfrageformat finden Sie in der [Chat Completions API-Referenz](/de/api-reference/chat-completions).

## Von der Model ID des begrenzten Tests migrieren

Wenn eine Konfiguration noch die vorherige Model ID des begrenzten Tests verwendet:

1. Suchen Sie alle Konfigurationen, die `deepseek-v4.1-flash-expires-on-0910` enthalten.
2. Ersetzen Sie sie durch `deepseek-flash`.
3. Führen Sie nach der Änderung einen kurzen Funktionstest aus.
4. Prüfen Sie den aktuellen Modelleintrag und Preis in der model plaza.

## Häufige Fragen

### Kann ich diese Model ID in der Produktion verwenden?

Ja. Verwenden Sie `deepseek-flash` und prüfen Sie in der model plaza, ob das Modell für Ihren BetterToken API Key verfügbar ist.

### Kann ich es mit Claude Code oder der Anthropic Messages API verwenden?

Ja. Verwenden Sie für Claude Code oder Anthropic Messages die Base URL `{{anthropic-base-url}}` und die Model ID `deepseek-flash`. Direkte Messages-Anfragen verwenden `POST /v1/messages` mit dem BetterToken API Key im Header `x-api-key`.

### Wo finde ich den aktuellen Preis?

Prüfen Sie die aktuelle <a href={"{{model-plaza-url}}"}>model plaza</a>. Verfügbarkeit und Preis können sich ändern.
