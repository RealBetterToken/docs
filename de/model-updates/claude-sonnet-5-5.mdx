Veröffentlichungsdatum: 28. September 2026

Claude Sonnet 5.5 ist das zweite Modell der Claude-5.5-Familie von Anthropic. Anthropic positioniert es als schnellere Wahl für klar umrissene Alltagsaufgaben: Programmieren, Fehlerbehebung sowie das Erstellen von Dokumenten, Präsentationen und Tabellen. Für komplexere, offenere Aufgaben kommt Opus 5.5 infrage.

**Claude Sonnet 5.5** ist jetzt bei BetterToken verfügbar. Setzen Sie die Base URL auf `{{anthropic-base-url}}` und verwenden Sie `claude-sonnet-5-5` als Modell-ID. Aktuelle Verfügbarkeit und Preise finden Sie in der <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Stärken

- **Gezielte Programmierung**: geeignet für klar definierte Implementierungen und Fehlerbehebung.
- **Professionelle Inhalte**: Anthropic hebt Dokumente, Präsentationen und Tabellen hervor.
- **Langer Kontext**: Anthropic nennt ein Kontextfenster mit 1 Million Tokens und maximal 128.000 Ausgabe-Tokens.

## Vor dem Wechsel von Sonnet 5

Wenn Ihr Client die Anthropic Messages API direkt aufruft, lesen Sie vor dem Wechsel der Modell-ID den [offiziellen Migrationsleitfaden](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide). Sonnet 5.5 ändert einige Verhaltensweisen bei thinking und der Tool-Auswahl. Testen Sie zuerst typische Anfragen.

1. <a href={"{{register-url}}"}>Erstellen Sie einen BetterToken API Key</a>.
