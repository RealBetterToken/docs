## Claude Fable 5.1 konfigurieren

1. Erstelle eine BetterToken API Key oder öffne den **Setup**-Dialog einer vorhandenen Key.
2. Kopiere `claude-fable-5-1` aus der model plaza.
3. Öffne die Anleitung für deinen Client und trage BetterToken API Key, erforderliche Base URL und exakte Model ID ein.
4. Starte den Client neu, wenn die Modellliste nicht automatisch aktualisiert wird.
5. Sende eine kurze Testanfrage und prüfe sie im Dashboard.
