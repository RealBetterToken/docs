BetterToken bietet OpenAI-kompatible Chat Completions- und Responses-APIs sowie eine Anthropic-kompatible Messages-API. Wählen Sie das Format Ihres Clients.

## API auswählen

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/de/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/de/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/de/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/de/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/de/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Chat Completions verbinden

| Feld | Wert |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Vollständige Anfrage-URL | `{{chat-completions-url}}` |
| Methode | `POST` |
| Autorisierung | `Bearer YOUR_API_KEY` |
| Modell | `YOUR_MODEL_ID` |

Kopiere eine aktuelle Modell-ID aus dem <a href={"{{model-plaza-url}}"}>model plaza</a> oder dem Dialog **Setup** für den API Key in der Console.

<Warning>
  Wenn ein Tool nach einer **Base URL** fragt, gib `{{openai-base-url}}` ein. Verwende `{{chat-completions-url}}` nur, wenn das Tool ausdrücklich eine vollständige Anfrage-URL verlangt.
</Warning>

## Schnelltest

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Eine erfolgreiche Antwort enthält `choices[0].message.content`.
