`POST /v1/messages`

Verwende diesen Endpunkt für Claude Code, das Anthropic SDK und Anwendungen, die die Anthropic Messages API nutzen.

<Note>
  Verwende für ein SDK `{{anthropic-base-url}}` als Base URL. Ein manueller Request und der Playground verwenden den vollständigen Pfad `{{anthropic-base-url}}/v1/messages`.
</Note>

## Im Playground testen

Trage im Playground auf der rechten Seite deinen API Key im Feld `x-api-key` ein, belasse `anthropic-version` bei `claude-cli/2.0.76 (external, cli)`, wähle ein verfügbares Claude-Provider-Modell und sende den Request.

<Warning>
  Verwende für diesen Endpunkt nicht `Authorization: Bearer ...`. Er benötigt den Header `x-api-key`.
</Warning>
