`POST /v1/responses`

Verwende diesen Endpunkt für Codex und Anwendungen, die die OpenAI Responses API nutzen.

<Note>
  Base URL: `{{openai-base-url}}`. Übermittle deinen API Key als `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Im Playground testen

Trage im Playground auf der rechten Seite deinen API Key ein, ersetze bei Bedarf `model` durch eine aktuelle GPT-Provider-Model-ID und sende den Request. Bestätige das Modell vor dem Test in der <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Warning>
  Verwende nur deinen eigenen Test-API-Key. Lege Keys nicht in Code, Screenshots, Tickets oder Git-Repositories ab.
</Warning>
