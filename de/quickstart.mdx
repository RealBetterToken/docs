---
title: "Schnellstart"
description: "Erstelle in 4 Schritten ein Konto, lade Guthaben auf, erstelle einen API Key und öffne die passende Anleitung für dein Tool."
---

<Steps>
  <Step title="Konto erstellen">
    Öffne die <a href={"{{register-url}}"}>BetterToken-Registrierungsseite</a>, um ein Konto zu erstellen.

    Lade nach der Registrierung dein Guthaben auf, bevor du eine BetterToken API Key erstellst.
  </Step>
  <Step title="Guthaben aufladen">
    Du kannst **Online top-up** oder **Redeem code** verwenden. Kehre nach dem Aufladen zur Konsole zurück und prüfe, ob **Current balance** aktualisiert wurde, bevor du einen API Key erstellst.

    <Tabs>
      <Tab title="Online top-up">
        Öffne nach der Anmeldung die **Console**. Wähle in der Karte **Current balance** die gewünschte Währung und klicke auf die zugehörige Schaltfläche **Top up**.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Die Karte Current balance in der BetterToken Console mit Schaltflächen zum Aufladen von USD und RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Folge den Zahlungsanweisungen. Kehre nach erfolgreicher Zahlung zur Konsole zurück und prüfe, ob **Current balance** aktualisiert wurde.
      </Tab>
      <Tab title="Redeem code">
        Öffne nach der Anmeldung die **Console** und klicke unten links in der Karte **Current balance** auf **Redeem code**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Die Karte Current balance in der BetterToken Console mit einem Pfeil auf die Schaltfläche Redeem code unten links."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Gib den Einlösungscode im Dialog ein und klicke auf **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Der Dialog Redeem code mit Codeeingabe und Schaltfläche Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Kehre nach dem Einlösen zur Konsole zurück und prüfe, ob **Current balance** aktualisiert wurde.
      </Tab>
    </Tabs>
  </Step>
  <Step title="API-Key-Verwaltung öffnen und API Key erstellen">
    Sobald Guthaben verfügbar ist, klicke oben rechts im Bereich **Your API keys** der Konsole auf **Create API key**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Der Bereich Your API keys in der BetterToken Console mit einem Pfeil auf die Schaltfläche Create API key oben rechts."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Dadurch wird das Formular zum Erstellen eines API Key geöffnet.

    <Info>
      Verwende den vorgesehenen Einsatzzweck als Namen des API Key. Wenn du zuerst den richtigen Anwendungsfall wählst, wird die weitere Konfiguration einfacher.
    </Info>
  </Step>
  <Step title="Anbieter nach Tooltyp wählen">
    Trage im Formular **Name** ein, wähle den **provider** und bestätige das Ablaufdatum sowie das optionale Ausgabenlimit.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Das Formular Create API Key mit Optionen für Name, provider, Ablaufdatum und Ausgabenlimit."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Wähle den Anbieter passend zu dem Tool, das du verbinden möchtest.

    <Warning>
      Der **Claude provider** kann nur mit Claude Code verwendet werden.
    </Warning>

    <Warning>
      Der **GPT provider** kann mit Codex und externen Tools wie OpenClaw, OpenCode und Cursor verwendet werden.
    </Warning>

    Wähle einen dieser Anbieter:

    ```text
    Claude
    GPT
    ```

    Nach dem Erstellen des API Key wird der Dialog **API key setup** geöffnet. Kopiere dort **API Key** und **Base URL**.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="Der BetterToken-Dialog API key setup mit API Key, Base URL, Toolauswahl und Konfigurationsmethoden."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Konfigurationsmethode wählen">
    Wähle links im Dialog **API key setup** das zu verbindende Tool und anschließend eine Konfigurationsmethode.

    - **One-click Bash Configuration**: Wähle das Tool und `macOS / Linux` oder `Windows`, kopiere den erzeugten Befehl und führe ihn in deinem lokalen Terminal aus. Verwende diese Methode für eine schnelle Konfiguration von Codex, OpenClaw oder OpenCode.
    - **CC Switch integration**: Klicke auf **Import to CC Switch**, um die aktuelle **API Key** und **Base URL** in CC Switch zu importieren. Verwende diese Methode, wenn du mehrere Tools und Anbieter in einer App verwaltest.
    - **Manual configuration**: Kopiere **API Key** und **Base URL** und füge sie in die Konfiguration des Zieltools ein. Verwende diese Methode für Cursor, Cline, Roo Code, Zed und andere Clients.

    <Note>
      Die Tools verwenden unterschiedliche Authentifizierungsfelder, Modellauswahlen und Speicherorte für Konfigurationsdateien. Öffne die Anleitung für das jeweilige Tool, bevor du die Einrichtung abschließt.
    </Note>
  </Step>
</Steps>
