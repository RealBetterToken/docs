## Was ist BetterToken?

BetterToken ist ein API-Gateway für KI-Modelle. Es bietet über eine API Zugriff auf Claude- und GPT/Codex-Modelle und unterstützt KI-Coding-Tools wie Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode und CC Switch. Nach der Registrierung erhältst du $1 Testguthaben, um deinen eigenen Entwicklungsworkflow zu testen.

Die Dokumentation unterscheidet zwischen zwei Zugriffsarten:

- **Claude Code / `ANTHROPIC_BASE_URL`**: Verwende `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / externe Tools**: Verwende `{{openai-base-url}}`

**Wichtige Merkmale:**

- **Mehrere Anbieter**: BetterToken kann gleichzeitig mit mehreren Anbietern verbunden sein
- **Dynamisches Routing**: Anfragen können bei langsamen oder instabilen Upstreams umgeleitet werden
- **Unterstützung für Coding-Tools**: Die Integration wird für Claude Code und das Codex-Ökosystem gepflegt
- **Zwei klare Wege**: Konfiguriere den Endpunkt passend zum Protokoll, statt überall dieselbe `base_url` zu verwenden

## Zwei Zugriffsarten

| Szenario | Base URL | Hinweise |
|----------|----------|-------|
| Claude Code | `{{anthropic-base-url}}` | Anthropic-Protokoll, ohne das Suffix `/v1` |
| Codex / externe Tools | `{{openai-base-url}}` | OpenAI-kompatibles Protokoll; externe Tools verwenden den GPT-Anbieter |

## Welches Problem BetterToken löst

Jedes Tool erwartet ein bestimmtes Protokoll, ein Authentifizierungsfeld und eine Methode zur Modellauswahl. BetterToken stellt dafür zwei stabile Endpunkte bereit: einen mit Anthropic-Protokoll und einen OpenAI-kompatiblen Endpunkt. Du kannst Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode und CC Switch verbinden, indem du Base URL und API Key ersetzt. Der übrige Workflow bleibt unverändert.

## Endpunkte für Entwickler

BetterToken ist ein Multi-Modell-API-Gateway mit zwei standardisierten Einstiegspunkten:

| Protokoll | Base URL | Verwendet für |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| OpenAI-kompatibel | https://bettertoken.ai/v1 | Codex und andere externe Tools |

Erstelle nach der Registrierung eine API Key, wähle den Claude- oder GPT-Anbieter und verbinde Cursor, Cline, OpenClaw, OpenCode, CC Switch oder ein anderes Tool durch Ersetzen der Base URL. Anfragen, Token-Nutzung und Guthaben werden im Dashboard angezeigt.

## Teams und Kostenkontrolle

Teams können Claude- und GPT/Codex-Workflows über eine gemeinsame API-Schicht verbinden. BetterToken erfasst die tatsächliche Nutzung und leitet Anfragen zwischen mehreren Anbietern weiter, um die Auswirkungen einer einzelnen Upstream-Störung zu verringern. Im Dashboard kannst du Nutzung und Guthaben pro API Key prüfen und Budgets nach Workflow zuweisen, etwa für Claude Code oder Codex.

## Häufige Fragen

**Was ist BetterToken?** BetterToken ist ein API-Gateway und Proxy für den Zugriff auf KI-Modelle über kompatible Endpunkte.

**Welches Problem löst es?** Es bietet eine gemeinsame Integrationsschicht für Tools, die das Anthropic- oder OpenAI-Protokoll verwenden.

**Welche Modelle werden unterstützt?** Claude-Modelle über das Anthropic-Protokoll und GPT/Codex-Modelle über das OpenAI-kompatible Protokoll.

**Welche Tools werden unterstützt?** Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode und CC Switch.

**Wie fange ich an?** Registriere ein Konto, erhalte $1 Testguthaben, erstelle eine BetterToken API Key, wähle ein kompatibles Anbietermodell und ersetze die Base URL in deinem Tool.

**Welche Supportkanäle gibt es?** Telegram und support@bettertoken.ai.
