## 빠른 답변

Claude Code에서 타사 API를 설정할 때는 먼저 엔드포인트가 Anthropic 호환인지 확인하세요. 이 문서에서 Claude Code는 `{{anthropic-base-url}}`을 사용합니다. `/v1`을 추가하지 마세요.

API Key는 요청을 인증하고 Base URL은 Claude Code가 모델 요청을 보낼 위치를 지정합니다. 두 값은 같은 제공자와 프로토콜에 속해야 합니다.

일반적인 Claude API 액세스를 찾고 있다면 [BetterToken Claude API 페이지](https://bettertoken.ai/ru/claude-api/)를 확인하세요. 랜딩 페이지는 API 액세스 목적을 다루며, 이 FAQ는 Claude Code의 API Key와 Base URL 설정에 집중합니다.

BetterToken API Key, Base URL `{{anthropic-base-url}}`, 사용할 Model ID를 설정해 Claude Code를 연결하세요. <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

## 이 설정이 필요한 경우

- Claude Code에서 사용자 지정 API 게이트웨이를 사용하려 할 때
- API Key는 있지만 어떤 Base URL을 사용할지 모를 때
- Claude Code에서 인증 또는 엔드포인트 오류가 발생할 때
- `{{anthropic-base-url}}`과 `{{openai-base-url}}` 중 하나를 선택해야 할 때


## 핵심 개념

| 필드 | 의미 |
| --- | --- |
| API Key | 모델 API 요청을 위한 인증 정보 |
| Base URL | 요청을 보내는 API 주소 |
| Anthropic 호환 API | Anthropic / Claude 요청 규칙을 따르는 엔드포인트 |
| OpenAI 호환 API | OpenAI 방식 규칙을 따르는 엔드포인트로, Codex, Cursor, Cline에서 주로 사용 |
| Model ID | 도구에서 요청하는 모델 이름 또는 매핑 값 |

## 권장 설정

BetterToken API Key, Base URL `{{anthropic-base-url}}`, 사용할 Model ID를 설정해 Claude Code를 연결하세요.

<a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

`YOUR_MODEL_ID`를 복사한 ID로 바꾸세요. `ANTHROPIC_MODEL`은 기본 모델을, 세 개의 `ANTHROPIC_DEFAULT_*_MODEL` 변수는 Haiku, Sonnet, Opus 별칭을 설정합니다. 같은 모델이나 역할별로 다른 모델을 지정할 수 있습니다.

설정에서 Model ID를 변경하고 Claude Code를 다시 시작하세요. 세션 중에는 `/model YOUR_MODEL_ID`로 전환하세요.

## 흔한 실수

- Claude Code Base URL에 `/v1` 추가하기
- API Key만 변경하고 요청은 기본 엔드포인트로 계속 보내기

- Claude Code의 Anthropic 호환 필드에 OpenAI 호환 엔드포인트 입력하기
- 셸 프로필의 기존 환경 변수가 새 설정을 덮어쓰도록 두기

## BetterToken에서의 사용 방식

BetterToken은 두 가지 엔드포인트를 제공합니다. Claude Code에는 Anthropic 호환 `{{anthropic-base-url}}`을 사용하고 Codex와 외부 도구에는 OpenAI 호환 `{{openai-base-url}}`을 사용합니다.

하나의 Dashboard에서 API Key, 잔액, 사용 내역을 관리할 수 있지만 Claude Code에서 Anthropic 호환 요청 형식을 사용해야 한다는 요구 사항은 바뀌지 않습니다.
