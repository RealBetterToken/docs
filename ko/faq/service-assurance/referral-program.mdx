## 짧은 답변

referral program은 real invitations에 reward를 제공합니다. friend를 invite하고 해당 friend가 first top-up을 완료하면 그 first top-up amount의 **10%**에 해당하는 referral reward를 받습니다.

reward는 in-product reward balance로 issued되며 future API request costs를 pay하는 데 automatically 사용됩니다. suspicious referrals는 manually reviewed됩니다. review가 approved된 후 rewards가 issued됩니다.

## referral program 사용 방법

1. console에 sign in합니다.
2. account 또는 referral rewards area에서 referral link를 copy합니다.
3. referral link를 friend에게 send합니다.
4. friend가 link를 통해 register하고 first top-up을 완료합니다.
5. system은 friend의 first top-up amount의 **10%**로 reward를 calculate합니다.
6. reward가 issued된 후 future request costs에 automatically 사용됩니다.

friend가 link를 통해 register하지 않으면 referral relationship이 automatically created되지 않을 수 있습니다. screenshot만 보내지 말고 full referral link를 share하세요.

## reward balance 사용 방식

Reward balance는 cash withdrawal channel이 아닙니다. model request costs를 pay하는 데 사용되는 in-product balance입니다.

API requests를 send하면 system이 account rules에 따라 balance와 reward balance를 apply합니다. each request마다 reward balance를 choose할 필요가 없습니다.

## manual review가 triggered될 수 있는 경우

abuse를 prevent하기 위해 다음 cases는 manual review를 trigger할 수 있습니다.

- same device 또는 network에서 many mutual invitations가 발생한 경우
- abnormal top-up behavior 또는 suspected non-real users
- fake accounts, bulk accounts 또는 automated registration
- self-referrals
- payment, account, request behavior 간 abnormal links

review가 approved되면 reward가 normally issued됩니다. referral이 suspicious하다고 judged되면 reward가 delayed, canceled 또는 frozen될 수 있습니다.

## FAQ

### referral reward rate는 얼마인가요?

referral reward는 friend의 first top-up amount의 **10%**입니다.

### friend가 top up하면 reward가 즉시 도착하나요?

normal referrals는 system rules에 따라 issued됩니다. risk control 또는 abnormal links가 detected되면 reward가 manual review에 들어가며 approval 후 issued됩니다.

### reward balance를 withdraw할 수 있나요?

아니요. Reward balance는 request costs를 pay하는 데 사용됩니다.

### reward balance를 manually apply해야 하나요?

아니요. Reward balance는 request costs에 automatically 사용됩니다.
