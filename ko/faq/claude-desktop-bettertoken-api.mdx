이 페이지는 BetterToken **Claude provider**의 direct Claude Desktop setup만 다룹니다. BetterToken API Key, `{{anthropic-base-url}}`, `x-api-key`를 입력한 다음 Claude Desktop을 다시 시작하세요.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| 모델 | Claude provider model |

## 사전 요구 사항

- <a href={"{{register-url}}"}>BetterToken API Key를 만들고 복사</a>
- API Key가 Claude provider models를 사용할 수 있는지 확인

## 설치

[Claude Desktop website](https://claude.ai/download)에서 최신 version을 설치하거나 업데이트한 다음 Claude Desktop을 시작하세요.

<Steps>

    confirmation window에서 **Enable**을 클릭한 다음 Claude Desktop을 다시 시작하세요.

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
        alt="Claude Desktop에서 developer mode를 확인합니다."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="third-party inference settings 열기">
    restart 후 macOS menu bar에서 **Developer** → **Configure Third-Party Inference...**를 선택하세요.

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
        alt="Developer menu에서 Configure Third-Party Inference를 선택합니다."
        style={{ borderRadius: '0.5rem' }}

  <Step title="BetterToken API settings 입력">
    **Gateway**를 선택한 다음 다음을 입력하세요.

    | 필드 | 값 |
    | --- | --- |
    | **Gateway base URL** | `{{anthropic-base-url}}` |
    | **Gateway API key** | BetterToken API Key |
    | **Gateway auth scheme** | `x-api-key` |

    auth scheme를 선택하면 Claude Desktop이 available Claude models를 fetch합니다. **Apply locally**를 클릭하세요.

## 연결 확인

**Save & Restart**를 클릭하세요. **Continue with Gateway**를 선택한 다음 짧은 message를 보내세요. 왼쪽 아래에 **Gateway**가 표시되고 message가 정상적으로 반환되면 setup이 활성화된 것입니다.

## 모델 전환

model selector를 열고 Gateway가 반환한 다른 Claude model을 선택하세요. model이 없으면 **Configure Third-Party Inference...**를 다시 열고 **Apply locally**를 클릭한 다음 Claude Desktop을 다시 시작하세요.

## 일반적인 오류

| 문제 | 해결 방법 |
| --- | --- |
| Gateway가 연결할 수 없음 | **Gateway base URL**에는 정확히 `{{anthropic-base-url}}`을 사용하세요. `/v1`을 추가하지 마세요. |
| Request가 `401`을 반환함 | BetterToken API Key를 다시 복사하고 auth scheme가 `x-api-key`인지 확인하세요. |
| Claude models가 표시되지 않음 | API Key가 Claude provider models를 사용할 수 있는지 확인한 다음 settings window를 다시 여세요. |
| Configuration이 적용되지 않음 | Claude Desktop을 완전히 종료하고 다시 연 다음 **Continue with Gateway**를 선택하세요. |

## 고급 설정

Claude Desktop에서 GPT, Kimi, GLM 또는 다른 non-Claude provider를 사용하려면 [CC Switch의 Claude Desktop tab](/ko/ai-tools/cc-switch#claude-desktop)을 따르세요. CC Switch가 API Format, model mapping, proxy 및 restart flow를 처리합니다.

| Provider | 상태 |
| --- | --- |
| Claude | 수동 설정 |
| GPT | 고급 설정 |
| Kimi | 고급 설정 |
| GLM | 고급 설정 |

<Note>표시된 상태는 이 페이지에서 설명하는 BetterToken 설정 방식에 적용됩니다.</Note>

  - **수동 설정**: API Key, Base URL, Model을 입력하세요.
</Accordion>
