Claude Desktop은 Claude 모델만 지원합니다. 이는 Claude Desktop 클라이언트의 제한입니다.

모델 광장에서 사용 가능한 Claude Model ID를 복사하고 저장한 뒤 Claude Desktop을 다시 시작하세요.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| 모델 | 모델 광장에서 사용 가능한 Claude Model ID를 복사하고 저장한 뒤 Claude Desktop을 다시 시작하세요. |

## 사전 요구 사항

- <a href={"{{register-url}}"}>BetterToken API Key를 만들고 복사</a>
- <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

## 구독과 API 결제를 분리하기

Gateway 요청은 BetterToken API Key와 BetterToken 잔액을 사용합니다. Claude 구독 한도를 사용하거나 연장하지 않습니다. 구독과 API를 별도의 액세스 및 결제 경로로 취급하세요.

실제 작업에 사용하기 전에 다음을 확인하세요.

1. Claude Desktop 전용 BetterToken API Key를 만듭니다.
2. **Gateway**를 통해 민감한 정보가 없는 짧은 테스트 메시지를 보냅니다.
3. BetterToken Dashboard를 열고 모델, 상태, input, output, cache Token, 청구액을 확인합니다.
4. Key가 스크린샷, 저장소 또는 공개 로그에 노출되었다면 폐기하고 새 Key를 만듭니다.

## 설치

[Claude Desktop website](https://claude.ai/download)에서 최신 version을 설치하거나 업데이트한 다음 Claude Desktop을 시작하세요.

## 모델 전환

model selector를 열고 Gateway가 반환한 다른 Claude model을 선택하세요. model이 없으면 **Configure Third-Party Inference...**를 다시 열고 **Apply locally**를 클릭한 다음 Claude Desktop을 다시 시작하세요.

## 일반적인 오류

| 문제 | 해결 방법 |
| --- | --- |
| Gateway가 연결할 수 없음 | **Gateway base URL**에는 정확히 `{{anthropic-base-url}}`을 사용하세요. `/v1`을 추가하지 마세요. |
| Request가 `401`을 반환함 | BetterToken API Key를 다시 복사하고 auth scheme가 `x-api-key`인지 확인하세요. |
| Claude models가 표시되지 않음 | 모델 광장에서 사용 가능한 Claude Model ID를 복사하고 저장한 뒤 Claude Desktop을 다시 시작하세요. |
| Configuration이 적용되지 않음 | Claude Desktop을 완전히 종료하고 다시 연 다음 **Continue with Gateway**를 선택하세요. |
