BetterToken을 OpenAI 호환 provider로 연결해 OpenCode에서 Kimi K3를 사용합니다. BetterToken API Key, Base URL `https://bettertoken.ai/v1`, Model ID `kimi-k3`를 입력하세요.

## 핵심 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai/v1` |
| 모델 | `kimi-k3` |

## 사전 준비

- 최신 [OpenCode](https://opencode.ai/).
- <a href={"{{register-url}}"}>BetterToken API Key 만들기</a>.
- **Setup** 대화 상자에서 해당 도구와 provider를 선택하고 사용 가능한 Model ID를 복사하세요.

## `/connect`로 구성

```text
/connect
```

**Other**를 선택하고 provider id로 `bettertoken`을 입력한 후 BetterToken API Key를 붙여넣으세요. `bettertoken/kimi-k3`를 선택한 다음 저장 후 OpenCode를 다시 시작하세요.

## 수동 구성

전역 파일 `~/.config/opencode/opencode.json`을 엽니다. 한 프로젝트에만 적용하려면 프로젝트 루트의 `opencode.json`을 사용할 수 있습니다.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/kimi-k3",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "https://bettertoken.ai/v1",
        "apiKey": "YOUR_API_KEY"
      },
      "models": {
        "kimi-k3": {
          "name": "kimi-k3"
        }
      }
    }
  }
}
```

`YOUR_API_KEY`를 바꾸세요. OpenCode가 요청 경로를 직접 추가하므로 `baseURL`에 `/chat/completions`를 넣지 마세요.

## 연결 확인

OpenCode에서 프로젝트를 열고 `bettertoken/kimi-k3`를 선택한 뒤 짧은 프롬프트를 보내세요. 정상 응답이 오면 연결이 확인됩니다.

## 일반적인 오류

| 오류 | 확인할 항목 |
| --- | --- |
| `401` | `/connect`를 다시 실행하거나 `apiKey`를 확인하세요. |
| `404` | `baseURL`에는 `https://bettertoken.ai/v1`만 사용하세요. |
| 모델을 찾을 수 없음 | 최상위 `model` 값은 `bettertoken/kimi-k3`이고 `models`의 키는 `kimi-k3`여야 합니다. |
| 구성이 적용되지 않음 | 프로젝트 수준 `opencode.json`이 전역 파일을 덮어쓰는지 확인하세요. |
