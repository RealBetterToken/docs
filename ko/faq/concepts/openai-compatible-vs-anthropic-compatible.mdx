## 빠른 답변

OpenAI 호환 API와 Anthropic 호환 API는 서로 다른 호환 계층입니다. 둘 다 모델 요청에 사용할 수 있지만 요청 형식, 필드, 도구 의미 체계, 클라이언트 요구 사항이 다릅니다.

Codex CLI, Cursor, Cline, OpenCode, OpenClaw는 일반적으로 OpenAI 호환 엔드포인트를 사용합니다. Claude Code와 일부 Claude Desktop Gateway 경로는 Anthropic 호환 엔드포인트를 사용합니다.

모델 이름만 보고 선택하지 마세요. 도구에서 요구하는 프로토콜을 먼저 선택한 뒤 이에 맞는 Base URL, API Key, Model ID를 사용하세요.

## 이 구분이 중요한 경우

- 두 개의 Base URL 중 무엇을 사용할지 모를 때
- Claude Code는 작동하지만 Codex 또는 Cursor가 실패할 때
- Codex는 작동하지만 Claude Code에서 엔드포인트 또는 인증 오류가 발생할 때
- 하나의 API Key를 여러 도구에서 사용하려 할 때
- API 게이트웨이, 모델 라우터 또는 로컬 프록시를 설정할 때

## 핵심 개념

| 개념 | 의미 |
| --- | --- |
| OpenAI 호환 API | OpenAI 방식 요청 규칙을 따르는 엔드포인트 |
| Anthropic 호환 API | Anthropic / Claude 요청 규칙을 따르는 엔드포인트 |
| Base URL | 클라이언트가 사용하는 API 루트 주소 |
| API Key | 선택한 제공자의 인증 정보 |
| Model ID | 해당 제공자와 프로토콜에서 사용할 수 있는 모델 식별자 |
| Gateway | 클라이언트와 제공자 사이에서 호환성, 라우팅, 과금, 관측성을 담당하는 계층 |

## 권장 선택

먼저 도구를 확인하세요.

| 도구 | 일반적인 프로토콜 | 이 문서의 Base URL |
| --- | --- | --- |
| Claude Code | Anthropic 호환 | `{{anthropic-base-url}}` |
| Claude Desktop Gateway | Anthropic 호환 또는 로컬 경로 | Gateway 설정 따르기 |
| Codex CLI | OpenAI 호환 / Responses | `{{openai-base-url}}` |
| Cursor | OpenAI 호환 | `{{openai-base-url}}` |
| Cline | OpenAI 호환 제공자 | `{{openai-base-url}}` |
| OpenCode / OpenClaw | OpenAI 호환 | `{{openai-base-url}}` |

도구가 OpenAI 방식 API를 요구하면 Claude Code용 Anthropic Base URL을 사용하지 마세요. 도구가 Anthropic 방식 API를 요구하면 OpenAI 호환 `/v1` 엔드포인트를 사용하지 마세요.

## 흔한 실수

- 하나의 모델 이름을 모든 프로토콜에서 그대로 사용할 수 있다고 가정하기
- Claude Code에 OpenAI 호환 Base URL 입력하기
- Codex, Cursor, Cline에 Anthropic 호환 Base URL 입력하기
- Claude.ai 또는 ChatGPT 구독을 API Key로 간주하기
- Base URL과 Model ID가 맞지 않는 상태에서 API Key만 변경하기

## BetterToken에서의 사용 방식

BetterToken은 Anthropic 호환 방식과 OpenAI 호환 방식을 모두 제공합니다. 하나의 Dashboard에서 API Key, 잔액, 사용 내역을 관리할 수 있지만 각 클라이언트에는 실제로 지원하는 프로토콜을 설정해야 합니다.

간단한 원칙은 다음과 같습니다. Claude Code는 Anthropic 호환 방식을 사용하고 Codex, Cursor, Cline, OpenCode, OpenClaw는 일반적으로 OpenAI 호환 방식을 사용합니다.
