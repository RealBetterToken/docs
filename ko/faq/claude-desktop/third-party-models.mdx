Claude Desktop은 Claude 모델만 지원합니다. 이는 Claude Desktop 클라이언트의 제한입니다.

## 설정 방법

[Claude Desktop 가이드](/ko/faq/claude-desktop-bettertoken-api)에 따라 **Gateway**, Base URL `{{anthropic-base-url}}`, BetterToken API Key, **Gateway auth scheme** `x-api-key`를 설정하세요. **Apply locally**로 저장하고 Claude Desktop을 완전히 다시 시작하세요.

<a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

## 문제 해결

### 401 / Unauthorized

API Key가 정확히 복사되었고 만료되지 않았는지 확인하세요. 이 Gateway 설정에는 `x-api-key`를 사용하고 저장한 뒤 Claude Desktop을 다시 시작하세요.

### 모델

모델 광장에서 사용 가능한 Claude Model ID를 복사하고 저장한 뒤 Claude Desktop을 다시 시작하세요.
