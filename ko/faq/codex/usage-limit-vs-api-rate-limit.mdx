Codex 사용 경고와 API `429` 응답은 같은 제한이 아닙니다. 먼저 접근 방식을 확인하세요.

## 접근 방식 확인

| 사용 방식 | 제한이 적용되는 곳 | 확인할 항목 |
| --- | --- | --- |
| 공식 ChatGPT/Codex 로그인 | Codex 플랜 또는 credits | Codex 사용 정보와 공식 가이드 |
| BetterToken API Key | 별도 API 워크플로 | HTTP status, body, request ID, 잔액, 요청 기록 |

<Warning>
  BetterToken API Key는 공식 Codex 플랜 한도를 늘리거나 우회하지 않습니다. 별도의 API 워크플로를 만듭니다.
</Warning>

## Codex가 플랜 한도를 표시하는 경우

1. 작업 상태, 변경 파일, 검증 결과를 저장합니다.
2. 정확한 경고 문구와 시간을 기록합니다.
3. [Codex 사용량 및 credits 공식 가이드](https://help.openai.com/en/articles/12642688)를 확인합니다.
4. 공식 계정 화면에 표시되는 옵션을 사용하거나 한도 재설정을 기다립니다.

하나의 백분율만으로 남은 사용량을 추정하지 마세요. 지표가 서로 다른 기간이나 리소스를 나타낼 수 있습니다.

## API가 429를 반환하는 경우

1. HTTP status, body, request ID, rate-limit 또는 retry header를 저장합니다.
2. BetterToken Workspace에서 잔액과 실패한 요청을 확인합니다.
3. OpenAI-compatible Base URL `https://bettertoken.ai/v1`과 본인의 BetterToken API Key를 확인합니다.
4. 일시적인 rate limit일 때만 횟수가 제한된 exponential backoff로 재시도합니다.

잔액, 접근 권한, 설정이 원인이면 먼저 수정한 뒤 짧은 테스트 요청을 보내세요.

## 수정 확인

짧은 prompt를 보내고 Dashboard에서 모델, status, Token, 과금 기록을 확인합니다.

[Codex를 BetterToken에 연결](/ko/ai-tools/codex) 문서도 확인하세요.
