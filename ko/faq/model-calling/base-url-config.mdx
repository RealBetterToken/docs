## 짧은 답변

Base URL은 도구에서 요구하는 프로토콜과 일치해야 합니다. Claude Code는 일반적으로 Anthropic 호환 루트 주소를 사용합니다. Codex CLI, Cursor, Cline, OpenCode, OpenClaw 등 외부 도구는 일반적으로 OpenAI 호환 `/v1` 주소를 사용합니다.

BetterToken에서는 다음과 같이 설정합니다.

| 사용 환경 | Base URL |
| --- | --- |
| Claude Code / Anthropic 호환 | `{{anthropic-base-url}}` |
| Codex CLI / OpenAI 호환 | `{{openai-base-url}}` |
| Cursor, Cline, OpenCode, OpenClaw | `{{openai-base-url}}` |

경로를 추측하지 마세요. API Key, Base URL, Model ID는 같은 제공자 또는 게이트웨이에서 가져와야 합니다.

## Base URL이 서로 다른 이유

SDK마다 경로를 추가하는 방식이 다릅니다.

| 프로토콜 또는 도구 유형 | 일반적인 동작 |
| --- | --- |
| OpenAI 호환 SDK | 일반적으로 `/v1` 아래의 Chat Completions 또는 Responses 리소스를 호출 |
| Anthropic 호환 SDK | 메시지 엔드포인트 경로를 자체적으로 추가하므로 `/v1`을 다시 추가하면 안 됨 |
| 도구 내장 제공자 | 경로를 자동으로 추가하거나 전체 Base URL 입력을 요구할 수 있음 |

모델 이름이 같아도 모든 곳에서 같은 Base URL이 작동하는 것은 아닙니다. 도구 프로토콜, Base URL, API Key, 제공자, Model ID가 서로 일치해야 합니다.

## 빠른 참조

| 도구 | 권장 설정 |
| --- | --- |
| Claude Code | BetterToken API Key와 `{{anthropic-base-url}}` 사용 |
| Claude Desktop Gateway | 인증 방식을 포함해 Gateway 페이지 안내 따르기 |
| Codex CLI | BetterToken API Key와 `{{openai-base-url}}` 사용 |
| Cursor | BetterToken API Key와 `{{openai-base-url}}` 사용 |
| Cline | OpenAI 호환 제공자와 `{{openai-base-url}}` 사용 |
| OpenCode / OpenClaw | BetterToken API Key와 `{{openai-base-url}}` 사용 |

## 흔한 오류

| 오류 또는 증상 | 가능한 원인 |
| --- | --- |
| `404 Not Found` | Base URL 경로가 SDK에서 요구하는 경로와 일치하지 않음 |
| `model not found` | Model ID가 현재 제공자에 속하지 않음 |
| `invalid_api_key` | API Key와 Base URL이 서로 다른 서비스에서 생성됨 |
| 인증은 성공하지만 모델을 사용할 수 없음 | 제공자와 Model ID가 일치하지 않음 |
| 요청이 계속 실패함 | OpenAI 호환 도구에 Anthropic 호환 주소를 사용했거나 그 반대인 경우 |

## 권장 문제 해결 순서

1. 도구에서 OpenAI 호환 API와 Anthropic 호환 API 중 무엇을 요구하는지 확인하세요.
2. Base URL이 해당 프로토콜과 일치하는지 확인하세요.
3. API Key가 같은 서비스에서 발급되었는지 확인하세요.
4. Model ID를 <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 복사했으며 현재 제공자에 속하는지 확인하세요.
5. `hello` 같은 최소 테스트 요청을 보내세요.

## 코드 예제

OpenAI 호환 도구는 일반적으로 `/v1` 주소를 사용합니다.

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="{{openai-base-url}}"
)

response = client.chat.completions.create(
    model="your-model-id",
    messages=[{"role": "user", "content": "hello"}]
)
```

Claude / Anthropic 호환 설정은 일반적으로 루트 주소를 사용합니다.

```python
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="{{anthropic-base-url}}"
)

message = client.messages.create(
    model="your-claude-model-id",
    max_tokens=1024,
    messages=[{"role": "user", "content": "hello"}]
)
```

## BetterToken에서의 사용 방식

BetterToken은 Anthropic 호환 연결과 OpenAI 호환 연결을 모두 제공합니다. 같은 Dashboard에서 API Key, 잔액, 사용 내역을 관리할 수 있지만 각 클라이언트에는 지원하는 프로토콜 주소를 설정해야 합니다.

간단한 원칙은 다음과 같습니다. Claude Code는 `{{anthropic-base-url}}`을 사용하고 Codex CLI, Cursor, Cline, OpenCode, OpenClaw는 `{{openai-base-url}}`을 사용합니다.
