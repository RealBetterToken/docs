## 짧은 답변

Cursor에서 BetterToken을 Custom OpenAI API로 연결하려면 BetterToken API Key를 입력하고 Override OpenAI Base URL을 enable한 후 `{{openai-base-url}}`로 설정하세요. 그런 다음 모델 광장에서 current GPT Model ID를 추가하세요. API Key, Base URL, Model ID는 모두 같은 provider에 속해야 합니다.

BetterToken의 public Base URL은 `https://bettertoken.ai/v1`입니다.

## 이 내용이 필요한 경우

- Cursor가 third-party OpenAI-compatible provider를 사용하게 하려 함
- Override OpenAI Base URL을 설정해야 함
- custom model을 추가 중임
- model not found 또는 authentication failures가 표시됨
- Cursor, Codex 및 other tools가 하나의 model routing layer를 공유하게 하려 함

## Field 의미

| Field | 역할 |
| --- | --- |
| API Key | authentication credential |
| Base URL | OpenAI-compatible endpoint, 보통 `/v1` URL |
| Model ID | provider가 인식하는 model identifier |
| Custom model | Cursor 안에서 manually added 또는 selected model |

## 권장 단계

1. provider dashboard에서 API Key를 만드세요.
2. Cursor model settings에 API Key를 추가하세요.
3. Override OpenAI Base URL에 provider Base URL을 입력하세요.
4. provider가 지원하는 Model ID를 추가하거나 선택하세요.
5. 저장 후 간단한 request로 확인하세요.

## 문제 해결

### 401 Unauthorized

BetterToken API Key를 extra spaces 없이 복사했으며 Cursor가 `https://bettertoken.ai/v1`을 사용하는지 확인하세요. 한 provider의 API Key를 다른 provider의 Base URL과 섞지 마세요. Key가 regenerate 또는 revoke되었다면 Cursor에서 교체하고 다시 test하세요.

### Model Not Found 또는 404

interface의 display name이 아니라 BetterToken Model Plaza에 표시된 exact API Model ID를 사용하세요. 해당 model이 OpenAI-compatible endpoint에서 제공되며 Base URL이 `/v1`로 끝나는지 확인하세요.

### private 네트워크 접근 금지 오류 해결

Cursor는 `localhost`, `127.0.0.1`, private LAN address 또는 다른 non-public endpoint를 거부할 수 있습니다. BetterToken 사용 시 public HTTPS Base URL `https://bettertoken.ai/v1`을 유지하세요. Local proxy를 사용한다면 Cursor의 current local-network restrictions에 맞게 구성하세요.

## 일반적인 실수

- **401 Unauthorized:** active BetterToken API Key를 사용하고 extra spaces를 제거하세요.
- **404 Not Found:** complete request path가 아니라 `https://bettertoken.ai/v1`을 Base URL로 사용하세요.

- 한 provider의 API Key와 다른 provider의 Base URL을 사용함
- Claude model name을 OpenAI-compatible configuration에 입력함
- API model ID 대신 UI display name을 사용함
- Cursor Rules가 API authentication에 영향을 준다고 생각함
- global override가 다른 OpenAI models에 영향을 줄 수 있음을 잊음

## BetterToken 정보

Cursor와 유사한 external tools는 보통 OpenAI-compatible setup을 사용합니다. BetterToken Base URL은 `{{openai-base-url}}`이며 model IDs는 <a href={"{{model-plaza-url}}"}>모델 광장</a>의 **GPT provider**에서 가져옵니다.

Claude Code `{{anthropic-base-url}}`을 Cursor OpenAI-compatible configuration에 입력하지 마세요.
