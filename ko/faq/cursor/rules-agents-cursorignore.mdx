## 짧은 답변

Cursor Rules는 Cursor에 project 작업 방법을 알려줍니다. `AGENTS.md`는 여러 coding agents가 읽을 수 있는 repository instruction file입니다. `.cursorignore`는 Cursor가 index 또는 read하지 않아야 할 files 또는 directories를 제어합니다.

모두 project context와 관련되지만 다른 problems를 해결합니다. Rules는 behavior를 guide하고 `AGENTS.md`는 cross-agent instructions를 제공하며 `.cursorignore`는 content를 exclude합니다.

## 비교

| File / feature | 주요 역할 |
| --- | --- |
| Cursor Rules | Cursor용 project, team 또는 user-level rules |
| `AGENTS.md` | cross-agent repository instructions 및 collaboration norms |
| `.cursorignore` | Cursor가 ignore해야 할 files 또는 directories |
| API Key / Base URL | project rules가 아닌 model request setup |

## Rules에 적합한 내용

- project coding style
- framework conventions
- component 및 directory rules
- test 및 validation requirements
- Cursor editing behavior

## .cursorignore에 적합한 내용

- large build artifacts
- dependency directories
- generated files
- index해서는 안 되는 sensitive directories
- current development와 무관한 large files

## 일반적인 실수

- Rules 또는 `AGENTS.md`에 API Keys를 작성함
- `.cursorignore`를 complete security system으로 취급함
- AI를 오도하는 outdated rules를 유지함
- Base URL configuration이 project rules를 대체한다고 생각함
- Cursor Rules와 Claude Code `CLAUDE.md`를 섞음

## BetterToken 정보

BetterToken은 model API access 및 usage visibility를 처리합니다. Cursor Rules, `AGENTS.md`, `.cursorignore`는 project context 및 editing behavior를 처리합니다.

API access는 첫 단계일 뿐입니다. long-term output quality는 clear rules와 controlled context에 크게 의존합니다.
