## 계정 및 과금

  <Accordion title="BetterToken은 사용량을 어떻게 과금하나요?">

    자세한 내용은 <a href={"{{pricing-url}}"}>가격 페이지</a>에서 확인하세요.
  </Accordion>

  <Accordion title="가입 후 환불받을 수 있나요?">

  </Accordion>

  <Accordion title="하나의 API Key를 여러 도구에서 사용할 수 있나요?">

## 설정 및 구성

<AccordionGroup>
  <Accordion title="BetterToken의 base_url은 무엇인가요?">
    BetterToken은 프로토콜에 따라 서로 다른 두 엔드포인트를 사용합니다.

    | 사용 환경 | Base URL |
    |----------|----------|
    | Claude Code / `ANTHROPIC_BASE_URL` | `{{anthropic-base-url}}` |
    | Codex / `OPENAI_BASE_URL` / 외부 도구 | `{{openai-base-url}}` |

    모든 도구에서 하나의 주소를 재사용하지 마세요.
  </Accordion>

  <Accordion title="Claude Code에서 모델을 지정해야 하나요?">
    선택한 제공자에 따라 다릅니다.

    **Claude 제공자**에서는 `ANTHROPIC_BASE_URL`과 `ANTHROPIC_AUTH_TOKEN`만 설정하면 됩니다. 모델 변수는 필요하지 **않습니다**.

    **GPT 제공자**에서는 `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_OPUS_MODEL`로 Claude Code 모델 매핑을 추가하세요. <a href={"{{model-plaza-url}}"}>모델 광장</a>의 현재 **GPT 제공자**에서 모델 ID를 복사하세요.
  </Accordion>

  <Accordion title="Codex에서 모델을 지정해야 하나요?">
    예. <a href={"{{model-plaza-url}}"}>모델 광장</a>의 **GPT 제공자**에서 복사한 모델 ID를 입력하세요.

    자세한 내용은 [Codex 설정 가이드](/ko/ai-tools/codex)를 참고하세요.
  </Accordion>

  <Accordion title="Cursor 같은 다른 도구에서도 모델을 지정해야 하나요?">
    예. Cursor, Cline, Zed, OpenClaw 같은 외부 도구는 **GPT 제공자**를 사용합니다. <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 현재 모델 ID를 복사하세요.

    이 도구들에서 하드코딩된 Claude 모델 이름을 계속 사용하지 마세요.

    자세한 내용은 [Cursor 설정 가이드](/ko/ai-tools/cursor)를 참고하세요.
  </Accordion>

  <Accordion title="OpenClaw와 다른 외부 도구에 추가 헤더가 필요한가요?">
    일반적으로 필요하지 않습니다.

    확인한 공식 문서에 따르면 Cursor, Cline, Zed 같은 일반적인 외부 도구에서는 `Base URL`, API Key, 모델 ID를 설정합니다. OpenCode와 OpenClaw는 선택적 `headers`도 지원하지만 공식 문서에서는 이를 BetterToken의 필수 설정이 아닌 사용자 지정 헤더 또는 사용자 지정 인증 용도로 설명합니다.

    도구의 공식 문서나 자체 업스트림 게이트웨이, 테넌트 라우팅, 관측성 또는 캐시 계층에서 명시적으로 요구할 때만 추가 헤더를 설정하세요.
  </Accordion>

  <Accordion title="설정 후 인증에 실패하면 어떻게 해야 하나요?">
    다음 항목을 확인하세요.

    1. API Key가 정확하고 불필요한 공백이 없는지 확인하세요.
    2. Claude Code는 `{{anthropic-base-url}}`을 사용하고 Codex / 외부 도구는 `{{openai-base-url}}`을 사용하는지 확인하세요.
    3. 기존 `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_BASE_URL` 변수가 설정을 덮어쓰는지 확인하세요.
    4. 외부 도구의 버전 제한, 모델 허용 목록 또는 업스트림 게이트웨이가 명시적으로 요구하는 추가 헤더 같은 공식 요구 사항을 확인하세요.

    문제가 계속되면 고객 지원에 문의하세요.
  </Accordion>
</AccordionGroup>

## 안정성과 Rate Limit

<AccordionGroup>
  <Accordion title="BetterToken은 어떻게 안정성을 유지하나요?">
    BetterToken은 여러 공급자에 연결하고 다음 메커니즘을 사용합니다.

    - **다중 공급원**: 한 공급자에 장애가 발생해도 전체 요청이 중단되지 않습니다.
    - **동적 라우팅**: BetterToken이 가장 빠르고 안정적인 경로를 실시간으로 선택합니다.
    - **핵심 도구 집중**: Claude Code와 Codex 생태계의 안정성을 우선합니다.
  </Accordion>

  <Accordion title="Rate Limit이나 시간 초과가 발생하면 어떻게 해야 하나요?">
    BetterToken은 개별 공급자의 Rate Limit과 시간 초과를 자동으로 처리합니다. 문제가 계속되면 다음을 확인하세요.

    1. 잔액이 충분한지 확인하세요.
    2. 도구의 시간 제한을 늘리세요. (`API_TIMEOUT_MS=3000000` 권장)
    3. 고객 지원에 문의해 현재 할당량 상태를 확인하세요.
  </Accordion>

  <Accordion title="BetterToken은 프로덕션 환경에 적합한가요?">
    BetterToken은 주로 Claude Code와 Codex 같은 AI 코딩 도구를 사용하는 개인 개발자를 위해 설계되었습니다. 대규모 프로덕션 API 워크로드에는 자체 요구 사항에 맞춰 평가하세요.
  </Accordion>
</AccordionGroup>
