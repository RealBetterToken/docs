`POST /v1/responses`

Codex와 OpenAI Responses API를 사용하는 applications에는 이 endpoint를 사용하세요.

<Note>
  Base URL: `{{openai-base-url}}`. API Key를 `Authorization: Bearer YOUR_API_KEY`로 전달하세요.
</Note>

## Playground에서 테스트

오른쪽 Playground에서 API Key를 입력하고 필요하면 `model`을 현재 GPT provider model ID로 바꾼 다음 request를 보내세요. 테스트하기 전에 <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 model을 확인하세요.

<Warning>
  자신의 test API Key만 사용하세요. keys를 code, screenshots, tickets 또는 Git repositories에 넣지 마세요.
</Warning>
