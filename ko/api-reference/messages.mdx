`POST /v1/messages`

Claude Code, Anthropic SDK 및 Anthropic Messages API를 사용하는 applications에는 이 endpoint를 사용하세요.

<Note>
  SDK에는 `{{anthropic-base-url}}`을 Base URL로 사용하세요. manual request와 Playground는 전체 `{{anthropic-base-url}}/v1/messages` path를 사용합니다.
</Note>

## Playground에서 테스트

오른쪽 Playground에서 `x-api-key` field에 API Key를 입력하고 `anthropic-version`은 `claude-cli/2.0.76 (external, cli)`로 유지한 후 사용할 수 있는 Claude provider model을 선택하여 request를 보내세요.

<Warning>
  이 endpoint에 `Authorization: Bearer ...`를 사용하지 마세요. `x-api-key` header가 필요합니다.
</Warning>
