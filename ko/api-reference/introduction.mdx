BetterToken은 OpenAI-compatible Chat Completions 및 Responses API와 Anthropic-compatible Messages API를 제공합니다. 클라이언트에서 사용하는 API 형식을 선택하세요.

## API 선택

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/ko/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/ko/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/ko/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/ko/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/ko/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Chat Completions 연결 정보

| 필드 | 값 |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Full request URL | `{{chat-completions-url}}` |
| Method | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

<a href={"{{model-plaza-url}}"}>모델 광장</a> 또는 콘솔의 API Key **설정** 대화 상자에서 현재 Model ID를 복사하세요.

<Warning>
  도구에서 **Base URL**을 요구하면 `{{openai-base-url}}`을 입력하세요. 도구가 전체 요청 URL을 명시적으로 요구할 때만 `{{chat-completions-url}}`을 사용하세요.
</Warning>

## 빠른 테스트

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

성공한 응답에는 `choices[0].message.content`가 포함됩니다.
