현재 공개된 BetterToken API 레퍼런스는 **OpenAI 호환 Chat Completions API**만 다룹니다. 다른 프로토콜은 모든 채널에서 일관되게 지원되지 않으므로 Responses API와 Anthropic Messages API는 공개 인터페이스로 제공하지 않습니다.

## 연결 정보

| 필드 | 값 |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Full request URL | `{{chat-completions-url}}` |
| Method | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

<a href={"{{model-plaza-url}}"}>모델 광장</a> 또는 콘솔의 API Key **설정** 대화 상자에서 현재 Model ID를 복사하세요.

<Warning>
  도구에서 **Base URL**을 요구하면 `{{openai-base-url}}`을 입력하세요. 도구가 전체 요청 URL을 명시적으로 요구할 때만 `{{chat-completions-url}}`을 사용하세요.
</Warning>

## 빠른 테스트

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

성공한 응답에는 `choices[0].message.content`가 포함됩니다.
