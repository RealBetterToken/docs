OpenCode는 `@ai-sdk/openai-compatible`을 사용해 BetterToken에 연결합니다. OpenCode 제공자 이름은 **BetterToken** 또는 **OpenAI Compatible**로 지정하세요. GPT, Kimi, GLM은 BetterToken 내부의 모델 제공자이며 OpenCode 제공자 이름이 아닙니다.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## 명령줄 설정

BetterToken 자동 설정 스크립트는 OpenCode의 BetterToken 제공자를 생성하거나 업데이트합니다. Node.js가 필요합니다. API Key 또는 Model ID를 인수로 전달하지 않으면 직접 입력하라는 메시지가 표시됩니다.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-opencode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-opencode-provider-ps1-url}}" -OutFile "$env:TEMP\install-opencode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-opencode-provider.ps1"
    ```
  </Tab>
</Tabs>

스크립트가 완료되면 `bettertoken/YOUR_MODEL_ID`를 선택하세요. OpenCode가 이미 실행 중이라면 테스트 전에 다시 시작하세요.

## 수동 설정

### 방법 1: /connect로 인증 정보 저장

OpenCode를 시작하고 다음을 실행하세요.

```text
/connect
```

**Other**를 선택하고 제공자 ID로 `bettertoken`을 입력한 뒤 `YOUR_API_KEY`를 입력하세요. OpenCode가 인증 정보를 로컬에 저장합니다.

### 방법 2: JSON 설정

전역 파일은 `~/.config/opencode/opencode.json`입니다. 프로젝트 루트에서는 `opencode.json`을 사용할 수 있습니다.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "{{openai-base-url}}"
      },
      "models": {
        "YOUR_MODEL_ID": {
          "name": "YOUR_MODEL_ID"
        }
      }
    }
  }
}
```

`/connect`를 사용하지 않으면 `"apiKey": "YOUR_API_KEY"`를 `options` 아래에 추가하세요. 실제 Key가 포함된 설정은 절대 커밋하지 마세요.

## 연결 확인

프로젝트에서 `opencode`를 실행하고 `bettertoken/YOUR_MODEL_ID`를 선택한 뒤 짧은 메시지를 보내세요. 정상 응답이 오면 설정이 완료된 것입니다. JSON을 변경한 뒤에는 OpenCode를 다시 시작하세요.

## 모델 전환

새 `YOUR_MODEL_ID`를 `provider.bettertoken.models` 아래에 추가하고 최상위 `model`을 업데이트한 뒤 저장하고 다시 시작하세요.

## 흔한 오류

| 오류 | 해결 방법 |
| --- | --- |
| `401` | `/connect`를 다시 실행하거나 `apiKey`를 확인하세요. |
| `404` | `{{openai-base-url}}`만 `baseURL`로 사용하고 `/chat/completions`를 추가하지 마세요. |
| 모델을 찾을 수 없음 | 최상위 `model`이 `models` 아래의 ID와 정확히 일치하도록 설정하세요. |
| 설정이 적용되지 않음 | 프로젝트의 `opencode.json`이 전역 파일을 덮어쓰는지 확인한 뒤 OpenCode를 다시 시작하세요. |
