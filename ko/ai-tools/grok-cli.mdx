“Grok CLI”는 서로 다른 두 도구를 가리킬 수 있습니다.

- **Grok Build** — xAI 공식 coding agent
- **커뮤니티 Grok CLI** — xAI와 관련 없는 오픈 소스 프로젝트

두 클라이언트 모두 BetterToken에서 검증되었습니다. BetterToken API Key, Base URL, Model ID를 사용해 모델 응답을 받았습니다. 이 문서는 설정이 더 직접적인 **커뮤니티 Grok CLI**부터 설명합니다.

<Warning>두 도구 모두 `grok` 명령을 사용합니다. 둘 다 설치하면 `PATH`에서 먼저 발견된 버전이 실행됩니다.</Warning>

## Grok CLI와 Grok Build 비교

| 항목 | 공식 Grok Build | 커뮤니티 Grok CLI |
| --- | --- | --- |
| 관리자 | xAI | `superagent-ai/grok-cli`, xAI와 무관 |
| 인증 | 브라우저 로그인 또는 `XAI_API_KEY` | `GROK_API_KEY` |
| 사용자 Base URL | `~/.grok/config.toml` | `GROK_BASE_URL` |
| 모델 | 설정의 alias | `GROK_MODEL` |
| BetterToken 모델 호출 | 검증됨 | 검증됨 |
| 명령 | `grok` | `grok` |

검증 범위는 텍스트 및 코드 모델 요청이며 도구 호출과 xAI 전용 API는 포함하지 않습니다.

## 커뮤니티 Grok CLI에서 BetterToken 사용

다음 명령은 macOS, Linux, WSL용입니다. 커뮤니티 클라이언트의 Windows 네이티브 설정은 검증되지 않았습니다.

### 설치

```bash
curl -fsSL https://raw.githubusercontent.com/superagent-ai/grok-cli/main/install.sh | bash
grok --version
```

Bun이 설치되어 있다면:

```bash
bun add -g grok-dev
```

### BetterToken 설정

```bash
export GROK_BASE_URL="{{openai-base-url}}"
export GROK_API_KEY="YOUR_API_KEY"
export GROK_MODEL="YOUR_MODEL_ID"
```

`YOUR_MODEL_ID`를 <a href={"{{model-plaza-url}}"}>모델 광장</a>의 전체 Model ID로 바꾸고 <a href={"{{register-url}}"}>BetterToken API Key</a>를 사용하세요.

### 연결 확인

```bash
grok -p "Reply with only: OK"
```

모델 응답이 반환되어야 API Key, Base URL, Model ID가 작동한다고 확인할 수 있습니다. 환경 변수를 바꾼 뒤 클라이언트를 다시 시작하세요.

## 공식 Grok Build

[Grok Build](https://docs.x.ai/build/overview)는 xAI 공식 터미널 coding agent입니다.

### 설치 및 로그인

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    grok --version
    ```
  </Tab>
</Tabs>

처음 실행하면 브라우저가 열립니다. 브라우저가 없는 환경에서는 다음을 사용합니다.

```bash
export XAI_API_KEY="YOUR_XAI_API_KEY"
grok
```

### Grok Build에서 BetterToken 설정

```toml
[model.bettertoken]
model = "YOUR_MODEL_ID"
base_url = "{{openai-base-url}}"
name = "BetterToken"
env_key = "BETTERTOKEN_API_KEY"
api_backend = "chat_completions"

[models]
default = "bettertoken"
```

`BETTERTOKEN_API_KEY`는 예시 변수 이름입니다. Grok Build는 `env_key`에 지정된 변수를 읽습니다.

```bash
export BETTERTOKEN_API_KEY="YOUR_API_KEY"
grok inspect
grok -p "Reply with only: OK" -m bettertoken
```

<Note>이 설정으로 Grok Build가 BetterToken을 통해 모델 응답을 반환했습니다. 도구 호출과 xAI 전용 API는 검증되지 않았습니다.</Note>

## 자주 발생하는 오류

| 문제 | 확인 사항 |
| --- | --- |
| 다른 클라이언트가 실행됨 | 각 `grok` 명령의 경로와 버전을 확인합니다. |
| `401` 또는 `Unauthorized` | 커뮤니티 버전은 `GROK_API_KEY`, Grok Build는 `env_key`의 변수를 읽습니다. |
| `model not found` | 모델 광장에서 전체 Model ID를 복사한 뒤 다시 시작합니다. |
| 요청이 xAI로 전송됨 | `GROK_BASE_URL`을 확인하거나 Grok Build에서 `grok inspect`를 실행합니다. |

## 모델 및 기능 제한

<a href={"{{model-plaza-url}}"}>모델 광장</a>의 OpenAI-compatible 전체 Model ID를 사용하세요. X Search, 음성, 이미지, 동영상 등 xAI 전용 API는 이 설정에 포함되지 않습니다.
