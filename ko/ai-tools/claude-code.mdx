BetterToken API Key, Base URL `{{anthropic-base-url}}`, 사용할 Model ID를 설정해 Claude Code를 연결하세요. <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## 준비 사항

- 최신 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 설치
- Node.js 설치
- <a href={"{{register-url}}"}>BetterToken API Key 생성 및 복사</a>

## 설치하기

```bash
npm install -g @anthropic-ai/claude-code
```

## 명령줄 설정

BetterToken 자동 설정 스크립트는 Claude Code 제공자 설정을 작성합니다. Node.js가 필요하며 API Key를 인수로 전달하지 않으면 직접 입력하라는 메시지가 표시됩니다.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

완료되면 `~/.claude/settings.json`을 확인하세요. Windows에서는 `%USERPROFILE%\.claude\settings.json`을 확인합니다. 그런 다음 Claude Code를 완전히 다시 시작하세요. 각 필드를 직접 제어하려면 아래 수동 설정을 사용하세요.

## 수동 설정

| 시스템 | 파일 |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

<a href={"{{model-plaza-url}}"}>모델 광장</a>에서 정확한 Model ID를 복사하세요.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

`YOUR_MODEL_ID`를 복사한 ID로 바꾸세요. `ANTHROPIC_MODEL`은 기본 모델을, 세 개의 `ANTHROPIC_DEFAULT_*_MODEL` 변수는 Haiku, Sonnet, Opus 별칭을 설정합니다. 같은 모델이나 역할별로 다른 모델을 지정할 수 있습니다.

### VS Code 확장

확장 프로그램은 VS Code의 `settings.json`을 사용합니다. 별도의 `claudeCode.environmentVariables` 설정을 추가하세요.

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_SONNET_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_OPUS_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

## 연결 확인

프로젝트에서 Claude Code를 시작하세요.

```bash
claude
```

짧은 메시지를 보내세요. `401`, 연결 오류, 모델 오류 없이 정상 응답이 오면 설정이 완료된 것입니다. 파일을 변경한 뒤에는 Claude Code를 완전히 다시 시작하세요.

## 모델 전환

설정에서 Model ID를 변경하고 Claude Code를 다시 시작하세요. 세션 중에는 `/model YOUR_MODEL_ID`로 전환하세요.

## 흔한 오류

| 오류 | 해결 방법 |
| --- | --- |
| `401` 또는 인증 실패 | `ANTHROPIC_AUTH_TOKEN`을 확인하고 API Key 앞뒤의 공백을 제거하세요. |
| `ConnectionRefused` | `{{anthropic-base-url}}`을 정확히 사용하고 `/v1`을 추가하지 마세요. |
| Model ID | 모델 광장에서 정확한 Model ID를 확인하고 클라이언트의 모델 설정에 입력하세요. |
| 설정이 적용되지 않음 | 파일 경로를 확인하고 충돌하는 환경 변수를 제거한 뒤 Claude Code를 완전히 다시 시작하세요. |
