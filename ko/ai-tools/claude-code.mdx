Claude 모델은 터미널 변수나 설정 파일을 통해 직접 연결할 수 있습니다. Kimi와 GLM은 같은 Base URL에 명시적인 모델 매핑을 사용합니다. GPT에는 [고급 설정](#advanced-setup)이 필요합니다.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude Code에서 관리 |

## 준비 사항

- 최신 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 설치
- Node.js 설치
- <a href={"{{register-url}}"}>BetterToken API Key 생성 및 복사</a>

## 설치하기

```bash
npm install -g @anthropic-ai/claude-code
```

## 명령줄 설정

BetterToken 자동 설정 스크립트는 Claude Code 제공자 설정을 작성합니다. Node.js가 필요하며 API Key를 인수로 전달하지 않으면 직접 입력하라는 메시지가 표시됩니다.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

완료되면 `~/.claude/settings.json`을 확인하세요. Windows에서는 `%USERPROFILE%\.claude\settings.json`을 확인합니다. 그런 다음 Claude Code를 완전히 다시 시작하세요. 각 필드를 직접 제어하려면 아래 수동 설정을 사용하세요.

## 수동 설정

### Claude 제공자 설정

Claude Code CLI는 다음 파일을 읽습니다.

| 시스템 | 파일 |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

다음을 추가하세요.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000"
  }
}
```

Claude 제공자에는 이 네 개의 변수만 필요합니다. `ANTHROPIC_MODEL` 또는 `ANTHROPIC_DEFAULT_*_MODEL`을 추가하지 마세요.

### Kimi 또는 GLM 제공자 설정

Kimi와 GLM은 같은 `settings.json`에 모델 매핑이 필요합니다. 각 `YOUR_MODEL_ID`를 설정 대화 상자 또는 모델 광장의 Model ID로 교체하세요.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

세 매핑에 하나의 Model ID를 사용하거나 같은 제공자의 서로 다른 모델을 사용할 수 있습니다. 여기에 GPT Model ID를 입력하지 말고 이 페이지 끝의 고급 설정을 사용하세요.

### Claude Code VS Code 확장 프로그램 설정

확장 프로그램은 VS Code의 `settings.json`을 사용합니다. 별도의 `claudeCode.environmentVariables` 설정을 추가하세요.

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    }
  ]
}
```

**Developer: Reload Window**를 실행하거나 VS Code를 완전히 다시 시작하세요.

## 연결 확인

프로젝트에서 Claude Code를 시작하세요.

```bash
claude
```

짧은 메시지를 보내세요. `401`, 연결 오류, 모델 오류 없이 정상 응답이 오면 설정이 완료된 것입니다. 파일을 변경한 뒤에는 Claude Code를 완전히 다시 시작하세요.

## 모델 전환

- Claude 제공자: Claude Code가 모델 선택을 관리하도록 두세요. `ANTHROPIC_MODEL` 또는 `ANTHROPIC_DEFAULT_*_MODEL`을 추가하지 마세요.
- Kimi 또는 GLM 제공자: `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_OPUS_MODEL`을 변경한 뒤 Claude Code를 완전히 다시 시작하세요.
- GPT 제공자: 아래 [고급 설정](#advanced-setup)에 따라 모델을 전환하세요.

## 흔한 오류

| 오류 | 해결 방법 |
| --- | --- |
| `401` 또는 인증 실패 | `ANTHROPIC_AUTH_TOKEN`을 확인하고 API Key 앞뒤의 공백을 제거하세요. |
| `ConnectionRefused` | `{{anthropic-base-url}}`을 정확히 사용하고 `/v1`을 추가하지 마세요. |
| 모델을 찾을 수 없음 | Claude에서는 모델을 수동으로 설정하지 마세요. Kimi 또는 GLM에서는 세 `ANTHROPIC_DEFAULT_*_MODEL` 값이 모두 현재 Model ID인지 확인하세요. |
| 설정이 적용되지 않음 | 파일 경로를 확인하고 충돌하는 환경 변수를 제거한 뒤 Claude Code를 완전히 다시 시작하세요. |

### 지원 Provider

| Provider | 상태 |
| --- | --- |
| Claude | 명령줄 + 수동 설정 |
| GPT | 고급 설정 |
| Kimi | 수동 설정 |
| GLM | 수동 설정 |

<Note>표시된 상태는 이 페이지에서 설명하는 BetterToken 설정 방식에 적용됩니다.</Note>

<Accordion title="설정 방식 설명">
  - **고급 설정**: CC Switch를 설치하고 로컬 프록시, 프로토콜 변환 또는 모델 매핑을 사용하세요.
  - **수동 설정**: API Key, Base URL, Model을 입력하세요.
  - **명령줄 + 수동 설정**: 생성된 명령을 사용하거나 전체 수동 단계를 따르세요.
</Accordion>
{/* tool-provider-support:end */}

Claude Code에서 GPT를 사용하려면 [BetterToken과 CC Switch](/ko/ai-tools/cc-switch#claude-code)를 통해 설정하세요. Claude Code 탭에서 API Key, Base URL, Model Mapping을 입력한 뒤 프록시를 활성화하세요.
