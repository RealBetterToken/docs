Hermes Agent를 BetterToken에 연결하려면 API Key를 준비하고 아래 Base URL을 입력한 후 모델 광장에서 현재 Model ID를 선택하세요.

## 주요 설정

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| 모델 | <a href={"{{model-plaza-url}}"}>모델 광장</a>의 현재 Model ID |

## 사전 요구 사항

- 최신 버전의 도구가 설치되어 있음
- BetterToken API Key: <a href={"{{register-url}}"}>등록하고 발급받기</a>
- <a href={"{{model-plaza-url}}"}>모델 광장</a>의 Model ID

### 추가 요구 사항

- 선택한 Model ID가 **지원되는 provider**에서 옴
- macOS, Linux, Windows 10/11 또는 WSL2
- 도구 사용을 위한 최소 64K context window의 모델

## 수동 설정

Interactive Hermes Agent model setup을 기본 경로로 사용하세요. Manual setup이 필요한 경우에만 config files를 직접 수정하세요.

| 필드 | 값 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| 모델 | <a href={"{{model-plaza-url}}"}>모델 광장</a>의 현재 Model ID |

### 설정

<Tabs>
  <Tab title="Interactive setup">
    <Steps>
      <Step title="model selector 실행">
        Hermes chat이 열려 있다면 먼저 session을 종료하세요. 그런 다음 실행하세요.

        ```bash
        hermes model
        ```
      </Step>

      <Step title="Custom endpoint 선택">
        provider list에서 **Custom endpoint (self-hosted / VLLM / etc.)**를 선택하세요.
      </Step>

      <Step title="BetterToken config 입력">
        다음을 입력하세요.

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: BetterToken API Key
        - **Model**: <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 복사한 **지원되는 provider의 model ID**

        Hermes가 API mode를 묻는다면 **Chat Completions**를 선택하세요. Agent tool use에는 context가 64K 이상인 model을 선택하세요.
      </Step>

      <Step title="Hermes Agent 시작">
        ```bash
        hermes --tui
        ```

        Classic terminal interface를 사용하려면 `hermes`를 실행하세요.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Config files">
    `~/.hermes/config.yaml`에 custom provider를 추가하세요.

    ```yaml
    model:
      default: YOUR_MODEL_ID
      provider: custom
      base_url: "{{openai-base-url}}"
    ```

    BetterToken API Key는 `~/.hermes/.env`에 별도로 저장하세요.

    ```dotenv
    OPENAI_API_KEY=YOUR_API_KEY
    ```

    `YOUR_MODEL_ID`를 <a href={"{{model-plaza-url}}"}>모델 광장</a>의 supported provider model ID로, `YOUR_API_KEY`를 BetterToken API Key로 바꾸세요. Native Windows에서는 이 files가 `%LOCALAPPDATA%\hermes\`에 있습니다.
  </Tab>
</Tabs>

### OpenClaw에서 migration

이미 OpenClaw를 사용한다면 먼저 현재 Hermes Agent version이 migration command를 제공하는지 확인하세요. 무엇이든 변경하기 전에 dry run을 실행하세요.

```bash
hermes claw migrate --dry-run
```

output을 확인한 후 migration을 실행하세요.

```bash
hermes claw migrate
```

migration 후에도 Hermes Agent **Base URL**, API Key 및 model ID를 검토하세요. 이는 `{{openai-base-url}}`, BetterToken API Key 및 지원되는 provider의 model ID와 일치해야 합니다.

## 연결 확인

Hermes Agent를 시작하고 다음 테스트 prompt를 보내세요. `Reply with HERMES_OK only. Do not use tools.` response가 정확히 `HERMES_OK`라면 연결이 작동합니다.

## 모델 전환

Session 밖에서는 `hermes model`을 실행하세요. Active chat에서 이미 configured된 provider 또는 model을 바꾸려면 `/model`을 사용하세요. <a href={"{{model-plaza-url}}"}>모델 광장</a>의 정확한 Model ID를 선택하세요.

## 일반적인 오류

| 오류 | 확인할 사항 |
| --- | --- |
| `401` 또는 `Unauthorized` | BetterToken API Key를 확인하고 앞뒤 spaces를 제거하세요. |
| `404` | Base URL을 확인하고 specific endpoint path를 추가하지 마세요. |
| `model not found` | 모델 광장에서 현재 Model ID를 복사하세요. |
| Changes가 적용되지 않음 | configuration을 저장하고 도구를 완전히 다시 시작하세요. |


### 문제 해결

- requests가 실패하거나 response를 반환하지 않으면 **Base URL**이 정확히 `{{openai-base-url}}`인지 확인하세요. 이 field에 `/chat/completions`를 추가하지 마세요.
- Hermes가 model이 존재하지 않는다고 보고하면 **Model**이 <a href={"{{model-plaza-url}}"}>모델 광장</a>의 지원되는 provider model ID인지 확인하세요.
- authentication이 실패하면 복사된 spaces를 확인하고 선택한 Model ID가 **지원되는 provider**에서 왔는지 확인하세요.
- 변경 후에도 Hermes가 이전 model을 사용하면 현재 Hermes Agent session을 종료하고 `hermes`를 다시 실행하세요.
- BetterToken에는 보통 extra `User-Agent` 또는 custom headers가 필요하지 않습니다. custom gateway, tenant routing, observability 또는 caching layer가 명시적으로 요구할 때만 headers를 추가하세요.

<Note>
  실제 API Keys를 repository에 commit하지 마세요. team-shared setup에는 environment variables 또는 local config를 우선 사용하세요.
</Note>
