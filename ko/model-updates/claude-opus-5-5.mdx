Claude Opus 5.5는 Anthropic이 발표한 Claude 5.5 제품군의 첫 모델입니다. Anthropic에 따르면 Opus 5보다 장시간 코딩과 전문 업무에서 성능이 개선됐으며, 긴 작업 세션에서도 설명이 더 명확해졌습니다.

**Claude Opus 5.5**를 BetterToken에서 사용할 수 있습니다. `Claude` 제공자를 선택하고 Base URL을 `{{anthropic-base-url}}`로 설정한 뒤 Model ID에 `claude-opus-5-5`를 입력하세요. 현재 이용 가능 여부와 가격은 <a href={"{{model-plaza-url}}"}>model plaza</a>에서 확인합니다.

## 주요 특징

- 복잡한 저장소 변경, 감사, 장시간 Agent 작업.
- 프로덕션 코드, 복잡한 문서, computer use.
- 긴 세션에서 더 명확한 설명. Anthropic은 Opus 5보다 답변이 이해하기 쉬워졌다고 설명합니다.

## 연결 방법

1. <a href={"{{register-url}}"}>BetterToken API Key를 만듭니다</a>.
2. `Claude`와 `{{anthropic-base-url}}`을 설정합니다.
3. Model ID에 `claude-opus-5-5`를 입력합니다.
