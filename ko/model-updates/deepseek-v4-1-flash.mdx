## 현재 사용할 수 있는 설정

| 설정 | 값 |
| --- | --- |
| 제공업체 | **DeepSeek** |
| Model ID | `deepseek-flash` |
| OpenAI Base URL | `{{openai-base-url}}` |
| OpenAI Chat Completions | `POST /v1/chat/completions` |
| Anthropic Base URL | `{{anthropic-base-url}}` |

클라이언트에 맞게 OpenAI Chat Completions 또는 Anthropic Messages를 선택하세요. 두 프로토콜은 같은 BetterToken API Key와 Model ID를 사용합니다.

## 사용 권장 사항

실제 워크플로에 중요한 작업으로 DeepSeek V4.1 Flash와 현재 사용할 수 있는 다른 모델을 비교하세요.

- **코드 변경**: 두 모델에 같은 저장소 작업을 주고 정확성, 수정 품질, 추가 지시가 필요한 정도를 비교합니다
- **Agent 워크플로**: 각 모델이 여러 단계의 지시를 따르고 클라이언트 도구를 사용하는 안정성을 측정합니다
- **추론 품질**: 같은 프롬프트와 평가 기준으로 어려운 디버깅, 계획, 분석 작업을 비교합니다
- **지연 시간과 비용**: 첫 token까지의 시간, 전체 완료 시간, token 사용량, 현재 BetterToken 가격을 기록합니다

한 번의 결과에 의존하지 말고 대표적인 프롬프트를 여러 개 실행하세요. 공정한 비교를 위해 클라이언트, 시스템 프롬프트, 도구 정의, 샘플링 설정을 동일하게 유지하세요.

## 빠른 시작

1. <a href={"{{register-url}}"}>BetterToken API Key를 생성</a>하거나 기존 Key의 **Setup**을 엽니다.
2. 모델 광장에서 `deepseek-flash`를 사용할 수 있는지 확인합니다.
3. **DeepSeek 제공업체**를 선택합니다.
4. 위 표에서 프로토콜에 맞는 Base URL을 선택하고 전체 Model ID를 입력합니다.
5. 긴 평가를 시작하기 전에 작은 요청을 먼저 보냅니다.

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

성공한 응답에서는 모델 출력이 `choices[0].message.content`에 반환됩니다. SDK 예제와 전체 요청 형식은 [Chat Completions API 레퍼런스](/ko/api-reference/chat-completions)를 참조하세요.

## 기간 한정 테스트용 Model ID에서 이전하기

설정에서 이전 기간 한정 테스트용 Model ID를 계속 사용하고 있다면 다음을 수행하세요.

1. `deepseek-v4.1-flash-expires-on-0910`이 포함된 모든 설정을 찾습니다.
2. `deepseek-flash`로 교체합니다.
3. 변경 후 스모크 테스트를 실행합니다.
4. 모델 광장에서 현재 모델 항목과 가격을 확인합니다.

## 자주 묻는 질문

### 이 Model ID를 프로덕션에서 사용할 수 있나요?

가능합니다. `deepseek-flash`를 사용하고 모델 광장에서 BetterToken API Key로 이 모델을 사용할 수 있는지 확인하세요.

### Claude Code 또는 Anthropic Messages API와 함께 사용할 수 있나요?

지원합니다. Claude Code 또는 Anthropic Messages에서는 Base URL `{{anthropic-base-url}}`과 Model ID `deepseek-flash`을 사용하세요. Messages를 직접 호출할 때는 `POST /v1/messages`를 사용하고 `x-api-key` 헤더에 BetterToken API Key를 전달하세요.

### 현재 가격은 어디에서 확인할 수 있나요?

실시간 <a href={"{{model-plaza-url}}"}>모델 광장</a>을 확인하세요. 제공 여부와 가격은 변경될 수 있습니다.
