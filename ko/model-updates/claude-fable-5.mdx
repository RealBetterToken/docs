Release date: 2026년 6월 9일

BetterToken은 `Claude Fable 5` model entry를 업데이트했습니다. <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 currently available model ID를 확인한 다음 client에 맞는 Claude Code 또는 external-tool setup guide를 통해 configure하세요.

Anthropic은 2026년 6월 9일 Claude Fable 5를 officially introduced했으며 hardest knowledge work와 coding problems를 위한 new generation of intelligence라고 설명합니다. Anthropic에 따르면 Fable 5는 longer, more complex, more asynchronous work, 특히 long-running agents, complex software engineering, knowledge work, vision-heavy workflows를 위해 built된 Mythos-class model입니다.

## 주요 특징

- **Stronger long-running agent work**: Anthropic은 Fable 5가 Claude Code 또는 agent harness에서 longer operate하고 stages에 걸쳐 planning, executing, own work checking을 수행할 수 있다고 설명합니다.
- **complex software engineering에 더 적합**: 이 model은 large migrations, complex implementations, multi-day autonomous sessions 및 less direct supervision이 필요한 engineering tasks를 대상으로 합니다.
- **improved knowledge work와 vision**: Fable 5는 complex analysis, document reasoning, charts, tables, PDFs 및 other visual materials를 대상으로 합니다.
- **more active self-checking**: Anthropic은 Fable 5가 own work를 more thoroughly validates한다고 강조하며, 이는 task를 hand off하고 나중에 result를 review할 때 도움이 됩니다.
- **new safeguards**: cybersecurity, biology, chemistry 같은 sensitive areas에서 Anthropic은 safeguards와 fallback behavior를 적용합니다. 일부 requests는 대신 Claude Opus 4.8이 answer할 수 있습니다.

## Setup guidance

Claude Code를 사용한다면 [Claude Code setup guide](/ko/ai-tools/claude-code)로 start하세요. Different providers는 different protocols와 model configuration patterns를 사용합니다.

- `Claude` group: `{{anthropic-base-url}}`를 사용합니다.
- `GPT` group 또는 external tools: relevant tool guide에 따라 `{{openai-base-url}}`를 사용합니다.

<a href={"{{model-plaza-url}}"}>모델 광장</a>에 currently shown되는 model name을 사용하세요. 거기에 표시되지 않은 model name을 hardcode하지 마세요.

<Note>
  Claude Fable 5는 high-value, long-context, long-running tasks에 가장 적합합니다. simple Q&A 또는 low-cost batch work에는 model plaza에 표시된 groups와 pricing을 기준으로 lighter model을 선택하세요.
</Note>
