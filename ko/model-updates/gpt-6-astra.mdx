업데이트: 2026년 9월 5일

BetterToken에서 **GPT-6 Astra**를 사용할 수 있습니다. 정확한 Model ID는 `gpt-6-astra`입니다. OpenAI는 Astra를 복잡한 추론, 소프트웨어 엔지니어링, 연구, 컴퓨터 사용, 문서 작성과 같은 어려운 엔드투엔드 작업을 위한 가장 강력한 모델로 소개합니다. 현재 제공 상태와 BetterToken 가격은 <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 확인하세요.

## 업데이트 주요 내용

- **엔드투엔드 작업**: 코드, 브라우저, 도구, 전문 애플리케이션을 아우르는 복잡한 다단계 작업용
- **소프트웨어 엔지니어링**: OpenAI는 Astra를 코딩과 에이전트 개발을 위한 현재까지 가장 강력한 모델로 설명합니다
- **대규모 컨텍스트**: OpenAI 사양은 `1,050,000` tokens 컨텍스트와 최대 `128,000` output tokens를 명시합니다
- **조절 가능한 추론**: OpenAI API는 `low`, `medium`, `high`, `xhigh`, `max` reasoning effort를 지원합니다
- **Responses API 도구**: 함수 호출, 구조화 출력, 웹 검색, 파일 검색, 코드 인터프리터, computer use, MCP 등을 지원합니다

## 설정 권장 사항

- 어려운 코딩, 연구, computer use, 장시간 에이전트 작업에 Astra를 사용해 보세요. 일상 작업에는 모델 광장의 더 빠르거나 저렴한 모델과 비교하세요.
- 프로덕션 트래픽을 전환하기 전에 실제 작업으로 품질, 지연 시간, token 사용량을 비교하세요.
- **GPT provider**, Base URL `{{openai-base-url}}`, 정확한 Model ID `gpt-6-astra`를 사용하세요.
- 단계적 출시 중에는 제공 상태가 바뀔 수 있습니다. BetterToken 제공 여부와 가격은 모델 광장을 기준으로 확인하세요.

## 빠른 시작

1. BetterToken API Key를 만들거나 기존 Key의 **Setup** 창을 엽니다.
2. 모델 광장에서 `gpt-6-astra`의 제공 상태를 확인합니다.
3. Base URL을 `{{openai-base-url}}`, model을 `gpt-6-astra`로 설정합니다.
4. 모델 목록이 자동으로 갱신되지 않으면 클라이언트를 다시 시작합니다.
5. 작은 테스트 작업을 실행하고 Dashboard에서 요청을 확인합니다.

## 자주 묻는 질문

### GPT-6 Astra의 Model ID는 무엇인가요?

`gpt-6-astra`를 사용하세요. 표시 이름 `GPT-6 Astra`나 다른 플랫폼의 ID를 사용하지 마세요.

### BetterToken에서 1,050,000-token 컨텍스트를 모두 사용할 수 있나요?

OpenAI는 GPT-6 Astra의 컨텍스트를 `1,050,000` tokens로 명시합니다. 실제 사용 한도는 클라이언트, 요청 설정, 현재 BetterToken 라우팅의 영향도 받을 수 있습니다. 매우 큰 prompt를 보내기 전에 모델 광장과 클라이언트 문서를 확인하세요.

### Model not found 오류는 어떻게 해결하나요?

Model ID가 정확히 `gpt-6-astra`인지, BetterToken API Key에 접근 권한이 있는지, **GPT provider**가 선택되었는지, Base URL이 `{{openai-base-url}}`인지 확인하세요. 클라이언트를 다시 시작한 뒤 재시험합니다.

### 현재 가격은 어디에서 확인하나요?

<a href={"{{model-plaza-url}}"}>모델 광장</a>에서 확인하세요. BetterToken 가격은 OpenAI API 직접 가격과 다를 수 있으며 변경될 수 있습니다.
