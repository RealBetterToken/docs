출시일: 2026년 9월 22일

OpenAI는 Astra에 이어 GPT-6 제품군에 Sol과 Luna를 추가했습니다. Sol은 복잡한 코딩과 Agent 워크플로, Luna는 명확하고 반복적인 대량 작업에 초점을 맞춥니다. OpenAI에 따르면 두 모델 모두 GPT-5.6 세대보다 코딩, 사실 정확성, 설명의 명확성이 개선됐습니다.

BetterToken에서 **GPT-6 Sol**과 **GPT-6 Luna**를 지원합니다. `GPT` 제공자와 Base URL `{{openai-base-url}}`을 설정하고 `gpt-6-sol` 또는 `gpt-6-luna`를 사용하세요. 공식 명칭은 **Sol**이며 `Sora`가 아닙니다.

BetterToken의 현재 가격과 제공 여부는 <a href={"{{model-plaza-url}}"}>model plaza</a>에서 확인하세요.

## 모델 선택

- **`gpt-6-sol`**: 복잡한 코딩과 Agent 워크플로에 사용합니다.
- **`gpt-6-luna`**: 명확하고 반복적인 대량 작업에 사용합니다.

## 주요 특징

- **큰 컨텍스트**: OpenAI는 두 모델 모두 `1,050,000` tokens 컨텍스트와 최대 `128,000` tokens 출력을 지원한다고 설명합니다.
- **조정 가능한 추론 수준**: 두 모델 모두 `none`, `low`, `medium`, `high`, `xhigh`, `max`를 지원합니다.
- **작업 품질**: OpenAI는 GPT-5.6 세대보다 코딩, 사실 정확성, 기술 설명이 개선됐다고 발표했습니다.

## 연결 방법

1. <a href={"{{register-url}}"}>BetterToken API Key를 만듭니다</a>.
2. `GPT`와 Base URL `{{openai-base-url}}`을 설정합니다.
3. 고난도 Agent에는 `gpt-6-sol`, 반복적인 대량 작업에는 `gpt-6-luna`를 사용합니다.
