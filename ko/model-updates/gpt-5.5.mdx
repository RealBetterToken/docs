Release date: April 24, 2026

BetterToken은 `GPT-5.5` model entry를 업데이트했습니다. <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 currently available **GPT provider** model ID를 확인한 다음 matching setup guide를 통해 Codex, OpenCode, OpenClaw, Cursor, Cline, Zed 또는 other external tools에서 configure하세요.

OpenAI는 GPT-5.5를 April 23, 2026에 officially introduced했으며 complex real-world work용 model이라고 described했습니다. OpenAI는 stronger agentic coding, computer use, knowledge work, scientific research workflows를 highlights합니다. 이 model은 intent를 earlier understand하고 more effectively plan하며 tools를 use하고 results를 check하며 multi-step tasks를 continue하도록 designed되었습니다.

## 주요 특징

- **stronger coding-agent performance**: OpenAI는 Terminal-Bench 2.0 및 SWE-Bench Pro 같은 coding과 agentic benchmarks에서 GPT-5.4 대비 improvements를 reports합니다.
- **more reliable long tasks**: implementation, debugging, validation, documentation을 combine하는 workflows에 더 적합합니다.
- **more active tool use**: OpenAI는 stronger tool use, output checking, ambiguous tasks를 통한 progress를 emphasizes합니다.
- **higher efficiency**: OpenAI에 따르면 GPT-5.5는 Codex tasks에서 fewer tokens를 사용하면서 GPT-5.4-level latency를 keeps합니다.

## Setup guidance

Codex와 external tools에서는 <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 current **GPT provider** model ID를 copy하세요. 거기에 표시되지 않은 model name을 hardcode하지 마세요.

Codex version이 API mode에서 `gpt-5.5`를 select하지 못한다면 [Codex가 API mode에서 GPT-5.5를 사용할 수 없는 이유](/ko/faq/codex/gpt-5.5-api-mode)를 참조하세요.
