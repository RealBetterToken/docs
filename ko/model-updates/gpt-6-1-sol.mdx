업데이트: 2026년 9월 30일

**GPT-6.1 Sol**은 GPT-6 Sol의 개선 버전입니다. OpenAI에 따르면 에이전트 코딩, 컴퓨터 조작, 전문 업무에서 성능이 향상됐으며 일부 평가에서는 GPT-6 Astra에 근접합니다. 어려운 작업에는 실제 워크플로에서 품질, 지연 시간, 토큰 사용량을 비교해 보세요.

BetterToken의 Model ID는 `gpt-6.1-sol`입니다. 현재 사용 가능 여부와 BetterToken 가격은 <a href={"{{model-plaza-url}}"}>model plaza</a>에서 확인하세요.

## 주요 특징

- **코딩과 에이전트**: 여러 파일에 걸친 변경, 디버깅, 장시간의 소프트웨어 개발 작업에 적합합니다.
- **앱 조작과 문서 작업**: OpenAI는 이 분야에서 GPT-6 Sol보다 개선됐다고 설명합니다.
- **긴 컨텍스트**: OpenAI가 명시한 컨텍스트 창은 `1,050,000`토큰, 최대 출력은 `128,000`토큰입니다. 클라이언트나 연결 경로에 따라 실제 한도는 더 낮을 수 있습니다.
- **조절 가능한 추론 강도**: `low`, `medium`, `high`, `xhigh`, `max`를 지원하며 `none`과 `minimal`은 지원하지 않습니다.

## 연결 방법

1. <a href={"{{register-url}}"}>BetterToken API Key를 만드세요</a>.
2. Codex CLI 또는 OpenAI 호환 클라이언트에서 Base URL을 `{{openai-base-url}}`, Model ID를 `gpt-6.1-sol`로 설정하세요.
3. 도구 호출이 필요하면 [Responses API](/ko/api-reference/responses)를 사용하세요. OpenAI 문서에 따르면 이 모델의 Chat Completions에서는 도구 호출을 지원하지 않습니다.
4. 기존 워크플로를 전환하기 전에 대표적인 작업으로 테스트하세요.

Claude Code에서는 Anthropic 프로토콜의 Base URL `{{anthropic-base-url}}`과 같은 Model ID를 사용하세요. 자세한 설정은 [Claude Code 가이드](/ko/ai-tools/claude-code)와 [Codex CLI 가이드](/ko/ai-tools/codex)를 참고하세요.
