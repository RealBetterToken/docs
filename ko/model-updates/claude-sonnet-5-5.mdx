출시일: 2026년 9월 28일

Claude Sonnet 5.5는 Anthropic의 Claude 5.5 제품군에서 두 번째로 나온 모델입니다. Anthropic은 코딩, 버그 수정, 문서·프레젠테이션·스프레드시트 제작처럼 범위가 명확한 일상 작업에 더 빠른 선택지로 소개합니다. 더 복잡하고 열린 형태의 작업에는 Opus 5.5를 고려하세요.

**Claude Sonnet 5.5**를 이제 BetterToken에서 사용할 수 있습니다. `Claude` 제공업체를 선택하고 Base URL을 `{{anthropic-base-url}}`로, 모델 ID를 `claude-sonnet-5-5`로 설정하세요. 최신 제공 여부와 가격은 <a href={"{{model-plaza-url}}"}>모델 광장</a>에서 확인하세요.

## 주요 특징

- **명확한 코딩 작업**: 범위가 정해진 기능 구현과 버그 수정에 사용하세요.
- **전문 콘텐츠**: Anthropic은 문서, 프레젠테이션, 스프레드시트 제작을 강조합니다.
- **긴 컨텍스트**: Anthropic에 따르면 컨텍스트 창은 100만 토큰, 최대 출력은 12만 8천 토큰입니다.

## Sonnet 5에서 전환하기 전에

클라이언트에서 Anthropic Messages API를 직접 호출한다면 모델 ID를 변경하기 전에 [공식 마이그레이션 가이드](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)를 확인하세요. Sonnet 5.5에서는 일부 thinking 및 도구 선택 동작이 달라집니다. 대표적인 요청으로 먼저 테스트하세요.

## 연결 방법

1. <a href={"{{register-url}}"}>BetterToken API Key를 생성</a>하세요.
2. `Claude` 제공업체와 Base URL `{{anthropic-base-url}}`을 설정하세요.
3. 모델 ID로 `claude-sonnet-5-5`를 입력하세요.
4. 프로덕션 트래픽을 전환하기 전에 실제 작업으로 테스트하세요.

클라이언트 설정은 [Claude Code 가이드](/ko/ai-tools/claude-code)를, 대안 비교는 [모델 선택 가이드](/ko/faq/model-calling/model-selection-guide)를 참고하세요.
