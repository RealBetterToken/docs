---
title: "빠른 시작"
description: "4단계로 BetterToken 계정 등록, 잔액 충전, API Key 생성을 완료한 뒤 Claude Code, Codex CLI 또는 다른 외부 도구에 맞는 설정 가이드로 이동하세요."
---

<Steps>
  <Step title="계정 만들기">
    <a href={"{{register-url}}"}>BetterToken 가입 페이지</a>에서 계정을 만드세요.

    가입 후 잔액을 충전한 다음 BetterToken API Key를 만드세요.
  </Step>
  <Step title="계정 잔액 충전하기">
    **온라인 충전** 또는 **코드 사용**을 선택할 수 있습니다. 충전 후 콘솔로 돌아가 **현재 잔액**이 갱신되었는지 확인한 다음 API Key를 만드세요.

    <Tabs>
      <Tab title="온라인 충전">
        로그인 후 **콘솔**을 여세요. **현재 잔액** 카드에서 충전할 통화를 선택하고 해당 **충전** 버튼을 클릭하세요.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="여러 통화의 충전 버튼이 표시된 BetterToken 콘솔의 현재 잔액 카드."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        결제 안내를 따르세요. 결제가 완료되면 콘솔로 돌아가 **현재 잔액**이 갱신되었는지 확인하세요.
      </Tab>
      <Tab title="코드 사용">
        로그인 후 **콘솔**을 열고 **현재 잔액** 카드의 왼쪽 아래에 있는 **코드 사용**을 클릭하세요.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="왼쪽 아래의 코드 사용 버튼을 화살표로 표시한 BetterToken 콘솔의 현재 잔액 카드."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        대화 상자에 교환 코드를 입력한 뒤 **사용**을 클릭하세요.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="코드 입력란과 사용 버튼이 있는 코드 사용 대화 상자."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        코드를 사용한 뒤 콘솔로 돌아가 **현재 잔액**이 갱신되었는지 확인하세요.
      </Tab>
    </Tabs>
  </Step>
  <Step title="API Key 관리에서 API Key 만들기">
    사용할 수 있는 잔액이 생기면 콘솔의 **내 API Key** 섹션 오른쪽 위에 있는 **API Key 만들기**를 클릭하세요.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="오른쪽 위의 API Key 만들기 버튼을 화살표로 표시한 BetterToken 콘솔의 내 API Key 섹션."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    **Create API Key** 창에서 **API key name**을 입력하세요. 만료일이나 지출 한도가 필요하면 **Advanced settings**를 펼친 뒤 **Create API Key**를 클릭하세요.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="API key name, Advanced settings, Create API Key 버튼이 있는 Create API Key 창."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="연결 정보 또는 설정 코드 복사하기">
    Key를 만든 후 **Set up API key**의 **Connection details**에서 **API Key**를 복사하세요. 사용할 프로토콜에 따라 **OpenAI** 또는 **Anthropic**을 선택하고 해당 **Base URL**을 복사하세요.

    또는 아래 **Configuration guide**에서 도구나 **API call**을 선택하고, 필요하면 API와 예시 모델을 선택한 다음 제공된 코드를 복사하세요. 자세한 단계는 **View tool documentation**이나 아래 가이드를 참조하세요. 완료하면 **Finish**를 클릭하세요.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="위쪽에서 API Key와 Base URL을 복사하고 아래 Configuration guide에서 도구와 코드를 선택할 수 있는 Set up API key 창."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
