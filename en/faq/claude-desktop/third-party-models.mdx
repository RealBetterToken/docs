Claude Desktop supports only Claude models. This is a Claude Desktop client limitation.

## Setup

Use the [Claude Desktop setup guide](/en/faq/claude-desktop-bettertoken-api) to configure **Gateway**, Base URL `{{anthropic-base-url}}`, your BetterToken API Key, and **Gateway auth scheme** `x-api-key`. Save with **Apply locally**, then fully restart Claude Desktop.

Copy the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Troubleshooting

### 401 / Unauthorized

Check that the API Key is copied correctly and has not expired. Use `x-api-key` for this Gateway configuration, save, and restart Claude Desktop.

### Model

Copy an available Claude Model ID from the model plaza, save the configuration, and restart Claude Desktop.
