With CC Switch `v3.16.5` or later, you can use a BetterToken **GPT Key group** API Key in Claude Desktop. Create a provider, enable the proxy, and restart Claude Desktop. The configuration then takes effect automatically.

<Info>
  Use the latest versions of Claude Desktop and CC Switch. This setup requires a BetterToken API Key from the **GPT Key group**.
</Info>

## Setup steps

<Steps>
  <Step title="Update Claude Desktop and CC Switch">
    Update Claude Desktop to the latest version and CC Switch to `v3.16.5` or later.

    - [Download Claude Desktop](https://claude.ai/download)
    - [Download CC Switch](https://github.com/farion1231/cc-switch/releases)
  </Step>

  <Step title="Switch to Claude Desktop and add a provider">
    Open CC Switch. Select the **Claude Desktop** icon in the top toolbar, then click **+** in the upper-right corner to add a provider.

    <Frame>
      <img
        src="/images/claude-desktop-third-party-models/cc-switch-claude-desktop-add-provider.png"
        alt="Switch to Claude Desktop in CC Switch and click the plus button in the upper-right corner to add a provider."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Fill in the basic fields">
    Enter the following values:

    - **Provider Name**: `BetterToken-codex`
    - **API Key**: your BetterToken API Key from the **GPT Key group**
    - **API Endpoint**: `{{anthropic-base-url}}`

    <Frame>
      <img
        src="/images/claude-desktop-third-party-models/provider-basic-fields.png"
        alt="CC Switch provider editor with BetterToken-codex, API Key, and API Endpoint fields."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Set the model mappings">
    Set **API Format** to **OpenAI Responses API (Requires routing)**, then click **Fetch Models**.

    Use the mappings shown below and keep **Declare 1M** enabled:

    | Model role | Requested model |
    | --- | --- |
    | Sonnet | `gpt-5.6-terra` |
    | Opus | `gpt-5.6-sol` |
    | Fable | `gpt-5.6-sol` |
    | Haiku | `gpt-5.6-luna` |

    <Frame>
      <img
        src="/images/claude-desktop-third-party-models/provider-model-mapping.png"
        alt="CC Switch with OpenAI Responses API selected and mappings configured for Sonnet, Opus, Fable, and Haiku."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Use model IDs currently available in the GPT Key group of the <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Step>

  <Step title="Save, switch, and enable the proxy">
    After saving the provider, return to the Claude Desktop provider list:

    1. Select your new **BetterToken-codex** provider until it shows **In use**.
    2. Turn on the proxy switch in the upper-left corner.

    <Frame>
      <img
        src="/images/claude-desktop-third-party-models/provider-enable-proxy.png"
        alt="BetterToken-codex is active in CC Switch and the proxy switch in the upper-left corner is enabled."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Restart Claude Desktop and choose a model">
    Quit Claude Desktop completely, then open it again. **Gateway** in the lower-left corner confirms that the configuration is active.

    Choose the model you need from the model menu in the message box, then start working.

    <Frame>
      <img
        src="/images/claude-desktop-third-party-models/claude-desktop-gateway-ready.png"
        alt="Claude Desktop after restart, showing Gateway in the lower-left corner and the model selection menu."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## Troubleshooting

### Gateway does not appear in Claude Desktop

Check that **BetterToken-codex** is set to **In use** in CC Switch and the proxy switch is on. Quit Claude Desktop completely and open it again.

### The model list is empty

Open the provider editor, click **Fetch Models**, and confirm that the model mappings were saved. Use a model ID from the GPT Key group in the <a href={"{{model-plaza-url}}"}>model plaza</a>, then restart Claude Desktop.

### `401` or `Unauthorized`

Confirm that you entered a BetterToken API Key from the **GPT Key group**. Save the provider, re-enable the proxy, and restart Claude Desktop after replacing the key.

### Requests are not sent through BetterToken

Confirm that **BetterToken-codex**, rather than Claude Desktop Official, is active and that the proxy switch in the upper-left corner remains enabled.
