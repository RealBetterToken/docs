Claude Desktop can use a third-party inference gateway when developer mode is enabled. Choose the setup path based on your BetterToken Key group: enter the Anthropic-compatible endpoint directly, or forward requests through a CC Switch local route.

<Info>
  If you use an API key from the **Claude Key group**, you can enter `{{anthropic-base-url}}` directly in Claude Desktop. If you use an API key from the **GPT Key group**, configure a local route through CC Switch first, then enter the local service address in Claude Desktop. Do not enter the Codex / OpenAI-compatible endpoint `{{openai-base-url}}` directly in Claude Desktop Gateway.
</Info>

## Setup steps

<Steps>
  <Step title="Download Claude Desktop">
    Download the latest Claude Desktop app from the official link:

    [Download Claude for Mac](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect)

    After installation, do not sign in to a Claude account. Continue to the next step and enable developer mode.
  </Step>

  <Step title="Enable developer mode">
    Open Claude Desktop, then choose **Help** → **Troubleshooting** → **Enable Developer Mode** from the macOS menu bar.

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/enable-developer-mode-menu.png"
        alt="Select Enable Developer Mode from the Claude Desktop Help menu."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    In the confirmation window, click **Enable**, then restart Claude Desktop.

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
        alt="Confirm developer mode in Claude Desktop."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Open third-party inference settings">
    After restarting, the macOS menu bar shows a **Developer** menu.

    Choose **Developer** → **Configure Third-Party Inference...**.

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
        alt="Choose Configure Third-Party Inference from the Developer menu."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

After you finish the first 3 steps, choose the path that matches your BetterToken Key group.

<Tabs>
  <Tab title="Claude Key group">
    <Steps>
      <Step title="Enter BetterToken API settings">
        In the settings window, select **Gateway**, then enter:

        | Field | Value |
        |-------|-------|
        | **Gateway base URL** | `{{anthropic-base-url}}` |
        | **Gateway API key** | Copy your API Key from **Token management** in the BetterToken console |
        | **Gateway auth scheme** | `x-api-key` |

        After you select **Gateway auth scheme**, Claude Desktop automatically fetches the available models for the **Claude Key group**. Click **Apply locally** after entering the settings.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-credentials.png"
            alt="Configure BetterToken Gateway settings in Claude Desktop and click Apply locally."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Confirm the app relaunch">
        After Claude writes the local configuration, it asks you to save and restart. Click **Save & Restart** so the new gateway configuration takes effect.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/relaunch-claude.png"
            alt="Claude Desktop asks to save and restart, with the Save & Restart button highlighted."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Sign in with Gateway">
        After restarting, wait about 3 seconds for the sign-in choice to appear.

        <Frame>

            alt="Claude Desktop shows the Continue with Gateway sign-in option."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Choose **Continue with Gateway**. After Claude opens, **Cowork 3P | Gateway** appears in the lower-left corner and you can start using it.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-ready.png"
            alt="Claude Desktop is ready after signing in with Gateway."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

## Troubleshooting

If the **Developer** menu does not appear in Claude Desktop, confirm that you clicked **Enable** and fully restarted the app.

If requests fail, check these items first:

1. **Gateway base URL** matches the setup path: use `{{anthropic-base-url}}` for a **Claude Key group**, or the local service address copied from CC Switch for a **GPT Key group**
2. **Gateway API key** comes from **Token management** in the BetterToken console
3. **Gateway auth scheme** matches the Key group: use `x-api-key` for a **Claude Key group** and `bearer` for a **GPT Key group**
4. You clicked **Apply locally**
5. If you use a **GPT Key group**, the main routing switch and the **Claude** route are enabled in CC Switch **Routing** settings
6. You clicked **Save & Restart** and selected **Continue with Gateway** after restart
