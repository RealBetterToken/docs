Claude Desktop supports two BetterToken setup paths. Choose the tab that matches your API Key group: use Claude Desktop Gateway for the **Claude Key group**, or CC Switch automatic setup for the **GPT Key group**.

<Tabs>
  <Tab title="Claude Key group">
    <Info>
      This path uses a Claude Key group API Key and connects directly to `{{anthropic-base-url}}`.
    </Info>

    <Steps>
      <Step title="Download Claude Desktop">
        Download the latest Claude Desktop app:

        [Download Claude Desktop](https://claude.ai/download)
      </Step>

      <Step title="Enable developer mode">
        In Claude Desktop, choose **Help** → **Troubleshooting** → **Enable Developer Mode** from the macOS menu bar.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/enable-developer-mode-menu.png"
            alt="Select Enable Developer Mode from the Claude Desktop Help menu."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Click **Enable** in the confirmation window, then restart Claude Desktop.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
            alt="Confirm developer mode in Claude Desktop."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Open third-party inference settings">
        After restarting, choose **Developer** → **Configure Third-Party Inference...** from the macOS menu bar.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
            alt="Choose Configure Third-Party Inference from the Developer menu."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Enter BetterToken API settings">
        Select **Gateway**, then enter:

        | Field | Value |
        | --- | --- |
        | **Gateway base URL** | `{{anthropic-base-url}}` |
        | **Gateway API key** | Copy a Claude Key group API Key from **Token management** in the BetterToken console |
        | **Gateway auth scheme** | `x-api-key` |

        Claude Desktop automatically fetches available Claude Key group models after you select **Gateway auth scheme**. Click **Apply locally**.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-credentials.png"
            alt="Configure BetterToken Gateway settings in Claude Desktop and click Apply locally."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Restart and open Claude Desktop through Gateway">
        Click **Save & Restart**. After the app reopens, select **Continue with Gateway**. **Gateway** in the lower-left corner confirms that the setup is ready.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-ready.png"
            alt="Claude Desktop is ready after opening through Gateway."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

  <Tab title="GPT Key group">
    <Info>
      This path uses a GPT Key group API Key. Use the latest Claude Desktop and CC Switch `v3.16.5` or later.
    </Info>

    <Steps>
      <Step title="Update Claude Desktop and CC Switch">
        - [Download Claude Desktop](https://claude.ai/download)
        - [Download CC Switch](https://github.com/farion1231/cc-switch/releases)
      </Step>

      <Step title="Switch to Claude Desktop and add a provider">
        Open CC Switch. Select the **Claude Desktop** icon in the top toolbar, then click **+** in the upper-right corner to add a provider.

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/cc-switch-claude-desktop-add-provider.png"
            alt="Switch to Claude Desktop in CC Switch and click the plus button in the upper-right corner to add a provider."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Fill in the basic fields">
        - **Provider Name**: `BetterToken-codex`
        - **API Key**: your BetterToken API Key from the GPT Key group
        - **API Endpoint**: `{{anthropic-base-url}}`

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-basic-fields.png"
            alt="CC Switch provider editor with BetterToken-codex, API Key, and API Endpoint fields."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Set the model mappings">
        Set **API Format** to **OpenAI Responses API (Requires routing)**, click **Fetch Models**, and keep **Declare 1M** enabled.

        | Model role | Requested model |
        | --- | --- |
        | Sonnet | `gpt-5.6-terra` |
        | Opus | `gpt-5.6-sol` |
        | Fable | `gpt-5.6-sol` |
        | Haiku | `gpt-5.6-luna` |

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-model-mapping.png"
            alt="CC Switch with OpenAI Responses API selected and mappings configured for Sonnet, Opus, Fable, and Haiku."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Use model IDs currently available in the GPT Key group of the <a href={"{{model-plaza-url}}"}>model plaza</a>.
      </Step>

      <Step title="Save, switch, and enable the proxy">
        Save the provider, set **BetterToken-codex** to **In use**, then turn on the proxy switch in the upper-left corner.

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-enable-proxy.png"
            alt="BetterToken-codex is active in CC Switch and the proxy switch in the upper-left corner is enabled."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Restart Claude Desktop and choose a model">
        Quit Claude Desktop completely, then open it again. **Gateway** in the lower-left corner confirms that the configuration is active. Choose a model from the menu in the message box and start working.

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/claude-desktop-gateway-ready.png"
            alt="Claude Desktop after restart, showing Gateway in the lower-left corner and the model selection menu."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Troubleshooting

### Claude Key group cannot connect

Confirm that **Gateway base URL** is `{{anthropic-base-url}}`, then use a Claude Key group API Key and `x-api-key`. Save the settings and restart Claude Desktop.

### Gateway does not appear for the GPT Key group

In CC Switch, confirm that **BetterToken-codex** is **In use** and the proxy switch is on. Quit Claude Desktop completely, then open it again.

### GPT Key group model list is empty or requests return `401`

Click **Fetch Models** and save the mapping in CC Switch. Confirm that the API Key is from the GPT Key group. Use model IDs currently available in the GPT Key group of the <a href={"{{model-plaza-url}}"}>model plaza</a>.
