Claude Desktop supports only Claude models. This is a Claude Desktop client limitation.

Copy an available Claude Model ID from the model plaza, save the configuration, and restart Claude Desktop.

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude |

## Prerequisites

- <a href={"{{register-url}}"}>Create and copy a BetterToken API Key</a>
- Copy the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Separate subscription from API billing

Gateway requests use your BetterToken API Key and BetterToken balance. They do not consume or extend a Claude subscription allowance. Treat the subscription and API as separate access and billing paths.

Before you use the setup for real work:

1. Create a dedicated BetterToken API Key for Claude Desktop.
2. Send one short, non-sensitive test message through **Gateway**.
3. Open the BetterToken Dashboard and confirm the model, status, input, output, cache Token, and charge.
4. Revoke the Key and create a new one if it appears in a screenshot, repository, or public log.

## Install

Install or update to the latest version from the [Claude Desktop website](https://claude.ai/download), then start Claude Desktop.

## Verify the connection

Click **Save & Restart**. Select **Continue with Gateway**, then send a short message. The setup is active when **Gateway** appears in the lower-left corner and the message returns normally.

## Switch models

Open the model selector and choose another Claude model returned by the Gateway. If the model is missing, reopen **Configure Third-Party Inference...**, click **Apply locally**, and restart Claude Desktop.

## Common errors

| Problem | Fix |
| --- | --- |
| Gateway cannot connect | Use exactly `{{anthropic-base-url}}` for **Gateway base URL**. Do not append `/v1`. |
| Request returns `401` | Copy the BetterToken API Key again and confirm that the auth scheme is `x-api-key`. |
| No Claude models appear | Copy an available Claude Model ID from the model plaza, save the configuration, and restart Claude Desktop. |
| Configuration is not applied | Quit Claude Desktop completely, reopen it, and choose **Continue with Gateway**. |
