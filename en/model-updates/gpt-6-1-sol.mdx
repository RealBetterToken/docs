Updated: September 30, 2026

**GPT-6.1 Sol** is an upgrade to GPT-6 Sol. OpenAI reports improvements in agentic coding, computer use, and professional work, with performance approaching GPT-6 Astra on selected evaluations. It suits demanding tasks where you want to compare capability, latency, and usage before choosing a model.

BetterToken now offers the Model ID `gpt-6.1-sol`. Check the <a href={"{{model-plaza-url}}"}>model plaza</a> for current availability and BetterToken pricing.

## Highlights

- **Coding and agents**: use it for multi-file changes, debugging, and longer software-engineering tasks.
- **Computer and professional work**: OpenAI reports gains on application workflows and complex documents over GPT-6 Sol.
- **Large context**: OpenAI lists a `1,050,000`-token context window and up to `128,000` output tokens. Your client and route may impose lower limits.
- **Adjustable reasoning**: `low`, `medium`, `high`, `xhigh`, and `max` are supported; `none` and `minimal` are not.

## Connect it

1. <a href={"{{register-url}}"}>Create a BetterToken API Key</a>.
2. For Codex CLI or another OpenAI-compatible client, set the Base URL to `{{openai-base-url}}` and the Model ID to `gpt-6.1-sol`.
3. Use the [Responses API](/en/api-reference/responses) when your workflow needs tool calling. OpenAI documents Chat Completions support for this model without tool calling.
4. Test a representative task before switching an existing workflow.

For Claude Code, use the Anthropic-protocol Base URL `{{anthropic-base-url}}` with the same Model ID. See the [Claude Code setup guide](/en/ai-tools/claude-code) or [Codex CLI setup guide](/en/ai-tools/codex) for client-specific steps.
