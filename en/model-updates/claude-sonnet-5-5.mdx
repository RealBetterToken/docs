Release date: September 28, 2026

Claude Sonnet 5.5 is the second model in Anthropic's Claude 5.5 family. Anthropic positions it as a faster option for well-scoped everyday work, including coding, bug fixes, and polished documents, slides, and spreadsheets. For more open-ended, complex work, consider Opus 5.5.

**Claude Sonnet 5.5** is now available on BetterToken. Set the Base URL to `{{anthropic-base-url}}`, and use `claude-sonnet-5-5` as the model ID. Check the <a href={"{{model-plaza-url}}"}>model plaza</a> for current availability and pricing.

## Highlights

- **Focused coding**: use it for well-defined implementation tasks and bug fixes.
- **Professional output**: Anthropic highlights its work on documents, slides, and spreadsheets.
- **Long context**: Anthropic lists a 1M-token context window and up to 128K output tokens.

## Before switching from Sonnet 5

If your client calls the Anthropic Messages API directly, review the [official migration guide](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide) before changing the model ID. Sonnet 5.5 changes some thinking and tool-choice behavior; test representative requests first.

## Connect it

1. <a href={"{{register-url}}"}>Create a BetterToken API Key</a>.
2. Use `{{anthropic-base-url}}` as the Base URL.
3. Set the model ID to `claude-sonnet-5-5`.
