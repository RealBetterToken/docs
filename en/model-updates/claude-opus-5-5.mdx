Release date: September 22, 2026

Anthropic introduces Claude Opus 5.5 as the first model in the Claude 5.5 family. Anthropic reports improvements over Opus 5 on long-running coding and professional work, with clearer communication across extended sessions.

**Claude Opus 5.5** is now available on BetterToken. Select the `Claude` provider, set the Base URL to `{{anthropic-base-url}}`, and use `claude-opus-5-5` as the model ID. Check the <a href={"{{model-plaza-url}}"}>model plaza</a> for current availability and pricing.

## Highlights

- **Long-running coding agents**: use it for complex repository changes, audits, and multi-step work.
- **Production-oriented work**: Anthropic recommends it for production-ready code, complex documents, and computer use.
- **Clearer collaboration**: Anthropic reports more direct, easier-to-follow explanations than Opus 5 in long sessions.

## Connect it

1. <a href={"{{register-url}}"}>Create a BetterToken API Key</a>.
2. Select the `Claude` provider and use `{{anthropic-base-url}}` as the Base URL.
3. Set the model ID to `claude-opus-5-5`.
4. Test a representative task before moving production traffic.

Use the [Claude Code setup guide](/en/ai-tools/claude-code) for client setup, or compare alternatives in the [model selection guide](/en/faq/model-calling/model-selection-guide).
