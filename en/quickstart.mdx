<Steps>
  <Step title="Create an account and claim your trial credit">
    Visit the [BetterToken registration page](https://www.bettertoken.ai/register) to create an account.

    You'll automatically receive a **¥7 trial credit** on signup.
  </Step>
  <Step title="Get your API Key">
    Log in to the dashboard and create your API Key.

    <Warning>
      Keep your API Key safe. Store it as an environment variable instead of hardcoding it into source code or config files.
    </Warning>

    Start with:

    ```bash
    export BETTERTOKEN_API_KEY="your-api-key-here"
    ```
  </Step>
  <Step title="Verify by access mode (optional)">
    BetterToken now has two distinct access modes. Do not reuse the same `base_url` across every tool.

    <Tabs>
      <Tab title="Claude Code / Anthropic">
        For Claude Code and integrations that use `ANTHROPIC_BASE_URL`:

        ```bash
        export ANTHROPIC_BASE_URL="https://www.bettertoken.ai"
        export ANTHROPIC_AUTH_TOKEN="$BETTERTOKEN_API_KEY"

        curl https://www.bettertoken.ai/messages           -H "x-api-key: $BETTERTOKEN_API_KEY"           -H "anthropic-version: 2023-06-01"           -H "content-type: application/json"           -d '{
            "model": "claude-sonnet-4-6",
            "max_tokens": 1024,
            "messages": [
              {"role": "user", "content": "Hello, introduce yourself."}
            ]
          }'
        ```
      </Tab>
      <Tab title="Codex / OpenAI-style">
        For Codex CLI and external tools. The `base_url` must be `https://www.bettertoken.ai/v1`:

        ```bash
        export OPENAI_BASE_URL="https://www.bettertoken.ai/v1"

        curl https://www.bettertoken.ai/v1/chat/completions           -H "Authorization: Bearer $BETTERTOKEN_API_KEY"           -H "content-type: application/json"           -d '{
            "model": "Codex group model ID copied from https://www.bettertoken.ai/pricing",
            "messages": [
              {"role": "user", "content": "Hello, introduce yourself."}
            ]
          }'
        ```

        <Note>
          External tools now use the Codex group. Do not keep hardcoded Claude model examples in these tools.
        </Note>
      </Tab>
    </Tabs>
  </Step>
</Steps>
