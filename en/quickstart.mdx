title: "Quickstart"
description: "Create a BetterToken account, add credit, generate an API Key, and open the step-by-step setup guide for Claude Code, Codex CLI, or another external tool."
---

<Steps>
  <Step title="Create an account">
    Visit the <a href={"{{register-url}}"}>BetterToken registration page</a> to create an account.

    After registration, top up your balance before creating a BetterToken API Key.
  </Step>
  <Step title="Add credit to your account">
    You can use **Online top-up** or **Redeem code**. After adding credit, return to the console and confirm that **Current balance** has updated before you create an API Key.

    <Tabs>
      <Tab title="Online top-up">
        After you sign in, open the **Console**. In the **Current balance** card, choose the currency you want to top up, then click its **Top up** button.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="The BetterToken Console Current balance card with Top up buttons for USD and RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Follow the payment prompts. After the payment succeeds, return to the console and confirm that **Current balance** has updated.
      </Tab>
      <Tab title="Redeem code">
        After you sign in, open the **Console** and click **Redeem code** in the lower-left corner of the **Current balance** card.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="The BetterToken Console Current balance card with an arrow pointing to the Redeem code button in the lower-left corner."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Enter your redemption code in the dialog, then click **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="The Redeem code dialog with the code input and Redeem button."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        After the code is redeemed, return to the console and confirm that **Current balance** has updated.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Open API Key management and create an API Key">
    Once you have available credit, click **Create API key** in the upper-right corner of the **Your API keys** section of the console.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="The BetterToken Console Your API keys section with an arrow pointing to the Create API key button in the upper-right corner."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    In **Create API Key**, enter an **API key name**. Expand **Advanced settings** if you need an expiration date or spending limit, then click **Create API Key**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="Create API Key dialog with the API key name field, Advanced settings, and Create API Key button."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Copy connection details or setup code">
    After creating the key, copy the **API Key** from **Connection details** in **Set up API key**. Select **OpenAI** or **Anthropic** to match your protocol, then copy the corresponding **Base URL**.

    Or select your tool or **API call** in the **Configuration guide** below, choose an endpoint and example model if needed, and copy the provided code. For more detailed steps, click **View tool documentation** or use a guide below. Click **Finish** when done.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="Set up API key dialog with copyable API Key and Base URL above a Configuration guide offering tools and code."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
