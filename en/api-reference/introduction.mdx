The public BetterToken API reference currently covers the **OpenAI-compatible Chat Completions API** only. Support for other protocols is not yet consistent across all channels, so the Responses API and Anthropic Messages API are not published as public interfaces.

## Supported providers

| Provider | Status |
| --- | --- |
| Claude | Not supported |
| GPT | Manual setup |
| Kimi | Manual setup |
| GLM | Manual setup |

## Connection details

| Field | Value |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Full request URL | `{{chat-completions-url}}` |
| Method | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

Copy a current Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> or the API Key **Setup** dialog in Console.

<Warning>
  When a tool asks for a **Base URL**, enter `{{openai-base-url}}`. Use `{{chat-completions-url}}` only when the tool explicitly asks for a full request URL.
</Warning>

## Quick test

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

A successful response contains `choices[0].message.content`.
