`POST /v1/responses`

Use this endpoint for Codex and applications that use the OpenAI Responses API.

<Note>
  Base URL: `{{openai-base-url}}`. Pass your API Key as `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Test in the Playground

In the Playground on the right, enter your API Key, replace `model` with a current GPT provider model ID when needed, and send the request. Confirm the model in the <a href={"{{model-plaza-url}}"}>model plaza</a> before testing.

<Warning>
  Only use your own test API Key. Do not put keys in code, screenshots, tickets, or Git repositories.
</Warning>
