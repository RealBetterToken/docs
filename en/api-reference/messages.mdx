`POST /v1/messages`

Use this endpoint for Claude Code, the Anthropic SDK, and applications that use the Anthropic Messages API.

<Note>
  For an SDK, use `{{anthropic-base-url}}` as the Base URL. A manual request and the Playground use the full `{{anthropic-base-url}}/v1/messages` path.
</Note>

## Test in the Playground

In the Playground on the right, enter your API Key in the `x-api-key` field, leave `anthropic-version` as `2023-06-01`, choose an available Claude Key group model, and send the request.

<Warning>
  Do not use `Authorization: Bearer ...` for this endpoint. It requires the `x-api-key` header.
</Warning>
