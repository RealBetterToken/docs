`POST /v1/chat/completions`

Use this endpoint for external tools and applications that require the OpenAI-compatible Chat Completions API.

<Note>
  Base URL: `{{openai-base-url}}`. Pass your API Key as `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Test in the Playground

In the Playground on the right, enter your API Key, choose an available GPT Key group model, fill in `messages`, and send the request. Confirm the model ID in the <a href={"{{model-plaza-url}}"}>model plaza</a> before testing.

<Warning>
  Do not append `/chat/completions` to the Base URL in an external tool when the tool constructs the endpoint path itself. The Playground already uses the full path.
</Warning>
