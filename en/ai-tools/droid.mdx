Droid is Factory AI's CLI coding assistant. Its BYOK support lets you add BetterToken in `~/.factory/settings.json` and select a GPT Key group model from the `/model` menu.

## Prerequisites

- BetterToken API Key (<a href={"{{register-url}}"}>register here</a>)
- A current **GPT Key group** model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>

## Setup

<Steps>
  <Step title="Set the BetterToken API Key">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    Replace `YOUR_API_KEY` with your BetterToken API Key. Droid supports `${BETTERTOKEN_API_KEY}` environment-variable expansion in its JSON configuration.
  </Step>

  <Step title="Edit the Droid config file">
    Config file path: `~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Codex",
          "model": "YOUR_GPT_MODEL_ID",
          "baseUrl": "{{openai-base-url}}",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "openai"
        }
      ]
    }
    ```

    Replace `YOUR_GPT_MODEL_ID` with a current **GPT Key group** model ID copied from the <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Step>

  <Step title="Start Droid and select the model">
    ```bash
    cd /path/to/your/project
    droid
    ```

    Enter `/model` in Droid and select **BetterToken Codex**. Factory watches the settings file for changes; if the model list does not refresh, exit and relaunch Droid.
  </Step>

  <Step title="Run a small test task">
    Start with a small task such as “Explain this project's directory structure.” Once Droid returns a result, continue with cross-file edits or longer agent tasks.
  </Step>
</Steps>

<Note>
  Set `provider` to `openai`. In Factory's BYOK configuration, this value selects the OpenAI Responses API. Use `{{openai-base-url}}` and an API Key from the **GPT Key group**.
</Note>

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| The custom model is missing from `/model` | Validate the JSON and confirm that `model`, `baseUrl`, `apiKey`, and `provider` are all present |
| `Invalid provider` | Use the exact lowercase value `"openai"`, not a UI display label |
| `401` or `403` | Copy the API Key again, confirm the Droid process can read `BETTERTOKEN_API_KEY`, and check your account balance |
| `404` or Model not found | Use `{{openai-base-url}}` and copy a current GPT model ID from the model plaza |
| The old model remains after editing | Open `/model` again; if it still does not refresh, fully exit and relaunch Droid |

## FAQ

### Why should I use the GPT Key group?

Droid's `provider: "openai"` uses the OpenAI Responses API. BetterToken's GPT Key group provides the matching OpenAI-compatible endpoint and model IDs.

### Do I need custom headers?

No extra headers are required for a standard BetterToken setup. Add tenant, routing, or audit headers only when another gateway explicitly requires them.

### Where can I check pricing and usage?

Use the live <a href={"{{model-plaza-url}}"}>model plaza</a> for current model pricing. Request usage and balance are available in the BetterToken Dashboard.
