Droid is Factory AI's CLI coding assistant. You can connect BetterToken as a custom Anthropic-compatible provider through BYOK configuration.

## Prerequisites

- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install Droid

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://app.factory.ai/cli | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://app.factory.ai/cli/windows | iex
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    <Warning>
      You must unset `ANTHROPIC_AUTH_TOKEN` before proceeding. If it remains set, it overrides the API key in the config file and causes authentication failures.
    </Warning>

    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="Set your BetterToken API Key">
    ```bash
    export BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```

    Replace `YOUR_API_KEY` with your BetterToken API Key. To persist it across sessions, add the line to `~/.zshrc` or `~/.bashrc`.
  </Step>

  <Step title="Edit the Droid config file">
    Config file path: `~/.factory/settings.json`

    <Note>
      The legacy `~/.factory/config.json` snake_case format is still supported for compatibility, but Factory currently recommends `settings.json`. When both files exist, `settings.json` takes priority.
    </Note>

    Add the following:

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Claude",
          "model": "claude-sonnet-4-6",
          "baseUrl": "https://www.bettertoken.com/v1",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "anthropic",
          "maxOutputTokens": 64000
        }
      ]
    }
    ```
  </Step>

  <Step title="Navigate to your project and start Droid">
    ```bash
    cd /path/to/your/project
    droid
    ```
  </Step>

  <Step title="Select the model">
    Type `/model` in Droid and select **BetterToken Claude**.
  </Step>
</Steps>

## Using multiple models

To configure multiple models, add additional entries to the `customModels` array:

```json
{
  "customModels": [
    {
      "displayName": "Claude Sonnet",
      "model": "claude-sonnet-4-6",
      "baseUrl": "https://www.bettertoken.com/v1",
      "apiKey": "${BETTERTOKEN_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 64000
    },
    {
      "displayName": "Claude Opus",
      "model": "claude-opus-4-6",
      "baseUrl": "https://www.bettertoken.com/v1",
      "apiKey": "${BETTERTOKEN_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 32000
    }
  ]
}
```
