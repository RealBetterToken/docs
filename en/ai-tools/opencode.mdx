Connecting OpenCode to BetterToken is done by editing the config file. BetterToken is compatible with the Anthropic SDK format.

## Prerequisites

- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install OpenCode

<Tabs>
  <Tab title="curl">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g opencode-ai
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="Edit the OpenCode config file">
    Config file location: `~/.config/opencode/opencode.json`

    Add the following (replace `YOUR_API_KEY`):

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "model": "bettertoken/claude-sonnet-4-6",
      "provider": {
        "bettertoken": {
          "npm": "@ai-sdk/anthropic",
          "options": {
            "baseURL": "https://www.BetterToken.ai/v1",
            "apiKey": "YOUR_API_KEY"
          },
          "models": {
            "claude-sonnet-4-6": {
              "name": "claude-sonnet-4-6"
            }
          }
        }
      }
    }
    ```
  </Step>

  <Step title="Start OpenCode">
    ```bash
    cd /path/to/your/project
    opencode
    ```
  </Step>

  <Step title="Confirm the model">
    The `model` field sets `bettertoken/claude-sonnet-4-6` as the default model. To switch models later, type `/models` inside OpenCode.
  </Step>
</Steps>

## Add more models

Add multiple models to the `models` field in the config:

```json
"models": {
  "claude-sonnet-4-6": { "name": "claude-sonnet-4-6" },
  "claude-opus-4-6":   { "name": "claude-opus-4-6" },
  "claude-haiku-4-6":  { "name": "claude-haiku-4-6" }
}
```

After adding a model, set the top-level `model` field to `bettertoken/<model-name>` to make it the default.
