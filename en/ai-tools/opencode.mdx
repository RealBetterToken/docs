You can connect BetterToken to OpenCode by editing the config file. The current setup should use an OpenAI-compatible provider and a model ID from the Codex group.

## Prerequisites

- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install OpenCode

<Tabs>
  <Tab title="curl">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g opencode-ai
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Edit the OpenCode config file">
    Config file path: `~/.config/opencode/opencode.json`

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "model": "bettertoken/YOUR_CODEX_MODEL_ID",
      "provider": {
        "bettertoken": {
          "npm": "@ai-sdk/openai",
          "options": {
            "baseURL": "https://www.bettertoken.ai/v1",
            "apiKey": "YOUR_API_KEY"
          },
          "models": {
            "YOUR_CODEX_MODEL_ID": {
              "name": "YOUR_CODEX_MODEL_ID"
            }
          }
        }
      }
    }
    ```

    Replace `YOUR_CODEX_MODEL_ID` with a current **Codex group** model ID copied from the [model plaza](https://www.bettertoken.ai/pricing).
  </Step>

  <Step title="Add the required headers if supported">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Restart OpenCode">
    After updating the config file, quit the current OpenCode session and start it again.
  </Step>

  <Step title="Start OpenCode">
    ```bash
    cd /path/to/your/project
    opencode
    ```
  </Step>
</Steps>

## Notes

- Use a **Codex group** model ID as the default model instead of fixed Claude model names
- If your OpenCode version does not expose custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`
