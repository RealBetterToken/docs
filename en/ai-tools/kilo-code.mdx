Kilo Code is a VS Code extension. To connect BetterToken, choose the OpenAI Compatible provider and use a model ID from the Codex group.

## Prerequisites

- VS Code installed
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Open Kilo Code settings">
    Open the Kilo Code settings UI.
  </Step>

  <Step title="Configure the API provider">
    Fill in:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `https://www.bettertoken.ai/v1`
    - **API Key** → your BetterToken API Key
    - **Model** → a **Codex group** model ID copied from the [model plaza](https://www.bettertoken.ai/pricing)
  </Step>

  <Step title="Add the required headers if supported">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Restart Kilo Code">
    After changing the config, restart VS Code or reload the Kilo Code extension so the new settings take effect.
  </Step>
</Steps>

<Note>
  If your Kilo Code version cannot set custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`.
</Note>
