To connect TRAE to BetterToken, prepare an API key, enter the Base URL shown below, and choose a current Model ID from the model plaza.

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |
| Full request URL | `{{chat-completions-url}}` |
| Model | A current Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Prerequisites

- The current version of the tool is installed
- A BetterToken API key: <a href={"{{register-url}}"}>register and get one</a>
- A Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>

### Additional requirements

## Install

Install or open TRAE, then continue with the manual setup below.

## Manual setup

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |
| Full request URL | `{{chat-completions-url}}` |
| Model | A current Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Setup

<Steps>
  <Step title="Open settings">
    In **IDE** mode, click the **Settings** icon in the upper-right corner to open the settings center.

    You can also open **SOLO** mode and click the **Settings** icon in the upper-right corner of the chat panel.
  </Step>

  <Step title="Open the model panel">
    In the left navigation, choose **Model** to open the **Model** panel.
  </Step>

  <Step title="Add a model">
    Click **+ Add model**.

    ![The TRAE model panel with the settings entry, model navigation item, and add model button highlighted.](/images/trae/add-model.png)
  </Step>

  <Step title="Fill in the model configuration">
    When the **Add model** window appears, fill in the fields as follows:

    | Field | Value |
    |-------|-------|
    | Provider | `OpenAI` |
    | Model | `Custom model` |
    | Model ID | a **model ID from a supported provider** copied from the <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | API key | your API Key copied from the BetterToken console |
    | Custom request URL | `{{chat-completions-url}}` |

    ![The TRAE add model window with OpenAI selected, a custom model selected, and fields for model ID, API key, and custom request URL.](/images/trae/model-config.png)
  </Step>

  <Step title="Save and start using it">
    Click **Confirm** to save the configuration, then choose the new model from a supported provider.
  </Step>
</Steps>

<Note>
  BetterToken only supports TRAE through **models from a supported provider**. Do not use fixed Claude model names, and do not set the custom request URL to `{{openai-base-url}}`.
</Note>

## Verify the connection

Send a short test prompt. If the tool returns a response without an authentication or Model ID error, the connection works. Fully restart the tool after changing its configuration.

## Switch models

Open the model selector or change the `Model` field in the configuration. Use the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>, then restart the current session.

## Common errors

| Error | What to check |
| --- | --- |
| `401` or `Unauthorized` | Check the BetterToken API key and remove leading or trailing spaces. |
| `404` | Check the Base URL and do not append a specific endpoint path. |
| `model not found` | Copy a current Model ID from the model plaza. |
| Changes do not apply | Save the configuration and fully restart the tool. |
