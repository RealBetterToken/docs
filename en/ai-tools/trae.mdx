When connecting BetterToken to TRAE, choose an OpenAI-style provider and use a model ID from the Codex group.

## Prerequisites

- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Open model configuration">
    Click **+ Add Model** and choose **Custom** or **OpenAI Compatible**.
  </Step>

  <Step title="Fill in the BetterToken config">

    | Field | Value |
    |-------|-------|
    | API URL | `https://www.bettertoken.ai/v1` |
    | API Key | your BetterToken API Key |
    | Model name | a **Codex group** model ID copied from the [model plaza](https://www.bettertoken.ai/pricing) |
  </Step>

  <Step title="Add the required headers if supported">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Save and start using it">
    Save the config, then choose the new Codex group model.
  </Step>

  <Step title="Restart TRAE">
    After saving the config, close and reopen TRAE before choosing the new model.
  </Step>
</Steps>

<Note>
  Do not keep using fixed Claude model names. If your TRAE version cannot set custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`.
</Note>
