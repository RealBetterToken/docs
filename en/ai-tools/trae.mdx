Connecting TRAE to BetterToken requires adding a custom model through the settings UI.

## Prerequisites

- TRAE installed ([download at trae.ai](https://www.trae.ai))
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Open model settings">
    Click the **Settings** icon in the top-right corner of the TRAE AI chat panel, then select the **Models** tab.
  </Step>

  <Step title="Add a custom model">
    Click **+ Add Model** and select **Custom** or **OpenAI Compatible** as the provider.
  </Step>

  <Step title="Enter BetterToken config">
    | Field | Value |
    |-------|-------|
    | API URL | `https://www.bettertoken.com/v1` |
    | API Key | Your BetterToken API Key |
    | Model name | `claude-sonnet-4-6` (or another supported model) |
  </Step>

  <Step title="Save and verify">
    Click **Add Model**. TRAE will validate your API Key automatically:

    - Success: the model appears in your model list
    - Failure: check the API URL and API Key
  </Step>

  <Step title="Select the model">
    Choose the newly added model from the chat panel dropdown to start using it.
  </Step>
</Steps>

## Supported models

| Series | Model | Description |
|--------|-------|-------------|
| Claude | `claude-sonnet-4-6` | Balanced — recommended |
| Claude | `claude-opus-4-6` | Most capable |
| Claude | `claude-haiku-4-6` | Fastest |
| GPT | `gpt-5.4` | OpenAI flagship |
| GPT | `gpt-5.4-mini` | Lightweight, faster |
