Cline is a VS Code AI coding extension. To connect BetterToken, choose the OpenAI Compatible provider and use a model ID from the Codex group.

## Prerequisites

- VS Code installed
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install Cline

Open VS Code, search for **Cline** in the extensions marketplace, and install it.

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Open the Cline config UI">
    Click **Use your own API key** in the Cline sidebar.
  </Step>

  <Step title="Configure the API provider">
    Fill in:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `https://www.bettertoken.ai/v1/`
    - **API Key** → your BetterToken API Key
    - **Model** → a **Codex group** model ID copied from the model plaza
  </Step>

  <Step title="Add the required headers if supported">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Save the config">
    Click **Done**.
  </Step>
</Steps>

<Note>
  If your Cline version cannot set custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`.
</Note>
