To connect Grok CLI to BetterToken, prepare an API key, enter the Base URL shown below, and choose a current Model ID from the model plaza.

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| Model | A current Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Prerequisites

- The current version of the tool is installed
- A BetterToken API key: <a href={"{{register-url}}"}>register and get one</a>
- A Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>

## Install

### Install Grok CLI

Run this on Windows, macOS, or Linux:

```bash
npm install -g @vibe-kit/grok-cli
```

If `grok` is not found after installation, close and reopen the terminal, then run `grok --help`. Check that the global `npm` package directory is on your `PATH`.

## Manual setup

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |

### What you need

- Node.js and `npm`
- A BetterToken API Key: <a href={"{{register-url}}"}>register here</a>
- A currently available **model ID from a supported provider** from the <a href={"{{model-plaza-url}}"}>model plaza</a>

### Configure the Base URL and API Key

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="Clear conflicting variables">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="Set BetterToken variables">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="Start Grok CLI with a model">
        ```bash
        grok --model YOUR_MODEL_ID
        ```

        Replace `YOUR_MODEL_ID` with a current **model ID from a supported provider** from the model plaza.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="Set variables for the current PowerShell window">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="Start Grok CLI with a model">
        ```powershell
        grok --model YOUR_MODEL_ID
        ```

        These variables apply only to the current PowerShell window. Set them again through your team's approved secret-storage approach when you open a new window.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Verify the connection

Send a short test prompt. If the tool returns a response without an authentication or Model ID error, the connection works. Fully restart the tool after changing its configuration.

After Grok CLI starts, send a short prompt. If it replies without an authentication or model ID error, the connection is ready. Whenever you change environment variables, end the current Grok CLI session and start a new one.

## Switch models

Open the model selector or change the `Model` field in the configuration. Use the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>, then restart the current session.

## Common errors

| Symptom | What to check |
| --- | --- |
| `grok: command not found` | Install again, open a new terminal, and check `grok --help`. |
| `401`, `Unauthorized`, or `Invalid API key` | Check `GROK_API_KEY`, make sure no extra whitespace was copied, and start Grok CLI in the same terminal where the variable is set. |
| `model not found` or unavailable model | Copy a current model ID from the **supported provider** in the model plaza. Do not use an ID from the Claude provider. |
| Requests still use a previous service | Check `GROK_BASE_URL`, do not append `/chat/completions`, then restart the terminal and Grok CLI. |
| Connection error | Confirm the Base URL is `{{openai-base-url}}` and that your network can reach `bettertoken.ai` over HTTPS. |

### Setup FAQ

**Which Base URL should I use in Grok CLI?**

Use `{{openai-base-url}}`. This is BetterToken's OpenAI-compatible Base URL.

**Which API Key and model should I select?**

Use a BetterToken API Key and a model from the same group.

**Do I need to change a system proxy or enable a VPN?**

No. Configure the Base URL and API Key in your terminal to connect to BetterToken.
