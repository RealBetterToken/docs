Zed supports custom LLM providers. When using BetterToken, choose the OpenAI route and paste a model ID from the Codex group.

## Prerequisites

- Zed installed (see [Zed docs](https://zed.dev/docs))
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Open the AI panel">
    Click the ✨ icon in the bottom-right corner of Zed.
  </Step>

  <Step title="Open settings">
    Open the menu in the panel and choose **Settings**.
  </Step>

  <Step title="Add a provider">
    In **LLM Provider**, click **+ Add Provider** and choose **OpenAI**.
  </Step>

  <Step title="Fill in the BetterToken config">

    | Field | Value |
    |-------|-------|
    | Provider Name | `BetterToken` |
    | API URL | `https://www.bettertoken.ai/v1` |
    | API Key | your BetterToken API Key |
    | Model Name | a **Codex group** model ID copied from the [model plaza](https://www.bettertoken.ai/pricing) |
  </Step>

  <Step title="Add the required headers if supported">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Save the provider">
    Click **Save Provider**, then select the model you configured.
  </Step>

  <Step title="Restart Zed">
    After saving the provider, restart Zed before selecting the configured model.
  </Step>
</Steps>

<Note>
  If your Zed version cannot set custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`.
</Note>
