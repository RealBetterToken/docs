Zed is a high-performance code editor that supports custom LLM providers. Through BetterToken, you can use Claude or GPT series models in Zed's AI panel.

## Prerequisites

- Zed installed (see [Zed documentation](https://zed.dev/docs))
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Open the AI panel">
    Click the ✨ icon in the bottom-right corner of Zed to open the agent panel.
  </Step>

  <Step title="Go to settings">
    Click the three-dot menu (⋯) in the top-right corner of the panel and select **Settings**.
  </Step>

  <Step title="Add an LLM provider">
    Find the **LLM Provider** section, click **+ Add Provider**, and select **OpenAI** from the dropdown.
  </Step>

  <Step title="Fill in the BetterToken config">
    Enter the following values:

    | Field | Value |
    |-------|-------|
    | Provider Name | `BetterToken` (or any name you prefer) |
    | API URL | `https://www.bettertoken.com/v1` |
    | API Key | your BetterToken API Key |
    | Model Name | `claude-sonnet-4-6` (or another supported model) |
  </Step>

  <Step title="Save the provider">
    Click **Save Provider**. The provider now appears in the LLM Provider list.

    Click **BetterToken**, re-enter your API Key, and press **Enter** to confirm.
  </Step>

  <Step title="Select a model and start">
    Return to the agent panel, click **Select a Model** in the bottom-right, and choose the model you just configured.
  </Step>
</Steps>

## Supported models

| Model | Description |
|-------|-------------|
| `claude-sonnet-4-6` | Balanced — recommended |
| `claude-opus-4-6` | Most capable — complex tasks |
| `claude-haiku-4-6` | Fastest — simple completions |
| `gpt-5.4` | OpenAI flagship |
| `gpt-5.4-mini` | Lightweight, faster |

To add more models, repeat the **Add an LLM provider** step with a different model name each time.
