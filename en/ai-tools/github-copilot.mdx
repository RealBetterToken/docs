To connect GitHub Copilot to BetterToken, prepare an API key, enter the Base URL shown below, and choose a current Model ID from the model plaza.

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |
| Full request URL | `{{chat-completions-url}}` |
| Model | A current Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Prerequisites

- The current version of the tool is installed
- A BetterToken API key: <a href={"{{register-url}}"}>register and get one</a>
- A Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>

### Additional requirements

- Latest VS Code installed
- GitHub Copilot / Copilot Chat installed and signed in
- The selected Model ID comes from the **supported provider**
- A model ID is available, for example `YOUR_MODEL_ID`

<Warning>
  Do not manually write your real API Key into `chatLanguageModels.json`. Paste it into the VS Code API Key prompt. VS Code will generate a local secret reference such as `${input:chat.lm.secret...}`.
</Warning>

## Install

Install or open GitHub Copilot, then continue with the manual setup below.

| Field | Value |
| --- | --- |
| API Key | BetterToken API key |

### Setup steps

<Steps>
  <Step title="Open model management">
    In the Copilot Chat input area, click the model selector, then choose **Manage Models...**.

    <Frame>
      <img
        src="/images/github-copilot/manage-models-entry.png"
        alt="Open Manage Models from the Copilot Chat model selector."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Add Custom Endpoint">
    In **Language Models**, click **Add Models**, then choose **Custom Endpoint**.

    <Frame>
      <img
        src="/images/github-copilot/add-custom-endpoint.png"
        alt="Click Add Models in Language Models and choose Custom Endpoint."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Enter the group name">
    In **Group Name**, enter:

    ```text
    BetterToken
    ```

    Then press **Enter**.

    <Frame>
      <img
        src="/images/github-copilot/group-name.png"
        alt="Enter BetterToken in the Group Name input."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Enter the API Key">
    VS Code will ask for the API Key. Paste your BetterToken API Key, then press **Enter**.

    This value will not be shown directly in the configuration file. VS Code stores it as a local secret and generates a reference like this:

    ```json
    "apiKey": "${input:chat.lm.secret.xxxxx}"
    ```

    <Warning>
      Do not replace `${input:chat.lm.secret...}` with your real API Key. Keep the secret reference generated by VS Code.
    </Warning>
  </Step>

  <Step title="Select the API type">
    In **Custom Endpoint: API Type**, select **Chat Completions**.

    <Frame>
      <img
        src="/images/github-copilot/select-chat-completions.png"
        alt="Select Chat Completions in Custom Endpoint API Type."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Edit the JSON configuration">
    VS Code opens `chatLanguageModels.json`. Confirm or update the configuration:

    <Frame>
      <img
        src="/images/github-copilot/chat-language-models-json.png"
        alt="Configure BetterToken model URL, toolCalling, vision, and token limits in chatLanguageModels.json."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    ```json
    [
      {
        "name": "BetterToken",
        "vendor": "customendpoint",
        "apiKey": "${input:chat.lm.secret.xxxxx}",
        "apiType": "chat-completions",
        "models": [
          {
            "id": "YOUR_MODEL_ID",
            "name": "YOUR_MODEL_ID",
            "url": "{{chat-completions-url}}",
            "toolCalling": true,
            "vision": true,
            "maxInputTokens": 1000000,
            "maxOutputTokens": 64000
          }
        ]
      }
    ]
    ```

    Check these fields:

    | Field | Recommended value |
    | --- | --- |
    | `name` | `BetterToken` |
    | `apiType` | `chat-completions` |
    | `id` | `YOUR_MODEL_ID` or another model ID from a supported provider from the <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | `name` | Same as the model ID |
    | `url` | `{{chat-completions-url}}` |
    | `toolCalling` | `true` |
    | `vision` | `true` |
    | `maxInputTokens` | `1000000` |
    | `maxOutputTokens` | `64000` |
  </Step>

  <Step title="Save and reload VS Code">
    Save `chatLanguageModels.json`, then run:

    ```text
    Developer: Reload Window
    ```

    After reload, return to the Copilot Chat model selector and choose `YOUR_MODEL_ID`.
  </Step>

  <Step title="Send a test message">
    Send a simple message in Copilot Chat:

    ```text
    Describe the model you are using in one sentence.
    ```

    If Copilot Chat replies normally, the BetterToken Custom Endpoint is configured successfully.
  </Step>
</Steps>

## Verify the connection

Send a short test prompt. If the tool returns a response without an authentication or Model ID error, the connection works. Fully restart the tool after changing its configuration.

## Switch models

Open the model selector or change the `Model` field in the configuration. Use the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>, then restart the current session.

## Common errors

### Why should I enter the API Key in the prompt?

VS Code stores the API Key in local secret storage and references it in JSON with `${input:chat.lm.secret...}`. This is safer than writing the real API Key into the JSON file.

### Why use Chat Completions?

The verified working configuration uses **Chat Completions**. The URL is:

```text
{{chat-completions-url}}
```

Do not use `/v1/responses`, and do not stop at `/v1`.

### Does this replace GitHub Copilot inline completion?

No. This Custom Endpoint is mainly used for Copilot Chat language model calls. GitHub Copilot inline completion is still provided by GitHub Copilot itself.

### What should I do if I see Invalid token?

Check these items in order:

1. The API Key was entered in the VS Code prompt
2. JSON keeps the `${input:chat.lm.secret...}` reference
3. The selected Model ID comes from the **supported provider**
4. `url` is `{{chat-completions-url}}`
5. `apiType` is `chat-completions`
6. The model ID is a model from a supported provider from the <a href={"{{model-plaza-url}}"}>model plaza</a>
