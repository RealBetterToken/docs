When connecting BetterToken to Cursor, use the OpenAI Base URL. External tools now use the Codex group, so copy the current model ID from the [model plaza](https://www.bettertoken.ai/pricing).

<Warning>
  Cursor's custom API key, custom model, and custom header capabilities depend on the current client version and plan. If an option is missing, follow what your Cursor version actually supports.
</Warning>

## Prerequisites

- Cursor installed ([download Cursor](https://www.cursor.com))
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Open the model settings page">
    In Cursor, open **Settings** and go to **Models**.
  </Step>

  <Step title="Configure the BetterToken API">
    In **API Keys**:

    1. Enable **Override OpenAI Base URL**
    2. Enter `https://www.bettertoken.ai/v1`
    3. Paste your BetterToken API Key into **OpenAI API Key**
    4. Complete the verification flow
  </Step>

  <Step title="Add a model">
    In **Models**, click **View All Models**, then **Add Custom Model**.

    Paste a current **Codex group** model ID copied from the [model plaza](https://www.bettertoken.ai/pricing).
  </Step>

  <Step title="Add the required headers if the UI supports it">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="Select the model and start using it">
    Choose the model you just added in the Cursor chat panel.
  </Step>
</Steps>

## Notes

- Do not keep using hardcoded Claude model names
- If your Cursor version cannot set custom headers, missing the required UA may trigger `403 block` or `403 Forbidden`
