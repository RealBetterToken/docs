MonkeyCode is an enterprise AI development platform covering the full lifecycle from requirements to design, development, and review. BetterToken provides stable Claude model access for MonkeyCode.

## Prerequisites

- MonkeyCode account ([sign up at MonkeyCode](https://monkeycode.ai))
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Setup

<Steps>
  <Step title="Log in to MonkeyCode">
    Visit [MonkeyCode](https://monkeycode.ai) and log in.
  </Step>

  <Step title="Go to the task page">
    After logging in, click **Get Started** to enter the MonkeyCode development platform.
  </Step>

  <Step title="Open system settings">
    Click the **Settings** button in the bottom-right corner of the page.
  </Step>

  <Step title="Bind an AI model">
    In the **AI Model** section, click **Bind**.
  </Step>

  <Step title="Fill in the BetterToken config">
    Enter the following values:

    | Field | Value |
    |-------|-------|
    | Model API URL | `https://www.BetterToken.ai/v1` |
    | API Key | your BetterToken API Key |
    | API format | `anthropic` |
    | Model name | `claude-sonnet-4-6` |

    Click **Save** to apply the configuration.
  </Step>

  <Step title="Start using">
    Return to the MonkeyCode main page, enter a prompt, and click **Run** to call Claude models through BetterToken.
  </Step>
</Steps>
