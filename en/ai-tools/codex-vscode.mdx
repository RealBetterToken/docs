The Codex VS Code Extension shares `~/.codex/config.toml` with Codex CLI/App. Use this page when you need to keep the official login, plugins, or Remote Control.

## Key settings

| Field | Value |
| --- | --- |
| API Key | `experimental_bearer_token = "YOUR_API_KEY"` |
| Base URL | `{{openai-base-url}}` |
| Model | `gpt-6-astra` |

## Prerequisites

- Install the latest Codex VS Code Extension
- Complete the official login in the Extension or Codex App
- <a href={"{{register-url}}"}>Create a BetterToken API Key</a>
- Copy a Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a> or key **Setup** dialog

## Install

Install the extension from the VS Code Marketplace, then restart VS Code.

## Manual setup

If you use a custom `CODEX_HOME`, edit `config.toml` in that directory. Otherwise use `~/.codex/config.toml` on macOS / Linux or `%USERPROFILE%\.codex\config.toml` on Windows.

Fully quit Codex, then back up the existing `config.toml` and `auth.json`. Update the existing provider settings instead of adding a duplicate provider table.

### Configure the Extension

Edit `~/.codex/config.toml`:

```toml
model_provider = "bettertoken"
model = "gpt-6-astra"

[model_providers.bettertoken]
name = "BetterToken"
base_url = "{{openai-base-url}}"
wire_api = "responses"
requires_openai_auth = true
experimental_bearer_token = "YOUR_API_KEY"
```

Save the file, run **Developer: Reload Window** in VS Code, and reopen the Codex panel.

## Verify the connection

Create a new Extension session and send a short task. A response from `gpt-6-astra` while plugins and Remote Control remain available confirms the setup.

## Switch models

Change `model` and, optionally, `review_model`, then run **Developer: Reload Window**. Use a Model ID from the Setup dialog or model plaza.

## Common errors

| Error | Fix |
| --- | --- |
| Extension asks you to sign in again | Restore the official login and keep `requires_openai_auth = true`. |
| `401` or `403` | Copy `experimental_bearer_token` again; do not overwrite `auth.json`. |
| Duplicate table | Remove the other `[model_providers.bettertoken]` table and keep one authentication mode. |
| Model not found | Replace `gpt-6-astra` with a current complete Model ID. |
| Configuration not applied | Save the file and run **Developer: Reload Window**. |
