Roo Code is a VS Code AI coding extension. Connecting to BetterToken requires selecting the OpenAI Compatible provider in the settings UI.

## Prerequisites

- VS Code installed
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install Roo Code

Search for **Roo Code** in the VS Code Extensions marketplace, click Install, and restart VS Code.

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="Open Roo Code settings">
    Click the **Settings** button in the Roo Code sidebar.
  </Step>

  <Step title="Configure the API provider">
    Fill in the following:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `https://www.bettertoken.com/v1`
    - **API Key** → your BetterToken API Key
    - **Model** → `claude-sonnet-4-6` (or another supported model)

    <Note>
      Roo Code's OpenAI Compatible provider requires the endpoint to support OpenAI-style tool calling. If chat works but tool use fails, first confirm that the selected model and endpoint support tool calling.
    </Note>
  </Step>

  <Step title="Save">
    Click **Save** then **Done**.
  </Step>
</Steps>

## Supported models

| Model | Description |
|-------|-------------|
| `claude-sonnet-4-6` | Balanced — recommended |
| `claude-opus-4-6` | Most capable — complex tasks |
| `claude-haiku-4-6` | Fastest — simple completions |
| `gpt-5.4` | OpenAI flagship |
| `gpt-5.4-mini` | Lightweight, faster |
