Yingdao AI Power is a no-code product for building AI applications. It aggregates existing AI models and provides a simple toolset for creating AI apps.

When connecting BetterToken to Yingdao AI Power, add an `OpenAI-API-compatible` model and use a model ID from the GPT Key group.

## Prerequisites

- BetterToken API Key (<a href={"{{register-url}}"}>register here</a>)
- A **GPT Key group** model ID copied from the <a href={"{{model-plaza-url}}"}>model plaza</a>

## Setup

<Steps>
  <Step title="Open model management">
    Go to **Enterprise management**, then open **Model management**. Find **OpenAI-API-compatible** and click **Add model**.

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-management.png"
        alt="The Yingdao AI Power model management page with OpenAI-API-compatible and the add model entry highlighted."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Fill in the model configuration">
    In the **Authorization management: OpenAI-API-compatible** window, fill in the fields as follows:

    | Field | Value |
    |-------|-------|
    | Model type | `LLM` |
    | Model name | a **GPT Key group** model ID copied from the <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | Request URL | `{{chat-completions-url}}` |
    | API key | Select only a key that corresponds to the `Codex*` group |
    | Max output token limit | `128000` |
    | Vision understanding | Select **Yes** |
    | Function calling | Select **Yes** |

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-config.png"
        alt="The Yingdao AI Power OpenAI-API-compatible authorization window with model name, request URL, API key, max output token limit, vision understanding, and function calling settings."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Enable vision understanding">
    Set **Vision understanding** to **Yes** so the model can be selected in the **Workflow - multimodal large model** component.

    <Frame>
      <img
        src="/images/yingdao-ai-power/workflow-multimodal-model.png"
        alt="The Yingdao AI Power workflow page where the multimodal large model component can select OpenAI-API-compatible and the added model."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Enable function calling">
    Set **Function calling** to **Yes** so the model can be selected in **Agent - Tools**.

    <Frame>
      <img
        src="/images/yingdao-ai-power/agent-tool-model.png"
        alt="The Yingdao AI Power agent tools page where model settings can select OpenAI-API-compatible and the added model."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Add more models">
    If you need multiple models, repeat the steps above. Use the matching GPT Key group model ID for each model.
  </Step>
</Steps>

<Note>
  In Yingdao AI Power, the **Request URL** must be the full chat completions endpoint `{{chat-completions-url}}`. Do not use only `{{openai-base-url}}`.
</Note>
