When connecting BetterToken to OpenClaw, choose the **Codex provider** instead of the Anthropic provider. The endpoint is `https://www.bettertoken.ai/v1`, and the protocol is `OpenAI Responses`.

<Warning>
  If OpenClaw does not send the expected Codex `User-Agent`, you may see `403 block` or `403 Forbidden`.
</Warning>

## Prerequisites

- OpenClaw installed
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install OpenClaw

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://openclaw.ai/install.sh | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://openclaw.ai/install.ps1 | iex
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Run onboarding">
    ```bash
    openclaw onboard --install-daemon
    ```
  </Step>

  <Step title="Add the BetterToken credential">
    ```bash
    openclaw models auth add
    ```
  </Step>

  <Step title="Choose the Codex provider and fill in the fields">
    In the wizard, choose **Codex** and enter:

    - **API endpoint**: `https://www.bettertoken.ai/v1`
    - **API protocol**: `OpenAI Responses`
    - **Token group**: choose a `Codex_*` group
    - **Model**: a currently available model ID copied from the [model plaza](https://www.bettertoken.ai/pricing)
  </Step>

  <Step title="Add the required headers">
    If your OpenClaw version exposes a custom headers editor, enter:

    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```

    Replace `sk-xxx` with your BetterToken API Key.
  </Step>

  <Step title="Set the default model and verify">
    Run `openclaw models list` to confirm the provider id, then set the default model and check the status:

    ```bash
    openclaw models list
    openclaw models set <provider>/<Codex model ID copied from https://www.bettertoken.ai/pricing>
    openclaw gateway restart
    openclaw models status
    ```

    After changing the config, run `openclaw gateway restart` before checking the status.
  </Step>
</Steps>

## Usage notes

- OpenClaw should now use the **Codex provider** instead of legacy `anthropic/<Claude-model>` style configuration
- Copy the model name directly from the **Codex group** in the [model plaza](https://www.bettertoken.ai/pricing)
- Missing the required UA may trigger `403 block` or `403 Forbidden`
