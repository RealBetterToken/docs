Connect OpenClaw to BetterToken with the official onboarding and model commands. OpenClaw's config structure changes quickly, so avoid copying older raw JSON config.

## Prerequisites

- OpenClaw installed
- BetterToken API Key ([register here](https://www.bettertoken.ai/register))

## Install OpenClaw

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://openclaw.ai/install.sh | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://openclaw.ai/install.ps1 | iex
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Clear conflicting environment variables">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="Run onboarding">
    ```bash
    openclaw onboard --install-daemon
    ```

    Follow the wizard to finish Gateway and base model setup.
  </Step>

  <Step title="Add BetterToken credentials">
    Run the model auth wizard:

    ```bash
    openclaw models auth add
    ```

    Choose **Anthropic**, **Anthropic Compatible**, or a custom API Key provider, then enter:

    - **Base URL**: `https://www.BetterToken.ai/v1`
    - **API Key**: your BetterToken API Key
    - **Model**: `claude-sonnet-4-6`
  </Step>

  <Step title="Set the default model">
    ```bash
    openclaw models set anthropic/claude-sonnet-4-6
    ```

    <Note>
      If your OpenClaw version shows a provider id other than `anthropic`, run `openclaw models list` first, then use the listed `<provider>/claude-sonnet-4-6`.
    </Note>
  </Step>

  <Step title="Verify">
    Restart the Gateway and check model status:

    ```bash
    openclaw gateway restart
    openclaw models status
    ```

    To run a live probe, use `openclaw models status --probe-provider anthropic`. A probe may consume model credits.
  </Step>
</Steps>

## Switch models

BetterToken supports the full Claude model lineup. Use `openclaw models set <provider>/<model>` to switch:

| Model | Use case |
|-------|----------|
| `claude-sonnet-4-6` | Balanced — recommended |
| `claude-opus-4-6` | Most capable — complex tasks |
| `claude-haiku-4-6` | Fastest — lightweight tasks |

After changing the model, run `openclaw gateway restart` to apply.
