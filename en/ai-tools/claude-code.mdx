Claude models can connect directly through terminal variables or a settings file. Kimi and GLM use the same Base URL with explicit model mappings. GPT requires [advanced setup](#advanced-setup).

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Managed by Claude Code |

## Prerequisites

- Install the latest [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- Install Node.js
- <a href={"{{register-url}}"}>Create and copy a BetterToken API Key</a>

## Install

```bash
npm install -g @anthropic-ai/claude-code
```

## Command-line setup

The BetterToken Automatic setup script writes the Claude Code provider configuration. It requires Node.js and prompts for the API Key when one is not passed as an argument.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

After it finishes, inspect `~/.claude/settings.json` (or `%USERPROFILE%\.claude\settings.json` on Windows) and fully restart Claude Code. Use the manual setup below when you want to control each field yourself.

## Manual setup

### Configure the Claude provider

Claude Code CLI reads:

| System | File |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

Add:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000"
  }
}
```

The Claude provider needs only these four variables. Do not add `ANTHROPIC_MODEL` or `ANTHROPIC_DEFAULT_*_MODEL`.

### Configure a Kimi or GLM provider

Kimi and GLM require model mappings in the same `settings.json`. Replace each `YOUR_MODEL_ID` with a Model ID from the Setup dialog or model plaza:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

The three mappings can use one Model ID or different models from the same provider. Do not put a GPT Model ID here; use the advanced setup at the end of this page.

### Configure the Claude Code VS Code extension

The extension uses VS Code `settings.json`. Add a separate `claudeCode.environmentVariables` configuration:

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    }
  ]
}
```

Run **Developer: Reload Window**, or fully restart VS Code.

## Verify the connection

Start Claude Code in your project:

```bash
claude
```

Send a short message. A normal response without `401`, connection, or model errors confirms the setup. Fully restart Claude Code after changing the file.

## Switch models

- Claude provider: let Claude Code manage model selection. Do not add `ANTHROPIC_MODEL` or `ANTHROPIC_DEFAULT_*_MODEL`.
- Kimi or GLM provider: change `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, and `ANTHROPIC_DEFAULT_OPUS_MODEL`, then fully restart Claude Code.
- GPT provider: follow the [advanced setup](#advanced-setup) below to switch models.

## Common errors

| Error | Fix |
| --- | --- |
| `401` or authentication failure | Check `ANTHROPIC_AUTH_TOKEN` and remove spaces around the API Key. |
| `ConnectionRefused` | Use exactly `{{anthropic-base-url}}`; do not append `/v1`. |
| Model not found | Do not set a model manually for Claude. For Kimi or GLM, check that all three `ANTHROPIC_DEFAULT_*_MODEL` values use current Model IDs. |
| Configuration not applied | Check the file path, clear conflicting environment variables, and fully restart Claude Code. |

## Advanced setup

### Supported providers

| Provider | Status |
| --- | --- |
| Claude | Command-line + manual setup |
| GPT | Advanced setup |
| Kimi | Manual setup |
| GLM | Manual setup |

<Note>Statuses apply to the BetterToken setup documented on this page.</Note>

<Accordion title="What the setup methods mean">
  - **Advanced setup**: install CC Switch and use a local proxy, protocol conversion, or model mapping.
  - **Manual setup**: enter the API Key, Base URL, and Model.
  - **Command-line + manual setup**: use a generated command or follow the complete manual steps.
</Accordion>
{/* tool-provider-support:end */}

To use GPT in Claude Code, configure it through [CC Switch with BetterToken](/en/ai-tools/cc-switch#claude-code). Enter the API Key, Base URL, and Model Mapping in the Claude Code tab, then enable the proxy.

## Technical details

<Accordion title="Protocol and endpoint">
  Claude Code uses Anthropic Messages. Set `ANTHROPIC_BASE_URL` to `{{anthropic-base-url}}`; the client appends `/v1/messages`, so do not add `/v1` to the Base URL.
</Accordion>
