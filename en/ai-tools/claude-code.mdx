Connect Claude Code with your BetterToken API Key, Base URL `{{anthropic-base-url}}`, and the Model ID you want to use. Copy the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Key settings

| Field | Value |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## Prerequisites

- Install the latest [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- Install Node.js
- <a href={"{{register-url}}"}>Create and copy a BetterToken API Key</a>

## Install

```bash
npm install -g @anthropic-ai/claude-code
```

## Command-line setup

The BetterToken Automatic setup script writes the Claude Code provider configuration. It requires Node.js and prompts for the API Key when one is not passed as an argument.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

After it finishes, inspect `~/.claude/settings.json` (or `%USERPROFILE%\.claude\settings.json` on Windows) and fully restart Claude Code. Use the manual setup below when you want to control each field yourself.

## Manual setup

| System | File |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

Copy the exact Model ID from the <a href={"{{model-plaza-url}}"}>model plaza</a>.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

Replace `YOUR_MODEL_ID` with the Model ID you copied. Set `ANTHROPIC_MODEL` for the main model and the three `ANTHROPIC_DEFAULT_*_MODEL` variables for the Haiku, Sonnet, and Opus aliases. You can map them to the same model or choose a different model for each role.

### VS Code extension

The extension uses VS Code `settings.json`. Add a separate `claudeCode.environmentVariables` configuration:

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_SONNET_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_OPUS_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

## Verify the connection

Start Claude Code in your project:

```bash
claude
```

Send a short message. A normal response without `401`, connection, or model errors confirms the setup. Fully restart Claude Code after changing the file.

## Switch models

Update the Model ID in your configuration and restart Claude Code. To switch during a session, use `/model YOUR_MODEL_ID`.

## Common errors

| Error | Fix |
| --- | --- |
| `401` or authentication failure | Check `ANTHROPIC_AUTH_TOKEN` and remove spaces around the API Key. |
| `ConnectionRefused` | Use exactly `{{anthropic-base-url}}`; do not append `/v1`. |
| Model ID | Check the exact Model ID in the model plaza and enter it in the client model settings. |
| Configuration not applied | Check the file path, clear conflicting environment variables, and fully restart Claude Code. |

## Technical details

<Accordion title="Protocol and endpoint">
  Claude Code uses Anthropic Messages. Set `ANTHROPIC_BASE_URL` to `{{anthropic-base-url}}`; the client appends `/v1/messages`, so do not add `/v1` to the Base URL.
</Accordion>
