## What is BetterToken?

BetterToken is an AI model API gateway for developers and teams worldwide. It provides access to Claude and GPT/Codex models through standard API endpoints and supports AI coding tools such as Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode, and CC Switch.

The docs distinguish between two access modes:

- **Claude Code / `ANTHROPIC_BASE_URL`**: use `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / external tools**: use `{{openai-base-url}}`

**Key benefits:**

- **Multi-source supply**: multiple suppliers connected simultaneously
- **Dynamic routing**: Automatically bypasses slow or unstable upstreams
- **Flagship focus**: Reliability work is concentrated on Claude Code and the Codex ecosystem
- **Two clear tracks**: Configure the endpoint by protocol instead of reusing one `base_url` everywhere

## Two access modes

| Scenario | Base URL | Notes |
|----------|----------|-------|
| Claude Code | `{{anthropic-base-url}}` | Anthropic protocol, no `/v1` suffix |
| Codex / external tools | `{{openai-base-url}}` | OpenAI-style protocol; external tools use the GPT provider |

## What problem BetterToken solves

AI coding tools expect different protocols, authentication fields, and model settings. BetterToken provides two standard API endpoints for Claude and GPT/Codex workflows. You can connect Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode, and CC Switch by replacing the Base URL and API Key without changing the rest of your workflow.

## Developer endpoints

BetterToken is a multi-model API gateway with two standard entry points:

| Protocol | Base URL | Used for |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| OpenAI-compatible | https://bettertoken.ai/v1 | Codex and other external tools |

After registration, create a BetterToken API Key, choose a compatible provider model, and connect it in Cursor, Cline, OpenClaw, OpenCode, CC Switch, or another tool by replacing the Base URL. Requests, token usage, and balance are visible in the Dashboard.

## Teams and cost control

Teams can use one API layer for Claude and GPT/Codex workflows. BetterToken records actual usage and routes requests across multiple providers to reduce the impact of an isolated upstream outage. Teams can track usage and balance per API Key in the Dashboard and allocate budget by workflow, such as Claude Code or Codex.
