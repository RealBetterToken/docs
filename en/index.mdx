## What is BetterToken?

BetterToken is an AI API relay service for developers. By aggregating 12+ suppliers, BetterToken sits between you and Anthropic/OpenAI, providing a highly available routing layer so that your Claude Code, Codex, and other AI coding tools stay stable even during peak hours.

**Key benefits:**

- **Multi-source supply**: 12+ suppliers connected simultaneously — a single provider's outage won't affect you
- **Dynamic routing**: Finds the optimal path in real time, automatically bypassing timeouts and rate limits
- **Flagship focus**: Only Claude and Codex — no sprawl, maximum reliability
- **Drop-in compatible**: Fully compatible with OpenAI SDK and Anthropic SDK — just change one line of config
