Date de sortie : 22 septembre 2026

OpenAI complète la famille GPT-6 avec Sol et Luna aux côtés d'Astra. Sol vise le code complexe et les workflows agentifs ; Luna, les tâches ciblées et répétables à grand volume. Selon OpenAI, les deux progressent par rapport à GPT-5.6 en code, exactitude factuelle et communication.

BetterToken prend désormais en charge **GPT-6 Sol** et **GPT-6 Luna**. Sélectionnez `GPT`, utilisez Base URL `{{openai-base-url}}` et choisissez `gpt-6-sol` ou `gpt-6-luna`. Le nom officiel est **Sol**, et non `Sora`.

Vérifiez la disponibilité et le prix actuels de BetterToken dans le <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Quel modèle choisir

- **`gpt-6-sol`** : pour le code complexe et les workflows agentifs.
- **`gpt-6-luna`** : pour les tâches ciblées, répétables et à grand volume.

## Points forts

- **Grand contexte** : OpenAI documente une fenêtre de `1,050,000` tokens et jusqu'à `128,000` tokens de sortie pour les deux modèles.
- **Raisonnement réglable** : les deux acceptent `none`, `low`, `medium`, `high`, `xhigh` et `max`.
- **Travail quotidien** : OpenAI indique des progrès par rapport à GPT-5.6 en code, exactitude factuelle et clarté technique.

## Connexion

1. <a href={"{{register-url}}"}>Créez une BetterToken API Key</a>.
2. Sélectionnez `GPT` et Base URL `{{openai-base-url}}`.
3. Utilisez `gpt-6-sol` pour les agents exigeants ou `gpt-6-luna` pour les tâches répétables à grand volume.
