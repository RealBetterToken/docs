Date de publication : 9 juin 2026

BetterToken a mis à jour l’entrée du modèle `Claude Fable 5`. Consultez la <a href={"{{model-plaza-url}}"}>model plaza</a> pour connaître le Model ID actuellement disponible, puis configurez-le à l’aide du guide de configuration Claude Code ou external tool correspondant à votre client.

Anthropic a présenté officiellement Claude Fable 5 le 9 juin 2026 et le décrit comme une nouvelle génération d’intelligence pour les problèmes les plus difficiles de travail de connaissance et de programmation. Anthropic indique que Fable 5 est un modèle de classe Mythos conçu pour un travail plus long, plus complexe et plus asynchrone, en particulier les agents de longue durée, l’ingénierie logicielle complexe, le travail de connaissance et les flux fortement axés sur la vision.

## Points forts

- **Travail d’agent de longue durée plus solide** : Anthropic indique que Fable 5 peut fonctionner plus longtemps dans Claude Code ou un harnais d’agent, en planifiant par étapes, en exécutant et en vérifiant son propre travail
- **Meilleure adéquation avec l’ingénierie logicielle complexe** : le modèle est positionné pour les grandes migrations, implémentations complexes, sessions autonomes de plusieurs jours et tâches d’ingénierie nécessitant moins de supervision directe
- **Travail de connaissance et vision améliorés** : Fable 5 cible l’analyse complexe, le raisonnement sur documents, les graphiques, tableaux, PDF et autres supports visuels
- **Autocontrôle plus actif** : Anthropic souligne que Fable 5 valide plus minutieusement son propre travail, ce qui aide lorsque vous déléguez une tâche et révisez le résultat plus tard
- **Nouvelles protections** : pour les domaines sensibles tels que la cybersécurité, la biologie et la chimie, Anthropic applique des protections et un comportement de repli ; certaines requêtes peuvent être traitées par Claude Opus 4.8 à la place

## Guide de configuration

Si vous utilisez Claude Code, commencez par le [guide de configuration de Claude Code](/fr/ai-tools/claude-code). Les différents fournisseurs utilisent des protocoles et schémas de configuration de modèles différents :

- Fournisseur `Claude` : utilisez `{{anthropic-base-url}}`
- Fournisseur `GPT` ou external tools : suivez le guide de l’outil concerné avec `{{openai-base-url}}`

Utilisez le nom de modèle actuellement affiché dans la <a href={"{{model-plaza-url}}"}>model plaza</a>. Ne codez pas en dur un nom de modèle qui n’y est pas affiché.

<Note>
  Claude Fable 5 convient le mieux aux tâches à forte valeur, à contexte long et de longue durée. Pour des questions-réponses simples ou un travail par lots à faible coût, choisissez un modèle plus léger selon les fournisseurs et prix affichés dans la model plaza.
</Note>
