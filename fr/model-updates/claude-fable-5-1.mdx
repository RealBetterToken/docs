BetterToken prend désormais en charge **Claude Fable 5.1** avec le Model ID exact `claude-fable-5-1`. Consultez sa disponibilité et son prix actuels dans la <a href={"{{model-plaza-url}}"}>model plaza</a>, puis utilisez cet ID dans un client compatible.

## Informations disponibles

- **Modèle** : Claude Fable 5.1
- **Model ID** : `claude-fable-5-1`
- **Disponibilité et prix** : consultez les informations en temps réel dans la model plaza

## Configurer Claude Fable 5.1

1. Créez une BetterToken API Key ou ouvrez la fenêtre **Setup** d’une Key existante.
2. Copiez `claude-fable-5-1` depuis la model plaza.
3. Ouvrez le guide de votre client et saisissez la BetterToken API Key, la Base URL requise et le Model ID exact.
4. Redémarrez le client si la liste des modèles ne se met pas à jour automatiquement.
5. Envoyez une courte requête de test et vérifiez-la dans le Dashboard.

## Corriger Model not found

Vérifiez que le Model ID est exactement `claude-fable-5-1`, que la BetterToken API Key permet d’utiliser le modèle et que la Base URL correspond au guide du client. Redémarrez le client et testez à nouveau.
