Mise à jour : 5 septembre 2026

BetterToken prend désormais en charge **GPT-6 Astra** avec le Model ID exact `gpt-6-astra`. OpenAI présente Astra comme son modèle le plus performant pour les travaux complexes de bout en bout, notamment le raisonnement avancé, l’ingénierie logicielle, la recherche, l’utilisation d’un ordinateur et la création de documents. Consultez la disponibilité et le prix BetterToken dans la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Points forts

- **Travail de bout en bout** : conçu pour des tâches complexes en plusieurs étapes couvrant le code, les navigateurs, les outils et les applications professionnelles
- **Ingénierie logicielle** : OpenAI positionne Astra comme son modèle le plus puissant à ce jour pour le développement et les agents de programmation
- **Grand contexte** : OpenAI documente une fenêtre de `1 050 000` tokens et jusqu’à `128 000` tokens en sortie
- **Raisonnement réglable** : l’API OpenAI accepte les niveaux `low`, `medium`, `high`, `xhigh` et `max`
- **Outils Responses API** : OpenAI documente les appels de fonctions, les sorties structurées, la recherche web et dans les fichiers, l’interpréteur de code, computer use et MCP

## Conseils de configuration

- Utilisez Astra pour le développement difficile, la recherche, computer use ou les tâches agentiques longues. Pour les tâches courantes, comparez-le aux modèles plus rapides ou économiques de la model plaza.
- Testez une tâche représentative avant de basculer le trafic de production, puis comparez la qualité, la latence et la consommation de tokens.
- Sélectionnez le **provider GPT**, utilisez la Base URL `{{openai-base-url}}` et le Model ID exact `gpt-6-astra`.
- L’accès peut être déployé progressivement. La model plaza fait foi pour la disponibilité et le prix BetterToken.

## Démarrage rapide

1. Créez une BetterToken API Key ou ouvrez la fenêtre **Setup** d’une clé existante.
2. Vérifiez dans la model plaza que `gpt-6-astra` est disponible.
3. Définissez `{{openai-base-url}}` comme Base URL et `gpt-6-astra` comme modèle.
4. Redémarrez le client si la liste des modèles ne se met pas à jour automatiquement.
5. Lancez une petite tâche de test et vérifiez la requête dans le Dashboard.

## Questions fréquentes

### Quel est le Model ID de GPT-6 Astra ?

Utilisez `gpt-6-astra`. Ne le remplacez pas par le nom affiché `GPT-6 Astra` ni par l’ID d’une autre plateforme.

### BetterToken fournit-il tout le contexte de 1 050 000 tokens ?

OpenAI indique une fenêtre de contexte de `1 050 000` tokens pour GPT-6 Astra. La limite utilisable peut aussi dépendre du client, des paramètres de la requête et du routage BetterToken actuel. Consultez la model plaza et la documentation du client avant d’envoyer de très grands prompts.

### Comment corriger Model not found ?

Vérifiez que le Model ID est exactement `gpt-6-astra`, que la BetterToken API Key autorise l’accès, que le **provider GPT** est sélectionné et que la Base URL est `{{openai-base-url}}`. Redémarrez le client et testez à nouveau.

### Où trouver le prix actuel ?

Consultez la <a href={"{{model-plaza-url}}"}>model plaza</a>. Le prix BetterToken peut différer du tarif direct de l’API OpenAI et évoluer dans le temps.
