Date de publication : 24 avril 2026

BetterToken a mis à jour l’entrée du modèle `GPT-5.5`. Consultez la <a href={"{{model-plaza-url}}"}>model plaza</a> pour connaître le Model ID actuellement disponible du **fournisseur GPT**, puis configurez-le dans Codex, OpenCode, OpenClaw, Cursor, Cline, Zed ou d’autres external tools à l’aide du guide de configuration correspondant.

OpenAI a présenté officiellement GPT-5.5 le 23 avril 2026 et l’a décrit comme un modèle destiné au travail complexe dans le monde réel. OpenAI met en avant une programmation agentique, une utilisation de l’ordinateur, un travail de connaissance et des flux de recherche scientifique plus solides. Il est conçu pour comprendre l’intention plus tôt, planifier plus efficacement, utiliser des outils, vérifier les résultats et poursuivre les tâches en plusieurs étapes.

## Points forts

- **Performances d’agent de programmation plus solides** : OpenAI indique des améliorations par rapport à GPT-5.4 sur des benchmarks de programmation et d’agent tels que Terminal-Bench 2.0 et SWE-Bench Pro
- **Tâches longues plus fiables** : il convient mieux aux flux qui combinent implémentation, débogage, validation et documentation
- **Utilisation d’outils plus active** : OpenAI souligne une utilisation d’outils, une vérification de sortie et une progression dans les tâches ambiguës plus solides
- **Efficacité supérieure** : OpenAI indique que GPT-5.5 conserve une latence au niveau de GPT-5.4 tout en utilisant moins de tokens pour les tâches Codex

## Guide de configuration

Pour Codex et les external tools, copiez le Model ID actuel du **fournisseur GPT** depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>. Ne codez pas en dur un nom de modèle qui n’y est pas affiché.

Si votre version de Codex ne peut pas sélectionner `gpt-5.5` en mode API, consultez [Pourquoi Codex ne peut-il pas utiliser GPT-5.5 en mode API ?](/fr/faq/codex/gpt-5.5-api-mode).
