Date de publication : 10 juillet 2026

BetterToken prend désormais en charge la famille de modèles GPT-5.6. Consultez la <a href={"{{model-plaza-url}}"}>model plaza</a> pour connaître les Model ID actuellement disponibles du **fournisseur GPT** et les tarifs en direct, puis utilisez-les dans Codex, OpenCode, OpenClaw, Cursor, Cline, Zed ou d’autres external tools via le protocole compatible OpenAI.

Les nouveaux Model ID sont :

| Model ID | Idéal pour |
| --- | --- |
| `gpt-5.6-sol` | Raisonnement complexe, grandes bases de code, tâches d’agent en plusieurs étapes et flux de programmation de longue durée |
| `gpt-5.6-terra` | Programmation quotidienne, développement interactif, tâches d’agent courantes et équilibre capacité/coût |
| `gpt-5.6-luna` | Tâches légères où la vitesse et le coût comptent, telles que l’assistance par lots, les questions-réponses rapides, les réécritures simples et les petits appels d’outils |

## Points forts

- **Trois niveaux de modèles** : OpenAI positionne GPT-5.6 Sol, Terra et Luna pour le travail à raisonnement élevé, les tâches quotidiennes équilibrées et les tâches légères à fort volume
- **Meilleure adéquation avec les agents de programmation** : OpenAI met en avant des améliorations dans les tâches d’agent de programmation, de flux terminal et de coordination d’outils
- **Prêts pour les external tools** : le centre d’aide OpenAI confirme que Sol, Terra et Luna sont disponibles via l’API OpenAI ; dans BetterToken, utilisez le **fournisseur GPT** et `{{openai-base-url}}`
- **Choisir selon la charge de travail** : commencez avec `gpt-5.6-sol` pour le travail complexe, `gpt-5.6-terra` pour le développement quotidien et `gpt-5.6-luna` pour les requêtes plus légères ou sensibles au coût

## Guide de configuration

Pour Codex ou d’autres outils compatibles OpenAI, suivez le guide de configuration correspondant :

- **Base URL** : `{{openai-base-url}}`
- **fournisseur** : choisissez le **fournisseur GPT**
- **Nom du modèle** : copiez le Model ID actuel depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>

<Note>
  Ne codez pas en dur un nom de modèle qui n’est pas affiché dans la model plaza. La disponibilité, les tarifs et l’état du routage des modèles suivent la <a href={"{{model-plaza-url}}"}>model plaza</a> en direct.
</Note>

## Démarrage rapide

1. Créez une BetterToken API Key.
2. Définissez `{{openai-base-url}}` comme Base URL dans votre outil.
3. Copiez un Model ID actuel `gpt-5.6-sol`, `gpt-5.6-terra` ou `gpt-5.6-luna` depuis la model plaza.
4. Exécutez d’abord une petite tâche de programmation, puis vérifiez l’utilisation de la requête dans le Dashboard.

Utilisez l’un de ces guides de configuration :

- [Configuration de Codex CLI et Codex App](/fr/ai-tools/codex)
- [Configuration OpenCode](/fr/ai-tools/opencode)
- [Configuration d’une API compatible OpenAI dans Cline](/fr/faq/cline/openai-compatible-api)

## Comment choisir

Si vous ne savez pas par où commencer, choisissez selon la complexité de la tâche :

- Utilisez `gpt-5.6-sol` pour comprendre de grandes bases de code, modifier plusieurs fichiers, réparer des tests, effectuer de longues boucles de débogage et réaliser des tâches d’agent exigeant un raisonnement plus fort
- Utilisez `gpt-5.6-terra` pour la programmation quotidienne, l’explication de code, les refactorisations courantes, la documentation et la plupart des tâches de développement interactif
- Utilisez `gpt-5.6-luna` pour les questions-réponses légères, l’assistance par lots, le traitement de texte simple, les appels d’outils à faible latence et les requêtes à fort volume sensibles au coût

## FAQ

### Quel modèle dois-je essayer en premier ?

Commencez avec `gpt-5.6-terra` pour la plupart des tâches de programmation quotidiennes. Passez à `gpt-5.6-sol` lorsque la tâche nécessite un raisonnement plus profond, ou utilisez `gpt-5.6-luna` lorsque la latence compte davantage.

### Où trouver le prix actuel ?

Consultez la <a href={"{{model-plaza-url}}"}>model plaza</a> en direct pour connaître les tarifs et la disponibilité actuels. Cette page ne code pas en dur les prix parce qu’ils peuvent changer.

### Que faire si l’outil signale Model not found ?

Copiez de nouveau le Model ID depuis la model plaza, vérifiez que le modèle sélectionné est disponible auprès du fournisseur GPT et contrôlez `{{openai-base-url}}`. Consultez le [guide de sélection de modèle](/fr/faq/model-calling/model-selection-guide) pour d’autres vérifications.
