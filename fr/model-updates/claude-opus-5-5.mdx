Date de sortie : 22 septembre 2026

Claude Opus 5.5 est le premier modèle de la famille Claude 5.5 d'Anthropic. Selon Anthropic, il progresse par rapport à Opus 5 sur le code de longue durée et le travail professionnel, avec des réponses plus claires lors des sessions prolongées.

**Claude Opus 5.5** est disponible sur BetterToken. Sélectionnez le provider `Claude`, utilisez `{{anthropic-base-url}}` comme Base URL et indiquez `claude-opus-5-5` comme Model ID. Consultez le <a href={"{{model-plaza-url}}"}>model plaza</a> pour la disponibilité et le prix actuels.

## Points forts

- Modifications complexes de dépôts, audits et tâches agentives longues.
- Code prêt pour la production, documents complexes et computer use.
- Communication plus claire pendant les longues sessions, selon Anthropic, par rapport à Opus 5.

1. <a href={"{{register-url}}"}>Créez une BetterToken API Key</a>.
2. Sélectionnez `Claude` et `{{anthropic-base-url}}`.
3. Utilisez `claude-opus-5-5` comme Model ID.
