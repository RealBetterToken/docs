Cette page explique la configuration directe de Claude Desktop pour le **fournisseur Claude** de BetterToken uniquement. Saisissez votre BetterToken API Key, `{{anthropic-base-url}}` et `x-api-key`, puis redémarrez Claude Desktop.

## Paramètres clés

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Modèle du fournisseur Claude |

## Prérequis

- <a href={"{{register-url}}"}>Créez et copiez une BetterToken API Key</a>
- Vérifiez que l’API Key peut utiliser les modèles du fournisseur Claude

## Séparer l’abonnement de la facturation API

Les requêtes Gateway utilisent votre BetterToken API Key et votre solde BetterToken. Elles ne consomment ni ne prolongent le quota d’un abonnement Claude. Considérez l’abonnement et l’API comme deux voies distinctes d’accès et de facturation.

Avant d’utiliser cette configuration pour un travail réel :

1. Créez une BetterToken API Key dédiée à Claude Desktop.
2. Envoyez un court message de test sans données sensibles via **Gateway**.
3. Ouvrez le Dashboard BetterToken et vérifiez le modèle, le statut, les Token input, output et cache, ainsi que le débit.
4. Révoquez la Key et créez-en une nouvelle si elle apparaît dans une capture, un dépôt ou un journal public.

## Installation

Installez ou mettez à jour la dernière version depuis le [site de Claude Desktop](https://claude.ai/download), puis démarrez Claude Desktop.

## Vérifier la connexion

Cliquez sur **Save & Restart**. Sélectionnez **Continue with Gateway**, puis envoyez un court message. La configuration est active lorsque **Gateway** apparaît dans le coin inférieur gauche et que le message reçoit une réponse normale.

## Changer de modèle

Ouvrez le sélecteur de modèles et choisissez un autre modèle Claude renvoyé par la passerelle. Si le modèle manque, rouvrez **Configure Third-Party Inference...**, cliquez sur **Apply locally**, puis redémarrez Claude Desktop.

## Erreurs courantes

| Problème | Solution |
| --- | --- |
| La passerelle ne peut pas se connecter | Utilisez exactement `{{anthropic-base-url}}` pour **Gateway base URL**. N’ajoutez pas `/v1`. |
| La requête renvoie `401` | Copiez à nouveau la BetterToken API Key et vérifiez que le schéma d’authentification est `x-api-key`. |
| Aucun modèle Claude n’apparaît | Vérifiez que l’API Key peut utiliser les modèles du fournisseur Claude, puis rouvrez la fenêtre des paramètres. |
| La configuration ne s’applique pas | Quittez complètement Claude Desktop, ouvrez-le à nouveau et choisissez **Continue with Gateway**. |

## Configuration avancée

Pour utiliser GPT, Kimi, GLM ou un autre fournisseur autre que Claude dans Claude Desktop, suivez l’[onglet Claude Desktop dans CC Switch](/fr/ai-tools/cc-switch#claude-desktop). CC Switch gère le format API, le mappage des modèles, le proxy et le redémarrage.
