## Réponse rapide

Lorsque vous changez de Sonnet, Opus ou d’un autre modèle dans Claude Code, privilégiez le point d’entrée `/model` pris en charge ou le parcours officiel de configuration de modèle.

Les alias de modèles, Model ID complets et mappages de fournisseurs ne sont pas toujours identiques. Un nom marketing affiché dans une interface Web n’est pas toujours le model ID reconnu par l’API.

Si vous utilisez une passerelle tierce, utilisez le model ID affiché par cette passerelle ou sa documentation de fournisseur.

## Cas où cela est important

- Vous souhaitez passer d’un modèle moins cher à un modèle plus puissant
- Vous voyez les alias Sonnet / Opus / Haiku mais ne savez pas quoi saisir
- Vous utilisez une Base URL tierce ou une passerelle de modèles
- Vous souhaitez contrôler le coût en tokens Claude Code
- Vous voyez model not found ou la sélection de modèle ne prend pas effet

## Trois niveaux de noms de modèles

| Niveau | Signification |
| --- | --- |
| Nom d’affichage | Nom compréhensible affiché dans une interface |
| Alias | Nom court ou raccourci dans un outil |
| Model ID | Identifiant réellement reconnu par l’API |

Pour réussir une Request, l’essentiel est que le fournisseur actuel reconnaisse le Model ID.

## Pratique recommandée

1. Confirmez quels modèles le fournisseur actuel prend en charge.
2. Utilisez Claude Code `/model` ou le parcours officiel de configuration de modèle.
3. Si vous utilisez une passerelle tierce, copiez le model ID disponible depuis son model plaza.
4. Considérez ensemble le choix de modèle et le coût.
5. Ne devinez pas les noms de modèles à la main.

## À propos de BetterToken

Si vous connectez Claude Code via BetterToken, copiez le model ID actuel depuis le <a href={"{{model-plaza-url}}"}>model plaza</a>. Les modèles des fournisseurs Claude et GPT appartiennent à des parcours de protocole différents ; ne les mélangez pas.

Le choix de modèle affecte la qualité, la vitesse et le coût. Les enregistrements d’utilisation vous aident à comparer la consommation réelle entre modèles.
