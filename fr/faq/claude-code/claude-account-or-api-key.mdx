## Réponse rapide

Claude Code peut s’authentifier de plusieurs façons. Les utilisateurs individuels se connectent souvent avec un compte Claude.ai. Les utilisateurs d’API ou les équipes peuvent utiliser Claude Console, des fournisseurs cloud ou un parcours de fournisseur tiers pris en charge.

Un compte Claude.ai et une API Key ne sont pas la même chose. La connexion Claude.ai concerne l’expérience produit officielle. Une API Key est utilisée pour les Request d’API de modèle et est généralement associée à une Base URL et une configuration de fournisseur.

Si vous utilisez une passerelle API tierce, les champs importants sont API Key et Base URL. Vous devez aussi confirmer si l’outil attend un protocole Anthropic compatible ou OpenAI compatible.

## Cas où cela est important

- Vous voyez une invite de connexion pendant la configuration de Claude Code
- Vous ne savez pas si Claude Pro ou Max vous fournit une API Key
- Vous souhaitez router Claude Code via une passerelle API personnalisée
- Vous devez choisir entre la connexion officielle et un fournisseur tiers
- Une équipe a besoin d’un modèle d’authentification cohérent

## Concepts clés

| Concept | Signification |
| --- | --- |
| Compte Claude.ai | Connexion produit officielle pour les expériences Claude |
| API Claude Console | Accès API côté développeur et gestion de l’utilisation |
| API Key | Identifiant utilisé pour les Request d’API de modèle |
| Base URL | Endpoint vers lequel les Request sont envoyées |
| Fournisseur | Source d’authentification et de Request de modèle utilisée par Claude Code |
| Passerelle API tierce | Couche de compatibilité, routage, facturation ou observabilité entre l’outil et les fournisseurs de modèles |

## Processus de décision recommandé

1. Si vous souhaitez uniquement l’expérience Claude Code officielle et utilisez un plan Claude.ai, commencez par la connexion officielle.
2. Si vous avez besoin de facturation API ou d’un accès API géré par l’équipe, examinez Claude Console ou votre fournisseur d’équipe.
3. Si vous avez besoin d’une passerelle API personnalisée, confirmez que Claude Code prend en charge ce parcours de fournisseur, puis configurez API Key et Base URL.
4. Si vous avez besoin des fonctions officielles de l’application avec un fournisseur d’inférence tiers, décidez si vous devez préserver l’état de connexion officielle.

Dans cette documentation, la Base URL Claude Code Anthropic compatible est `{{anthropic-base-url}}`.

## Erreurs courantes

- Traiter un abonnement Claude.ai comme une API Key.
- Coller un identifiant ChatGPT Plus ou d’un autre abonnement dans Claude Code.
- Copier uniquement l’API Key et oublier de modifier la Base URL.
- Placer une Base URL OpenAI compatible dans la configuration Anthropic compatible de Claude Code.
- Partager `auth.json`, des refresh tokens ou des identifiants de session comme s’il s’agissait d’API Key.

## À propos de BetterToken

Si vous choisissez le parcours API Key + Base URL, BetterToken peut fournir l’endpoint compatible et un Dashboard pour les API Key, le solde et l’historique d’utilisation.

BetterToken ne remplace pas la connexion Claude.ai et ne transforme pas un abonnement Claude.ai en API Key. Il gère uniquement la couche API de modèle.
