## Réponse rapide

Lorsque vous configurez une API tierce dans Claude Code, vérifiez d’abord que l’endpoint est compatible avec Anthropic. Dans cette documentation, Claude Code utilise `{{anthropic-base-url}}`. N’ajoutez pas `/v1`.

L’API Key authentifie la requête. La Base URL indique à Claude Code où envoyer les requêtes au modèle. Les deux doivent appartenir au même fournisseur et au même protocole.

Pour un accès général à Claude API, consultez la [page Claude API de BetterToken](https://bettertoken.ai/ru/claude-api/). Cette landing page répond au besoin d’accès à l’API ; cette FAQ traite uniquement de l’API Key et de la Base URL dans Claude Code.

Connectez Claude Code avec votre BetterToken API Key, la Base URL `{{anthropic-base-url}}` et le Model ID souhaité. Copiez le Model ID exact depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Quand cette configuration est importante

- Vous souhaitez utiliser une gateway API personnalisée avec Claude Code
- Vous avez une API Key, mais vous ne savez pas quelle Base URL utiliser
- Claude Code signale une erreur d’authentification ou d’endpoint
- Vous hésitez entre `{{anthropic-base-url}}` et `{{openai-base-url}}`


## Concepts principaux

| Champ | Signification |
| --- | --- |
| API Key | Identifiant utilisé pour les requêtes à l’API du modèle |
| Base URL | Adresse de l’API vers laquelle les requêtes sont envoyées |
| API compatible avec Anthropic | Endpoint qui suit les conventions de requête Anthropic ou Claude |
| API compatible avec OpenAI | Endpoint qui suit les conventions OpenAI, souvent utilisé par Codex, Cursor et Cline |
| Model ID | Nom du modèle ou valeur d’association demandée par l’outil |

## Configuration recommandée

Connectez Claude Code avec votre BetterToken API Key, la Base URL `{{anthropic-base-url}}` et le Model ID souhaité.

Copiez le Model ID exact depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

Remplacez `YOUR_MODEL_ID` par l’ID copié. `ANTHROPIC_MODEL` définit le modèle principal et les trois variables `ANTHROPIC_DEFAULT_*_MODEL` définissent les alias Haiku, Sonnet et Opus. Vous pouvez utiliser un même modèle ou un modèle différent pour chaque rôle.

Modifiez le Model ID dans la configuration et redémarrez Claude Code. Pour changer en cours de session, utilisez `/model YOUR_MODEL_ID`.

## Erreurs fréquentes

- Ajouter `/v1` à la Base URL de Claude Code.
- Modifier l’API Key tout en conservant l’endpoint par défaut comme destination des requêtes.

- Saisir un endpoint compatible avec OpenAI dans les champs compatibles avec Anthropic de Claude Code.
- Définir dans un profil shell d’anciennes variables d’environnement qui remplacent la nouvelle configuration.

## À propos de BetterToken

BetterToken fournit deux types d’endpoint : `{{anthropic-base-url}}`, compatible avec Anthropic pour Claude Code, et `{{openai-base-url}}`, compatible avec OpenAI pour Codex et les outils externes.

Vous pouvez gérer les API Key, le solde et l’historique d’utilisation dans un seul Dashboard, mais Claude Code nécessite toujours un format de requête compatible avec Anthropic.
