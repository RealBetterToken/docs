## Réponse rapide

Claude Code est un agent de code destiné au travail sur une base de code. Son fonctionnement repose sur la lecture du projet, l’édition de fichiers, l’exécution de commandes et la vérification des résultats.

Claude Desktop est l’application de bureau Claude. C’est un point d’entrée graphique pour les conversations, extensions de bureau, serveurs MCP locaux et certains workflows de bureau, comme les fonctionnalités Cowork ou Code.

Ils peuvent partager certaines capacités, mais ne constituent pas la même surface produit. Leur configuration, modèle d’autorisations, comportement MCP et configuration Gateway peuvent différer.

## Cas où cela est important

- Vous choisissez entre Claude Code CLI et Claude Desktop
- Vous souhaitez que Claude modifie un dépôt
- Vous configurez Claude Desktop Gateway ou MCP
- Vous utilisez Claude Code via un terminal, un IDE, une application de bureau ou le Web
- Vous déboguez un écart entre le comportement desktop et CLI

## Concepts clés

| Domaine | Claude Code | Claude Desktop |
| --- | --- | --- |
| Rôle principal | Agent de code | Application de bureau |
| Entrée habituelle | Terminal, IDE, bureau, Web | Application de bureau macOS ou Windows |
| Travail sur base de code | Conçu pour les lectures de fichiers, modifications et commandes | Dépend des fonctions Desktop, extensions, Cowork ou mode Code |
| Point de configuration | Répertoire de projet, autorisations, `CLAUDE.md`, fournisseur API | Connexion, extensions de bureau, MCP, Gateway |
| Usage adapté | Modifications de code, tests, révision, automatisation | Conversations, connecteurs de bureau, workflows visuels |

## Choix recommandé

Utilisez Claude Code lorsque vous voulez qu’un agent travaille directement dans une base de code. Son workflow est construit autour du répertoire de projet, des modifications de fichiers, des commandes et de la vérification.

Utilisez Claude Desktop si vous souhaitez une application Claude graphique, des extensions de bureau, des serveurs MCP locaux ou des workflows propres à Desktop. Si vous utilisez Code ou Cowork dans Desktop, vérifiez si vous utilisez le comportement Claude Code inclus ou une configuration Claude Code CLI distincte.

Pour les API tierces, suivez le protocole pris en charge par la surface actuelle. Dans cette documentation, Claude Code utilise `{{anthropic-base-url}}`. Ne placez pas directement la valeur OpenAI compatible `{{openai-base-url}}` dans un champ Gateway Anthropic compatible.

## Erreurs courantes

- Supposer que Claude Desktop installe ou remplace automatiquement Claude Code CLI.
- Copier les paramètres MCP de Desktop dans Claude Code, ou l’inverse.
- Traiter un abonnement Claude.ai comme une API Key.
- Utiliser une Base URL OpenAI compatible dans un champ Claude Desktop Gateway qui attend du trafic Anthropic compatible.
- Supposer que les fonctionnalités Desktop remplacent les autorisations, hooks ou politiques de commandes Claude Code.

## À propos de BetterToken

BetterToken fait partie de la couche API de modèle. Il peut fournir des endpoints compatibles aux endroits où l’outil prend en charge une API Key et une Base URL personnalisées.

Il ne fusionne pas Claude Code et Claude Desktop en une seule configuration. Vous devez toujours suivre le protocole, Gateway, MCP et le modèle d’autorisations de la surface que vous utilisez.
