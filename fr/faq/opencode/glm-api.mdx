Vous pouvez connecter GLM a OpenCode via BetterToken comme provider compatible OpenAI. Saisissez votre BetterToken API Key, le Base URL `https://bettertoken.ai/v1` et le Model ID GLM exact affiche dans Setup.

## Parametres essentiels

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai/v1` |
| Modele | `YOUR_GLM_MODEL_ID` |

## Prerequis

- Installez [OpenCode](https://opencode.ai/).
- <a href={"{{register-url}}"}>Creez une BetterToken API Key</a>.
- Dans **Setup**, choisissez OpenCode et le provider **GLM**, puis copiez le Model ID complet disponible.

## Configurer avec `/connect`

Lancez OpenCode puis executez :

```text
/connect
```

Choisissez **Other**, entrez `bettertoken` comme identifiant du provider, puis collez votre BetterToken API Key. Selectionnez `bettertoken/YOUR_GLM_MODEL_ID`, puis redemarrez OpenCode.

## Configuration manuelle

Ouvrez `~/.config/opencode/opencode.json` ou un fichier `opencode.json` dans votre projet :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_GLM_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "https://bettertoken.ai/v1",
        "apiKey": "YOUR_API_KEY"
      },
      "models": {
        "YOUR_GLM_MODEL_ID": {
          "name": "YOUR_GLM_MODEL_ID"
        }
      }
    }
  }
}
```

Remplacez `YOUR_API_KEY` et `YOUR_GLM_MODEL_ID` par les valeurs de Setup. N'utilisez pas un Model ID repris dans un ancien article : choisissez un ID actuellement disponible pour votre BetterToken API Key.

## Verifier la connexion

Selectionnez `bettertoken/YOUR_GLM_MODEL_ID` dans OpenCode et envoyez une courte demande. Une reponse sans erreur API confirme la configuration. Redemarrez completement OpenCode apres une modification du JSON.

## Erreurs frequentes

| Erreur | Verification |
| --- | --- |
| `401` | Verifiez la BetterToken API Key enregistree avec `/connect` ou dans `apiKey`. |
| `404` | Conservez `https://bettertoken.ai/v1` dans `baseURL`, sans `/chat/completions`. |
| Modele introuvable | Copiez a nouveau le Model ID GLM complet depuis Setup et utilisez-le aux deux emplacements du JSON. |
| La configuration ne s'applique pas | Verifiez le fichier `opencode.json` de projet, qui peut remplacer le fichier global. |
