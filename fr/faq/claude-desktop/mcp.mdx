## Réponse courte

Claude Desktop peut se connecter à des outils locaux et à des sources de données par l’intermédiaire de serveurs MCP. Déclarez le serveur dans la configuration MCP de Claude Desktop, redémarrez ou actualisez la connexion, puis vérifiez son état dans l’application.

MCP n’est pas une API de modèle. Il permet à Claude Desktop d’accéder à des outils ou à du contexte. Les requêtes de modèle dépendent toujours du modèle et du mode d’accès au compte actuellement utilisés par Claude Desktop.

## Quand en avez-vous besoin ?

- Vous voulez que Claude Desktop accède à des fichiers locaux, des bases de données ou des outils de développement
- Vous voyez une configuration de serveur MCP sans savoir où l’ajouter
- Vous comparez MCP local et MCP distant
- Vous pensez que MCP peut remplacer une API Key ou une Base URL
- Vous devez vérifier si MCP est connecté

## MCP local et MCP distant

| Type | Signification |
| --- | --- |
| MCP local | Exécute un serveur sur votre machine, souvent pour des outils, fichiers ou environnements de développement locaux |
| MCP distant | Se connecte à un service distant, souvent pour des outils cloud ou des services d’équipe |
| Extension de bureau | Format davantage orienté bureau pour l’installation et la distribution |

## Configuration recommandée

1. Vérifiez que vous connectez un serveur MCP, et non un fournisseur de modèles.
2. Ajoutez la configuration MCP locale ou distante conformément à la documentation Claude Desktop.
3. Redémarrez ou actualisez Claude Desktop.
4. Vérifiez l’état de la connexion MCP dans Claude Desktop.
5. Accordez au serveur MCP uniquement les autorisations et variables d’environnement dont il a besoin.

## Erreurs fréquentes

- Traiter un serveur MCP comme une Base URL.
- Placer une API Key de modèle dans la configuration MCP.
- Supposer que MCP modifie le coût des modèles.
- Oublier qu’un serveur MCP peut accéder à des données locales sensibles.
- Vérifier uniquement l’interface Claude Desktop alors que le serveur local ne fonctionne pas.

## À propos de BetterToken

BetterToken gère l’accès aux API de modèles, et non les serveurs MCP. Le MCP de Claude Desktop connecte des outils. Les couches API de type BetterToken gèrent les requêtes de modèles, le solde et l’utilisation.

Si vous avez besoin à la fois d’accès aux outils et de routage unifié des modèles, configurez MCP et l’accès API séparément.
