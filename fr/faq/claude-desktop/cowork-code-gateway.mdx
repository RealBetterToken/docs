Après avoir configuré la passerelle BetterToken dans Claude Desktop, les symptômes suivants ne signifient généralement pas que l’API Key est invalide :

- Le mode Cowork ne fonctionne pas
- Le mode Code affiche `Claude Code process exited with code 1`
- La même API Key fonctionne dans Claude Code CLI depuis un terminal

Ces problèmes proviennent généralement de deux causes distinctes : le schéma d’authentification de la passerelle de bureau ne correspond pas au fournisseur, ou la version intégrée de Claude Code dans Claude Desktop n’a pas fini de se mettre à jour.

Si vous n’avez pas encore configuré la passerelle, commencez par [Utiliser l’API BetterToken dans Claude Desktop](/fr/faq/claude-desktop-bettertoken-api).

## Corriger d’abord le mode Cowork

Claude Desktop prend uniquement en charge les modèles Claude. Il s’agit d’une limitation du client Claude Desktop.

Suivez le [guide Claude Desktop](/fr/faq/claude-desktop-bettertoken-api) : sélectionnez **Gateway**, indiquez la Base URL `{{anthropic-base-url}}`, votre BetterToken API Key et **Gateway auth scheme** `x-api-key`. Cliquez sur **Apply locally**, puis redémarrez complètement Claude Desktop.

## Corriger ensuite les erreurs de sortie du mode Code

Si Cowork fonctionne, mais que le mode Code, l’onglet `</>`, affiche toujours `Claude Code process exited with code 1`, vérifiez si Claude Desktop utilise encore une ancienne version intégrée de Claude Code.

**Cause principale** : Claude Desktop peut télécharger une version plus récente de Claude Code en arrière-plan. Avant la fin du téléchargement, le mode Code peut revenir à une ancienne version installée de Claude Code. Cette ancienne version peut ne pas être compatible avec l’utilisation d’une passerelle tierce dans le mode Code, de sorte que le processus s’arrête immédiatement.

**Procédure de correction** :

<Steps>
  <Step title="Attendre la fin du téléchargement de la nouvelle version de Claude Code">
    Laissez Claude Desktop ouvert quelque temps pour permettre la fin de la mise à jour de Claude Code en arrière-plan.
  </Step>

  <Step title="Quitter complètement Claude Desktop">
    Utilisez **Cmd+Q** pour quitter complètement l’application. Ne fermez pas uniquement la fenêtre.
  </Step>

  <Step title="Rouvrir et démarrer une nouvelle session Code">
    Ouvrez à nouveau Claude Desktop, accédez au mode Code et démarrez une nouvelle session.
  </Step>
</Steps>

<Note>
  Si les journaux indiquent que Claude Desktop revient à une ancienne version de Claude Code, telle que `2.1.111`, alors qu’une version plus récente, telle que `2.1.119`, n’est pas encore prête, attendez la fin du téléchargement de la nouvelle version, puis redémarrez l’application.
</Note>

## Référence rapide

| Symptôme | Cause principale fréquente | Solution |
|---------|-------------------|-----|
| Cowork | Gateway auth scheme | Vérifiez que l’API Key est complète et n’a pas expiré. Utilisez `x-api-key` pour ce Gateway, enregistrez et redémarrez Claude Desktop. |
| Le mode Code affiche `Claude Code process exited with code 1` | Claude Desktop revient à une ancienne version de Claude Code | Attendez la fin du téléchargement de la nouvelle version, quittez complètement avec **Cmd+Q**, puis rouvrez |
