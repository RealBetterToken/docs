---
title: "Démarrage rapide"
description: "En 4 étapes, créez un compte, ajoutez du crédit, créez une API Key et ouvrez le guide de configuration adapté à votre outil."
---

<Steps>
  <Step title="Créer un compte">
    Ouvrez la <a href={"{{register-url}}"}>page d’inscription BetterToken</a> pour créer un compte.

    Après votre inscription, rechargez votre solde avant de créer une BetterToken API Key.
  </Step>
  <Step title="Ajouter du crédit au compte">
    Vous pouvez utiliser **Online top-up** ou **Redeem code**. Après l’ajout de crédit, revenez dans la console et vérifiez que **Current balance** a été mis à jour avant de créer une API Key.

    <Tabs>
      <Tab title="Online top-up">
        Après vous être connecté, ouvrez la **Console**. Dans la carte **Current balance**, choisissez la devise à créditer, puis cliquez sur le bouton **Top up** correspondant.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Carte Current balance de la BetterToken Console avec les boutons Top up pour USD et RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Suivez les instructions de paiement. Une fois le paiement réussi, revenez dans la console et vérifiez que **Current balance** a été mis à jour.
      </Tab>
      <Tab title="Redeem code">
        Après vous être connecté, ouvrez la **Console** et cliquez sur **Redeem code** en bas à gauche de la carte **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Carte Current balance de la BetterToken Console avec une flèche pointant vers le bouton Redeem code en bas à gauche."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Saisissez votre code dans la boîte de dialogue, puis cliquez sur **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Boîte de dialogue Redeem code avec le champ de saisie du code et le bouton Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Une fois le code utilisé, revenez dans la console et vérifiez que **Current balance** a été mis à jour.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Ouvrir la gestion des API Key et créer une API Key">
    Dès que du crédit est disponible, cliquez sur **Create API key** en haut à droite de la section **Your API keys** de la console.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Section Your API keys de la BetterToken Console avec une flèche pointant vers le bouton Create API key en haut à droite."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Le formulaire de création d’une API Key s’ouvre.

    <Info>
      Utilisez la fonction prévue de l’API Key comme nom. Si vous choisissez d’abord le bon cas d’utilisation, la suite de la configuration sera plus claire.
    </Info>
  </Step>
  <Step title="Choisir le fournisseur selon le type d’outil">
    Dans le formulaire, renseignez **Name**, choisissez le **provider**, puis confirmez la date d’expiration et la limite de dépenses facultative.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Formulaire Create API Key avec les options de nom, de provider, d’expiration et de limite de dépenses."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Choisissez le fournisseur selon l’outil que vous allez connecter.

    <Warning>
      Le **Claude provider** peut uniquement être utilisé avec Claude Code.
    </Warning>

    <Warning>
      Le **GPT provider** peut être utilisé avec Codex et des outils externes comme OpenClaw, OpenCode et Cursor.
    </Warning>

    Choisissez l’un de ces fournisseurs :

    ```text
    Claude
    GPT
    ```

    Après la création de l’API Key, la boîte de dialogue **API key setup** s’ouvre. Copiez **API Key** et **Base URL** depuis cette boîte de dialogue.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="Boîte de dialogue BetterToken API key setup avec l’API Key, la Base URL, la sélection de l’outil et les méthodes de configuration."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Choisir une méthode de configuration">
    Dans la boîte de dialogue **API key setup**, choisissez à gauche l’outil à connecter, puis sélectionnez une méthode de configuration.

    - **One-click Bash Configuration** : choisissez l’outil et `macOS / Linux` ou `Windows`, copiez la commande générée et exécutez-la dans votre terminal local. Utilisez cette méthode pour configurer rapidement Codex, OpenClaw ou OpenCode.
    - **CC Switch integration** : cliquez sur **Import to CC Switch** pour importer l’**API Key** et la **Base URL** actuelles dans CC Switch. Utilisez cette méthode pour gérer plusieurs outils et fournisseurs dans une seule application.
    - **Manual configuration** : copiez l’**API Key** et la **Base URL**, puis collez-les dans le processus de configuration de l’outil cible. Utilisez cette méthode pour Cursor, Cline, Roo Code, Zed et les autres clients.

    <Note>
      Les outils utilisent des champs d’authentification, des sélecteurs de modèle et des emplacements de configuration différents. Consultez le guide propre à l’outil avant de terminer la configuration.
    </Note>
  </Step>
</Steps>
