---
title: "Démarrage rapide"
description: "Créez un compte BetterToken, ajoutez du crédit, générez une API Key et ouvrez le guide adapté à Claude Code, Codex CLI ou un autre outil externe compatible."
---

<Steps>
  <Step title="Créer un compte">
    Ouvrez la <a href={"{{register-url}}"}>page d’inscription BetterToken</a> pour créer un compte.

    Après votre inscription, rechargez votre solde avant de créer une BetterToken API Key.
  </Step>
  <Step title="Ajouter du crédit au compte">
    Vous pouvez utiliser **Online top-up** ou **Redeem code**. Après l’ajout de crédit, revenez dans la console et vérifiez que **Current balance** a été mis à jour avant de créer une API Key.

    <Tabs>
      <Tab title="Online top-up">
        Après vous être connecté, ouvrez la **Console**. Dans la carte **Current balance**, choisissez la devise à créditer, puis cliquez sur le bouton **Top up** correspondant.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Carte Current balance de la BetterToken Console avec les boutons Top up pour USD et RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Suivez les instructions de paiement. Une fois le paiement réussi, revenez dans la console et vérifiez que **Current balance** a été mis à jour.
      </Tab>
      <Tab title="Redeem code">
        Après vous être connecté, ouvrez la **Console** et cliquez sur **Redeem code** en bas à gauche de la carte **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Carte Current balance de la BetterToken Console avec une flèche pointant vers le bouton Redeem code en bas à gauche."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Saisissez votre code dans la boîte de dialogue, puis cliquez sur **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Boîte de dialogue Redeem code avec le champ de saisie du code et le bouton Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Une fois le code utilisé, revenez dans la console et vérifiez que **Current balance** a été mis à jour.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Ouvrir la gestion des API Key et créer une API Key">
    Dès que du crédit est disponible, cliquez sur **Create API key** en haut à droite de la section **Your API keys** de la console.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Section Your API keys de la BetterToken Console avec une flèche pointant vers le bouton Create API key en haut à droite."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Dans **Create API Key**, saisissez un **API key name**. Si vous souhaitez définir une date d’expiration ou un plafond de dépenses, ouvrez **Advanced settings**, puis cliquez sur **Create API Key**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="Fenêtre Create API Key avec le champ API key name, Advanced settings et le bouton Create API Key."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Copier les informations de connexion ou le code de configuration">
    Après la création de la clé, ouvrez **Set up API key**. Dans **Connection details**, copiez l’**API Key**, sélectionnez **OpenAI** ou **Anthropic** selon le protocole, puis copiez la **Base URL** correspondante.

    Vous pouvez aussi choisir votre outil ou **API call** dans **Configuration guide**, sélectionner l’API et un modèle d’exemple si nécessaire, puis copier le code proposé. Pour plus de détails, ouvrez **View tool documentation** ou l’un des guides ci-dessous. Cliquez ensuite sur **Finish**.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="Fenêtre Set up API key avec API Key et Base URL à copier, puis Configuration guide proposant des outils et du code."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
