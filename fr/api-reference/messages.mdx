`POST /v1/messages`

Utilisez cet endpoint pour Claude Code, le SDK Anthropic et les applications qui utilisent l’API Anthropic Messages.

<Note>
  Pour un SDK, utilisez `{{anthropic-base-url}}` comme Base URL. Une Request manuelle et le Playground utilisent le chemin complet `{{anthropic-base-url}}/v1/messages`.
</Note>

## Tester dans le Playground

Dans le Playground à droite, saisissez votre API Key dans le champ `x-api-key`, conservez `anthropic-version` à `claude-cli/2.0.76 (external, cli)`, choisissez un modèle de fournisseur Claude disponible et envoyez la Request.

<Warning>
  N’utilisez pas `Authorization: Bearer ...` pour cet endpoint. Il exige l’en-tête `x-api-key`.
</Warning>
