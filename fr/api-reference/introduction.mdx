La référence API publique de BetterToken couvre actuellement uniquement l’**API Chat Completions compatible avec OpenAI**. Les autres protocoles ne sont pas encore pris en charge de façon uniforme sur tous les canaux ; Responses API et Anthropic Messages API ne sont donc pas publiées comme interfaces publiques.

## Fournisseurs pris en charge

| Fournisseur | Statut |
| --- | --- |
| Claude | Non pris en charge |
| GPT | Configuration manuelle |
| Kimi | Configuration manuelle |
| GLM | Configuration manuelle |

## Informations de connexion

| Champ | Valeur |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| URL de requête complète | `{{chat-completions-url}}` |
| Méthode | `POST` |
| Autorisation | `Bearer YOUR_API_KEY` |
| Modèle | `YOUR_MODEL_ID` |

Copiez un Model ID actuel depuis le <a href={"{{model-plaza-url}}"}>model plaza</a> ou la boîte de dialogue **Setup** de l’API Key dans la Console.

<Warning>
  Lorsqu’un outil demande une **Base URL**, saisissez `{{openai-base-url}}`. Utilisez `{{chat-completions-url}}` uniquement lorsque l’outil demande explicitement une URL de requête complète.
</Warning>

## Test rapide

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Une réponse réussie contient `choices[0].message.content`.
