`POST /v1/responses`

Utilisez cet endpoint pour Codex et les applications qui utilisent l’API OpenAI Responses.

<Note>
  Base URL : `{{openai-base-url}}`. Passez votre API Key sous la forme `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Tester dans le Playground

Dans le Playground à droite, saisissez votre API Key, remplacez `model` par un model ID actuel du fournisseur GPT si nécessaire et envoyez la Request. Confirmez le modèle dans le <a href={"{{model-plaza-url}}"}>model plaza</a> avant le test.

<Warning>
  Utilisez uniquement votre propre API Key de test. Ne placez pas de Key dans le code, les captures d’écran, tickets ou dépôts Git.
</Warning>
