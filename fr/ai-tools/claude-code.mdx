Connectez Claude Code avec votre BetterToken API Key, la Base URL `{{anthropic-base-url}}` et le Model ID souhaité. Copiez le Model ID exact depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Paramètres principaux

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## Prérequis

- Installez la dernière version de [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- Installez Node.js
- <a href={"{{register-url}}"}>Créez et copiez une BetterToken API Key</a>

## Installation

```bash
npm install -g @anthropic-ai/claude-code
```

## Configuration par la ligne de commande

Le script de configuration automatique BetterToken écrit la configuration du fournisseur Claude Code. Il nécessite Node.js et demande l’API Key si elle n’est pas transmise en argument.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

Une fois le script terminé, vérifiez `~/.claude/settings.json` (ou `%USERPROFILE%\.claude\settings.json` sous Windows), puis redémarrez complètement Claude Code. Utilisez la configuration manuelle ci-dessous pour contrôler chaque champ.

## Configuration manuelle

| Système | Fichier |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

Copiez le Model ID exact depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>.

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

Remplacez `YOUR_MODEL_ID` par l’ID copié. `ANTHROPIC_MODEL` définit le modèle principal et les trois variables `ANTHROPIC_DEFAULT_*_MODEL` définissent les alias Haiku, Sonnet et Opus. Vous pouvez utiliser un même modèle ou un modèle différent pour chaque rôle.

### Extension VS Code

L’extension utilise le fichier VS Code `settings.json`. Ajoutez une configuration `claudeCode.environmentVariables` distincte :

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_SONNET_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_OPUS_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

## Vérifier la connexion

Lancez Claude Code dans votre projet :

```bash
claude
```

Envoyez un court message. Une réponse normale sans erreur `401`, de connexion ou de modèle confirme la configuration. Redémarrez complètement Claude Code après avoir modifié le fichier.

## Changer de modèle

Modifiez le Model ID dans la configuration et redémarrez Claude Code. Pour changer en cours de session, utilisez `/model YOUR_MODEL_ID`.

## Erreurs fréquentes

| Erreur | Solution |
| --- | --- |
| `401` ou échec de l’authentification | Vérifiez `ANTHROPIC_AUTH_TOKEN` et supprimez les espaces autour de l’API Key. |
| `ConnectionRefused` | Utilisez exactement `{{anthropic-base-url}}` ; n’ajoutez pas `/v1`. |
| Model ID | Vérifiez le Model ID exact dans la model plaza et saisissez-le dans les paramètres du modèle du client. |
| Configuration non appliquée | Vérifiez le chemin du fichier, supprimez les variables d’environnement conflictuelles et redémarrez complètement Claude Code. |
