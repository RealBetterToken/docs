Ce guide configure le package terminal tiers `@vibe-kit/grok-cli`, et non une CLI officielle de xAI. Après l’installation, définissez `GROK_API_KEY` et `GROK_BASE_URL`, choisissez un Model ID actuel, puis démarrez une conversation dans le terminal. Les instructions ci-dessous concernent uniquement ce package npm.

<Note>
  `@vibe-kit/grok-cli` est un projet open source tiers. Consultez son dépôt pour suivre les versions et les changements.
</Note>

## Paramètres principaux

| Champ | Valeur |
| --- | --- |

| Base URL | `{{openai-base-url}}` |
| Model | Un Model ID actuel du <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Prérequis

- La version actuelle de l’outil est installée
- Une BetterToken API Key : <a href={"{{register-url}}"}>inscrivez-vous pour en obtenir une</a>
- Un Model ID du <a href={"{{model-plaza-url}}"}>model plaza</a>

## Installation

### Installer Grok CLI

Exécutez ceci sur Windows, macOS ou Linux :

```bash
npm install -g @vibe-kit/grok-cli
```

Si `grok` est introuvable après l’installation, fermez et rouvrez le terminal, puis exécutez `grok --help`. Vérifiez que le répertoire global des paquets `npm` est dans votre `PATH`.

### Configurer la Base URL et l’API Key

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="Effacer les variables en conflit">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="Définir les variables BetterToken">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="Démarrer Grok CLI avec un modèle">
        ```bash
        grok --model YOUR_MODEL_ID
        ```

        Remplacez `YOUR_MODEL_ID` par un **model ID actuel d’un fournisseur compatible** du model plaza.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="Définir les variables pour la fenêtre PowerShell actuelle">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="Démarrer Grok CLI avec un modèle">
        ```powershell
        grok --model YOUR_MODEL_ID
        ```

        Ces variables ne s’appliquent qu’à la fenêtre PowerShell actuelle. Définissez-les à nouveau à l’aide de la méthode de stockage de secrets approuvée par votre équipe lorsque vous ouvrez une nouvelle fenêtre.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Vérifier la connexion

Envoyez un court prompt de test. Si l’outil renvoie une réponse sans erreur d’authentification ni erreur de Model ID, la connexion fonctionne. Redémarrez complètement l’outil après avoir modifié sa configuration.

Une fois Grok CLI démarré, envoyez un court prompt. S’il répond sans erreur d’authentification ni erreur de model ID, la connexion est prête. À chaque modification de variables d’environnement, terminez la session Grok CLI actuelle et démarrez-en une nouvelle.

## Changer de modèle

Ouvrez le sélecteur de modèle ou modifiez le champ `Model` dans la configuration. Utilisez le Model ID exact du <a href={"{{model-plaza-url}}"}>model plaza</a>, puis redémarrez la session actuelle.

## Erreurs courantes

| Symptôme | Vérifications |
| --- | --- |
| `grok: command not found` | Réinstallez, ouvrez un nouveau terminal et vérifiez `grok --help`. |
| `401`, `Unauthorized` ou `Invalid API key` | Vérifiez `GROK_API_KEY`, assurez-vous qu’aucun espace superflu n’a été copié et démarrez Grok CLI dans le même terminal où la variable est définie. |
| `model not found` ou modèle indisponible | Copiez un model ID actuel du **fournisseur compatible** dans le model plaza. N’utilisez pas d’ID du fournisseur Claude. |
| Les Request utilisent encore un service précédent | Vérifiez `GROK_BASE_URL`, n’ajoutez pas `/chat/completions`, puis redémarrez le terminal et Grok CLI. |
| Erreur de connexion | Vérifiez que la Base URL est `{{openai-base-url}}` et que votre réseau peut atteindre `bettertoken.ai` via HTTPS. |

### FAQ de configuration

**Quelle Base URL dois-je utiliser dans Grok CLI ?**

Utilisez `{{openai-base-url}}`. Il s’agit de la Base URL OpenAI compatible de BetterToken.

**Quelle API Key et quel modèle dois-je sélectionner ?**

Utilisez une BetterToken API Key et un modèle du même groupe.

**Dois-je modifier un proxy système ou activer un VPN ?**

Non. Configurez la Base URL et l’API Key dans votre terminal pour vous connecter à BetterToken.
