## Paramètres principaux

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modèle | `YOUR_MODEL_ID` |

## Prérequis

- Installez la dernière version d’OpenClaw
- <a href={"{{register-url}}"}>Créez une BetterToken API Key</a>
- Copiez un Model ID depuis le <a href={"{{model-plaza-url}}"}>model plaza</a> ou la boîte de dialogue **Setup** de l’API Key

## Configuration par la ligne de commande

Le script de configuration automatique BetterToken écrit la configuration OpenClaw. Il nécessite Node.js. Si vous ne transmettez pas l’API Key ou le Model ID en argument, le script vous les demande.

<Tabs>
  <Tab title="macOS / Linux">

  </Tab>

## Configuration manuelle

### Configurer OpenClaw

Copiez le Model ID exact depuis la <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Tabs>
  <Tab title="Responses API">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-responses",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Chat Completions">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-completions",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

`openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`.

## Vérifier la connexion

Exécutez :

```bash
openclaw config validate
openclaw gateway restart
openclaw models list
openclaw models status
```

La configuration est active lorsque la validation réussit, que le Gateway redémarre et que `bettertoken/YOUR_MODEL_ID` apparaît dans la liste et le statut des modèles. Si une session existante utilise toujours un ancien modèle, créez une nouvelle session et vérifiez de nouveau.

## Changer de modèle

Ajoutez le nouveau modèle à `models.providers.bettertoken.models`, puis définissez `agents.defaults.model.primary` sur `bettertoken/YOUR_MODEL_ID`. Enregistrez, validez la configuration et redémarrez le Gateway.

## Erreurs fréquentes

| Erreur | Solution |
| --- | --- |
| Échec de `config validate` | Vérifiez les virgules, guillemets et accolades du JSON. |
| `401` | Copiez de nouveau `apiKey` et supprimez les espaces. |
| `404` | `openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`. |
| Modèle absent | Vérifiez qu’il figure dans la liste des modèles du fournisseur et dans `agents.defaults.model.primary`. |
| La session existante utilise l’ancien modèle | Exécutez `openclaw gateway restart` et créez une nouvelle session. |
