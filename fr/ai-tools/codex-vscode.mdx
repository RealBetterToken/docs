L’extension Codex VS Code partage `~/.codex/config.toml` avec Codex CLI/App. Utilisez cette page si vous devez conserver la connexion officielle, les plugins ou Remote Control.

## Paramètres principaux

| Champ | Valeur |
| --- | --- |
| API Key | `experimental_bearer_token = "YOUR_API_KEY"` |
| Base URL | `{{openai-base-url}}` |
| Model | `gpt-6-astra` |

## Prérequis

- Installez la dernière version de l’extension Codex VS Code
- Terminez la connexion officielle dans l’extension ou Codex App
- <a href={"{{register-url}}"}>Créez une BetterToken API Key</a>
- Copiez un Model ID depuis le <a href={"{{model-plaza-url}}"}>model plaza</a> ou la boîte de dialogue **Setup** de la Key

## Installation

Installez l’extension depuis VS Code Marketplace, puis redémarrez VS Code.

## Configuration manuelle

Si vous avez défini un `CODEX_HOME` personnalisé, modifiez le fichier `config.toml` de ce répertoire. Sinon, utilisez `~/.codex/config.toml` sur macOS / Linux ou `%USERPROFILE%\.codex\config.toml` sur Windows.

Quittez complètement Codex, puis sauvegardez les fichiers `config.toml` et `auth.json` existants. Mettez à jour les paramètres du fournisseur existant sans ajouter une table de fournisseur en double.

### Configurer l’extension

Modifiez `~/.codex/config.toml` :

```toml
model_provider = "bettertoken"
model = "gpt-6-astra"

[model_providers.bettertoken]
name = "BetterToken"
base_url = "{{openai-base-url}}"
wire_api = "responses"
requires_openai_auth = true
experimental_bearer_token = "YOUR_API_KEY"
```

Enregistrez le fichier, exécutez **Developer: Reload Window** dans VS Code, puis rouvrez le panneau Codex.

## Vérifier la connexion

Créez une nouvelle session Extension et envoyez une courte tâche. Une réponse de `gpt-6-astra` alors que les plugins et Remote Control restent disponibles confirme la configuration.

## Changer de modèle

Modifiez `model` et, si nécessaire, `review_model`, puis exécutez **Developer: Reload Window**. Utilisez un Model ID de la boîte de dialogue Setup ou du model plaza.

## Erreurs courantes

| Erreur | Correction |
| --- | --- |
| L’extension vous demande de vous reconnecter | Restaurez la connexion officielle et conservez `requires_openai_auth = true`. |
| `401` ou `403` | Copiez à nouveau `experimental_bearer_token` ; n’écrasez pas `auth.json`. |
| Table dupliquée | Supprimez l’autre table `[model_providers.bettertoken]` et conservez un seul mode d’authentification. |
| Model not found | Remplacez `gpt-6-astra` par un Model ID actuel et complet. |
| Configuration non appliquée | Enregistrez le fichier et exécutez **Developer: Reload Window**. |
