Pour connecter Kodacode à BetterToken, préparez une API Key, saisissez la Base URL ci-dessous et choisissez un Model ID actuel dans le model plaza.

## Paramètres principaux

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Un Model ID actuel du <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Prérequis

- La version actuelle de l’outil est installée
- Une BetterToken API Key : <a href={"{{register-url}}"}>inscrivez-vous pour en obtenir une</a>
- Un Model ID du <a href={"{{model-plaza-url}}"}>model plaza</a>

### Exigences supplémentaires

- VS Code est installé
- L’extension Kodacode / Koda est installée
- Le Model ID sélectionné provient du **fournisseur compatible**

## Installation

Installez ou ouvrez Kodacode, puis poursuivez avec la configuration manuelle ci-dessous.

## Configuration manuelle

| Champ | Valeur |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | Un Model ID actuel du <a href={"{{model-plaza-url}}"}>model plaza</a> |

<Steps>

  </Step>

  <Step title="Renseigner les paramètres du modèle OpenAI compatible">
    Dans la boîte de dialogue d’ajout de modèle, utilisez ces valeurs :

    | Champ | Valeur recommandée |
    | --- | --- |
    | Provider | `Any OpenAI-compatible API` |
    | API Base | `{{openai-base-url}}/` |
    | Model ID | Un model ID d’un fournisseur compatible du <a href={"{{model-plaza-url}}"}>model plaza</a>, par exemple `YOUR_MODEL_ID` |
    | API Key | Votre BetterToken API Key |

    Cliquez sur **Connect** après avoir renseigné les champs.

    <Frame>
      <img

### Exemple de config.yaml

Utilisez cette structure complète comme référence. Remplacez `YOUR_API_KEY` par votre BetterToken API Key et ne validez pas une API Key réelle dans votre dépôt.

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: YOUR_MODEL_ID
    provider: openai
    model: YOUR_MODEL_ID
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  Si vous utilisez un modèle autre que `YOUR_MODEL_ID`, mettez à jour `name` et `model` afin qu’ils correspondent au model ID d’un fournisseur compatible du <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Note>

## Vérifier la connexion

Envoyez un court prompt de test. Si l’outil renvoie une réponse sans erreur d’authentification ni erreur de Model ID, la connexion fonctionne. Redémarrez complètement l’outil après avoir modifié sa configuration.

## Changer de modèle

Ouvrez le sélecteur de modèle ou modifiez le champ `Model` dans la configuration. Utilisez le Model ID exact du <a href={"{{model-plaza-url}}"}>model plaza</a>, puis redémarrez la session actuelle.

## Erreurs courantes

| Erreur | Vérifications |
| --- | --- |
| `401` ou `Unauthorized` | Vérifiez la BetterToken API Key et supprimez les espaces initiaux ou finaux. |
| `404` | Vérifiez la Base URL et n’ajoutez pas de chemin d’endpoint spécifique. |
| `model not found` | Copiez un Model ID actuel depuis le model plaza. |
| Les modifications ne sont pas appliquées | Enregistrez la configuration et redémarrez complètement l’outil. |


- Si la connexion échoue, vérifiez que **API Base** est `{{openai-base-url}}/` et conservez la barre oblique finale `/`.
- Si le modèle est indisponible, vérifiez que **Model ID** provient du fournisseur compatible.
- Si l’authentification échoue, copiez à nouveau l’API Key et évitez les espaces ou retours à la ligne superflus.
- Si les modifications de `config.yaml` ne s’appliquent pas, redémarrez VS Code ou exécutez **Developer: Reload Window**.
- BetterToken ne nécessite généralement pas de `User-Agent` supplémentaire ni d’en-têtes personnalisés.
