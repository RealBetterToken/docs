## Настройка

<AccordionGroup>
  <Accordion title="Какой base_url у BetterToken?">
    BetterToken использует два endpoint в зависимости от протокола:

    | Сценарий | Base URL |
    |----------|----------|
    | Claude Code / `ANTHROPIC_BASE_URL` | `{{anthropic-base-url}}` |
    | Codex / `OPENAI_BASE_URL` / внешние инструменты | `{{openai-base-url}}` |

    Не используйте один адрес во всех инструментах.
  </Accordion>

  <Accordion title="Нужно ли указывать модель для Claude Code?">
    Это зависит от выбранного провайдера.

    С провайдером **Claude** задайте только `ANTHROPIC_BASE_URL` и `ANTHROPIC_AUTH_TOKEN`. Переменные модели не нужны.

    С провайдером **GPT** добавьте сопоставления моделей через `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` и `ANTHROPIC_DEFAULT_OPUS_MODEL`. ID модели копируйте из каталога провайдера **GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Accordion>

  <Accordion title="Нужно ли указывать модель для Codex?">
    Да. Укажите ID модели у провайдера **GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Подробнее смотрите в [инструкции для Codex](/ai-tools/codex).
  </Accordion>

  <Accordion title="Нужно ли указывать модель в Cursor и других инструментах?">
    Да. Внешние инструменты, например Cursor, Cline, Zed и OpenClaw, используют провайдер **GPT**. Копируйте актуальный ID модели из <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Не используйте в этих инструментах жестко заданные имена Claude-моделей.

    Подробнее смотрите в [инструкции для Cursor](/ai-tools/cursor).
  </Accordion>

  <Accordion title="Нужны ли OpenClaw и другим внешним инструментам дополнительные headers?">
    Обычно нет.

    По официальным инструкциям, которые мы проверяли, Cursor, Cline, Zed и похожие инструменты в основном требуют `Base URL`, API Key и ID модели. OpenCode и OpenClaw поддерживают необязательные `headers`, но в их документации это описано как настройка для нестандартной авторизации, а не как обязательный шаг BetterToken.

    Добавляйте дополнительные headers только если это явно требуется документацией инструмента или вашим upstream gateway, tenant routing, observability-слоем либо кеширующей прослойкой.
  </Accordion>

  <Accordion title="Что делать, если после настройки не проходит авторизация?">
    Проверьте:

    1. API Key введен правильно и без лишних пробелов
    2. Claude Code использует `{{anthropic-base-url}}`, а Codex / внешние инструменты используют `{{openai-base-url}}`
    3. Старые переменные `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `OPENAI_API_KEY` или `OPENAI_BASE_URL` не переопределяют конфигурацию
    4. Для внешних инструментов нет дополнительных требований: версии клиента, allowlist моделей или обязательных headers вашего upstream gateway

    Если проблема остается, обратитесь в поддержку.
  </Accordion>
</AccordionGroup>

## Надежность и лимиты

<AccordionGroup>
  <Accordion title="За счет чего BetterToken остается стабильным?">
    BetterToken подключается к нескольким поставщикам и использует несколько механизмов:

    - **Несколько источников**: сбой одного поставщика не останавливает все запросы
    - **Динамическая маршрутизация**: BetterToken в реальном времени выбирает самый быстрый и стабильный путь
    - **Фокус на ключевых сценариях**: надежность в первую очередь оптимизирована для Claude Code и экосистемы Codex
  </Accordion>

  <Accordion title="Что делать при rate limit или timeout?">
    BetterToken автоматически обрабатывает лимиты и timeout отдельных поставщиков. Если проблемы продолжаются:

    1. Проверьте, что на балансе достаточно средств
    2. Увеличьте timeout в инструменте, рекомендуется `API_TIMEOUT_MS=3000000`
    3. Обратитесь в поддержку, чтобы уточнить текущий статус квот
  </Accordion>

  <Accordion title="Подходит ли BetterToken для production?">
    BetterToken в первую очередь сделан для индивидуальных разработчиков, которые используют AI-инструменты вроде Claude Code и Codex. Для крупных production-нагрузок оцените сервис по собственным требованиям.
  </Accordion>
</AccordionGroup>

## Конфиденциальность и безопасность

<AccordionGroup>
  <Accordion title="Хранит ли BetterToken содержимое моих запросов?">
    BetterToken работает как прокси и не сохраняет содержимое диалогов на постоянной основе. Подробнее смотрите в <a href={"{{privacy-url}}"}>Privacy Policy</a>.
  </Accordion>

  <Accordion title="Что делать, если API Key утек?">
    Сразу войдите в панель управления, удалите старый ключ и создайте новый. Затем обновите каждый инструмент, где использовался этот ключ.
  </Accordion>
</AccordionGroup>
