リリース日: 2026 年 9 月 28 日

Claude Sonnet 5.5 は、Anthropic の Claude 5.5 ファミリーで 2 番目のモデルです。Anthropic は、コーディング、バグ修正、文書・プレゼンテーション・スプレッドシートの作成など、範囲が明確な日常業務に向けた、より高速な選択肢と位置付けています。複雑で自由度の高いタスクには Opus 5.5 も検討してください。

**Claude Sonnet 5.5** が BetterToken で利用可能になりました。`Claude` プロバイダーを選び、Base URL を `{{anthropic-base-url}}`、モデル ID を `claude-sonnet-5-5` に設定してください。最新の提供状況と価格は<a href={"{{model-plaza-url}}"}>モデル広場</a>で確認できます。

## 主な特長

- **明確な開発タスク**: 要件が定まった実装やバグ修正に使用できます。
- **業務用コンテンツ**: Anthropic は文書、プレゼンテーション、スプレッドシートの作成を挙げています。
- **長いコンテキスト**: Anthropic によると、コンテキストウィンドウは 100 万トークン、最大出力は 12.8 万トークンです。

## Sonnet 5 から切り替える前に

クライアントから Anthropic Messages API を直接呼び出している場合は、モデル ID を変更する前に[公式移行ガイド](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)を確認してください。Sonnet 5.5 では thinking とツール選択の一部の動作が変わります。代表的なリクエストで先に検証してください。

## 接続方法

1. <a href={"{{register-url}}"}>BetterToken API Key を作成</a>します。
2. `Claude` プロバイダーを選び、Base URL に `{{anthropic-base-url}}` を指定します。
3. モデル ID に `claude-sonnet-5-5` を指定します。
4. 本番トラフィックを切り替える前に、実際のタスクで試します。

クライアントの設定は [Claude Code ガイド](/ja/ai-tools/claude-code)、他モデルとの比較は[モデル選択ガイド](/ja/faq/model-calling/model-selection-guide)を参照してください。
