更新日：2026 年 9 月 5 日

BetterToken で **GPT-6 Astra** が利用可能になりました。正確な Model ID は `gpt-6-astra` です。OpenAI は、複雑な推論、ソフトウェア開発、調査、コンピュータ操作、文書作成など、難易度の高いエンドツーエンド作業向けの最も高性能なモデルとして Astra を紹介しています。現在の提供状況と BetterToken の価格は<a href={"{{model-plaza-url}}"}>モデル広場</a>で確認してください。

## 更新のポイント

- **エンドツーエンド作業**：コード、ブラウザ、ツール、業務アプリをまたぐ複雑な複数ステップのタスク向け
- **ソフトウェア開発**：OpenAI は Astra を、コーディングとエージェント開発における現時点で最も強力なモデルと位置づけています
- **大きなコンテキスト**：OpenAI の仕様ではコンテキストは `1,050,000` tokens、最大出力は `128,000` tokens
- **調整可能な推論**：OpenAI API では `low`、`medium`、`high`、`xhigh`、`max` を選択可能
- **Responses API ツール**：関数呼び出し、構造化出力、Web 検索、ファイル検索、Code Interpreter、computer use、MCP などをサポート

## 設定の推奨事項

- 難しいコーディング、調査、computer use、長時間のエージェント作業で Astra を試してください。日常作業では、モデル広場にある高速または低コストのモデルとも比較してください。
- 本番トラフィックを切り替える前に、実際のタスクで品質、遅延、token 使用量を比較してください。
- **GPT provider**、Base URL `{{openai-base-url}}`、正確な Model ID `gpt-6-astra` を使用してください。
- 段階的な提供中は可用性が変わる場合があります。BetterToken の提供状況と価格はモデル広場を基準にしてください。

## よくある質問

### GPT-6 Astra の Model ID は何ですか？

`gpt-6-astra` を使用してください。表示名 `GPT-6 Astra` や他のプラットフォーム用 ID は使用しないでください。

### BetterToken で 1,050,000-token のコンテキストをすべて利用できますか？

OpenAI は GPT-6 Astra のコンテキストを `1,050,000` tokens としています。実際の上限はクライアント、リクエスト設定、BetterToken の現在のルーティングにも左右されます。非常に大きな prompt を送る前にモデル広場とクライアントの文書を確認してください。

### Model not found を解決するには？

Model ID が `gpt-6-astra` であること、BetterToken API Key にアクセス権があること、**GPT provider** が選択されていること、Base URL が `{{openai-base-url}}` であることを確認してください。再起動後に再試行します。

### 現在の価格はどこで確認できますか？

<a href={"{{model-plaza-url}}"}>モデル広場</a>で確認してください。BetterToken の価格は OpenAI API の直接価格と異なる場合があり、変更されることがあります。
