リリース日：2026 年 4 月 16 日

BetterToken は `Claude Opus 4.7` のモデルエントリーを更新しました。<a href={"{{model-plaza-url}}"}>モデル広場</a>で現在利用可能なモデル ID を確認してから、クライアントに合った Claude Code または外部ツールのセットアップガイドで設定してください。

Anthropic は 2026 年 4 月 16 日に Claude Opus 4.7 を正式発表し、一般提供を開始しました。Anthropic は Opus 4.7 を、高度なソフトウェアエンジニアリング、複雑で長時間実行するタスク、視覚情報、プロフェッショナルなナレッジワークにおける Opus 4.6 からの改善として説明しています。

## 主な特徴

- **ソフトウェアエンジニアリングの強化**：Anthropic によると、Opus 4.7 は最も難しい高度なソフトウェアエンジニアリングタスクを改善し、以前はより厳しい監督が必要だった作業により適しています。
- **長いタスクの一貫性向上**：このモデルは、複雑で長時間実行する作業でより厳密かつ一貫しており、報告前の自己確認も強化されています。
- **視覚情報の改善**：Opus 4.7 はより高解像度の画像入力をサポートしており、情報量の多いスクリーンショット、複雑な図、細部の多い視覚資料に役立ちます。
- **安全管理の更新**：Anthropic は Project Glasswing の後に Opus 4.7 を提供し、禁止または高リスクのサイバーセキュリティリクエストを検出・ブロックするセーフガードを導入しました。
