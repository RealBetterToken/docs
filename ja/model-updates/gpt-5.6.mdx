リリース日：2026 年 7 月 10 日

BetterToken は GPT-5.6 モデルファミリーをサポートしています。<a href={"{{model-plaza-url}}"}>モデル広場</a>で現在利用可能な **GPT プロバイダー**のモデル ID と最新価格を確認してから、OpenAI 互換プロトコルを通じて Codex、OpenCode、OpenClaw、Cursor、Cline、Zed、その他の外部ツールで使用してください。

新しいモデル ID は次のとおりです。

| モデル ID | 適した用途 |
| --- | --- |
| `gpt-5.6-sol` | 複雑な推論、大規模なコードベース、複数ステップのエージェントタスク、長時間実行するコーディングワークフロー |
| `gpt-5.6-terra` | 日常的なコーディング、対話的な開発、一般的なエージェントタスク、能力と費用のバランス |
| `gpt-5.6-luna` | バッチ支援、短い Q&A、簡単な書き換え、小規模なツール呼び出しなど、速度と費用が重要な軽量タスク |

## 主な特徴

- **3 つのモデル階層**：OpenAI は GPT-5.6 Sol、Terra、Luna を、高度な推論作業、バランスの取れた日常タスク、軽量で大量のタスク向けに位置付けています。
- **コーディングエージェントへの適合**：OpenAI は、コーディングエージェント、ターミナルワークフロー、ツール連携タスクでの改善を強調しています。
- **外部ツールで利用可能**：OpenAI Help Center は、Sol、Terra、Luna が OpenAI API を通じて利用可能であると示しています。BetterToken では **GPT プロバイダー**と `{{openai-base-url}}` を使用してください。
- **ワークロードで選ぶ**：複雑な作業には `gpt-5.6-sol`、日常開発には `gpt-5.6-terra`、軽量または費用重視のリクエストには `gpt-5.6-luna` から始めてください。

## 設定ガイダンス

Codex またはその他の OpenAI 互換ツールでは、該当するセットアップガイドに従ってください。

- **Base URL**：`{{openai-base-url}}`
- **プロバイダー**：**GPT プロバイダー**を選択
- **モデル名**：<a href={"{{model-plaza-url}}"}>モデル広場</a>から現在のモデル ID をコピー

<Note>
  モデル広場に表示されていないモデル名をハードコードしないでください。モデルの提供状況、価格、ルーティング状態は、最新の<a href={"{{model-plaza-url}}"}>モデル広場</a>に従います。
</Note>

## クイックスタート

1. BetterToken API Key を作成します。
2. ツールの Base URL に `{{openai-base-url}}` を設定します。
3. モデル広場から、現在の `gpt-5.6-sol`、`gpt-5.6-terra`、または `gpt-5.6-luna` のモデル ID をコピーします。
4. まず小さなコーディングタスクを実行し、その後 Dashboard でリクエスト使用量を確認します。

次のいずれかのセットアップガイドを使用してください。

- [Codex CLI と Codex App のセットアップ](/ja/ai-tools/codex)
- [OpenCode のセットアップ](/ja/ai-tools/opencode)
- [Cline での OpenAI 互換 API のセットアップ](/ja/faq/cline/openai-compatible-api)

## 選び方

どこから始めるべきか分からない場合は、タスクの複雑さで選んでください。

- 大規模コードベースの理解、複数ファイルの編集、テスト修正、長いデバッグループ、より強い推論が必要なエージェントタスクには `gpt-5.6-sol` を使用します。
- 日常的なコーディング、コードの説明、定型的なリファクタリング、ドキュメント作成、ほとんどの対話的な開発タスクには `gpt-5.6-terra` を使用します。
- 軽量な Q&A、バッチ支援、簡単なテキスト処理、低レイテンシーのツール呼び出し、大量で費用重視のリクエストには `gpt-5.6-luna` を使用します。

## FAQ

### 最初に試すべきモデルはどれですか？

ほとんどの日常的なコーディングでは、`gpt-5.6-terra` から始めてください。タスクにより深い推論が必要な場合は `gpt-5.6-sol` に切り替え、レイテンシーがより重要な場合は `gpt-5.6-luna` を使用します。

### 現在の価格はどこで確認できますか？

最新の<a href={"{{model-plaza-url}}"}>モデル広場</a>で、現在の価格と提供状況を確認してください。価格は変わる可能性があるため、このページには固定で記載していません。

### ツールで「Model not found」と表示された場合はどうすればよいですか？

モデル広場からモデル ID をもう一度コピーし、選択したモデルが GPT プロバイダーで利用可能であることと、`{{openai-base-url}}` を確認してください。さらに確認するには、[モデル選択ガイド](/ja/faq/model-calling/model-selection-guide)を参照してください。
