リリース日: 2026年9月22日

OpenAI は Astra に加え、GPT-6 ファミリーに Sol と Luna を追加しました。Sol は複雑なコーディングや Agent ワークフロー向け、Luna は明確で反復的な大量処理向けです。OpenAI によると、両モデルは GPT-5.6 世代よりコーディング、事実の正確さ、説明の明瞭さが向上しています。

BetterToken で **GPT-6 Sol** と **GPT-6 Luna** を利用できます。`GPT` プロバイダー、Base URL `{{openai-base-url}}` を設定し、`gpt-6-sol` または `gpt-6-luna` を指定します。公式名称は **Sol** であり、`Sora` ではありません。

最新の提供状況と価格は <a href={"{{model-plaza-url}}"}>model plaza</a> で確認してください。

## モデルの選び方

- **`gpt-6-sol`**: 複雑なコーディングや Agent ワークフロー向けです。
- **`gpt-6-luna`**: 明確で反復的な大量処理向けです。

## 主な特長

- **大きなコンテキスト**: OpenAI は両モデルについて、`1,050,000` tokens のコンテキストと最大 `128,000` tokens の出力を記載しています。
- **調整できる推論強度**: 両モデルとも `none`、`low`、`medium`、`high`、`xhigh`、`max` に対応します。
- **作業品質**: OpenAI は GPT-5.6 世代と比べて、コーディング、事実の正確さ、技術的な説明が改善したと報告しています。

## 接続方法

1. <a href={"{{register-url}}"}>BetterToken API Key を作成</a>します。
2. `GPT` と `{{openai-base-url}}` を設定します。
3. 高度な Agent には `gpt-6-sol`、反復的な大量処理には `gpt-6-luna` を使います。
