リリース日：2026 年 4 月 24 日

BetterToken は `GPT-5.5` のモデルエントリーを更新しました。<a href={"{{model-plaza-url}}"}>モデル広場</a>で現在利用可能な **GPT プロバイダー**のモデル ID を確認してから、該当するセットアップガイドを通じて Codex、OpenCode、OpenClaw、Cursor、Cline、Zed、その他の外部ツールで設定してください。

OpenAI は 2026 年 4 月 23 日に GPT-5.5 を正式発表し、複雑な実世界の作業に向けたモデルとして説明しました。OpenAI は、エージェント型コーディング、コンピューターの利用、ナレッジワーク、科学研究のワークフローの強化を強調しています。このモデルは、より早く意図を理解し、より効果的に計画し、ツールを使い、結果を確認し、複数ステップのタスクを継続するよう設計されています。

## 主な特徴

- **コーディングエージェント性能の強化**：OpenAI は、Terminal-Bench 2.0 や SWE-Bench Pro などのコーディング・エージェントベンチマークで、GPT-5.4 を上回る改善を報告しています。
- **長いタスクの信頼性向上**：実装、デバッグ、検証、ドキュメント作成を組み合わせるワークフローにより適しています。
- **より積極的なツール利用**：OpenAI は、ツール利用、出力確認、曖昧なタスクの進行における強化を強調しています。
- **高い効率**：OpenAI によると、GPT-5.5 は Codex タスクでより少ない Token を使いながら、GPT-5.4 レベルのレイテンシーを維持します。

## 設定ガイダンス

Codex と外部ツールでは、<a href={"{{model-plaza-url}}"}>モデル広場</a>から現在の **GPT プロバイダー**のモデル ID をコピーしてください。そこに表示されていないモデル名をハードコードしないでください。

Codex のバージョンで API モードの `gpt-5.5` を選択できない場合は、[Codex が API モードで GPT-5.5 を使用できない理由](/ja/faq/codex/gpt-5.5-api-mode)を参照してください。
