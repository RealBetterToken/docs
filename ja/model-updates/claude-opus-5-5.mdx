リリース日: 2026年9月22日

Claude Opus 5.5 は、Anthropic が発表した Claude 5.5 ファミリー最初のモデルです。Anthropic によると、Opus 5 と比べて長時間のコーディングや専門業務に強く、長い作業セッションでも説明がより明確になっています。

**Claude Opus 5.5** を BetterToken で利用できます。`Claude` プロバイダーを選び、Base URL を `{{anthropic-base-url}}` に設定して、Model ID に `claude-opus-5-5` を指定してください。最新の提供状況と価格は <a href={"{{model-plaza-url}}"}>model plaza</a> で確認できます。

## 主な特長

- 複雑なリポジトリ変更、監査、長時間の Agent タスク。
- 本番向けコード、複雑な文書、computer use。
- 長いセッションでの明確な説明。Anthropic は Opus 5 よりも伝わりやすい回答になったと説明しています。

## 接続方法

1. <a href={"{{register-url}}"}>BetterToken API Key を作成</a>します。
2. `Claude` と `{{anthropic-base-url}}` を設定します。
3. Model ID に `claude-opus-5-5` を指定します。
