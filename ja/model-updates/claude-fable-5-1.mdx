BetterToken で **Claude Fable 5.1** が利用可能になりました。正確な Model ID は `claude-fable-5-1` です。現在の提供状況と価格を<a href={"{{model-plaza-url}}"}>モデル広場</a>で確認し、対応クライアントにこの ID を設定してください。

## 提供情報

- **モデル**：Claude Fable 5.1
- **Model ID**：`claude-fable-5-1`
- **提供状況と価格**：モデル広場の最新情報を確認

## Claude Fable 5.1 を設定する

1. BetterToken API Key を作成するか、既存 Key の **Setup** を開きます。
2. モデル広場から `claude-fable-5-1` をコピーします。
3. クライアントの設定ガイドを開き、BetterToken API Key、必要な Base URL、正確な Model ID を入力します。
4. モデル一覧が自動更新されない場合はクライアントを再起動します。
5. 短いテストリクエストを送信し、Dashboard で確認します。

- [Claude Desktop の設定](/ja/faq/claude-desktop-bettertoken-api)

## Model not found を解決する

Model ID が正確に `claude-fable-5-1` であること、BetterToken API Key がモデルを利用できること、Base URL がクライアントガイドと一致することを確認してください。クライアントを再起動して再度テストします。
