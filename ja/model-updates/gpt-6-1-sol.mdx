更新日：2026 年 9 月 30 日

**GPT-6.1 Sol** は GPT-6 Sol の改良版です。OpenAI によると、エージェントを使ったコーディング、コンピューター操作、専門的な作業で性能が向上し、一部の評価では GPT-6 Astra に近づいています。難しいタスクでは、自分のワークフローで品質、応答時間、トークン使用量を比較してください。

BetterToken での Model ID は `gpt-6.1-sol` です。現在の利用可否と料金は <a href={"{{model-plaza-url}}"}>model plaza</a> で確認してください。

## 主な特徴

- **コーディングとエージェント**：複数ファイルの変更、デバッグ、長時間のソフトウェア開発タスクに適しています。
- **アプリ操作と文書作業**：OpenAI は、これらの作業で GPT-6 Sol より改善したと報告しています。
- **長いコンテキスト**：OpenAI が示すコンテキストウィンドウは `1,050,000` トークン、最大出力は `128,000` トークンです。クライアントや接続経路によって上限が低くなる場合があります。
- **調整可能な推論**：`low`、`medium`、`high`、`xhigh`、`max` に対応し、`none` と `minimal` には対応しません。

## 接続方法

1. <a href={"{{register-url}}"}>BetterToken API Key を作成</a>します。
2. Codex CLI や OpenAI 互換クライアントでは、Base URL に `{{openai-base-url}}`、Model ID に `gpt-6.1-sol` を指定します。
3. ツール呼び出しが必要な場合は [Responses API](/ja/api-reference/responses) を使います。OpenAI の文書では、このモデルの Chat Completions はツール呼び出しなしでの対応です。
4. 既存のワークフローを切り替える前に、代表的なタスクで試してください。

Claude Code では Anthropic プロトコルの Base URL `{{anthropic-base-url}}` と同じ Model ID を使用します。詳しくは [Claude Code の設定](/ja/ai-tools/claude-code) と [Codex CLI の設定](/ja/ai-tools/codex) を参照してください。
