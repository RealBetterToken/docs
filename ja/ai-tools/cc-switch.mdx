CC Switch は Claude Code、Claude Desktop、Codex CLI、OpenCode、OpenClaw の API Key、接続先、モデル設定を管理する任意のデスクトップアプリです。

## CC Switch をインストールする

<Tabs>
  <Tab title="macOS">
    Homebrew が最も簡単な方法です。[GitHub Releases](https://github.com/farion1231/cc-switch/releases) から最新の `.dmg` または `.zip` をダウンロードすることもできます。

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    [GitHub Releases](https://github.com/farion1231/cc-switch/releases) から最新の `CC-Switch-v{version}-Windows.msi` インストーラーまたはポータブル版 `.zip` をダウンロードします。
  </Tab>
  <Tab title="Linux">
    [GitHub Releases](https://github.com/farion1231/cc-switch/releases) から最新の `.deb`、`.rpm`、または `.AppImage` をダウンロードします。
  </Tab>
</Tabs>

## 準備するもの

- BetterToken API Key（<a href={"{{register-url}}"}>登録して取得</a>）
- Claude Code は Anthropic プロトコルを使用するため、`Base URL` は `{{anthropic-base-url}}` です
- Codex、OpenCode、OpenClaw は OpenAI 互換プロトコルを使用するため、`Base URL` は `{{openai-base-url}}` です
- Codex、OpenCode、OpenClaw 用に現在のモデル ID を 1 つ用意します。<a href={"{{model-plaza-url}}"}>BetterToken モデル広場</a>からコピーするか、CC Switch に `/v1/models` から取得させます

<Info>
  初回起動時に、CC Switch はマシン上ですでに見つかった設定を自動的にインポートします。公式プロバイダーをフォールバックとして残し、BetterToken を並行して追加できます。
</Info>

<Note>
  BetterToken には Anthropic と OpenAI 互換という 2 つのアクセス方式があります。`{{anthropic-base-url}}` と `{{openai-base-url}}` を混同しないため、Claude Code と OpenAI 互換ツールを 1 つの汎用プロバイダーにまとめようとせず、アプリごとにプロバイダーを作成することをおすすめします。
</Note>

## BetterToken プロバイダーを追加する

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    CC Switch で **Claude Code** を選び、**Add Provider** をクリックしてください。

    BetterToken API Key、Base URL `{{anthropic-base-url}}`、使用する Model ID を設定して Claude Code に接続します。

    - **Provider Name**: `BetterToken`
    - **API Key**: `YOUR_API_KEY`
    - **API Endpoint**: `{{anthropic-base-url}}`

    Anthropic Messages API 形式を使用します。**Model Mapping** に選択した Model ID を入力して保存します。

    <a href={"{{model-plaza-url}}"}>モデル広場</a>から正確な Model ID をコピーしてください。

    設定を保存して BetterToken を有効にし、クライアントを完全に再起動します。
  </Tab>

  <Tab title="Claude Desktop" id="claude-desktop">
    Claude Desktop で使用できるのは Claude モデルのみです。これは Claude Desktop クライアントの制限です。

    [Claude Desktop ガイド](/ja/faq/claude-desktop-bettertoken-api)に従い、**Gateway**、Base URL `{{anthropic-base-url}}`、BetterToken API Key、**Gateway auth scheme** `x-api-key` を設定します。**Apply locally** で保存し、Claude Desktop を完全に再起動してください。
  </Tab>

        スクリーンショットの番号はこれらの操作に対応します。

      <Step title="CC Switch で OpenCode を開き、プロバイダーを追加する">
        CC Switch を開き、**OpenCode** に切り替えて **Add Provider** をクリックします。CC Switch が最初にプリセットを求める場合は、**OpenAI Compatible** または **Custom** を選択してください。

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: BetterToken API Key
        - **API Format**: `OpenAI Compatible`
      </Step>

      <Step title="デフォルトモデルを選択する">
        可能な場合は **Fetch Models** を使用します。モデルを手動で入力する必要がある場合は、<a href={"{{model-plaza-url}}"}>BetterToken モデル広場</a>にある現在のモデル ID を使用します。

        OpenCode は保存されたプロバイダー設定を直接読み込むため、CC Switch proxy は不要です。
      </Step>

      <Step title="保存して切り替える">
        プロバイダーを保存し、OpenCode を BetterToken に切り替えます。
      </Step>

  <Tab title="OpenClaw" id="openclaw">
    <Steps>
      <Step title="CC Switch で OpenClaw を開き、プロバイダーを追加する">
        CC Switch を開き、**OpenClaw** に切り替えて **Add Provider** をクリックします。CC Switch が最初にプリセットを求める場合は、**OpenAI Compatible** または **Custom** を選択してください。
      </Step>

      <Step title="基本項目を入力する">
        - **Provider Name**: `BetterToken`
        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: BetterToken API Key
        - **API Format**: `OpenAI Responses API`

        カスタム OpenClaw プロバイダー設定を編集する場合は、`api` が `openai-responses` に設定されていることを確認します。
      </Step>

      <Step title="デフォルトモデルを選択する">
        可能な場合は **Fetch Models** を使用します。モデルを手動で入力する必要がある場合は、現在のモデル ID を使用します。

        OpenClaw は保存されたプロバイダー設定を直接使用するため、CC Switch proxy は不要です。
      </Step>

## 保存した変更を反映する

保存してプロバイダーを切り替えた後、設定を確認する前に対象のクライアントまたは Gateway を再起動します。

- Claude Code：現在の Claude Code セッションを完全に終了してから、もう一度起動します。
- Claude Desktop：アプリを完全に終了して開き直し、左下に **Gateway** が表示されることを確認します。
- Codex：現在の Codex プロセスを再起動するか、新しいターミナルセッションを開きます。
- OpenCode：現在の OpenCode セッションを終了してから、もう一度起動します。
- OpenClaw：`openclaw gateway restart` を実行してから、Discord で `/new`、`/status`、`/model` を使用します。

## CC Switch 固有の高度な機能

CC Switch は、サードパーティプロバイダーに切り替えても公式 Codex ログインを保持し、公式とサードパーティのセッションを 1 つの履歴にまとめられます。これらのオプションを有効にした後は Codex を再起動してください。[公式 Codex ログインと統合セッション履歴を維持する](/ja/faq/codex/official-login-third-party-api)も参照してください。

## よくある問題

- Claude Code では、`/v1` を `Base URL` に追加しないでください

- Claude Desktop で Claude プロバイダー以外を使用する場合、**CC Switch proxy** を有効にし、アプリを完全に再起動します
- Codex、OpenCode、OpenClaw は `{{openai-base-url}}` を使用します
- Codex、OpenCode、OpenClaw でモデルを求められた場合は、モデル ID を使用します
- **Fetch Models** が失敗する場合は、API Key と `Base URL` を確認してからモデル ID を手動で貼り付けます
- 切り替えが反映されない場合は、CC Switch で BetterToken がアクティブなプロバイダーであることを確認し、上記の説明どおりに対象のクライアントまたは Gateway を再起動します
