「Grok CLI」は、現在 2 つの異なるツールを指します。

- **Grok Build** — xAI 公式の coding agent。
- **コミュニティ版 Grok CLI** — xAI と提携していないオープンソースプロジェクト。

どちらも BetterToken で検証済みです。BetterToken API Key、Base URL、Model ID を使い、両方のクライアントでモデル応答を確認しました。このガイドでは設定が直接的な**コミュニティ版 Grok CLI**を先に説明します。

<Warning>どちらも `grok` コマンドを使います。両方をインストールすると、`PATH` で先に見つかったバージョンが実行されます。</Warning>

## Grok CLI と Grok Build の違い

| 項目 | 公式 Grok Build | コミュニティ版 Grok CLI |
| --- | --- | --- |
| 開発元 | xAI | `superagent-ai/grok-cli`、xAI とは無関係 |
| 認証 | ブラウザログインまたは `XAI_API_KEY` | `GROK_API_KEY` |
| カスタム Base URL | `~/.grok/config.toml` | `GROK_BASE_URL` |
| モデル | 設定内の alias | `GROK_MODEL` |
| BetterToken 経由のモデル呼び出し | 検証済み | 検証済み |
| コマンド | `grok` | `grok` |

検証範囲はテキストおよびコードモデルのリクエストです。ツール呼び出しや xAI 固有 API は含みません。

## コミュニティ版 Grok CLI を BetterToken で使う

次のコマンドは macOS、Linux、WSL 向けです。コミュニティ版の Windows ネイティブ環境は未検証です。

### インストール

```bash
curl -fsSL https://raw.githubusercontent.com/superagent-ai/grok-cli/main/install.sh | bash
grok --version
```

Bun がインストール済みの場合：

```bash
bun add -g grok-dev
```

### BetterToken を設定

```bash
export GROK_BASE_URL="{{openai-base-url}}"
export GROK_API_KEY="YOUR_API_KEY"
export GROK_MODEL="YOUR_MODEL_ID"
```

`YOUR_MODEL_ID` を<a href={"{{model-plaza-url}}"}>モデル広場</a>の完全な Model ID に置き換え、<a href={"{{register-url}}"}>BetterToken API Key</a>を使います。

### 接続を確認

```bash
grok -p "Reply with only: OK"
```

モデル応答が返った場合のみ、API Key、Base URL、Model ID が有効だと確認できます。環境変数を変更したら再起動してください。

## 公式 Grok Build

[Grok Build](https://docs.x.ai/build/overview) は xAI 公式のターミナル coding agent です。

### インストールとログイン

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    grok --version
    ```
  </Tab>
</Tabs>

初回起動時はブラウザが開きます。ブラウザのない環境では次を使います。

```bash
export XAI_API_KEY="YOUR_XAI_API_KEY"
grok
```

### Grok Build で BetterToken を設定

```toml
[model.bettertoken]
model = "YOUR_MODEL_ID"
base_url = "{{openai-base-url}}"
name = "BetterToken"
env_key = "BETTERTOKEN_API_KEY"
api_backend = "chat_completions"

[models]
default = "bettertoken"
```

`BETTERTOKEN_API_KEY` は例として付けた変数名です。Grok Build は `env_key` で指定した変数を読み取ります。

```bash
export BETTERTOKEN_API_KEY="YOUR_API_KEY"
grok inspect
grok -p "Reply with only: OK" -m bettertoken
```

<Note>この設定で Grok Build から BetterToken 経由のモデル応答を確認しました。ツール呼び出しと xAI 固有 API は未検証です。</Note>

## よくあるエラー

| 問題 | 確認事項 |
| --- | --- |
| 別のクライアントが起動する | 各 `grok` のパスとバージョンを確認します。 |
| `401` または `Unauthorized` | コミュニティ版は `GROK_API_KEY`、Grok Build は `env_key` の変数を読みます。 |
| `model not found` | モデル広場から完全な Model ID をコピーし、再起動します。 |
| xAI に送信される | `GROK_BASE_URL` を確認するか、Grok Build で `grok inspect` を実行します。 |

## モデルと機能の制限

<a href={"{{model-plaza-url}}"}>モデル広場</a>の OpenAI-compatible な完全な Model ID を使用してください。X Search、音声、画像、動画などの xAI 固有 API は対象外です。
