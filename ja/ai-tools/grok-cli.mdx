Grok CLI を BetterToken に接続するには、API Key を用意し、以下の Base URL を入力して、モデル広場から現在の Model ID を選択します。

## 主要な設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>モデル広場</a>にある現在の Model ID |

## 前提条件

- 現在のバージョンのツールがインストールされている
- BetterToken API Key：<a href={"{{register-url}}"}>登録して取得</a>
- <a href={"{{model-plaza-url}}"}>モデル広場</a>の Model ID

## インストール

### Grok CLI をインストールする

Windows、macOS、Linux で次を実行します。

```bash
npm install -g @vibe-kit/grok-cli
```

インストール後に `grok` が見つからない場合は、ターミナルを閉じて開き直し、`grok --help` を実行します。グローバル `npm` パッケージディレクトリが `PATH` に含まれていることを確認してください。

## 手動設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>モデル広場</a>にある現在の Model ID |

### 必要なもの

- Node.js と `npm`
- BetterToken API Key：<a href={"{{register-url}}"}>ここで登録</a>
- <a href={"{{model-plaza-url}}"}>モデル広場</a>にある現在利用可能な**対応プロバイダーのモデル ID**

### Base URL と API Key を設定する

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="競合する変数を削除する">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="BetterToken 変数を設定する">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="モデルを指定して Grok CLI を起動する">
        ```bash
        grok --model YOUR_MODEL_ID
        ```

        `YOUR_MODEL_ID` を、モデル広場にある現在の**対応プロバイダーのモデル ID**に置き換えます。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="現在の PowerShell ウィンドウの変数を設定する">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="モデルを指定して Grok CLI を起動する">
        ```powershell
        grok --model YOUR_MODEL_ID
        ```

        これらの変数は現在の PowerShell ウィンドウにのみ適用されます。新しいウィンドウを開くときは、チームで承認されたシークレット保存方法で再度設定してください。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 接続を確認する

短いテストプロンプトを送信します。認証または Model ID のエラーなしでツールがレスポンスを返せば、接続は機能しています。設定を変更した後はツールを完全に再起動してください。

Grok CLI の起動後に短いプロンプトを送信します。認証またはモデル ID のエラーなしで応答すれば、接続は準備できています。環境変数を変更したときは、現在の Grok CLI セッションを終了し、新しいセッションを開始してください。

## モデルを切り替える

モデルセレクターを開くか、設定の `Model` フィールドを変更します。<a href={"{{model-plaza-url}}"}>モデル広場</a>にある正確な Model ID を使用してから、現在のセッションを再起動してください。

## よくあるエラー

| 症状 | 確認事項 |
| --- | --- |
| `grok: command not found` | もう一度インストールし、新しいターミナルを開いて `grok --help` を確認します。 |
| `401`、`Unauthorized`、または `Invalid API key` | `GROK_API_KEY` を確認し、余分な空白がコピーされていないことと、変数を設定した同じターミナルで Grok CLI を起動していることを確認します。 |
| `model not found` または利用不可モデル | モデル広場の**対応プロバイダー**から現在のモデル ID をコピーします。Claude プロバイダーの ID は使用しないでください。 |
| リクエストで以前のサービスが使われる | `GROK_BASE_URL` を確認し、`/chat/completions` を追加せずに、ターミナルと Grok CLI を再起動します。 |
| 接続エラー | Base URL が `{{openai-base-url}}` であり、ネットワークから HTTPS 経由で `bettertoken.ai` に到達できることを確認します。 |

### セットアップ FAQ

**Grok CLI ではどの Base URL を使用すべきですか？**

`{{openai-base-url}}` を使用します。これは BetterToken の OpenAI 互換 Base URL です。

**どの API Key とモデルを選択すべきですか？**

BetterToken API Key と、同じグループのモデルを使用します。

**システムプロキシを変更したり VPN を有効にしたりする必要がありますか？**

いいえ。ターミナルで Base URL と API Key を設定して BetterToken に接続します。
