Hermes Agent を BetterToken に接続するには、API Key を用意し、以下の Base URL を入力して、モデル広場から現在の Model ID を選択します。

## 主要な設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>モデル広場</a>にある現在の Model ID |

## 前提条件

- 現在のバージョンのツールがインストールされている
- BetterToken API Key：<a href={"{{register-url}}"}>登録して取得</a>
- <a href={"{{model-plaza-url}}"}>モデル広場</a>の Model ID

### 追加要件

- 選択した Model ID が**対応プロバイダー**のものである
- macOS、Linux、Windows 10/11、または WSL2
- ツールを使うモデルには 64K 以上のコンテキストウィンドウが必要

## インストール

### Hermes Agent をインストールする

<Tabs>
  <Tab title="Desktop（macOS / Windows）">
    Hermes は macOS と Windows では Desktop インストーラーを推奨しています。[Hermes Desktop をダウンロード](https://hermes-agent.nousresearch.com/)し、OS に対応するインストーラーを実行します。
  </Tab>

  <Tab title="Linux / macOS / WSL2">
    ```bash
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    ```

    インストール後、新しいターミナルを開くか shell を再読み込みしてから `hermes` を実行します。
  </Tab>

  <Tab title="Windows PowerShell">
    Hermes Agent は Windows 10 と Windows 11 をネイティブでサポートします。PowerShell または Windows Terminal で次を実行します。

    ```powershell
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)
    ```

    管理者権限は不要です。インストール後は新しい PowerShell ウィンドウを開き、更新された User PATH を読み込みます。
  </Tab>
</Tabs>

```bash
hermes --version
hermes doctor
```

<Note>WSL2 もサポートされますが必須ではありません。Linux 環境または Web Dashboard の埋め込みターミナルが必要な場合に選択してください。</Note>

### 機能のクイックリファレンス

| 機能 | 用途 |
| --- | --- |
| Terminal UI | ターミナルでエージェントと直接チャット |
| Skills | 繰り返すタスクのための再利用可能なワークフローを保存 |
| MCP | ローカルまたはリモートのツール機能を接続 |
| Scheduled tasks | 時刻指定のジョブと定期ワークフローを実行 |
| Subagents | 複雑な作業を焦点を絞ったエージェントに分割 |
| Message gateway | より多くのメッセージ入口にエージェントを接続 |

## 手動設定

Hermes Agent の対話型モデル設定を主な方法として使用します。手動設定が必要な場合のみ、設定ファイルを直接編集します。

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>モデル広場</a>にある現在の Model ID |

### 設定手順

<Tabs>
  <Tab title="対話型設定">
    <Steps>
      <Step title="モデルセレクターを実行する">
        実行中の Hermes チャットを終了してから次を実行します。

        ```bash
        hermes model
        ```
      </Step>

      <Step title="Custom endpoint を選択する">
        プロバイダー一覧から **Custom endpoint (self-hosted / VLLM / etc.)** を選択します。
      </Step>

      <Step title="BetterToken の設定を入力する">
        次を入力します。

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**：BetterToken API Key
        - **Model**：<a href={"{{model-plaza-url}}"}>モデル広場</a>からコピーした、**対応プロバイダーのモデル ID**

        API mode を聞かれた場合は OpenAI-compatible Chat Completions を選択します。context length はモデルの公開値を使い、64K 以上であることを確認します。
      </Step>

      <Step title="Hermes Agent を起動する">
        ```bash
        hermes --tui
        ```

        クラシックなターミナル UI を使う場合は `hermes` を実行します。
      </Step>
    </Steps>
  </Tab>

  <Tab title="設定ファイル">
    対話型設定では endpoint が検証されて保存されます。手動で設定する場合は `~/.hermes/config.yaml` にモデル設定を追加します。

    ```yaml
    model:
      default: YOUR_MODEL_ID
      provider: custom
      base_url: "{{openai-base-url}}"
    ```

    API Key は `~/.hermes/.env` に分けて保存します。

    ```dotenv
    OPENAI_API_KEY=YOUR_API_KEY
    ```

    ネイティブ Windows では、これらのファイルは `%LOCALAPPDATA%\hermes\` にあります。値を置き換えた後、`hermes doctor` を実行します。
  </Tab>
</Tabs>

### OpenClaw から移行する

すでに OpenClaw を使用している場合は、まず現在の Hermes Agent バージョンで移行コマンドが提供されているか確認します。変更前にドライランを実行してください。

```bash
hermes claw migrate --dry-run
```

出力を確認したら、移行を実行します。

```bash
hermes claw migrate
```

移行後も、Hermes Agent の **Base URL**、API Key、モデル ID を確認してください。これらは `{{openai-base-url}}`、BetterToken API Key、対応プロバイダーのモデル ID と一致している必要があります。

## 接続を確認する

`hermes --tui` または `hermes` を起動し、`Reply with HERMES_OK only. Do not use tools.` と送信します。認証、endpoint、Model ID のエラーなしで `HERMES_OK` が返れば接続は成功です。

## モデルを切り替える

プロバイダーの追加や再設定には、チャット外で `hermes model` を実行します。チャット内では `/model` を使い、設定済みのプロバイダーとモデルを切り替えます。

## よくあるエラー

| エラー | 確認事項 |
| --- | --- |
| `401` または `Unauthorized` | BetterToken API Key を確認し、先頭または末尾の空白を削除します。 |
| `404` | Base URL を確認し、特定の Endpoint パスを追加しないでください。 |
| `model not found` | モデル広場から現在の Model ID をコピーします。 |
| 変更が反映されない | 設定を保存して、ツールを完全に再起動します。 |


### トラブルシューティング

- リクエストが失敗する、またはレスポンスが返らない場合は、**Base URL** が正確に `{{openai-base-url}}` であることを確認します。このフィールドに `/chat/completions` を追加しないでください。
- Hermes がモデルが存在しないと報告する場合は、**Model** が<a href={"{{model-plaza-url}}"}>モデル広場</a>にある対応プロバイダーのモデル ID であることを確認します。
- 認証に失敗する場合は、コピーした空白を確認し、選択した Model ID が**対応プロバイダー**のものであることを確認します。
- 変更後も Hermes が古いモデルを使用する場合は、現在の Hermes Agent セッションを終了して `hermes` を再度実行します。
- BetterToken では通常、追加の `User-Agent` やカスタムヘッダーは必要ありません。カスタムゲートウェイ、テナントルーティング、可観測性、キャッシュレイヤーで明示的に要求される場合にのみヘッダーを追加してください。

<Note>
  実際の API Key をリポジトリにコミットしないでください。チームで共有する設定には、環境変数またはローカル設定を優先してください。
</Note>
