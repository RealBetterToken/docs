GitHub Copilot を BetterToken に接続するには、API Key を用意し、以下の Base URL を入力して、model plaza から現在利用可能な Model ID を選択します。

## 主要設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| 完全なリクエスト URL | `{{chat-completions-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>model plaza</a> の現在利用可能な Model ID |

## 事前準備

- 現在のツールバージョンがインストール済みであること
- BetterToken API Key：<a href={"{{register-url}}"}>登録して取得</a>
- <a href={"{{model-plaza-url}}"}>model plaza</a> の Model ID

### 追加要件

- 最新の VS Code がインストール済みであること
- GitHub Copilot / Copilot Chat がインストール済みでログインしていること
- 選択する Model ID が**対応プロバイダー**のものであること
- たとえば `YOUR_MODEL_ID` のような Model ID を用意すること

<Warning>
  実際の API Key を `chatLanguageModels.json` に手入力しないでください。VS Code の API Key プロンプトに貼り付けます。VS Code は `${input:chat.lm.secret...}` のようなローカルシークレット参照を生成します。
</Warning>

## インストール

GitHub Copilot をインストールまたは開いてから、以下の手動設定を続けます。

## 手動設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| 完全なリクエスト URL | `{{chat-completions-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>model plaza</a> の現在利用可能な Model ID |

### 設定手順

<Steps>
  <Step title="モデル管理を開く">
    Copilot Chat の入力欄でモデルセレクターをクリックし、**Manage Models...** を選択します。

    <Frame>
      <img
        src="/images/github-copilot/manage-models-entry.png"
        alt="Copilot Chat のモデルセレクターから Manage Models を開きます。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Custom Endpoint を追加する">
    **Language Models** で **Add Models** をクリックし、**Custom Endpoint** を選択します。

    <Frame>
      <img
        src="/images/github-copilot/add-custom-endpoint.png"
        alt="Language Models で Add Models をクリックし、Custom Endpoint を選択します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="グループ名を入力する">
    **Group Name** に次を入力します。

    ```text
    BetterToken
    ```

    次に **Enter** を押します。

    <Frame>
      <img
        src="/images/github-copilot/group-name.png"
        alt="Group Name の入力欄に BetterToken を入力します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="API Key を入力する">
    VS Code から API Key の入力を求められます。BetterToken API Key を貼り付け、**Enter** を押します。

    この値は設定ファイルに直接表示されません。VS Code はローカルシークレットとして保存し、次のような参照を生成します。

    ```json
    "apiKey": "${input:chat.lm.secret.xxxxx}"
    ```

    <Warning>
      `${input:chat.lm.secret...}` を実際の API Key に置き換えないでください。VS Code が生成したシークレット参照を保持します。
    </Warning>
  </Step>

  <Step title="API タイプを選択する">
    **Custom Endpoint: API Type** で **Chat Completions** を選択します。

    <Frame>
      <img
        src="/images/github-copilot/select-chat-completions.png"
        alt="Custom Endpoint API Type で Chat Completions を選択します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="JSON 設定を編集する">
    VS Code で `chatLanguageModels.json` が開きます。設定内容を確認し、必要に応じて更新します。

    <Frame>
      <img
        src="/images/github-copilot/chat-language-models-json.png"
        alt="chatLanguageModels.json で BetterToken のモデル URL、toolCalling、vision、トークン上限を設定します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    ```json
    [
      {
        "name": "BetterToken",
        "vendor": "customendpoint",
        "apiKey": "${input:chat.lm.secret.xxxxx}",
        "apiType": "chat-completions",
        "models": [
          {
            "id": "YOUR_MODEL_ID",
            "name": "YOUR_MODEL_ID",
            "url": "{{chat-completions-url}}",
            "toolCalling": true,
            "vision": true,
            "maxInputTokens": 1000000,
            "maxOutputTokens": 64000
          }
        ]
      }
    ]
    ```

    次の項目を確認します。

    | 項目 | 推奨値 |
    | --- | --- |
    | `name` | `BetterToken` |
    | `apiType` | `chat-completions` |
    | `id` | `YOUR_MODEL_ID`、または<a href={"{{model-plaza-url}}"}>モデル広場</a>にある対応プロバイダーのモデル ID |
    | `name` | モデル ID と同じ値 |
    | `url` | `{{chat-completions-url}}` |
    | `toolCalling` | `true` |
    | `vision` | `true` |
    | `maxInputTokens` | `1000000` |
    | `maxOutputTokens` | `64000` |
  </Step>

  <Step title="保存して VS Code を再読み込みする">
    `chatLanguageModels.json` を保存してから、次を実行します。

    ```text
    Developer: Reload Window
    ```

    再読み込み後、Copilot Chat のモデルセレクターに戻り、`YOUR_MODEL_ID` を選択します。
  </Step>

  <Step title="テストメッセージを送信する">
    Copilot Chat で簡単なメッセージを送信します。

    ```text
    Describe the model you are using in one sentence.
    ```

    Copilot Chat が正常に応答すれば、BetterToken Custom Endpoint の設定は完了です。
  </Step>
</Steps>

## 接続を確認する

短いテストプロンプトを送信します。認証エラーやモデル ID エラーが出ずに応答が返れば、接続は成功しています。設定を変更した後は、ツールを完全に再起動してください。

## モデルを切り替える

モデルセレクターを開くか、設定内の `Model` 項目を変更します。<a href={"{{model-plaza-url}}"}>モデル広場</a>に表示される正確なモデル ID を使用し、現在のセッションを再起動します。

## よくあるエラー

### API Key を入力画面に入力する理由は何ですか？

VS Code は API Key をローカルのシークレットストレージに保存し、JSON では `${input:chat.lm.secret...}` として参照します。実際の API Key を JSON ファイルに書き込むより安全です。

### Chat Completions を使用する理由は何ですか？

動作確認済みの設定では **Chat Completions** を使用します。URL は次のとおりです。

```text
{{chat-completions-url}}
```

`/v1/responses` は使用せず、`/v1` だけで終わらせないでください。

### GitHub Copilot のインライン補完も置き換えられますか？

いいえ。この Custom Endpoint は主に Copilot Chat の言語モデル呼び出しに使用します。GitHub Copilot のインライン補完は、引き続き GitHub Copilot 自体から提供されます。

### Invalid token と表示された場合はどうすればよいですか？

次の項目を順番に確認します。

1. VS Code の入力画面で API Key を入力した
2. JSON に `${input:chat.lm.secret...}` の参照が残っている
3. 選択したモデル ID が**対応プロバイダー**のものである
4. `url` が `{{chat-completions-url}}` である
5. `apiType` が `chat-completions` である
6. モデル ID が<a href={"{{model-plaza-url}}"}>モデル広場</a>にある対応プロバイダーのモデルである
