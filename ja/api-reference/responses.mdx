`POST /v1/responses`

この Endpoint は、Codex と OpenAI Responses API を使用するアプリケーションに使用します。

<Note>
  Base URL：`{{openai-base-url}}`。API Key は `Authorization: Bearer YOUR_API_KEY` として渡します。
</Note>

## Playground でテストする

右側の Playground で API Key を入力し、必要に応じて `model` を現在の GPT プロバイダーのモデル ID に置き換え、リクエストを送信します。テスト前に<a href={"{{model-plaza-url}}"}>モデル広場</a>でモデルを確認してください。

<Warning>
  自分のテスト用 API Key だけを使用してください。キーをコード、スクリーンショット、チケット、Git リポジトリに含めないでください。
</Warning>
