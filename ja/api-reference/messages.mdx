`POST /v1/messages`

この Endpoint は、Claude Code、Anthropic SDK、Anthropic Messages API を使用するアプリケーションに使用します。

<Note>
  SDK では `{{anthropic-base-url}}` を Base URL として使用します。手動リクエストと Playground では、完全な `{{anthropic-base-url}}/v1/messages` パスを使用します。
</Note>

## Playground でテストする

右側の Playground で、`x-api-key` フィールドに API Key を入力し、`anthropic-version` は `claude-cli/2.0.76 (external, cli)` のままにして、利用可能な Claude プロバイダーのモデルを選び、リクエストを送信します。

<Warning>
  この Endpoint に `Authorization: Bearer ...` を使用しないでください。`x-api-key` ヘッダーが必要です。
</Warning>
