BetterToken は OpenAI-compatible Chat Completions と Responses API、および Anthropic-compatible Messages API を提供します。クライアントで使用する API 形式を選んでください。

## API を選択する

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/ja/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/ja/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/ja/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/ja/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/ja/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Chat Completions の接続情報

| 項目 | 値 |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| 完全なリクエスト URL | `{{chat-completions-url}}` |
| メソッド | `POST` |
| 認証 | `Bearer YOUR_API_KEY` |
| モデル | `YOUR_MODEL_ID` |

現在の Model ID は、<a href={"{{model-plaza-url}}"}>model plaza</a> または Console の API Key **Setup** ダイアログからコピーします。

<Warning>
  外部ツールで **Base URL** を求められた場合は、`{{openai-base-url}}` を入力します。`{{chat-completions-url}}` は、完全なリクエスト URL を明示的に求められた場合だけ使ってください。
</Warning>

## 簡単なテスト

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

成功したレスポンスには `choices[0].message.content` が含まれます。

## 対話型テストと SDK の例

[OpenAI Chat Completions API](/ja/api-reference/chat-completions) を開くと、次の操作ができます。

- Playground からリクエストを送信する
- リクエストパラメーターとレスポンススキーマを確認する
- curl、Python、JavaScript の例をコピーする

<Note>
  実際の API Key をドキュメント、スクリーンショット、公開コードに保存しないでください。`YOUR_API_KEY` と `YOUR_MODEL_ID` は実際の値に置き換えます。
</Note>
