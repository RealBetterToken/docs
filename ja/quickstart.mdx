title: "クイックスタート"
description: "4 ステップで BetterToken アカウントの登録、残高追加、API Key の作成を完了し、Claude Code、Codex CLI、その他の外部ツールに対応する設定ガイドへ進みます。"
---

<Steps>
  <Step title="アカウントを作成する">
    <a href={"{{register-url}}"}>BetterToken の登録ページ</a>にアクセスして、アカウントを作成します。

    登録後、BetterToken API Key を作成する前に残高をチャージしてください。
  </Step>
  <Step title="アカウントに残高を追加する">
    **オンラインチャージ**または**引き換えコード**を利用できます。残高を追加したらコンソールに戻り、**Current balance** が更新されたことを確認してから API Key を作成します。

    <Tabs>
      <Tab title="オンラインチャージ">
        サインインして **Console** を開きます。**Current balance** カードでチャージする通貨を選び、対応する **Top up** ボタンをクリックします。

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="BetterToken Console の Current balance カードにある USD と RUB の Top up ボタン。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        画面の案内に沿って支払いを完了します。支払いが完了したらコンソールに戻り、**Current balance** が更新されたことを確認します。
      </Tab>
      <Tab title="引き換えコード">
        サインインして **Console** を開き、**Current balance** カードの左下にある **Redeem code** をクリックします。

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="BetterToken Console の Current balance カードで、左下の Redeem code ボタンを矢印が示している画面。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        ダイアログに引き換えコードを入力し、**Redeem** をクリックします。

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="コード入力欄と Redeem ボタンがある Redeem code ダイアログ。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        コードを引き換えたらコンソールに戻り、**Current balance** が更新されたことを確認します。
      </Tab>
    </Tabs>
  </Step>
  <Step title="API Key 管理を開いて API Key を作成する">
    利用可能な残高があることを確認し、コンソールの **Your API keys** セクション右上にある **Create API key** をクリックします。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="BetterToken Console の Your API keys セクションで、右上の Create API key ボタンを矢印が示している画面。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    **Create API Key** で **API key name** を入力します。有効期限や利用上限を設定する場合は **Advanced settings** を開き、**Create API Key** をクリックします。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="API key name、Advanced settings、Create API Key ボタンがある Create API Key ダイアログ。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="接続情報または設定コードをコピーする">
    Key を作成したら、**Set up API key** の **Connection details** で **API Key** をコピーします。利用するプロトコルに合わせて **OpenAI** または **Anthropic** を選び、対応する **Base URL** をコピーします。

    または、下の **Configuration guide** でツールか **API call** を選び、必要に応じて API とサンプルモデルを選択して、表示されたコードをコピーします。詳しい手順は **View tool documentation** または以下のガイドを参照してください。最後に **Finish** をクリックします。

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="上部で API Key と Base URL をコピーでき、下部にツールとコードの Configuration guide がある Set up API key ダイアログ。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
