BetterToken を OpenAI 互換プロバイダーとして接続し、OpenCode で GLM を使用します。BetterToken API Key、Base URL `https://bettertoken.ai/v1`、Setup ダイアログの GLM Model ID を入力します。

## 重要な設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai/v1` |
| モデル | `YOUR_GLM_MODEL_ID` |

## 事前準備

- 最新の [OpenCode](https://opencode.ai/)。
- <a href={"{{register-url}}"}>BetterToken API Key を作成</a>。
- Setup ダイアログで対象ツールとプロバイダーを選び、利用可能な Model ID をコピーします。

## `/connect` で設定する

```text
/connect
```

`bettertoken/YOUR_GLM_MODEL_ID` を選び、OpenCode を再起動します。

## 手動設定

`~/.config/opencode/opencode.json` または project-level `opencode.json` を開きます。

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_GLM_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "https://bettertoken.ai/v1",
        "apiKey": "YOUR_API_KEY"
      },
      "models": {
        "YOUR_GLM_MODEL_ID": {
          "name": "YOUR_GLM_MODEL_ID"
        }
      }
    }
  }
}
```

`YOUR_API_KEY` と `YOUR_GLM_MODEL_ID` を Setup の値に置き換えます。`baseURL` に `/chat/completions` は追加しません。

## 接続を確認する

OpenCode で `bettertoken/YOUR_GLM_MODEL_ID` を選択して短い prompt を送信します。JSON の変更後は OpenCode を再起動します。

## よくあるエラー

| Error | 項目 |
| --- | --- |
| `401` | `/connect` または `apiKey` を確認します。 |
| `404` | `baseURL` は `https://bettertoken.ai/v1` にします。 |
| Model not found | `model`、`models`、Model ID を Setup と照合します。 |
| Configuration is not applied | `opencode.json` が global file を上書きしていないか確認します。 |
