Codex CLI と Codex App はローカルタスクで `config.toml` と `auth.json` を共有します。この設定では OpenAI Responses 経由で BetterToken API Key を使用します。

`gpt-6-astra` を使う前に Codex を更新してください。

## ファイルの場所を確認してバックアップする

独自の `CODEX_HOME` を設定している場合は、そのディレクトリの `config.toml` と `auth.json` を編集してください。それ以外は macOS / Linux では `~/.codex`、Windows では `%USERPROFILE%\.codex` を使用します。CLI と App は同じディレクトリを使用する必要があります。WSL のユーザーディレクトリは別です。

編集前に Codex を完全に終了し、両方のファイルを非公開の場所にバックアップしてください。ファイルがなければ作成します。既存の設定を置き換え、キーやテーブルを重複して追加しないでください。無関係な設定は残します。

<Warning>
  この設定は ChatGPT ログインから API Key 認証に切り替えます。公式アカウントへのアクセスは維持されません。`auth.json` とバックアップを保護し、共有したりリポジトリにコミットしたりしないでください。
</Warning>

## config.toml を編集する

`model_provider`、`model`、`cli_auth_credentials_store` はプロファイル内ではなく、すべての TOML テーブルより前のトップレベルに記述してください。プロバイダー ID とテーブル名を一致させます。このファイル認証では、選択したプロバイダーから `env_key` と `experimental_bearer_token` を削除してください。

```toml
model_provider = "bettertoken"
model = "gpt-6-astra"
cli_auth_credentials_store = "file"

[model_providers.bettertoken]
name = "BetterToken"
base_url = "{{openai-base-url}}"
wire_api = "responses"
requires_openai_auth = true
request_max_retries = 4
stream_max_retries = 8
stream_idle_timeout_ms = 300000
supports_websockets = false
```

例では GPT-6 Astra（`gpt-6-astra`）を使用します。別のモデルでは、<a href={"{{model-plaza-url}}"}>モデル広場</a>から完全な ID をコピーして `model` を置き換えてください。GPT、Kimi、GLM のファイル認証構造は共通です。自動設定は GPT で利用できます。

## auth.json を編集する

`auth.json` は `config.toml` と同じディレクトリにあります。`auth.json` がない場合は、そのディレクトリに新規作成してください。ファイルの内容を次の JSON にし、`YOUR_API_KEY` を自分の BetterToken API Key に置き換えて保存してください。

```json
{
  "auth_mode": "apikey",
  "OPENAI_API_KEY": "YOUR_API_KEY"
}
```

## 再起動して確認する

両方のファイルを保存し、ターミナルで新しい Codex CLI セッションを直接起動します。

```bash
codex
```

バックグラウンドプロセスを含めて Codex App を完全に終了し、再度開いて新しいローカルタスクを作成してください。使用する各クライアントで短いプロンプトを送信します。正常な応答でそのクライアントの接続を確認してください。

## トラブルシューティング

`401`、`403`、ログイン要求が出た場合は、使用中のディレクトリ、`auth.json` の Key、`auth_mode = apikey`、`cli_auth_credentials_store = file`、`requires_openai_auth = true` を確認してください。プロバイダーやモデルのエラーでは、プロバイダー ID の一致、`{{openai-base-url}}`、`wire_api = responses`、モデルの利用可否を確認します。変更が反映されない場合は設定の上書きを調べ、CLI と App が同じ `CODEX_HOME` を使用していることを確認してください。
