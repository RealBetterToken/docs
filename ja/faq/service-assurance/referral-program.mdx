## 短い回答

紹介プログラムでは、実際の紹介に特典が付与されます。友人を招待し、その友人が初回チャージを完了すると、初回チャージ額の **10%** に相当する紹介特典を受け取れます。

特典はプロダクト内の特典残高として付与され、今後の API リクエスト費用に自動的に使用されます。不審な紹介は手動で審査されます。特典は審査が承認された後に付与されます。

## 紹介プログラムの条件

| 条件 | 説明 |
| --- | --- |
| 1 | 友人を招待します。友人が初回チャージを完了すると、その初回チャージ額の **10%** に相当する紹介特典を受け取れます。 |
| 2 | 特典残高はリクエスト費用の支払いに自動的に使用されます。 |
| 3 | 不審な紹介は手動で審査されます。特典は審査が承認された後に付与されます。 |

## 紹介プログラムの利用方法

1. コンソールにサインインします。
2. アカウントまたは紹介特典の画面から紹介リンクをコピーします。
3. 友人に紹介リンクを送信します。
4. 友人がリンク経由で登録し、初回チャージを完了します。
5. システムが、友人の初回チャージ額の **10%** を特典として計算します。
6. 特典の付与後、今後のリクエスト費用に自動的に使用されます。

友人が紹介リンク経由で登録しない場合、紹介関係が自動作成されないことがあります。スクリーンショットだけを送るのではなく、完全な紹介リンクを共有してください。

## 特典残高の使われ方

特典残高は現金を引き出すためのものではありません。モデルリクエスト費用の支払いに使用する、プロダクト内の残高です。

API リクエストを送信すると、システムはアカウントルールに従って残高と特典残高を適用します。リクエストごとに特典残高を選択する必要はありません。

## 手動審査の対象となる場合

不正利用を防ぐため、次のケースでは手動審査が行われる場合があります。

- 同じデバイスまたはネットワークからの多数の相互紹介
- 異常なチャージ行動、または実在しない利用者の疑い
- 偽アカウント、大量作成されたアカウント、または自動登録
- 自己紹介
- 支払い、アカウント、またはリクエスト行動の間にある異常な関連性

審査が承認された場合、特典は通常どおり付与されます。紹介が不審と判断された場合、特典の付与が遅延、取り消し、または凍結されることがあります。

## FAQ

### 紹介特典の割合はどれくらいですか？

紹介特典は、友人の初回チャージ額の **10%** です。

### 友人がチャージした直後に特典は届きますか？

通常の紹介では、システムルールに従って特典が付与されます。リスク管理または異常な関連性が検出された場合、特典は手動審査の対象となり、承認後に付与されます。

### 特典残高を引き出すことはできますか？

いいえ。特典残高はリクエスト費用の支払いに使用されます。

### 特典残高を手動で適用する必要がありますか？

いいえ。特典残高はリクエスト費用に自動的に使用されます。

## BetterToken について

BetterToken の紹介プログラムは、実際の利用者による紹介を対象としています。紹介特典は API リクエスト費用の一部を補うものであり、チームメンバー、友人、開発者コミュニティとの共有に適しています。
