Claude Desktop で使用できるのは Claude モデルのみです。これは Claude Desktop クライアントの制限です。

## 設定方法

[Claude Desktop ガイド](/ja/faq/claude-desktop-bettertoken-api)に従い、**Gateway**、Base URL `{{anthropic-base-url}}`、BetterToken API Key、**Gateway auth scheme** `x-api-key` を設定します。**Apply locally** で保存し、Claude Desktop を完全に再起動してください。

<a href={"{{model-plaza-url}}"}>モデル広場</a>から正確な Model ID をコピーしてください。

## トラブルシューティング

### 401 / Unauthorized

API Key が正しくコピーされ、有効期限内であることを確認します。この Gateway 設定には `x-api-key` を使用し、保存して Claude Desktop を再起動してください。

### モデル

モデル広場から利用可能な Claude Model ID をコピーし、保存して Claude Desktop を再起動します。
