## 短い答え

BetterToken を Cursor の Custom OpenAI API として接続するには、BetterToken API Key を入力し、Override OpenAI Base URL を有効にして `{{openai-base-url}}` を設定します。次に、モデル広場から現在の GPT モデル ID を追加します。API Key、Base URL、モデル ID はすべて同じプロバイダーに属している必要があります。

## この情報が役立つ場面

- Cursor でサードパーティの OpenAI 互換プロバイダーを使用したいとき
- Override OpenAI Base URL を設定する必要があるとき
- カスタムモデルを追加するとき
- モデルが見つからない、または認証に失敗するとき
- Cursor、Codex、その他のツールで 1 つのモデルルーティングレイヤーを共有したいとき

## 項目の意味

| 項目 | 役割 |
| --- | --- |
| API Key | 認証情報 |
| Base URL | OpenAI 互換エンドポイント。通常は `/v1` URL |
| モデル ID | プロバイダーが認識するモデル識別子 |
| カスタムモデル | Cursor 内で手動追加または選択するモデル |

## 推奨手順

1. プロバイダーのダッシュボードで API Key を作成します。
2. Cursor のモデル設定で API Key を追加します。
3. Override OpenAI Base URL にプロバイダーの Base URL を入力します。
4. プロバイダーがサポートするモデル ID を追加または選択します。
5. 保存し、簡単なリクエストで確認します。

## よくある間違い

- あるプロバイダーの API Key と別のプロバイダーの Base URL を使用すること。
- OpenAI 互換設定に Claude モデル名を入力すること。
- API モデル ID の代わりに UI 表示名を使用すること。
- Cursor Rules が API 認証に影響すると考えること。
- グローバル上書きが他の OpenAI モデルに影響する可能性を忘れること。

## BetterToken について

Cursor と同様の外部ツールでは通常、OpenAI 互換設定を使用します。BetterToken Base URL は `{{openai-base-url}}` であり、モデル ID は<a href={"{{model-plaza-url}}"}>モデル広場</a>の **GPT プロバイダー**から取得します。

Claude Code の `{{anthropic-base-url}}` を Cursor の OpenAI 互換設定に入力しないでください。
