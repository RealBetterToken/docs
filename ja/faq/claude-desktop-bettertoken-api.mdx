このページでは、BetterToken の **Claude プロバイダー**向け Claude Desktop 直接設定のみを説明します。BetterToken API Key、`{{anthropic-base-url}}`、`x-api-key` を入力してから Claude Desktop を再起動してください。

## 主要設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude プロバイダーのモデル |

## 事前準備

- <a href={"{{register-url}}"}>BetterToken API Key を作成してコピー</a>
- API Key で Claude プロバイダーのモデルを利用できることを確認

## インストール

[Claude Desktop のサイト](https://claude.ai/download)から最新バージョンをインストールまたは更新し、Claude Desktop を起動します。

## 手動設定

<Steps>
  <Step title="開発者モードを有効にする">
    Claude Desktop の macOS メニューバーで **Help** → **Troubleshooting** → **Enable Developer Mode** を選択します。

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/enable-developer-mode-menu.png"
        alt="Claude Desktop の Help メニューから Enable Developer Mode を選択します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    確認ウィンドウで **Enable** をクリックし、Claude Desktop を再起動します。

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
        alt="Claude Desktop で開発者モードを確認します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="サードパーティ推論設定を開く">
    再起動後、macOS メニューバーで **Developer** → **Configure Third-Party Inference...** を選択します。

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
        alt="Developer メニューから Configure Third-Party Inference を選択します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="BetterToken API 設定を入力する">
    **Gateway** を選択して、次を入力します。

    | 項目 | 値 |
    | --- | --- |
    | **Gateway base URL** | `{{anthropic-base-url}}` |
    | **Gateway API key** | あなたの BetterToken API Key |
    | **Gateway auth scheme** | `x-api-key` |

    認証方式を選択すると、Claude Desktop が利用可能な Claude モデルを取得します。**Apply locally** をクリックしてください。

    <Frame>
      <img

        alt="Claude Desktop に BetterToken Gateway の Base URL、API Key、認証方式を入力します。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

</Steps>

## 接続を確認する

**Save & Restart** をクリックします。**Continue with Gateway** を選択して短いメッセージを送信してください。左下に **Gateway** が表示され、通常どおりメッセージが返れば設定は有効です。

  <img

</Frame>

## モデルを切り替える

モデルセレクターを開き、Gateway が返した別の Claude モデルを選択します。モデルが表示されない場合は、**Configure Third-Party Inference...** を開き直し、**Apply locally** をクリックして Claude Desktop を再起動します。

## よくあるエラー

| 問題 | 対処方法 |
| --- | --- |
| Gateway に接続できない | **Gateway base URL** には正確に `{{anthropic-base-url}}` を使用します。`/v1` は追加しません。 |
| リクエストが `401` を返す | BetterToken API Key をもう一度コピーし、認証方式が `x-api-key` であることを確認します。 |
| Claude モデルが表示されない | API Key で Claude プロバイダーのモデルを利用できることを確認し、設定ウィンドウを開き直します。 |
| 設定が適用されない | Claude Desktop を完全に終了して開き直し、**Continue with Gateway** を選択します。 |
