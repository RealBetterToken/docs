Claude Desktop で使用できるのは Claude モデルのみです。これは Claude Desktop クライアントの制限です。

モデル広場から利用可能な Claude Model ID をコピーし、保存して Claude Desktop を再起動します。

## 主要設定

| 項目 | 値 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude |

## 事前準備

- <a href={"{{register-url}}"}>BetterToken API Key を作成してコピー</a>
- <a href={"{{model-plaza-url}}"}>モデル広場</a>から正確な Model ID をコピーしてください。

## サブスクリプションと API 課金を分ける

Gateway リクエストは BetterToken API Key と BetterToken 残高を使用します。Claude サブスクリプションの利用枠を消費したり延長したりするものではありません。サブスクリプションと API は別のアクセス・課金経路として扱ってください。

実際の作業に使う前に、次を確認します。

1. Claude Desktop 専用の BetterToken API Key を作成します。
2. **Gateway** から機密情報を含まない短いテストメッセージを送信します。
3. BetterToken Dashboard を開き、モデル、ステータス、input、output、cache Token、請求額を確認します。
4. Key がスクリーンショット、リポジトリ、公開ログに含まれた場合は、失効させて新しい Key を作成します。

## インストール

[Claude Desktop のサイト](https://claude.ai/download)から最新バージョンをインストールまたは更新し、Claude Desktop を起動します。

## 接続を確認する

**Save & Restart** をクリックします。**Continue with Gateway** を選択して短いメッセージを送信してください。左下に **Gateway** が表示され、通常どおりメッセージが返れば設定は有効です。

## モデルを切り替える

モデルセレクターを開き、Gateway が返した別の Claude モデルを選択します。モデルが表示されない場合は、**Configure Third-Party Inference...** を開き直し、**Apply locally** をクリックして Claude Desktop を再起動します。

## よくあるエラー

| 問題 | 対処方法 |
| --- | --- |
| Gateway に接続できない | **Gateway base URL** には正確に `{{anthropic-base-url}}` を使用します。`/v1` は追加しません。 |
| リクエストが `401` を返す | BetterToken API Key をもう一度コピーし、認証方式が `x-api-key` であることを確認します。 |
| Claude モデルが表示されない | モデル広場から利用可能な Claude Model ID をコピーし、保存して Claude Desktop を再起動します。 |
| 設定が適用されない | Claude Desktop を完全に終了して開き直し、**Continue with Gateway** を選択します。 |
