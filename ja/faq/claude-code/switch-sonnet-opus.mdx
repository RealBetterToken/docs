## 短い答え

Claude Code で Sonnet、Opus、または他のモデルを切り替えるときは、サポートされている `/model` の入口または公式のモデル設定経路を優先してください。

モデルエイリアス、完全なモデル ID、プロバイダーマッピングは常に同一ではありません。Web UI に表示されるマーケティング名が、必ずしも API で認識されるモデル ID とは限りません。

サードパーティゲートウェイを使用する場合は、そのゲートウェイまたはプロバイダーのドキュメントに表示されるモデル ID を使用してください。

## この情報が役立つ場面

- より安価なモデルとより高性能なモデルを切り替えたいとき
- Sonnet / Opus / Haiku のエイリアスは表示されるが、入力すべき値が分からないとき
- サードパーティの Base URL またはモデルゲートウェイを使用するとき
- Claude Code の Token コストを管理したいとき
- モデルが見つからない、またはモデル選択が反映されないとき

## モデル名の 3 つの層

| 層 | 意味 |
| --- | --- |
| 表示名 | UI に表示される人に分かりやすい名前 |
| エイリアス | ツール内の短い名前またはショートカット |
| モデル ID | API が実際に認識する識別子 |

リクエストの成功で重要なのは、現在のプロバイダーがモデル ID を認識できるかどうかです。

## 推奨事項

1. 現在のプロバイダーがサポートするモデルを確認します。
2. Claude Code の `/model` または公式のモデル設定経路を使用します。
3. サードパーティゲートウェイを使用する場合は、そのモデル広場から利用可能なモデル ID をコピーします。
4. モデルの選択とコストをあわせて検討します。
5. モデル名を手入力で推測しないでください。

## BetterToken について

BetterToken 経由で Claude Code を接続する場合は、<a href={"{{model-plaza-url}}"}>モデル広場</a>から現在のモデル ID をコピーしてください。Claude プロバイダーと GPT プロバイダーのモデルは異なるプロトコル経路に属するため、混在させないでください。

モデル選択は品質、速度、コストに影響します。使用履歴を使うと、モデル間の実際の消費量を比較できます。
