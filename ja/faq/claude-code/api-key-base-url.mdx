## 要点

Claude Code でサードパーティ API を設定する場合は、まずエンドポイントが Anthropic 互換であることを確認します。このドキュメントでは、Claude Code に `{{anthropic-base-url}}` を使います。`/v1` は追加しないでください。

API Key はリクエストの認証に使います。Base URL は、モデルへのリクエストの送信先を Claude Code に指定します。どちらも同じプロバイダーとプロトコルに属している必要があります。

Claude API 全般へのアクセスを探している場合は、[BetterToken の Claude API ページ](https://bettertoken.ai/ru/claude-api/)をご覧ください。ランディングページは API アクセスの検討向けで、この FAQ は Claude Code での API Key と Base URL の設定に特化しています。

BetterToken API Key、Base URL `{{anthropic-base-url}}`、使用する Model ID を設定して Claude Code に接続します。 <a href={"{{model-plaza-url}}"}>モデル広場</a>から正確な Model ID をコピーしてください。

## この設定が重要になる場合

- Claude Code でカスタム API gateway を使いたい
- API Key はあるが、どの Base URL を使うべきか分からない
- Claude Code で認証またはエンドポイントのエラーが表示される
- `{{anthropic-base-url}}` と `{{openai-base-url}}` のどちらを使うか判断したい


## 主な概念

| 項目 | 意味 |
| --- | --- |
| API Key | モデル API リクエストの認証情報 |
| Base URL | リクエストの送信先となる API アドレス |
| Anthropic 互換 API | Anthropic または Claude 形式のリクエスト規則に従うエンドポイント |
| OpenAI 互換 API | OpenAI 形式の規則に従うエンドポイント。Codex、Cursor、Cline でよく使われる |
| Model ID | 外部ツールが要求するモデル名またはマッピング値 |

## 推奨設定

BetterToken API Key、Base URL `{{anthropic-base-url}}`、使用する Model ID を設定して Claude Code に接続します。

<a href={"{{model-plaza-url}}"}>モデル広場</a>から正確な Model ID をコピーしてください。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

`YOUR_MODEL_ID` をコピーした ID に置き換えます。`ANTHROPIC_MODEL` で主モデルを、3 つの `ANTHROPIC_DEFAULT_*_MODEL` 変数で Haiku、Sonnet、Opus のエイリアスを設定します。同じモデルでも、役割ごとに別のモデルでも指定できます。

設定の Model ID を変更し、Claude Code を再起動します。セッション中は `/model YOUR_MODEL_ID` で切り替えられます。

## よくある間違い

- Claude Code の Base URL に `/v1` を追加する。
- API Key を変更しても、リクエストの送信先をデフォルトエンドポイントのままにする。

- Claude Code の Anthropic 互換フィールドに OpenAI 互換エンドポイントを設定する。
- シェルプロファイルに古い環境変数を定義し、新しい設定を上書きする。

## BetterToken について

BetterToken は 2 種類のエンドポイントを提供します。Claude Code には Anthropic 互換の `{{anthropic-base-url}}`、Codex とその他の外部ツールには OpenAI 互換の `{{openai-base-url}}` を使います。

API Key、残高、利用履歴は 1 つのダッシュボードで管理できますが、Claude Code が Anthropic 互換のリクエスト形式を必要とする点は変わりません。
