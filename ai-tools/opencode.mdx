Настройка OpenCode начинается с установки CLI и подключения BetterToken через `@ai-sdk/openai-compatible`. Назовите provider в OpenCode **BetterToken** или **OpenAI Compatible**.

## OpenCode: скачать и настроить provider

Установите OpenCode из официального источника, затем сохраните credential через `/connect` или настройте `opencode.json`. Для Kimi K3 используйте отдельную инструкцию [«Kimi K3 API в OpenCode»](/faq/opencode/kimi-k3-api), а точный Model ID выбирайте по [руководству по моделям](/faq/model-calling/model-selection-guide).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

Скрипт Automatic setup BetterToken создаёт или обновляет provider BetterToken в OpenCode. Для работы нужен Node.js. Если API Key или Model ID не переданы через параметры, скрипт запросит их во время запуска.

  <Tab title="macOS / Linux">

  </Tab>

## Ручная настройка

### Вариант 1: сохраните credential через /connect

Запустите OpenCode и выполните:

```text
/connect
```

Выберите **Other**, укажите provider id `bettertoken`, затем введите `YOUR_API_KEY`. OpenCode сохранит credential локально.

### Вариант 2: настройте JSON

Глобальный файл: `~/.config/opencode/opencode.json`. Для проекта можно использовать `opencode.json` в его корне.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "{{openai-base-url}}"
      },
      "models": {
        "YOUR_MODEL_ID": {
          "name": "YOUR_MODEL_ID"
        }
      }
    }
  }
}
```

Если `/connect` не используется, добавьте `"apiKey": "YOUR_API_KEY"` в `options`. Не отправляйте конфигурацию с реальным ключом в Git.

## Проверка подключения

Запустите `opencode` в проекте, выберите `bettertoken/YOUR_MODEL_ID` и отправьте короткое сообщение. Обычный ответ подтверждает настройку. После изменения JSON перезапустите OpenCode.

## Смена модели

Добавьте новый `YOUR_MODEL_ID` в `provider.bettertoken.models`, обновите верхнее поле `model`, сохраните файл и перезапустите OpenCode.

## Частые ошибки

| Ошибка | Решение |
| --- | --- |
| `401` | Повторите `/connect` или проверьте `apiKey`. |
| `404` | В `baseURL` укажите только `{{openai-base-url}}`, без `/chat/completions`. |
| Модель не найдена | Верхнее поле `model` должно точно совпадать с ID внутри `models`. |
| Конфигурация не применилась | Проверьте, не переопределяет ли проектный `opencode.json` глобальный файл, затем перезапустите OpenCode. |
