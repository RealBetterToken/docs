在 OpenCode 中接入 BetterToken，建议先用 `/connect` 添加凭证，再在配置文件中声明 BetterToken 这个 OpenAI-compatible provider，并填入 Codex 分组模型 ID。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 OpenCode

<Tabs>
  <Tab title="curl">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g opencode-ai
    ```
  </Tab>
</Tabs>

## 配置步骤

<Tabs>
  <Tab title="自动配置">
    你可以直接运行 BetterToken 提供的自动配置脚本。它只负责写入 BetterToken provider 配置，不替代页面上方的安装前置条件。脚本需要 `Node.js`。如果你没有显式传入 API Key 或模型，脚本会按工具能力提示你交互输入。

    <Tabs sync={false}>
      <Tab title="macOS / Linux">
        ```bash
        curl -fsSL https://www.bettertoken.ai/install-opencode-provider.sh | bash
        ```
      </Tab>
      <Tab title="Windows">
        ```powershell
        iwr https://www.bettertoken.ai/install-opencode-provider.ps1 -OutFile "$env:TEMP\install-opencode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-opencode-provider.ps1"
        ```
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="手动配置">
    <Steps>
      <Step title="清除冲突的环境变量">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="先用 /connect 添加 BetterToken 凭证">
        启动 OpenCode 后运行：

        ```bash
        /connect
        ```

        在向导里选择 **Other**，然后：

        - **provider id** 填 `bettertoken`
        - 粘贴你的 BetterToken API Key

        OpenCode 会将凭证保存到 `~/.local/share/opencode/auth.json`。
      </Step>

      <Step title="编辑 OpenCode 配置文件">
        你可以使用全局配置 `~/.config/opencode/opencode.json`，也可以在项目根目录创建 `opencode.json`。项目级配置优先级更高。

        ```json
        {
          "$schema": "https://opencode.ai/config.json",
          "model": "bettertoken/YOUR_CODEX_MODEL_ID",
          "provider": {
            "bettertoken": {
              "npm": "@ai-sdk/openai-compatible",
              "name": "BetterToken",
              "options": {
                "baseURL": "https://www.bettertoken.ai/v1"
              },
              "models": {
                "YOUR_CODEX_MODEL_ID": {
                  "name": "YOUR_CODEX_MODEL_ID"
                }
              }
            }
          }
        }
        ```

        将 `YOUR_CODEX_MODEL_ID` 替换为从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**。
      </Step>

      <Step title="如需在配置文件里直接写 API Key，可使用备用写法">
        ```json
        {
          "$schema": "https://opencode.ai/config.json",
          "model": "bettertoken/YOUR_CODEX_MODEL_ID",
          "provider": {
            "bettertoken": {
              "npm": "@ai-sdk/openai-compatible",
              "name": "BetterToken",
              "options": {
                "baseURL": "https://www.bettertoken.ai/v1",
                "apiKey": "YOUR_API_KEY"
              },
              "models": {
                "YOUR_CODEX_MODEL_ID": {
                  "name": "YOUR_CODEX_MODEL_ID"
                }
              }
            }
          }
        }
        ```

        这是备用方式。更推荐使用上一节的 `/connect`。
      </Step>

      <Step title="仅在有 provider-specific 需求时再使用 `options.headers`">
        OpenCode 官方文档支持通过 `provider.<id>.options.headers` 添加自定义 headers，但这是可选能力。接入 BetterToken 时通常不需要额外设置 `User-Agent`。

        如果你还接了 Helicone、租户路由网关、审计或缓存服务，再按这些上游服务的官方文档补充所需 headers。
      </Step>

      <Step title="重启 OpenCode">
        修改配置文件后，请退出当前 OpenCode 会话，再重新启动。
      </Step>

      <Step title="启动 OpenCode">
        ```bash
        cd /path/to/your/project
        opencode
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 注意事项

- 默认模型请填写 **Codex 分组模型 ID**，不要再写 Claude 系列固定模型名
- BetterToken 这类 OpenAI-compatible provider 当前应优先使用 `@ai-sdk/openai-compatible`
- 如果你使用 `/connect`，一般不需要再把 API Key 明文写进配置文件
- OpenCode 官方文档将 `options.headers` 视为可选扩展配置；接入 BetterToken 时通常不需要额外 headers
