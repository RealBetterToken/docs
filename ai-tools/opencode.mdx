在 OpenCode 中接入 BetterToken，可以通过编辑配置文件完成。当前应使用 OpenAI 兼容 provider，并填入 Codex 分组模型 ID。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 OpenCode

<Tabs>
  <Tab title="curl">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g opencode-ai
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="编辑 OpenCode 配置文件">
    配置文件路径：`~/.config/opencode/opencode.json`

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "model": "bettertoken/YOUR_CODEX_MODEL_ID",
      "provider": {
        "bettertoken": {
          "npm": "@ai-sdk/openai",
          "options": {
            "baseURL": "https://www.bettertoken.ai/v1",
            "apiKey": "YOUR_API_KEY"
          },
          "models": {
            "YOUR_CODEX_MODEL_ID": {
              "name": "YOUR_CODEX_MODEL_ID"
            }
          }
        }
      }
    }
    ```

    将 `YOUR_CODEX_MODEL_ID` 替换为从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**。
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="重启 OpenCode">
    修改配置文件后，请退出当前 OpenCode 会话，再重新启动。
  </Step>

  <Step title="启动 OpenCode">
    ```bash
    cd /path/to/your/project
    opencode
    ```
  </Step>
</Steps>

## 注意事项

- 默认模型请填写 **Codex 分组模型 ID**，不要再写 Claude 系列固定模型名
- 若当前版本没有自定义 headers 入口，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`
