Cline 是 VS Code 的 AI 编程助手插件。接入 BetterToken 只需在设置界面选择 OpenAI Compatible 提供商并填写配置。

## 前置条件

- 已安装 VS Code
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Cline

打开 VS Code，在扩展市场搜索 **Cline**，点击 Install 安装。安装完成后，VS Code 左侧活动栏会出现 Cline 图标。

<Note>
  请使用 **3.47.0 或更高版本**的 Cline，并在安装后重启 VS Code 和插件。
</Note>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="打开 Cline 配置界面">
    点击 Cline 侧边栏中的 **Use your own API key** 按钮，进入参数配置界面。
  </Step>

  <Step title="配置 API 提供商">
    按以下方式填写：

    - **API Provider** → 选择 `OpenAI Compatible`
    - **Base URL** → 填入 `https://www.bettertoken.com/v1`
    - **API Key** → 填入你的 BetterToken API Key
    - **Model** → 填入 `claude-sonnet-4-6`（或其他支持模型）
  </Step>

  <Step title="保存配置">
    点击右上角 **Done** 保存配置。
  </Step>

  <Step title="开启 Auto-approve（推荐）">
    在 Cline 的 **Auto-approve** 设置中，勾选 **Edit** 选项，允许 Cline 自动编辑文件，获得更流畅的编程体验。
  </Step>
</Steps>

## 支持的模型

| 模型名称 | 说明 |
|----------|------|
| `claude-sonnet-4-6` | 均衡，推荐日常编程 |
| `claude-opus-4-6` | 最强能力，适合复杂重构 |
| `claude-haiku-4-6` | 速度最快，适合快速补全 |
| `gpt-5.4` | OpenAI 旗舰模型 |
| `gpt-5.4-mini` | 轻量版，响应更快 |
