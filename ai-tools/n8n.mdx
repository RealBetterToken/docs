Чтобы подключить n8n OpenAI API Key, создайте credential **OpenAI**, укажите Base URL `{{openai-base-url}}` и выберите точный Model ID в узле **OpenAI Chat Model**.

## n8n OpenAI API Key и бесплатный API

BetterToken не заявляется как постоянно бесплатный OpenAI API для n8n. Актуальные условия и стоимость проверяйте на [странице цен](https://bettertoken.ai/pricing). Для настройки workflow смотрите шаги ниже, сравнение с [Dify](/ai-tools/dify) и [руководство по выбору модели](/faq/model-calling/model-selection-guide).

## Ключевые параметры

| Поле | Значение |

| Base URL | `{{openai-base-url}}` |

- Установленная актуальная версия инструмента

## Установка

Установите или откройте n8n, затем перейдите к ручной настройке ниже.

## Ручная настройка

Выполните эту настройку в интерфейсе параметров node в n8n. Редактировать конфигурационный файл n8n вручную не требуется.

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Что потребуется

- n8n Cloud или собственный экземпляр n8n
- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)
- Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>

| Параметр | Значение |
|---|---|
| Credential type | `OpenAI` |
| Base URL | `{{openai-base-url}}` |
| API Key | API Key BetterToken |
| Organization ID | оставить пустым |
| Custom Header | выключить |

<Note>
  Сохраните `/v1` в конце Base URL. Не добавляйте `/chat/completions` или `/responses`: n8n сам дополняет адрес маршрутом, который нужен узлу.
</Note>

### Настройка

<Steps>
  <Step title="Добавьте AI Agent и OpenAI Chat Model">
    Откройте workflow и добавьте узел **AI Agent**. В его разъём **Chat Model** добавьте подузел **OpenAI Chat Model**.

    В этой инструкции используется **OpenAI Chat Model**: он подключает модель к AI Agent, chain и другим AI workflow в n8n.
  </Step>

  <Step title="Создайте OpenAI credential">
    В **OpenAI Chat Model** откройте **Credential to connect with**, выберите **Create new credential**, затем — **OpenAI**.

    Если ваша версия n8n предлагает **OpenAI Account (ChatGPT)** и **API Key**, выберите **API Key**. Авторизация OpenAI Account предназначена для официального аккаунта, а не для custom Base URL BetterToken.
  </Step>

  <Step title="Введите данные BetterToken">
    Заполните поля так:

    | Поле n8n | Значение |
    |---|---|
    | API Key | ваш API Key BetterToken |
    | Organization ID (optional) | оставить пустым |
    | Base URL | `{{openai-base-url}}` |
    | Add Custom Header | выключить |

    Нажмите **Save**. n8n проверяет credential через `/models` относительно указанного Base URL, поэтому полный адрес проверки — `{{openai-base-url}}/models`.
  </Step>

  <Step title="Выберите модель">
    Вернитесь в **OpenAI Chat Model**, откройте список **Model** и выберите Model ID поддерживаемого провайдера из <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Если после сохранения credential список не обновился, заново откройте узел или credential и повторно загрузите модели.
  </Step>

  <Step title="Выберите Chat Completions или Responses">
    Для первой проверки выключите **Use Responses API** и отправьте обычный запрос через режим Chat Completions.

    Включайте **Use Responses API**, только если это требуется workflow. n8n описывает Web Search, File Search и Code Interpreter для связки **OpenAI Chat Model + AI Agent** с включённым Responses API. Эти инструменты OpenAI не становятся автоматически подтверждёнными возможностями BetterToken: проверяйте их с выбранной моделью и endpoint.
  </Step>

  <Step title="Проверьте подключение">
    Передайте AI Agent простой запрос:

    ```text
    Ответь только: Подключение работает
    ```

    Нажмите **Execute step** или запустите workflow. Если узел вернул ответ модели, настройка завершена.
  </Step>
</Steps>

### Решение проблем

### Credential test возвращает 401

- Проверьте API Key и удалите лишние пробелы
- Убедитесь, что Model ID доступен у провайдера **GPT**
- Проверьте статус ключа и баланс в Dashboard BetterToken

### Credential test возвращает 404

- Base URL должен быть `{{openai-base-url}}`
- Не указывайте `{{openai-base-url}}/models` как Base URL
- Не добавляйте `/chat/completions` или `/responses`

### Список Model пуст

- Сохраните credential ещё раз и повторно откройте **Model**
- Проверьте доступ к `{{openai-base-url}}/models` с текущим API Key
- Скопируйте актуальный ID из <a href={"{{model-plaza-url}}"}>model plaza</a>; не используйте удалённый ID или вариант с опечаткой

### Обычный чат работает, а вызов инструментов Agent — нет

Выключите **Use Responses API** и встроенные инструменты, затем проверьте обычный Chat Completions. После этого включайте инструменты по одному, чтобы отделить ограничения модели от ошибок параметров и workflow.

### Запрос завершается по тайм-ауту

Увеличьте **Timeout** в **OpenAI Chat Model > Options** и оставьте ограниченное значение **Max Retries**. Не повторяйте бесконечно запросы с `400`, `401` и ошибками конфигурации.

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

Инструкция подтверждает только LLM Chat через OpenAI-compatible протокол. Не используйте GPT chat model как embedding, rerank, speech или image model.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key и удалите лишние пробелы. |
| `403` | Проверьте доступ API Key к выбранному Model ID. |
| `timeout` | Увеличьте Timeout в OpenAI Chat Model и сначала проверьте обычный запрос без Agent tools. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из каталога моделей. |
| Настройки не применились | Сохраните файл и полностью перезапустите инструмент. |
