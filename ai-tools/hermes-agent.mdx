Hermes Agent 支持通过自定义模型提供商接入 BetterToken。当前外部工具应统一走 Codex 分组与 OpenAI 类协议。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）
- macOS、Linux 或 Windows WSL2 环境

## 安装 Hermes Agent

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## 配置步骤

<Steps>
  <Step title="运行模型选择器">
    ```bash
    hermes model
    ```
  </Step>

  <Step title="选择 OpenAI 或 OpenAI Compatible provider">
    在 provider 列表中，选择 **OpenAI** 或 **OpenAI Compatible**。
  </Step>

  <Step title="填写 BetterToken 配置">
    按提示依次输入：

    - **Base URL**：`https://www.bettertoken.ai/v1`
    - **API Key**：你的 BetterToken API Key
    - **Model**：从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    当前我们没有查到 Hermes Agent 官方接入说明要求 BetterToken 额外配置 `User-Agent`。默认先按页面中的 `Base URL`、API Key 和模型 ID 完成接入即可。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="重启 Hermes Agent">
    修改配置后，请退出当前 Hermes Agent 会话，再重新启动。
  </Step>

  <Step title="启动 Hermes Agent">
    ```bash
    hermes
    ```
  </Step>
</Steps>

<Note>
  如需额外 headers，请以 Hermes Agent 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 BetterToken 必填项。
</Note>
