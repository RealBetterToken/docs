Чтобы подключить Hermes Agent к BetterToken, подготовьте API Key, укажите Base URL из таблицы ниже и выберите актуальный Model ID в каталоге моделей.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- выбранный Model ID доступен у провайдера **GPT**
- macOS, Linux или Windows WSL2

## Ручная настройка

Основной способ — интерактивный интерфейс настройки моделей Hermes Agent. Команды и переменные окружения остаются дополнительными вариантами.

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройка

<Tabs>
  <Tab title="Интерактивная настройка">
    <Steps>
      <Step title="Запустите выбор модели">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="Выберите OpenAI или OpenAI Compatible provider">
        Выберите **OpenAI** или **OpenAI Compatible** в списке providers.
      </Step>

      <Step title="Заполните конфигурацию BetterToken">
        Введите:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: ваш API Key BetterToken
        - **Model**: Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>
      </Step>

      <Step title="Перезапустите Hermes Agent">
        После обновления конфигурации завершите текущую сессию Hermes Agent и запустите ее снова.
      </Step>

      <Step title="Запустите Hermes Agent">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI config">
    Если вам удобнее копировать команды, запишите конфигурацию Hermes Agent напрямую.

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_API_KEY"
    hermes config set llm.model "YOUR_MODEL_ID"
    ```

    Замените `YOUR_API_KEY` на ваш API Key BetterToken, а `YOUR_MODEL_ID` — на Model ID поддерживаемого провайдера из <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Затем запустите Hermes Agent:

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="Environment variables">
    Если вы не хотите сохранять API Key в конфигурации Hermes Agent, экспортируйте его в текущем shell.

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"
    export HERMES_MODEL="YOUR_MODEL_ID"
    hermes
    ```

    Эти переменные действуют только в текущей shell-сессии. В новом терминале экспортируйте их снова или добавьте в свой shell profile.
  </Tab>
</Tabs>

### Troubleshooting

- Если запросы не отвечают или завершаются ошибкой, проверьте, что **Base URL** равен `{{openai-base-url}}`. Обычно здесь не нужно добавлять `/chat/completions`.
- Если Hermes сообщает, что модель не существует, проверьте, что **Model** — это Model ID поддерживаемого провайдера из <a href={"{{model-plaza-url}}"}>model plaza</a>.
- Если возникает ошибка авторизации, проверьте лишние пробелы в API Key и убедитесь, что Model ID доступен у провайдера **GPT**.
- Если после изменения настроек Hermes все еще использует старую модель, завершите текущую сессию Hermes Agent и снова выполните `hermes`.
- BetterToken обычно не требует дополнительного `User-Agent` или custom headers. Добавляйте headers только если этого явно требует ваш custom gateway, tenant routing, observability или caching layer.

<Note>
  Не коммитьте реальные API Keys в репозиторий. Для командных конфигураций используйте environment variables или локальную конфигурацию.
</Note>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Технические детали

<Accordion title="Протокол, endpoint и внутренние параметры provider">
  В описанном сценарии используется Base URL `{{openai-base-url}}`. Инструмент сам добавляет путь OpenAI-compatible endpoint. Не добавляйте `/chat/completions` или `/responses` к Base URL, если это не требуется конкретным полем.

### Миграция с OpenClaw

Если вы уже используете OpenClaw, сначала проверьте, есть ли в вашей текущей версии Hermes Agent команда миграции. Перед изменениями запустите dry run.

```bash
hermes claw migrate --dry-run
```

После проверки результата выполните миграцию:

```bash
hermes claw migrate
```

После миграции все равно проверьте **Base URL**, API Key и model ID в Hermes Agent. Они должны соответствовать `{{openai-base-url}}`, вашему API Key BetterToken и Model ID поддерживаемого провайдера.
</Accordion>
