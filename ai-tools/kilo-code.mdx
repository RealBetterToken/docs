Kilo Code 是 VS Code 插件。接入 BetterToken 时，请选择 OpenAI Compatible 提供商，并使用 Codex 分组模型 ID。

## 前置条件

- 已安装 VS Code
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="打开 Kilo Code 设置">
    打开 Kilo Code 的设置界面。
  </Step>

  <Step title="配置 API 提供商">
    按以下方式填写：

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `https://www.bettertoken.ai/v1`
    - **API Key** → 你的 BetterToken API Key
    - **Model** → 从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    我们查到的 Kilo Code 官方资料提到 OpenAI-compatible provider 支持可选自定义 headers，但没有把 `User-Agent` 列为 BetterToken 默认接入的必填项。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="重启 Kilo Code">
    修改配置后，请重启 VS Code 或重新加载 Kilo Code 插件，使新配置生效。
  </Step>
</Steps>

<Note>
  如需额外 headers，请以 Kilo Code 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 BetterToken 必填项。
</Note>
