Настройка Kilo Code выполняется в интерфейсе расширения: выберите OpenAI-compatible provider, укажите API Key BetterToken, Base URL и точный Model ID.

## Kilo Code: настройка custom provider

После сохранения откройте новый чат и выполните короткий запрос. Для похожих расширений смотрите [Cline](/ai-tools/cline) и [Roo Code](/ai-tools/roo-code), а актуальный Model ID выбирайте по [руководству по моделям](/faq/model-calling/model-selection-guide).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установленный VS Code

## Установка

Установите или откройте Kilo Code, затем перейдите к ручной настройке ниже.

## Ручная настройка

Выполните эту настройку в интерфейсе Kilo Code. Редактировать конфигурационный файл вручную не требуется.

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройка

<Steps>
  <Step title="Очистите конфликтующие переменные окружения">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Откройте настройки Kilo Code">
    Откройте UI настроек Kilo Code.
  </Step>

  <Step title="Настройте API provider">
    Заполните:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → ваш API Key BetterToken
    - **Model** → Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Официальные материалы Kilo Code упоминают optional custom headers для OpenAI-compatible providers, но не считают `User-Agent` обязательным шагом настройки BetterToken.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Перезапустите Kilo Code">
    После изменения конфигурации перезапустите VS Code или перезагрузите расширение Kilo Code.
  </Step>
</Steps>

<Note>
  Если вам нужны extra headers, следуйте текущей документации Kilo Code или требованиям вашего upstream gateway, а не предполагайте, что `User-Agent` обязателен для BetterToken.
</Note>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key BetterToken и удалите лишние пробелы. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из model plaza. |
| Настройки не применились | Сохраните конфигурацию и полностью перезапустите инструмент. |

## Технические детали

<Accordion title="Протокол, endpoint и внутренние параметры provider">
  В описанном сценарии используется Base URL `{{openai-base-url}}`. Инструмент сам добавляет путь OpenAI-compatible endpoint. Не добавляйте `/chat/completions` или `/responses` к Base URL, если это не требуется конкретным полем.
