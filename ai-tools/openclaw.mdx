在 OpenClaw 中接入 BetterToken，建议使用官方 onboarding 和模型命令完成配置。OpenClaw 的配置结构迭代较快，不建议直接复制旧版 JSON 配置。

## 前置条件

- 已安装 OpenClaw
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 OpenClaw

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://openclaw.ai/install.sh | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://openclaw.ai/install.ps1 | iex
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="运行 onboarding">
    ```bash
    openclaw onboard --install-daemon
    ```

    按向导完成 Gateway 和基础模型配置。
  </Step>

  <Step title="添加 BetterToken 凭证">
    运行模型认证向导：

    ```bash
    openclaw models auth add
    ```

    在向导中选择 **Anthropic**、**Anthropic Compatible** 或自定义 API Key 提供商，并填写：

    - **Base URL**：`https://www.BetterToken.ai/v1`
    - **API Key**：你的 BetterToken API Key
    - **Model**：`claude-sonnet-4-6`
  </Step>

  <Step title="设置默认模型">
    ```bash
    openclaw models set anthropic/claude-sonnet-4-6
    ```

    <Note>
      如果你的 OpenClaw 版本显示的 provider id 不是 `anthropic`，先运行 `openclaw models list`，再使用列表中的 `<provider>/claude-sonnet-4-6`。
    </Note>
  </Step>

  <Step title="验证配置">
    重启 Gateway 并检查模型状态：

    ```bash
    openclaw gateway restart
    openclaw models status
    ```

    需要发起真实探测时，可运行 `openclaw models status --probe-provider anthropic`。探测可能消耗模型额度。
  </Step>
</Steps>

## 可选：切换模型

BetterToken 支持 Claude 全系列模型。使用 `openclaw models set <provider>/<model>` 切换模型：

| 模型名称 | 适用场景 |
|----------|----------|
| `claude-sonnet-4-6` | 均衡，推荐日常使用 |
| `claude-opus-4-6` | 最强能力，适合复杂任务 |
| `claude-haiku-4-6` | 速度最快，适合简单任务 |

切换模型后运行 `openclaw gateway restart` 使配置生效。
