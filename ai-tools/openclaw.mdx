在 OpenClaw 中接入 BetterToken 时，请选择 **Codex provider**，不要继续使用 Anthropic provider。API 端点固定为 `https://www.bettertoken.ai/v1/`，协议固定为 `OpenAI Responses`。

<Warning>
  OpenClaw 缺少 Codex 对应 `User-Agent` 时，可能报 `403 block` 或 `403 Forbidden`。
</Warning>

## 前置条件

- 已安装 OpenClaw
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 OpenClaw

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://openclaw.ai/install.sh | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://openclaw.ai/install.ps1 | iex
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="运行 onboarding">
    ```bash
    openclaw onboard --install-daemon
    ```

    按向导完成 Gateway 和基础组件安装。
  </Step>

  <Step title="添加 BetterToken 凭证">
    ```bash
    openclaw models auth add
    ```
  </Step>

  <Step title="选择 Codex provider 并填写参数">
    在向导中选择 **Codex**。然后填写：

    - **API 端点**：`https://www.bettertoken.ai/v1/`
    - **API 协议**：`OpenAI Responses`
    - **令牌分组**：选择 `Codex_*` 的分组
    - **模型**：从模型广场复制当前可用的 Codex 分组模型 ID
  </Step>

  <Step title="添加必需 headers">
    如果 OpenClaw 当前版本提供自定义 headers 输入框或 JSON 编辑器，请填写：

    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```

    将 `sk-xxx` 替换为你的 BetterToken API Key。
  </Step>

  <Step title="设置默认模型并验证">
    先运行 `openclaw models list`，确认当前 provider id，再设置默认模型并检查状态：

    ```bash
    openclaw models list
    openclaw models set <provider>/<从模型广场复制的 Codex 模型 ID>
    openclaw gateway restart
    openclaw models status
    ```
  </Step>
</Steps>

## 使用说明

- OpenClaw 当前应使用 **Codex provider**，不要再使用 `anthropic/<Claude模型>` 这类旧写法
- 模型名称请直接从模型广场复制 **Codex 分组**模型 ID
- 缺少对应 UA 时，即使 API Key 正确，也可能报 `403 block` 或 `403 Forbidden`
