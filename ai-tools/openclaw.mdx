OpenClaw подключается к BetterToken через `~/.openclaw/openclaw.json`. Модели провайдера GPT используют `openai-responses`, другие поддерживаемые провайдеры — `openai-completions`.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## Подготовка

- Установите последнюю версию OpenClaw
- <a href={"{{register-url}}"}>Создайте API Key BetterToken</a>
- Скопируйте Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a> или окна **Setup** для ключа

Скрипт Automatic setup BetterToken записывает конфигурацию OpenClaw. Для работы нужен Node.js. Если API Key или Model ID не переданы через параметры, скрипт запросит их во время запуска.

## Ручная настройка

### Настройка OpenClaw

Отредактируйте `~/.openclaw/openclaw.json`. Используйте вариант, соответствующий провайдеру выбранного Model ID.

<Tabs>
  <Tab title="GPT: openai-responses">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-responses",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Не GPT: openai-completions">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-completions",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

Не определяйте `api` только по названию модели. GPT использует `openai-responses`. Для другого провайдера применяйте `openai-completions` только после подтверждения в model plaza или окне Setup.

## Проверка подключения

Выполните:

```bash
openclaw config validate
openclaw gateway restart
openclaw models list
openclaw models status
```

Настройка активна, если валидация прошла, Gateway перезапустился, а `bettertoken/YOUR_MODEL_ID` виден в списке и статусе моделей. Для старой сессии создайте новую и проверьте снова.

## Смена модели

Добавьте модель в `models.providers.bettertoken.models`, затем измените `agents.defaults.model.primary` на `bettertoken/YOUR_MODEL_ID`. Сохраните файл, проверьте конфигурацию и перезапустите Gateway.

## Частые ошибки

| Ошибка | Решение |
| --- | --- |
| Ошибка `config validate` | Проверьте запятые, кавычки и скобки JSON. |
| `401` | Скопируйте `apiKey` заново и удалите пробелы. |
| `404` или ошибка протокола | Для GPT нужен `openai-responses`, для не-GPT — `openai-completions`. Не добавляйте endpoint к Base URL. |
| Модель не отображается | Проверьте список моделей provider и `agents.defaults.model.primary`. |
| Старая сессия использует прежнюю модель | Выполните `openclaw gateway restart` и создайте новую сессию. |

## Технические детали

<Accordion title="Responses и Chat Completions">
  `openai-responses` вызывает `/v1/responses` для провайдера GPT. `openai-completions` вызывает `/v1/chat/completions` для подтверждённых совместимых не-GPT провайдеров. В обоих случаях `baseUrl` равен `{{openai-base-url}}`.
</Accordion>
