在 OpenClaw 中接入 BetterToken，需要手动编辑配置文件，将 BetterToken 作为自定义 Anthropic 兼容提供商使用。

## 前置条件

- 已安装 OpenClaw
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 OpenClaw

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://openclaw.bot/install.sh | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://openclaw.ai/install.ps1 | iex
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="编辑 OpenClaw 配置文件">
    打开配置文件 `~/.openclaw/openclaw.json`，添加 BetterToken 作为自定义提供商：

    ```json
    {
      "model": {
        "provider": "anthropic",
        "baseURL": "https://www.bettertoken.com/v1",
        "apiKey": "YOUR_API_KEY",
        "model": "claude-sonnet-4-6"
      }
    }
    ```

    将 `YOUR_API_KEY` 替换为你的 BetterToken API Key。

    <Note>
      如果配置文件中已有其他内容，仅修改 `model` 字段，不要删除其他配置。
    </Note>
  </Step>

  <Step title="重启 OpenClaw 网关">
    ```bash
    openclaw gateway start
    ```
  </Step>

  <Step title="验证配置">
    运行 OpenClaw 终端界面，发送一条消息确认正常响应：

    ```bash
    openclaw tui
    ```
  </Step>
</Steps>

## 可选：切换模型

BetterToken 支持 Claude 全系列模型，修改配置文件中的 `model` 字段即可切换：

| 模型名称 | 适用场景 |
|----------|----------|
| `claude-sonnet-4-6` | 均衡，推荐日常使用 |
| `claude-opus-4-6` | 最强能力，适合复杂任务 |
| `claude-haiku-4-6` | 速度最快，适合简单任务 |

切换模型后需重新运行 `openclaw gateway start` 使配置生效。
