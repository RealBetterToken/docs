MonkeyCode — AI-инструмент для работы с задачами в собственном интерфейсе, где модель можно подключить через custom provider. Эта инструкция относится к настройке BetterToken в разделе **AI Model**, а не к официальному API MonkeyCode. Укажите API Key BetterToken, Base URL `{{openai-base-url}}` и точный Model ID, затем сохраните привязку и начните новый чат. Такой сценарий подходит, когда вы хотите использовать совместимую модель в MonkeyCode и самостоятельно контролировать её выбор. Официальные материалы и регистрация доступны на [сайте MonkeyCode](https://monkeycode.ai).

## MonkeyCode: настройка и ошибка 429

При ошибке `429` проверьте доступность модели и состояние баланса, затем повторите один короткий запрос без параллельных повторов. Для похожей настройки смотрите [KodaCode](/ai-tools/kodacode) и [Cline](/ai-tools/cline), а актуальный Model ID выбирайте по [руководству](/faq/model-calling/model-selection-guide).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Аккаунт MonkeyCode ([регистрация в MonkeyCode](https://monkeycode.ai))

## Установка

Установите или откройте MonkeyCode, затем перейдите к ручной настройке ниже.

## Ручная настройка

Выполните эту настройку в интерфейсе MonkeyCode. Редактировать конфигурационный файл вручную не требуется.

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройка

<Steps>
  <Step title="Войдите в MonkeyCode">
    Откройте [MonkeyCode](https://monkeycode.ai) и войдите в аккаунт.
  </Step>

  <Step title="Откройте системные настройки">
    Перейдите на страницу задачи и нажмите **Settings** в правом нижнем углу.
  </Step>

  <Step title="Привяжите AI-модель">
    В разделе **AI Model** нажмите **Bind**.
  </Step>

  <Step title="Заполните конфигурацию BetterToken">

    | Поле | Значение |
    |------|----------|
    | Model API URL | `{{openai-base-url}}` |
    | API Key | ваш API Key BetterToken |
    | API format | `OpenAI` или `OpenAI Compatible` по текущему названию в UI |
    | Model name | Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Мы не нашли официального требования MonkeyCode, по которому `User-Agent` обязателен для BetterToken. Начните с `Base URL`, API key и model ID на этой странице.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Сохраните и начните использовать">
    Нажмите **Save**, затем вернитесь на главную страницу и выберите настроенную модель.
  </Step>

  <Step title="Перезапустите MonkeyCode">
    После сохранения конфигурации обновите страницу или заново откройте MonkeyCode перед использованием новой модели.
  </Step>
</Steps>

<Note>
  Если вам нужны extra headers, следуйте текущей документации MonkeyCode или требованиям вашего upstream gateway.
</Note>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key BetterToken и удалите лишние пробелы. |
| `429` | Проверьте доступность модели и состояние баланса. Повторите один короткий запрос без параллельных повторов. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из model plaza. |
| Настройки не применились | Сохраните конфигурацию и полностью перезапустите инструмент. |
