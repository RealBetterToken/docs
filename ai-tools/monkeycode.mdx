MonkeyCode 是企业级 AI 开发平台。通过 BetterToken 接入时，请统一使用 Codex 分组和 OpenAI 类协议。

## 前置条件

- 已注册 MonkeyCode 账号（访问 [MonkeyCode 官网](https://monkeycode.ai) 注册）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="登录 MonkeyCode">
    访问 [MonkeyCode 官网](https://monkeycode.ai) 登录账号。
  </Step>

  <Step title="打开系统配置">
    进入任务页面后，点击右下角的 **配置**。
  </Step>

  <Step title="绑定 AI 大模型">
    在 **AI 大模型** 模块中点击 **绑定**。
  </Step>

  <Step title="填写 BetterToken 配置">

    | 配置项 | 值 |
    |--------|-----|
    | 模型 API 地址 | `https://www.bettertoken.ai/v1/` |
    | API Key | 你的 BetterToken API Key |
    | 接口格式类型 | `OpenAI` 或 `OpenAI Compatible`（以当前界面为准） |
    | 模型名称 | 从模型广场复制的 **Codex 分组模型 ID** |
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="保存并开始使用">
    点击 **保存**，返回主界面后选择刚配置的模型开始使用。
  </Step>
</Steps>

<Note>
  若当前版本无法设置 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`。
</Note>
