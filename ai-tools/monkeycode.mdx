MonkeyCode 是企业级 AI 开发平台，覆盖需求→设计→开发→Review 全流程。通过 BetterToken 可以为 MonkeyCode 提供稳定的 Claude 模型接入。

## 前置条件

- 已注册 MonkeyCode 账号（访问 [MonkeyCode 官网](https://monkeycode.ai) 注册）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="登录 MonkeyCode">
    访问 [MonkeyCode 官网](https://monkeycode.ai) 登录账号。
  </Step>

  <Step title="进入任务页面">
    登录后，点击**开始使用**按钮，进入 MonkeyCode 智能开发平台任务页面。
  </Step>

  <Step title="打开系统配置">
    点击页面右下角的**配置**按钮，进入系统配置页面。
  </Step>

  <Step title="绑定 AI 大模型">
    在 **AI 大模型**模块中，点击**绑定**按钮。
  </Step>

  <Step title="填写 BetterToken 配置">
    按以下信息填写：

    | 配置项 | 值 |
    |--------|-----|
    | 模型 API 地址 | `https://www.bettertoken.com/v1` |
    | API Key | 你的 BetterToken API Key |
    | 接口格式类型 | `anthropic` |
    | 模型名称 | `claude-sonnet-4-5` |

    填写完成后，点击**保存**按钮使配置生效。
  </Step>

  <Step title="开始使用">
    返回 MonkeyCode 主界面，输入 Prompt 后点击**执行**，即可调用 BetterToken 路由的 Claude 模型。
  </Step>
</Steps>

## 支持的模型

| 模型名称 | 说明 |
|----------|------|
| `claude-sonnet-4-5` | 均衡，推荐日常使用 |
| `claude-opus-4-5` | 最强能力，适合复杂 Agent 任务 |
| `claude-haiku-4-5` | 速度最快，适合高频调用 |
