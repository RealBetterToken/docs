Roo Code 是 VS Code 的 AI 编程助手插件。接入 BetterToken 只需在设置界面选择 OpenAI Compatible 提供商并填写配置。

## 前置条件

- 已安装 VS Code
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Roo Code

打开 VS Code，在扩展市场搜索 **Roo Code**，点击 Install 安装，安装完成后重启 VS Code。

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="打开 Roo Code 设置">
    点击 Roo Code 侧边栏中的 **Settings** 按钮，进入参数配置界面。
  </Step>

  <Step title="配置 API 提供商">
    按以下方式填写：

    - **API Provider** → 选择 `OpenAI Compatible`
    - **Base URL** → 填入 `https://www.BetterToken.ai/v1`
    - **API Key** → 填入你的 BetterToken API Key
    - **Model** → 填入 `claude-sonnet-4-6`（或其他支持模型）

    <Note>
      Roo Code 的 OpenAI Compatible 提供商需要接口支持 OpenAI 风格的 tool calling。若模型可以聊天但工具调用失败，请先确认当前模型和接口支持 tool calling。
    </Note>
  </Step>

  <Step title="保存配置">
    依次点击右上角的 **Save** 和 **Done** 按钮保存配置。
  </Step>

  <Step title="开始使用">
    在 VS Code 中打开 Roo Code 面板，选择已配置的模型开始使用。
  </Step>
</Steps>

## 支持的模型

| 模型名称 | 说明 |
|----------|------|
| `claude-sonnet-4-6` | 均衡，推荐日常编程 |
| `claude-opus-4-6` | 最强能力，适合复杂任务 |
| `claude-haiku-4-6` | 速度最快，适合简单补全 |
| `gpt-5.4` | OpenAI 旗舰模型 |
| `gpt-5.4-mini` | 轻量版，响应更快 |
