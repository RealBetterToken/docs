Roo Code 是 VS Code 的 AI 编程助手插件。接入 BetterToken 时，请选择 OpenAI Compatible 提供商，并使用 Codex 分组模型 ID。

## 前置条件

- 已安装 VS Code
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Roo Code

打开 VS Code，在扩展市场搜索 **Roo Code**，点击 Install 安装，安装完成后重启 VS Code。

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="打开 Roo Code 设置">
    点击 Roo Code 侧边栏中的 **Settings**。
  </Step>

  <Step title="配置 API 提供商">
    按以下方式填写：

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `https://www.bettertoken.ai/v1`
    - **API Key** → 你的 BetterToken API Key
    - **Model** → 从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="保存并开始使用">
    点击 **Save** 和 **Done**，然后选择刚配置的 Codex 分组模型。
  </Step>
</Steps>

<Note>
  Roo Code 的 OpenAI Compatible 提供商需要接口支持 OpenAI 风格 tool calling。若当前版本无法设置 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`。
</Note>
