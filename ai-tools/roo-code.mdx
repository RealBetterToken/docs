Настройка Roo Code выполняется через OpenAI-compatible provider: укажите API Key BetterToken, Base URL `{{openai-base-url}}` и точный Model ID.

## Roo Code: настройка и проверка, если он не работает

Если Roo Code не работает после сохранения, откройте новый чат, проверьте выбранный provider и перезапустите VS Code. Для сравнения смотрите [Cline](/ai-tools/cline) и [Kilo Code](/ai-tools/kilo-code), а адрес проверьте по [руководству по Base URL](/faq/model-calling/base-url-config).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установленный VS Code

## Установка

### Установка Roo Code

Откройте VS Code, найдите **Roo Code** в marketplace расширений и установите его.

## Ручная настройка

Выполните эту настройку в интерфейсе Roo Code. Редактировать конфигурационный файл вручную не требуется.

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройка

<Steps>
  <Step title="Очистите конфликтующие переменные окружения">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Откройте настройки Roo Code">
    Откройте панель **Settings** в Roo Code.
  </Step>

  <Step title="Настройте API provider">
    Заполните:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → ваш API Key BetterToken
    - **Model** → Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Материалы Roo Code, которые мы проверяли, описывают OpenAI-compatible или custom API setup, но не делают дополнительный `User-Agent` обязательным шагом для BetterToken.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Сохраните и начните использовать">
    Нажмите **Save** и **Done**, затем выберите настроенную модель.
  </Step>

  <Step title="Перезапустите Roo Code">
    После сохранения перезапустите VS Code или перезагрузите расширение Roo Code перед выбором модели.
  </Step>
</Steps>

<Note>
  OpenAI Compatible provider в Roo Code зависит от OpenAI-style tool calling. Если вам нужны extra headers, следуйте актуальной документации Roo Code или требованиям вашего upstream gateway.
</Note>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key BetterToken и удалите лишние пробелы. |
| Roo Code не работает после сохранения | Убедитесь, что выбран provider BetterToken, откройте новый чат и выполните **Developer: Reload Window**. |
| `connection error` | Проверьте доступ к `{{openai-base-url}}` и отключите конфликтующий прокси. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из model plaza. |
| Настройки не применились | Сохраните конфигурацию и полностью перезапустите инструмент. |
