在 TRAE 中接入 BetterToken 时，请选择 OpenAI 类提供商，并使用 Codex 分组模型 ID。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="打开模型配置">
    点击 **+ 添加模型**，在服务商选择中选择 **Custom** 或 **OpenAI Compatible**。
  </Step>

  <Step title="填写 BetterToken 配置">

    | 配置项 | 值 |
    |--------|-----|
    | API 地址 | `https://www.bettertoken.ai/v1` |
    | API Key | 你的 BetterToken API Key |
    | 模型名称 | 从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID** |
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    当前我们没有查到 TRAE 官方接入说明要求 BetterToken 额外配置 `User-Agent`。默认先按页面中的 `Base URL`、API Key 和模型 ID 完成接入即可。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="保存并开始使用">
    保存配置后，选择刚添加的 Codex 分组模型开始使用。
  </Step>

  <Step title="重启 TRAE">
    修改配置后，请关闭并重新打开 TRAE，再选择刚添加的模型。
  </Step>
</Steps>

<Note>
  不要继续填写 Claude 系列固定模型名。如需额外 headers，请以 TRAE 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 BetterToken 必填项。
</Note>
