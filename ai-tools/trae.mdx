Чтобы подключить TRAE к BetterToken, подготовьте API Key, укажите Base URL из таблицы ниже и выберите актуальный Model ID в каталоге моделей.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Полный URL запроса | `{{chat-completions-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

## Установка

Установите или откройте TRAE, затем перейдите к ручной настройке ниже.

## Ручная настройка

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Полный URL запроса | `{{chat-completions-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройка

<Steps>
  <Step title="Откройте настройки">
    В режиме **IDE** нажмите иконку **Settings** в правом верхнем углу, чтобы открыть центр настроек.

    Также можно открыть режим **SOLO** и нажать иконку **Settings** в правом верхнем углу панели чата.
  </Step>

  <Step title="Откройте панель модели">
    В левом меню выберите **Model**, чтобы открыть панель **Model**.
  </Step>

  <Step title="Добавьте модель">
    Нажмите **+ Add model**.

    ![Панель моделей TRAE с выделенными входом в настройки, пунктом Model и кнопкой Add model.](/images/trae/add-model.png)
  </Step>

  <Step title="Заполните конфигурацию модели">
    Когда появится окно **Add model**, заполните поля так:

    | Поле | Значение |
    |------|----------|
    | Provider | `OpenAI` |
    | Model | `Custom model` |
    | Model ID | Model ID провайдера **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | API key | ваш API Key из консоли BetterToken |
    | Custom request URL | `{{chat-completions-url}}` |

    ![Окно добавления модели TRAE с выбранным OpenAI, custom model и полями model ID, API key и custom request URL.](/images/trae/model-config.png)
  </Step>

  <Step title="Сохраните и начните использовать">
    Нажмите **Confirm**, чтобы сохранить конфигурацию, затем выберите новую модель поддерживаемого провайдера.
  </Step>
</Steps>

<Note>
  BetterToken поддерживает TRAE только через модели провайдера **GPT**. Не используйте фиксированные имена Claude-моделей и не задавайте custom request URL как `{{openai-base-url}}`.
</Note>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key BetterToken и удалите лишние пробелы. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из model plaza. |
| Настройки не применились | Сохраните конфигурацию и полностью перезапустите инструмент. |

## Технические детали

<Accordion title="Протокол, endpoint и внутренние параметры provider">
  В описанном сценарии используется Base URL `{{openai-base-url}}`. Инструмент сам добавляет путь OpenAI-compatible endpoint. Не добавляйте `/chat/completions` или `/responses` к Base URL, если это не требуется конкретным полем.
