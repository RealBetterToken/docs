在 TRAE 中接入 BetterToken，需要通过设置界面添加自定义模型。

## 前置条件

- 已安装 TRAE（前往 [TRAE 官网](https://www.trae.ai) 下载）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="打开模型设置">
    在 TRAE AI 对话框右上角，点击**设置**图标，进入设置界面后选择**模型**页签。
  </Step>

  <Step title="添加自定义模型">
    点击 **+ 添加模型** 按钮，在服务商选择中选择 **Custom**（自定义）或 **OpenAI Compatible**。
  </Step>

  <Step title="填写 BetterToken 配置">
    按以下信息填写：

    | 配置项 | 值 |
    |--------|-----|
    | API 地址 | `https://www.BetterToken.ai/v1` |
    | API Key | 你的 BetterToken API Key |
    | 模型名称 | `claude-sonnet-4-6`（或其他支持模型） |

  </Step>

  <Step title="完成添加">
    点击**添加模型**按钮。TRAE 会自动验证 API Key 是否有效：

    - 验证成功：模型会出现在可选列表中
    - 验证失败：请检查 API Key 和 API 地址是否正确
  </Step>

  <Step title="选择模型开始使用">
    回到对话界面，在模型下拉菜单中选择刚添加的模型，即可开始使用。
  </Step>
</Steps>

## 支持的模型

| 系列 | 模型名称 | 说明 |
|------|----------|------|
| Claude | `claude-sonnet-4-6` | 均衡，推荐日常编程 |
| Claude | `claude-opus-4-6` | 最强能力，适合复杂任务 |
| Claude | `claude-haiku-4-6` | 速度最快，适合快速补全 |
| GPT | `gpt-5.4` | OpenAI 旗舰模型 |
| GPT | `gpt-5.4-mini` | 轻量版，响应更快 |
