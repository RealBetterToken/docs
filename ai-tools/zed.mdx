Zed 支持添加自定义 LLM Provider。通过 BetterToken 接入时，请使用 OpenAI 方案，并粘贴 GPT 分组模型 ID。

## 前置条件

- 已安装 Zed（参考 [Zed 官方文档](https://zed.dev/docs) 安装）
- 已获取 BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）

## 配置步骤

<Steps>
  <Step title="打开 AI 面板">
    点击 Zed 右下角的 ✨ 图标。
  </Step>

  <Step title="进入配置页面">
    点击右上角菜单，选择 **Settings**。
  </Step>

  <Step title="添加 Provider">
    在 **LLM Provider** 中点击 **+ Add Provider**，并选择 **OpenAI**。
  </Step>

  <Step title="填写 BetterToken 配置">

    | 配置项 | 值 |
    |--------|-----|
    | Provider Name | `BetterToken` |
    | API URL | `{{openai-base-url}}` |
    | API Key | 你的 BetterToken API Key |
    | Model Name | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **GPT 分组模型 ID** |
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    我们查到的 Zed 官方 OpenAI Compatible / 自定义 provider 文档默认聚焦 `api_url`、`available_models` 和 API Key，没有把额外 `User-Agent` 列为 BetterToken 接入的必填项。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="保存配置">
    点击 **Save Provider** 保存，然后在模型列表中选择刚配置的模型。
  </Step>

  <Step title="重启 Zed">
    修改配置后，请重启 Zed，再从模型列表中选择刚配置的模型。
  </Step>
</Steps>

<Note>
  优先检查 `API URL`、API Key、模型 ID 和工具版本；不要默认把 `User-Agent` 当作 BetterToken 必填项。
</Note>
