Zed 支持添加自定义 LLM Provider。通过 BetterToken 接入时，请使用 OpenAI 方案，并粘贴 Codex 分组模型 ID。

## 前置条件

- 已安装 Zed（参考 [Zed 官方文档](https://zed.dev/docs) 安装）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="打开 AI 面板">
    点击 Zed 右下角的 ✨ 图标。
  </Step>

  <Step title="进入配置页面">
    点击右上角菜单，选择 **Settings**。
  </Step>

  <Step title="添加 Provider">
    在 **LLM Provider** 中点击 **+ Add Provider**，并选择 **OpenAI**。
  </Step>

  <Step title="填写 BetterToken 配置">

    | 配置项 | 值 |
    |--------|-----|
    | Provider Name | `BetterToken` |
    | API URL | `https://www.bettertoken.ai/v1/` |
    | API Key | 你的 BetterToken API Key |
    | Model Name | 从模型广场复制的 **Codex 分组模型 ID** |
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="保存配置">
    点击 **Save Provider** 保存，然后在模型列表中选择刚配置的模型。
  </Step>
</Steps>

<Note>
  若当前版本无法设置自定义 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`。
</Note>
