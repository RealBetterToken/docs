Добавьте OpenAI-compatible провайдер в **Agent Settings** Zed, затем укажите API Key BetterToken, Base URL и Model ID. Ключ, сохранённый через этот экран, попадает в системное хранилище ключей, а не в `settings.json`.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| Provider | `BetterToken` |
| API Key | `YOUR_API_KEY` |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## Подготовка

- Установите актуальную версию [Zed](https://zed.dev/docs)
- <a href={"{{register-url}}"}>Создайте API Key BetterToken</a>
- Скопируйте `YOUR_MODEL_ID` из <a href={"{{model-plaza-url}}"}>model plaza</a>

## Установка

Установите или обновите Zed до актуальной версии с [официального сайта](https://zed.dev). Запустите Zed, затем откройте Agent settings по шагам ниже.

## Ручная настройка

<Steps>
  <Step title="Добавьте OpenAI-compatible провайдер">
    Нажмите **Add Provider**, выберите **OpenAI Compatible** и укажите `BetterToken` в поле Provider Name.
  </Step>

  <Step title="Заполните параметры подключения">

    | Поле | Значение |
    | --- | --- |
    | API URL | `{{openai-base-url}}` |
    | API Key | `YOUR_API_KEY` |
    | Model ID | `YOUR_MODEL_ID` |

    Укажите только Base URL. Zed самостоятельно формирует путь Chat Completions.
  </Step>

  <Step title="Сохраните API Key">
    Сохраните провайдер в настройках Zed. Приложение поместит API Key в локальное системное хранилище и не запишет его в `settings.json`.
  </Step>

  <Step title="Выберите модель">
    Откройте список моделей в Agent Panel и выберите `YOUR_MODEL_ID` у провайдера `BetterToken`.
  </Step>
</Steps>

<Warning>
  Не добавляйте `YOUR_API_KEY` в `settings.json`, файлы проекта или Git-репозиторий.
</Warning>

### Необязательно: объявите провайдер и модель в `settings.json`

Если нужно управлять списком моделей через файл, выполните `zed: open settings file`. В файле оставьте только провайдер, `api_url` и параметры модели:

```json
{
  "language_models": {
    "openai_compatible": {
      "BetterToken": {
        "api_url": "{{openai-base-url}}",
        "available_models": [
          {
            "name": "YOUR_MODEL_ID",
            "display_name": "YOUR_MODEL_ID",
            "max_tokens": 128000
          }
        ]
      }
    }
  }
}
```

Zed требует `max_tokens` как объявление контекстного окна. Укажите значение для выбранной модели. API Key вводите в **Agent Settings**, чтобы его сохранило системное хранилище.

## Проверка подключения

1. Выберите `BetterToken / YOUR_MODEL_ID` в Agent Panel.
2. Отправьте короткое тестовое сообщение.
3. Обычный ответ без ошибок авторизации или модели означает, что подключение работает.

После изменения провайдера или модели полностью закройте и заново откройте Zed.

## Смена модели

Выберите другую модель BetterToken в списке Agent Panel. Для добавления Model ID скопируйте актуальное значение из <a href={"{{model-plaza-url}}"}>model plaza</a>, затем обновите настройки провайдера или `available_models`.

## Частые ошибки

| Ошибка | Решение |
| --- | --- |
| `401` или `Unauthorized` | Повторно введите API Key BetterToken в Agent Settings и удалите пробелы по краям. |
| `404` | Укажите `{{openai-base-url}}` как API URL; не добавляйте `/chat/completions`. |
| `model not found` | Скопируйте `YOUR_MODEL_ID` заново из model plaza. |
| Настройки не применились | Сохраните провайдер, полностью закройте Zed и откройте снова. |
| Используется старый ключ | Удалите переменную окружения провайдера, которая переопределяет системное хранилище, и перезапустите Zed. |

## Технические детали

<Accordion title="Системное хранилище, settings.json и endpoint">
  Zed обращается к BetterToken через OpenAI-compatible провайдер. Экран настроек сохраняет ключ в системном хранилище; в `settings.json` остаются только провайдер, `api_url` и модель. Используйте `{{openai-base-url}}` как Base URL: путь Chat Completions Zed добавит самостоятельно.
</Accordion>
