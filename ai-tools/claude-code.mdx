Задайте Claude Code Anthropic Base URL `{{anthropic-base-url}}`, API Key BetterToken и точный Model ID. Claude Code API error чаще всего появляется из-за неверного Base URL, ключа или недоступной модели.

## Claude Code Anthropic Base URL и API error

Base URL для Claude Code не содержит `/v1`: приложение само добавляет путь Anthropic Messages. Начните с [руководства по Claude Code custom API endpoint, API Key и Base URL](/faq/claude-code/api-key-base-url), а различия протоколов проверьте в статье [OpenAI-compatible и Anthropic-compatible API](/faq/concepts/openai-compatible-vs-anthropic-compatible). Для GPT перейдите к [расширенной настройке](#расширенная-настройка).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{anthropic-base-url}}` |
| Model | Выбирается Claude Code |

## Подготовка

- Установите последнюю версию [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- Установите Node.js
- <a href={"{{register-url}}"}>Создайте и скопируйте API Key BetterToken</a>

## Установка

```bash
npm install -g @anthropic-ai/claude-code
```

## Настройка командой

Скрипт Automatic setup от BetterToken записывает конфигурацию provider для Claude Code. Для него нужен Node.js; если API Key не передан параметром, скрипт запросит его интерактивно.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

После выполнения проверьте `~/.claude/settings.json` (в Windows — `%USERPROFILE%\.claude\settings.json`) и полностью перезапустите Claude Code. Если нужен контроль каждого поля, используйте ручную настройку ниже.

## Ручная настройка

### Настройка провайдера Claude

Claude Code CLI читает:

| Система | Файл |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

Добавьте:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000"
  }
}
```

Для провайдера Claude нужны только эти четыре переменные. Не добавляйте `ANTHROPIC_MODEL` или `ANTHROPIC_DEFAULT_*_MODEL`.

### Настройка провайдера Kimi или GLM

Для Kimi и GLM добавьте сопоставление моделей в тот же `settings.json`. Замените каждый `YOUR_MODEL_ID` на Model ID из окна Setup или model plaza:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

Можно использовать один Model ID во всех трёх полях или разные модели одного провайдера. Не указывайте здесь GPT: для него используйте расширенную настройку в конце страницы.

### Настройка расширения Claude Code для VS Code

Расширение использует `settings.json` VS Code. Добавьте отдельную настройку `claudeCode.environmentVariables`:

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    }
  ]
}
```

Выполните **Developer: Reload Window** или полностью перезапустите VS Code.

## Проверка подключения

Запустите Claude Code в проекте:

```bash
claude
```

Отправьте короткое сообщение. Обычный ответ без ошибок `401`, соединения или модели подтверждает настройку. После изменения файла полностью перезапустите Claude Code.

## Смена модели

- Провайдер Claude: выбором модели управляет Claude Code. Не добавляйте `ANTHROPIC_MODEL` или `ANTHROPIC_DEFAULT_*_MODEL`.
- Провайдер Kimi или GLM: измените `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` и `ANTHROPIC_DEFAULT_OPUS_MODEL`, затем полностью перезапустите Claude Code.
- Провайдер GPT: для смены модели используйте [расширенную настройку](#расширенная-настройка) ниже.

## Частые ошибки

| Ошибка | Решение |
| --- | --- |
| `401` или ошибка авторизации | Проверьте `ANTHROPIC_AUTH_TOKEN` и удалите пробелы вокруг API Key. |
| `403` | Проверьте, доступна ли выбранная модель для API Key. Не заменяйте Anthropic Base URL адресом OpenAI-compatible API. |
| `500` или `timeout` | Повторите короткий запрос. Если ошибка сохраняется, выберите другую доступную модель и проверьте запрос в Dashboard. |
| `ConnectionRefused` | Используйте точно `{{anthropic-base-url}}`, не добавляя `/v1`. |
| Модель не найдена | Для Claude не задавайте модель вручную. Для Kimi или GLM проверьте актуальность всех трёх значений `ANTHROPIC_DEFAULT_*_MODEL`. |
| Конфигурация не применилась | Проверьте путь, очистите конфликтующие переменные окружения и полностью перезапустите Claude Code. |
