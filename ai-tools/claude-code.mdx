在 Claude Code 中接入 BetterToken，核心配置项是 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`。**不要**给 Claude Code 的 Base URL 加 `/v1`。

## 前置条件

- 已安装 Claude Code（参考 [Claude Code 官方文档](https://docs.anthropic.com/en/docs/claude-code) 安装）
- 已获取 BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）

<Warning>
  配置前请确保清除以下环境变量，避免它们覆盖配置文件中的设置：

  ```bash
  unset ANTHROPIC_AUTH_TOKEN
  unset ANTHROPIC_BASE_URL
  ```
</Warning>

## 配置步骤

<Tabs>
  <Tab title="自动配置">
    你可以直接运行 BetterToken 提供的自动配置脚本。它只负责写入 BetterToken provider 配置，不替代页面上方的安装前置条件。脚本需要 `Node.js`。如果你没有显式传入 API Key 或模型，脚本会按工具能力提示你交互输入。

    按你的操作系统执行对应步骤。你只需要执行其中一项。

    <Steps>
      <Step title="如果你使用 macOS / Linux">
        ```bash
        curl -fsSL {{anthropic-base-url}}/install-claudecode-provider.sh | bash
        ```
      </Step>
      <Step title="如果你使用 Windows">
        ```powershell
        iwr {{anthropic-base-url}}/install-claudecode-provider.ps1 -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="通过 CC-Switch 配置">
    这条接入路径由 [CC Switch 接入文档](/ai-tools/cc-switch#claude-code) 统一维护。

    直接查看 [CC Switch 中的 Claude Code 配置步骤](/ai-tools/cc-switch#claude-code)。

    通过 CC Switch 完成配置后，再回到本页继续参考启动、验证或生效说明。
  </Tab>

  <Tab title="手动配置">
    <Steps>
      <Step title="确认 API Key 分组">
        先确认你当前使用的是哪一类 BetterToken API Key：

        - **Claude 分组**：只需要填写 `ANTHROPIC_BASE_URL` 与 `ANTHROPIC_AUTH_TOKEN`
        - **GPT 分组**：除了基础认证外，还需要配置 Claude Code 的模型映射

        两种分组都继续使用 Anthropic 协议，`ANTHROPIC_BASE_URL` 都填写 `{{anthropic-base-url}}`，不要添加 `/v1`。
      </Step>

      <Step title="编辑 Claude Code 配置文件">
        配置文件路径：

        - macOS / Linux：`~/.claude/settings.json`
        - Windows：`%USERPROFILE%\.claude\settings.json`

        如果你使用 **Claude 分组**，将以下内容写入配置文件（`YOUR_API_KEY` 替换为你的 BetterToken API Key）：

        ```json
        {
          "env": {
            "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
            "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
            "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
            "API_TIMEOUT_MS": "3000000"
          }
        }
        ```

        <Note>
          **Claude 分组**下**无需**设置 `ANTHROPIC_MODEL`、`ANTHROPIC_SMALL_FAST_MODEL`、`ANTHROPIC_DEFAULT_SONNET_MODEL` 等模型变量。Claude Code 会自行管理模型选择。
        </Note>
      </Step>

      <Step title="如使用 GPT 分组，补充模型映射">
        如果你的 API Key 属于 **GPT 分组**，请改为以下配置：

        <Tip>
          如果你使用 **GPT 分组**，优先建议通过 [CC Switch](/ai-tools/cc-switch#claude-code) 配置。它更适合处理 Claude Code 里的模型映射和代理开关。只有在你明确需要直接维护配置文件时，再使用下面的手动配置。
        </Tip>

        ```json
        {
          "env": {
            "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
            "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
            "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
            "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gpt-5.4",
            "ANTHROPIC_DEFAULT_SONNET_MODEL": "gpt-5.4",
            "ANTHROPIC_DEFAULT_OPUS_MODEL": "gpt-5.4",
            "API_TIMEOUT_MS": "3000000"
          },
          "model": "opus"
        }
        ```

        字段说明：

        | 字段 | 说明 |
        | --- | --- |
        | `ANTHROPIC_AUTH_TOKEN` | 你的 BetterToken API Key |
        | `ANTHROPIC_BASE_URL` | BetterToken 的 Claude Code `Base URL` |
        | `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | 设为 `1`，减少非必要后台请求 |
        | `ANTHROPIC_DEFAULT_HAIKU_MODEL` | Haiku 级别任务使用的模型 |
        | `ANTHROPIC_DEFAULT_SONNET_MODEL` | Sonnet 级别任务使用的模型 |
        | `ANTHROPIC_DEFAULT_OPUS_MODEL` | Opus 级别任务使用的模型 |
        | `model` | Claude Code 默认使用的模型级别；设为 `opus` 时会调用 `ANTHROPIC_DEFAULT_OPUS_MODEL` |

        <Note>
          示例里的 `gpt-5.4` 是一个 **GPT 分组**模型 ID 示例。实际使用时，请以 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 中当前可用的 **GPT 分组**模型 ID 为准。三个级别可以填写同一个模型，也可以分别映射不同模型。
        </Note>
      </Step>

      <Step title="重启 Claude Code">
        修改配置文件后，先完全退出 Claude Code，再重新启动，使新配置生效。
      </Step>

      <Step title="完成首次启动">
        如果这是你第一次使用 Claude Code，直接运行 `claude` 并按界面提示完成首次启动流程。
      </Step>

      <Step title="启动 Claude Code">
        进入你的工作目录，运行：

        ```bash
        claude
        ```

        首次启动时，选择 **Trust This Folder**，允许 Claude Code 访问该目录中的文件。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 在 VS Code 插件中使用

如果你使用 Claude Code 的 VS Code 插件，配置方式如下：

<Steps>
  <Step title="安装插件">
    在 VS Code 插件市场搜索并安装 **Claude Code**。
  </Step>
  <Step title="打开设置">
    点击插件设置图标，进入配置界面。
  </Step>
  <Step title="配置环境变量">
    如果你使用 **Claude 分组**，点击 **Edit in settings.json**，将 `claudeCode.environmentVariables` 修改为：

    ```json
    {
      "claudeCode.environmentVariables": [
        {
          "name": "ANTHROPIC_BASE_URL",
          "value": "{{anthropic-base-url}}"
        },
        {
          "name": "ANTHROPIC_AUTH_TOKEN",
          "value": "YOUR_API_KEY"
        },
        {
          "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
          "value": "1"
        },
        {
          "name": "API_TIMEOUT_MS",
          "value": "3000000"
        }
      ]
    }
    ```
  </Step>

  <Step title="如使用 GPT 分组，补充模型映射">
    如果你的 API Key 属于 **GPT 分组**，请改为：

    ```json
    {
      "claudeCode.environmentVariables": [
        {
          "name": "ANTHROPIC_BASE_URL",
          "value": "{{anthropic-base-url}}"
        },
        {
          "name": "ANTHROPIC_AUTH_TOKEN",
          "value": "YOUR_API_KEY"
        },
        {
          "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
          "value": "1"
        },
        {
          "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL",
          "value": "gpt-5.4"
        },
        {
          "name": "ANTHROPIC_DEFAULT_SONNET_MODEL",
          "value": "gpt-5.4"
        },
        {
          "name": "ANTHROPIC_DEFAULT_OPUS_MODEL",
          "value": "gpt-5.4"
        },
        {
          "name": "API_TIMEOUT_MS",
          "value": "3000000"
        }
      ]
    }
    ```

    <Note>
      示例里的 `gpt-5.4` 仅作为 **GPT 分组**模型 ID 示例。请从 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 复制当前可用的 **GPT 分组**模型 ID。插件内默认按 Opus 级别使用时，会优先命中 `ANTHROPIC_DEFAULT_OPUS_MODEL`。
    </Note>
  </Step>

  <Step title="重启 VS Code 插件">
    修改 `settings.json` 后，请重启 VS Code 或重新加载 Claude Code 插件，使配置生效。
  </Step>
</Steps>

## 验证配置

启动 Claude Code 后，在终端中发送一条消息。收到正常回复即表示配置成功。

如遇到认证错误，请检查：
1. `ANTHROPIC_AUTH_TOKEN` 是否填写了正确的 BetterToken API Key
2. `ANTHROPIC_BASE_URL` 是否填写为 `{{anthropic-base-url}}`
3. **Claude 分组**是否避免填写模型变量，**GPT 分组**是否已配置 `ANTHROPIC_DEFAULT_*_MODEL`
4. 是否有旧的环境变量在覆盖配置文件

## 常见问题

<AccordionGroup>
  <Accordion title="报错 API Error: Unable to connect to API (ConnectionRefused) 怎么办？">
    这通常表示 Claude Code 没有连上 BetterToken API，一般是网络连接异常、代理异常或防火墙拦截，不是 API Key 或模型配置错误。

    请先检查本机网络是否正常，再确认系统代理、公司网络、路由器或安全软件是否拦截了 `{{anthropic-base-url}}`。如果你设置了防火墙，请允许 Claude Code 访问该地址。
  </Accordion>
</AccordionGroup>
