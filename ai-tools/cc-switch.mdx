CC Switch — кроссплатформенное desktop-приложение для управления providers в Claude Code, Claude Desktop, Codex, OpenCode и OpenClaw. На этой странице собраны расширенные настройки. Сначала используйте прямую настройку нужного инструмента, а CC Switch подключайте для смены provider или работы с неродной моделью.

## Установка CC Switch

<Tabs>
  <Tab title="macOS">
    Самый простой вариант — Homebrew. Также можно скачать актуальный `.dmg` или `.zip` из [GitHub Releases](https://github.com/farion1231/cc-switch/releases).

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    Скачайте актуальный installer `CC-Switch-v{version}-Windows.msi` или portable `.zip` build из [GitHub Releases](https://github.com/farion1231/cc-switch/releases).
  </Tab>
  <Tab title="Linux">
    Скачайте актуальный `.deb`, `.rpm` или `.AppImage` build из [GitHub Releases](https://github.com/farion1231/cc-switch/releases).
  </Tab>
</Tabs>

## Что подготовить

- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)
- Claude Code использует Anthropic-протокол, поэтому его `Base URL` — `{{anthropic-base-url}}`
- Для Claude Desktop с провайдером, отличным от Claude, нужны последние версии Claude Desktop и CC Switch `v3.16.5` или новее
- Codex, OpenCode и OpenClaw используют OpenAI-compatible protocol, поэтому их `Base URL` — `{{openai-base-url}}`
- Подготовьте актуальный Model ID провайдера **GPT** для Codex, OpenCode и OpenClaw. Его можно скопировать из <a href={"{{model-plaza-url}}"}>BetterToken model plaza</a> или дать CC Switch получить его из `/v1/models`

<Info>
  При первом запуске CC Switch автоматически импортирует конфигурации, которые уже находит на вашей машине. Можно оставить официальный provider как fallback и добавить BetterToken рядом с ним.
</Info>

<Note>
  BetterToken использует два режима доступа: Anthropic и OpenAI-compatible. Чтобы не смешивать `{{anthropic-base-url}}` и `{{openai-base-url}}`, лучше создавать providers отдельно для каждого приложения, а не пытаться использовать один универсальный provider для Claude Code и OpenAI-compatible инструментов.
</Note>

## Добавьте provider BetterToken

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    <Steps>
      <Step title="Откройте Claude Code в CC Switch и добавьте provider">
        Откройте CC Switch, переключитесь на **Claude Code** и нажмите **Add Provider**.

        <Frame>
          <img
            src="/images/cc-switch/claude-code-add-provider.png"
            alt="Страница Claude Code в CC Switch, кнопка добавления provider в правом верхнем углу."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Заполните базовые поля">
        - **Provider Name**: `BetterToken-claude` (или другое понятное имя для различения provider)
        - **Base URL**: `{{anthropic-base-url}}`
        - **API Key**: ваш API Key BetterToken
        - **API Format**: `OpenAI Responses API`

        Нумерованные маркеры на скриншоте соответствуют этим полям:

        1. **Provider Name**
        2. **API Key**
        3. **Base URL**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-basic-fields.png"
            alt="Страница редактирования Claude Code provider в CC Switch с полями Provider Name, API Key и API Endpoint."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Настройте model mapping по провайдеру">
        - Если вы используете провайдер **Claude**, обычно не нужно менять advanced options или model mapping
        - Если вы используете провайдер **GPT**, выполните дополнительную настройку ниже:

        1. Откройте **Advanced Options**
        2. Установите **API Format** в **OpenAI Responses API**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-api-format.png"
            alt="Advanced Options в CC Switch, API Format установлен в OpenAI Responses API."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        3. В **Model Mapping** нажмите **Fetch Model List**
        4. Явно выберите значения в dropdown для **Primary Model**, **Thinking Model**, **Haiku Default Model**, **Sonnet Default Model** и **Opus Default Model**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-model-mapping.png"
            alt="Раздел model mapping в CC Switch с Fetch Model List и mappings для Primary, Thinking, Haiku, Sonnet и Opus."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Все эти модели должны использовать актуальные model IDs провайдера **GPT** из <a href={"{{model-plaza-url}}"}>BetterToken model plaza</a>.
      </Step>

      <Step title="Сохраните, переключитесь и решите, нужен ли proxy">
        После сохранения вернитесь к списку providers:

        1. Отметьте provider BetterToken как активный
        2. Если вы используете провайдер **Claude**, включать **CC Switch proxy** в левом верхнем углу не нужно
        3. Если вы используете провайдер **GPT**, включите **CC Switch proxy**

        На скриншоте ниже BetterToken-claude уже включен в списке providers. Включайте **CC Switch proxy** в левом верхнем углу только при использовании провайдера **GPT**.

        <Frame>
          <img
            src="/images/cc-switch/claude-code-enable-proxy.png"
            alt="Список providers CC Switch, где BetterToken-claude выбран и отмечен как In Use."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

      <Step title="Заполните основные поля">
        - **Provider Name**: понятное имя, например `BetterToken-GPT`
        - **API Key**: ваш API Key BetterToken
        - **API Endpoint**: `{{anthropic-base-url}}`

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-basic-fields.png"

          />
        </Frame>

        Сопоставьте Sonnet, Opus, Fable и Haiku с нужным Model ID:

        | Model role | Requested model |
        | --- | --- |
        | Sonnet | `YOUR_MODEL_ID` |
        | Opus | `YOUR_MODEL_ID` |
        | Fable | `YOUR_MODEL_ID` |
        | Haiku | `YOUR_MODEL_ID` |

        <Frame>
          <img

## Как применить сохраненные изменения

После сохранения и переключения providers перезапустите затронутый client или gateway перед проверкой настройки.

- Claude Code: полностью завершите текущую сессию Claude Code, затем запустите ее заново.
- Claude Desktop: полностью закройте приложение, откройте его снова и убедитесь, что в левом нижнем углу отображается **Gateway**.
- Codex: перезапустите текущий процесс Codex или откройте новую terminal session.
- OpenCode: завершите текущую сессию OpenCode и запустите ее снова.
- OpenClaw: выполните `openclaw gateway restart`, затем используйте `/new`, `/status` и `/model` в Discord.

## Расширенные функции CC Switch

CC Switch может сохранять официальный вход Codex при переключении на сторонний provider и объединять официальные и сторонние сеансы в одной истории. После включения этих параметров перезапустите Codex. См. [сохранение официального входа Codex и общей истории сеансов](/faq/codex/official-login-third-party-api).

## Частые проблемы

- Не добавляйте `/v1` к Claude Code `Base URL`
- Когда Claude Code использует провайдера **GPT**, установите **API Format** в **OpenAI Responses API** в **Advanced Options**
- Когда Claude Code использует провайдера **Claude**, включать **CC Switch proxy** не нужно
- Для Claude Desktop с провайдером, отличным от Claude, включите **CC Switch proxy** и полностью перезапустите приложение
- Codex, OpenCode и OpenClaw должны использовать `{{openai-base-url}}`
- Когда Codex, OpenCode или OpenClaw запрашивает модель, используйте Model ID провайдера **GPT**
- Если **Fetch Models** не работает, проверьте API key и `Base URL`, затем вставьте model ID вручную
- Если переключение не вступило в силу, убедитесь, что BetterToken активный provider в CC Switch, и перезапустите затронутый client или gateway, как описано выше
