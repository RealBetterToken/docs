Droid — CLI coding assistant от Factory AI. Через BYOK можно подключить LLMEasy как custom OpenAI-compatible provider.

## Требования

- API Key LLMEasy (<a href={"{{register-url}}"}>зарегистрироваться</a>)

## Установка Droid

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://app.factory.ai/cli | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://app.factory.ai/cli/windows | iex
    ```
  </Tab>
</Tabs>

## Настройка

<Steps>
  <Step title="Очистите конфликтующие переменные окружения">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Задайте API Key LLMEasy">
    ```bash
    export LLMEASY_API_KEY="YOUR_API_KEY"
    ```
  </Step>

  <Step title="Отредактируйте конфиг Droid">
    Путь к конфигу: `~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "LLMEasy Codex",
          "model": "YOUR_GPT_MODEL_ID",
          "baseUrl": "{{openai-base-url}}",
          "apiKey": "${LLMEASY_API_KEY}",
          "provider": "openai",
          "maxOutputTokens": 64000
        }
      ]
    }
    ```

    Замените `YOUR_GPT_MODEL_ID` на актуальный ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Мы не нашли официального требования Droid, по которому `User-Agent` обязателен для LLMEasy. Начните с `Base URL`, API key и model ID на этой странице.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Перезапустите Droid">
    После обновления конфигурации или переменных окружения остановите текущий процесс Droid и запустите его снова.
  </Step>

  <Step title="Запустите Droid">
    ```bash
    cd /path/to/your/project
    droid
    ```
  </Step>
</Steps>

<Note>
  Если ваша версия называет provider `OpenAI Compatible` вместо `openai`, следуйте текущему названию в UI. Extra headers добавляйте только по документации Droid или требованиям вашего upstream gateway.
</Note>
