Droid 是 Factory AI 的 CLI 编程助手。通过 BYOK 配置，可以将 BetterToken 作为自定义 Anthropic 兼容提供商接入。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Droid

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://app.factory.ai/cli | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://app.factory.ai/cli/windows | iex
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    <Warning>
      必须清除 `ANTHROPIC_AUTH_TOKEN` 环境变量，否则它会覆盖配置文件中的 API Key 导致认证失败。
    </Warning>

    ```bash
    unset ANTHROPIC_AUTH_TOKEN
    unset ANTHROPIC_BASE_URL
    ```
  </Step>

  <Step title="设置 BetterToken API Key">
    ```bash
    export BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```

    将 `YOUR_API_KEY` 替换为你的 BetterToken API Key。需要长期生效时，将这行添加到 `~/.zshrc` 或 `~/.bashrc`。
  </Step>

  <Step title="编辑 Droid 配置文件">
    配置文件路径：`~/.factory/settings.json`

    <Note>
      `~/.factory/config.json` 的旧版 snake_case 写法仍可兼容，但 Factory 当前推荐使用 `settings.json`。当两个文件同时存在时，`settings.json` 优先级更高。
    </Note>

    添加以下内容：

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Claude",
          "model": "claude-sonnet-4-6",
          "baseUrl": "https://www.BetterToken.ai/v1",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "anthropic",
          "maxOutputTokens": 64000
        }
      ]
    }
    ```
  </Step>

  <Step title="进入项目目录并启动 Droid">
    ```bash
    cd /path/to/your/project
    droid
    ```
  </Step>

  <Step title="选择模型">
    在 Droid 中输入 `/model`，选择 **BetterToken Claude** 开始使用。
  </Step>
</Steps>

## 使用多个模型

如果需要同时配置多个模型，在 `customModels` 数组中添加多条记录即可：

```json
{
  "customModels": [
    {
      "displayName": "Claude Sonnet",
      "model": "claude-sonnet-4-6",
      "baseUrl": "https://www.BetterToken.ai/v1",
      "apiKey": "${BETTERTOKEN_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 64000
    },
    {
      "displayName": "Claude Opus",
      "model": "claude-opus-4-6",
      "baseUrl": "https://www.BetterToken.ai/v1",
      "apiKey": "${BETTERTOKEN_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 32000
    }
  ]
}
```
