Droid 是 Factory AI 的 CLI 编程助手。通过 BYOK 配置，可以将 BetterToken 作为自定义 OpenAI 兼容提供商接入。

## 前置条件

- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Droid

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://app.factory.ai/cli | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://app.factory.ai/cli/windows | iex
    ```
  </Tab>
</Tabs>

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="设置 BetterToken API Key">
    ```bash
    export BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```
  </Step>

  <Step title="编辑 Droid 配置文件">
    配置文件路径：`~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Codex",
          "model": "YOUR_CODEX_MODEL_ID",
          "baseUrl": "https://www.bettertoken.ai/v1",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "openai",
          "maxOutputTokens": 64000
        }
      ]
    }
    ```

    将 `YOUR_CODEX_MODEL_ID` 替换为从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**。
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="启动 Droid">
    ```bash
    cd /path/to/your/project
    droid
    ```
  </Step>
</Steps>

<Note>
  如果当前版本把 provider 文案显示为 `OpenAI Compatible`，以当前界面显示为准。若无法设置 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`。
</Note>
