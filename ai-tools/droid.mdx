Droid — CLI coding assistant от Factory AI. Через BYOK вы можете добавить BetterToken в `~/.factory/settings.json`, а затем выбрать модель группы GPT в меню `/model`.

## Требования

- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)
- Актуальный model ID из **группы ключа GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>

## Настройка

<Steps>
  <Step title="Задайте API Key BetterToken">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    Замените `YOUR_API_KEY` на ваш API Key BetterToken. Droid поддерживает подстановку `${BETTERTOKEN_API_KEY}` из переменной окружения в JSON-конфигурации.
  </Step>

  <Step title="Отредактируйте конфиг Droid">
    Путь к конфигу: `~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Codex",
          "model": "YOUR_GPT_MODEL_ID",
          "baseUrl": "{{openai-base-url}}",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "openai"
        }
      ]
    }
    ```

    Замените `YOUR_GPT_MODEL_ID` на актуальный ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Step>

  <Step title="Запустите Droid и выберите модель">
    ```bash
    cd /path/to/your/project
    droid
    ```

    Введите `/model` и выберите **BetterToken Codex**. Factory отслеживает изменения файла настроек. Если список моделей не обновился, полностью закройте и снова запустите Droid.
  </Step>

  <Step title="Проверьте на небольшой задаче">
    Сначала отправьте короткую задачу, например «Объясни структуру каталогов этого проекта». После успешного ответа переходите к изменениям в нескольких файлах и длительным agent-задачам.
  </Step>
</Steps>

<Note>
  Поле `provider` должно содержать `openai`. В BYOK-конфигурации Factory это значение выбирает OpenAI Responses API. Используйте `{{openai-base-url}}` и API Key из **группы ключа GPT**.
</Note>

## Частые ошибки

| Симптом | Что проверить |
| --- | --- |
| Кастомной модели нет в `/model` | Проверьте синтаксис JSON и наличие полей `model`, `baseUrl`, `apiKey` и `provider` |
| `Invalid provider` | Используйте точное значение `"openai"` в нижнем регистре, а не название из интерфейса |
| `401` или `403` | Скопируйте API Key заново, убедитесь, что процесс Droid видит `BETTERTOKEN_API_KEY`, и проверьте баланс |
| `404` или Model not found | Используйте `{{openai-base-url}}` и скопируйте актуальный GPT model ID из model plaza |
| После изменения осталась старая модель | Снова откройте `/model`; если список не обновился, полностью перезапустите Droid |

## FAQ

### Почему нужна группа ключа GPT?

`provider: "openai"` в Droid использует OpenAI Responses API. Группа ключа GPT в BetterToken предоставляет соответствующий OpenAI-compatible endpoint и model ID.

### Нужны ли дополнительные headers?

Для обычного подключения BetterToken дополнительные headers не нужны. Добавляйте tenant, routing или audit headers только в том случае, если их явно требует другой используемый вами gateway.

### Где посмотреть цены и расход?

Актуальные цены моделей смотрите в <a href={"{{model-plaza-url}}"}>model plaza</a>. Расход запросов и баланс доступны в Dashboard BetterToken.
