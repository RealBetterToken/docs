影刀AI Power 是一款无需代码即可搭建 AI 应用的产品。它全面聚合现有的 AI 大模型，提供了一套极简的 AI 应用搭建工具。

接入 BetterToken 时，请在影刀AI Power 中添加 `OpenAI-API-compatible` 模型，并使用 GPT 分组模型 ID。

## 前置条件

- 已获取 BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）
- 已在<a href={"{{model-plaza-url}}"}>模型广场</a>复制要使用的 **GPT 分组模型 ID**

## 配置步骤

<Steps>
  <Step title="打开模型管理">
    进入 **企业管理**，选择 **模型管理**。找到 **OpenAI-API-compatible**，点击 **添加模型**。

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-management.png"
        alt="影刀AI Power 企业管理的模型管理页面，标出了 OpenAI-API-compatible 和添加模型入口。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="填写模型配置">
    在 **授权管理：OpenAI-API-compatible** 窗口中，按下面的方式填写：

    | 配置项 | 值 |
    |--------|-----|
    | 模型类型 | `LLM` |
    | 模型名称 | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **GPT 分组模型 ID** |
    | 请求地址 | `{{chat-completions-url}}` |
    | API 密钥 | 仅支持选择 `Codex*` 分组对应的密钥 |
    | 最大输出 Token 上限 | `128000` |
    | 是否支持视觉理解 | 选择 **是** |
    | 是否支持函数调用 | 选择 **是** |

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-config.png"
        alt="影刀AI Power 的 OpenAI-API-compatible 授权管理窗口，展示模型名称、请求地址、API 密钥、最大输出 Token 上限、视觉理解和函数调用配置。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="启用视觉理解">
    **是否支持视觉理解** 选择 **是** 后，模型才可以在 **工作流-多模态大模型** 组件里选择使用。

    <Frame>
      <img
        src="/images/yingdao-ai-power/workflow-multimodal-model.png"
        alt="影刀AI Power 工作流页面中，多模态大模型组件可以选择 OpenAI-API-compatible 和已添加的模型。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="启用函数调用">
    **是否支持函数调用** 选择 **是** 后，模型才可以在 **智能体-工具** 里选择使用。

    <Frame>
      <img
        src="/images/yingdao-ai-power/agent-tool-model.png"
        alt="影刀AI Power 智能体工具页面中，模型设置里可以选择 OpenAI-API-compatible 和已添加的模型。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="继续添加其他模型">
    如果需要使用多个模型，请按以上步骤继续添加模型。每个模型都使用对应的 GPT 分组模型 ID。
  </Step>
</Steps>

<Note>
  影刀AI Power 的 **请求地址** 需要填写完整的 chat completions 地址 `{{chat-completions-url}}`，不要只填写 `{{openai-base-url}}`。
</Note>
