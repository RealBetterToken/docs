Чтобы подключить Continue CLI к BetterToken, подготовьте API Key, укажите Base URL из таблицы ниже и выберите актуальный Model ID в каталоге моделей.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установите Node.js 20 или новее, если используете установку через npm

### Настройте API Key и Base URL

<Steps>
  <Step title="Задайте переменную окружения API Key">
    <Tabs>
      <Tab title="macOS / Linux">
        Выполните команду в том же терминале, из которого будете запускать Continue CLI:

        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>

      <Tab title="Windows PowerShell">
        Выполните команду в том же окне PowerShell, из которого будете запускать Continue CLI:

        ```powershell
        $env:BETTERTOKEN_API_KEY = "YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    Замените `YOUR_API_KEY` на ваш API Key BetterToken. Не добавляйте ключ в Git и не сохраняйте его в общей конфигурации.
  </Step>

  <Step title="Создайте config.yaml">
    Создайте или отредактируйте файл в пользовательской директории:

    - macOS / Linux: `~/.continue/config.yaml`
    - Windows: `%USERPROFILE%\.continue\config.yaml`

    Добавьте конфигурацию:

    ```yaml
    name: BetterToken
    version: 0.0.1
    schema: v1

    models:
      - name: BetterToken GPT
        provider: openai
        model: YOUR_MODEL_ID
        apiBase: "{{openai-base-url}}"
        apiKey: ${{ secrets.BETTERTOKEN_API_KEY }}
        useResponsesApi: false
    ```

    `YOUR_MODEL_ID` приведён только как пример. Замените его на актуальный ID модели у провайдера **GPT** в model plaza.
  </Step>

  <Step title="Запустите Continue CLI">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        cn --config ~/.continue/config.yaml
        ```
      </Tab>

      <Tab title="Windows PowerShell">
        ```powershell
        cn --config "$env:USERPROFILE\.continue\config.yaml"
        ```
      </Tab>
    </Tabs>

    Можно сначала перейти в каталог проекта, а затем выполнить команду. После загрузки конфигурации введите задачу прямо в Continue CLI.
  </Step>
</Steps>

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

После изменения `model` в `config.yaml` завершите текущую сессию `cn` и запустите её снова. Model ID должен быть совместим с настроенным endpoint.

Для отдельной конфигурации одного проекта сохраните файл в проекте и явно укажите путь:

```bash
cn --config ./continue-bettertoken.yaml
```

## Частые ошибки

| Симптом | Что делать |
| --- | --- |
| `401`, `Unauthorized` или ошибка API Key | Убедитесь, что `BETTERTOKEN_API_KEY` задан в текущем терминале и относится к **поддерживаемый провайдер**. |
| `model not found` или модель недоступна | Скопируйте актуальный ID у провайдера **GPT** в model plaza. Не используйте модель провайдера Claude. |
| Continue использует старую конфигурацию | Запускайте `cn --config` с явным путём к файлу. Проверьте имя файла `config.yaml`. |
| Неверный URL запроса или `404` | Проверьте, что `apiBase` равен `{{openai-base-url}}`. Не добавляйте `/chat/completions` или имя модели. |
| Переменная API Key не подставляется | Задайте `BETTERTOKEN_API_KEY` в том же терминале, где запускаете `cn`, затем запустите команду снова. |

### FAQ по настройке

**Какой Base URL использовать в Continue CLI?**

Используйте `{{openai-base-url}}`. Это OpenAI-compatible Base URL BetterToken.

**Можно использовать модель provider Claude?**

Нет. В этой конфигурации Continue CLI используется OpenAI-compatible API, поэтому нужен API Key BetterToken и модель, совместимую с настроенным endpoint.

**Как посмотреть или сменить сохранённую конфигурацию?**

Введите `/config` в сессии Continue CLI, чтобы посмотреть и выбрать локальную конфигурацию.
