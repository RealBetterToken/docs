Grok CLI 通过环境变量配置 API 地址和 Key。接入 BetterToken 时，请使用 `/v1/` 地址，并指定 Codex 分组模型 ID。

<Warning>
  Grok CLI 更适合轻量场景。如需完整 Agent 工作流，优先使用 Claude Code、Codex CLI 或 OpenClaw。
</Warning>

## 前置条件

- 已安装 Node.js
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 安装 Grok CLI

```bash
npm install -g @vibe-kit/grok-cli
```

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="设置 BetterToken 环境变量">
    ```bash
    export GROK_BASE_URL="https://www.bettertoken.ai/v1/"
    export GROK_API_KEY="YOUR_API_KEY"
    ```
  </Step>

  <Step title="启动 Grok CLI 并指定模型">
    ```bash
    grok --model YOUR_CODEX_MODEL_ID
    ```

    将 `YOUR_CODEX_MODEL_ID` 替换为从模型广场复制的 **Codex 分组模型 ID**。
  </Step>
</Steps>

<Note>
  若当前版本不支持补充自定义 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`。
</Note>
