Под названием Grok CLI сейчас могут подразумевать два разных инструмента:

- **Grok Build** — официальный coding agent от xAI;
- **Community Grok CLI** — open-source-проект сообщества, не связанный с xAI.

Официальный Grok Build и Community Grok CLI прошли проверку с BetterToken. Оба клиента вернули ответ модели с API Key BetterToken, Base URL и Model ID. В этой инструкции первым рассматривается **Community Grok CLI**, потому что его проще настроить.

<Warning>
  Оба инструмента используют команду `grok`. Если установить их вместе, терминал запустит версию, которая стоит раньше в `PATH`. Из-за этого настройки могут не примениться. Оставьте один клиент или установите их в разных окружениях.
</Warning>

## Чем отличаются Grok CLI и Grok Build

| Параметр | Официальный Grok Build | Community Grok CLI |
| --- | --- | --- |
| Разработчик | xAI | `superagent-ai/grok-cli`, не связан с xAI |
| Кому подходит | Тем, кому нужен официальный coding agent xAI | Тем, кому нужен пользовательский Base URL для модели |
| Авторизация по умолчанию | Вход через браузер или `XAI_API_KEY` | `GROK_API_KEY` |
| Пользовательский Base URL | Настраивается в `~/.grok/config.toml` | Задаётся через `GROK_BASE_URL` |
| Выбор модели | Alias модели в конфигурационном файле | Переменная `GROK_MODEL` |
| Запросы через BetterToken | Проверено, работает | Проверено, работает |
| Команда запуска | `grok` | `grok` |

В этой инструкции рассматриваются только запросы к текстовым моделям и моделям для работы с кодом. Функции на основе отдельных API xAI — X Search, распознавание речи, генерация изображений и видео — здесь не поддерживаются.

## Подключение Community Grok CLI к BetterToken

Команды ниже подходят для macOS, Linux и WSL. Установка и настройка Community Grok CLI в Windows без WSL не проверялись.

### Установка

```bash
curl -fsSL https://raw.githubusercontent.com/superagent-ai/grok-cli/main/install.sh | bash
grok --version
```

Если Bun уже установлен, используйте альтернативный способ:

```bash
bun add -g grok-dev
```

Старый пакет `@vibe-kit/grok-cli` больше не указан в текущем README проекта как рекомендуемый способ установки.

### Настройка BetterToken

```bash
export GROK_BASE_URL="{{openai-base-url}}"
export GROK_API_KEY="YOUR_API_KEY"
export GROK_MODEL="YOUR_MODEL_ID"
```

Замените `YOUR_MODEL_ID` на полный Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a>. Используйте свой API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>.

### Проверка подключения

```bash
grok -p "Ответь только: OK"
```

API Key, Base URL и Model ID работают, только если модель вернула ответ. Запуск клиента сам по себе не подтверждает подключение.

<Note>
  Community Grok CLI прошёл проверку: модель вернула ответ через BetterToken. Результат относится только к описанным здесь запросам к текстовым моделям и моделям для работы с кодом, а не к вызовам инструментов или отдельным функциям xAI.
</Note>

Открытая сессия Grok CLI не подхватит новые переменные окружения автоматически. После изменения настроек завершите сессию и запустите клиент снова.

### Смена модели

Укажите другой полный Model ID в `GROK_MODEL`, перезапустите Grok CLI и повторите короткий запрос.

## Официальный Grok Build

[Grok Build](https://docs.x.ai/build/overview) — официальный терминальный coding agent xAI. Он работает в интерактивном TUI, headless-режиме и через ACP.

### Установка

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    grok --version
    ```
  </Tab>
</Tabs>

### Вход через аккаунт xAI или API Key

При первом запуске Grok Build открывает браузер для входа. Для среды без браузера xAI документирует `XAI_API_KEY`:

```bash
export XAI_API_KEY="YOUR_XAI_API_KEY"
grok
```

### Дополнительно: настройка BetterToken в Grok Build

Grok Build поддерживает OpenAI-compatible пользовательские модели. Для них можно задать Base URL, Model ID, переменную окружения с ключом и протокол запросов.

```toml
[model.bettertoken]
model = "YOUR_MODEL_ID"
base_url = "{{openai-base-url}}"
name = "BetterToken"
env_key = "BETTERTOKEN_API_KEY"
api_backend = "chat_completions"

[models]
default = "bettertoken"
```

`BETTERTOKEN_API_KEY` — имя переменной только для этого примера, а не обязательное имя в Grok Build. Клиент читает переменную, указанную в `env_key`.

```bash
export BETTERTOKEN_API_KEY="YOUR_API_KEY"
grok inspect
grok -p "Ответь только: OK" -m bettertoken
```

<Note>
  Grok Build вернул ответ модели с API Key BetterToken, Base URL и Model ID. Проверка охватывает только описанные здесь запросы к текстовым моделям и моделям для работы с кодом, но не вызовы инструментов и отдельные API xAI.
</Note>

## Как избежать конфликта команды `grok`

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    type -a grok
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    Get-Command grok -All
    grok --version
    ```
  </Tab>
</Tabs>

Команды `type -a grok` и `Get-Command grok -All` показывают все исполняемые файлы с этим именем. Если установлены два клиента, удалите ненужный или измените `PATH`.

## Частые ошибки

| Симптом | Что проверить |
| --- | --- |
| После установки запускается не тот Grok | Выведите все команды `grok`, затем проверьте путь и версию. |
| Официальный Grok Build открывает браузер | Это стандартный вход в Grok Build. Для xAI продолжите вход, а для BetterToken настройте пользовательскую модель. |
| `401` или `Unauthorized` | Пользовательская модель Grok Build читает переменную из `env_key`, а Community Grok CLI — `GROK_API_KEY`. Задайте только переменную текущего клиента. |
| `model not found` | Скопируйте полный Model ID из model plaza и перезапустите клиент. |
| Запрос уходит на xAI | Для Community Grok CLI проверьте `GROK_BASE_URL`. В Grok Build запустите `grok inspect` и проверьте `base_url` и активный alias модели. |
| Не работает функция xAI | BetterToken обрабатывает только описанные здесь запросы к моделям. Для X Search, речи и медиа используйте официальный API xAI. |

## Доступные модели и ограничения функций

Скопируйте из <a href={"{{model-plaza-url}}"}>model plaza</a> полный Model ID с поддержкой OpenAI-compatible запросов. Возможность изменить Base URL сама по себе не подтверждает совместимость запросов, вызовов инструментов и формата контекста для конкретной модели.

<Note>
  Страница описывает только запросы к текстовым моделям и моделям для работы с кодом. BetterToken не предоставляет через эту настройку X Search, распознавание речи, генерацию изображений, видео и другие отдельные API xAI.
</Note>
