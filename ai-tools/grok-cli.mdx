Чтобы подключить кастомный API к Grok CLI, установите CLI, задайте Base URL `{{openai-base-url}}` и API Key BetterToken, затем запустите инструмент с ID модели из группы **GPT**. Для этого подключения не нужен отдельный VPN endpoint или локальный proxy.

<Info>
  Grok CLI использует OpenAI-compatible API BetterToken. Введите только базовый адрес `{{openai-base-url}}`; не добавляйте `/chat/completions` в переменную `GROK_BASE_URL`.
</Info>

<Warning>
  Grok CLI лучше подходит для легких задач в терминале. Для полноценного agent workflow используйте Claude Code, Codex CLI или OpenClaw.
</Warning>

## Что нужно подготовить

- Node.js и `npm`
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться</a>
- ID доступной модели из группы **GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>

## Установите Grok CLI

В Windows, macOS и Linux выполните:

```bash
npm install -g @vibe-kit/grok-cli
```

Если после установки команда `grok` не найдена, закройте терминал, откройте его снова и выполните `grok --help`. Проверьте, что каталог глобальных пакетов `npm` добавлен в `PATH`.

## Настройте Base URL и API Key

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="Очистите конфликтующие переменные">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="Задайте переменные BetterToken">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="Запустите Grok CLI с моделью">
        ```bash
        grok --model YOUR_GPT_MODEL_ID
        ```

        Замените `YOUR_GPT_MODEL_ID` на текущий ID модели из группы **GPT** в model plaza.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="Задайте переменные для текущего окна PowerShell">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="Запустите Grok CLI с моделью">
        ```powershell
        grok --model YOUR_GPT_MODEL_ID
        ```

        Переменные в этом примере действуют только в текущем окне PowerShell. После открытия нового окна задайте их снова через безопасный способ хранения секретов, принятый в вашей команде.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Проверьте подключение

После запуска отправьте короткий запрос в Grok CLI. Если инструмент отвечает без ошибки авторизации или model ID, подключение готово. При изменении переменных окружения всегда завершайте текущую сессию Grok CLI и запускайте новую.

## Частые ошибки

| Симптом | Что проверить |
| --- | --- |
| `grok: command not found` | Выполните установку еще раз, затем откройте новый терминал и проверьте `grok --help`. |
| `401`, `Unauthorized` или `Invalid API key` | Проверьте `GROK_API_KEY`, убедитесь, что в ключ не попал пробел, и запустите Grok CLI в том же окне терминала, где задана переменная. |
| `model not found` или модель недоступна | Скопируйте актуальный ID модели из группы **GPT** в model plaza. Не используйте ID из группы Claude. |
| Запрос уходит на прежний сервис | Проверьте `GROK_BASE_URL`, не добавляйте путь `/chat/completions`, затем перезапустите терминал и Grok CLI. |
| Ошибка соединения | Убедитесь, что Base URL равен `{{openai-base-url}}`, и что сеть разрешает HTTPS-соединения с `bettertoken.ai`. |

## Вопросы по настройке

**Какой Base URL нужен для Grok CLI?**

Используйте `{{openai-base-url}}`. Это OpenAI-compatible Base URL BetterToken.

**Какой API Key и модель выбрать?**

Для Grok CLI используйте API Key из группы **GPT** и модель из той же группы.

**Нужно ли менять системный proxy или включать VPN?**

Нет. Для подключения BetterToken достаточно настроить Base URL и API Key в терминале.
