Aider может подключаться к OpenAI-compatible API. Чтобы использовать BetterToken, задайте `OPENAI_API_BASE` и `OPENAI_API_KEY`, а затем запустите Aider с именем модели в формате `openai/model-id`.

<Info>
  Aider использует OpenAI-compatible API BetterToken. Укажите Base URL `{{openai-base-url}}`, API Key **группы ключа GPT** и модель из той же группы.
</Info>

## Перед началом

- Получите API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и начать</a>
- Скопируйте актуальный ID модели из **группы ключа GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>
- Установите Python

## Установите Aider

Выполните в терминале:

```bash
python -m pip install aider-install
aider-install
```

После установки проверьте, что Aider доступен:

```bash
aider --help
```

## Настройте BetterToken для текущего терминала

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"

    cd /path/to/your/project
    aider --model openai/gpt-5.6-sol
    ```
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell
    setx OPENAI_API_BASE "{{openai-base-url}}"
    setx OPENAI_API_KEY "YOUR_API_KEY"
    ```

    После `setx` закройте и снова откройте PowerShell. Затем перейдите в каталог проекта и выполните:

    ```powershell
    aider --model openai/gpt-5.6-sol
    ```
  </Tab>
</Tabs>

Замените `YOUR_API_KEY` на ваш API Key из **группы ключа GPT**. `gpt-5.6-sol` приведён только как пример. Замените его на актуальный ID из model plaza и сохраните префикс `openai/`.

## Сохраните конфигурацию в .env

Чтобы не задавать переменные при каждом запуске терминала, создайте файл `.env` в Git-корне проекта:

```dotenv
OPENAI_API_BASE={{openai-base-url}}
OPENAI_API_KEY=YOUR_API_KEY
AIDER_MODEL=openai/gpt-5.6-sol
```

Добавьте `.env` в `.gitignore`, чтобы API Key не попал в Git. Затем перейдите в каталог проекта и выполните:

```bash
aider
```

Чтобы использовать другой файл для одного проекта, укажите его явно:

```bash
aider --env-file ./aider-bettertoken.env
```

## Как сменить модель

Замените модель в команде запуска на актуальный ID из **группы ключа GPT**:

```bash
aider --model openai/YOUR_GPT_MODEL_ID
```

Не удаляйте префикс `openai/`. API Key и модель должны относиться к одной **группе ключа GPT**.

## Частые ошибки

| Симптом | Что делать |
| --- | --- |
| `401`, `Unauthorized` или `Invalid API key` | Проверьте `OPENAI_API_KEY`, убедитесь, что это API Key **группы ключа GPT**, и удалите лишние пробелы. |
| `model not found` или модель недоступна | Скопируйте актуальный ID из **группы ключа GPT** в model plaza и передайте его Aider в формате `openai/model-id`. |
| Неверный URL запроса или `404` | Проверьте, что `OPENAI_API_BASE` равен `{{openai-base-url}}`. Не добавляйте `/chat/completions`. |
| Windows не видит новые переменные | `setx` действует только в новых терминалах. Закройте текущее окно PowerShell и откройте новое. |
| Aider сообщает, что модель неизвестна | Сначала проверьте ID модели и группу API Key. Aider может показать предупреждение для новой модели, но используйте только актуальный ID из model plaza. |

## FAQ по настройке

**Какой Base URL использовать в Aider?**

Используйте `{{openai-base-url}}`. Это OpenAI-compatible Base URL BetterToken.

**Почему перед названием модели нужен префикс `openai/`?**

Aider использует этот префикс для определения OpenAI-compatible модели. Без него Aider может выбрать неправильный provider.

**Можно сохранить API Key в `.aider.conf.yml`?**

Не рекомендуем. Используйте переменные окружения или `.env`, который добавлен в `.gitignore`, чтобы снизить риск раскрытия API Key в файлах проекта.
