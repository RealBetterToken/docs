Чтобы подключить Aider к BetterToken, подготовьте API Key, укажите Base URL из таблицы ниже и выберите актуальный Model ID в каталоге моделей.

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установите Python

## Установка

### Установите Aider

Выполните в терминале:

```bash
python -m pip install aider-install
aider-install
```

После установки проверьте, что Aider доступен:

```bash
aider --help
```

## Ручная настройка

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

### Настройте BetterToken для текущего терминала

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"

    cd /path/to/your/project
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell
    setx OPENAI_API_BASE "{{openai-base-url}}"
    setx OPENAI_API_KEY "YOUR_API_KEY"
    ```

    После `setx` закройте и снова откройте PowerShell. Затем перейдите в каталог проекта и выполните:

    ```powershell
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>
</Tabs>

Замените `YOUR_API_KEY` на ваш API Key BetterToken. `YOUR_MODEL_ID` приведён только как пример. Замените его на актуальный ID из model plaza и сохраните префикс `openai/`.

### Сохраните конфигурацию в .env

Чтобы не задавать переменные при каждом запуске терминала, создайте файл `.env` в Git-корне проекта:

```dotenv
OPENAI_API_BASE={{openai-base-url}}
OPENAI_API_KEY=YOUR_API_KEY
AIDER_MODEL=openai/YOUR_MODEL_ID
```

Добавьте `.env` в `.gitignore`, чтобы API Key не попал в Git. Затем перейдите в каталог проекта и выполните:

```bash
aider
```

Чтобы использовать другой файл для одного проекта, укажите его явно:

```bash
aider --env-file ./aider-bettertoken.env
```

### Опционально: .aider.conf.yml

Чтобы сохранить только несекретные настройки, создайте `.aider.conf.yml` в домашнем каталоге или корне проекта:

```yaml
model: openai/YOUR_MODEL_ID
openai-api-base: "{{openai-base-url}}"
```

API Key по-прежнему передавайте через переменную `OPENAI_API_KEY`, а не через общий YAML-файл.

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

Замените модель в команде запуска на актуальный ID у провайдера **GPT**:

```bash
aider --model openai/YOUR_MODEL_ID
```

Не удаляйте префикс `openai/`. Model ID должен быть совместим с OpenAI-compatible endpoint.

## Частые ошибки

| Симптом | Что делать |
| --- | --- |
| `401`, `Unauthorized` или `Invalid API key` | Проверьте `OPENAI_API_KEY`, убедитесь, что это API Key BetterToken, и удалите лишние пробелы. |
| `model not found` или модель недоступна | Скопируйте актуальный ID у провайдера **GPT** в model plaza и передайте его Aider в формате `openai/model-id`. |
| Неверный URL запроса или `404` | Проверьте, что `OPENAI_API_BASE` равен `{{openai-base-url}}`. Не добавляйте `/chat/completions`. |
| Windows не видит новые переменные | `setx` действует только в новых терминалах. Закройте текущее окно PowerShell и откройте новое. |
| Aider сообщает, что модель неизвестна | Сначала проверьте ID модели и провайдер. Aider может показать предупреждение для новой модели, но используйте только актуальный ID из model plaza. |

### FAQ по настройке

**Какой Base URL использовать в Aider?**

Используйте `{{openai-base-url}}`. Это OpenAI-compatible Base URL BetterToken.

**Почему перед названием модели нужен префикс `openai/`?**

Aider использует этот префикс для определения OpenAI-compatible модели. Без него Aider может выбрать неправильный provider.

**Можно сохранить API Key в `.aider.conf.yml`?**

Не рекомендуем. Используйте переменные окружения или `.env`, который добавлен в `.gitignore`, чтобы снизить риск раскрытия API Key в файлах проекта.
