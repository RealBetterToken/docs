在 Cursor 中接入 BetterToken 时，使用 OpenAI Base URL。外部工具统一走 Codex 分组，请从[模型广场](https://www.bettertoken.ai/pricing)复制当前可用的模型 ID。

<Warning>
  Cursor 的自定义 API Key、自定义模型与 Base URL 能力受客户端版本与套餐限制。如果当前界面不支持这些选项，请以 Cursor 当前版本实际能力为准。
</Warning>

## 前置条件

- 已安装 Cursor（前往 [Cursor 官网](https://www.cursor.com) 下载）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="打开模型配置页面">
    在 Cursor 中，点击左下角 **Settings**，进入设置界面后选择 **Models**。
  </Step>

  <Step title="配置 BetterToken API">
    在 **API Keys** 部分：

    1. 勾选 **Override OpenAI Base URL**
    2. 填入 `https://www.bettertoken.ai/v1`
    3. 在 **OpenAI API Key** 中填入你的 BetterToken API Key
    4. 按界面提示完成验证
  </Step>

  <Step title="添加模型">
    在 **Models** 部分，点击 **View All Models**，再点击 **Add Custom Model**。

    模型名称请直接粘贴从[模型广场](https://www.bettertoken.ai/pricing)复制的 **Codex 分组模型 ID**。
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    我们查到的 Cursor 官方 API Key 文档没有把额外 `User-Agent` 列为 BetterToken / OpenAI 兼容接入的必填项。接入 BetterToken 时通常不需要额外设置 headers。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="重启 Cursor">
    修改配置后，请完全退出并重新打开 Cursor，再选择刚添加的模型。
  </Step>

  <Step title="选择模型并开始使用">
    在 Cursor 聊天面板中选择刚添加的 Codex 分组模型即可开始使用。
  </Step>
</Steps>

## 注意事项

- 不要继续填写固定 Claude 模型名
- 如需额外 headers，请以 Cursor 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 BetterToken 必填项
