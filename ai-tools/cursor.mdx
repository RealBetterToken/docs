在 Cursor 中接入 BetterToken 时，使用 OpenAI Base URL。外部工具统一走 Codex 分组，请从模型广场复制当前可用的模型 ID。

<Warning>
  Cursor 的自定义 API Key、自定义模型和自定义 headers 能力受客户端版本与套餐限制。如果当前界面不支持这些选项，请以 Cursor 当前版本实际能力为准。
</Warning>

## 前置条件

- 已安装 Cursor（前往 [Cursor 官网](https://www.cursor.com) 下载）
- 已获取 BetterToken API Key（[注册并获取](https://www.bettertoken.ai/register)）

## 配置步骤

<Steps>
  <Step title="打开模型配置页面">
    在 Cursor 中，点击左下角 **Settings**，进入设置界面后选择 **Models**。
  </Step>

  <Step title="配置 BetterToken API">
    在 **API Keys** 部分：

    1. 勾选 **Override OpenAI Base URL**
    2. 填入 `https://www.bettertoken.ai/v1/`
    3. 在 **OpenAI API Key** 中填入你的 BetterToken API Key
    4. 按界面提示完成验证
  </Step>

  <Step title="添加模型">
    在 **Models** 部分，点击 **View All Models**，再点击 **Add Custom Model**。

    模型名称请直接粘贴从模型广场复制的 **Codex 分组模型 ID**。
  </Step>

  <Step title="如支持自定义 headers，补齐必填项">
    如果当前版本提供自定义 headers 入口，请添加：

    ```json
    {
      "Authorization": "Bearer sk-xxx",
      "User-Agent": "codex_cli_rs/0.77.0 (Windows 10.0.26100; x86_64) WindowsTerminal"
    }
    ```
  </Step>

  <Step title="选择模型并开始使用">
    在 Cursor 聊天面板中选择刚添加的 Codex 分组模型即可开始使用。
  </Step>
</Steps>

## 注意事项

- 不要继续填写固定 Claude 模型名
- 如果当前版本不能设置自定义 headers，缺少对应 UA 时可能出现 `403 block` 或 `403 Forbidden`
