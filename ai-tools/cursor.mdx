Чтобы подключить Cursor custom API, укажите OpenAI Base URL `{{openai-base-url}}`, API Key BetterToken и точный Model ID. Если проверка ключа завершается ошибкой, проверьте адрес и повторно добавьте custom model.

## Cursor custom API и API Key error

Пошаговая настройка полей собрана в [FAQ по Cursor custom OpenAI API](/faq/cursor/custom-openai-api). Для сравнения интерфейсов откройте [Cline](/ai-tools/cline) и [Zed](/ai-tools/zed), а правила выбора адреса — в [руководстве по Base URL](/faq/model-calling/base-url-config).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установленный Cursor ([скачать Cursor](https://www.cursor.com))
- Вы будете использовать provider **GPT** и модель, совместимую с настроенным endpoint

## Установка

Скачайте и установите актуальную версию с [сайта Cursor](https://www.cursor.com). Войдите в аккаунт Cursor, который поддерживает custom models, затем перейдите к настройке ниже.

<Warning>
  Cursor позволяет настраивать custom models только пользователям платного advanced tier или выше. Если в вашем аккаунте или версии клиента нет опций custom model, API Key или Base URL, сначала проверьте план Cursor и версию клиента.
</Warning>

<Warning>
  **Известное ограничение:** **Override OpenAI Base URL** — глобальная настройка. Когда она включена, она влияет на все API keys, настроенные в Cursor, включая Anthropic / GPT keys для встроенных моделей Cursor. Официальное сообщество Cursor подтверждало это поведение: Base URL влияет на все API keys и модели ([обсуждение](https://forum.cursor.com/t/cursor-models-fail-when-using-byok-openai-key-with-overridden-base-url-glm-4-7/147218)).

  Если встроенные Claude / GPT модели Cursor перестали работать после включения **Override OpenAI Base URL**, выключайте **Override OpenAI Base URL**, когда не используете BetterToken. Cursor пока не поддерживает отдельный Base URL для каждой модели; эта возможность отслеживается как feature request ([feature request](https://forum.cursor.com/t/custom-base-urls-for-each-custom-model/147219)).
</Warning>

## Ручная настройка

Выполните эту настройку в интерфейсе Cursor. Редактировать конфигурационный файл вручную не требуется.

| Поле Cursor | Значение |
| --- | --- |
| **Override OpenAI Base URL** | Включить |
| **Base URL** | `{{openai-base-url}}` |
| **OpenAI API Key** | API Key BetterToken |
| Custom model | Полный Model ID поддерживаемого провайдера |

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

### Ошибки custom API и API Key

Перед сменой модели или API Key сравните текущие параметры с [настройкой Cursor custom OpenAI API](/faq/cursor/custom-openai-api).

### В Cursor нет полей Custom API, API Key или Base URL

Проверьте план и версию приложения Cursor. Custom models доступны только в поддерживаемых платных tiers. После обновления Cursor снова откройте **Settings** → **Models**.

### API Key не включается или не проходит проверку

Проверьте, что вы сначала ввели Base URL `{{openai-base-url}}` и API Key, а уже затем включили toggle **OpenAI API Key**. Не добавляйте `/chat/completions` к Base URL и не используйте Model ID, несовместимый с endpoint.

### После refresh нет нужной модели

Убедитесь, что выбранный Model ID доступен у провайдера **GPT**, дождитесь окончания refresh и включите только модель, совместимую с настроенным endpoint. Текущий список ID всегда доступен в model plaza.

### Встроенные модели Cursor перестали работать

**Override OpenAI Base URL** действует глобально. Когда вы не используете BetterToken, выключайте этот toggle, чтобы Cursor вернулся к собственному Base URL.

### В чате выбирается не та модель

Откройте model picker и выключите **Auto**. Затем выберите включенную модель вручную.

## Технические детали

<Accordion title="Протокол, endpoint и внутренние параметры provider">
  В описанном сценарии используется Base URL `{{openai-base-url}}`. Инструмент сам добавляет путь OpenAI-compatible endpoint. Не добавляйте `/chat/completions` или `/responses` к Base URL, если это не требуется конкретным полем.

### Примечания

- Не используйте ID моделей провайдера **Claude** в Codex / OpenAI-compatible flow
- Не используйте жестко заданные имена Claude-моделей; берите актуальный Model ID поддерживаемого провайдера из <a href={"{{model-plaza-url}}"}>model plaza</a>
</Accordion>
