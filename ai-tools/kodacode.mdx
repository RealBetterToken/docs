Настройка KodaCode выполняется через форму **Any OpenAI-compatible API**. Укажите API Key BetterToken, Base URL `{{openai-base-url}}` и точный Model ID.

## KodaCode: настройка и ошибка 429

Ошибка `429` не исправляется заменой Base URL. Проверьте доступность выбранной модели и состояние баланса, затем повторите один короткий запрос. Для сравнения откройте [MonkeyCode](/ai-tools/monkeycode) и [Cline](/ai-tools/cline), а Model ID возьмите из [руководства по моделям](/faq/model-calling/model-selection-guide).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{openai-base-url}}` |
| Model | Актуальный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a> |

## Подготовка

- Установленная актуальная версия инструмента
- API Key BetterToken: <a href={"{{register-url}}"}>зарегистрироваться и получить</a>
- Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>

### Дополнительные требования

- Установлен VS Code
- Установлено расширение Kodacode / Koda
- выбранный Model ID доступен у провайдера **GPT**

### Пример config.yaml

Ниже полная структура для проверки. Замените `YOUR_API_KEY` на ваш API Key BetterToken и не коммитьте реальный API Key в репозиторий.

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: YOUR_MODEL_ID
    provider: openai
    model: YOUR_MODEL_ID
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  Если вы используете не `YOUR_MODEL_ID`, измените и `name`, и `model`, чтобы они совпадали с Model ID поддерживаемого провайдера из <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Note>

### Troubleshooting

- Если подключение не работает, проверьте, что **API Base** равен `{{openai-base-url}}/`, включая завершающий `/`.
- Если модель недоступна, проверьте, что **Model ID** относится к поддерживаемый провайдер.
- Если возникает ошибка авторизации, скопируйте API Key заново и проверьте, что нет лишних пробелов или переносов строки.
- Если изменения в `config.yaml` не применились, перезапустите VS Code или выполните **Developer: Reload Window**.
- BetterToken обычно не требует дополнительного `User-Agent` или custom headers.

## Проверка подключения

Отправьте короткий тестовый запрос. Если инструмент возвращает ответ без ошибок авторизации или Model ID, подключение работает. После изменения конфигурации полностью перезапустите инструмент.

## Смена модели

Откройте селектор моделей или измените поле `Model` в конфигурации. Используйте точный Model ID из <a href={"{{model-plaza-url}}"}>каталога моделей</a>, затем перезапустите текущую сессию.

## Частые ошибки

| Ошибка | Что проверить |
| --- | --- |
| `401` или `Unauthorized` | Проверьте API Key и удалите лишние пробелы. |
| `429` | Проверьте доступность модели и состояние баланса. Не запускайте несколько повторов одновременно. |
| `404` | Проверьте Base URL и не добавляйте путь конкретного endpoint. |
| `model not found` | Скопируйте актуальный Model ID из каталога моделей. |
| Настройки не применились | Сохраните файл и полностью перезапустите инструмент. |
