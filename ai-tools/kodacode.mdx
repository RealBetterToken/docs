Расширение Kodacode для VS Code может использовать модели в chat, agent и edit workflows. Для подключения BetterToken добавьте модель **Any OpenAI-compatible API** и используйте API Key из группы GPT.

<Info>
  В этом руководстве показан пример для расширения VS Code. В документации Kodacode указано, что нужна версия VS Code `1.75` или новее, а ID расширения — `Koda.koda`.
</Info>

## Требования

- Установлен VS Code
- Установлено расширение Kodacode / Koda
- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)
- API Key относится к группе **GPT**
- ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>, например `gpt-5.5`

## Настройка

<Steps>
  <Step title="Откройте панель Koda и добавьте модель">
    Откройте панель **KODA** в боковой панели VS Code, нажмите на selector модели под полем ввода и выберите **Добавить модель: Agent** / **Add model: Agent**.

    <Frame>
      <img
        src="/images/kodacode/select-model-menu.png"
        alt="Выбор Add model: Agent в selector модели на панели Koda."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Заполните настройки OpenAI-compatible модели">
    В окне добавления модели заполните поля так:

    | Поле | Рекомендуемое значение |
    | --- | --- |
    | Provider | `Any OpenAI-compatible API` |
    | API Base | `{{openai-base-url}}/` |
    | Model ID | ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>, например `gpt-5.5` |
    | API Key | Ваш API Key BetterToken |

    После заполнения нажмите **Подключить** / **Connect**.

    <Frame>
      <img
        src="/images/kodacode/add-openai-compatible-model.png"
        alt="В окне добавления модели Kodacode выбран Any OpenAI-compatible API и заполнены API Base, Model ID и API Key."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Проверьте, что модель активна">
    После успешного подключения выберите новую модель, например `gpt-5.5`, в selector модели под полем ввода Koda. Отправьте короткое сообщение и проверьте, что ответ приходит.
  </Step>

  <Step title="Проверьте config.yaml">
    Kodacode записывает конфигурацию в `~/.koda/config.yaml`. Откройте этот файл и проверьте, что модель добавлена.

    <Frame>
      <img
        src="/images/kodacode/config-yaml-result.png"
        alt="Файл config.yaml Kodacode с добавленной OpenAI-compatible моделью."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## Пример config.yaml

Ниже полная структура для проверки. Замените `YOUR_API_KEY` на ваш API Key BetterToken и не коммитьте реальный API Key в репозиторий.

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: gpt-5.5
    provider: openai
    model: gpt-5.5
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  Если вы используете не `gpt-5.5`, измените и `name`, и `model`, чтобы они совпадали с ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Note>

## Troubleshooting

- Если подключение не работает, проверьте, что **API Base** равен `{{openai-base-url}}/`, включая завершающий `/`.
- Если модель недоступна, проверьте, что **Model ID** относится к группе GPT.
- Если возникает ошибка авторизации, скопируйте API Key заново и проверьте, что нет лишних пробелов или переносов строки.
- Если изменения в `config.yaml` не применились, перезапустите VS Code или выполните **Developer: Reload Window**.
- BetterToken обычно не требует дополнительного `User-Agent` или custom headers.
