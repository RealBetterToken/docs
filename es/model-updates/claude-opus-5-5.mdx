Fecha de lanzamiento: 22 de septiembre de 2026

Claude Opus 5.5 es el primer modelo de la familia Claude 5.5 de Anthropic. Según Anthropic, mejora frente a Opus 5 en programación de larga duración y trabajo profesional, y se comunica con más claridad durante sesiones extensas.

**Claude Opus 5.5** ya está disponible en BetterToken. Selecciona el proveedor `Claude`, configura Base URL como `{{anthropic-base-url}}` y usa `claude-opus-5-5` como Model ID. Consulta la disponibilidad y el precio actuales en el <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Aspectos destacados

- Cambios complejos de repositorio, auditorías y tareas agentivas de larga duración.
- Código listo para producción, documentos complejos y computer use.
- Comunicación más clara en sesiones largas, según las pruebas de Anthropic frente a Opus 5.

## Conexión

1. <a href={"{{register-url}}"}>Crea una BetterToken API Key</a>.
2. Selecciona `Claude` y Base URL `{{anthropic-base-url}}`.
3. Usa `claude-opus-5-5` como Model ID.
