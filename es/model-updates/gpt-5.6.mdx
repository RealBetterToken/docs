Fecha de lanzamiento: 10 de julio de 2026

BetterToken ya admite la familia de modelos GPT-5.6. Consulta en la <a href={"{{model-plaza-url}}"}>model plaza</a> los ID de modelo disponibles actualmente para el **proveedor GPT** y sus precios; después, úsalos en Codex, OpenCode, OpenClaw, Cursor, Cline, Zed u otras herramientas externas mediante el protocolo compatible con OpenAI.

Los nuevos ID de modelo son:

| ID del modelo | Uso recomendado |
| --- | --- |
| `gpt-5.6-sol` | Razonamiento complejo, repositorios grandes, tareas de agentes de varios pasos y flujos de programación prolongados |
| `gpt-5.6-terra` | Programación diaria, desarrollo interactivo, tareas habituales de agentes y equilibrio entre capacidad y coste |
| `gpt-5.6-luna` | Tareas ligeras donde importan la velocidad y el coste, como asistencia por lotes, preguntas rápidas, reescrituras sencillas y llamadas pequeñas a herramientas |

## Aspectos destacados

- **Tres niveles de modelo**: OpenAI orienta GPT-5.6 Sol, Terra y Luna a trabajos de razonamiento avanzado, tareas diarias equilibradas y tareas ligeras de gran volumen
- **Mejor para agentes de programación**: OpenAI destaca mejoras en agentes de programación, flujos de terminal y coordinación de herramientas
- **Preparado para herramientas externas**: el centro de ayuda de OpenAI confirma que Sol, Terra y Luna están disponibles mediante la API de OpenAI; en BetterToken, usa el **proveedor GPT** y `{{openai-base-url}}`
- **Elige según la carga**: empieza con `gpt-5.6-sol` para trabajos complejos, `gpt-5.6-terra` para desarrollo diario y `gpt-5.6-luna` para solicitudes ligeras o sensibles al coste

## Guía de configuración

Para Codex u otras herramientas compatibles con OpenAI, sigue la guía de configuración correspondiente:

- **Base URL**: `{{openai-base-url}}`
- **Proveedor**: elige el **proveedor GPT**
- **Nombre del modelo**: copia el ID de modelo actual desde la <a href={"{{model-plaza-url}}"}>model plaza</a>

<Note>
  No fijes un nombre de modelo que no aparezca en la model plaza. La disponibilidad, los precios y el estado de enrutamiento se consultan en la <a href={"{{model-plaza-url}}"}>model plaza</a> actual.
</Note>

## Inicio rápido

1. Crea una BetterToken API Key.
2. Establece `{{openai-base-url}}` como Base URL en tu herramienta.
3. Copia desde la model plaza un ID actual de `gpt-5.6-sol`, `gpt-5.6-terra` o `gpt-5.6-luna`.
4. Ejecuta primero una tarea de programación pequeña y comprueba el uso de la solicitud en el Dashboard.

Usa una de estas guías de configuración:

- [Configuración de Codex CLI y Codex App](/es/ai-tools/codex)
- [Configuración de OpenCode](/es/ai-tools/opencode)
- [Configuración de una API compatible con OpenAI en Cline](/es/faq/cline/openai-compatible-api)

## Cómo elegir

Si no sabes por dónde empezar, elige según la complejidad de la tarea:

- Usa `gpt-5.6-sol` para comprender repositorios grandes, modificar varios archivos, reparar pruebas, depurar durante ciclos largos y ejecutar tareas de agentes que necesiten mayor razonamiento
- Usa `gpt-5.6-terra` para programación diaria, explicación de código, refactorizaciones habituales, documentación y la mayoría de las tareas de desarrollo interactivo
- Usa `gpt-5.6-luna` para preguntas ligeras, asistencia por lotes, procesamiento de texto sencillo, llamadas a herramientas de baja latencia y solicitudes de gran volumen sensibles al coste

## Preguntas frecuentes

### ¿Qué modelo debo probar primero?

Empieza con `gpt-5.6-terra` para la mayoría de las tareas diarias de programación. Cambia a `gpt-5.6-sol` cuando la tarea necesite un razonamiento más profundo o usa `gpt-5.6-luna` cuando la latencia sea más importante.

### ¿Dónde puedo consultar el precio actual?

Consulta los precios y la disponibilidad actuales en la <a href={"{{model-plaza-url}}"}>model plaza</a>. Esta página no fija precios porque pueden cambiar.

### ¿Qué hago si la herramienta indica que no encuentra el modelo?

Vuelve a copiar el ID del modelo desde la model plaza, confirma que el modelo seleccionado esté disponible en el proveedor GPT y verifica `{{openai-base-url}}`. Consulta más comprobaciones en la [guía de selección de modelos](/es/faq/model-calling/model-selection-guide).
