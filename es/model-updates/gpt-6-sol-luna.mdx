Fecha de lanzamiento: 22 de septiembre de 2026

OpenAI amplía la familia GPT-6 con Sol y Luna junto a Astra. Sol se orienta a programación compleja y flujos agentivos; Luna, a tareas concretas y repetibles de alto volumen. Según OpenAI, ambos mejoran frente a GPT-5.6 en programación, precisión factual y comunicación.

BetterToken ahora admite **GPT-6 Sol** y **GPT-6 Luna**. Selecciona `GPT`, usa Base URL `{{openai-base-url}}` y elige `gpt-6-sol` o `gpt-6-luna`. El nombre oficial es **Sol**, no `Sora`.

Consulta la disponibilidad y el precio actuales de BetterToken en el <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Qué modelo elegir

- **`gpt-6-sol`**: para programación compleja y flujos agentivos.
- **`gpt-6-luna`**: para trabajo centrado, repetible y de alto volumen.

## Aspectos destacados

- **Contexto amplio**: OpenAI documenta una ventana de `1,050,000` tokens y hasta `128,000` tokens de salida para ambos modelos.
- **Razonamiento ajustable**: ambos admiten `none`, `low`, `medium`, `high`, `xhigh` y `max`.
- **Trabajo diario**: OpenAI señala mejoras frente a GPT-5.6 en programación, precisión factual y claridad técnica.

## Conexión

1. <a href={"{{register-url}}"}>Crea una BetterToken API Key</a>.
2. Selecciona `GPT` y Base URL `{{openai-base-url}}`.
3. Usa `gpt-6-sol` para agentes exigentes o `gpt-6-luna` para tareas repetibles de alto volumen.
