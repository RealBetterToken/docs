Fecha de lanzamiento: 28 de septiembre de 2026

Claude Sonnet 5.5 es el segundo modelo de la familia Claude 5.5 de Anthropic. La empresa lo presenta como una opción más rápida para tareas cotidianas bien delimitadas: programar, corregir errores y crear documentos, presentaciones y hojas de cálculo. Para trabajos más complejos y abiertos, considera Opus 5.5.

**Claude Sonnet 5.5** ya está disponible en BetterToken. Selecciona el proveedor `Claude`, configura la Base URL como `{{anthropic-base-url}}` y usa `claude-sonnet-5-5` como ID de modelo. Consulta la disponibilidad y el precio actuales en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Puntos destacados

- **Programación enfocada**: úsalo para implementaciones bien definidas y corrección de errores.
- **Contenido profesional**: Anthropic destaca la creación de documentos, presentaciones y hojas de cálculo.
- **Contexto largo**: Anthropic indica una ventana de contexto de 1 millón de tokens y un máximo de 128 000 tokens de salida.

## Antes de cambiar desde Sonnet 5

Si tu cliente llama directamente a la API Messages de Anthropic, consulta la [guía oficial de migración](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide) antes de cambiar el ID. Sonnet 5.5 modifica algunos comportamientos de thinking y selección de herramientas; prueba solicitudes representativas primero.

## Conexión

1. <a href={"{{register-url}}"}>Crea una BetterToken API Key</a>.
2. Selecciona el proveedor `Claude` y usa `{{anthropic-base-url}}` como Base URL.
3. Introduce `claude-sonnet-5-5` como ID de modelo.
4. Prueba una tarea real antes de cambiar el tráfico de producción.

Para configurar el cliente, consulta la [guía de Claude Code](/es/ai-tools/claude-code). Compara alternativas en la [guía de selección de modelos](/es/faq/model-calling/model-selection-guide).
