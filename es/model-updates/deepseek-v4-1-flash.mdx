## Recomendaciones de uso

Compara DeepSeek V4.1 Flash con otro modelo disponible en tareas relevantes para tu flujo de trabajo:

- **Cambios de código**: asigna a ambos modelos la misma tarea de repositorio y compara la corrección, la calidad de las modificaciones y el seguimiento necesario
- **Flujos de agentes**: mide la fiabilidad con la que cada modelo sigue instrucciones de varios pasos y utiliza las herramientas del cliente
- **Calidad del razonamiento**: compara tareas difíciles de depuración, planificación y análisis con el mismo prompt y los mismos criterios
- **Latencia y coste**: registra el tiempo hasta el primer token, la duración total, el uso de tokens y el precio actual de BetterToken

Ejecuta varios prompts representativos en lugar de confiar en un único resultado. Mantén iguales el cliente, el prompt del sistema, las definiciones de herramientas y los ajustes de muestreo para realizar una comparación justa.

## Inicio rápido

1. <a href={"{{register-url}}"}>Crea una BetterToken API Key</a> o abre **Setup** para una clave existente.
2. Confirma en la model plaza que `deepseek-flash` está disponible.
3. Selecciona el **proveedor DeepSeek**.
4. Configura la Base URL de tu protocolo según la tabla anterior e introduce el Model ID completo.
5. Envía una solicitud pequeña antes de iniciar una evaluación más larga.

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

Una respuesta correcta devuelve el contenido del modelo en `choices[0].message.content`. Consulta ejemplos de SDK y el formato completo en la [referencia de Chat Completions API](/es/api-reference/chat-completions).

2. Sustitúyelo por `deepseek-flash`.
3. Ejecuta una prueba rápida después del cambio.
4. Confirma la entrada actual del modelo y el precio en la model plaza.

## Preguntas frecuentes

Sí. Usa `deepseek-flash` y confirma en la model plaza que el modelo está disponible para tu BetterToken API Key.

### ¿Dónde puedo consultar el precio actual?

Consulta la <a href={"{{model-plaza-url}}"}>model plaza</a> en tiempo real. La disponibilidad y el precio pueden cambiar.
