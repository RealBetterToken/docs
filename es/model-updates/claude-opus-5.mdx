Fecha de lanzamiento: 24 de julio de 2026

BetterToken ya admite `claude-opus-5`. El modelo está diseñado para programación compleja, flujos prolongados con agentes y trabajos de varios pasos en repositorios grandes. Para conectarlo, crea una BetterToken API Key, selecciona el proveedor `Claude`, usa `{{anthropic-base-url}}` como Base URL y elige `claude-opus-5` como ID de modelo.

Consulta siempre la disponibilidad y los precios actuales en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Aspectos destacados

- **Cargas de programación complejas**: Anthropic recomienda Opus 5 para programación compleja con agentes y trabajos profesionales donde importan la calidad y la fiabilidad a largo plazo
- **Hasta `1M tokens` de contexto**: el modelo puede trabajar con repositorios grandes, historiales largos y abundante material de referencia
- **Hasta `128K tokens` de salida**: permite grandes cambios de código, informes y entregables de varios pasos
- **Razonamiento adaptativo predeterminado**: el modelo ajusta la profundidad de razonamiento a la tarea
- **Mayor control del esfuerzo**: admite los niveles `low`, `medium`, `high`, `xhigh` y `max`

## Cómo conectarlo

1. <a href={"{{register-url}}"}>Regístrate y crea una BetterToken API Key</a>; después, selecciona el proveedor `Claude`.
2. Establece la Base URL en `{{anthropic-base-url}}`.
3. Selecciona `claude-opus-5` como modelo.
4. Sigue la [guía de configuración de Claude Code](/es/ai-tools/claude-code). Para gestionar varios proveedores, usa la [guía de CC Switch](/es/ai-tools/cc-switch).

Si vas a elegir un modelo para una carga concreta, compara Opus 5 con otras opciones en la [guía de selección de modelos](/es/faq/model-calling/model-selection-guide).

## Qué comprobar al migrar desde Opus 4.8

En la mayoría de las configuraciones, puedes sustituir `claude-opus-4-8` por `claude-opus-5`. Revisa estos dos cambios de comportamiento:

- **El razonamiento está activado de forma predeterminada**. Si effort se establece en `xhigh` o `max`, desactivar el razonamiento devuelve un error `400`.
- **`max_tokens` cubre el razonamiento y la salida visible**. Deja margen suficiente para tareas que requieren un razonamiento largo y una respuesta final extensa.

<Tip>
  Empieza con una tarea real de tu flujo, como analizar un repositorio, modificar varios archivos o ejecutar una tarea prolongada con un agente. Así podrás evaluar mejor la calidad, la latencia y el consumo de tokens antes de migrar más cargas.
</Tip>
