Actualizado: 30 de septiembre de 2026

**GPT-6.1 Sol** es una actualización de GPT-6 Sol. Según OpenAI, mejora en programación agéntica, uso de aplicaciones y trabajo profesional, y se acerca a GPT-6 Astra en algunas evaluaciones. Para tareas exigentes, compara la calidad, la latencia y el consumo en tu propio flujo de trabajo.

BetterToken ofrece el Model ID `gpt-6.1-sol`. Consulta la disponibilidad y los precios actuales de BetterToken en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Aspectos destacados

- **Código y agentes**: útil para cambios en varios archivos, depuración y tareas de ingeniería de software de larga duración.
- **Aplicaciones y documentos**: OpenAI informa de mejoras frente a GPT-6 Sol en estos trabajos.
- **Contexto amplio**: OpenAI indica una ventana de `1,050,000` tokens y hasta `128,000` tokens de salida. El cliente y la ruta de conexión pueden imponer límites menores.
- **Razonamiento ajustable**: admite `low`, `medium`, `high`, `xhigh` y `max`, pero no `none` ni `minimal`.

## Cómo conectarlo

1. <a href={"{{register-url}}"}>Crea una BetterToken API Key</a>.
2. En Codex CLI u otro cliente compatible con OpenAI, usa `{{openai-base-url}}` como Base URL y `gpt-6.1-sol` como Model ID.
3. Si necesitas llamar a herramientas, usa la [Responses API](/es/api-reference/responses). OpenAI documenta Chat Completions para este modelo sin llamadas a herramientas.
4. Prueba una tarea representativa antes de cambiar un flujo de trabajo existente.

Para Claude Code, usa la Base URL del protocolo Anthropic `{{anthropic-base-url}}` y el mismo Model ID. Consulta las guías de [Claude Code](/es/ai-tools/claude-code) y [Codex CLI](/es/ai-tools/codex).
