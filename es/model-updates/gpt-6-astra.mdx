Actualizado: 5 de septiembre de 2026

BetterToken ya admite **GPT-6 Astra** con el Model ID exacto `gpt-6-astra`. OpenAI lo presenta como su modelo más capaz para trabajos complejos de principio a fin, como razonamiento avanzado, ingeniería de software, investigación, uso del ordenador y creación de documentos. Consulta la disponibilidad y el precio de BetterToken en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Novedades principales

- **Trabajo de principio a fin**: creado para tareas complejas de varios pasos con código, navegadores, herramientas y aplicaciones profesionales
- **Ingeniería de software**: OpenAI lo posiciona como su modelo más potente hasta la fecha para programación y desarrollo agéntico
- **Contexto amplio**: OpenAI documenta una ventana de `1.050.000` tokens y hasta `128.000` tokens de salida
- **Razonamiento ajustable**: la API de OpenAI admite los niveles `low`, `medium`, `high`, `xhigh` y `max`
- **Herramientas de Responses API**: OpenAI documenta function calling, salidas estructuradas, búsqueda web y de archivos, intérprete de código, computer use y MCP

## Recomendaciones de configuración

- Usa Astra para programación difícil, investigación, computer use o tareas agénticas largas. Para trabajo cotidiano, compáralo con modelos más rápidos o económicos en la model plaza.
- Prueba una tarea representativa antes de cambiar tráfico de producción y compara calidad, latencia y consumo de tokens.
- Elige el **provider GPT**, usa la Base URL `{{openai-base-url}}` y el Model ID exacto `gpt-6-astra`.
- El acceso puede desplegarse por fases. La model plaza es la referencia para disponibilidad y precios de BetterToken.

## Inicio rápido

1. Crea una BetterToken API Key o abre el cuadro **Setup** de una clave existente.

## Preguntas frecuentes

### ¿Cuál es el Model ID de GPT-6 Astra?

Usa `gpt-6-astra`. No lo sustituyas por el nombre visible `GPT-6 Astra` ni por un ID de otra plataforma.

### ¿BetterToken ofrece el contexto completo de 1.050.000 tokens?

OpenAI indica una ventana de contexto de `1.050.000` tokens para GPT-6 Astra. El límite utilizable también puede depender del cliente, la solicitud y el enrutamiento actual de BetterToken. Consulta la model plaza y la documentación del cliente antes de enviar prompts muy grandes.

### ¿Cómo soluciono Model not found?

Comprueba que el Model ID sea exactamente `gpt-6-astra`, que la BetterToken API Key tenga acceso, que esté seleccionado el **provider GPT** y que la Base URL sea `{{openai-base-url}}`. Reinicia el cliente y vuelve a probar.

### ¿Dónde puedo consultar el precio actual?

Consulta la <a href={"{{model-plaza-url}}"}>model plaza</a>. El precio de BetterToken puede diferir del precio directo de la API de OpenAI y cambiar con el tiempo.
