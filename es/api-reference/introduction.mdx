BetterToken ofrece las API OpenAI-compatible Chat Completions y Responses, además de Anthropic-compatible Messages. Elige el formato que utilice tu cliente.

## Elige una API

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/es/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/es/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/es/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/es/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/es/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Conexión con Chat Completions

| Campo | Valor |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| URL completa de solicitud | `{{chat-completions-url}}` |
| Método | `POST` |
| Autorización | `Bearer YOUR_API_KEY` |
| Modelo | `YOUR_MODEL_ID` |

Copia un Model ID vigente desde el <a href={"{{model-plaza-url}}"}>model plaza</a> o desde el cuadro **Setup** de la API Key en Console.

<Warning>
  Cuando una herramienta solicite un **Base URL**, introduce `{{openai-base-url}}`. Usa `{{chat-completions-url}}` solo si la herramienta pide explícitamente la URL completa de la solicitud.
</Warning>

## Prueba rápida

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Una respuesta correcta contiene `choices[0].message.content`.
