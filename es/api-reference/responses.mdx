`POST /v1/responses`

Usa este endpoint para Codex y las aplicaciones que usan la API de OpenAI Responses.

<Note>
  Base URL: `{{openai-base-url}}`. Envía tu API Key como `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Prueba en el Playground

En el Playground de la derecha, introduce tu API Key, sustituye `model` por el model ID actual del proveedor GPT cuando sea necesario y envía la solicitud. Confirma el modelo en el <a href={"{{model-plaza-url}}"}>modelo plaza</a> antes de probarlo.

<Warning>
  Usa solo tu propia API Key de prueba. No incluyas keys en código, capturas, tickets ni repositorios Git.
</Warning>
