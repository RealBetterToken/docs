`POST /v1/messages`

Usa este endpoint para Claude Code, el SDK de Anthropic y las aplicaciones que usan la API de Anthropic Messages.

<Note>
  Para un SDK, usa `{{anthropic-base-url}}` como Base URL. Una solicitud manual y el Playground usan la ruta completa `{{anthropic-base-url}}/v1/messages`.
</Note>

## Prueba en el Playground

En el Playground de la derecha, introduce tu API Key en el campo `x-api-key`, deja `anthropic-version` como `claude-cli/2.0.76 (external, cli)`, elige un modelo disponible del proveedor Claude y envía la solicitud.

<Warning>
  No uses `Authorization: Bearer ...` para este endpoint. Requiere el encabezado `x-api-key`.
</Warning>
