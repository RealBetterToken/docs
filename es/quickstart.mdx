---
title: "Inicio rápido"
description: "Crea una cuenta BetterToken, añade saldo, genera una API Key y abre la guía adecuada para configurar Claude Code, Codex CLI u otra herramienta externa."
---

<Steps>
  <Step title="Crea una cuenta">
    Visita la <a href={"{{register-url}}"}>página de registro de BetterToken</a> para crear una cuenta.

    Después de registrarte, recarga el saldo antes de crear una BetterToken API Key.
  </Step>
  <Step title="Añade saldo a tu cuenta">
    Puedes usar **Recarga en línea** o **Código de canje**. Después de añadir saldo, vuelve a la consola y confirma que **Current balance** se ha actualizado antes de crear una API Key.

    <Tabs>
      <Tab title="Recarga en línea">
        Inicia sesión y abre la **Console**. En la tarjeta **Current balance**, elige la moneda que quieras recargar y haz clic en el botón **Top up** correspondiente.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Tarjeta Current balance de la Console de BetterToken con botones Top up para USD y RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Sigue las indicaciones de pago. Cuando el pago termine correctamente, vuelve a la consola y confirma que **Current balance** se ha actualizado.
      </Tab>
      <Tab title="Código de canje">
        Inicia sesión, abre la **Console** y haz clic en **Redeem code** en la esquina inferior izquierda de la tarjeta **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Tarjeta Current balance de la Console de BetterToken con una flecha que señala el botón Redeem code de la esquina inferior izquierda."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Introduce el código en el cuadro de diálogo y haz clic en **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Cuadro de diálogo Redeem code con el campo para el código y el botón Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Después de canjear el código, vuelve a la consola y confirma que **Current balance** se ha actualizado.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Abre la gestión de API Key y crea una API Key">
    Cuando tengas saldo disponible, haz clic en **Create API key** en la esquina superior derecha de la sección **Your API keys** de la consola.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Sección Your API keys de la Console de BetterToken con una flecha que señala el botón Create API key de la esquina superior derecha."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    En **Create API Key**, introduce un **API key name**. Si necesitas una fecha de vencimiento o un límite de gasto, abre **Advanced settings**. Después, haz clic en **Create API Key**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="Cuadro Create API Key con el campo API key name, Advanced settings y el botón Create API Key."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Copia los datos de conexión o el código de configuración">
    Después de crear la clave, abre **Set up API key**. En **Connection details**, copia la **API Key**, selecciona **OpenAI** o **Anthropic** según el protocolo y copia la **Base URL** correspondiente.

    También puedes elegir tu herramienta o **API call** en **Configuration guide**, seleccionar la API y un modelo de ejemplo si hace falta, y copiar el código proporcionado. Para más detalles, abre **View tool documentation** o una de las guías siguientes. Al terminar, haz clic en **Finish**.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="Ventana Set up API key con API Key y Base URL para copiar, y Configuration guide con herramientas y código debajo."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
