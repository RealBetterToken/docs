---
title: "Inicio rápido"
description: "En 4 pasos, crea una cuenta, añade saldo, crea una API Key y abre la guía de configuración correspondiente a tu herramienta."
---

<Steps>
  <Step title="Crea una cuenta">
    Visita la <a href={"{{register-url}}"}>página de registro de BetterToken</a> para crear una cuenta.

    Al registrarte, recibirás automáticamente **$1 de crédito de prueba**.
  </Step>
  <Step title="Añade saldo a tu cuenta">
    Puedes usar **Recarga en línea** o **Código de canje**. Después de añadir saldo, vuelve a la consola y confirma que **Current balance** se ha actualizado antes de crear una API Key.

    <Tabs>
      <Tab title="Recarga en línea">
        Inicia sesión y abre la **Console**. En la tarjeta **Current balance**, elige la moneda que quieras recargar y haz clic en el botón **Top up** correspondiente.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Tarjeta Current balance de la Console de BetterToken con botones Top up para USD y RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Sigue las indicaciones de pago. Cuando el pago termine correctamente, vuelve a la consola y confirma que **Current balance** se ha actualizado.
      </Tab>
      <Tab title="Código de canje">
        Inicia sesión, abre la **Console** y haz clic en **Redeem code** en la esquina inferior izquierda de la tarjeta **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Tarjeta Current balance de la Console de BetterToken con una flecha que señala el botón Redeem code de la esquina inferior izquierda."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Introduce el código en el cuadro de diálogo y haz clic en **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Cuadro de diálogo Redeem code con el campo para el código y el botón Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Después de canjear el código, vuelve a la consola y confirma que **Current balance** se ha actualizado.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Abre la gestión de API Key y crea una API Key">
    Cuando tengas saldo disponible, haz clic en **Create API key** en la esquina superior derecha de la sección **Your API keys** de la consola.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Sección Your API keys de la Console de BetterToken con una flecha que señala el botón Create API key de la esquina superior derecha."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Se abrirá el formulario para crear la API Key.

    <Info>
      Usa el nombre de la API Key para indicar su finalidad. Elegir primero el uso correcto facilita el resto de la configuración.
    </Info>
  </Step>
  <Step title="Elige el proveedor según el tipo de herramienta">
    En el formulario, completa **Name**, elige el **provider** y confirma la fecha de vencimiento y el límite de gasto opcional.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Formulario Create API Key con opciones de nombre, proveedor, vencimiento y límite de gasto."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Elige el proveedor según la herramienta que vayas a conectar.

    <Warning>
      El **proveedor Claude** solo se puede usar con Claude Code.
    </Warning>

    <Warning>
      El **proveedor GPT** se puede usar con Codex y herramientas externas como OpenClaw, OpenCode y Cursor.
    </Warning>

    Elige uno de estos proveedores:

    ```text
    Claude
    GPT
    ```

    Después de crear la clave, se abrirá el cuadro de diálogo **API key setup**. Copia la **API Key** y la **Base URL** desde este cuadro.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="Cuadro de diálogo API key setup de BetterToken con la API Key, la Base URL, la selección de herramientas y los métodos de configuración."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Elige un método de configuración">
    En el cuadro de diálogo **API key setup**, elige en el lado izquierdo la herramienta que quieras conectar y selecciona un método de configuración.

    - **One-click Bash Configuration**: selecciona la herramienta y `macOS / Linux` o `Windows`, copia el comando generado y ejecútalo en tu terminal local. Usa este método para configurar rápidamente Codex, OpenClaw u OpenCode.
    - **Integración con CC Switch**: haz clic en **Import to CC Switch** para importar la **API Key** y la **Base URL** actuales en CC Switch. Usa este método si administras varias herramientas y proveedores desde una sola aplicación.
    - **Configuración manual**: copia la **API Key** y la **Base URL** y pégalas en el flujo de configuración de la herramienta. Usa este método con Cursor, Cline, Roo Code, Zed y otros clientes.

    <Note>
      Cada herramienta utiliza campos de autenticación, selectores de modelos y ubicaciones de archivos de configuración diferentes. Continúa con la guía específica de la herramienta antes de terminar la configuración.
    </Note>
  </Step>
</Steps>
