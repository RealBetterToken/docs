## Cuenta y facturación

<AccordionGroup>
  <Accordion title="¿Cómo factura BetterToken el uso?">
    BetterToken cobra según el uso real de tokens y sigue los precios de Anthropic / OpenAI sin añadir un recargo. Cada cuenta nueva recibe $1 de crédito de prueba.

    Consulta la <a href={"{{pricing-url}}"}>página de precios</a> para obtener más información.
  </Accordion>

  <Accordion title="¿Puedo solicitar un reembolso después de registrarme?">
    Las recargas pagadas son reembolsables. El crédito de prueba no es reembolsable. Contacta con soporte si necesitas un reembolso.
  </Accordion>

  <Accordion title="¿Puedo usar la misma API Key en varias herramientas?">
    Sí. Puedes usar la misma API Key al mismo tiempo en Claude Code, Codex, Cursor y otras herramientas. El uso es compartido.
  </Accordion>

  <Accordion title="¿Dónde puedo consultar el uso?">
    Inicia sesión en el Dashboard para consultar el uso actual y los registros de facturación.
  </Accordion>
</AccordionGroup>

## Instalación y configuración

<AccordionGroup>
  <Accordion title="¿Cuál es la base_url de BetterToken?">
    BetterToken utiliza dos endpoints diferentes según el protocolo:

    | Escenario | Base URL |
    |----------|----------|
    | Claude Code / `ANTHROPIC_BASE_URL` | `{{anthropic-base-url}}` |
    | Codex / `OPENAI_BASE_URL` / herramientas externas | `{{openai-base-url}}` |

    No reutilices una sola dirección en todas las herramientas.
  </Accordion>

  <Accordion title="¿Tengo que indicar un modelo al usar Claude Code?">
    Depende del proveedor.

    Con el **proveedor Claude**, configura solo `ANTHROPIC_BASE_URL` y `ANTHROPIC_AUTH_TOKEN`. **No** necesitas variables de modelo.

    Con el **proveedor GPT**, añade los mapeos de modelos de Claude Code mediante `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` y `ANTHROPIC_DEFAULT_OPUS_MODEL`. Copia el ID del modelo del **proveedor GPT** actual en el <a href={"{{model-plaza-url}}"}>model plaza</a>.
  </Accordion>

  <Accordion title="¿Tengo que indicar un modelo al usar Codex?">
    Sí. Introduce un ID de modelo copiado del **proveedor GPT** en el <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Consulta la [guía de configuración de Codex](/es/ai-tools/codex) para obtener más información.
  </Accordion>

  <Accordion title="¿Tengo que indicar un modelo al usar otras herramientas como Cursor?">
    Sí. Las herramientas externas como Cursor, Cline, Zed y OpenClaw usan el **proveedor GPT**. Copia el ID del modelo actual desde el <a href={"{{model-plaza-url}}"}>model plaza</a>.

    No sigas usando nombres de modelos Claude escritos directamente en estas herramientas.

    Consulta la [guía de configuración de Cursor](/es/ai-tools/cursor) para obtener más información.
  </Accordion>

  <Accordion title="¿OpenClaw y otras herramientas externas necesitan headers adicionales?">
    Normalmente no.

    Según la documentación oficial revisada, las herramientas externas habituales, como Cursor, Cline y Zed, se centran en la `Base URL`, la API key y el ID del modelo. OpenCode y OpenClaw admiten `headers` opcionales, pero su documentación oficial los presenta para headers personalizados o necesidades de autenticación específicas, no como un paso obligatorio para configurar BetterToken.

    Añade headers adicionales solo cuando lo exija la documentación oficial de la herramienta o tu propio gateway upstream, enrutamiento de tenant, capa de observabilidad o caché.
  </Accordion>

  <Accordion title="¿Qué hago si la autenticación falla después de configurar la herramienta?">
    Comprueba lo siguiente:

    1. La API Key es correcta y no contiene espacios adicionales
    2. Claude Code usa `{{anthropic-base-url}}`, mientras que Codex y las herramientas externas usan `{{openai-base-url}}`
    3. Ninguna variable anterior, como `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `OPENAI_API_KEY` o `OPENAI_BASE_URL`, está sobrescribiendo la configuración
    4. En herramientas externas, comprueba si existen requisitos oficiales adicionales, como límites de versión, listas de modelos permitidos o headers exigidos expresamente por tu gateway upstream

    Si el problema continúa, contacta con soporte.
  </Accordion>
</AccordionGroup>

## Fiabilidad y límites de uso

<AccordionGroup>
  <Accordion title="¿Cómo mantiene BetterToken la fiabilidad?">
    BetterToken se conecta a varios proveedores y usa estos mecanismos:

    - **Varios proveedores**: una incidencia en un proveedor no interrumpe todas las solicitudes
    - **Enrutamiento dinámico**: BetterToken selecciona en tiempo real una ruta rápida y estable
    - **Compatibilidad prioritaria**: el trabajo de fiabilidad se concentra en Claude Code y el ecosistema de Codex
  </Accordion>

  <Accordion title="¿Qué hago si encuentro límites de uso o timeouts?">
    BetterToken gestiona automáticamente los límites de uso y timeouts de proveedores concretos. Si el problema continúa:

    1. Comprueba que el saldo sea suficiente
    2. Aumenta el timeout de la herramienta (se recomienda `API_TIMEOUT_MS=3000000`)
    3. Contacta con soporte para confirmar el estado actual de la cuota
  </Accordion>

  <Accordion title="¿BetterToken es adecuado para producción?">
    BetterToken está diseñado principalmente para desarrolladores individuales que usan herramientas de desarrollo con IA como Claude Code y Codex. Para cargas de API de producción a gran escala, evalúalo según tus propios requisitos.
  </Accordion>
</AccordionGroup>

## Privacidad y seguridad

<AccordionGroup>
  <Accordion title="¿BetterToken almacena el contenido de mis solicitudes?">
    BetterToken actúa como relay y no conserva el contenido de las conversaciones. Consulta la <a href={"{{privacy-url}}"}>Política de privacidad</a> para obtener más información.
  </Accordion>

  <Accordion title="¿Qué hago si se filtra mi API Key?">
    Inicia sesión inmediatamente en el Dashboard, elimina la clave anterior y genera una nueva. Después, actualiza todas las herramientas que usan esa clave.
  </Accordion>
</AccordionGroup>
