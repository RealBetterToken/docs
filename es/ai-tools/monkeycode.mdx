MonkeyCode es una herramienta de IA que permite conectar un modelo mediante un proveedor personalizado desde su propia interfaz. Esta guía cubre la configuración de BetterToken en **AI Model**; no documenta una API oficial de MonkeyCode. Introduce la API Key de BetterToken, `{{openai-base-url}}` y un Model ID exacto, guarda la vinculación e inicia un chat nuevo. Si el problema ocurre en Kodacode / Koda, usa la [guía de configuración y errores 429 de Kodacode](/es/ai-tools/kodacode). La información oficial y el registro están en el [sitio de MonkeyCode](https://monkeycode.ai).

## Ajustes principales

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Un ID de modelo vigente de la <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Requisitos previos

- La versión actual de la herramienta está instalada
- Una BetterToken API Key: <a href={"{{register-url}}"}>regístrate y obtén una</a>
- Un ID de modelo de la <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionales

- Una cuenta de MonkeyCode ([regístrate en MonkeyCode](https://monkeycode.ai))

## Instalación

Instala o abre MonkeyCode y continúa con la configuración manual siguiente.

## Configuración manual

Completa esta configuración en la interfaz de ajustes de MonkeyCode. No necesitas editar un archivo de configuración.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Un ID de modelo vigente de la <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Pasos de configuración

<Steps>
  <Step title="Inicia sesión en MonkeyCode">
    Visita [MonkeyCode](https://monkeycode.ai) e inicia sesión.
  </Step>

  <Step title="Abre los ajustes del sistema">
    Entra en la página de tareas y haz clic en **Settings**, en la esquina inferior derecha.
  </Step>

  <Step title="Vincula un modelo de IA">
    En la sección **AI Model**, haz clic en **Bind**.
  </Step>

  <Step title="Completa la configuración de BetterToken">

    | Campo | Valor |
    |-------|-------|
    | Model API URL | `{{openai-base-url}}` |
    | API Key | Tu BetterToken API Key |
    | Formato de API | `OpenAI` u `OpenAI Compatible` (sigue la etiqueta actual de la interfaz) |
    | Nombre del modelo | Un **ID de modelo de un proveedor compatible** copiado desde la <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Configura cabeceras adicionales solo si la documentación oficial las exige">
    No encontramos ningún requisito oficial de MonkeyCode que haga obligatorio `User-Agent` para BetterToken. Empieza con la `Base URL`, la API Key y el ID de modelo indicados en esta página.

    Si también usas un gateway personalizado, enrutamiento por tenant, observabilidad o una capa de caché, añade cabeceras únicamente según la documentación oficial de ese servicio original.
  </Step>

  <Step title="Guarda y empieza a usarlo">
    Haz clic en **Save**, vuelve a la página principal y selecciona el modelo que acabas de configurar.
  </Step>

  <Step title="Reinicia MonkeyCode">
    Después de guardar la configuración, actualiza la página o vuelve a abrir MonkeyCode antes de usar el modelo nuevo.
  </Step>
</Steps>

<Note>
  Si necesitas cabeceras adicionales, sigue la documentación actual de MonkeyCode o los requisitos de tu gateway original; no supongas que `User-Agent` sea obligatorio para BetterToken.
</Note>

## Verifica la conexión

Envía un prompt de prueba breve. Si la herramienta responde sin errores de autenticación ni de ID del modelo, la conexión funciona. Reinicia por completo la herramienta después de cambiar la configuración.

## Cambia de modelo

Abre el selector de modelos o cambia el campo `Model` de la configuración. Usa el ID de modelo exacto de la <a href={"{{model-plaza-url}}"}>model plaza</a> y reinicia la sesión actual.

## Errores habituales

| Error | Qué comprobar |
| --- | --- |
| `401` o `Unauthorized` | Comprueba la BetterToken API Key y elimina los espacios iniciales o finales. |
| `404` | Comprueba la Base URL y no añadas una ruta específica de endpoint. |
| `model not found` | Copia un ID de modelo vigente desde la model plaza. |
| Los cambios no se aplican | Guarda la configuración y reinicia la herramienta por completo. |

## Detalles técnicos

<Accordion title="Protocolo, endpoint y campos internos del proveedor">
  Esta configuración usa `{{openai-base-url}}`. La herramienta añade la ruta del endpoint compatible con OpenAI. No añadas `/chat/completions` ni `/responses` salvo que un campo concreto lo exija explícitamente.
</Accordion>
