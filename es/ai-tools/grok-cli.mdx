“Grok CLI” puede referirse a dos herramientas distintas:

- **Grok Build**, el coding agent oficial de xAI;
- **Grok CLI comunitario**, un proyecto open source sin relación con xAI.

Ambos clientes se han verificado con BetterToken: devolvieron una respuesta del modelo usando una BetterToken API Key, Base URL y Model ID. Esta guía empieza por el **Grok CLI comunitario**, cuya configuración es más directa.

<Warning>Las dos herramientas usan el comando `grok`. Si instalas ambas, se ejecutará la primera versión encontrada en `PATH`.</Warning>

## Diferencias entre Grok CLI y Grok Build

| Elemento | Grok Build oficial | Grok CLI comunitario |
| --- | --- | --- |
| Mantenedor | xAI | `superagent-ai/grok-cli`, sin relación con xAI |
| Autenticación | Inicio de sesión en el navegador o `XAI_API_KEY` | `GROK_API_KEY` |
| Base URL personalizada | En `~/.grok/config.toml` | Con `GROK_BASE_URL` |
| Modelo | Alias en la configuración | `GROK_MODEL` |
| Llamar modelos mediante BetterToken | Verificado | Verificado |
| Comando | `grok` | `grok` |

La verificación cubre solicitudes de modelos de texto y código, no llamadas a herramientas ni APIs exclusivas de xAI.

## Usar Grok CLI comunitario con BetterToken

Estos comandos sirven para macOS, Linux y WSL. La instalación nativa en Windows no se ha verificado para el cliente comunitario.

### Instalación

```bash
curl -fsSL https://raw.githubusercontent.com/superagent-ai/grok-cli/main/install.sh | bash
grok --version
```

Si ya tienes Bun:

```bash
bun add -g grok-dev
```

### Configurar BetterToken

```bash
export GROK_BASE_URL="{{openai-base-url}}"
export GROK_API_KEY="YOUR_API_KEY"
export GROK_MODEL="YOUR_MODEL_ID"
```

Sustituye `YOUR_MODEL_ID` por el Model ID completo de la <a href={"{{model-plaza-url}}"}>model plaza</a> y usa tu <a href={"{{register-url}}"}>BetterToken API Key</a>.

### Verificar la conexión

```bash
grok -p "Reply with only: OK"
```

Solo una respuesta del modelo confirma que la API Key, la Base URL y el Model ID funcionan. Reinicia el cliente después de cambiar variables de entorno.

## Grok Build oficial

[Grok Build](https://docs.x.ai/build/overview) es el coding agent oficial para terminal de xAI.

### Instalación y autenticación

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    grok --version
    ```
  </Tab>
</Tabs>

En el primer inicio, Grok Build abre el navegador. Sin navegador:

```bash
export XAI_API_KEY="YOUR_XAI_API_KEY"
grok
```

### Configurar BetterToken en Grok Build

```toml
[model.bettertoken]
model = "YOUR_MODEL_ID"
base_url = "{{openai-base-url}}"
name = "BetterToken"
env_key = "BETTERTOKEN_API_KEY"
api_backend = "chat_completions"

[models]
default = "bettertoken"
```

`BETTERTOKEN_API_KEY` es un nombre de variable elegido para el ejemplo. Grok Build lee la variable indicada en `env_key`.

```bash
export BETTERTOKEN_API_KEY="YOUR_API_KEY"
grok inspect
grok -p "Reply with only: OK" -m bettertoken
```

<Note>Grok Build devolvió una respuesta del modelo mediante BetterToken con esta configuración. Esto no verifica llamadas a herramientas ni APIs exclusivas de xAI.</Note>

## Errores frecuentes

| Problema | Qué comprobar |
| --- | --- |
| Se abre el cliente equivocado | Comprueba la ruta y la versión de cada comando `grok`. |
| `401` o `Unauthorized` | El cliente comunitario lee `GROK_API_KEY`; Grok Build lee la variable de `env_key`. |
| `model not found` | Copia el Model ID completo de la model plaza y reinicia. |
| La solicitud sigue yendo a xAI | Revisa `GROK_BASE_URL` o ejecuta `grok inspect` en Grok Build. |

## Modelos y límites funcionales

Usa un Model ID completo compatible con OpenAI de la <a href={"{{model-plaza-url}}"}>model plaza</a>. X Search, voz, imágenes, vídeo y otras APIs exclusivas de xAI no forman parte de esta configuración.
