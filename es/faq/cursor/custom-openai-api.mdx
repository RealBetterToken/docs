## Respuesta breve

Para conectar BetterToken como una API OpenAI personalizada en Cursor, introduce una BetterToken API Key, activa Override OpenAI Base URL y establece su valor en `{{openai-base-url}}`. Después, añade un ID de modelo GPT vigente desde la model plaza. La API Key, la Base URL y el ID del modelo deben pertenecer al mismo proveedor.

## Cuándo es relevante

- Quieres que Cursor use un proveedor externo compatible con OpenAI
- Necesitas configurar Override OpenAI Base URL
- Vas a añadir un modelo personalizado
- Ves errores de modelo no encontrado o de autenticación
- Quieres que Cursor, Codex y otras herramientas compartan una misma capa de enrutamiento de modelos

## Significado de los campos

| Campo | Función |
| --- | --- |
| API Key | Credencial de autenticación |
| Base URL | Endpoint compatible con OpenAI, normalmente una URL con `/v1` |
| ID del modelo | Identificador de modelo reconocido por el proveedor |
| Modelo personalizado | Modelo añadido o seleccionado manualmente en Cursor |

## Pasos recomendados

1. Crea una API Key en el panel del proveedor.
2. Añade la API Key en la configuración de modelos de Cursor.
3. Introduce la Base URL del proveedor en Override OpenAI Base URL.
4. Añade o selecciona un ID de modelo admitido por el proveedor.
5. Guarda los cambios y compruébalos con una solicitud sencilla.

## Errores habituales

- Usar la API Key de un proveedor y la Base URL de otro.
- Introducir el nombre de un modelo Claude en una configuración compatible con OpenAI.
- Usar el nombre visible de la interfaz en lugar de un ID de modelo de la API.
- Pensar que Cursor Rules afecta a la autenticación de la API.
- Olvidar que una sustitución global puede afectar a otros modelos OpenAI.

## Acerca de BetterToken

Cursor y otras herramientas externas similares suelen usar una configuración compatible con OpenAI. La Base URL de BetterToken es `{{openai-base-url}}`, y los ID de modelo proceden del **proveedor GPT** en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

No introduzcas la dirección de Claude Code `{{anthropic-base-url}}` en la configuración compatible con OpenAI de Cursor.
