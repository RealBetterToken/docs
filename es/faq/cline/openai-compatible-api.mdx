## Respuesta directa

En Cline, selecciona **OpenAI Compatible**, establece **Base URL** en `{{openai-base-url}}`, pega tu BetterToken API Key e introduce un ID de modelo del **proveedor GPT**. No uses la dirección compatible con Anthropic destinada a Claude Code ni selecciones el proveedor oficial **OpenAI**.

| Campo de Cline | Valor para BetterToken |
| --- | --- |
| API Provider | `OpenAI Compatible` |
| Base URL | `{{openai-base-url}}` |
| API Key | Tu BetterToken API Key |
| Model ID | Un ID de modelo del **proveedor GPT** en la <a href={"{{model-plaza-url}}"}>model plaza</a> |

<Info>
  Esta página se centra en los valores de cada campo y en la solución de problemas de conexión. Si necesitas empezar por la instalación, sigue la [guía completa de configuración de Cline](/es/ai-tools/cline).
</Info>

## Configuración completa

<Steps>
  <Step title="Prepara la API Key y el ID del modelo">
    Crea una API Key y copia un ID de modelo disponible actualmente desde el **proveedor GPT** en la <a href={"{{model-plaza-url}}"}>model plaza</a>. Introduce el ID exactamente como aparece, en lugar de usar su nombre comercial visible.
  </Step>
  <Step title="Abre la configuración de Cline">
    Abre el panel de Cline en VS Code y haz clic en el icono de engranaje.
  </Step>
  <Step title="Selecciona OpenAI Compatible">
    En **API Provider**, selecciona **OpenAI Compatible**. Este proveedor conecta Cline con un endpoint externo compatible con OpenAI.
  </Step>
  <Step title="Introduce los cuatro valores obligatorios">
    Completa Provider, Base URL, API Key y Model ID con los valores de la tabla anterior. La Base URL debe incluir `/v1`.

    Si aparece **Use Azure Identity Authentication**, déjalo desactivado. BetterToken se autentica con una API Key, no con Azure Identity.
  </Step>
  <Step title="Verifica la conexión">
    Haz clic en **Verify** en Cline. Cuando la verificación termine correctamente, crea una tarea y envía un prompt sencillo para confirmar que el modelo responde y que las llamadas a herramientas funcionan.
  </Step>
</Steps>

## ¿Qué campos avanzados debes cambiar?

Cline también puede mostrar Context Window, Max Output Tokens, Image Support o Computer Use. Conserva los valores predeterminados durante la primera conexión. Cambia un campo solo cuando la model plaza o la documentación del modelo confirmen la capacidad y el límite correspondientes.

Los precios de los modelos pueden cambiar. No confíes en un precio fijo guardado en la configuración local de Cline; consulta el modelo y el precio actuales en la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Errores habituales

| Síntoma | Primera comprobación | Solución |
| --- | --- | --- |
| `Invalid API Key` o `401` | Si la Key está completa y pertenece a la cuenta actual | Vuelve a copiar la Key, elimina los espacios que la rodean y no la mezcles con una Key oficial de OpenAI |
| `Model Not Found` | Si el ID del modelo pertenece al proveedor GPT | Copia un ID disponible desde la model plaza sin cambiar sus mayúsculas, minúsculas ni sufijo |
| `404` o endpoint no encontrado | Si falta `/v1` | Usa `{{openai-base-url}}`, no la dirección de Claude Code compatible con Anthropic |
| Tiempo de espera agotado | La red local, el firewall o una configuración de proxy obsoleta | Confirma que BetterToken se abre en tu navegador, desactiva cualquier proxy no válido y vuelve a ejecutar **Verify** |
| Sigue aplicándose la configuración anterior | La sesión de Cline no se ha actualizado | Guarda la configuración, vuelve a abrir Cline o ejecuta **Developer: Reload Window** |

## Dónde se aplica esta configuración

Estos valores conectan Cline con los modelos del **proveedor GPT** mediante el endpoint de BetterToken compatible con OpenAI. No modifican Cline Rules, Memory Bank, MCP ni los permisos de las herramientas locales.

Para Claude Code, usa la dirección compatible con Anthropic sin `/v1` y sigue la [guía de configuración de Claude Code](/es/ai-tools/claude-code).
