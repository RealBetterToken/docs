## Respuesta rápida

El consumo de tokens de Claude Code no se limita a la respuesta final que ves. Puede incluir los archivos que lee, instrucciones del proyecto, historial de conversación, resultados y descripciones de herramientas MCP, la salida generada y resúmenes compactados.

Un consumo elevado suele deberse a la combinación de tareas demasiado amplias, mucho contexto, archivos de reglas largos, numerosos servidores MCP, trabajo repetido y modelos de alto consumo.

La solución práctica consiste en acotar cada tarea y cargar únicamente el contexto que necesita.

## Cuándo es relevante

- Claude Code lee muchos archivos antes de cada respuesta
- Un cambio pequeño se convierte en una larga sesión de exploración
- `CLAUDE.md` o los archivos de reglas siguen creciendo
- Hay muchos servidores MCP activados, pero apenas se usan
- Claude Code repite el mismo trabajo varias veces
- Tu equipo necesita un gasto de API predecible

## Conceptos principales

| Concepto | Significado |
| --- | --- |
| Tokens de entrada | Prompts del usuario, contexto, archivos, resultados de herramientas e instrucciones |
| Tokens de salida | Texto, código y respuestas generados por el modelo |
| Ventana de contexto | Cantidad de información que puede contener una sesión |
| Caché de prompts | Reducción del coste para determinados contextos repetidos |
| Compactación | Resumen del historial anterior cuando aumenta el contexto |
| Sobrecarga de MCP | Las definiciones y los resultados de herramientas pueden añadir contexto |

## Flujo de trabajo recomendado

Controla el coste desde los límites de la tarea:

1. Asigna a Claude Code un solo objetivo claro cada vez.
2. Pídele que lea primero únicamente los archivos relevantes.
3. Usa `/clear` al cambiar a una tarea no relacionada.
4. Mantén `CLAUDE.md` breve y específico.
5. Desactiva los servidores MCP que no necesites para el trabajo actual.
6. Usa modelos ligeros para cambios sencillos y modelos más potentes para razonamientos complejos.
7. Ejecuta la comprobación relevante más pequeña después de cada cambio para reducir el trabajo repetido.

Si usas un gateway de API, revisa con regularidad el consumo en el panel. Separa el consumo de entrada, salida, caché y contexto cuando el panel muestre ese detalle.

## Errores habituales

- Fijarse solo en la longitud de la respuesta final e ignorar los archivos y la salida de las herramientas.
- Convertir `CLAUDE.md` en un manual largo que se carga en todas las sesiones.
- Activar muchos servidores MCP sin comprobar si la tarea los necesita.
- Empezar con prompts como «refactoriza todo el repositorio».
- Esperar que un gateway de API reduzca automáticamente el uso de contexto de Claude Code.
