## Respuesta breve

El programa de recomendación recompensa las invitaciones reales. Cuando invitas a un amigo y este completa su primera recarga, recibes una recompensa equivalente al **10%** del importe de esa primera recarga.

La recompensa se entrega como saldo dentro del producto y se usa automáticamente para pagar el coste de futuras solicitudes a la API. Las recomendaciones sospechosas se revisan manualmente. Las recompensas se entregan después de aprobar la revisión.

## Condiciones del programa de recomendación

| Término | Descripción |
| --- | --- |
| 1 | Invita a un amigo. Después de su primera recarga, recibes una recompensa equivalente al **10%** del importe de esa recarga. |
| 2 | El saldo de recompensa se usa automáticamente para pagar el coste de las solicitudes. |
| 3 | Las recomendaciones sospechosas se revisan manualmente. Las recompensas se entregan después de aprobar la revisión. |

## Cómo usar el programa de recomendación

1. Inicia sesión en la consola.
2. Copia tu enlace de recomendación desde el área de la cuenta o de recompensas.
3. Envía el enlace a tu amigo.
4. Tu amigo se registra mediante el enlace y completa su primera recarga.
5. El sistema calcula tu recompensa como el **10%** del importe de la primera recarga de tu amigo.
6. Una vez entregada, la recompensa se usa automáticamente para pagar tus futuras solicitudes.

Si tu amigo no se registra mediante tu enlace, es posible que la relación de recomendación no se cree automáticamente. Comparte el enlace completo en lugar de enviar solo una captura de pantalla.

## Cómo se usa el saldo de recompensa

El saldo de recompensa no se puede retirar en efectivo. Es un saldo dentro del producto que sirve para pagar el coste de las solicitudes al modelo.

Cuando envías solicitudes a la API, el sistema aplica el saldo y el saldo de recompensa según las reglas de la cuenta. No necesitas seleccionar el saldo de recompensa en cada solicitud.

## Qué puede activar una revisión manual

Para prevenir abusos, los siguientes casos pueden activar una revisión manual:

- Muchas invitaciones mutuas desde el mismo dispositivo o red
- Comportamiento anómalo de recarga o sospecha de usuarios no reales
- Cuentas falsas, cuentas creadas en masa o registros automatizados
- Autorrecomendaciones
- Relaciones anómalas entre los pagos, las cuentas o el comportamiento de las solicitudes

Si se aprueba la revisión, la recompensa se entrega con normalidad. Si una recomendación se considera sospechosa, la recompensa puede retrasarse, cancelarse o congelarse.

## Preguntas frecuentes

### ¿Cuál es el porcentaje de recompensa?

La recompensa es el **10%** del importe de la primera recarga de tu amigo.

### ¿La recompensa llega inmediatamente después de la recarga de mi amigo?

Las recomendaciones normales se procesan según las reglas del sistema. Si se detectan riesgos o relaciones anómalas, la recompensa pasa a revisión manual y se entrega después de su aprobación.

### ¿Puedo retirar el saldo de recompensa?

No. El saldo de recompensa sirve para pagar el coste de las solicitudes.

### ¿Tengo que aplicar manualmente el saldo de recompensa?

No. El saldo de recompensa se usa automáticamente para pagar las solicitudes.

## Acerca de BetterToken

El programa de recomendación de BetterToken está destinado a invitaciones de usuarios reales. Las recompensas ayudan a cubrir el coste de las solicitudes a la API y permiten compartir el servicio con compañeros de equipo, amigos o comunidades de desarrolladores.
