## Respuesta rápida

Claude Code es un agente de programación que trabaja con repositorios. Su flujo se basa en leer un proyecto, editar archivos, ejecutar comandos y verificar los resultados.

Claude Desktop es la aplicación de escritorio de Claude. Ofrece una interfaz gráfica para conversaciones, extensiones de escritorio, servidores MCP locales y algunos flujos de escritorio, como las funciones Cowork o Code.

Pueden compartir algunas funciones, pero no son la misma interfaz de producto. Su configuración, modelo de permisos, comportamiento de MCP y configuración del Gateway pueden ser diferentes.

## Cuándo es importante

- Estás eligiendo entre Claude Code CLI y Claude Desktop
- Quieres que Claude modifique un repositorio
- Estás configurando Claude Desktop Gateway o MCP
- Utilizas Claude Code desde una terminal, un IDE, una aplicación de escritorio o la web
- Estás investigando diferencias entre el comportamiento de la aplicación y la CLI

## Conceptos clave

| Área | Claude Code | Claude Desktop |
| --- | --- | --- |
| Función principal | Agente de programación | Aplicación de escritorio |
| Acceso habitual | Terminal, IDE, escritorio, web | Aplicación de escritorio para macOS o Windows |
| Trabajo con repositorios | Diseñado para leer y editar archivos y ejecutar comandos | Depende de las funciones de Desktop, extensiones, Cowork o el modo Code |
| Enfoque de la configuración | Directorio del proyecto, permisos, `CLAUDE.md`, proveedor de API | Inicio de sesión, extensiones de escritorio, MCP, Gateway |
| Uso recomendado | Cambios de código, pruebas, revisión, automatización | Conversaciones, conectores de escritorio, flujos visuales |

## Elección recomendada

Utiliza Claude Code cuando quieras que un agente trabaje directamente dentro de un repositorio. Su flujo gira en torno al directorio del proyecto, los cambios de archivos, los comandos y la verificación.

Utiliza Claude Desktop cuando quieras una aplicación gráfica de Claude, extensiones de escritorio, servidores MCP locales o flujos específicos de Desktop. Si utilizas Code o Cowork en Desktop, comprueba si empleas el comportamiento integrado de Claude Code o una configuración independiente de Claude Code CLI.

Para las API de terceros, utiliza el protocolo compatible con la interfaz actual. En esta documentación, Claude Code utiliza `{{anthropic-base-url}}`. No introduzcas directamente la dirección compatible con OpenAI `{{openai-base-url}}` en un campo del Gateway que espere el protocolo Anthropic.

## Errores habituales

- Suponer que Claude Desktop instala o sustituye automáticamente Claude Code CLI.
- Copiar la configuración de MCP de Desktop en Claude Code, o al contrario.
- Tratar una suscripción de Claude.ai como una API Key.
- Utilizar una Base URL compatible con OpenAI en un campo de Claude Desktop Gateway que espera tráfico compatible con Anthropic.
- Suponer que las funciones de Desktop sustituyen los permisos, hooks o políticas de comandos de Claude Code.

## Cómo interviene BetterToken

BetterToken forma parte de la capa de API del modelo. Puede proporcionar endpoints compatibles cuando la herramienta admite una API Key y una Base URL personalizadas.

No combina Claude Code y Claude Desktop en una sola configuración. Debes seguir el protocolo, el Gateway, la configuración de MCP y el modelo de permisos de la interfaz que utilices.
