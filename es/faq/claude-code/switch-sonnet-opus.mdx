## Respuesta breve

Para cambiar entre Sonnet, Opus u otro modelo en Claude Code, utiliza preferentemente el punto de entrada compatible `/model` o la vía oficial de configuración de modelos.

Los alias, los Model ID completos y las asignaciones del proveedor no siempre coinciden. Un nombre comercial mostrado en una interfaz web no siempre es el Model ID reconocido por la API.

Si utilizas un gateway de terceros, usa el Model ID que aparece en dicho gateway o en la documentación del proveedor.

## Cuándo es importante

- Quieres cambiar entre modelos más económicos y modelos más capaces
- Ves los alias Sonnet / Opus / Haiku, pero no sabes qué introducir
- Utilizas una Base URL o un gateway de modelos de terceros
- Quieres controlar el coste de tokens de Claude Code
- Aparece un error de modelo no encontrado o el cambio de modelo no se aplica

## Tres niveles de nombres de modelo

| Nivel | Significado |
| --- | --- |
| Nombre mostrado | Nombre legible que aparece en una interfaz |
| Alias | Nombre corto o acceso directo dentro de una herramienta |
| Model ID | Identificador que reconoce realmente la API |

Para que una solicitud sea correcta, el proveedor actual debe reconocer el Model ID.

## Práctica recomendada

1. Confirma qué modelos admite el proveedor actual.
2. Utiliza `/model` en Claude Code o la vía oficial de configuración de modelos.
3. Si utilizas un gateway de terceros, copia el Model ID disponible de su model plaza.
4. Evalúa conjuntamente la elección del modelo y el coste.
5. No escribas nombres de modelos por aproximación.

## Cómo interviene BetterToken

Si conectas Claude Code mediante BetterToken, copia el Model ID actual de la <a href={"{{model-plaza-url}}"}>model plaza</a>. Los modelos del proveedor Claude y del proveedor GPT pertenecen a vías de protocolo diferentes; no los mezcles.

La elección del modelo afecta a la calidad, la velocidad y el coste. Los registros de uso permiten comparar el consumo real entre modelos.
