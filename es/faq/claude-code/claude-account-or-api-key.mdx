## Respuesta rápida

Claude Code admite varios métodos de autenticación. Los usuarios individuales suelen iniciar sesión con una cuenta de Claude.ai. Los usuarios de API o los equipos pueden utilizar Claude Console, proveedores cloud o una vía compatible de un proveedor externo.

Una cuenta de Claude.ai y una API Key no son lo mismo. El inicio de sesión de Claude.ai corresponde a la experiencia oficial del producto. Una API Key se utiliza para las solicitudes a la API del modelo y suele acompañarse de una Base URL y la configuración del proveedor.

Si utilizas un gateway de API de terceros, los campos importantes son API Key y Base URL. También debes confirmar si la herramienta espera un protocolo compatible con Anthropic o con OpenAI.

## Cuándo es importante

- Aparece una solicitud de inicio de sesión al configurar Claude Code
- No sabes si Claude Pro o Max proporciona una API Key
- Quieres enrutar Claude Code mediante un gateway de API personalizado
- Debes elegir entre el inicio de sesión oficial y un proveedor externo
- Un equipo necesita un patrón de autenticación uniforme

## Conceptos clave

| Concepto | Significado |
| --- | --- |
| Cuenta de Claude.ai | Inicio de sesión oficial para las experiencias de Claude |
| API de Claude Console | Acceso a la API y gestión del uso para desarrolladores |
| API Key | Credencial utilizada para las solicitudes a la API del modelo |
| Base URL | Endpoint al que se envían las solicitudes |
| Proveedor | Fuente de autenticación y solicitudes del modelo utilizada por Claude Code |
| Gateway de API de terceros | Capa de compatibilidad, enrutamiento, facturación u observabilidad entre la herramienta y los proveedores de modelos |

## Flujo de decisión recomendado

1. Si solo quieres la experiencia oficial de Claude Code y utilizas un plan de Claude.ai, empieza con el inicio de sesión oficial.
2. Si necesitas facturación por API o acceso gestionado por el equipo, revisa Claude Console o el proveedor del equipo.
3. Si necesitas un gateway de API personalizado, confirma que Claude Code admite la vía del proveedor y configura API Key y Base URL.
4. Si necesitas funciones de la aplicación oficial y un proveedor de inferencia externo, decide si debes conservar la sesión oficial.

En esta documentación, la Base URL compatible con Anthropic para Claude Code es `{{anthropic-base-url}}`.

## Errores habituales

- Tratar una suscripción de Claude.ai como una API Key.
- Pegar una credencial de ChatGPT Plus u otra suscripción en Claude Code.
- Copiar solo la API Key y olvidar cambiar la Base URL.
- Introducir una Base URL compatible con OpenAI en la configuración compatible con Anthropic de Claude Code.
- Compartir `auth.json`, refresh tokens o credenciales de sesión como si fueran API Keys.

## Cómo interviene BetterToken

Si eliges la vía de API Key + Base URL, BetterToken puede proporcionar el endpoint compatible y un Dashboard para gestionar API Keys, saldo e historial de uso.

BetterToken no sustituye el inicio de sesión de Claude.ai ni convierte una suscripción de Claude.ai en una API Key. Solo gestiona la capa de API del modelo.
