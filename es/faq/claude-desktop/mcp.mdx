## Respuesta breve

Claude Desktop puede conectarse a herramientas locales y fuentes de datos mediante servidores MCP. Declara el servidor en la configuración MCP de Claude Desktop, reinicia o actualiza la conexión y comprueba su estado en la aplicación.

MCP no es una API de modelo. Permite que Claude Desktop acceda a herramientas o contexto. Las solicitudes al modelo siguen dependiendo del modelo y de la vía de acceso a la cuenta que use Claude Desktop.

## Cuándo lo necesitas

- Quieres que Claude Desktop acceda a archivos locales, bases de datos o herramientas de desarrollo
- Ves la configuración de un servidor MCP, pero no sabes dónde colocarla
- Estás comparando MCP local y MCP remoto
- Piensas que MCP puede sustituir la API Key / Base URL
- Necesitas comprobar si MCP está conectado

## MCP local frente a MCP remoto

| Tipo | Significado |
| --- | --- |
| MCP local | Ejecuta un servidor en tu equipo, normalmente para herramientas, archivos o entornos de desarrollo locales |
| MCP remoto | Se conecta a un servicio remoto, normalmente para herramientas en la nube o servicios de equipo |
| Extensión de escritorio | Formato de instalación y distribución más orientado al escritorio |

## Configuración recomendada

1. Confirma que estás conectando un servidor MCP, no un proveedor de modelos.
2. Añade la configuración MCP local o remota según la documentación de Claude Desktop.
3. Reinicia o actualiza Claude Desktop.
4. Comprueba el estado de la conexión MCP en Claude Desktop.
5. Concede al servidor MCP solo los permisos y las variables de entorno que necesita.

## Errores habituales

- Tratar un servidor MCP como una Base URL.
- Introducir la API Key de un modelo en la configuración de MCP.
- Suponer que MCP cambia el coste del modelo.
- Olvidar que un servidor MCP puede acceder a datos locales sensibles.
- Revisar únicamente la interfaz de Claude Desktop cuando el servidor local no está en ejecución.

## Acerca de BetterToken

BetterToken gestiona el acceso a la API del modelo, no los servidores MCP. MCP en Claude Desktop conecta herramientas. Las capas de API como BetterToken gestionan las solicitudes al modelo, el saldo y el uso.

Si necesitas acceso a herramientas y un enrutamiento unificado de modelos, configura MCP y el acceso a la API por separado.
