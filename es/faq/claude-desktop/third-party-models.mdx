Claude Desktop solo admite modelos Claude. Es una limitación del cliente Claude Desktop.

## Configuración

Sigue la [guía de Claude Desktop](/es/faq/claude-desktop-bettertoken-api): selecciona **Gateway**, usa la Base URL `{{anthropic-base-url}}`, tu BetterToken API Key y **Gateway auth scheme** `x-api-key`. Pulsa **Apply locally** y reinicia Claude Desktop por completo.

Copia el Model ID exacto de la <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Solución de problemas

### 401 / Unauthorized

Comprueba que la API Key esté completa y no haya vencido. Usa `x-api-key` en esta configuración Gateway, guarda y reinicia Claude Desktop.

### Modelo

Copia un Model ID de Claude disponible en la model plaza, guarda y reinicia Claude Desktop.
