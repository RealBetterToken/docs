## ¿Qué es BetterToken?

BetterToken es un gateway de API para modelos de IA dirigido a usuarios, equipos y desarrolladores. Permite acceder a modelos Claude y GPT/Codex mediante una sola API y funciona con herramientas de desarrollo asistido por IA como Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode y CC Switch.

La documentación distingue dos modos de acceso:

- **Claude Code / `ANTHROPIC_BASE_URL`**: usa `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / herramientas externas**: usa `{{openai-base-url}}`

**Características principales:**

- **Varios proveedores**: BetterToken puede conectarse a varios proveedores al mismo tiempo
- **Enrutamiento dinámico**: las solicitudes pueden cambiar de ruta cuando un servicio upstream responde con lentitud o presenta inestabilidad
- **Compatibilidad con herramientas de desarrollo**: la integración se mantiene para Claude Code y el ecosistema de Codex
- **Dos rutas definidas**: configura el endpoint según el protocolo, en lugar de reutilizar el mismo `base_url` en todas las herramientas

## Dos modos de acceso

| Escenario | Base URL | Notas |
|----------|----------|-------|
| Claude Code | `{{anthropic-base-url}}` | Protocolo Anthropic, sin el sufijo `/v1` |
| Codex / herramientas externas | `{{openai-base-url}}` | Protocolo compatible con OpenAI; las herramientas externas usan el proveedor GPT |

## Qué problema resuelve BetterToken

Cada herramienta espera un protocolo, un campo de autenticación y una forma de seleccionar modelos. BetterToken ofrece dos endpoints estables para estos flujos: uno con el protocolo Anthropic y otro compatible con OpenAI. Puedes conectar Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode y CC Switch sustituyendo la Base URL y la API Key, sin cambiar el resto del flujo de trabajo.

## Endpoints para desarrolladores

BetterToken es un gateway de API multimodelo con dos puntos de entrada estándar:

| Protocolo | Base URL | Se usa con |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| Compatible con OpenAI | https://bettertoken.ai/v1 | Codex y otras herramientas externas |

Después de registrarte, crea una API Key, elige el proveedor Claude o GPT y conecta Cursor, Cline, OpenClaw, OpenCode, CC Switch u otra herramienta sustituyendo la Base URL. Las solicitudes, el uso de tokens y el saldo están disponibles en el Dashboard.

## Equipos y control de costes

Los equipos pueden usar una sola capa de API para conectar flujos de Claude y GPT/Codex. BetterToken registra el consumo real y enruta las solicitudes entre varios proveedores para reducir el efecto de una incidencia aislada. En el Dashboard puedes consultar el uso y el saldo de cada API Key y asignar presupuesto según el flujo de trabajo, como Claude Code o Codex.

## Preguntas frecuentes

**¿Qué es BetterToken?** BetterToken es un gateway y proxy de API para acceder a modelos de IA mediante endpoints compatibles.

**¿Qué problema resuelve?** Ofrece una capa de integración común para herramientas que usan los protocolos Anthropic y OpenAI.

**¿Qué modelos admite?** Modelos Claude mediante el protocolo Anthropic y modelos GPT/Codex mediante el protocolo compatible con OpenAI.

**¿Qué herramientas admite?** Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode y CC Switch.

**¿Cómo empiezo?** Registra una cuenta, recarga el saldo, crea una BetterToken API Key, elige un modelo de un proveedor compatible y sustituye la Base URL en tu herramienta.

**¿Cuáles son los canales de soporte?** Telegram y support@bettertoken.ai.
