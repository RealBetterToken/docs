<Steps>
  <Step title="अकाउंट बनाएं">
    अकाउंट बनाने के लिए <a href={"{{register-url}}"}>BetterToken रजिस्ट्रेशन पेज</a> खोलें।

    रजिस्टर करने के बाद बैलेंस टॉप-अप करें, फिर BetterToken API Key बनाएं।
  </Step>
  <Step title="अकाउंट में बैलेंस जोड़ें">
    **Online top-up** या **Redeem code** का उपयोग करें। क्रेडिट जोड़ने के बाद Console पर लौटें और API Key बनाने से पहले पुष्टि करें कि **Current balance** अपडेट हो गया है।

    <Tabs>
      <Tab title="Online top-up">
        साइन इन करके **Console** खोलें। **Current balance** कार्ड में वह currency चुनें जिसे top up करना है, फिर उसका **Top up** बटन क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="BetterToken Console का Current balance कार्ड, जिसमें अलग-अलग currency के Top up बटन दिखाई दे रहे हैं।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        payment निर्देशों का पालन करें। payment सफल होने पर Console पर लौटें और पुष्टि करें कि **Current balance** अपडेट हो गया है।
      </Tab>
      <Tab title="Redeem code">
        साइन इन करके **Console** खोलें और **Current balance** कार्ड के नीचे बाईं ओर **Redeem code** पर क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="BetterToken Console का Current balance कार्ड, जिसमें नीचे बाईं ओर Redeem code बटन पर तीर दिखाया गया है।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        dialog में redemption code दर्ज करें, फिर **Redeem** पर क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Code input और Redeem बटन वाला Redeem code dialog।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        code redeem होने के बाद Console पर लौटें और पुष्टि करें कि **Current balance** अपडेट हो गया है।
      </Tab>
    </Tabs>
  </Step>
  <Step title="API Key प्रबंधन खोलें और API Key बनाएं">
    बैलेंस उपलब्ध होने पर Console के **Your API keys** सेक्शन के ऊपर दाईं ओर **Create API key** पर क्लिक करें।

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="BetterToken Console का Your API keys सेक्शन, जिसमें ऊपर दाईं ओर Create API key बटन पर तीर दिखाया गया है।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    **Create API Key** में **API key name** दर्ज करें। यदि समाप्ति तिथि या खर्च सीमा तय करनी हो, तो **Advanced settings** खोलें। फिर **Create API Key** पर क्लिक करें।

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="Create API Key डायलॉग में API key name, Advanced settings और Create API Key बटन।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="कनेक्शन विवरण या सेटअप कोड कॉपी करें">
    Key बनाने के बाद **Set up API key** खोलें। **Connection details** से **API Key** कॉपी करें। अपने प्रोटोकॉल के अनुसार **OpenAI** या **Anthropic** चुनें और संबंधित **Base URL** कॉपी करें।

    या नीचे **Configuration guide** में अपना टूल या **API call** चुनें, ज़रूरत के अनुसार API और उदाहरण मॉडल चुनें, फिर दिया गया कोड कॉपी करें। विस्तृत निर्देशों के लिए **View tool documentation** या नीचे दी गई गाइड देखें। अंत में **Finish** पर क्लिक करें।

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="Set up API key डायलॉग में ऊपर कॉपी करने योग्य API Key और Base URL तथा नीचे टूल और कोड वाला Configuration guide।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
