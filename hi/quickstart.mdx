<Steps>
  <Step title="अकाउंट बनाएं">
    अकाउंट बनाने के लिए <a href={"{{register-url}}"}>BetterToken रजिस्ट्रेशन पेज</a> खोलें।

    रजिस्टर करने पर आपको अपने-आप **$1 का ट्रायल क्रेडिट** मिलेगा।
  </Step>
  <Step title="अकाउंट में बैलेंस जोड़ें">
    **Online top-up** या **Redeem code** का उपयोग करें। क्रेडिट जोड़ने के बाद Console पर लौटें और API Key बनाने से पहले पुष्टि करें कि **Current balance** अपडेट हो गया है।

    <Tabs>
      <Tab title="Online top-up">
        साइन इन करके **Console** खोलें। **Current balance** कार्ड में वह currency चुनें जिसे top up करना है, फिर उसका **Top up** बटन क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="BetterToken Console का Current balance कार्ड, जिसमें अलग-अलग currency के Top up बटन दिखाई दे रहे हैं।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        payment निर्देशों का पालन करें। payment सफल होने पर Console पर लौटें और पुष्टि करें कि **Current balance** अपडेट हो गया है।
      </Tab>
      <Tab title="Redeem code">
        साइन इन करके **Console** खोलें और **Current balance** कार्ड के नीचे बाईं ओर **Redeem code** पर क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="BetterToken Console का Current balance कार्ड, जिसमें नीचे बाईं ओर Redeem code बटन पर तीर दिखाया गया है।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        dialog में redemption code दर्ज करें, फिर **Redeem** पर क्लिक करें।

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Code input और Redeem बटन वाला Redeem code dialog।"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        code redeem होने के बाद Console पर लौटें और पुष्टि करें कि **Current balance** अपडेट हो गया है।
      </Tab>
    </Tabs>
  </Step>
  <Step title="API Key प्रबंधन खोलें और API Key बनाएं">
    बैलेंस उपलब्ध होने पर Console के **Your API keys** सेक्शन के ऊपर दाईं ओर **Create API key** पर क्लिक करें।

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="BetterToken Console का Your API keys सेक्शन, जिसमें ऊपर दाईं ओर Create API key बटन पर तीर दिखाया गया है।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    इससे API Key बनाने का form खुलता है।

    <Info>
      API Key का नाम उसके उपयोग के अनुसार रखें। पहले सही use case चुनने पर बाकी सेटअप स्पष्ट हो जाता है।
    </Info>
  </Step>
  <Step title="टूल के प्रकार के अनुसार प्रदाता चुनें">
    form में **Name** भरें, **provider** चुनें और expiry date तथा वैकल्पिक spending limit की पुष्टि करें।

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Name, provider, expiration और spending limit विकल्पों वाला Create API Key form।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    जिस टूल को कनेक्ट करना है उसके अनुसार प्रदाता चुनें।

    <Warning>
      **Claude प्रदाता** का उपयोग केवल Claude Code के साथ किया जा सकता है।
    </Warning>

    <Warning>
      **GPT प्रदाता** का उपयोग Codex और OpenClaw, OpenCode तथा Cursor जैसे बाहरी टूल के साथ किया जा सकता है।
    </Warning>

    इनमें से एक प्रदाता चुनें:

    ```text
    Claude
    GPT
    ```

    Key बनाने के बाद **API key setup** dialog खुलता है। इस dialog से **API Key** और **Base URL** कॉपी करें।

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="API Key, Base URL, टूल चयन और सेटअप विधियों वाला BetterToken API key setup dialog।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="सेटअप विधि चुनें">
    **API key setup** dialog के बाईं ओर कनेक्ट करने वाला टूल चुनें, फिर एक सेटअप विधि चुनें।

    - **One-click Bash Configuration**: टूल और `macOS / Linux` या `Windows` चुनें, generated command कॉपी करें और अपने local terminal में चलाएं। Codex, OpenClaw या OpenCode के त्वरित सेटअप के लिए इसका उपयोग करें।
    - **CC Switch integration**: मौजूदा **API Key** और **Base URL** को CC Switch में import करने के लिए **Import to CC Switch** पर क्लिक करें। एक app में कई टूल और प्रदाता प्रबंधित करने के लिए इसका उपयोग करें।
    - **Manual configuration**: **API Key** और **Base URL** कॉपी करके target टूल के सेटअप में paste करें। Cursor, Cline, Roo Code, Zed और अन्य client के लिए इसका उपयोग करें।

    <Note>
      अलग-अलग टूल में अलग auth field, मॉडल selector और config file location होती है। सेटअप पूरा करने से पहले उस टूल की गाइड खोलें।
    </Note>
  </Step>
</Steps>
