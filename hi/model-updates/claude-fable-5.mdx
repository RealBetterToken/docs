release date: 9 जून 2026

BetterToken ने `Claude Fable 5` model entry अपडेट किया है। वर्तमान में उपलब्ध model ID के लिए <a href={"{{model-plaza-url}}"}>model plaza</a> जांचें, फिर अपने client से मेल खाती Claude Code या external-tool setup guide से कॉन्फ़िगर करें।

Anthropic ने 9 जून 2026 को Claude Fable 5 आधिकारिक रूप से पेश किया और इसे सबसे कठिन knowledge work व coding problems के लिए intelligence की नई generation बताया। Anthropic के अनुसार Fable 5, Mythos-class model है जो अधिक लंबे, complex और asynchronous work के लिए बना है, विशेषकर long-running agents, complex software engineering, knowledge work और vision-heavy workflows के लिए।

## मुख्य विशेषताएं

- **मजबूत long-running agent work**: Anthropic के अनुसार Fable 5, Claude Code या agent harness में लंबे समय तक operate कर सकता है, stages में plan करता है, execute करता है और अपने काम की जांच करता है
- **complex software engineering के लिए बेहतर**: model को large migrations, complex implementations, multi-day autonomous sessions और कम direct supervision वाले engineering tasks के लिए रखा गया है
- **बेहतर knowledge work और vision**: Fable 5 complex analysis, document reasoning, charts, tables, PDFs और अन्य visual materials के लिए लक्षित है
- **अधिक सक्रिय self-checking**: Anthropic बताता है कि Fable 5 अपने काम को अधिक गहराई से validate करता है, जो task hand off कर बाद में result review करने में मदद करता है
- **नई safeguards**: cybersecurity, biology और chemistry जैसे sensitive areas के लिए Anthropic safeguards और fallback behavior लागू करता है; कुछ requests का उत्तर Claude Opus 4.8 से दिया जा सकता है

## setup guidance

Claude Code उपयोग करने पर [Claude Code सेटअप गाइड](/hi/ai-tools/claude-code) से शुरू करें। अलग providers अलग protocols और model configuration patterns उपयोग करते हैं:

- `Claude` group: `{{anthropic-base-url}}` उपयोग करें
- `GPT` group या external tools: `{{openai-base-url}}` के साथ relevant tool guide देखें

<a href={"{{model-plaza-url}}"}>model plaza</a> में वर्तमान में दिखता model name उपयोग करें। वहां न दिखने वाला model name hardcode न करें।

<Note>
  Claude Fable 5 high-value, long-context, long-running tasks के लिए सर्वश्रेष्ठ है। simple Q&A या low-cost batch work के लिए model plaza में दिखाए groups और pricing के आधार पर lighter model चुनें।
</Note>
