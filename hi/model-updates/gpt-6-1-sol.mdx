अपडेट: 30 सितंबर 2026

**GPT-6.1 Sol**, GPT-6 Sol का नया संस्करण है। OpenAI के अनुसार, यह agent-based coding, computer use और पेशेवर काम में बेहतर है और कुछ मूल्यांकन में GPT-6 Astra के करीब पहुंचता है। कठिन काम के लिए अपने workflow में गुणवत्ता, latency और token उपयोग की तुलना करें।

BetterToken पर इसका Model ID `gpt-6.1-sol` है। उपलब्धता और BetterToken की मौजूदा कीमतें <a href={"{{model-plaza-url}}"}>model plaza</a> में देखें।

## मुख्य विशेषताएं

- **Coding और agents**: कई फाइलों में बदलाव, debugging और लंबे software-engineering काम के लिए।
- **Apps और documents**: OpenAI ने इन कामों में GPT-6 Sol से बेहतर परिणाम बताए हैं।
- **बड़ा context**: OpenAI `1,050,000` token का context window और अधिकतम `128,000` output tokens बताता है। Client और कनेक्शन के अनुसार कम सीमा लागू हो सकती है।
- **बदलने योग्य reasoning**: `low`, `medium`, `high`, `xhigh` और `max` समर्थित हैं; `none` और `minimal` नहीं।

## कैसे कनेक्ट करें

1. <a href={"{{register-url}}"}>BetterToken API Key बनाएं</a>।
2. Codex CLI या दूसरे OpenAI-compatible client में Base URL `{{openai-base-url}}` और Model ID `gpt-6.1-sol` सेट करें।
3. Tool calling के लिए [Responses API](/hi/api-reference/responses) उपयोग करें। OpenAI इस मॉडल के लिए Chat Completions को tool calling के बिना समर्थित बताता है।
4. मौजूदा workflow बदलने से पहले एक सामान्य काम पर परीक्षण करें।

Claude Code में Anthropic-protocol Base URL `{{anthropic-base-url}}` और यही Model ID उपयोग करें। Client के लिए [Claude Code गाइड](/hi/ai-tools/claude-code) या [Codex CLI गाइड](/hi/ai-tools/codex) देखें।
