रिलीज़ तिथि: 22 सितंबर 2026

OpenAI ने GPT-6 परिवार में Astra के साथ Sol और Luna को जोड़ा है। Sol जटिल coding और Agent workflows के लिए है, जबकि Luna केंद्रित, बड़े पैमाने पर दोहराए जाने वाले कार्यों के लिए है। OpenAI के अनुसार, दोनों GPT-5.6 परिवार से coding, तथ्यात्मकता और संवाद में बेहतर हैं।

BetterToken अब **GPT-6 Sol** और **GPT-6 Luna** का समर्थन करता है। `GPT` प्रदाता चुनें, Base URL `{{openai-base-url}}` सेट करें और `gpt-6-sol` या `gpt-6-luna` उपयोग करें। आधिकारिक नाम **Sol** है, `Sora` नहीं।

BetterToken की वर्तमान उपलब्धता और कीमत <a href={"{{model-plaza-url}}"}>model plaza</a> में देखें।

## मॉडल चुनें

- **`gpt-6-sol`**: जटिल coding और Agent workflows के लिए।
- **`gpt-6-luna`**: केंद्रित, दोहराए जाने वाले और उच्च-वॉल्यूम कार्यों के लिए।

## मुख्य विशेषताएं

- **बड़ा context**: OpenAI दोनों मॉडलों के लिए `1,050,000` token context window और अधिकतम `128,000` output tokens बताता है।
- **समायोज्य reasoning**: दोनों `none`, `low`, `medium`, `high`, `xhigh` और `max` effort का समर्थन करते हैं।
- **काम की गुणवत्ता**: OpenAI के अनुसार, GPT-5.6 की तुलना में coding, तथ्यात्मकता और तकनीकी जवाबों की स्पष्टता बेहतर हुई है।

## कनेक्ट करें

1. <a href={"{{register-url}}"}>BetterToken API Key बनाएं</a>।
2. `GPT` और `{{openai-base-url}}` Base URL चुनें।
3. जटिल Agent कार्यों के लिए `gpt-6-sol` और दोहराए जाने वाले उच्च-वॉल्यूम कार्यों के लिए `gpt-6-luna` उपयोग करें।
