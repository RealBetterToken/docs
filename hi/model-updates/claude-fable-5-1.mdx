BetterToken अब सटीक Model ID `claude-fable-5-1` के साथ **Claude Fable 5.1** उपलब्ध कराता है। मौजूदा उपलब्धता और कीमत <a href={"{{model-plaza-url}}"}>model plaza</a> में जांचें, फिर supported client में यही ID उपयोग करें।

## उपलब्ध जानकारी

- **Model**: Claude Fable 5.1
- **Model ID**: `claude-fable-5-1`
- **उपलब्धता और कीमत**: model plaza की live जानकारी देखें

## Claude Fable 5.1 configure करें

1. BetterToken API Key बनाएं या मौजूदा Key का **Setup** dialog खोलें।
2. model plaza से `claude-fable-5-1` कॉपी करें।
3. अपने client की setup guide खोलें और BetterToken API Key, आवश्यक Base URL और सही Model ID भरें।
4. Model सूची refresh न होने पर client restart करें।
5. छोटा test request भेजें और Dashboard में उसे verify करें।
