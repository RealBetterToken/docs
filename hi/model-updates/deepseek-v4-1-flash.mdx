**DeepSeek V4.1 Flash** अब BetterToken पर आधिकारिक रूप से उपलब्ध है। सटीक Model ID `deepseek-flash` इस्तेमाल करें। अनुरोध भेजने से पहले <a href={"{{model-plaza-url}}"}>model plaza</a> में मौजूदा उपलब्धता और कीमत देखें।

<Check>

</Check>

## अभी क्या उपलब्ध है

| सेटिंग | मान |
| --- | --- |
| प्रोवाइडर | **DeepSeek** |
| Model ID | `deepseek-flash` |
| OpenAI Base URL | `{{openai-base-url}}` |
| OpenAI Chat Completions | `POST /v1/chat/completions` |
| Anthropic Base URL | `{{anthropic-base-url}}` |
| Anthropic Messages | `POST /v1/messages` |
| BetterToken स्थिति | उपलब्ध |

अपने क्लाइंट के अनुसार OpenAI Chat Completions या Anthropic Messages चुनें। दोनों प्रोटोकॉल एक ही BetterToken API Key और Model ID इस्तेमाल करते हैं।

## उपयोग के सुझाव

अपने वर्कफ़्लो के लिए महत्वपूर्ण कार्यों पर DeepSeek V4.1 Flash की तुलना किसी अन्य उपलब्ध मॉडल से करें:

- **कोड में बदलाव**: दोनों मॉडलों को एक ही रिपॉज़िटरी कार्य दें और शुद्धता, बदलाव की गुणवत्ता तथा आवश्यक फ़ॉलो-अप की तुलना करें
- **Agent वर्कफ़्लो**: मापें कि हर मॉडल कई चरणों वाले निर्देशों का पालन और क्लाइंट के टूल का उपयोग कितनी विश्वसनीयता से करता है
- **रीज़निंग गुणवत्ता**: एक ही प्रॉम्प्ट और मूल्यांकन मानदंड के साथ कठिन डीबगिंग, योजना और विश्लेषण कार्यों की तुलना करें
- **लेटेंसी और लागत**: पहले token तक का समय, पूरा होने का समय, token उपयोग और BetterToken की लाइव कीमत दर्ज करें

एक परिणाम पर निर्भर रहने के बजाय कई प्रतिनिधि प्रॉम्प्ट चलाएं। निष्पक्ष तुलना के लिए क्लाइंट, सिस्टम प्रॉम्प्ट, टूल परिभाषाएं और सैंपलिंग सेटिंग एक जैसी रखें।

## जल्दी शुरू करें

1. <a href={"{{register-url}}"}>BetterToken API Key बनाएं</a> या मौजूदा Key के लिए **Setup** खोलें।
2. model plaza में पुष्टि करें कि `deepseek-flash` उपलब्ध है।
3. **DeepSeek प्रोवाइडर** चुनें।
4. ऊपर की तालिका से अपने प्रोटोकॉल का Base URL चुनें और पूरा Model ID दर्ज करें।
5. लंबा मूल्यांकन शुरू करने से पहले एक छोटा अनुरोध भेजें।

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

सफल प्रतिक्रिया में मॉडल आउटपुट `choices[0].message.content` में मिलता है। SDK उदाहरण और पूरा अनुरोध प्रारूप [Chat Completions API संदर्भ](/hi/api-reference/chat-completions) में देखें।

## सीमित-टेस्ट Model ID से माइग्रेट करें

अगर किसी कॉन्फ़िगरेशन में पिछला सीमित-टेस्ट Model ID अभी भी मौजूद है:

1. `deepseek-v4.1-flash-expires-on-0910` वाली हर कॉन्फ़िगरेशन खोजें।
2. इसे `deepseek-flash` से बदलें।
3. बदलाव के बाद स्मोक टेस्ट चलाएं।
4. model plaza में मौजूदा मॉडल एंट्री और कीमत की पुष्टि करें।

## अक्सर पूछे जाने वाले प्रश्न

### क्या मैं इस Model ID को प्रोडक्शन में इस्तेमाल कर सकता हूं?

हां। `deepseek-flash` इस्तेमाल करें और model plaza में पुष्टि करें कि मॉडल आपकी BetterToken API Key के लिए उपलब्ध है।

### क्या इसे Claude Code या Anthropic Messages API के साथ इस्तेमाल किया जा सकता है?

हां। Claude Code या Anthropic Messages के लिए Base URL `{{anthropic-base-url}}` और Model ID `deepseek-flash` इस्तेमाल करें। सीधे Messages अनुरोधों में `POST /v1/messages` और `x-api-key` हेडर में अपनी BetterToken API Key दें।

### मौजूदा कीमत कहां मिलेगी?

लाइव <a href={"{{model-plaza-url}}"}>model plaza</a> देखें। उपलब्धता और कीमत बदल सकती है।
