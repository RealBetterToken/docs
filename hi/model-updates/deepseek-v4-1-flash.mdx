अपडेट: 9 सितंबर 2026

BetterToken अब सटीक Model ID `deepseek-v4.1-flash-expires-on-0910` के माध्यम से **DeepSeek V4.1 Flash** का सीमित टेस्ट एक्सेस देता है। यह अस्थायी एंट्री **10 सितंबर 2026** को समाप्त होने वाली है। इसे स्थायी प्रोडक्शन कॉन्फ़िगरेशन के रूप में नहीं, बल्कि मॉडल का मूल्यांकन करने के लिए इस्तेमाल करें। अनुरोध भेजने से पहले <a href={"{{model-plaza-url}}"}>model plaza</a> में मौजूदा उपलब्धता और कीमत देखें।

<Warning>
  अस्थायी Model ID में उसकी समाप्ति तिथि शामिल है। यह 10 सितंबर 2026 के बाद काम करना बंद कर सकता है और भविष्य के स्थिर ID से अपने आप नहीं बदलेगा। एक स्थिर वैकल्पिक मॉडल तैयार रखें।
</Warning>

## अभी क्या उपलब्ध है

| सेटिंग | मान |
| --- | --- |
| प्रोवाइडर | **DeepSeek** |
| Model ID | `deepseek-v4.1-flash-expires-on-0910` |
| Base URL | `{{openai-base-url}}` |
| एंडपॉइंट | `POST /v1/chat/completions` |
| प्रोटोकॉल | OpenAI-संगत Chat Completions |
| BetterToken स्थिति | सीमित टेस्ट; 10 सितंबर 2026 को समाप्त होना निर्धारित |

यह मॉडल OpenAI-संगत Chat Completions का उपयोग करता है। इस प्रोटोकॉल का समर्थन करने वाले बाहरी टूल में नीचे दी गई सेटिंग इस्तेमाल करें।

## उपयोग के सुझाव

टेस्ट अवधि में अपने वर्कफ़्लो के लिए महत्वपूर्ण कार्यों पर DeepSeek V4.1 Flash की तुलना स्थिर DeepSeek V4 Flash एंट्री से करें:

- **कोड में बदलाव**: दोनों मॉडलों को एक ही रिपॉज़िटरी कार्य दें और शुद्धता, बदलाव की गुणवत्ता तथा आवश्यक फ़ॉलो-अप की तुलना करें
- **Agent वर्कफ़्लो**: मापें कि हर मॉडल कई चरणों वाले निर्देशों का पालन और क्लाइंट के टूल का उपयोग कितनी विश्वसनीयता से करता है
- **रीज़निंग गुणवत्ता**: एक ही प्रॉम्प्ट और मूल्यांकन मानदंड के साथ कठिन डीबगिंग, योजना और विश्लेषण कार्यों की तुलना करें
- **लेटेंसी और लागत**: पहले token तक का समय, पूरा होने का समय, token उपयोग और BetterToken की लाइव कीमत दर्ज करें

एक परिणाम पर निर्भर रहने के बजाय कई प्रतिनिधि प्रॉम्प्ट चलाएं। निष्पक्ष तुलना के लिए क्लाइंट, सिस्टम प्रॉम्प्ट, टूल परिभाषाएं और सैंपलिंग सेटिंग एक जैसी रखें।

## जल्दी शुरू करें

1. <a href={"{{register-url}}"}>BetterToken API Key बनाएं</a> या मौजूदा Key के लिए **Setup** खोलें।
2. model plaza में पुष्टि करें कि `deepseek-v4.1-flash-expires-on-0910` अभी भी उपलब्ध है।
3. **DeepSeek प्रोवाइडर** चुनें।
4. Base URL को `{{openai-base-url}}` पर सेट करें और सटीक अस्थायी Model ID इस्तेमाल करें।
5. लंबा मूल्यांकन शुरू करने से पहले एक छोटा अनुरोध भेजें।

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-v4.1-flash-expires-on-0910",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

सफल प्रतिक्रिया में मॉडल आउटपुट `choices[0].message.content` में मिलता है। SDK उदाहरण और पूरा अनुरोध प्रारूप [Chat Completions API संदर्भ](/hi/api-reference/chat-completions) में देखें।

## समाप्ति के लिए तैयारी करें

10 सितंबर 2026 से पहले:

1. `deepseek-v4.1-flash-expires-on-0910` वाली हर कॉन्फ़िगरेशन खोजें।
2. ज़रूरी मूल्यांकन परिणाम सुरक्षित करें।
3. अस्थायी ID को `deepseek-v4-flash-0731` या किसी अन्य वर्तमान में उपलब्ध Model ID से बदलें।
4. बदलाव के बाद स्मोक टेस्ट चलाएं।
5. model plaza में नई स्थिर V4.1 एंट्री देखें। उसके Model ID का अनुमान न लगाएं।

## अक्सर पूछे जाने वाले प्रश्न

### क्या मैं इस Model ID को प्रोडक्शन में इस्तेमाल कर सकता हूं?

एंट्री उपलब्ध रहने तक आप अनुरोध भेज सकते हैं, लेकिन इसे लंबे समय की प्रोडक्शन कॉन्फ़िगरेशन में एकमात्र मॉडल न बनाएं। टेस्ट समाप्त होने के बाद निर्धारित समाप्ति के कारण अनुरोध विफल हो सकते हैं।

### क्या इसे Claude Code या Anthropic Messages API के साथ इस्तेमाल किया जा सकता है?

यह मॉडल अभी BetterToken पर Chat Completions का समर्थन करता है। संगत बाहरी टूल में `{{openai-base-url}}` इस्तेमाल करें। इस मॉडल के लिए Claude Code और Anthropic Messages API समर्थित नहीं हैं।

### मौजूदा कीमत कहां मिलेगी?

लाइव <a href={"{{model-plaza-url}}"}>model plaza</a> देखें। टेस्ट के दौरान अस्थायी मॉडल की उपलब्धता और कीमत बदल सकती है।
