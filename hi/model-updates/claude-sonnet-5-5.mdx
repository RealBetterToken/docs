रिलीज़ की तारीख: 28 सितंबर 2026

Claude Sonnet 5.5, Anthropic के Claude 5.5 परिवार का दूसरा मॉडल है। Anthropic इसे स्पष्ट दायरे वाले दैनिक कार्यों के लिए तेज़ विकल्प बताता है, जैसे कोड लिखना, बग सुधारना और दस्तावेज़, प्रस्तुतियाँ तथा स्प्रेडशीट बनाना। अधिक जटिल और खुले कार्यों के लिए Opus 5.5 पर विचार करें।

**Claude Sonnet 5.5** अब BetterToken पर उपलब्ध है। `Claude` provider चुनें, Base URL `{{anthropic-base-url}}` रखें और मॉडल ID `claude-sonnet-5-5` दर्ज करें। वर्तमान उपलब्धता और कीमत के लिए <a href={"{{model-plaza-url}}"}>model plaza</a> देखें।

## मुख्य विशेषताएँ

- **स्पष्ट कोडिंग कार्य**: सीमित दायरे वाले फीचर और बग सुधार के लिए उपयोग करें।
- **पेशेवर सामग्री**: Anthropic दस्तावेज़, प्रस्तुतियाँ और स्प्रेडशीट बनाने की क्षमता पर ज़ोर देता है।
- **लंबा कॉन्टेक्स्ट**: Anthropic के अनुसार 10 लाख टोकन की कॉन्टेक्स्ट विंडो और अधिकतम 1.28 लाख आउटपुट टोकन मिलते हैं।

## Sonnet 5 से बदलने से पहले

यदि आपका क्लाइंट सीधे Anthropic Messages API को कॉल करता है, तो मॉडल ID बदलने से पहले [आधिकारिक माइग्रेशन गाइड](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide) पढ़ें। Sonnet 5.5 में thinking और tool choice के कुछ व्यवहार बदले हैं। सामान्य अनुरोधों को पहले जाँचें।

## कनेक्ट करें

1. <a href={"{{register-url}}"}>BetterToken API Key बनाएँ</a>।
2. `Claude` provider और Base URL `{{anthropic-base-url}}` चुनें।
3. मॉडल ID `claude-sonnet-5-5` दर्ज करें।
4. प्रोडक्शन ट्रैफ़िक बदलने से पहले किसी वास्तविक कार्य पर परीक्षण करें।
