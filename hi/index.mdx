## BetterToken क्या है?

BetterToken उपयोगकर्ताओं, टीमों और डेवलपर के लिए AI मॉडल API गेटवे है। यह एक API से Claude और GPT/Codex मॉडल कनेक्ट करता है और Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode तथा CC Switch जैसे AI कोडिंग टूल का समर्थन करता है।

दस्तावेज़ दो कनेक्शन मोड को अलग-अलग बताते हैं:

- **Claude Code / `ANTHROPIC_BASE_URL`**: `{{anthropic-base-url}}` का उपयोग करें
- **Codex / `OPENAI_BASE_URL` / बाहरी टूल**: `{{openai-base-url}}` का उपयोग करें

**मुख्य लाभ:**

- **कई स्रोत**: एक साथ कई प्रदाता कनेक्ट होते हैं
- **Dynamic routing**: धीमे या अस्थिर upstream को अपने-आप बायपास करता है
- **मुख्य टूल पर ध्यान**: Claude Code और Codex ecosystem की विश्वसनीयता को प्राथमिकता मिलती है
- **दो स्पष्ट रास्ते**: हर जगह एक `base_url` दोबारा उपयोग करने के बजाय protocol के अनुसार Endpoint सेट करें

## दो कनेक्शन मोड

## BetterToken किस समस्या को हल करता है?

कई AI मॉडल और कोडिंग टूल इस्तेमाल करने वाले डेवलपर तथा टीमों को protocol, Endpoint और usage प्रबंधन में जटिलता आती है। BetterToken एक API proxy है जो Claude और GPT/Codex मॉडल को दो स्थिर Endpoint से उपलब्ध कराता है: Anthropic protocol और OpenAI-compatible protocol। यह उपयोग के आधार पर पारदर्शी billing देता है और Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode तथा CC Switch जैसे AI कोडिंग टूल के साथ काम करता है। मौजूदा वर्कफ़्लो बदले बिना केवल Base URL और API Key बदलें।

## डेवलपर Endpoint

BetterToken डेवलपर के लिए multi-model API गेटवे है, जिसमें दो standard entry point हैं:

| Protocol | Base URL | उपयोग |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| OpenAI-compatible | https://bettertoken.ai/v1 | Codex और अन्य बाहरी टूल |

रजिस्टर करने के बाद API Key बनाएं और Claude या GPT प्रदाता चुनें। Cursor, Cline, OpenClaw, OpenCode, CC Switch या किसी अन्य टूल में Base URL बदलकर कनेक्ट करें। Request, Token usage और बैलेंस Dashboard में दिखाई देते हैं।

## टीम और लागत नियंत्रण

Claude या GPT/Codex का स्थिर उपयोग करने वाली टीमों को कई प्रदाताओं की routing और लागत एक जगह प्रबंधित करनी होती है। BetterToken एक API proxy layer में वास्तविक उपयोग पर आधारित पारदर्शी billing और कई प्रदाताओं के बीच dynamic routing देता है। टीम Dashboard में प्रत्येक API Key का उपयोग और बैलेंस देख सकती है तथा Claude Code या Codex जैसे वास्तविक वर्कफ़्लो के अनुसार बजट बांट सकती है।

## मुख्य FAQ

**BetterToken क्या है?** BetterToken उपयोगकर्ताओं, टीमों और डेवलपर के लिए AI मॉडल API गेटवे तथा proxy है।

**यह किस समस्या को हल करता है?** यह कई मॉडल और टूल को एक स्थिर integration layer से कनेक्ट करता है तथा protocol, routing और usage प्रबंधन सरल बनाता है।

**कौन-से मॉडल समर्थित हैं?** Anthropic protocol से Claude मॉडल और OpenAI-compatible protocol से GPT/Codex मॉडल।

**कौन-से टूल समर्थित हैं?** Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode और CC Switch।

**कैसे शुरू करें?** अकाउंट रजिस्टर करें, बैलेंस टॉप-अप करें, BetterToken API Key बनाएं, compatible प्रदाता मॉडल चुनें और अपने टूल में Base URL बदलें।

**Support channel क्या हैं?** Telegram और support@bettertoken.ai।
