Claude Desktop केवल Claude मॉडल का समर्थन करता है। यह Claude Desktop क्लाइंट की सीमा है।

## सेटअप

[Claude Desktop गाइड](/hi/faq/claude-desktop-bettertoken-api) के अनुसार **Gateway**, Base URL `{{anthropic-base-url}}`, अपनी BetterToken API Key और **Gateway auth scheme** `x-api-key` सेट करें। **Apply locally** दबाएँ और Claude Desktop पूरी तरह फिर से शुरू करें।

<a href={"{{model-plaza-url}}"}>model plaza</a> से सही Model ID कॉपी करें।

## समस्या निवारण

### 401 / Unauthorized

जाँचें कि API Key पूरी कॉपी हुई है और समाप्त नहीं हुई है। इस Gateway में `x-api-key` चुनें, सहेजें और Claude Desktop फिर से शुरू करें।

### मॉडल

model plaza से उपलब्ध Claude Model ID कॉपी करें, सहेजें और Claude Desktop फिर से शुरू करें।
