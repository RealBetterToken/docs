Claude Desktop में BetterToken Gateway कॉन्फ़िगर करने के बाद ये लक्षण सामान्यतः API Key के अमान्य होने का अर्थ नहीं हैं:

- Cowork mode काम नहीं करता
- Code mode में `Claude Code process exited with code 1` दिखता है
- वही API Key terminal से Claude Code CLI में काम करती है

Gateway अभी कॉन्फ़िगर नहीं किया है तो [Claude Desktop में BetterToken API उपयोग करें](/hi/faq/claude-desktop-bettertoken-api) से शुरू करें।

## पहले Cowork mode ठीक करें

Claude Desktop केवल Claude मॉडल का समर्थन करता है। यह Claude Desktop क्लाइंट की सीमा है।

जाँचें कि API Key पूरी कॉपी हुई है और समाप्त नहीं हुई है। इस Gateway में `x-api-key` चुनें, सहेजें और Claude Desktop फिर से शुरू करें।

[Claude Desktop गाइड](/hi/faq/claude-desktop-bettertoken-api) के अनुसार **Gateway**, Base URL `{{anthropic-base-url}}`, अपनी BetterToken API Key और **Gateway auth scheme** `x-api-key` सेट करें। **Apply locally** दबाएँ और Claude Desktop पूरी तरह फिर से शुरू करें।

## फिर Code mode exit त्रुटियां ठीक करें

Cowork काम करे लेकिन Code mode का `</>` tab अब भी `Claude Code process exited with code 1` दिखाए, तो जांचें कि Claude Desktop अब भी पुराना bundled Claude Code संस्करण उपयोग कर रहा है या नहीं।

**मुख्य कारण**: Claude Desktop background में नया Claude Code संस्करण डाउनलोड कर रहा हो सकता है। डाउनलोड पूरा होने से पहले Code mode पुराने installed Claude Code संस्करण पर fallback कर सकता है। वह पुराना संस्करण Code mode में third-party Gateway उपयोग के साथ संगत न हो, इसलिए process तुरंत exit होता है।

**इसे कैसे ठीक करें**:

<Steps>
  <Step title="नया Claude Code संस्करण डाउनलोड होने की प्रतीक्षा करें">
    Claude Desktop को कुछ समय खुला रखें ताकि background Claude Code update पूरा हो सके।
  </Step>

  <Step title="Claude Desktop पूरी तरह बंद करें">
    ऐप को पूरी तरह बंद करने के लिए **Cmd+Q** उपयोग करें। केवल window बंद न करें।
  </Step>

  <Step title="फिर खोलें और नया Code session शुरू करें">
    Claude Desktop फिर खोलें, Code mode में जाएं और नया session शुरू करें।
  </Step>
</Steps>

<Note>
  log में Claude Desktop पुराना Claude Code संस्करण, जैसे `2.1.111`, fallback के रूप में दिखाए और नया संस्करण, जैसे `2.1.119`, अभी तैयार न हो, तो नया संस्करण डाउनलोड होने की प्रतीक्षा करके ऐप रीस्टार्ट करें।
</Note>

| लक्षण | सामान्य मुख्य कारण | समाधान |
|---------|-------------------|-----|
| Cowork | Gateway auth scheme | जाँचें कि API Key पूरी कॉपी हुई है और समाप्त नहीं हुई है। इस Gateway में `x-api-key` चुनें, सहेजें और Claude Desktop फिर से शुरू करें। |
