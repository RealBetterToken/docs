## Task type के आधार पर चुनें

| Task type | प्राथमिकता |
| --- | --- |
| जटिल coding, architecture, लंबे task | Reasoning quality, context window, tool-call stability |
| रोज़मर्रा के सवाल और हल्का generation | Speed और cost |
| Batch translation, classification, summary | Unit price, throughput, stability |
| Code review और technical documentation | Code understanding, long context, stable output |
| Exploratory task | Mid-cost मॉडल से शुरू करें, critical चरण में मजबूत मॉडल चुनें |

हर task को default रूप से सबसे महंगे मॉडल पर न भेजें। कई batch task को deep reasoning या अधिक creativity की जरूरत नहीं होती। उनके लिए तेज और कम लागत वाला मॉडल बेहतर हो सकता है।

## अनुशंसित वर्कफ़्लो

1. पुष्टि करें कि टूल OpenAI-compatible या Anthropic-compatible API में से किसका समर्थन करता है।
2. <a href={"{{model-plaza-url}}"}>मॉडल प्लाज़ा</a> से मौजूदा Model ID कॉपी करें।
3. छोटे task से quality, speed और cost टेस्ट करें।
4. लंबे समय तक मॉडल उपयोग करने से पहले Dashboard में usage देखें।
5. केवल एक मॉडल सेट करने के बजाय जटिल task के लिए मजबूत backup मॉडल रखें।

## सामान्य गलतियां

- केवल display name देखना और Model ID की पुष्टि न करना
- यह मानना कि नया मॉडल हर task के लिए हमेशा बेहतर है
- Context length, speed और cost को अनदेखा करके केवल output quality की तुलना करना
- छोटे test के बिना production traffic को नए मॉडल पर भेजना
