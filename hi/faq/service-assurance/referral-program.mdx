## संक्षिप्त उत्तर

referral program वास्तविक invitations को reward करता है। दोस्त को invite करने और उसके पहला top-up पूरा करने पर, आपको उस first top-up amount के **10%** के बराबर referral reward मिलता है।

reward in-product reward balance के रूप में जारी होता है और future API request costs के भुगतान के लिए automatically उपयोग होता है। suspicious referrals का manual review होता है। review approve होने के बाद rewards जारी होते हैं।

## referral program की शर्तें

| शर्त | विवरण |
| --- | --- |
| 1 | दोस्त को invite करें। उसके first top-up के बाद आपको उस first top-up amount के **10%** के बराबर referral reward मिलता है। |
| 2 | reward balance request costs के भुगतान के लिए automatically उपयोग होता है। |
| 3 | suspicious referrals का manual review होता है। review approve होने के बाद rewards जारी होते हैं। |

## referral program कैसे उपयोग करें

1. console में sign in करें।
2. account या referral rewards area से अपना referral link copy करें।
3. referral link अपने दोस्त को भेजें।
4. आपका दोस्त link से register होकर first top-up पूरा करता है।
5. system आपके reward को दोस्त के first top-up amount के **10%** के रूप में calculate करता है।
6. reward जारी होने के बाद यह आपकी future request costs के लिए automatically उपयोग होता है।

दोस्त आपके link से register न करे तो referral relationship automatically नहीं बन सकता। केवल screenshot के बजाय पूरा referral link साझा करें।

## reward balance कैसे उपयोग होता है

reward balance cash withdrawal channel नहीं है। यह model request costs के भुगतान के लिए in-product balance है।

API requests भेजने पर system account rules के अनुसार balance और reward balance लागू करता है। प्रत्येक request के लिए reward balance चुनने की आवश्यकता नहीं है।

## manual review किससे trigger हो सकती है

abuse रोकने के लिए ये cases manual review trigger कर सकते हैं:

- समान device या network से कई mutual invitations
- abnormal top-up behavior या suspected non-real users
- fake accounts, bulk accounts या automated registration
- self-referrals
- payment, account या request behavior के बीच abnormal links

review approve होने पर reward सामान्य रूप से जारी होता है। referral suspicious माना जाए तो reward delay, cancel या freeze हो सकता है।

## FAQ

### referral reward rate क्या है?

referral reward आपके दोस्त के first top-up amount का **10%** है।

### दोस्त के top-up के बाद reward तुरंत आता है?

normal referrals system rules के अनुसार जारी होते हैं। risk control या abnormal links detect होने पर reward manual review में जाता है और approval के बाद जारी होता है।

### क्या reward balance withdraw कर सकता हूं?

नहीं। reward balance request costs के भुगतान के लिए उपयोग होता है।

### क्या reward balance manually लागू करना होगा?

नहीं। reward balance request costs के लिए automatically उपयोग होता है।

## BetterToken के बारे में

BetterToken का referral program वास्तविक user invitations के लिए है। referral rewards API request costs को cover करने में मदद करते हैं और teammates, friends या developer communities के साथ साझा करने के लिए उपयुक्त हैं।
