यह पेज केवल BetterToken **Claude provider** के लिए सीधा Claude Desktop setup बताता है। BetterToken API Key, `{{anthropic-base-url}}` और `x-api-key` भरें, फिर Claude Desktop रीस्टार्ट करें।

## मुख्य सेटिंग्स

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| मॉडल | Claude provider मॉडल |

## आवश्यक शर्तें

- <a href={"{{register-url}}"}>BetterToken API Key बनाएं और कॉपी करें</a>
- पुष्टि करें कि API Key Claude provider मॉडल उपयोग कर सकती है

## इंस्टॉल करें

[Claude Desktop website](https://claude.ai/download) से नवीनतम संस्करण इंस्टॉल या अपडेट करें, फिर Claude Desktop शुरू करें।

## मैन्युअल सेटअप

<Steps>
  <Step title="developer mode चालू करें">
    Claude Desktop में macOS menu bar से **Help** → **Troubleshooting** → **Enable Developer Mode** चुनें।

    <Frame>

      />
    </Frame>

    confirmation window में **Enable** क्लिक करें, फिर Claude Desktop रीस्टार्ट करें।

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
        alt="Claude Desktop में developer mode की पुष्टि करें।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="third-party inference settings खोलें">
    रीस्टार्ट के बाद macOS menu bar से **Developer** → **Configure Third-Party Inference...** चुनें।

    <Frame>
      <img
        src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
        alt="Developer मेनू से Configure Third-Party Inference चुनें।"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="BetterToken API settings भरें">
    **Gateway** चुनें, फिर भरें:

    | फ़ील्ड | मान |
    | --- | --- |
    | **Gateway base URL** | `{{anthropic-base-url}}` |
    | **Gateway API key** | आपकी BetterToken API Key |
    | **Gateway auth scheme** | `x-api-key` |

    auth scheme चुनने के बाद Claude Desktop उपलब्ध Claude मॉडल लेता है। **Apply locally** क्लिक करें।

    <Frame>

    </Frame>
  </Step>

</Steps>

## कनेक्शन सत्यापित करें

**Save & Restart** क्लिक करें। **Continue with Gateway** चुनें, फिर छोटा संदेश भेजें। नीचे-बाएं कोने में **Gateway** दिखे और संदेश सामान्य उत्तर दे तो setup सक्रिय है।

## मॉडल बदलें

मॉडल selector खोलें और Gateway द्वारा लौटाया दूसरा Claude मॉडल चुनें। मॉडल न मिले तो **Configure Third-Party Inference...** फिर खोलें, **Apply locally** क्लिक करें और Claude Desktop रीस्टार्ट करें।

## सामान्य त्रुटियां

| समस्या | समाधान |
| --- | --- |
| Gateway कनेक्ट नहीं होता | **Gateway base URL** के लिए ठीक `{{anthropic-base-url}}` उपयोग करें। `/v1` न जोड़ें। |
| अनुरोध `401` लौटाता है | BetterToken API Key फिर कॉपी करें और पुष्टि करें कि auth scheme `x-api-key` है। |
| कोई Claude मॉडल नहीं दिखता | पुष्टि करें कि API Key Claude provider मॉडल उपयोग कर सकती है, फिर settings window दोबारा खोलें। |
| configuration लागू नहीं होता | Claude Desktop पूरी तरह बंद करें, फिर खोलें और **Continue with Gateway** चुनें। |

## उन्नत सेटअप

Claude Desktop में GPT, Kimi, GLM या अन्य non-Claude provider उपयोग करने के लिए [CC Switch का Claude Desktop टैब](/hi/ai-tools/cc-switch#claude-desktop) अपनाएं। CC Switch API Format, मॉडल mapping, proxy और restart flow संभालता है।
