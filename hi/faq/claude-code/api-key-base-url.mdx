## त्वरित उत्तर

Claude Code में third-party API सेट करते समय पहले पुष्टि करें कि Endpoint Anthropic-compatible है। इस दस्तावेज़ में Claude Code `{{anthropic-base-url}}` उपयोग करता है। `/v1` न जोड़ें।

सामान्य Claude API access, उपलब्ध models और शुरुआत के विकल्पों के लिए <a href="https://bettertoken.ai/ru/claude-api/">BetterToken Claude API page</a> देखें। यह FAQ केवल मौजूदा BetterToken API Key को Base URL और environment variables से Claude Code में सेट करने के बारे में है।

API Key Request को authenticate करता है। Base URL बताता है कि Claude Code मॉडल Request कहां भेजे। दोनों एक ही प्रदाता और protocol के होने चाहिए।

अपनी BetterToken API Key, Base URL `{{anthropic-base-url}}` और चुनी हुई Model ID से Claude Code कनेक्ट करें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सही Model ID कॉपी करें।

## यह सेटअप कब आवश्यक है?

- Claude Code में custom API gateway उपयोग करना हो
- API Key हो, लेकिन सही Base URL पता न हो
- Claude Code authentication या Endpoint त्रुटि दिखाए
- `{{anthropic-base-url}}` और `{{openai-base-url}}` में से चुनना हो


## मुख्य अवधारणाएं

| Field | अर्थ |
| --- | --- |
| API Key | मॉडल API Request का credential |
| Base URL | API address जहां Request भेजे जाते हैं |
| Anthropic-compatible API | Anthropic / Claude Request नियमों का पालन करने वाला Endpoint |
| OpenAI-compatible API | OpenAI-शैली नियमों वाला Endpoint, जो अक्सर Codex, Cursor और Cline में उपयोग होता है |
| Model ID | टूल द्वारा मांगा गया मॉडल नाम या mapping value |

## अनुशंसित सेटअप

अपनी BetterToken API Key, Base URL `{{anthropic-base-url}}` और चुनी हुई Model ID से Claude Code कनेक्ट करें।

<a href={"{{model-plaza-url}}"}>model plaza</a> से सही Model ID कॉपी करें।

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

`YOUR_MODEL_ID` को कॉपी की गई ID से बदलें। मुख्य मॉडल के लिए `ANTHROPIC_MODEL` और Haiku, Sonnet तथा Opus के लिए तीन `ANTHROPIC_DEFAULT_*_MODEL` वेरिएबल सेट करें। सभी भूमिकाओं के लिए एक मॉडल या अलग-अलग मॉडल चुन सकते हैं।

कॉन्फ़िगरेशन में Model ID बदलकर Claude Code को फिर से शुरू करें। सत्र के दौरान बदलने के लिए `/model YOUR_MODEL_ID` इस्तेमाल करें।

## सामान्य गलतियां

- Claude Code Base URL में `/v1` जोड़ना
- API Key बदलकर भी Request को default Endpoint पर भेजना

- Claude Code के Anthropic-compatible Field में OpenAI-compatible Endpoint डालना
- Shell profile के पुराने environment variable से नए Config को override करना

## BetterToken में उपयोग

BetterToken दो Endpoint प्रकार देता है: Claude Code के लिए Anthropic-compatible `{{anthropic-base-url}}` और Codex तथा बाहरी टूल के लिए OpenAI-compatible `{{openai-base-url}}`।

इससे एक Dashboard में API Key, बैलेंस और usage history प्रबंधित किए जा सकते हैं, लेकिन Claude Code की Anthropic-compatible Request format की जरूरत नहीं बदलती।
