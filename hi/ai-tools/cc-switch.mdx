CC Switch एक वैकल्पिक डेस्कटॉप ऐप है जो Claude Code, Claude Desktop, Codex CLI, OpenCode और OpenClaw की API Keys, endpoints और मॉडल सेटिंग प्रबंधित करता है।

## CC Switch इंस्टॉल करें

<Tabs>
  <Tab title="macOS">
    Homebrew सबसे आसान विकल्प है। आप [GitHub Releases](https://github.com/farion1231/cc-switch/releases) से नवीनतम `.dmg` या `.zip` भी डाउनलोड कर सकते हैं।

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    [GitHub Releases](https://github.com/farion1231/cc-switch/releases) से नवीनतम `CC-Switch-v{version}-Windows.msi` इंस्टॉलर या portable `.zip` build डाउनलोड करें।
  </Tab>
  <Tab title="Linux">
    [GitHub Releases](https://github.com/farion1231/cc-switch/releases) से नवीनतम `.deb`, `.rpm` या `.AppImage` build डाउनलोड करें।
  </Tab>
</Tabs>

## क्या तैयार रखें

- BetterToken API Key (<a href={"{{register-url}}"}>यहां रजिस्टर करें</a>)
- Claude Code Anthropic protocol का उपयोग करता है, इसलिए उसका `Base URL` `{{anthropic-base-url}}` है
- Codex, OpenCode और OpenClaw OpenAI-compatible protocol का उपयोग करते हैं, इसलिए उनका `Base URL` `{{openai-base-url}}` है
- Codex, OpenCode और OpenClaw के लिए कोई वर्तमान मॉडल ID तैयार रखें। इसे <a href={"{{model-plaza-url}}"}>BetterToken model plaza</a> से कॉपी करें, या CC Switch को `/v1/models` से लेने दें

<Info>
  पहली बार खुलने पर CC Switch आपके कंप्यूटर पर मिले मौजूदा config को अपने-आप आयात करता है। आप आधिकारिक provider को fallback के रूप में रखकर उसके साथ BetterToken जोड़ सकते हैं।
</Info>

<Note>
  BetterToken के दो access mode हैं: Anthropic और OpenAI-compatible। `{{anthropic-base-url}}` और `{{openai-base-url}}` को मिलाने से बचने के लिए, Claude Code और OpenAI-compatible टूल को एक सार्वभौमिक provider में मजबूर करने के बजाय हर ऐप के लिए अलग provider बनाएं।
</Note>

## BetterToken provider जोड़ें

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    CC Switch में **Claude Code** चुनें और **Add Provider** पर क्लिक करें।

    अपनी BetterToken API Key, Base URL `{{anthropic-base-url}}` और चुनी हुई Model ID से Claude Code कनेक्ट करें।

    - **Provider Name**: `BetterToken`
    - **API Key**: `YOUR_API_KEY`
    - **API Endpoint**: `{{anthropic-base-url}}`

    Anthropic Messages API फ़ॉर्मैट चुनें। **Model Mapping** में चुनी हुई Model IDs दर्ज करें और सहेजें।

    <a href={"{{model-plaza-url}}"}>model plaza</a> से सही Model ID कॉपी करें।

    सेटिंग सहेजें, BetterToken सक्रिय करें और क्लाइंट पूरी तरह फिर से शुरू करें।
  </Tab>

  <Tab title="Claude Desktop" id="claude-desktop">
    Claude Desktop केवल Claude मॉडल का समर्थन करता है। यह Claude Desktop क्लाइंट की सीमा है।

    [Claude Desktop गाइड](/hi/faq/claude-desktop-bettertoken-api) के अनुसार **Gateway**, Base URL `{{anthropic-base-url}}`, अपनी BetterToken API Key और **Gateway auth scheme** `x-api-key` सेट करें। **Apply locally** दबाएँ और Claude Desktop पूरी तरह फिर से शुरू करें।

## सहेजे गए बदलाव लागू करें

provider सहेजने और स्विच करने के बाद, सेटअप सत्यापित करने से पहले प्रभावित client या gateway रीस्टार्ट करें।

- Claude Code: मौजूदा Claude Code session को पूरी तरह बंद करके फिर शुरू करें।
- Claude Desktop: ऐप को पूरी तरह बंद करके फिर खोलें और पुष्टि करें कि नीचे-बाएं कोने में **Gateway** दिखता है।
- Codex: मौजूदा Codex process रीस्टार्ट करें या नया terminal session खोलें।
- OpenCode: मौजूदा OpenCode session बंद करके फिर शुरू करें।
- OpenClaw: `openclaw gateway restart` चलाएं, फिर Discord में `/new`, `/status` और `/model` उपयोग करें।

## CC Switch के खास उन्नत फ़ीचर

CC Switch third-party provider पर स्विच करने पर भी आधिकारिक Codex login सुरक्षित रख सकता है और आधिकारिक व third-party session को एक history में जोड़ सकता है। इन विकल्पों को चालू करने के बाद Codex रीस्टार्ट करें। [आधिकारिक Codex login और एकीकृत session history बनाए रखें](/hi/faq/codex/official-login-third-party-api) देखें।

## सामान्य समस्याएं

- `/v1` को Claude Code के `Base URL` में न जोड़ें

- Codex, OpenCode और OpenClaw को `{{openai-base-url}}` इस्तेमाल करना चाहिए
- Codex, OpenCode या OpenClaw मॉडल मांगे तो मॉडल ID उपयोग करें
- यदि **Fetch Models** विफल हो, तो API key और `Base URL` जांचें, फिर मॉडल ID मैन्युअल रूप से पेस्ट करें
- यदि स्विच करने के बाद बदलाव लागू न हो, तो CC Switch में BetterToken सक्रिय provider है इसकी पुष्टि करें और ऊपर बताए अनुसार प्रभावित client या gateway रीस्टार्ट करें
