### API Key और Base URL कॉन्फ़िगर करें

<Steps>
  <Step title="API Key environment variable सेट करें">
    <Tabs>
      <Tab title="macOS / Linux">
        इसे उसी terminal में चलाएं जो Continue CLI शुरू करेगा:

        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>

      <Tab title="Windows PowerShell">
        इसे उसी PowerShell window में चलाएं जो Continue CLI शुरू करेगा:

        ```powershell
        $env:BETTERTOKEN_API_KEY = "YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    `YOUR_API_KEY` को अपनी BetterToken API Key से बदलें। key को Git में commit न करें या साझा configuration फ़ाइल में न रखें।
  </Step>

  <Step title="config.yaml बनाएं">
    अपनी user directory में यह फ़ाइल बनाएं या संपादित करें:

    - macOS / Linux: `~/.continue/config.yaml`
    - Windows: `%USERPROFILE%\.continue\config.yaml`

    यह configuration जोड़ें:

    ```yaml
    name: BetterToken
    version: 0.0.1
    schema: v1

    models:
      - name: BetterToken GPT
        provider: openai
        model: YOUR_MODEL_ID
        apiBase: "{{openai-base-url}}"
        apiKey: ${{ secrets.BETTERTOKEN_API_KEY }}
        useResponsesApi: false
    ```

    `YOUR_MODEL_ID` केवल उदाहरण है। इसे model plaza की वर्तमान **किसी समर्थित provider की मॉडल ID** से बदलें।
  </Step>

  <Step title="Continue CLI शुरू करें">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        cn --config ~/.continue/config.yaml
        ```
      </Tab>

      <Tab title="Windows PowerShell">
        ```powershell
        cn --config "$env:USERPROFILE\.continue\config.yaml"
        ```
      </Tab>
    </Tabs>

    पहले अपनी project directory में जाएं, फिर command चलाएं। configuration लोड होने पर Continue CLI में सीधे कार्य लिखें।
  </Step>
</Steps>

### मॉडल बदलें

`model` को `config.yaml` में बदलने के बाद मौजूदा `cn` session बंद करें और फिर शुरू करें। Model ID कॉन्फ़िगर किए गए endpoint के साथ संगत होनी चाहिए।

किसी एक project के लिए अलग configuration इस्तेमाल करने के लिए इसे उसी project में सहेजें और उसका path स्पष्ट रूप से दें:

```bash
cn --config ./continue-bettertoken.yaml
```

## कनेक्शन सत्यापित करें

छोटा test prompt भेजें। यदि टूल बिना authentication या Model ID त्रुटि के उत्तर देता है, तो कनेक्शन काम कर रहा है। configuration बदलने के बाद टूल को पूरी तरह रीस्टार्ट करें।

## मॉडल बदलें

मॉडल selector खोलें या configuration में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर मौजूदा session रीस्टार्ट करें।

## सामान्य त्रुटियां

| लक्षण | क्या करें |
| --- | --- |
| `401`, `Unauthorized` या API Key त्रुटि | पुष्टि करें कि मौजूदा terminal में `BETTERTOKEN_API_KEY` सेट है और वह BetterToken API Key है। |
| `model not found` या मॉडल अनुपलब्ध | model plaza से वर्तमान **किसी समर्थित provider की मॉडल ID** कॉपी करें। Claude provider मॉडल का उपयोग न करें। |
| Continue अब भी पुराना configuration इस्तेमाल करता है | `cn --config` और स्पष्ट फ़ाइल path के साथ शुरू करें। जांचें कि फ़ाइल का नाम `config.yaml` है। |
| गलत request URL या `404` | पुष्टि करें कि `apiBase` `{{openai-base-url}}` है। `/chat/completions` या मॉडल नाम न जोड़ें। |
| API Key variable resolve नहीं हो रहा | उसी terminal में `BETTERTOKEN_API_KEY` सेट करें जो `cn` शुरू करता है, फिर इसे दोबारा चलाएं। |

### सेटअप FAQ

**Continue CLI को कौन-सा Base URL उपयोग करना चाहिए?**

`{{openai-base-url}}` उपयोग करें। यह BetterToken का OpenAI-compatible Base URL है।

**क्या मैं BetterToken API key उपयोग कर सकता हूं?**

हां। `provider: openai` के साथ `useResponsesApi: false` OpenAI-compatible Chat Completions का उपयोग करता है। API Key और Model ID दोनों BetterToken से प्राप्त करें।

**सहेजे गए configuration कैसे देखें या बदलें?**

स्थानीय configuration देखने और चुनने के लिए Continue CLI session में `/config` लिखें।
