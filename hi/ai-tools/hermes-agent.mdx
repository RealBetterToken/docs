Hermes Agent को BetterToken से कनेक्ट करने के लिए API key तैयार करें, नीचे दिया Base URL भरें और model plaza से वर्तमान Model ID चुनें।

## मुख्य सेटिंग्स

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

## आवश्यकताएं

- टूल का वर्तमान संस्करण इंस्टॉल है
- BetterToken API key: <a href={"{{register-url}}"}>रजिस्टर करें और प्राप्त करें</a>
- <a href={"{{model-plaza-url}}"}>model plaza</a> से Model ID

### अतिरिक्त आवश्यकताएं

- चुनी गई Model ID **supported provider** से है
- macOS, Linux, Windows 10/11 या WSL2
- tool use के लिए कम से कम 64K context window वाला model

## मैन्युअल सेटअप

interactive Hermes Agent मॉडल सेटअप को मुख्य तरीका मानें। Manual setup की जरूरत होने पर ही config files को सीधे edit करें।

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

### सेटअप

<Tabs>
  <Tab title="Interactive setup">
    <Steps>
      <Step title="मॉडल selector चलाएं">
        यदि Hermes chat खुली है, तो पहले session से बाहर निकलें। फिर चलाएं:

        ```bash
        hermes model
        ```
      </Step>

      <Step title="Custom endpoint चुनें">
        provider सूची से **Custom endpoint (self-hosted / VLLM / etc.)** चुनें।
      </Step>

      <Step title="BetterToken config भरें">
        भरें:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: आपकी BetterToken API Key
        - **Model**: <a href={"{{model-plaza-url}}"}>model plaza</a> से कॉपी की **किसी समर्थित provider की मॉडल ID**

        यदि Hermes API mode पूछे, तो **Chat Completions** चुनें। Agent tool use के लिए कम से कम 64K context वाला model चुनें।
      </Step>

      <Step title="Hermes Agent शुरू करें">
        ```bash
        hermes --tui
        ```

        Classic terminal interface के लिए `hermes` चलाएं।
      </Step>
    </Steps>
  </Tab>

  <Tab title="Config files">
    `~/.hermes/config.yaml` में custom provider जोड़ें:

    ```yaml
    model:
      default: YOUR_MODEL_ID
      provider: custom
      base_url: "{{openai-base-url}}"
    ```

    BetterToken API Key को `~/.hermes/.env` में अलग रखें:

    ```dotenv
    OPENAI_API_KEY=YOUR_API_KEY
    ```

    `YOUR_MODEL_ID` को <a href={"{{model-plaza-url}}"}>model plaza</a> की supported provider model ID से और `YOUR_API_KEY` को अपनी BetterToken API Key से बदलें। Native Windows पर ये files `%LOCALAPPDATA%\hermes\` में होती हैं।
  </Tab>
</Tabs>

### OpenClaw से माइग्रेट करें

यदि आप पहले से OpenClaw इस्तेमाल करते हैं, तो पहले जांचें कि वर्तमान Hermes Agent संस्करण migration command देता है या नहीं। बदलाव से पहले dry run चलाएं।

```bash
hermes claw migrate --dry-run
```

output की पुष्टि के बाद migration चलाएं:

```bash
hermes claw migrate
```

migration के बाद भी Hermes Agent **Base URL**, API Key और मॉडल ID जांचें। वे `{{openai-base-url}}`, आपकी BetterToken API Key और समर्थित provider मॉडल ID से मेल खाने चाहिए।

## कनेक्शन सत्यापित करें

Hermes Agent शुरू करें और यह छोटा test prompt भेजें: `Reply with HERMES_OK only. Do not use tools.` यदि response ठीक `HERMES_OK` है, तो connection काम कर रहा है।

## मॉडल बदलें

Session के बाहर `hermes model` चलाएं। Active chat में पहले से configured provider या model बदलने के लिए `/model` उपयोग करें। <a href={"{{model-plaza-url}}"}>model plaza</a> की exact Model ID चुनें।

## सामान्य त्रुटियां

| त्रुटि | क्या जांचें |
| --- | --- |
| `401` या `Unauthorized` | BetterToken API key जांचें और शुरुआत/अंत के space हटाएं। |
| `404` | Base URL जांचें और कोई विशिष्ट endpoint path न जोड़ें। |
| `model not found` | model plaza से वर्तमान Model ID कॉपी करें। |
| बदलाव लागू नहीं होते | configuration सहेजें और टूल पूरी तरह रीस्टार्ट करें। |


### समस्या निवारण

- यदि अनुरोध विफल हो या उत्तर न मिले, तो पुष्टि करें कि **Base URL** ठीक `{{openai-base-url}}` है। इस फ़ील्ड में `/chat/completions` न जोड़ें।
- यदि Hermes बताए कि मॉडल मौजूद नहीं है, तो पुष्टि करें कि **Model** <a href={"{{model-plaza-url}}"}>model plaza</a> से समर्थित provider की मॉडल ID है।
- authentication विफल होने पर कॉपी किए गए space जांचें और पुष्टि करें कि चुनी Model ID **supported provider** से है।
- बदलाव के बाद Hermes अब भी पुराना मॉडल उपयोग करे तो मौजूदा Hermes Agent session बंद करके `hermes` फिर चलाएं।
- BetterToken को सामान्यतः अतिरिक्त `User-Agent` या custom header की जरूरत नहीं होती। header केवल तब जोड़ें जब आपका custom gateway, tenant routing, observability या caching layer स्पष्ट रूप से मांगे।

<Note>
  असली API Key को repository में commit न करें। टीम के साझा सेटअप के लिए environment variable या local config उपयोग करें।
</Note>
