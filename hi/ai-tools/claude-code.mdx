Claude मॉडल terminal variable या settings file से सीधे कनेक्ट होते हैं। Kimi और GLM समान Base URL के साथ स्पष्ट मॉडल mapping उपयोग करते हैं। शुरुआत के लिए [Claude Code custom API endpoint, API Key और Base URL guide](/hi/faq/claude-code/api-key-base-url) देखें। GPT के लिए [उन्नत सेटअप](#advanced-setup) आवश्यक है।

## मुख्य सेटिंग

| Field | मान |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | Claude Code द्वारा प्रबंधित |

## आवश्यकताएं

- नवीनतम [Claude Code](https://docs.anthropic.com/en/docs/claude-code) इंस्टॉल करें
- Node.js इंस्टॉल करें
- <a href={"{{register-url}}"}>BetterToken API Key बनाकर कॉपी करें</a>

## इंस्टॉल करें

```bash
npm install -g @anthropic-ai/claude-code
```

## Command-line सेटअप

BetterToken automatic setup script Claude Code प्रदाता configuration लिखता है। इसके लिए Node.js आवश्यक है। API Key argument में न देने पर script उसे दर्ज करने को कहता है।

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

पूरा होने पर `~/.claude/settings.json` देखें। Windows पर `%USERPROFILE%\.claude\settings.json` देखें। फिर Claude Code को पूरी तरह restart करें। हर Field स्वयं नियंत्रित करने के लिए नीचे मैन्युअल सेटअप उपयोग करें।

## मैन्युअल सेटअप

### Claude प्रदाता सेट करें

Claude Code CLI ये file पढ़ता है:

| System | File |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

यह जोड़ें:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000"
  }
}
```

Claude प्रदाता को केवल ये चार variable चाहिए। `ANTHROPIC_MODEL` या `ANTHROPIC_DEFAULT_*_MODEL` न जोड़ें।

### Kimi या GLM प्रदाता सेट करें

Kimi और GLM को उसी `settings.json` में मॉडल mapping चाहिए। हर `YOUR_MODEL_ID` को Setup dialog या मॉडल प्लाज़ा के Model ID से बदलें:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

तीनों mapping में एक Model ID या समान प्रदाता के अलग मॉडल उपयोग किए जा सकते हैं। यहां GPT Model ID न डालें; पेज के अंत में उन्नत सेटअप उपयोग करें।

### Claude Code VS Code extension सेट करें

Extension VS Code `settings.json` उपयोग करता है। अलग `claudeCode.environmentVariables` configuration जोड़ें:

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    }
  ]
}
```

**Developer: Reload Window** चलाएं या VS Code को पूरी तरह restart करें।

## कनेक्शन सत्यापित करें

Project में Claude Code शुरू करें:

```bash
claude
```

छोटा message भेजें। `401`, connection या मॉडल त्रुटि के बिना सामान्य Response सेटअप की पुष्टि करता है। File बदलने के बाद Claude Code को पूरी तरह restart करें।

## मॉडल बदलें

- Claude प्रदाता: Claude Code को मॉडल चयन प्रबंधित करने दें। `ANTHROPIC_MODEL` या `ANTHROPIC_DEFAULT_*_MODEL` न जोड़ें।
- Kimi या GLM प्रदाता: `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` और `ANTHROPIC_DEFAULT_OPUS_MODEL` बदलें, फिर Claude Code को पूरी तरह restart करें।
- GPT प्रदाता: मॉडल बदलने के लिए नीचे [उन्नत सेटअप](#advanced-setup) का पालन करें।

## सामान्य त्रुटियां

| त्रुटि | समाधान |
| --- | --- |
| `401` या authentication विफल | `ANTHROPIC_AUTH_TOKEN` जांचें और API Key के आसपास के space हटाएं। |
| `ConnectionRefused` | ठीक `{{anthropic-base-url}}` उपयोग करें; `/v1` न जोड़ें। |
| मॉडल नहीं मिला | Claude के लिए मॉडल manually सेट न करें। Kimi या GLM में जांचें कि तीनों `ANTHROPIC_DEFAULT_*_MODEL` मान मौजूदा Model ID उपयोग करते हैं। |
| Configuration लागू नहीं | File path जांचें, टकराने वाले environment variable हटाएं और Claude Code को पूरी तरह restart करें। |

### समर्थित provider

| Provider | स्थिति |
| --- | --- |
| Claude | कमांड लाइन + मैन्युअल सेटअप |
| GPT | उन्नत सेटअप |

<Note>ये स्थितियां केवल इस पेज पर बताए गए BetterToken सेटअप पर लागू होती हैं।</Note>

<Accordion title="सेटअप के तरीकों का अर्थ">
  - **उन्नत सेटअप**: CC Switch इंस्टॉल करें और local proxy, protocol conversion या model mapping का उपयोग करें।
  - **मैन्युअल सेटअप**: API Key, Base URL और Model दर्ज करें।
  - **कमांड लाइन + मैन्युअल सेटअप**: तैयार कमांड का उपयोग करें या पूरे मैन्युअल चरणों का पालन करें।
</Accordion>
