OpenCode `@ai-sdk/openai-compatible` से BetterToken को कनेक्ट करता है। OpenCode प्रदाता का नाम **BetterToken** या **OpenAI Compatible** रखें। GPT, Kimi और GLM BetterToken के भीतर मॉडल प्रदाता हैं, OpenCode प्रदाता के नाम नहीं। सामान्य API Key, Base URL या `opencode.json` सेटअप के लिए इसी पेज का उपयोग करें। किसी खास मॉडल को चुनने और जांचने के लिए [GLM guide](/hi/faq/opencode/glm-api) या [Kimi K3 guide](/hi/faq/opencode/kimi-k3-api) देखें।

## Command-line सेटअप

BetterToken automatic setup script OpenCode में BetterToken प्रदाता बनाता या अपडेट करता है। इसके लिए Node.js आवश्यक है। API Key या Model ID argument में न देने पर script उन्हें दर्ज करने को कहता है।

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-opencode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-opencode-provider-ps1-url}}" -OutFile "$env:TEMP\install-opencode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-opencode-provider.ps1"
    ```
  </Tab>
</Tabs>

Script पूरा होने के बाद `bettertoken/YOUR_MODEL_ID` चुनें। OpenCode पहले से चल रहा हो तो test से पहले restart करें।

## मैन्युअल सेटअप

### विकल्प 1: /connect से credential save करें

OpenCode शुरू करके चलाएं:

```text
/connect
```

**Other** चुनें, प्रदाता ID के रूप में `bettertoken` दर्ज करें, फिर `YOUR_API_KEY` दर्ज करें। OpenCode credential को local रूप से स्टोर करता है।

### विकल्प 2: JSON सेट करें

Global file `~/.config/opencode/opencode.json` है। Project अपने root में `opencode.json` उपयोग कर सकता है।

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "{{openai-base-url}}"
      },
      "models": {
        "YOUR_MODEL_ID": {
          "name": "YOUR_MODEL_ID"
        }
      }
    }
  }
}
```

`/connect` उपयोग न करें तो `"apiKey": "YOUR_API_KEY"` को `options` के अंतर्गत जोड़ें। वास्तविक Key वाली configuration कभी commit न करें।

## कनेक्शन सत्यापित करें

Project में `opencode` चलाएं, `bettertoken/YOUR_MODEL_ID` चुनें और छोटा message भेजें। सामान्य Response सेटअप की पुष्टि करता है। JSON बदलने के बाद OpenCode restart करें।

## मॉडल बदलें

नया `YOUR_MODEL_ID` को `provider.bettertoken.models` के अंतर्गत जोड़ें, top-level `model` अपडेट करें, save करके restart करें।

## सामान्य त्रुटियां

| त्रुटि | समाधान |
| --- | --- |
| `401` | `/connect` फिर चलाएं या `apiKey` जांचें। |
| `404` | केवल `{{openai-base-url}}` को `baseURL` के रूप में उपयोग करें; `/chat/completions` न जोड़ें। |
| मॉडल नहीं मिला | Top-level `model` को `models` के अंतर्गत ID से exactly मिलाएं। |
| Configuration लागू नहीं | जांचें कि project `opencode.json` global file को override तो नहीं करता, फिर OpenCode restart करें। |
