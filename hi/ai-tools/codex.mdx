Codex CLI और Codex App, OpenAI Responses से BetterToken को कनेक्ट करते हैं। Automatic setup Codex API Key login उपयोग करता है। Manual setup credential को `BETTERTOKEN_API_KEY` में रखता है।

## मुख्य सेटिंग

| Field | मान |
| --- | --- |
| API Key | Automatic: Codex API Key login; manual: `BETTERTOKEN_API_KEY` |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## आवश्यकताएं

- Node.js इंस्टॉल करें
- <a href={"{{register-url}}"}>BetterToken API Key बनाएं</a>
- <a href={"{{model-plaza-url}}"}>मॉडल प्लाज़ा</a> या Key **Setup** dialog से Model ID कॉपी करें

## इंस्टॉल करें

```bash
npm install -g @openai/codex
```

## Command-line सेटअप

BetterToken automatic setup script Codex प्रदाता configuration लिखता है और BetterToken API Key को `~/.codex/auth.json` में save करता है। यह `requires_openai_auth = true` सेट करता है, जिससे Codex API Key login उपयोग करता है। इसके लिए Node.js आवश्यक है। API Key या Model ID argument में न देने पर script उन्हें दर्ज करने को कहता है।

<Warning>
  Automatic setup Codex को official ChatGPT login से API Key login पर switch करता है। Official login बनाए रखने के लिए script को छोड़ें और नीचे manual प्रदाता setup उपयोग करें।
</Warning>

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-codex-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-codex-provider-ps1-url}}" -OutFile "$env:TEMP\install-codex-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-codex-provider.ps1"
    ```
  </Tab>
</Tabs>

पूरा होने पर `~/.codex/config.toml` खोलें। Windows पर `%USERPROFILE%\.codex\config.toml` खोलें। पुष्टि करें कि `model`, `review_model`, BetterToken प्रदाता और `requires_openai_auth = true` सही लिखे गए हैं। फिर **कनेक्शन सत्यापित करें** में दिए restart steps पूरे करें।

## मैन्युअल सेटअप

GPT, Kimi और GLM समान `config.toml` structure उपयोग करते हैं। केवल `YOUR_MODEL_ID` को चुने गए प्रदाता के मौजूदा Model ID से बदलें। One-click command-line सेटअप अभी केवल GPT के लिए उपलब्ध है।

### API Key सेट करें

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```

    इसे स्थायी रखने के लिए यह line `~/.zshrc` या `~/.bashrc` में जोड़ें।
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    [Environment]::SetEnvironmentVariable("BETTERTOKEN_API_KEY", "YOUR_API_KEY", "User")
    $env:BETTERTOKEN_API_KEY = "YOUR_API_KEY"
    ```

    पहला command future processes के लिए variable को स्थायी बनाता है। दूसरा Codex CLI शुरू करने से पहले current PowerShell session में variable उपलब्ध कराता है।
  </Tab>
  <Tab title="Codex App">
    ```dotenv
    BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```

    यह line `~/.codex/.env` में save करें। Windows पर `%USERPROFILE%\.codex\.env` उपयोग करें। Custom `CODEX_HOME` उपयोग करने पर `.env` को उसी directory में save करें। File बदलने के बाद Codex App को पूरी तरह बंद करके दोबारा खोलें।
  </Tab>
</Tabs>

<Warning>
  इस manual method में BetterToken API Key को `~/.codex/auth.json` में न डालें। उस file में official login बनाए रखें और custom प्रदाता को `env_key` से `BETTERTOKEN_API_KEY` पढ़ने दें। ऊपर दिया automatic method अलग API Key login mode है।
</Warning>

### config.toml सेट करें

`~/.codex/config.toml` संपादित करें:

```toml
model_provider = "custom"
model = "YOUR_MODEL_ID"
review_model = "YOUR_MODEL_ID"
model_reasoning_effort = "high"

[model_providers.custom]
name = "BetterToken"
base_url = "{{openai-base-url}}"
env_key = "BETTERTOKEN_API_KEY"
wire_api = "responses"
requires_openai_auth = false
request_max_retries = 4
stream_max_retries = 8
stream_idle_timeout_ms = 300000
supports_websockets = false
```

`model_provider = "custom"` का `[model_providers.custom]` table से मेल खाना आवश्यक है। दोनों `YOUR_MODEL_ID` मान मौजूदा पूरे Model ID से बदलें।

## मॉडल बदलें

`model` बदलें और जरूरत हो तो `review_model` भी बदलें। File save करें, मौजूदा Codex process रोकें और दोबारा शुरू करें। Setup dialog या मॉडल प्लाज़ा का Model ID उपयोग करें।

## सामान्य त्रुटियां

| त्रुटि | समाधान |
| --- | --- |
| `401` या OpenAI sign-in prompt | Automatic: पुष्टि करें कि script पूरा हुआ और `requires_openai_auth = true` सेट है। Manual: `BETTERTOKEN_API_KEY`, `env_key` और `requires_openai_auth = false` जांचें। |
| प्रदाता नहीं मिला | `model_provider = "custom"` को `[model_providers.custom]` से मिलाएं। |
| API mode त्रुटि | `wire_api = "responses"` बनाए रखें; Chat Completions पर न बदलें। |
| मॉडल नहीं मिला | `YOUR_MODEL_ID` को Setup या मॉडल प्लाज़ा के मौजूदा पूरे ID से बदलें। |
| Configuration लागू नहीं | CLI के लिए नया terminal खोलें। Codex App को पूरी तरह बंद करके दोबारा खोलें और नया task बनाएं। Manual mode में यह भी जांचें कि active process `BETTERTOKEN_API_KEY` पढ़ सकता है। |
