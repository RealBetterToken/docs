Kilo Code को BetterToken से कनेक्ट करने के लिए API key तैयार करें, नीचे दिया Base URL भरें और model plaza से वर्तमान Model ID चुनें।

## मुख्य सेटिंग्स

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

## आवश्यकताएं

- टूल का वर्तमान संस्करण इंस्टॉल है
- BetterToken API key: <a href={"{{register-url}}"}>रजिस्टर करें और प्राप्त करें</a>
- <a href={"{{model-plaza-url}}"}>model plaza</a> से Model ID

### अतिरिक्त आवश्यकताएं

- VS Code इंस्टॉल है

## इंस्टॉल करें

Kilo Code इंस्टॉल या खोलें, फिर नीचे का मैन्युअल सेटअप जारी रखें।

## मैन्युअल सेटअप

यह सेटअप Kilo Code settings UI में पूरा करें। configuration फ़ाइल संपादित करने की जरूरत नहीं है।

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

### सेटअप

<Steps>
  <Step title="टकराव वाले environment variable हटाएं">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Kilo Code settings खोलें">
    Kilo Code settings UI खोलें।
  </Step>

  <Step title="API provider कॉन्फ़िगर करें">
    भरें:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → आपकी BetterToken API Key
    - **Model** → <a href={"{{model-plaza-url}}"}>model plaza</a> से कॉपी की **किसी समर्थित provider की मॉडल ID**
  </Step>

  <Step title="अतिरिक्त header केवल तभी कॉन्फ़िगर करें जब आधिकारिक दस्तावेज स्पष्ट रूप से कहें">
    उपलब्ध आधिकारिक Kilo Code सामग्री में OpenAI-compatible provider के लिए वैकल्पिक custom header का उल्लेख है, लेकिन वह `User-Agent` को BetterToken सेटअप का अनिवार्य चरण नहीं मानती।

    custom gateway, tenant routing, observability या caching layer भी इस्तेमाल कर रहे हों तो header केवल उस upstream सेवा के आधिकारिक दस्तावेज के अनुसार जोड़ें।
  </Step>

  <Step title="Kilo Code रीस्टार्ट करें">
    config बदलने के बाद VS Code रीस्टार्ट करें या Kilo Code extension reload करें ताकि नई सेटिंग लागू हो।
  </Step>
</Steps>

<Note>
  अतिरिक्त header चाहिए हों तो `User-Agent` को BetterToken के लिए अनिवार्य मानने के बजाय वर्तमान Kilo Code दस्तावेज या upstream gateway आवश्यकता का पालन करें।
</Note>

## कनेक्शन सत्यापित करें

छोटा test prompt भेजें। यदि टूल बिना authentication या Model ID त्रुटि के उत्तर देता है, तो कनेक्शन काम कर रहा है। configuration बदलने के बाद टूल को पूरी तरह रीस्टार्ट करें।

## मॉडल बदलें

मॉडल selector खोलें या configuration में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर मौजूदा session रीस्टार्ट करें।

## सामान्य त्रुटियां

| त्रुटि | क्या जांचें |
| --- | --- |
| `401` या `Unauthorized` | BetterToken API key जांचें और शुरुआत/अंत के space हटाएं। |
| `404` | Base URL जांचें और कोई विशिष्ट endpoint path न जोड़ें। |
| `model not found` | model plaza से वर्तमान Model ID कॉपी करें। |
| बदलाव लागू नहीं होते | configuration सहेजें और टूल पूरी तरह रीस्टार्ट करें। |
