## इंस्टॉल करें

### Aider इंस्टॉल करें

टर्मिनल में ये कमांड चलाएं:

```bash
python -m pip install aider-install
aider-install
```

इंस्टॉलेशन के बाद पुष्टि करें कि Aider उपलब्ध है:

```bash
aider --help
```

## मैन्युअल सेटअप

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | <a href={"{{model-plaza-url}}"}>model plaza</a> से एक वर्तमान Model ID |

### वर्तमान टर्मिनल के लिए BetterToken कॉन्फ़िगर करें

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"

    cd /path/to/your/project
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell
    setx OPENAI_API_BASE "{{openai-base-url}}"
    setx OPENAI_API_KEY "YOUR_API_KEY"
    ```

    `setx` के बाद PowerShell बंद करके फिर खोलें। फिर अपनी प्रोजेक्ट डायरेक्टरी में जाएं और चलाएं:

    ```powershell
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>
</Tabs>

`YOUR_API_KEY` को अपने BetterToken API Key से बदलें। `YOUR_MODEL_ID` केवल उदाहरण है। इसे model plaza से वर्तमान **समर्थित provider की model ID** से बदलें और `openai/` उपसर्ग रखें।

### .env से कॉन्फ़िगरेशन सहेजें

हर बार टर्मिनल खोलने पर वेरिएबल सेट करने से बचने के लिए, प्रोजेक्ट के Git root में `.env` फ़ाइल बनाएं:

```dotenv
OPENAI_API_BASE={{openai-base-url}}
OPENAI_API_KEY=YOUR_API_KEY
AIDER_MODEL=openai/YOUR_MODEL_ID
```

API Key कमिट होने से रोकने के लिए `.env` को `.gitignore` में जोड़ें। फिर प्रोजेक्ट डायरेक्टरी में जाकर चलाएं:

```bash
aider
```

किसी प्रोजेक्ट के लिए अन्य फ़ाइल उपयोग करने हेतु उसे स्पष्ट रूप से निर्दिष्ट करें:

```bash
aider --env-file ./aider-bettertoken.env
```

### वैकल्पिक: .aider.conf.yml उपयोग करें

केवल गैर-संवेदनशील सेटिंग्स सहेजने के लिए, होम या प्रोजेक्ट डायरेक्टरी में `.aider.conf.yml` बनाएं:

```yaml
model: openai/YOUR_MODEL_ID
openai-api-base: "{{openai-base-url}}"
```

API Key को साझा YAML फ़ाइल के बजाय `OPENAI_API_KEY` environment variable में रखें।

### Model ID बदलें

लॉन्च कमांड में मॉडल को वर्तमान **समर्थित provider की model ID** से बदलें:

```bash
aider --model openai/YOUR_MODEL_ID
```

`openai/` उपसर्ग न हटाएं। Model ID कॉन्फ़िगर किए गए endpoint के अनुकूल होनी चाहिए।

## कनेक्शन सत्यापित करें

एक छोटा टेस्ट prompt भेजें। यदि टूल authentication या Model ID त्रुटि के बिना उत्तर देता है, तो कनेक्शन काम कर रहा है। कॉन्फ़िगरेशन बदलने के बाद टूल को पूरी तरह पुनः आरंभ करें।

## मॉडल बदलें

मॉडल चयनकर्ता खोलें या कॉन्फ़िगरेशन में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर वर्तमान सत्र पुनः आरंभ करें।

## सामान्य त्रुटियां

| समस्या | क्या करें |
| --- | --- |
| `401`, `Unauthorized` या `Invalid API key` | `OPENAI_API_KEY` जांचें, पुष्टि करें कि यह BetterToken API Key है और अतिरिक्त स्पेस हटाएं। |
| `model not found` या मॉडल उपलब्ध नहीं | model plaza से वर्तमान **समर्थित provider की model ID** कॉपी करें और उसे Aider को `openai/model-id` के रूप में दें। |
| गलत request URL या `404` | पुष्टि करें कि `OPENAI_API_BASE` `{{openai-base-url}}` है। `/chat/completions` न जोड़ें। |
| Windows नए वेरिएबल नहीं पढ़ता | `setx` केवल नए खुले टर्मिनलों पर लागू होता है। वर्तमान PowerShell विंडो बंद करें और नई खोलें। |
| Aider अज्ञात मॉडल बताता है | पहले model ID और API provider जांचें। Aider नए मॉडल के लिए चेतावनी दे सकता है, लेकिन model plaza से वर्तमान ID ही उपयोग करें। |

### सेटअप FAQ

**Aider को कौन सा Base URL उपयोग करना चाहिए?**

`{{openai-base-url}}` उपयोग करें। यह BetterToken का OpenAI-compatible Base URL है।

**मॉडल नाम में `openai/` उपसर्ग क्यों चाहिए?**

Aider OpenAI-compatible मॉडल पहचानने के लिए इस उपसर्ग का उपयोग करता है। इसे छोड़ने से Aider गलत provider चुन सकता है।

**क्या मैं API Key को `.aider.conf.yml` में रख सकता हूं?**

हम इसकी अनुशंसा नहीं करते। प्रोजेक्ट फ़ाइलों में API Key उजागर होने का जोखिम घटाने के लिए environment variables या Git द्वारा अनदेखी की गई `.env` फ़ाइल उपयोग करें।
