MonkeyCode एक AI tool है जिसमें आप उसके interface से custom provider के जरिए model जोड़ सकते हैं। यह guide **AI Model** section में BetterToken setup बताती है; यह MonkeyCode के official API की documentation नहीं है। BetterToken API Key, `{{openai-base-url}}` और exact Model ID भरें, binding save करें और नया chat शुरू करें। यदि समस्या Kodacode / Koda में है, तो [Kodacode setup और 429 error guide](/hi/ai-tools/kodacode) देखें। Official product information और registration [MonkeyCode website](https://monkeycode.ai) पर उपलब्ध हैं।

## मुख्य सेटिंग्स

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

## आवश्यकताएं

- टूल का वर्तमान संस्करण इंस्टॉल है
- BetterToken API key: <a href={"{{register-url}}"}>रजिस्टर करें और प्राप्त करें</a>
- <a href={"{{model-plaza-url}}"}>model plaza</a> से Model ID

### अतिरिक्त आवश्यकताएं

- MonkeyCode account ([MonkeyCode में sign up करें](https://monkeycode.ai))

## इंस्टॉल करें

MonkeyCode इंस्टॉल या खोलें, फिर नीचे का मैन्युअल सेटअप जारी रखें।

## मैन्युअल सेटअप

यह सेटअप MonkeyCode settings UI में पूरा करें। configuration फ़ाइल संपादित करने की जरूरत नहीं है।

| फ़ील्ड | मान |
| --- | --- |
| API Key | BetterToken API key |
| Base URL | `{{openai-base-url}}` |
| मॉडल | <a href={"{{model-plaza-url}}"}>model plaza</a> से वर्तमान Model ID |

### सेटअप

<Steps>
  <Step title="MonkeyCode में लॉग इन करें">
    [MonkeyCode](https://monkeycode.ai) पर जाएं और लॉग इन करें।
  </Step>

  <Step title="system settings खोलें">
    task page पर जाएं, फिर नीचे-दाएं कोने में **Settings** क्लिक करें।
  </Step>

  <Step title="AI मॉडल bind करें">
    **AI Model** section में **Bind** क्लिक करें।
  </Step>

  <Step title="BetterToken config भरें">

    | फ़ील्ड | मान |
    |-------|-------|
    | Model API URL | `{{openai-base-url}}` |
    | API Key | आपकी BetterToken API Key |
    | API format | `OpenAI` या `OpenAI Compatible` (वर्तमान UI label का पालन करें) |
    | Model name | <a href={"{{model-plaza-url}}"}>model plaza</a> से कॉपी की **किसी समर्थित provider की मॉडल ID** |
  </Step>

  <Step title="अतिरिक्त header केवल तभी कॉन्फ़िगर करें जब आधिकारिक दस्तावेज स्पष्ट रूप से कहें">
    कोई ऐसी आधिकारिक MonkeyCode सेटअप आवश्यकता नहीं मिली जो `User-Agent` को BetterToken के लिए अनिवार्य बनाती हो। इस पेज पर दिए `Base URL`, API key और मॉडल ID से शुरू करें।

    custom gateway, tenant routing, observability या caching layer भी इस्तेमाल कर रहे हों तो header केवल उस upstream सेवा के आधिकारिक दस्तावेज के अनुसार जोड़ें।
  </Step>

  <Step title="सहेजें और उपयोग शुरू करें">
    **Save** क्लिक करें, फिर मुख्य पेज पर लौटकर अभी कॉन्फ़िगर किया मॉडल चुनें।
  </Step>

  <Step title="MonkeyCode रीस्टार्ट करें">
    config सहेजने के बाद नया मॉडल इस्तेमाल करने से पहले पेज refresh करें या MonkeyCode फिर खोलें।
  </Step>
</Steps>

<Note>
  अतिरिक्त header चाहिए हों तो `User-Agent` को BetterToken के लिए अनिवार्य मानने के बजाय वर्तमान MonkeyCode दस्तावेज या upstream gateway आवश्यकता का पालन करें।
</Note>

## कनेक्शन सत्यापित करें

छोटा test prompt भेजें। यदि टूल बिना authentication या Model ID त्रुटि के उत्तर देता है, तो कनेक्शन काम कर रहा है। configuration बदलने के बाद टूल को पूरी तरह रीस्टार्ट करें।

## मॉडल बदलें

मॉडल selector खोलें या configuration में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर मौजूदा session रीस्टार्ट करें。

## सामान्य त्रुटियां

| त्रुटि | क्या जांचें |
| --- | --- |
| `401` या `Unauthorized` | BetterToken API key जांचें और शुरुआत/अंत के space हटाएं। |
| `404` | Base URL जांचें और कोई विशिष्ट endpoint path न जोड़ें। |
| `model not found` | model plaza से वर्तमान Model ID कॉपी करें। |
| बदलाव लागू नहीं होते | configuration सहेजें और टूल पूरी तरह रीस्टार्ट करें। |
