### सेटअप

<Steps>
  <Step title="BetterToken API Key सेट करें">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    `YOUR_API_KEY` को अपनी BetterToken API Key से बदलें। Droid अपने JSON configuration में `${BETTERTOKEN_API_KEY}` environment-variable expansion समर्थित करता है।
  </Step>

  <Step title="Droid config फ़ाइल संपादित करें">
    Config फ़ाइल path: `~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Codex",
          "model": "YOUR_MODEL_ID",
          "baseUrl": "{{openai-base-url}}",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "openai"
        }
      ]
    }
    ```

    `YOUR_MODEL_ID` को <a href={"{{model-plaza-url}}"}>model plaza</a> से कॉपी की वर्तमान **किसी समर्थित provider की मॉडल ID** से बदलें।
  </Step>

  <Step title="Droid शुरू करें और मॉडल चुनें">
    ```bash
    cd /path/to/your/project
    droid
    ```

    Droid में `/model` लिखें और **BetterToken Codex** चुनें। Factory settings फ़ाइल के बदलाव देखता है; यदि मॉडल सूची refresh न हो, तो Droid बंद करके फिर चलाएं।
  </Step>

  <Step title="छोटा परीक्षण कार्य चलाएं">
    “इस project की directory structure समझाएं।” जैसे छोटे कार्य से शुरू करें। Droid परिणाम देने के बाद cross-file edit या लंबे agent कार्य जारी रखें।
  </Step>
</Steps>

<Note>
  `provider` को `openai` पर सेट करें। Factory के BYOK configuration में यह मान OpenAI Responses API चुनता है। `{{openai-base-url}}` और BetterToken API Key उपयोग करें।
</Note>

## कनेक्शन सत्यापित करें

छोटा test prompt भेजें। यदि टूल बिना authentication या Model ID त्रुटि के उत्तर देता है, तो कनेक्शन काम कर रहा है। configuration बदलने के बाद टूल को पूरी तरह रीस्टार्ट करें।

## मॉडल बदलें

मॉडल selector खोलें या configuration में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर मौजूदा session रीस्टार्ट करें।

## सामान्य त्रुटियां

### समस्या निवारण

| लक्षण | क्या जांचें |
| --- | --- |
| `/model` में कस्टम मॉडल नहीं दिखता | JSON जांचें और पुष्टि करें कि `model`, `baseUrl`, `apiKey` और `provider` सभी मौजूद हैं |
| `Invalid provider` | UI display label नहीं, सटीक lowercase मान `"openai"` उपयोग करें |
| `401` या `403` | API Key फिर से कॉपी करें, पुष्टि करें कि Droid process `BETTERTOKEN_API_KEY` पढ़ सकता है और account balance जांचें |
| `404` या Model not found | `{{openai-base-url}}` उपयोग करें और model plaza से वर्तमान GPT मॉडल ID कॉपी करें |
| संपादन के बाद पुराना मॉडल रहता है | `/model` फिर खोलें; यदि फिर भी refresh न हो, तो Droid पूरी तरह बंद करके फिर चलाएं |

### FAQ

### समर्थित provider क्यों इस्तेमाल करें?

Droid का `provider: "openai"` OpenAI Responses API उपयोग करता है। BetterToken का समर्थित provider मिलते-जुलते OpenAI-compatible endpoint और मॉडल ID प्रदान करता है।

### क्या कस्टम header चाहिए?

मानक BetterToken सेटअप के लिए अतिरिक्त header की जरूरत नहीं है। tenant, routing या audit header केवल तब जोड़ें जब दूसरा gateway स्पष्ट रूप से मांगे।

### मूल्य और उपयोग कहां जांचें?

वर्तमान मॉडल मूल्य के लिए live <a href={"{{model-plaza-url}}"}>model plaza</a> उपयोग करें। अनुरोध उपयोग और balance BetterToken Dashboard में उपलब्ध हैं।
