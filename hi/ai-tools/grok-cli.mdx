“Grok CLI” दो अलग tools के लिए इस्तेमाल हो सकता है:

- **Grok Build** — xAI का official coding agent;
- **Community Grok CLI** — xAI से असंबद्ध open-source project।

दोनों clients BetterToken के साथ verify किए गए हैं। BetterToken API Key, Base URL और Model ID से दोनों ने model response लौटाया। यह guide पहले **Community Grok CLI** दिखाती है क्योंकि इसकी configuration अधिक सीधी है।

<Warning>दोनों tools `grok` command इस्तेमाल करते हैं। दोनों install होने पर `PATH` में पहले मिलने वाला version चलेगा।</Warning>

## Grok CLI और Grok Build में अंतर

| विषय | Official Grok Build | Community Grok CLI |
| --- | --- | --- |
| Maintainer | xAI | `superagent-ai/grok-cli`, xAI से असंबद्ध |
| Authentication | Browser login या `XAI_API_KEY` | `GROK_API_KEY` |
| Custom Base URL | `~/.grok/config.toml` में | `GROK_BASE_URL` से |
| Model | Config alias | `GROK_MODEL` |
| BetterToken से model call | Verified | Verified |
| Command | `grok` | `grok` |

Verification केवल text और code model requests के लिए है, tool calls या xAI-specific APIs के लिए नहीं।

## Community Grok CLI को BetterToken के साथ इस्तेमाल करें

ये commands macOS, Linux और WSL के लिए हैं। Community client का native Windows setup verify नहीं किया गया है।

### इंस्टॉल करें

```bash
curl -fsSL https://raw.githubusercontent.com/superagent-ai/grok-cli/main/install.sh | bash
grok --version
```

Bun पहले से install हो तो:

```bash
bun add -g grok-dev
```

### BetterToken configure करें

```bash
export GROK_BASE_URL="{{openai-base-url}}"
export GROK_API_KEY="YOUR_API_KEY"
export GROK_MODEL="YOUR_MODEL_ID"
```

`YOUR_MODEL_ID` को <a href={"{{model-plaza-url}}"}>model plaza</a> की पूरी Model ID से बदलें और अपनी <a href={"{{register-url}}"}>BetterToken API Key</a> इस्तेमाल करें।

### Connection verify करें

```bash
grok -p "Reply with only: OK"
```

Model response मिलने पर ही API Key, Base URL और Model ID की पुष्टि होती है। Environment variables बदलने के बाद client restart करें।

## Official Grok Build

[Grok Build](https://docs.x.ai/build/overview) xAI का official terminal coding agent है।

### इंस्टॉलेशन और login

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    grok --version
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    grok --version
    ```
  </Tab>
</Tabs>

पहली बार Grok Build browser खोलता है। Browser के बिना:

```bash
export XAI_API_KEY="YOUR_XAI_API_KEY"
grok
```

### Grok Build में BetterToken configure करें

```toml
[model.bettertoken]
model = "YOUR_MODEL_ID"
base_url = "{{openai-base-url}}"
name = "BetterToken"
env_key = "BETTERTOKEN_API_KEY"
api_backend = "chat_completions"

[models]
default = "bettertoken"
```

`BETTERTOKEN_API_KEY` example का variable name है। Grok Build `env_key` में दिया variable पढ़ता है।

```bash
export BETTERTOKEN_API_KEY="YOUR_API_KEY"
grok inspect
grok -p "Reply with only: OK" -m bettertoken
```

<Note>इस configuration से Grok Build ने BetterToken के जरिए model response लौटाया। Tool calls और xAI-specific APIs verify नहीं किए गए हैं।</Note>

## सामान्य त्रुटियां

| समस्या | जांच |
| --- | --- |
| गलत client खुलता है | हर `grok` command का path और version जांचें। |
| `401` या `Unauthorized` | Community CLI `GROK_API_KEY` पढ़ता है; Grok Build `env_key` वाला variable पढ़ता है। |
| `model not found` | Model plaza से पूरी Model ID copy करके restart करें। |
| Request xAI पर जाता है | `GROK_BASE_URL` जांचें या Grok Build में `grok inspect` चलाएं। |

## Models और feature limits

<a href={"{{model-plaza-url}}"}>Model plaza</a> से OpenAI-compatible पूरी Model ID इस्तेमाल करें। X Search, voice, image, video और अन्य xAI-specific APIs इस setup में शामिल नहीं हैं।
