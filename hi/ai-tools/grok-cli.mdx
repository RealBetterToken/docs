## इंस्टॉल करें

### Grok CLI इंस्टॉल करें

इसे Windows, macOS या Linux पर चलाएं:

```bash
npm install -g @vibe-kit/grok-cli
```

इंस्टॉल के बाद `grok` न मिले तो terminal बंद करके फिर खोलें और `grok --help` चलाएं। जांचें कि global `npm` package directory आपके `PATH` पर है।

### Base URL और API Key कॉन्फ़िगर करें

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="टकराव वाले variable हटाएं">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="BetterToken variable सेट करें">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="मॉडल के साथ Grok CLI शुरू करें">
        ```bash
        grok --model YOUR_MODEL_ID
        ```

        `YOUR_MODEL_ID` को model plaza की वर्तमान **किसी समर्थित provider की मॉडल ID** से बदलें।
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="मौजूदा PowerShell window के लिए variable सेट करें">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="मॉडल के साथ Grok CLI शुरू करें">
        ```powershell
        grok --model YOUR_MODEL_ID
        ```

        ये variable केवल मौजूदा PowerShell window पर लागू होते हैं। नई window खोलने पर इन्हें अपनी टीम के अनुमोदित secret-storage तरीके से फिर सेट करें।
      </Step>
    </Steps>
  </Tab>
</Tabs>

## कनेक्शन सत्यापित करें

छोटा test prompt भेजें। यदि टूल बिना authentication या Model ID त्रुटि के उत्तर देता है, तो कनेक्शन काम कर रहा है। configuration बदलने के बाद टूल को पूरी तरह रीस्टार्ट करें।

Grok CLI शुरू होने के बाद छोटा prompt भेजें। यदि यह बिना authentication या model ID त्रुटि के उत्तर दे, तो कनेक्शन तैयार है। environment variable बदलने पर मौजूदा Grok CLI session बंद करें और नया शुरू करें।

## मॉडल बदलें

मॉडल selector खोलें या configuration में `Model` फ़ील्ड बदलें। <a href={"{{model-plaza-url}}"}>model plaza</a> से सटीक Model ID उपयोग करें, फिर मौजूदा session रीस्टार्ट करें।

## सामान्य त्रुटियां

| लक्षण | क्या जांचें |
| --- | --- |
| `grok: command not found` | फिर इंस्टॉल करें, नया terminal खोलें और `grok --help` जांचें। |
| `401`, `Unauthorized` या `Invalid API key` | `GROK_API_KEY` जांचें, सुनिश्चित करें कि अतिरिक्त whitespace कॉपी नहीं हुई और Grok CLI उसी terminal में शुरू करें जहां variable सेट है। |
| `model not found` या मॉडल अनुपलब्ध | model plaza में **supported provider** की वर्तमान मॉडल ID कॉपी करें। Claude provider की ID उपयोग न करें। |
| अनुरोध अब भी पुरानी सेवा का उपयोग करते हैं | `GROK_BASE_URL` जांचें, `/chat/completions` न जोड़ें, फिर terminal और Grok CLI रीस्टार्ट करें। |
| कनेक्शन त्रुटि | पुष्टि करें कि Base URL `{{openai-base-url}}` है और आपका नेटवर्क HTTPS से `bettertoken.ai` तक पहुंच सकता है। |

### सेटअप FAQ

**Grok CLI में कौन-सा Base URL इस्तेमाल करूं?**

`{{openai-base-url}}` उपयोग करें। यह BetterToken का OpenAI-compatible Base URL है।

**कौन-सी API Key और मॉडल चुनूं?**

BetterToken API Key और उसी group का मॉडल उपयोग करें।

**क्या system proxy बदलना या VPN चालू करना जरूरी है?**

नहीं। BetterToken से कनेक्ट करने के लिए अपने terminal में Base URL और API Key कॉन्फ़िगर करें।
