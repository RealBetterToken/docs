BetterToken में OpenAI-compatible Chat Completions और Responses API तथा Anthropic-compatible Messages API उपलब्ध हैं। अपने क्लाइंट का API फ़ॉर्मैट चुनें।

## API चुनें

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/hi/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/hi/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/hi/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/hi/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/hi/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Chat Completions कनेक्शन विवरण

| Field | मान |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Full request URL | `{{chat-completions-url}}` |
| Method | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

<a href={"{{model-plaza-url}}"}>मॉडल प्लाज़ा</a> या Console के API Key **Setup** dialog से मौजूदा Model ID कॉपी करें।

<Warning>
  टूल **Base URL** मांगे तो `{{openai-base-url}}` दर्ज करें। टूल स्पष्ट रूप से पूरा Request URL मांगे तभी `{{chat-completions-url}}` उपयोग करें।
</Warning>

## त्वरित टेस्ट

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

सफल Response में `choices[0].message.content` होता है।

</Note>
