`POST /v1/responses`

इस endpoint का उपयोग Codex और OpenAI Responses API इस्तेमाल करने वाले application के लिए करें।

<Note>
  Base URL: `{{openai-base-url}}`। API Key को `Authorization: Bearer YOUR_API_KEY` के रूप में भेजें।
</Note>

## Playground में परीक्षण

दाईं ओर Playground में API Key भरें, जरूरत पड़ने पर `model` को वर्तमान GPT provider मॉडल ID से बदलें और अनुरोध भेजें। परीक्षण से पहले <a href={"{{model-plaza-url}}"}>model plaza</a> में मॉडल की पुष्टि करें।

<Warning>
  केवल अपनी test API Key उपयोग करें। key को code, screenshot, ticket या Git repository में न रखें।
</Warning>
