`POST /v1/messages`

इस endpoint का उपयोग Claude Code, Anthropic SDK और Anthropic Messages API इस्तेमाल करने वाले application के लिए करें।

<Note>
  SDK के लिए `{{anthropic-base-url}}` को Base URL के रूप में उपयोग करें। मैन्युअल अनुरोध और Playground पूरा `{{anthropic-base-url}}/v1/messages` path उपयोग करते हैं।
</Note>

## Playground में परीक्षण

दाईं ओर Playground में `x-api-key` फ़ील्ड में API Key भरें, `anthropic-version` को `claude-cli/2.0.76 (external, cli)` ही रहने दें, उपलब्ध Claude provider मॉडल चुनें और अनुरोध भेजें।

<Warning>
  इस endpoint के लिए `Authorization: Bearer ...` उपयोग न करें। इसके लिए `x-api-key` header जरूरी है।
</Warning>
