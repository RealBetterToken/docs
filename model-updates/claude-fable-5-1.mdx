Дата обновления: 2 сентября 2026 года

BetterToken добавил **Claude Fable 5.1** с точным Model ID `claude-fable-5-1`. Anthropic позиционирует модель для сложных рассуждений и длительной агентной работы, включая крупные задачи по программированию, многоэтапные исследования и работу с документами. Актуальную доступность и цену BetterToken проверяйте в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Основные обновления

- **Длительная агентная работа**: модель рассчитана на сложные задачи с большим числом шагов, инструментов и приложений
- **Программирование и интеллектуальная работа**: подходит для крупных изменений в кодовой базе, ревью кода, исследований, документов, таблиц, презентаций, графиков и схем
- **Большой контекст и вывод**: Anthropic указывает контекст `1 млн токенов` и вывод до `128K токенов`
- **Адаптивное мышление**: всегда включено, значение effort по умолчанию в Claude API — `high`
- **Более дешёвое чтение кэша**: у Anthropic оно стоит в четыре раза меньше, чем для Claude Fable 5; цена BetterToken может отличаться, поэтому проверяйте model plaza

## Рекомендации по настройке

- Выбирайте Fable 5.1 для сложных рассуждений и длительных задач. Для большинства сценариев Anthropic рекомендует сначала Claude Opus 5 и переходить на Fable 5.1, если это подтверждают ваши тесты.
- Перед переключением рабочего трафика проверьте модель на реальной задаче и сравните качество, задержку и расход токенов.
- При переходе с Claude Fable 5 только добавляйте новые сообщения в историю. Fable 5.1 отклоняет принудительный вызов инструмента; ранние модели не читают созданные им thinking blocks, а изменение предыдущих сообщений делает эти блоки недействительными.
- Всегда указывайте точный Model ID BetterToken `claude-fable-5-1`, а не отображаемое имя или ID другой платформы.

## Быстрый старт

1. Создайте BetterToken API Key или откройте окно **Setup** для существующего ключа.
2. Убедитесь в model plaza, что `claude-fable-5-1` доступен.
3. Откройте инструкцию для клиента и укажите BetterToken API Key, требуемый Base URL и точный Model ID.
4. Перезапустите клиент, если список моделей не обновился автоматически.
5. Отправьте короткий тестовый запрос и проверьте его в Dashboard.

## Частые вопросы

### Для каких задач подходит Claude Fable 5.1?

Используйте модель для сложных рассуждений, длительных задач программирования, многоэтапных исследований и сложной работы с документами. Для обычных задач сначала сравните её с Claude Opus 5 и другими доступными моделями.

### Доступен ли через BetterToken весь контекст в 1 млн токенов?

Официальная спецификация Anthropic указывает контекст `1 млн токенов`. Фактический лимит также может зависеть от клиента и параметров запроса. Перед отправкой очень большого промпта проверьте model plaza и документацию клиента.

### Как исправить ошибку Model not found?

Убедитесь, что указан точный ID `claude-fable-5-1`, BetterToken API Key имеет доступ к модели, а Base URL соответствует инструкции клиента. Затем перезапустите клиент и повторите запрос.

### Можно ли сразу перейти с Claude Fable 5 на 5.1?

Сначала замените Model ID и запустите существующие тесты. Прежние промпты обычно остаются применимыми, но проверьте принудительный вызов инструментов, thinking blocks от других моделей и код, который изменяет ранние сообщения диалога.
