Дата обновления: 2 сентября 2026 года

BetterToken добавил модель **Claude Fable 5.1** с точным Model ID `claude-fable-5-1`. Проверьте ее текущую доступность и цену в <a href={"{{model-plaza-url}}"}>model plaza</a>, затем используйте этот ID в поддерживаемом клиенте.

## Что добавлено

- **Модель**: Claude Fable 5.1
- **Model ID**: `claude-fable-5-1`
- **Доступность и цена**: актуальные данные отображаются в model plaza

## Как настроить модель

1. Создайте BetterToken API Key или откройте окно **Setup** для существующего ключа.
2. Скопируйте Model ID `claude-fable-5-1` из model plaza.
3. Откройте инструкцию для вашего клиента и укажите BetterToken API Key, требуемый Base URL и точный Model ID.
4. Перезапустите клиент, если он не обновляет список моделей автоматически.
5. Отправьте короткий тестовый запрос и проверьте его в Dashboard.

## Если появляется Model not found

Убедитесь, что указан точный ID `claude-fable-5-1`, API Key имеет доступ к этой модели, а Base URL соответствует инструкции выбранного клиента. Затем перезапустите клиент и повторите запрос.
