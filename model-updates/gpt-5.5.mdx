Дата релиза: 24 апреля 2026 года

BetterToken обновил запись модели `GPT-5.5`. Проверьте актуальный ID модели группы **GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>, затем настройте его в Codex, OpenCode, OpenClaw, Cursor, Cline, Zed или другом внешнем инструменте по соответствующей инструкции.

OpenAI официально представила GPT-5.5 23 апреля 2026 года и описала ее как модель для сложной реальной работы. OpenAI выделяет улучшения в agentic coding, computer use, работе со знаниями и научных сценариях. Модель рассчитана на более раннее понимание намерения, эффективное планирование, использование инструментов, проверку результата и выполнение многошаговых задач.

## Главное

- **Более сильная работа coding agent**: OpenAI сообщает об улучшениях по сравнению с GPT-5.4 на coding и agentic-бенчмарках, включая Terminal-Bench 2.0 и SWE-Bench Pro
- **Более надежные длинные задачи**: модель лучше подходит для workflow, где вместе идут реализация, отладка, проверка и документация
- **Более активное использование инструментов**: OpenAI подчеркивает улучшения в tool use, проверке результата и продвижении в неоднозначных задачах
- **Выше эффективность**: по словам OpenAI, GPT-5.5 сохраняет latency уровня GPT-5.4 и использует меньше токенов в Codex-задачах

## Настройка

Для Codex и внешних инструментов копируйте текущий ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>. Не хардкодьте имя модели, если его нет на этой странице.

Если ваша версия Codex не дает выбрать `gpt-5.5` в API mode, смотрите [Почему Codex не может использовать GPT-5.5 в API mode?](/faq/codex/gpt-5.5-api-mode).
