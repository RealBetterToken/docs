发布日期：2026-04-24

BetterToken 已更新 `GPT-5.5` 相关模型入口。你可以在<a href={"{{model-plaza-url}}"}>模型广场</a>查看当前可用的 **GPT 分组**模型 ID，并在 Codex、OpenCode、OpenClaw、Cursor、Cline、Zed 等外部工具中按对应接入文档配置。

OpenAI 官方于 2026-04-23 发布 GPT-5.5，并将其定位为面向复杂真实工作的模型。官方说明中重点提到，它在 agentic coding、computer use、知识工作和科研任务上更强，能更早理解任务意图，更主动地规划、使用工具、检查结果并持续完成多步骤任务。

## 更新亮点

- **代码代理能力更强**：官方说明中，GPT-5.5 在 Terminal-Bench 2.0、SWE-Bench Pro 等代码与代理任务评测上相较 GPT-5.4 有提升
- **长任务更稳**：适合让模型处理包含实现、调试、验证和文档整理的多步骤任务
- **工具使用更主动**：官方强调 GPT-5.5 更擅长在工具之间移动、检查输出，并在不确定场景下继续推进
- **效率更高**：OpenAI 表示 GPT-5.5 在保持 GPT-5.4 级别延迟的同时，在 Codex 任务中使用更少 token 完成工作

## 配置建议

如果你使用 Codex 或外部工具，请从<a href={"{{model-plaza-url}}"}>模型广场</a>复制当前可用的 **GPT 分组**模型 ID。不要手写不在模型广场中的模型名。

如果你的 Codex 当前版本无法在 API 模式中选择 `gpt-5.5`，请参考[为什么在 Codex 的 API 模式无法使用 GPT-5.5？](/faq/codex-gpt-5.5-api-mode)。
