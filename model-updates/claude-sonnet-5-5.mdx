Дата релиза: 28 сентября 2026 года

Claude Sonnet 5.5 — вторая модель семейства Claude 5.5 от Anthropic. Компания предлагает её как более быстрый вариант для повседневных задач с чёткими границами: программирования, исправления ошибок, подготовки документов, презентаций и таблиц. Для сложных задач с открытым результатом рассмотрите Opus 5.5.

В BetterToken доступен **Claude Sonnet 5.5** с точным Model ID `claude-sonnet-5-5`. Укажите Base URL `{{anthropic-base-url}}`. Актуальную доступность и цену проверяйте в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Возможности

- **Программирование**: используйте модель для задач с понятными требованиями и исправления ошибок.
- **Рабочие материалы**: Anthropic выделяет создание документов, презентаций и таблиц.
- **Длинный контекст**: по данным Anthropic, окно контекста составляет 1 млн токенов, а максимальный вывод — 128 тыс. токенов.

## Перед переходом с Sonnet 5

Если ваш клиент напрямую вызывает Anthropic Messages API, изучите [официальное руководство по миграции](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide). В Sonnet 5.5 изменилось поведение некоторых настроек thinking и выбора инструментов. Проверьте типичные запросы перед сменой Model ID.
