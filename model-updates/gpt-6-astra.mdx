Обновлено: 5 сентября 2026 года

BetterToken добавил **GPT-6 Astra** с точным Model ID `gpt-6-astra`. OpenAI называет Astra своей самой мощной моделью для сложной сквозной работы, включая рассуждения, разработку ПО, исследования, работу с компьютером и создание документов. Актуальную доступность и цену BetterToken проверяйте в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Основные обновления

- **Сквозные задачи**: модель предназначена для сложных многоэтапных процессов с кодом, браузером, инструментами и профессиональными приложениями
- **Разработка ПО**: OpenAI позиционирует Astra как свою сильнейшую модель для программирования и агентной разработки
- **Большой контекст**: OpenAI указывает окно контекста `1 050 000` токенов и вывод до `128 000` токенов
- **Настраиваемая глубина рассуждений**: OpenAI API поддерживает уровни `low`, `medium`, `high`, `xhigh` и `max`
- **Инструменты Responses API**: в документации OpenAI заявлены вызов функций, структурированный вывод, веб-поиск, поиск по файлам, Code Interpreter, работа с компьютером и MCP

## Рекомендации по настройке

- Используйте Astra для сложного программирования, исследований, работы с компьютером и длительных агентных задач. Для повседневной работы сравните её с более быстрыми или экономичными моделями в model plaza.
- Перед переключением рабочего трафика проверьте модель на реальной задаче и сравните качество, задержку и расход токенов.
- Выберите **провайдера GPT**, укажите Base URL `{{openai-base-url}}` и точный Model ID `gpt-6-astra`.
- Доступ может открываться поэтапно. Источником актуальных данных о доступности и цене BetterToken является model plaza.

## Быстрый старт

1. Создайте BetterToken API Key или откройте окно **Setup** для существующего ключа.
2. Убедитесь в model plaza, что `gpt-6-astra` доступен.
3. Укажите в клиенте Base URL `{{openai-base-url}}` и Model ID `gpt-6-astra`.
4. Перезапустите клиент, если список моделей не обновился автоматически.
5. Выполните небольшой тестовый запрос и проверьте его в Dashboard.

## Частые вопросы

### Какой Model ID у GPT-6 Astra?

Используйте `gpt-6-astra`. Не заменяйте его отображаемым именем `GPT-6 Astra` или ID с другой платформы.

### Доступен ли в BetterToken полный контекст на 1 050 000 токенов?

OpenAI указывает для GPT-6 Astra окно контекста `1 050 000` токенов. Практический лимит также может зависеть от клиента, параметров запроса и текущей маршрутизации BetterToken. Перед отправкой очень больших запросов проверьте model plaza и документацию клиента.

### Как исправить ошибку Model not found?

Проверьте, что указан точный ID `gpt-6-astra`, BetterToken API Key имеет доступ к модели, выбран **провайдер GPT**, а Base URL равен `{{openai-base-url}}`. Затем перезапустите клиент и повторите запрос.

### Где посмотреть актуальную цену?

Проверьте <a href={"{{model-plaza-url}}"}>model plaza</a>. Цена BetterToken может отличаться от прямой цены OpenAI API и меняться со временем.
