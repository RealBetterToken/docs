发布日期：2026-04-29

BetterToken 已上线 `gpt-image-2` 图像生成模型入口。你可以在模型广场 (`{{model-plaza-url}}`)查看当前可用模型 ID，并通过 OpenAI 兼容协议调用图像生成 API。

OpenAI 官方于 2026-04-21 发布 ChatGPT Images 2.0，并在开发者文档中将 `gpt-image-2` 列为最新 GPT Image 模型。官方说明中，GPT Image 2 面向快速、高质量的图像生成与编辑，支持文本和图片输入、图片输出、灵活尺寸和高保真图片输入。

## 更新亮点

- **图片质量更高**：官方模型页将 GPT Image 2 标记为当前最高性能的图像生成模型，适合生成高质量视觉资产
- **尺寸更灵活**：`gpt-image-2` 支持更多符合约束的图片尺寸，常见方图、横图、竖图、2K 和 4K 比例都可以用于不同展示场景；2K 以上尺寸当前属于实验性输出
- **输入图片保真度更高**：在图像编辑和参考图工作流中，`gpt-image-2` 会以高保真方式处理图片输入，适合基于产品图、人物图或品牌素材继续生成
- **文字与复杂信息更强**：OpenAI 在系统卡中提到，ChatGPT Images 2.0 在世界知识、指令跟随、密集文字和复杂细节生成上有明显提升
- **支持流式中间图**：Image API 可以通过 `stream` 和 `partial_images` 返回生成过程中的中间图，适合做更有反馈感的产品体验

## 适合的场景

- 产品发布海报、活动物料、社媒配图
- 文档、博客、公众号文章的配图草稿
- App、网页和 SaaS 界面的视觉概念图
- 商品图、广告图和品牌视觉方向探索
- 需要中文或多语言文字元素的视觉内容

## API 调用方式

使用 OpenAI 兼容协议时，请使用：

| 配置项 | 值 |
|--------|----|
| `Base URL` | `{{openai-base-url}}` |
| 认证方式 | `Authorization: Bearer YOUR_API_KEY` |
| 模型 ID | `gpt-image-2` |
| 接口 | `POST /v1/images/generations` |

```bash
curl {{images-generations-url}} \
  -H "Authorization: Bearer $BETTERTOKEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "为一个 AI 编程工具生成一张现代中文发布海报，画面包含清晰标题、产品界面和干净背景",
    "size": "1024x1024",
    "quality": "high"
  }' | jq -r '.data[0].b64_json' | base64 --decode > gpt-image-2.png
```

更多参数请查看[文生图文档](/api-reference/images-generations)。

## 配置建议

如果你使用自己的应用、脚本或外部工具接入，请确认该工具支持 OpenAI 兼容的图像生成接口。图像生成使用 `{{openai-base-url}}`，不要使用 Claude Code / Anthropic 协议地址。

建议从模型广场 (`{{model-plaza-url}}`)复制当前可用模型 ID。不要把 ChatGPT 界面里的模式名称当作 API 参数。

## 使用注意

- 图片生成平均需要 `100` 到 `200` 秒。请将客户端、网关或外部工具的请求超时设置到 `300` 秒以上，并在应用里展示等待状态。
- `gpt-image-2` 当前不支持透明背景。需要透明图层时，请先生成非透明图片，再用其他图像工具处理背景。
- 图片结果默认以 `b64_json` 返回。保存图片时需要先做 base64 解码。
- 大尺寸、高质量图片会带来更高延迟和成本。预览图建议先用 `quality: "low"`。
- 含文字、版式和品牌元素的图片仍建议人工复核，尤其是面向公开发布的素材。
