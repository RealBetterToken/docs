Дата релиза: 24 июля 2026 года

В BetterToken стала доступна модель `claude-opus-5`. Она рассчитана на сложное программирование, долгие агентные задачи и многоэтапную работу с большими кодовыми базами. Для подключения создайте API Key BetterToken, выберите провайдера `Claude`, используйте Base URL `{{anthropic-base-url}}` и укажите ID модели `claude-opus-5`.

Актуальную доступность и цену всегда проверяйте в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Главное

- **Сложные задачи по программированию**: Anthropic рекомендует Opus 5 для complex agentic coding и профессиональных задач, где важны качество и устойчивость на длинных сценариях
- **Контекст до `1M tokens`**: модель может работать с крупными репозиториями, длинной историей и большим набором входных материалов
- **Вывод до `128K tokens`**: подходит для объемных изменений кода, отчетов и многоэтапных результатов
- **Adaptive thinking включен по умолчанию**: модель сама регулирует глубину рассуждений в зависимости от задачи
- **Расширенное управление effort**: поддерживаются уровни `low`, `medium`, `high`, `xhigh` и `max`

## Как подключить

1. <a href={"{{register-url}}"}>Зарегистрируйтесь и получите API Key BetterToken</a>, затем выберите провайдера `Claude`.
2. Укажите Base URL `{{anthropic-base-url}}`.
3. В качестве модели выберите `claude-opus-5`.
4. Для Claude Code следуйте [инструкции по подключению](/ai-tools/claude-code). Для управления несколькими провайдерами можно использовать [CC Switch](/ai-tools/cc-switch).

Если вы выбираете модель для конкретной задачи, сравните Opus 5 с другими вариантами в [руководстве по выбору модели](/faq/model-calling/model-selection-guide).

## Что проверить при переходе с Opus 4.8

В большинстве конфигураций достаточно заменить ID модели `claude-opus-4-8` на `claude-opus-5`. Обратите внимание на два изменения:

- **Thinking включен по умолчанию**. Если задан effort `xhigh` или `max`, отключение thinking вернет ошибку `400`.
- **`max_tokens` включает thinking и видимый ответ**. Оставьте достаточный запас для задач, которым нужны длинные рассуждения и большой итоговый вывод.

<Tip>
  Для первого теста используйте реальную задачу из своего рабочего процесса: анализ репозитория, многофайловое изменение или длительный агентный сценарий. Так проще оценить качество, задержку и расход токенов до массового переключения.
</Tip>
