Дата релиза: 1 июля 2026 года

BetterToken обновил запись модели `Claude Sonnet 5`. Проверьте актуальный ID модели и текущую цену в <a href={"{{model-plaza-url}}"}>model plaza</a>, затем настройте ее по инструкции для Claude Code или внешнего инструмента, который вы используете.

`Claude Sonnet 5` — новое поколение семейства Sonnet. Anthropic позиционирует его как обновление `Claude Sonnet 4.6` с основными улучшениями в программировании, агентных задачах и профессиональной работе.

## Главное

- **Лучше подходит для кода и агентных задач**: Anthropic указывает, что основные улучшения Sonnet 5 по сравнению с Sonnet 4.6 заметны в программировании и agentic-задачах
- **Больше контекстное окно**: Sonnet 5 по умолчанию поддерживает контекст `1M tokens` и вывод до `128K tokens`
- **Adaptive thinking включен по умолчанию**: запросы без поля `thinking` выполняются с adaptive thinking
- **Меньше изменений при миграции**: если вы уже используете Sonnet 4.6, во многих запросах достаточно заменить ID модели на `claude-sonnet-5`
- **Более явное поведение безопасности**: для высокорисковых тем кибербезопасности модель может вернуть отказ с `stop_reason: "refusal"`, а не HTTP-ошибку

## Что проверить при миграции

Если вы переходите с Sonnet 4.6 на Sonnet 5, сначала проверьте эти настройки:

- **Пересмотрите `max_tokens`**: размышление модели и финальный ответ используют один общий лимит вывода, поэтому задачам близко к лимиту может понадобиться запас
- **Уберите ручной бюджет thinking**: `thinking: { "type": "enabled", "budget_tokens": ... }` больше не поддерживается в Sonnet 5; используйте adaptive thinking
- **Не задавайте нестандартные sampling-параметры**: нестандартные `temperature`, `top_p` или `top_k` могут вернуть ошибку `400`
- **Пересчитайте токены**: Sonnet 5 использует новый tokenizer, поэтому один и тот же текст может давать больше токенов, чем в Sonnet 4.6
