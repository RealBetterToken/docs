Дата релиза: 22 сентября 2026 года

OpenAI расширила семейство GPT-6 двумя моделями наряду с Astra: Sol предназначена для сложного программирования и агентных сценариев, а Luna — для четко определенных задач с большим объемом запросов. По данным OpenAI, обе модели улучшены по сравнению с GPT-5.6 в программировании, точности ответов и стиле общения.

BetterToken добавил **GPT-6 Sol** и **GPT-6 Luna**. Укажите провайдера `GPT`, Base URL `{{openai-base-url}}` и точный Model ID: `gpt-6-sol` или `gpt-6-luna`. Название модели — **Sol**, не `Sora`.

Актуальную доступность и цены BetterToken проверяйте в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Выбор модели

- **`gpt-6-sol`**: для сложного программирования и агентных сценариев.
- **`gpt-6-luna`**: для сфокусированных повторяющихся задач и большого объема запросов.

## Ключевые особенности

- **Контекст и вывод**: OpenAI указывает для обеих моделей контекстное окно `1,050,000` токенов и до `128,000` токенов вывода.
- **Управляемое рассуждение**: обе модели поддерживают уровни `none`, `low`, `medium`, `high`, `xhigh` и `max`.
- **Рабочие задачи**: OpenAI сообщает об улучшениях в программировании, фактической точности и ясности ответов по сравнению с GPT-5.6.

## Как подключить

1. <a href={"{{register-url}}"}>Создайте BetterToken API Key</a>.
2. Выберите провайдера `GPT` и Base URL `{{openai-base-url}}`.
3. Для сложных агентных задач используйте `gpt-6-sol`, для повторяющихся массовых задач — `gpt-6-luna`.
4. Выполните тестовый запрос и сравните качество, задержку и расход токенов.

Для Codex CLI используйте [инструкцию по подключению](/ai-tools/codex). Для других клиентов откройте [руководство по выбору модели](/faq/model-calling/model-selection-guide).
