Дата релиза: 10 июля 2026 года

BetterToken добавил модели семейства GPT-5.6. Проверьте актуальные ID моделей **Группы ключа GPT** и текущие цены в <a href={"{{model-plaza-url}}"}>model plaza</a>, затем используйте их в Codex, OpenCode, OpenClaw, Cursor, Cline, Zed или других внешних инструментах через OpenAI-совместимый протокол.

Новые model ID:

| Model ID | Для каких задач |
| --- | --- |
| `gpt-5.6-sol` | Сложное reasoning, большие кодовые базы, многошаговые agent-задачи и долгие coding workflow |
| `gpt-5.6-terra` | Ежедневная разработка, interactive coding, обычные agent-задачи и баланс возможностей и стоимости |
| `gpt-5.6-luna` | Более легкие задачи, где важны скорость и стоимость: batch assistance, быстрые ответы, простые переписывания и небольшие tool calls |

## Главное

- **Три уровня моделей**: OpenAI позиционирует GPT-5.6 Sol, Terra и Luna для задач с высоким reasoning, сбалансированной ежедневной работы и более легких высокочастотных задач
- **Лучше подходит для coding agents**: OpenAI подчеркивает улучшения в coding-agent задачах, terminal workflow и координации инструментов
- **Готово для внешних инструментов**: OpenAI Help Center подтверждает доступность Sol, Terra и Luna через OpenAI API; в BetterToken используйте **Группу ключа GPT** и `{{openai-base-url}}`
- **Выбор по типу задачи**: тестируйте `gpt-5.6-sol` для сложной работы, `gpt-5.6-terra` для ежедневной разработки и `gpt-5.6-luna` для легких или чувствительных к стоимости запросов

## Настройка

Для Codex или других OpenAI-compatible инструментов используйте соответствующую инструкцию:

- **Base URL**: `{{openai-base-url}}`
- **Группа ключа API**: выберите **Группу ключа GPT**
- **Название модели**: скопируйте текущий model ID из <a href={"{{model-plaza-url}}"}>model plaza</a>

<Note>
  Не хардкодьте имя модели, если его нет в model plaza. Доступность моделей, цены и routing status определяются текущими данными в <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Note>

## Быстрый старт

1. Создайте API Key в **группе ключа GPT**.
2. Укажите `{{openai-base-url}}` как Base URL в выбранном инструменте.
3. Скопируйте актуальный ID `gpt-5.6-sol`, `gpt-5.6-terra` или `gpt-5.6-luna` из model plaza.
4. Сначала выполните небольшую coding-задачу и проверьте расход в Dashboard.

## Как выбрать

Если вы не уверены, с какой модели начать, ориентируйтесь на сложность задачи:

- Используйте `gpt-5.6-sol` для понимания больших кодовых баз, правок в нескольких файлах, исправления тестов, длинных циклов отладки и agent-задач, где нужно более сильное reasoning
- Используйте `gpt-5.6-terra` для ежедневного coding, объяснения кода, обычного refactoring, документации и большинства interactive development задач
- Используйте `gpt-5.6-luna` для легких вопросов, batch assistance, простой обработки текста, low-latency tool calls и частых запросов, чувствительных к стоимости

## FAQ

### Какую модель выбрать для начала?

Для большинства повседневных coding-задач начните с `gpt-5.6-terra`. Переходите на `gpt-5.6-sol`, когда задаче требуется более глубокое reasoning, или на `gpt-5.6-luna`, когда важнее скорость.

### Где посмотреть актуальную цену?

Смотрите текущую цену и доступность в <a href={"{{model-plaza-url}}"}>model plaza</a>. В статье цены не фиксируются, потому что они могут меняться.

### Что делать, если инструмент сообщает Model not found?

Скопируйте model ID заново из model plaza, убедитесь, что API Key относится к группе GPT, и проверьте Base URL `{{openai-base-url}}`. Дополнительные рекомендации есть в [руководстве по выбору модели](/faq/model-calling/model-selection-guide).
