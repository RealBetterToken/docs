Обновлено: 2026-09-10

OpenAI выпустила ChatGPT Images 2.5 2026-09-08 и представила две модели API: **GPT Image 2.5 Flare** и **GPT Image 2.5 Sunburst**. Обе указаны в <a href={"{{model-plaza-url}}"}>каталоге моделей</a> BetterToken. Актуальную доступность и цены проверяйте там.

## Как выбрать модель

| Модель | Полный ID модели | Подходящие задачи |
| --- | --- | --- |
| GPT Image 2.5 Flare | `gpt-image-2.5-flare` | Быстрая генерация, материалы для соцсетей, визуальные эскизы и повседневное редактирование. |
| GPT Image 2.5 Sunburst | `gpt-image-2.5-sunburst` | Изображения товаров, фирменные материалы и готовые иллюстрации, требующие сохранения деталей и точных правок. |

Обе модели принимают текст и изображения и создают изображения. Для повседневных задач начните с Flare; для многократных точных правок одного материала сравните результат с Sunburst. Используйте полный ID из таблицы, а не просто `gpt-image-2.5`.

## Что изменилось

- **Быстрее генерация**: по данным OpenAI, задержка Flare на 50% ниже, чем у GPT Image 2. Фактическое время также зависит от размера, качества и нагрузки на сервис.
- **Точнее редактирование**: модель лучше сохраняет объекты, композицию и детали исходного изображения, которые вы не просили менять, в том числе при последовательных правках.
- **Лучше изображение и компоновка**: улучшены освещение, текстуры, соблюдение стиля и выполнение сложных визуальных инструкций. Перед использованием готового изображения проверьте текст и факты.

## Новые параметры официального API

API изображений OpenAI предлагает следующие параметры для обеих моделей:

- `quality` принимает `low`, `medium`, `high`, `xhigh`, `max` и `auto`.
- Для прозрачного фона используйте `background: "transparent"` вместе с `output_format: "png"` или `"webp"`.
- Поддерживаются произвольные размеры. Ширина и высота должны быть кратны 16, соотношение сторон — от 1:3 до 3:1, каждая сторона — не более 3840 пикселей, общее число пикселей — от 655,360 до 8,294,400. Вывод выше `2560x1440` является экспериментальным.

## Подключение через BetterToken

Создайте BetterToken API Key с доступом к нужной модели и используйте следующие настройки:

| Настройка | Значение |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Аутентификация | `Authorization: Bearer YOUR_API_KEY` |
| Генерация изображений | `POST /v1/images/generations` |
| Редактирование изображений | `POST /v1/images/edits` |

### Создание изображения

В примере используется Flare. Для Sunburst замените `model` на `gpt-image-2.5-sunburst`.

```bash
curl --fail-with-body --max-time 300 "{{images-generations-url}}" \
  -H "Authorization: Bearer $BETTERTOKEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "A product photo of a green ceramic mug on a white studio table",
    "size": "1024x1024",
    "n": 1,
    "response_format": "b64_json",
    "output_format": "png"
  }'
```

Эндпоинт ожидает завершения генерации и возвращает изображение в `data[0].b64_json`. Перед декодированием и сохранением убедитесь, что запрос выполнен успешно. Полный пример сохранения приведён в разделе [генерации изображений](/api-reference/images-generations).

Для редактирования отправьте `multipart/form-data` на `POST /v1/images/edits`, укажите тот же полный ID модели и загрузите исходное изображение в поле `image`. Примеры приведены в разделе [редактирования изображений](/api-reference/images-edits).

## Рекомендации по подключению

- Для первого запроса используйте `n: 1`, `output_format: "png"` и `response_format: "b64_json"`, затем настройте остальные параметры.
- Отведите несколько минут на генерацию. При смене модели сравните фактическую задержку, размеры результата и качество правок.
- OpenAI взимает плату за токены. Тарифы и способ расчёта BetterToken смотрите в каталоге моделей; официальные оценки нельзя применять напрямую.
