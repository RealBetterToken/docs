Обновлено: 30 сентября 2026 года

**GPT-6.1 Sol** — обновление GPT-6 Sol. По данным OpenAI, модель лучше справляется с агентным программированием, работой с интерфейсами и профессиональными задачами, а в отдельных тестах приближается к GPT-6 Astra. Для сложных сценариев сравните качество, задержку и расход токенов на своих задачах.

В BetterToken модель доступна под ID `gpt-6.1-sol`. Актуальные доступность и цены BetterToken смотрите в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Ключевые особенности

- **Код и агенты**: подходит для изменений в нескольких файлах, отладки и длительных задач разработки.
- **Работа с интерфейсами и документами**: OpenAI сообщает об улучшениях по сравнению с GPT-6 Sol.
- **Большой контекст**: OpenAI указывает окно в `1,050,000` токенов и до `128,000` токенов вывода. Клиент и маршрут подключения могут ограничивать доступный объем.
- **Настраиваемое рассуждение**: поддерживаются `low`, `medium`, `high`, `xhigh` и `max`; уровни `none` и `minimal` не поддерживаются.

## Как подключить

1. <a href={"{{register-url}}"}>Создайте BetterToken API Key</a>.
2. Для Codex CLI или другого OpenAI-совместимого клиента укажите Base URL `{{openai-base-url}}` и Model ID `gpt-6.1-sol`.
3. Если нужны вызовы инструментов, используйте [Responses API](/api-reference/responses). Согласно документации OpenAI, Chat Completions для этой модели поддерживается без вызовов инструментов.
4. Перед переводом рабочего процесса протестируйте модель на типичной задаче.

Для Claude Code используйте Base URL протокола Anthropic `{{anthropic-base-url}}` и тот же Model ID. Подробности есть в инструкциях для [Claude Code](/ai-tools/claude-code) и [Codex CLI](/ai-tools/codex).
