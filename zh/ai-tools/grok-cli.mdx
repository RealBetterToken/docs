要在 Grok CLI 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 已安装 Node.js 和 `npm`

## 安装

### 安装 Grok CLI

Windows、macOS 和 Linux 都可以执行：

```bash
npm install -g @vibe-kit/grok-cli
```

如果安装后找不到 `grok` 命令，请关闭并重新打开终端，再运行 `grok --help`。同时检查全局 `npm` 包目录是否已加入 `PATH`。

## 手动配置

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 配置 Base URL 和 API Key

<Tabs>
  <Tab title="macOS / Linux">
    <Steps>
      <Step title="清除冲突的环境变量">
        ```bash
        unset OPENAI_API_KEY
        unset OPENAI_BASE_URL
        ```
      </Step>

      <Step title="设置 BetterToken 环境变量">
        ```bash
        export GROK_BASE_URL="{{openai-base-url}}"
        export GROK_API_KEY="YOUR_API_KEY"
        ```
      </Step>

      <Step title="指定模型启动 Grok CLI">
        ```bash
        grok --model YOUR_MODEL_ID
        ```

        将 `YOUR_MODEL_ID` 替换为模型广场中当前可用的 **受支持提供商的模型 ID**。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windows PowerShell">
    <Steps>
      <Step title="为当前 PowerShell 窗口设置变量">
        ```powershell
        $env:GROK_BASE_URL = "{{openai-base-url}}"
        $env:GROK_API_KEY = "YOUR_API_KEY"
        ```
      </Step>

      <Step title="指定模型启动 Grok CLI">
        ```powershell
        grok --model YOUR_MODEL_ID
        ```

        上述变量只在当前 PowerShell 窗口中有效。重新打开窗口后，请按团队认可的安全密钥管理方式再次设置。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

Grok CLI 启动后，发送一条简短提示词。没有出现认证或模型 ID 错误，就说明连接已生效。每次修改环境变量后，都应结束当前 Grok CLI 会话并重新启动。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 现象 | 排查方式 |
| --- | --- |
| `grok: command not found` | 重新执行安装命令，打开新的终端后运行 `grok --help`。 |
| `401`、`Unauthorized` 或 `Invalid API key` | 检查 `GROK_API_KEY`，确认复制的 Key 没有多余空格，并确保在设置变量的同一个终端中启动 Grok CLI。 |
| `model not found` 或模型不可用 | 从模型广场复制当前 **受支持提供商的模型 ID**。不要使用 Claude 提供商模型 ID。 |
| 请求仍发往旧服务 | 检查 `GROK_BASE_URL`，不要填写 `/chat/completions`，然后重启终端和 Grok CLI。 |
| 连接失败 | 确认 Base URL 是 `{{openai-base-url}}`，并确认网络可通过 HTTPS 访问 `bettertoken.ai`。 |

### 配置 FAQ

**Grok CLI 应该填写哪个 Base URL？**

填写 `{{openai-base-url}}`，这是 BetterToken 的 OpenAI-compatible Base URL。

**应该使用哪个 API Key 和模型？**

使用 BetterToken API Key，并选择与当前 endpoint 兼容的模型。

**需要修改系统代理或开启 VPN 吗？**

不需要。只要在终端中设置 Base URL 和 API Key，即可连接 BetterToken。
