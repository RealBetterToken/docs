Codex VS Code Extension 与 Codex CLI/App 共用 `~/.codex/config.toml`。如果你需要保留官方登录、插件或 Remote Control，请使用本页配置。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | `experimental_bearer_token = "YOUR_API_KEY"` |
| Base URL | `{{openai-base-url}}` |
| Model | `gpt-6-astra` |

## 准备工作

- 安装最新版 Codex VS Code Extension
- 先在 Extension 或 Codex App 中完成官方登录
- <a href={"{{register-url}}"}>创建 BetterToken API Key</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>或 Key 的 **Setup** 弹窗复制 Model ID

## 安装

从 VS Code Marketplace 安装扩展，然后重启 VS Code。

## 手动配置

如果设置了自定义 `CODEX_HOME`，请编辑该目录中的 `config.toml`。否则，macOS / Linux 使用 `~/.codex/config.toml`，Windows 使用 `%USERPROFILE%\.codex\config.toml`。

完全退出 Codex，然后备份现有的 `config.toml` 和 `auth.json`。更新已有的 provider 设置，不要重复添加同名 provider table。

### 配置 Extension

编辑 `~/.codex/config.toml`：

```toml
model_provider = "bettertoken"
model = "gpt-6-astra"

[model_providers.bettertoken]
name = "BetterToken"
base_url = "{{openai-base-url}}"
wire_api = "responses"
requires_openai_auth = true
experimental_bearer_token = "YOUR_API_KEY"
```

保存后在 VS Code 中执行 **Developer: Reload Window**，然后重新打开 Codex 面板。

## 验证连接

在 Extension 中新建会话并发送一条短任务。能够调用 `gpt-6-astra` 返回内容，同时插件和 Remote Control 仍可使用，即表示配置成功。

## 切换模型

修改 `model` 和可选的 `review_model`，保存后执行 **Developer: Reload Window**。Model ID 必须来自 Setup 弹窗或模型广场。

## 常见错误

| 错误 | 处理方式 |
| --- | --- |
| Extension 要求重新登录 | 先恢复官方登录，再确认 `requires_openai_auth = true`。 |
| `401` 或 `403` | 重新复制 `experimental_bearer_token`，不要改写 `auth.json`。 |
| Duplicate table | 删除另一套 `[model_providers.bettertoken]`，只保留当前场景的配置。 |
| 模型不存在 | 用当前完整 Model ID 替换 `gpt-6-astra`。 |
| 配置未生效 | 保存文件并执行 **Developer: Reload Window**。 |
