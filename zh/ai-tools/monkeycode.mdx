MonkeyCode 是一款允许你在自身界面中通过 custom provider 接入模型的 AI 工具。本文说明的是在 **AI Model** 中配置 BetterToken，不是 MonkeyCode 官方 API 文档。填写 BetterToken API Key、`{{openai-base-url}}` 和准确的 Model ID，保存绑定后新建对话即可使用。这个方式适合希望自行选择兼容模型的用户。如果错误发生在 Kodacode / Koda，请使用单独的 [Kodacode 配置与 429 错误指南](/zh/ai-tools/kodacode)。产品信息和注册入口以 [MonkeyCode 官网](https://monkeycode.ai)为准。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 已注册 MonkeyCode 账号（访问 [MonkeyCode 官网](https://monkeycode.ai) 注册）

## 安装

安装或打开 MonkeyCode，然后继续完成下方手动配置。

## 手动配置

主要通过 MonkeyCode 的设置界面完成以下配置，不需要手动编辑配置文件。

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 配置步骤

<Steps>
  <Step title="登录 MonkeyCode">
    访问 [MonkeyCode 官网](https://monkeycode.ai) 登录账号。
  </Step>

  <Step title="打开系统配置">
    进入任务页面后，点击右下角的 **配置**。
  </Step>

  <Step title="绑定 AI 大模型">
    在 **AI 大模型** 模块中点击 **绑定**。
  </Step>

  <Step title="填写 BetterToken 配置">

    | 配置项 | 值 |
    |--------|-----|
    | 模型 API 地址 | `{{openai-base-url}}` |
    | API Key | 你的 BetterToken API Key |
    | 接口格式类型 | `OpenAI` 或 `OpenAI Compatible`（以当前界面为准） |
    | 模型名称 | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **受支持提供商的模型 ID** |
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    当前我们没有查到 MonkeyCode 官方接入说明要求 BetterToken 额外配置 `User-Agent`。默认先按页面中的 `Base URL`、API Key 和模型 ID 完成接入即可。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="保存并开始使用">
    点击 **保存**，返回主界面后选择刚配置的模型开始使用。
  </Step>

  <Step title="重启 MonkeyCode">
    修改配置后，请刷新当前页面或重新打开 MonkeyCode，再使用新模型。
  </Step>
</Steps>

<Note>
  如需额外 headers，请以 MonkeyCode 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 BetterToken 必填项。
</Note>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 检查 BetterToken API Key，并删除首尾空格。 |
| `404` | 检查 Base URL，不要附加具体 endpoint 路径。 |
| `model not found` | 从模型广场重新复制当前 Model ID。 |
| 配置未生效 | 保存配置，并完全退出后重新启动工具。 |
