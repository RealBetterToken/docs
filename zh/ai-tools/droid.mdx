要在 Droid 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 配置步骤

<Steps>
  <Step title="设置 BetterToken API Key">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:BETTERTOKEN_API_KEY="YOUR_API_KEY"
        ```
      </Tab>
    </Tabs>

    将 `YOUR_API_KEY` 替换为你的 BetterToken API Key。Droid 支持在 JSON 配置中通过 `${BETTERTOKEN_API_KEY}` 读取环境变量。
  </Step>

  <Step title="编辑 Droid 配置文件">
    配置文件路径：`~/.factory/settings.json`

    ```json
    {
      "customModels": [
        {
          "displayName": "BetterToken Codex",
          "model": "YOUR_MODEL_ID",
          "baseUrl": "{{openai-base-url}}",
          "apiKey": "${BETTERTOKEN_API_KEY}",
          "provider": "openai"
        }
      ]
    }
    ```

    将 `YOUR_MODEL_ID` 替换为从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **受支持提供商的模型 ID**。
  </Step>

  <Step title="启动 Droid 并选择模型">
    ```bash
    cd /path/to/your/project
    droid
    ```

    在 Droid 中输入 `/model`，选择刚添加的 **BetterToken Codex**。Factory 会监听配置文件变化；如果模型列表没有刷新，再退出并重新启动 Droid。
  </Step>

  <Step title="发送测试任务">
    先发送一个小型任务，例如“解释当前项目的目录结构”。确认 Droid 能返回结果后，再进行跨文件修改或长时间 agent 任务。
  </Step>
</Steps>

<Note>
  `provider` 必须填写 `openai`。在 Factory 的 BYOK 配置中，这个值表示使用 OpenAI Responses API；Base URL 使用 `{{openai-base-url}}`，Model ID 必须来自 **受支持提供商**。
</Note>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 现象 | 检查方法 |
| --- | --- |
| `/model` 中没有自定义模型 | 检查 `settings.json` 是否为有效 JSON，并确认 `model`、`baseUrl`、`apiKey`、`provider` 四个字段都存在 |
| `Invalid provider` | `provider` 使用小写的 `"openai"`，不要填写界面展示名称 |
| `401` 或 `403` | 重新复制 API Key，确认启动 Droid 的终端能读取 `BETTERTOKEN_API_KEY`，并检查账户余额 |
| `404` 或 Model not found | Base URL 使用 `{{openai-base-url}}`；从模型广场重新复制当前 GPT 模型 ID |
| 修改配置后仍显示旧模型 | 再次打开 `/model`；如果列表仍未刷新，完全退出并重启 Droid |

### 常见问题

### 为什么要选择 受支持提供商？

Droid 的 `provider: "openai"` 使用 OpenAI Responses API。BetterToken 的 受支持提供商提供对应的 OpenAI-compatible endpoint 和模型 ID。

### 需要配置额外 headers 吗？

普通 BetterToken 接入不需要额外 headers。只有你的其他网关明确要求租户、路由或审计 header 时，才按该服务的文档添加。

### 如何查看模型价格和用量？

模型价格以<a href={"{{model-plaza-url}}"}>模型广场</a>实时信息为准。请求用量和余额可在 BetterToken Dashboard 查看。
