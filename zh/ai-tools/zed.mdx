在 Zed 的 **Agent Settings** 中添加 OpenAI-compatible provider，填写 BetterToken API Key、Base URL 和 Model ID。通过设置页保存的 API Key 会存入系统 Keychain，不会写入 `settings.json`。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| Provider | `BetterToken` |
| API Key | `YOUR_API_KEY` |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## 准备工作

- 安装当前版本的 [Zed](https://zed.dev/docs)
- <a href={"{{register-url}}"}>创建 BetterToken API Key</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制 `YOUR_MODEL_ID`

## 安装

从 [Zed 官网](https://zed.dev)安装或更新到当前版本。启动 Zed 后，再按下方步骤打开 Agent 设置。

## 手动配置

<Steps>
  <Step title="添加 OpenAI-compatible provider">
    点击 **Add Provider**，选择 **OpenAI Compatible**，Provider Name 填写 `BetterToken`。
  </Step>

  <Step title="填写连接信息">

    | 配置项 | 值 |
    | --- | --- |
    | API URL | `{{openai-base-url}}` |
    | API Key | `YOUR_API_KEY` |
    | Model ID | `YOUR_MODEL_ID` |

    API URL 只填写 Base URL。Zed 会自行请求 Chat Completions endpoint。
  </Step>

  <Step title="保存 API Key">
    在 Zed 设置页中保存 provider。Zed 会把 API Key 存入本机系统 Keychain，不会把它写入 `settings.json`。
  </Step>

  <Step title="选择模型">
    打开 Agent Panel 的模型选择器，选择 `BetterToken` 下的 `YOUR_MODEL_ID`。
  </Step>
</Steps>

<Warning>
  不要把 `YOUR_API_KEY` 写进 `settings.json`、项目文件或 Git 仓库。
</Warning>

### 可选：使用 `settings.json` 声明 provider 和模型

如果你需要用文件管理模型声明，请打开 `zed: open settings file`，只写 provider、`api_url` 和模型信息：

```json
{
  "language_models": {
    "openai_compatible": {
      "BetterToken": {
        "api_url": "{{openai-base-url}}",
        "available_models": [
          {
            "name": "YOUR_MODEL_ID",
            "display_name": "YOUR_MODEL_ID",
            "max_tokens": 128000
          }
        ]
      }
    }
  }
}
```

`max_tokens` 是 Zed 要求的模型上下文窗口声明。请按你选择的模型能力调整该数值。API Key 仍应在 **Agent Settings** 中输入，由系统 Keychain 保存。

## 验证连接

1. 在 Agent Panel 选择 `BetterToken / YOUR_MODEL_ID`。
2. 发送一条简短测试消息。
3. Zed 正常返回内容且没有认证或模型错误，即表示配置成功。

修改 provider 或模型配置后，请完全退出并重新启动 Zed。

## 切换模型

在 Agent Panel 的模型选择器中选择另一个 BetterToken 模型。新增 Model ID 时，先从<a href={"{{model-plaza-url}}"}>模型广场</a>复制当前值，再更新 provider 设置或 `available_models`。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 在 Agent Settings 中重新输入 BetterToken API Key，确认没有首尾空格。 |
| `404` | API URL 应为 `{{openai-base-url}}`，不要追加 `/chat/completions`。 |
| `model not found` | 从模型广场重新复制 `YOUR_MODEL_ID`。 |
| 配置未生效 | 保存 provider，完全退出并重新启动 Zed。 |
| 使用了旧 Key | 检查并移除可能覆盖 Keychain 的 provider 环境变量，然后重启 Zed。 |

## 技术说明

<Accordion title="Keychain、配置文件与 endpoint">
  Zed 通过 OpenAI-compatible provider 请求 BetterToken。设置页保存的 Key 位于系统 Keychain；`settings.json` 只声明 provider、`api_url` 和模型。Base URL 使用 `{{openai-base-url}}`，Zed 会自行拼接 Chat Completions 路径。
</Accordion>
