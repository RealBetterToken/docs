OpenCode 使用 `@ai-sdk/openai-compatible` 接入 BetterToken。Provider 名称填写 **BetterToken** 或 **OpenAI Compatible**；GPT、Kimi、GLM 是 BetterToken 内的模型提供商，不是 OpenCode provider 名称。配置 Kimi K3 时，请使用单独的 [Kimi K3 API 接入 OpenCode 指南](/zh/faq/opencode/kimi-k3-api)。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## 准备工作

- 安装最新版 OpenCode
- <a href={"{{register-url}}"}>创建 BetterToken API Key</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>或 Key 的 **Setup** 弹窗复制 Model ID

## 命令行配置

BetterToken Automatic setup 脚本会创建或更新 OpenCode 的 BetterToken provider。脚本需要 Node.js；如果没有通过参数提供 API Key 或 Model ID，运行时会提示你输入。

<Tabs>
  <Tab title="macOS / Linux">

    curl -fsSL "{{install-opencode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">

    ```
  </Tab>

运行后选择 `bettertoken/YOUR_MODEL_ID`。OpenCode 已经打开时，请重启后再验证。

## 手动配置

### 方式一：使用 /connect 保存凭证

启动 OpenCode，运行：

```text
/connect
```

选择 **Other**，provider id 填 `bettertoken`，再输入 `YOUR_API_KEY`。OpenCode 将凭证保存在本机认证存储中。

### 方式二：配置 JSON

全局配置文件是 `~/.config/opencode/opencode.json`；项目级可以在项目根目录使用 `opencode.json`。

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "{{openai-base-url}}"
      },
      "models": {
        "YOUR_MODEL_ID": {
          "name": "YOUR_MODEL_ID"
        }
      }
    }
  }
}
```

如果不使用 `/connect`，可以在 `options` 中添加 `"apiKey": "YOUR_API_KEY"`。不要把包含真实 Key 的配置提交到 Git。

## 验证连接

在项目目录运行 `opencode`，选择 `bettertoken/YOUR_MODEL_ID` 并发送一条简短消息。能够返回内容即表示配置成功。修改 JSON 后需要重启 OpenCode。

## 切换模型

在 `provider.bettertoken.models` 中加入新的 `YOUR_MODEL_ID`，同时更新顶层 `model`，保存后重启。

## 常见错误

| 错误 | 处理方式 |
| --- | --- |
| `401` | 重新执行 `/connect`，或检查 `apiKey`。 |
| `404` | `baseURL` 只填 `{{openai-base-url}}`，不要追加 `/chat/completions`。 |
| 找不到模型 | 确认顶层 `model` 与 `models` 中的 ID 完全一致。 |
| 配置未生效 | 检查项目级 `opencode.json` 是否覆盖全局配置，并重启 OpenCode。 |
