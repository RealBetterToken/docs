本页只适用于 **Kodacode / Koda**，不适用于 MonkeyCode。要在 Kodacode 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。如果错误发生在 MonkeyCode，请使用[单独的 MonkeyCode 指南](/zh/ai-tools/monkeycode)。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 已安装 VS Code
- 已安装 Kodacode / Koda 插件
- 所选 Model ID 来自 **受支持提供商**

## 安装

安装或打开 Kodacode，然后继续完成下方手动配置。

## 手动配置

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

<Steps>
  <Step title="打开 Koda 面板并添加模型">
    打开 VS Code 左侧的 **KODA** 面板，点击输入框下方的模型下拉菜单，然后选择 **Добавить модель: Agent** / **Add model: Agent**。

      />
    </Frame>
  </Step>

  <Step title="填写 OpenAI-compatible 模型配置">
    在添加模型窗口中，按下面方式填写：

    | 配置项 | 推荐值 |
    | --- | --- |
    | Provider | `Any OpenAI-compatible API` |
    | API Base | `{{openai-base-url}}/` |
    | Model ID | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 受支持提供商的模型 ID，例如 `YOUR_MODEL_ID` |
    | API Key | 你的 BetterToken API Key |

    填写完成后，点击 **Подключить** / **Connect**。

    <Frame>
      <img
        src="/images/kodacode/add-openai-compatible-model.png"

  </Step>

  <Step title="确认模型已生效">

  </Step>

  <Step title="检查 config.yaml">
    Kodacode 会把配置写入本机的 `~/.koda/config.yaml`。你可以打开该文件确认模型已经写入。

### config.yaml 示例

下面是可以对照检查的完整结构。请把 `YOUR_API_KEY` 替换为你的 BetterToken API Key，不要把真实 API Key 提交到仓库。

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: YOUR_MODEL_ID
    provider: openai
    model: YOUR_MODEL_ID
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  如果你使用的模型不是 `YOUR_MODEL_ID`，请同时修改 `name` 和 `model`，保持它们与<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商的模型 ID 一致。
</Note>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 检查 BetterToken API Key，并删除首尾空格。 |
| `404` | 检查 Base URL，不要附加具体 endpoint 路径。 |
| `model not found` | 从模型广场重新复制当前 Model ID。 |
| 配置未生效 | 保存配置，并完全退出后重新启动工具。 |


- 如果连接失败，先确认 **API Base** 是否为 `{{openai-base-url}}/`，并保留末尾 `/`。
- 如果模型不可用，确认 **Model ID** 是否来自 受支持提供商。
- 如果鉴权失败，重新复制 API Key，避免多复制空格或换行。
- 如果修改 `config.yaml` 后没有生效，重启 VS Code 或执行 **Developer: Reload Window**。
- 接入 BetterToken 时通常不需要额外设置 `User-Agent` 或其他 headers。
