Kodacode 的 VS Code 插件可以在聊天、Agent 和编辑场景中使用模型。接入 BetterToken 时，请添加一个 **Any OpenAI-compatible API** 模型，并使用 GPT 分组 API Key。

<Info>
  本文以 VS Code 插件为例。Kodacode 官方安装文档说明，VS Code 版本需要 `1.75` 或更新版本，扩展 ID 为 `Koda.koda`。
</Info>

## 前置条件

- 已安装 VS Code
- 已安装 Kodacode / Koda 插件
- 已获取 BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）
- API Key 属于 **GPT 分组**
- 已从<a href={"{{model-plaza-url}}"}>模型广场</a>复制要使用的 GPT 分组模型 ID，例如 `gpt-5.5`

## 配置步骤

<Steps>
  <Step title="打开 Koda 面板并添加模型">
    打开 VS Code 左侧的 **KODA** 面板，点击输入框下方的模型下拉菜单，然后选择 **Добавить модель: Agent** / **Add model: Agent**。

    <Frame>
      <img
        src="/images/kodacode/select-model-menu.png"
        alt="在 Koda 面板的模型下拉菜单中选择 Add model: Agent。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="填写 OpenAI-compatible 模型配置">
    在添加模型窗口中，按下面方式填写：

    | 配置项 | 推荐值 |
    | --- | --- |
    | Provider | `Any OpenAI-compatible API` |
    | API Base | `{{openai-base-url}}/` |
    | Model ID | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 GPT 分组模型 ID，例如 `gpt-5.5` |
    | API Key | 你的 BetterToken API Key |

    填写完成后，点击 **Подключить** / **Connect**。

    <Frame>
      <img
        src="/images/kodacode/add-openai-compatible-model.png"
        alt="在 Kodacode 添加模型窗口中选择 Any OpenAI-compatible API，并填写 API Base、Model ID 和 API Key。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="确认模型已生效">
    连接完成后，在 Koda 输入框下方的模型选择器中选择刚添加的模型，例如 `gpt-5.5`。发送一条简单消息，确认能够正常返回结果。
  </Step>

  <Step title="检查 config.yaml">
    Kodacode 会把配置写入本机的 `~/.koda/config.yaml`。你可以打开该文件确认模型已经写入。

    <Frame>
      <img
        src="/images/kodacode/config-yaml-result.png"
        alt="Kodacode config.yaml 中已经写入 OpenAI-compatible 模型配置。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## config.yaml 示例

下面是可以对照检查的完整结构。请把 `YOUR_API_KEY` 替换为你的 BetterToken API Key，不要把真实 API Key 提交到仓库。

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: gpt-5.5
    provider: openai
    model: gpt-5.5
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  如果你使用的模型不是 `gpt-5.5`，请同时修改 `name` 和 `model`，保持它们与<a href={"{{model-plaza-url}}"}>模型广场</a>中的 GPT 分组模型 ID 一致。
</Note>

## 排障提示

- 如果连接失败，先确认 **API Base** 是否为 `{{openai-base-url}}/`，并保留末尾 `/`。
- 如果模型不可用，确认 **Model ID** 是否来自 GPT 分组。
- 如果鉴权失败，重新复制 API Key，避免多复制空格或换行。
- 如果修改 `config.yaml` 后没有生效，重启 VS Code 或执行 **Developer: Reload Window**。
- 接入 BetterToken 时通常不需要额外设置 `User-Agent` 或其他 headers。
