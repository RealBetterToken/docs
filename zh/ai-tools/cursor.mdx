要在 Cursor 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 已安装 Cursor（前往 [Cursor 官网](https://www.cursor.com) 下载）

## 安装

从 [Cursor 官网](https://www.cursor.com)下载并安装当前版本。安装后登录支持自定义模型的 Cursor 账号，再进入下方配置。

<Warning>
  Cursor 仅支持订阅高级会员及以上的用户配置自定义模型。如果你的账号或当前客户端版本没有显示自定义模型、API Key 或 Base URL 选项，请先确认 Cursor 账号套餐与客户端版本。
</Warning>

<Warning>
  **已知问题：** **Override OpenAI Base URL** 是全局设置。开启后会影响 Cursor 中所有已配置的 API Key，包括 Cursor 自带模型使用的 Anthropic / GPT Key。Cursor 官方社区已确认这个问题：设置 Base URL 后，所有 API Key 和模型都会受影响（[社区帖](https://forum.cursor.com/t/cursor-models-fail-when-using-byok-openai-key-with-overridden-base-url-glm-4-7/147218)）。

  如果开启 **Override OpenAI Base URL** 后 Cursor 自带的 Claude / GPT 模型停止工作，请在不使用 BetterToken 时关闭 **Override OpenAI Base URL**。Cursor 目前不支持按模型设置不同 Base URL，相关能力仍在功能请求中（[feature request](https://forum.cursor.com/t/custom-base-urls-for-each-custom-model/147219)）。
</Warning>

## 手动配置

主要通过 Cursor 的设置界面完成以下配置，不需要手动编辑配置文件。

| Cursor 字段 | 填写内容 |
| --- | --- |
| **Override OpenAI Base URL** | 打开 |
| **Base URL** | `{{openai-base-url}}` |
| **OpenAI API Key** | BetterToken API Key |
| 自定义模型 | 从受支持提供商复制的完整 Model ID |

### 配置步骤

<Steps>
  <Step title="打开模型配置页面">
    在 Cursor 中，点击左下角 **Settings**，进入设置界面后选择 **Models**。向下找到 **API Keys** 区域。

    <Frame>
      <img
        src="/images/cursor/settings-api-key.png"
        alt="Cursor 设置页中，依次打开 Settings、Models、API Keys，并填写 OpenAI API Key 与 Override OpenAI Base URL。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="填写 Base URL 和 API Key">
    在 **API Keys** 区域按下面顺序配置：

    1. 打开 **Override OpenAI Base URL**
    2. 在 Base URL 输入框中填写 `{{openai-base-url}}`
    3. 在 **OpenAI API Key** 中填写你的 BetterToken API Key
    4. 填完 URL 和 Key 后，再打开 **OpenAI API Key** 开关

    先填写 Key，再打开开关。这样 Cursor 会弹出认证确认窗口。
  </Step>

  <Step title="启用 OpenAI API Key">
    在确认窗口中点击 **Enable OpenAI API Key**。

    <Frame>
      <img
        src="/images/cursor/enable-openai-api-key.png"
        alt="Cursor 弹出 Enable OpenAI API Key 确认窗口，需要点击 Enable OpenAI API Key。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="刷新模型列表并启用模型">
    回到 **Models** 区域后，一定要先点击右侧的刷新按钮。等待模型列表刷新完成后，再选择模型。

    请选择与 OpenAI-compatible endpoint 兼容的模型。请从模型广场复制 受支持提供商的模型 ID，并打开对应模型右侧的开关。

    <Frame>
      <img
        src="/images/cursor/models-refresh-select.png"
        alt="Cursor Models 区域中，点击刷新按钮刷新模型列表，并打开可用模型右侧的开关。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="回到对话界面并关闭 Auto">
    配置完成后回到 Cursor 对话界面，点击输入框下方的模型选择器。如果 **Auto** 处于开启状态，请先关闭 **Auto**。

    <Frame>
      <img
        src="/images/cursor/chat-disable-auto.png"
        alt="Cursor 对话界面中打开模型选择器，并关闭 Auto 模式。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="选择模型并开始对话">
    在模型选择器中选择刚启用的 受支持提供商的模型，然后开始对话。

    <Frame>
      <img
        src="/images/cursor/chat-select-model.png"
        alt="Cursor 对话界面中选择 YOUR_MODEL_ID 等已启用模型后开始对话。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

### 自定义 API 和 API Key 常见错误

更换模型或 API Key 前，请先对照 [Cursor 自定义 OpenAI API 配置](/zh/faq/cursor/custom-openai-api)核对当前设置。

### Cursor 没有显示自定义 API、API Key 或 Base URL

先检查 Cursor 账号套餐和客户端版本。自定义模型只对支持的付费套餐开放。更新 Cursor 后，再次打开 **Settings** → **Models**。

### API Key 无法启用或验证失败

先填写 Base URL `{{openai-base-url}}` 和 API Key，再打开 **OpenAI API Key** 开关。Base URL 不要附加 `/chat/completions`，也不要填写与当前 endpoint 不兼容的 Model ID。

### 刷新后没有需要的模型

确认 所选 Model ID 来自 **受支持提供商**，等待刷新完成后，只启用与当前 endpoint 兼容的模型。当前模型 ID 以模型广场为准。

### Cursor 自带模型停止工作

**Override OpenAI Base URL** 是全局设置。不使用 BetterToken 时，请关闭这个开关，让 Cursor 恢复使用自己的 Base URL。

### 对话中选错模型

打开模型选择器并关闭 **Auto**，再手动选择已启用的模型。
