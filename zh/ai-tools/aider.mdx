Aider 可以连接 OpenAI-compatible API。要使用 BetterToken，请设置 `OPENAI_API_BASE` 和 `OPENAI_API_KEY`，然后以 `openai/模型 ID` 的格式启动 Aider。

<Info>
  Aider 使用 BetterToken 的 OpenAI-compatible API。Base URL 填写 `{{openai-base-url}}`，并使用 **GPT 分组** API Key 和模型。
</Info>

## 准备工作

- 已获取 BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 已从<a href={"{{model-plaza-url}}"}>模型广场</a>复制当前可用的 **GPT 分组**模型 ID
- 已安装 Python

## 安装 Aider

在终端中执行：

```bash
python -m pip install aider-install
aider-install
```

安装完成后，运行以下命令确认 Aider 可用：

```bash
aider --help
```

## 为当前终端配置 BetterToken

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"

    cd /path/to/your/project
    aider --model openai/gpt-5.6-sol
    ```
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell
    setx OPENAI_API_BASE "{{openai-base-url}}"
    setx OPENAI_API_KEY "YOUR_API_KEY"
    ```

    执行 `setx` 后，请关闭并重新打开 PowerShell，再进入项目目录并运行：

    ```powershell
    aider --model openai/gpt-5.6-sol
    ```
  </Tab>
</Tabs>

将 `YOUR_API_KEY` 替换为你的 **GPT 分组** API Key。`gpt-5.6-sol` 只是示例；请改为模型广场中当前可用的 **GPT 分组**模型 ID，并保留 `openai/` 前缀。

## 使用 .env 持久保存配置

如果不想每次打开终端都设置变量，可在项目 Git 根目录创建 `.env`：

```dotenv
OPENAI_API_BASE={{openai-base-url}}
OPENAI_API_KEY=YOUR_API_KEY
AIDER_MODEL=openai/gpt-5.6-sol
```

将 `.env` 加入 `.gitignore`，避免 API Key 被提交。之后进入项目目录并直接运行：

```bash
aider
```

需要为某个项目使用其他文件时，可显式指定：

```bash
aider --env-file ./aider-bettertoken.env
```

## 切换模型

将启动命令中的模型替换为当前可用的 **GPT 分组**模型 ID：

```bash
aider --model openai/YOUR_GPT_MODEL_ID
```

`openai/` 前缀不能省略。API Key 与模型必须属于同一个 **GPT 分组**。

## 常见错误

| 现象 | 处理方式 |
| --- | --- |
| `401`、`Unauthorized` 或 `Invalid API key` | 检查 `OPENAI_API_KEY`，确认使用的是 **GPT 分组** API Key，且没有多余空格。 |
| `model not found` 或模型不可用 | 从模型广场重新复制当前 **GPT 分组**模型 ID，并以 `openai/模型 ID` 格式传给 Aider。 |
| 请求地址错误或 `404` | 确认 `OPENAI_API_BASE` 是 `{{openai-base-url}}`，不要填写 `/chat/completions`。 |
| 在 Windows 设置后仍读取不到变量 | `setx` 只对新打开的终端生效。关闭当前 PowerShell 后重新打开。 |
| Aider 提示不认识模型 | 先检查模型 ID 和 API Key 分组。Aider 可能对新模型显示警告，但模型仍需使用模型广场中的当前 ID。 |

## 配置 FAQ

**Aider 的 Base URL 应该填写哪个地址？**

填写 `{{openai-base-url}}`。这是 BetterToken 的 OpenAI-compatible Base URL。

**为什么模型名前要加 `openai/`？**

Aider 用这个前缀识别 OpenAI-compatible 模型。省略前缀可能导致它使用错误的 provider。

**可以把 API Key 写进 `.aider.conf.yml` 吗？**

不建议。优先使用环境变量或已加入 `.gitignore` 的 `.env`，避免 API Key 随项目文件泄露。
