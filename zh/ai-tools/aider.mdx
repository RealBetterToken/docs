## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>

### 工具特定要求

- 已安装 Python

## 安装

### 安装 Aider

在终端中执行：

```bash
python -m pip install aider-install
aider-install
```

安装完成后，运行以下命令确认 Aider 可用：

```bash
aider --help
```

## 手动配置

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 为当前终端配置 BetterToken

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"

    cd /path/to/your/project
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell
    setx OPENAI_API_BASE "{{openai-base-url}}"
    setx OPENAI_API_KEY "YOUR_API_KEY"
    ```

    执行 `setx` 后，请关闭并重新打开 PowerShell，再进入项目目录并运行：

    ```powershell
    aider --model openai/YOUR_MODEL_ID
    ```
  </Tab>
</Tabs>

将 `YOUR_API_KEY` 替换为你的 BetterToken API Key。`YOUR_MODEL_ID` 只是示例；请改为模型广场中当前可用的 **受支持提供商的模型 ID**，并保留 `openai/` 前缀。

### 使用 .env 持久保存配置

如果不想每次打开终端都设置变量，可在项目 Git 根目录创建 `.env`：

```dotenv
OPENAI_API_BASE={{openai-base-url}}
OPENAI_API_KEY=YOUR_API_KEY
AIDER_MODEL=openai/YOUR_MODEL_ID
```

将 `.env` 加入 `.gitignore`，避免 API Key 被提交。之后进入项目目录并直接运行：

```bash
aider
```

需要为某个项目使用其他文件时，可显式指定：

```bash
aider --env-file ./aider-bettertoken.env
```

### 可选：使用 .aider.conf.yml

如果只想保存非敏感设置，可在用户目录或项目根目录创建 `.aider.conf.yml`：

```yaml
model: openai/YOUR_MODEL_ID
openai-api-base: "{{openai-base-url}}"
```

API Key 仍通过 `OPENAI_API_KEY` 环境变量提供，不要写入共享 YAML 文件。

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

将启动命令中的模型替换为当前可用的 **受支持提供商的模型 ID**：

```bash
aider --model openai/YOUR_MODEL_ID
```

`openai/` 前缀不能省略。API Key 与模型必须属于当前配置使用的接口。

## 常见错误

| 现象 | 处理方式 |
| --- | --- |
| `401`、`Unauthorized` 或 `Invalid API key` | 检查 `OPENAI_API_KEY`，确认使用的是 BetterToken API Key，且没有多余空格。 |
| `model not found` 或模型不可用 | 从模型广场重新复制当前 **受支持提供商的模型 ID**，并以 `openai/模型 ID` 格式传给 Aider。 |
| 请求地址错误或 `404` | 确认 `OPENAI_API_BASE` 是 `{{openai-base-url}}`，不要填写 `/chat/completions`。 |
| 在 Windows 设置后仍读取不到变量 | `setx` 只对新打开的终端生效。关闭当前 PowerShell 后重新打开。 |
| Aider 提示不认识模型 | 先检查模型 ID 和 提供商。Aider 可能对新模型显示警告，但模型仍需使用模型广场中的当前 ID。 |

### 配置 FAQ

**Aider 的 Base URL 应该填写哪个地址？**

填写 `{{openai-base-url}}`。这是 BetterToken 的 OpenAI-compatible Base URL。

**为什么模型名前要加 `openai/`？**

Aider 用这个前缀识别 OpenAI-compatible 模型。省略前缀可能导致它使用错误的 provider。

**可以把 API Key 写进 `.aider.conf.yml` 吗？**

不建议。优先使用环境变量或已加入 `.gitignore` 的 `.env`，避免 API Key 随项目文件泄露。
