Hermes Agent 是面向本地终端工作流的 AI Agent。它可以作为日常开发助手使用，也可以结合技能、MCP、任务调度和子 Agent 处理更长的自动化任务。

接入 BetterToken 时，请使用 **GPT 分组** API Key，并通过 OpenAI-compatible endpoint 调用模型。

<Info>
  本文仅覆盖 Hermes Agent 的 GPT 分组接入方式。模型 ID 请以<a href={"{{model-plaza-url}}"}>模型广场</a>显示为准。
</Info>

## 前置条件

- 已获取 BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）
- API Key 属于 **GPT 分组**
- 已从<a href={"{{model-plaza-url}}"}>模型广场</a>复制要使用的 GPT 分组模型 ID
- macOS、Linux 或 Windows WSL2 环境

## 安装 Hermes Agent

<Tabs>
  <Tab title="macOS / Linux / WSL2">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
    ```
  </Tab>

  <Tab title="Windows">
    Windows 用户建议优先使用 WSL2。原生 PowerShell 支持取决于 Hermes Agent 当前版本；如果你使用原生 Windows 环境，请按 Hermes 安装器的当前提示操作。
  </Tab>
</Tabs>

## 配置步骤

<Tabs>
  <Tab title="交互式配置">
    <Steps>
      <Step title="运行模型选择器">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="选择 OpenAI 或 OpenAI Compatible provider">
        在 provider 列表中，选择 **OpenAI** 或 **OpenAI Compatible**。
      </Step>

      <Step title="填写 BetterToken 配置">
        按提示依次输入：

        - **Base URL**：`{{openai-base-url}}`
        - **API Key**：你的 BetterToken API Key
        - **Model**：从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **GPT 分组模型 ID**
      </Step>

      <Step title="重启 Hermes Agent">
        修改配置后，请退出当前 Hermes Agent 会话，再重新启动。
      </Step>

      <Step title="启动 Hermes Agent">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="命令行配置">
    如果你更适合复制命令，可以直接写入 Hermes Agent 配置。

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_BETTERTOKEN_API_KEY"
    hermes config set llm.model "YOUR_GPT_MODEL_ID"
    ```

    将 `YOUR_BETTERTOKEN_API_KEY` 替换为你的 BetterToken API Key，将 `YOUR_GPT_MODEL_ID` 替换为<a href={"{{model-plaza-url}}"}>模型广场</a>中的 GPT 分组模型 ID。

    配置完成后运行：

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="环境变量">
    如果你不想把 API Key 写入 Hermes Agent 配置，可以在当前 shell 中导出环境变量。

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_BETTERTOKEN_API_KEY"
    export HERMES_MODEL="YOUR_GPT_MODEL_ID"
    hermes
    ```

    这组环境变量只对当前 shell 会话生效。新开终端后需要重新导出，或写入你自己的 shell profile。
  </Tab>
</Tabs>

## 功能速查

| 能力 | 用途 |
| --- | --- |
| Terminal UI | 在终端中直接和 Agent 交互 |
| Skills | 为重复任务沉淀可复用流程 |

## 从 OpenClaw 迁移

如果你已经使用 OpenClaw，可以先在 Hermes Agent 当前版本中检查是否提供迁移命令。迁移前建议先做 dry run。

```bash
hermes claw migrate --dry-run
```

确认无误后再执行正式迁移：

```bash
hermes claw migrate
```

迁移后仍建议检查 Hermes Agent 中的 **Base URL**、API Key 和模型 ID，确保它们分别对应 `{{openai-base-url}}`、你的 BetterToken API Key，以及 GPT 分组模型 ID。

## 排障提示

- 无响应或请求失败时，先确认 **Base URL** 是否正好是 `{{openai-base-url}}`。这里通常不要再拼接 `/chat/completions`。
- 报模型不存在时，确认 **Model** 是否来自<a href={"{{model-plaza-url}}"}>模型广场</a>中的 GPT 分组。
- 报鉴权失败时，确认 API Key 没有复制空格，并且属于 **GPT 分组**。
- 修改配置后仍走旧模型时，退出当前 Hermes Agent 会话并重新运行 `hermes`。
- 接入 BetterToken 时通常不需要额外设置 `User-Agent` 或其他 headers。只有当你还接了自定义网关、租户路由、审计或缓存服务时，再按对应上游服务的官方文档补充。

<Note>
  请不要把真实 API Key 提交到仓库。团队共享配置时，优先使用环境变量或本机配置。
</Note>
