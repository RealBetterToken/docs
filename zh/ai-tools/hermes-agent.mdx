要在 Hermes Agent 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 所选 Model ID 来自 **受支持提供商**
- macOS、Linux、Windows 10/11 或 WSL2 环境
- 用于 Hermes Agent 工具调用的模型至少具备 64K 上下文窗口

## 安装

### 安装 Hermes Agent

<Tabs>
  <Tab title="Desktop（macOS / Windows）">
    Hermes 官方推荐 macOS 和 Windows 用户使用 Desktop 安装器。前往 [Hermes Desktop 下载页](https://hermes-agent.nousresearch.com/)，下载并运行对应系统的安装程序。
  </Tab>

  <Tab title="Linux / macOS / WSL2">
    ```bash
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    ```

    安装完成后，请打开新终端或重新加载 shell，再运行 `hermes`。
  </Tab>

  <Tab title="Windows PowerShell">
    Hermes Agent 原生支持 Windows 10 和 Windows 11。打开 PowerShell 或 Windows Terminal，然后运行：

    ```powershell
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)
    ```

    安装不需要管理员权限。完成后请重新打开 PowerShell，让更新后的用户 PATH 生效。
  </Tab>
</Tabs>

验证安装：

```bash
hermes --version
hermes doctor
```

<Note>
  WSL2 仍受支持，但不是必需条件。只有在你明确需要 Linux 环境或 Web Dashboard 的内嵌终端面板时才需要选择 WSL2。
</Note>

## 手动配置

优先使用 Hermes Agent 的交互式模型配置界面。只有在需要手动设置时，才直接编辑配置文件。

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 配置步骤

<Tabs>
  <Tab title="交互式配置">
    <Steps>
      <Step title="运行模型选择器">
        先退出正在运行的 Hermes 聊天，再执行：

        ```bash
        hermes model
        ```
      </Step>

      <Step title="选择 Custom endpoint">
        在 provider 列表中选择 **Custom endpoint (self-hosted / VLLM / etc.)**。
      </Step>

      <Step title="填写 BetterToken 配置">
        按提示依次输入：

        - **Base URL**：`{{openai-base-url}}`
        - **API Key**：你的 BetterToken API Key
        - **Model**：从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **受支持提供商的模型 ID**

        如果 Hermes 询问 API mode，请选择 OpenAI-compatible Chat Completions 选项。如果需要填写 context length，请使用该模型公布的值，并确保至少为 64K。
      </Step>

      <Step title="启动 Hermes Agent">
        ```bash
        hermes --tui
        ```

        你也可以运行 `hermes` 使用经典终端界面。
      </Step>
    </Steps>
  </Tab>

  <Tab title="配置文件">
    交互式配置会自动验证并保存 endpoint，因此更加稳妥。如需手动配置，请将非敏感的模型设置写入 `~/.hermes/config.yaml`：

    ```yaml
    model:
      default: YOUR_MODEL_ID
      provider: custom
      base_url: "{{openai-base-url}}"
    ```

    将 API Key 单独写入 `~/.hermes/.env`：

    ```dotenv
    OPENAI_API_KEY=YOUR_API_KEY
    ```

    在原生 Windows 中，这两个文件位于 `%LOCALAPPDATA%\hermes\`，而不是 `~/.hermes/`。替换 `YOUR_MODEL_ID` 和 `YOUR_API_KEY` 后，先运行 `hermes doctor`，再启动 Hermes。
  </Tab>
</Tabs>

## 验证连接

使用 `hermes --tui` 或 `hermes` 启动，然后发送以下短消息：

```text
Reply with HERMES_OK only. Do not use tools.
```

如果 Hermes 返回 `HERMES_OK`，且没有认证、endpoint 或 Model ID 错误，就说明连接成功。接下来先完成一个小型只读任务，再启用 gateway、定时任务或其他工具。

## 切换模型

在聊天外运行 `hermes model`，可以新增或重新配置 provider。在聊天中使用 `/model`，可以切换已经配置好的 provider 和模型。请使用<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 检查 BetterToken API Key，并删除首尾空格。 |
| `404` | 检查 Base URL，不要附加具体 endpoint 路径。 |
| `model not found` | 从模型广场重新复制当前 Model ID。 |
| `hermes: command not found` | 安装后打开新终端，再检查 PATH。 |
| 更新后配置错误 | 运行 `hermes config check`；如果提示迁移，再运行 `hermes config migrate`。 |


### 排障提示

- 无响应或请求失败时，先确认 **Base URL** 是否正好是 `{{openai-base-url}}`。这里通常不要再拼接 `/chat/completions`。
- 报模型不存在时，确认 **Model** 是否来自<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商。
- 报鉴权失败时，确认 API Key 没有复制空格，并检查 Model ID 来自 **受支持提供商**。
- 仍在使用旧模型时，退出聊天，运行 `hermes model` 重新保存 custom endpoint，再开始新聊天。
- 接入 BetterToken 时通常不需要额外设置 `User-Agent` 或其他 headers。只有当你还接了自定义网关、租户路由、审计或缓存服务时，再按对应上游服务的官方文档补充。

<Note>
  请不要把真实 API Key 提交到仓库。团队共享配置时，优先使用环境变量或本机配置。
</Note>

## 技术说明

<Accordion title="协议、endpoint 与 provider 内部字段">
  本页配置使用 `{{openai-base-url}}`。工具会自行拼接 OpenAI-compatible endpoint；除非具体字段明确要求，否则不要在 Base URL 后附加 `/chat/completions` 或 `/responses`。

### 从 OpenClaw 迁移

如果你已经使用 OpenClaw，可以先在 Hermes Agent 当前版本中检查是否提供迁移命令。迁移前建议先做 dry run。

```bash
hermes claw migrate --dry-run
```

确认无误后再执行正式迁移：

```bash
hermes claw migrate
```

迁移后仍建议检查 Hermes Agent 中的 **Base URL**、API Key 和模型 ID，确保它们分别对应 `{{openai-base-url}}`、你的 BetterToken API Key，以及 受支持提供商的模型 ID。
</Accordion>
