要在 Hermes Agent 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 所选 Model ID 来自 **受支持提供商**
- macOS、Linux 或 Windows WSL2 环境

## 安装

### 安装 Hermes Agent

<Tabs>
  <Tab title="macOS / Linux / WSL2">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
    ```
  </Tab>

  <Tab title="Windows">
    Windows 用户建议优先使用 WSL2。原生 PowerShell 支持取决于 Hermes Agent 当前版本；如果你使用原生 Windows 环境，请按 Hermes 安装器的当前提示操作。
  </Tab>
</Tabs>

## 手动配置

主要通过 Hermes Agent 的交互式模型配置界面完成设置；命令行和环境变量方式作为可选方案保留。

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 配置步骤

<Tabs>
  <Tab title="交互式配置">
    <Steps>
      <Step title="运行模型选择器">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="选择 OpenAI 或 OpenAI Compatible provider">
        在 provider 列表中，选择 **OpenAI** 或 **OpenAI Compatible**。
      </Step>

      <Step title="填写 BetterToken 配置">
        按提示依次输入：

        - **Base URL**：`{{openai-base-url}}`
        - **API Key**：你的 BetterToken API Key
        - **Model**：从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **受支持提供商的模型 ID**
      </Step>

      <Step title="重启 Hermes Agent">
        修改配置后，请退出当前 Hermes Agent 会话，再重新启动。
      </Step>

      <Step title="启动 Hermes Agent">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="命令行配置">
    如果你更适合复制命令，可以直接写入 Hermes Agent 配置。

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_API_KEY"
    hermes config set llm.model "YOUR_MODEL_ID"
    ```

    将 `YOUR_API_KEY` 替换为你的 BetterToken API Key，将 `YOUR_MODEL_ID` 替换为<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商的模型 ID。

    配置完成后运行：

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="环境变量">
    如果你不想把 API Key 写入 Hermes Agent 配置，可以在当前 shell 中导出环境变量。

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"
    export HERMES_MODEL="YOUR_MODEL_ID"
    hermes
    ```

    这组环境变量只对当前 shell 会话生效。新开终端后需要重新导出，或写入你自己的 shell profile。
  </Tab>
</Tabs>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 检查 BetterToken API Key，并删除首尾空格。 |
| `404` | 检查 Base URL，不要附加具体 endpoint 路径。 |
| `model not found` | 从模型广场重新复制当前 Model ID。 |
| 配置未生效 | 保存配置，并完全退出后重新启动工具。 |


### 排障提示

- 无响应或请求失败时，先确认 **Base URL** 是否正好是 `{{openai-base-url}}`。这里通常不要再拼接 `/chat/completions`。
- 报模型不存在时，确认 **Model** 是否来自<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商。
- 报鉴权失败时，确认 API Key 没有复制空格，并检查 Model ID 来自 **受支持提供商**。
- 修改配置后仍走旧模型时，退出当前 Hermes Agent 会话并重新运行 `hermes`。
- 接入 BetterToken 时通常不需要额外设置 `User-Agent` 或其他 headers。只有当你还接了自定义网关、租户路由、审计或缓存服务时，再按对应上游服务的官方文档补充。

<Note>
  请不要把真实 API Key 提交到仓库。团队共享配置时，优先使用环境变量或本机配置。
</Note>

## 技术说明

### 从 OpenClaw 迁移

如果你已经使用 OpenClaw，可以先在 Hermes Agent 当前版本中检查是否提供迁移命令。迁移前建议先做 dry run。

```bash
hermes claw migrate --dry-run
```

确认无误后再执行正式迁移：

```bash
hermes claw migrate
```

迁移后仍建议检查 Hermes Agent 中的 **Base URL**、API Key 和模型 ID，确保它们分别对应 `{{openai-base-url}}`、你的 BetterToken API Key，以及 受支持提供商的模型 ID。
</Accordion>
