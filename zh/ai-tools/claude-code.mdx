使用 BetterToken API Key、Base URL `{{anthropic-base-url}}` 和你选择的 Model ID 接入 Claude Code。 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制准确的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Model | `YOUR_MODEL_ID` |

## 准备工作

- 安装最新版 [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- 安装 Node.js
- <a href={"{{register-url}}"}>创建并复制 BetterToken API Key</a>

## 安装

```bash
npm install -g @anthropic-ai/claude-code
```

## 命令行配置

BetterToken Automatic setup 脚本会写入 Claude Code 配置。脚本需要 Node.js；如果没有通过参数提供 API Key，运行时会交互式提示输入。

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-claudecode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-claudecode-provider-ps1-url}}" -OutFile "$env:TEMP\install-claudecode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-claudecode-provider.ps1"
    ```
  </Tab>
</Tabs>

运行完成后检查 `~/.claude/settings.json`（Windows 为 `%USERPROFILE%\.claude\settings.json`），然后完全重启 Claude Code。希望逐项控制配置时，使用下面的手动配置。

## 手动配置

| 系统 | 文件 |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

从<a href={"{{model-plaza-url}}"}>模型广场</a>复制准确的 Model ID。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{anthropic-base-url}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000",
    "ANTHROPIC_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "YOUR_MODEL_ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "YOUR_MODEL_ID"
  }
}
```

把 `YOUR_MODEL_ID` 替换为复制的模型 ID。`ANTHROPIC_MODEL` 设置主模型，三个 `ANTHROPIC_DEFAULT_*_MODEL` 变量分别设置 Haiku、Sonnet 和 Opus 别名。可以使用同一个模型，也可以为各角色选择不同模型。

### VS Code 扩展

扩展使用 VS Code 的 `settings.json`。添加独立的 `claudeCode.environmentVariables` 配置：

```json
{
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "{{anthropic-base-url}}"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC",
      "value": "1"
    },
    {
      "name": "API_TIMEOUT_MS",
      "value": "3000000"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_SONNET_MODEL",
      "value": "YOUR_MODEL_ID"
    },
    {
      "name": "ANTHROPIC_DEFAULT_OPUS_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

## 验证连接

进入项目目录并启动：

```bash
claude
```

发送一条简短消息。能够正常返回内容，且没有 `401`、连接失败或模型不存在错误，即表示配置成功。修改配置后需要完全重启 Claude Code。

## 切换模型

修改配置中的 Model ID 后重启 Claude Code。需要在会话中切换时，使用 `/model YOUR_MODEL_ID`。

## 常见错误

| 错误 | 处理方式 |
| --- | --- |
| `401` 或认证失败 | 检查 `ANTHROPIC_AUTH_TOKEN`，确认没有空格或过期 Key。 |
| `ConnectionRefused` | 确认 `ANTHROPIC_BASE_URL` 正好是 `{{anthropic-base-url}}`，不要添加 `/v1`。 |
| Model ID | 核对模型广场中的准确 Model ID，并填入客户端的模型设置。 |
| 配置未生效 | 检查文件路径，清除冲突的环境变量，然后完全重启 Claude Code。 |

## 技术说明

<Accordion title="协议与 endpoint">
  Claude Code 使用 Anthropic Messages。`ANTHROPIC_BASE_URL` 填写 `{{anthropic-base-url}}`，客户端会自行请求 `/v1/messages`，因此不要在 Base URL 后添加 `/v1`。
</Accordion>
