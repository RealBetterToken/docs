Roo Code 是 VS Code 的 AI 编程助手插件。接入 LLMEasy 时，请选择 OpenAI Compatible 提供商，并使用 GPT 分组模型 ID。

## 前置条件

- 已安装 VS Code
- 已获取 LLMEasy API Key（<a href={"{{register-url}}"}>注册并获取</a>）

## 安装 Roo Code

打开 VS Code，在扩展市场搜索 **Roo Code**，点击 Install 安装，安装完成后重启 VS Code。

## 配置步骤

<Steps>
  <Step title="清除冲突的环境变量">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="打开 Roo Code 设置">
    点击 Roo Code 侧边栏中的 **Settings**。
  </Step>

  <Step title="配置 API 提供商">
    按以下方式填写：

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → 你的 LLMEasy API Key
    - **Model** → 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 **GPT 分组模型 ID**
  </Step>

  <Step title="仅在官方文档明确要求时再配置额外 headers">
    我们查到的 Roo Code 官方资料强调 OpenAI-compatible / custom API 接入，但没有把额外 `User-Agent` 列为 LLMEasy 默认接入的必填项。

    如果你还接了自定义网关、租户路由或审计服务，再按对应上游服务的官方文档补充所需 headers。
  </Step>

  <Step title="保存并开始使用">
    点击 **Save** 和 **Done**，然后选择刚配置的 GPT 分组模型。
  </Step>

  <Step title="重启 Roo Code">
    修改配置后，请重启 VS Code 或重新加载 Roo Code 插件，再选择刚配置的模型。
  </Step>
</Steps>

<Note>
  Roo Code 的 OpenAI Compatible 提供商需要接口支持 OpenAI 风格 tool calling。若需额外 headers，请以 Roo Code 官方当前版本说明或上游网关要求为准，不要默认把 `User-Agent` 当作 LLMEasy 必填项。
</Note>
