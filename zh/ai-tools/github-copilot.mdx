要在 GitHub Copilot 中使用 BetterToken，请准备 API Key，填写下表中的 Base URL，并从模型广场选择当前可用的 Model ID。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| 完整请求 URL | `{{chat-completions-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

## 准备工作

- 已安装该工具的当前版本
- BetterToken API Key：<a href={"{{register-url}}"}>注册并获取</a>
- 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的 Model ID

### 工具特定要求

- 已安装最新版 VS Code
- 已安装并登录 GitHub Copilot / Copilot Chat
- 所选 Model ID 来自 **受支持提供商**
- 已确认要使用的模型 ID，例如 `YOUR_MODEL_ID`

<Warning>
  不要把真实 API Key 手动写进 `chatLanguageModels.json`。请在 VS Code 弹出的 API Key 输入框中粘贴 Key，VS Code 会自动生成 `${input:chat.lm.secret...}` 这种本机密钥引用。
</Warning>

## 安装

安装或打开 GitHub Copilot，然后继续完成下方手动配置。

## 手动配置

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| 完整请求 URL | `{{chat-completions-url}}` |
| Model | 从<a href={"{{model-plaza-url}}"}>模型广场</a>复制的当前 Model ID |

### 配置步骤

<Steps>
  <Step title="打开模型管理入口">
    在 Copilot Chat 输入框下方，点击模型选择器，然后选择 **Manage Models...**。

    <Frame>
      <img
        src="/images/github-copilot/manage-models-entry.png"
        alt="在 Copilot Chat 模型选择器中点击 Manage Models。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="添加 Custom Endpoint">
    在 **Language Models** 界面中，点击 **Add Models**，然后选择 **Custom Endpoint**。

    <Frame>
      <img
        src="/images/github-copilot/add-custom-endpoint.png"
        alt="在 Language Models 界面中点击 Add Models 并选择 Custom Endpoint。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="输入名称">
    在 **Group Name** 输入框中填写：

    ```text
    BetterToken
    ```

    然后按 **Enter**。

    <Frame>
      <img
        src="/images/github-copilot/group-name.png"
        alt="在 Group Name 输入框中填写 BetterToken。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="输入 API Key">
    接下来 VS Code 会要求输入 API Key。粘贴你的 BetterToken API Key，然后按 **Enter**。

    这一步不会显示在配置文件里。VS Code 会把 API Key 保存成本机 secret，并在 JSON 中生成类似下面的引用：

    ```json
    "apiKey": "${input:chat.lm.secret.xxxxx}"
    ```

    <Warning>
      不要把 `${input:chat.lm.secret...}` 改成真实 API Key。保持 VS Code 自动生成的 secret 引用即可。
    </Warning>
  </Step>

  <Step title="选择 API 类型">
    在 **Custom Endpoint: API Type** 中选择 **Chat Completions**。

    <Frame>
      <img
        src="/images/github-copilot/select-chat-completions.png"
        alt="在 Custom Endpoint API Type 中选择 Chat Completions。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="编辑 JSON 配置">
    VS Code 会打开 `chatLanguageModels.json`。确认或修改配置为下面结构：

    <Frame>
      <img
        src="/images/github-copilot/chat-language-models-json.png"
        alt="在 chatLanguageModels.json 中配置 BetterToken 模型 URL、toolCalling、vision 和 token 上限。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    ```json
    [
      {
        "name": "BetterToken",
        "vendor": "customendpoint",
        "apiKey": "${input:chat.lm.secret.xxxxx}",
        "apiType": "chat-completions",
        "models": [
          {
            "id": "YOUR_MODEL_ID",
            "name": "YOUR_MODEL_ID",
            "url": "{{chat-completions-url}}",
            "toolCalling": true,
            "vision": true,
            "maxInputTokens": 1000000,
            "maxOutputTokens": 64000
          }
        ]
      }
    ]
    ```

    你需要重点确认：

    | 字段 | 推荐值 |
    | --- | --- |
    | `name` | `BetterToken` |
    | `apiType` | `chat-completions` |
    | `id` | `YOUR_MODEL_ID` 或<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商的模型 ID |
    | `name` | 与模型 ID 保持一致 |
    | `url` | `{{chat-completions-url}}` |
    | `toolCalling` | `true` |
    | `vision` | `true` |
    | `maxInputTokens` | `1000000` |
    | `maxOutputTokens` | `64000` |
  </Step>

  <Step title="保存并重新加载 VS Code">
    保存 `chatLanguageModels.json` 后，执行：

    ```text
    Developer: Reload Window
    ```

    重新加载后，回到 Copilot Chat 的模型选择器，选择 `YOUR_MODEL_ID`。
  </Step>

  <Step title="发送测试消息">
    在 Copilot Chat 中发送一条简单消息，例如：

    ```text
    用一句话说明你当前使用的模型。
    ```

    如果能够正常回复，说明 BetterToken Custom Endpoint 已配置成功。
  </Step>
</Steps>

## 验证连接

发送一条简短测试消息。工具正常返回内容，并且没有认证或 Model ID 错误，就说明连接成功。修改配置后请完全退出并重新启动工具。

## 切换模型

打开模型选择器，或修改配置中的 `Model` 字段。请填写<a href={"{{model-plaza-url}}"}>模型广场</a>中的完整 Model ID，然后重新启动当前会话。

## 常见错误

| 错误 | 排查方式 |
| --- | --- |
| `401` 或 `Unauthorized` | 检查 BetterToken API Key，并删除首尾空格。 |
| `404` | 检查 Base URL，不要附加具体 endpoint 路径。 |
| `model not found` | 从模型广场重新复制当前 Model ID。 |
| 配置未生效 | 保存配置，并完全退出后重新启动工具。 |


### 为什么必须在弹窗里输入 API Key？

VS Code 会把 API Key 保存到本机 secret 存储中，并在 JSON 里使用 `${input:chat.lm.secret...}` 引用它。这样比把真实 API Key 写进 JSON 更安全。

### 为什么选择 Chat Completions？

本次验证成功的配置使用的是 **Chat Completions**。对应 URL 是：

```text
{{chat-completions-url}}
```

不要把它写成 `/v1/responses`，也不要只写到 `/v1`。

### 这个配置会影响 GitHub Copilot 自动补全吗？

不会。这个 Custom Endpoint 主要用于 Copilot Chat 的语言模型调用。GitHub Copilot 的行内自动补全仍由 GitHub Copilot 自身服务提供。

### 报 Invalid token 怎么办？

如果出现 `Invalid token`，按顺序检查：

1. API Key 是否是在 VS Code 弹窗中输入的
2. JSON 里是否保留 `${input:chat.lm.secret...}`
3. 所选 Model ID 是否来自 **受支持提供商**
4. `url` 是否为 `{{chat-completions-url}}`
5. `apiType` 是否为 `chat-completions`
6. 模型 ID 是否为<a href={"{{model-plaza-url}}"}>模型广场</a>中的 受支持提供商的模型
