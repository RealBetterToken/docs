<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-openclaw-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">

## 手动配置

### 配置 OpenClaw

从<a href={"{{model-plaza-url}}"}>模型广场</a>复制准确的 Model ID。

<Tabs>
  <Tab title="Responses API">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-responses",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Chat Completions">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-completions",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

`openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`.

## 验证连接

依次执行：

```bash
openclaw config validate
openclaw gateway restart
openclaw models list
openclaw models status
```

配置校验通过、Gateway 重启成功，并且 `bettertoken/YOUR_MODEL_ID` 出现在模型列表和状态中，即表示配置生效。已有会话仍显示旧模型时，新建会话后再次检查状态。

## 切换模型

把新模型加入 `models.providers.bettertoken.models`，再将 `agents.defaults.model.primary` 改为 `bettertoken/YOUR_MODEL_ID`。保存后重新执行校验与 Gateway 重启命令。

## 常见错误

| 错误 | 处理方式 |
| --- | --- |
| `config validate` 失败 | 检查 JSON 逗号、引号和括号。 |
| `401` | 重新复制 `apiKey`，确认没有空格。 |
| `404` | `openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`. |
| 模型未显示 | 检查模型是否同时存在于 provider 列表和 `agents.defaults.model.primary`。 |
| 旧会话仍用旧模型 | 执行 `openclaw gateway restart` 并新建会话。 |
