CC Switch 是一款跨平台桌面工具，用来统一管理 Claude Code、Claude Desktop、Codex、OpenCode 和 OpenClaw 的 provider 配置。这篇文档集中介绍这些工具的进阶接入方式。普通用户应先使用各工具页面中的直接配置；只有需要切换 provider 或使用非原生模型时，再使用 CC Switch。

## 安装 CC Switch

<Tabs>
  <Tab title="macOS">
    推荐优先使用 Homebrew；也可以从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `.dmg` 或 `.zip`。

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `CC-Switch-v{version}-Windows.msi` 或便携版 `.zip`，然后按安装向导完成安装。
  </Tab>
  <Tab title="Linux">
    从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `.deb`、`.rpm` 或 `.AppImage`。
  </Tab>
</Tabs>

## 开始前准备

- BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）
- Claude Code 使用 Anthropic 协议：`Base URL` 填 `{{anthropic-base-url}}`
- Claude Desktop 使用非 Claude provider 时，需要最新版 Claude Desktop 和 CC Switch `v3.16.5` 或更新版本
- Codex、OpenCode、OpenClaw 使用 OpenAI-compatible 协议：`Base URL` 填 `{{openai-base-url}}`
- 给 Codex、OpenCode、OpenClaw 准备一个当前可用的 **GPT 提供商**模型 ID。你可以从 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 复制，或在 CC Switch 里用 **获取模型** 直接从 `/v1/models` 拉取

<Info>
  CC Switch 首次启动时会自动导入本机已有的配置。你可以保留官方 provider 作为回退，再新增 BetterToken。
</Info>

<Note>
  BetterToken 同时提供 Anthropic 和 OpenAI-compatible 两种接入模式。为了避免把 `{{anthropic-base-url}}` 和 `{{openai-base-url}}` 混在一起，建议在 CC Switch 里按应用分别创建 provider，而不是把 Claude Code 和 OpenAI-compatible 工具合并到一个统一供应商。
</Note>

## 添加 BetterToken provider

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    <Steps>
      <Step title="切到 Claude Code 并添加 provider">
        打开 CC Switch，切到 **Claude Code**，点击 **Add Provider**。

        <Frame>
          <img
            src="/images/cc-switch/claude-code-add-provider.png"
            alt="CC Switch 的 Claude Code 页面，右上角加号按钮用于新增 provider。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="填写基础字段">
        - **Provider Name**：`BetterToken-claude`（也可使用便于区分的名称）
        - **Base URL**：`{{anthropic-base-url}}`
        - **API Key**：你的 BetterToken API Key

        下图中的标注对应：

        1. **Provider Name**
        2. **API Key**
        3. **Base URL**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-basic-fields.png"
            alt="CC Switch 的 Claude Code provider 编辑页面，标出了 Provider Name、API Key 和 API Endpoint 的填写位置。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="按所选 provider 设置 API Format 和模型映射">
        - 如果你使用 **Claude 提供商**，通常不需要再调整高级选项或模型映射
        - 如果你使用 **GPT 提供商**，请额外完成下面这些设置：

        1. 打开 **高级选项**
        2. 在 **API 格式** 中选择 **OpenAI Responses API**

        <Frame>
          <img
            src="/images/cc-switch/claude-code-api-format.png"
            alt="CC Switch 的高级选项区域，API 格式被设置为 OpenAI Responses API。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        3. 在 **模型映射** 里点击 **获取模型列表**
        4. 将 **主模型**、**推理模型（Thinking）**、**Haiku 默认模型**、**Sonnet 默认模型**、**Opus 默认模型** 都从下拉列表中显式选中

        <Frame>
          <img
            src="/images/cc-switch/claude-code-model-mapping.png"
            alt="CC Switch 的模型映射区域，展示了获取模型列表以及主模型、Thinking、Haiku、Sonnet、Opus 的映射位置。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        这里使用的模型都应来自 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 当前可用的 **GPT 提供商**模型 ID。
      </Step>

      <Step title="保存、切换，并按接口格式决定是否开启代理">
        保存后，回到渠道列表页：

        1. 将刚保存的 BetterToken provider 设为 **使用中**
        2. 如果你使用 **Claude 提供商**，不需要打开左上角的 **CC Switch 代理功能**
        3. 如果你使用 **GPT 提供商**，再打开左上角的 **CC Switch 代理功能**

        下图展示保存后在 provider 列表中确认 BetterToken-claude 已启用。只有使用 **GPT 提供商**时，才需要额外打开左上角的 **CC Switch 代理功能**。

        <Frame>
          <img
            src="/images/cc-switch/claude-code-enable-proxy.png"
            alt="CC Switch provider 列表中，BetterToken-claude 已被选中并显示为 In Use。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>

        | Model role | Requested model |

## 保存后如何生效

所有配置保存并切换完成后，都建议先重启对应客户端或网关，再开始验证。

- Claude Code：完全退出当前 Claude Code 会话，再重新启动。
- Claude Desktop：完全退出应用后重新打开，确认左下角显示 **Gateway**。
- Codex：重启当前 Codex 进程，或新开一个终端会话。
- OpenCode：退出当前 OpenCode 会话并重新启动。
- OpenClaw：执行 `openclaw gateway restart`，再在 Discord 中依次执行 `/new`、`/status`、`/model`。

## CC Switch 专属高级功能

CC Switch 还可以在切换第三方 provider 时保留 Codex 官方登录，并统一显示官方与第三方会话。开启相关开关后需要重启 Codex。详细步骤请查看[保留 Codex 官方登录态和统一会话历史](/zh/faq/codex/official-login-third-party-api)。

## 常见问题

- Claude Code 的 `Base URL` 不要加 `/v1`
- Claude Code 使用 **GPT 提供商**时，要在 **高级选项** 里把 **API 格式** 切到 **OpenAI Responses API**
- Claude Code 使用 **Claude 提供商**时，不需要打开 **CC Switch 代理功能**
- Claude Desktop 使用非 Claude provider 时，需要启用 **CC Switch 代理功能**并完全重启应用
- Codex、OpenCode、OpenClaw 的 `Base URL` 要写 `{{openai-base-url}}`
- Codex、OpenCode、OpenClaw 在工具要求填写模型时，请使用 **GPT 提供商**模型 ID，不要沿用 Claude 风格模型名
- 如果 **获取模型** 失败，先检查 API Key 和 `Base URL`，再改为手动粘贴模型 ID
- 如果切换后没有生效，先确认 BetterToken provider 已被设为当前 provider，再按上面的方式重启对应客户端或网关
