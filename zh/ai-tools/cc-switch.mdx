CC Switch 是可选的桌面配置管理工具，用来管理 Claude Code、Claude Desktop、Codex CLI、OpenCode 和 OpenClaw 的 API Key、接入地址与模型设置。

## 安装 CC Switch

<Tabs>
  <Tab title="macOS">
    推荐优先使用 Homebrew；也可以从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `.dmg` 或 `.zip`。

    ```bash
    brew tap farion1231/ccswitch
    brew install --cask cc-switch
    ```
  </Tab>
  <Tab title="Windows">
    从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `CC-Switch-v{version}-Windows.msi` 或便携版 `.zip`，然后按安装向导完成安装。
  </Tab>
  <Tab title="Linux">
    从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases) 下载最新版 `.deb`、`.rpm` 或 `.AppImage`。
  </Tab>
</Tabs>

## 开始前准备

- BetterToken API Key（<a href={"{{register-url}}"}>注册并获取</a>）
- Claude Code 使用 Anthropic 协议：`Base URL` 填 `{{anthropic-base-url}}`
- Codex、OpenCode、OpenClaw 使用 OpenAI-compatible 协议：`Base URL` 填 `{{openai-base-url}}`
- 给 Codex、OpenCode、OpenClaw 准备一个当前可用的模型 ID。你可以从 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 复制，或在 CC Switch 里用 **获取模型** 直接从 `/v1/models` 拉取

<Info>
  CC Switch 首次启动时会自动导入本机已有的配置。你可以保留官方 provider 作为回退，再新增 BetterToken。
</Info>

<Note>
  BetterToken 同时提供 Anthropic 和 OpenAI-compatible 两种接入模式。为了避免把 `{{anthropic-base-url}}` 和 `{{openai-base-url}}` 混在一起，建议在 CC Switch 里按应用分别创建 provider，而不是把 Claude Code 和 OpenAI-compatible 工具合并到一个统一供应商。
</Note>

## 添加 BetterToken provider

<Tabs>
  <Tab title="Claude Code" id="claude-code">
    在 CC Switch 中选择 **Claude Code**，点击 **Add Provider**。

    使用 BetterToken API Key、Base URL `{{anthropic-base-url}}` 和你选择的 Model ID 接入 Claude Code。

    - **Provider Name**: `BetterToken`
    - **API Key**: `YOUR_API_KEY`
    - **API Endpoint**: `{{anthropic-base-url}}`

    使用 Anthropic Messages API 格式，在 **Model Mapping** 中填写你选择的模型 ID，然后保存配置。

    从<a href={"{{model-plaza-url}}"}>模型广场</a>复制准确的 Model ID。

    保存配置，将 BetterToken 设为当前配置，然后完全重启客户端。
  </Tab>

  <Tab title="Claude Desktop" id="claude-desktop">
    Claude Desktop 仅支持 Claude 模型，这是 Claude Desktop 客户端的限制。

    按照 [Claude Desktop 接入文档](/zh/faq/claude-desktop-bettertoken-api)配置 **Gateway**，Base URL 填写 `{{anthropic-base-url}}`，填入 BetterToken API Key，**Gateway auth scheme** 选择 `x-api-key`。点击 **Apply locally** 保存，然后完全重启 Claude Desktop。
  </Tab>

  <Tab title="Codex" id="codex-cli">
    <Steps>

  <Tab title="OpenCode" id="opencode">
    <Steps>
      <Step title="切到 OpenCode 并添加 provider">
        打开 CC Switch，切到 **OpenCode**，点击 **Add Provider**。如果界面先让你选预设，优先选择 **OpenAI Compatible** 或 **Custom**。
      </Step>

      <Step title="填写基础字段">
        - **Provider Name**：`BetterToken`
        - **Base URL**：`{{openai-base-url}}`
        - **API Key**：你的 BetterToken API Key
        - **API Format**：`OpenAI Compatible`
      </Step>

      <Step title="选择默认模型">
        优先点击 **获取模型**。如果需要手动填写，请直接使用 <a href={"{{model-plaza-url}}"}>BetterToken 模型广场</a> 中当前可用的模型 ID。

        OpenCode 直接读取保存后的 provider 配置，不需要开启 CC Switch 代理。
      </Step>

      <Step title="保存并切换">
        保存后将 BetterToken 设为当前 provider。

    </Steps>
  </Tab>

  <Tab title="OpenClaw" id="openclaw">
    <Steps>
      <Step title="切到 OpenClaw 并添加 provider">
        打开 CC Switch，切到 **OpenClaw**，点击 **Add Provider**。如果界面先让你选预设，优先选择 **OpenAI Compatible** 或 **Custom**。
      </Step>

      <Step title="填写基础字段">
        - **Provider Name**：`BetterToken`
        - **Base URL**：`{{openai-base-url}}`
        - **API Key**：你的 BetterToken API Key
        - **API Format**：`OpenAI Responses API`

        如果你进入的是 OpenClaw 的自定义 provider 配置视图，确保 `api` 写成 `openai-responses`。
      </Step>

      <Step title="选择默认模型">
        优先点击 **获取模型**。如果需要手动填写，请使用当前可用的模型 ID。

        OpenClaw 直接使用保存后的 provider 配置，不需要开启 CC Switch 代理。
      </Step>

      <Step title="保存并切换">
        保存后将 BetterToken 设为当前 provider。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 保存后如何生效

所有配置保存并切换完成后，都建议先重启对应客户端或网关，再开始验证。

- Claude Code：完全退出当前 Claude Code 会话，再重新启动。
- Claude Desktop：完全退出应用后重新打开，确认左下角显示 **Gateway**。
- Codex：重启当前 Codex 进程，或新开一个终端会话。
- OpenCode：退出当前 OpenCode 会话并重新启动。
- OpenClaw：执行 `openclaw gateway restart`，再在 Discord 中依次执行 `/new`、`/status`、`/model`。

## CC Switch 专属高级功能

CC Switch 还可以在切换第三方 provider 时保留 Codex 官方登录，并统一显示官方与第三方会话。开启相关开关后需要重启 Codex。详细步骤请查看[保留 Codex 官方登录态和统一会话历史](/zh/faq/codex/official-login-third-party-api)。

## 常见问题

- Claude Code 的 `Base URL` 不要加 `/v1`

- Codex、OpenCode、OpenClaw 的 `Base URL` 要写 `{{openai-base-url}}`
- Codex、OpenCode、OpenClaw 在工具要求填写模型时，请使用 模型 ID，不要沿用 Claude 风格模型名
- 如果 **获取模型** 失败，先检查 API Key 和 `Base URL`，再改为手动粘贴模型 ID
- 如果切换后没有生效，先确认 BetterToken provider 已被设为当前 provider，再按上面的方式重启对应客户端或网关
