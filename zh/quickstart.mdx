---
title: "快速接入"
description: "新用户用 4 步注册账号、为账户充值、创建 API Key，并进入对应工具的接入文档。"
---

<Steps>
  <Step title="注册账号">
    访问 <a href={"{{register-url}}"}>BetterToken 注册页面</a>，创建账号。

    注册后，请先为账户充值，再创建 BetterToken API Key。
  </Step>
  <Step title="为账户充值">
    你可以选择 **在线充值** 或 **兑换码充值**。充值完成后，回到控制台确认 **当前余额** 已更新，再继续创建 API Key。

    <Tabs>
      <Tab title="在线充值">
        登录后进入 **Console**。在 **Current balance** 卡片中选择要充值的币种，然后点击对应的 **Top up**。

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="BetterToken Console 的 Current balance 卡片，分别显示美元和卢布的 Top up 按钮。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        按页面提示完成支付。支付成功后，回到控制台确认 **当前余额** 已更新。
      </Tab>
      <Tab title="兑换码充值">
        登录后进入 **Console**，在 **Current balance** 卡片左下角点击 **Redeem code**。

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="BetterToken Console 的 Current balance 卡片，箭头指向左下角的 Redeem code 按钮。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        在弹窗中输入兑换码，然后点击 **兑换**。

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="兑换码弹窗中的输入框和兑换按钮。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        兑换成功后，回到控制台确认 **当前余额** 已更新。
      </Tab>
    </Tabs>
  </Step>
  <Step title="进入 API Key 管理并创建 API Key">
    有了可用额度后，在控制台 **Your API keys** 区域的右上角点击 **Create API key**。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="BetterToken Console 的 Your API keys 区域，箭头指向右上角的 Create API key 按钮。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    点击后会弹出创建 API Key 表单。

    <Info>
      你可以把 API Key 名称理解成“这把 Key 准备给谁用”。先分清用途，后面配置工具时会少踩很多坑。
    </Info>
  </Step>
  <Step title="按工具类型选择提供商">
    在创建表单里填写 **名称**，选择 **提供商**，并确认有效期和可选的额度限制。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="创建 API Key 表单，包含名称、提供商、有效期和额度限制选项。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    按你要接入的工具选择提供商。

    <Warning>
      **Claude 提供商**只能用于 Claude Code。
    </Warning>

    <Warning>
      **GPT 提供商**可以用于 Codex，也可以用于 OpenClaw、OpenCode、Cursor 等外部工具。
    </Warning>

    直接选择对应提供商：

    ```text
    Claude
    GPT
    ```

    创建完成后会弹出 **API key setup** 窗口。在这里可以复制 **API Key** 和 **Base URL**。

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="BetterToken 的 API key setup 窗口，包含 API Key、Base URL、工具选择和配置方式。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="选择一个配置方式">
    在 **API key setup** 窗口左侧选择你要接入的工具，然后选择一种配置方式。

    - **One-click Bash Configuration**：选择工具和 `macOS / Linux` 或 `Windows`，复制生成的命令，并在自己的本机终端执行。适合快速配置 Codex、OpenClaw 或 OpenCode。
    - **CC Switch 集成**：点击 **Import to CC Switch**，把当前 **API Key** 和 **Base URL** 导入 CC Switch。适合统一管理多个工具和 provider。
    - **手动配置**：复制 **API Key** 和 **Base URL**，再按对应工具文档填入。适合 Cursor、Cline、Roo Code、Zed 等其他客户端。

    <Note>
      不同工具的认证字段、模型选择和配置文件位置不一样。进入具体工具文档后，请按该工具的步骤继续配置。
    </Note>
  </Step>
</Steps>
