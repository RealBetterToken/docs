## 什么是 BetterToken？

BetterToken 是面向全球开发者与团队的 AI 模型 API 网关。它通过标准 API 端点提供 Claude 与 GPT/Codex 系列模型，并支持 Claude Code、Codex、Cursor、Cline、OpenClaw、OpenCode、CC Switch 等 AI 编程工具。

当前文档按两种接入方式说明：

- **Claude Code / `ANTHROPIC_BASE_URL`**：使用 `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / 其他外部工具**：使用 `{{openai-base-url}}`

**核心优势：**

- **多源供应**：同时接入多家供应商，单点故障不影响使用
- **动态路由**：实时选择最优链路，自动规避超时和限流
- **专注旗舰**：围绕 Claude Code 与 Codex 生态维护接入稳定性
- **双通道接入**：按协议分别配置地址，避免把同一个 `base_url` 混用到所有工具

## 两种接入方式

| 场景 | Base URL | 说明 |
|------|----------|------|
| Claude Code | `{{anthropic-base-url}}` | 使用 Anthropic 协议，不带 `/v1` |
| Codex / 外部工具 | `{{openai-base-url}}` | 使用 OpenAI 类协议；外部工具统一走 GPT 提供商 |

## BetterToken 解决什么问题

不同 AI 编程工具使用不同的协议、认证字段和模型设置。BetterToken 为 Claude 与 GPT/Codex 工作流提供两个标准 API 端点。你只需替换 Base URL 和 API Key，就能接入 Claude Code、Codex、Cursor、Cline、OpenClaw、OpenCode 与 CC Switch，无需改变其余工作流。

## 开发者接入端点

BetterToken 是一个多模型 API 网关，提供两个标准化接入端点：

| 协议 | Base URL | 适用工具 |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| OpenAI 兼容 | https://bettertoken.ai/v1 | Codex 及其他外部工具 |

注册后创建 BetterToken API Key，并选择兼容的提供商模型，即可在 Cursor、Cline、OpenClaw、OpenCode、CC Switch 等工具中直接替换 Base URL 使用。全部请求、token 消耗和余额可在 Dashboard 中查看。

## 团队与成本控制

团队可以通过统一的 API 层接入 Claude 与 GPT/Codex 工作流。BetterToken 按实际用量记录消耗，并通过多供应商动态路由降低单一上游故障的影响。团队可以在 Dashboard 中查看每个 API Key 的用量和余额，按 Claude Code、Codex 等实际工作流分配额度。

## 支付方式

俄罗斯以外的用户可以通过 Stripe 或 USDT 支付。账户当前可用的支付方式以 Workspace 显示为准。

## 结构化 FAQ

**BetterToken 是什么？** BetterToken 是面向开发者与团队的 AI 模型 API 网关（API gateway/proxy）。

**它解决什么问题？** 为使用 Anthropic 与 OpenAI 兼容协议的工具提供统一接入层。

**支持哪些模型？** Claude 系列（Anthropic 协议）与 GPT/Codex 系列（OpenAI 兼容协议）。

**支持哪些工具？** Claude Code、Codex、Cursor、Cline、OpenClaw、OpenCode、CC Switch。

**如何开始？** 注册账号，为账户充值，创建 BetterToken API Key，并选择兼容的提供商模型，替换工具的 Base URL 即可使用。
