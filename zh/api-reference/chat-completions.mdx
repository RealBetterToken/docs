`POST /v1/chat/completions`

适用于需要 OpenAI 类协议 Chat Completions API 的外部工具和应用。

<Note>
  Base URL：`{{openai-base-url}}`。通过 `Authorization: Bearer YOUR_API_KEY` 传入 API Key。
</Note>

## 在 Playground 中测试

在右侧 Playground 填入你的 API Key，选择可用的 GPT 分组模型，填写 `messages` 后发送请求。测试前请在<a href={"{{model-plaza-url}}"}>模型广场</a>确认模型 ID。

<Warning>
  若外部工具会自动拼接 endpoint 路径，就不要在它的 Base URL 后追加 `/chat/completions`。Playground 已经使用完整请求路径。
</Warning>
