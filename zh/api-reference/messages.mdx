`POST /v1/messages`

适用于 Claude Code、Anthropic SDK 与使用 Anthropic Messages API 的应用。

<Note>
  SDK 的 Base URL 填 `{{anthropic-base-url}}`。手动请求和 Playground 使用完整路径 `{{anthropic-base-url}}/v1/messages`。
</Note>

## 在 Playground 中测试

在右侧 Playground 的 `x-api-key` 字段填入你的 API Key，`anthropic-version` 保持 `claude-cli/2.0.76 (external, cli)`，选择可用的 Claude 分组模型后发送请求。

<Warning>
  此接口不要使用 `Authorization: Bearer ...`。它需要 `x-api-key` 请求头。
</Warning>
