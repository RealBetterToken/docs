BetterToken 当前公开的 API 参考仅包含 **OpenAI-compatible Chat Completions API**。不同渠道对其他协议的支持情况尚未完全统一，因此 Responses API 与 Anthropic Messages API 暂不作为公开接口提供。

## 接入信息

| 字段 | 填写内容 |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| 完整请求 URL | `{{chat-completions-url}}` |
| 请求方法 | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

从<a href={"{{model-plaza-url}}"}>模型广场</a>或 Console 中对应 API Key 的 **Setup** 弹窗复制 Model ID。

<Warning>
  工具要求填写 **Base URL** 时使用 `{{openai-base-url}}`。只有工具明确要求完整请求 URL 时，才填写 `{{chat-completions-url}}`。
</Warning>

## 快速测试

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

正常响应会包含 `choices[0].message.content`。
