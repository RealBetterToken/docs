发布日期：2026-06-09

BetterToken 已更新 `Claude Fable 5` 相关模型入口。你可以在<a href={"{{model-plaza-url}}"}>模型广场</a>查看当前可用模型 ID，并按 Claude Code 或外部工具的接入文档配置。

Anthropic 官方于 2026-06-09 发布 Claude Fable 5，并将其描述为面向最困难知识工作和代码问题的新一代模型。官方说明中，Fable 5 是一个 Mythos-class 模型，重点面向更长、更复杂、更异步的任务，尤其适合长周期 Agent、复杂软件工程、知识工作和视觉理解场景。

## 更新亮点

- **长周期 Agent 能力更强**：Anthropic 表示 Fable 5 可以在 Claude Code 或 Agent harness 中连续处理更长时间的任务，适合跨阶段规划、执行和自检
- **复杂代码工程更适合交给模型推进**：官方强调它适合大型迁移、复杂实现、多日自主会话和需要更少监督的工程任务
- **知识工作和视觉理解提升**：Fable 5 面向复杂分析、文档推理、图表理解、PDF 和视觉材料处理等场景
- **更主动的自我检查**：官方说明中，Fable 5 会更认真地验证自己的工作，适合需要模型持续推进并回报结果的任务
- **新增安全保护机制**：在网络安全、生物和化学等敏感领域，Anthropic 会对部分请求启用保护与回退机制，相关请求可能由 Claude Opus 4.8 响应

## 配置建议

如果你使用 Claude Code，请优先按 [Claude Code 接入文档](/zh/ai-tools/claude-code) 配置。不同 提供商对应的协议和模型配置方式不同：

- **Claude 提供商**：使用 `{{anthropic-base-url}}`
- **GPT 提供商**或外部工具：按对应工具文档使用 `{{openai-base-url}}`

模型名称请以<a href={"{{model-plaza-url}}"}>模型广场</a>当前显示为准。不要手写不在模型广场中的模型名。

<Note>
  Claude Fable 5 更适合高价值、长上下文、长周期任务。简单问答或低成本批量任务，仍建议根据模型广场中的 provider 和价格选择更轻量的模型。
</Note>
