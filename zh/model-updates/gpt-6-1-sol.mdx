更新日期：2026 年 9 月 30 日

**GPT-6.1 Sol** 是 GPT-6 Sol 的升级版本。OpenAI 表示，它在智能体编程、计算机操作和专业任务上有所提升，并在部分评测中接近 GPT-6 Astra。对于复杂任务，建议结合实际工作流比较效果、延迟和用量。

BetterToken 已支持模型 ID `gpt-6.1-sol`。实时可用性和 BetterToken 价格请查看<a href={"{{model-plaza-url}}"}>模型广场</a>。

## 主要亮点

- **编程与智能体任务**：适合跨文件修改、调试和较长的软件工程任务。
- **计算机操作与专业工作**：OpenAI 报告其在应用操作和复杂文档任务上的表现优于 GPT-6 Sol。
- **长上下文**：OpenAI 标注 105 万 Token 上下文窗口和最多 12.8 万输出 Token；实际可用上限也取决于客户端和接入路径。
- **可调推理强度**：支持 `low`、`medium`、`high`、`xhigh` 和 `max`，不支持 `none` 或 `minimal`。

## 快速接入

1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>。
2. 在 Codex CLI 或其他 OpenAI 兼容客户端中，将 Base URL 设为 `{{openai-base-url}}`，Model ID 设为 `gpt-6.1-sol`。
3. 如需工具调用，请使用 [Responses API](/zh/api-reference/responses)。OpenAI 文档说明，该模型通过 Chat Completions 接口调用时不支持工具调用。
4. 切换现有工作流前，先用典型任务测试。

在 Claude Code 中，可使用 Anthropic 协议 Base URL `{{anthropic-base-url}}` 和相同的 Model ID。客户端操作可参考 [Claude Code 接入文档](/zh/ai-tools/claude-code)或 [Codex CLI 接入文档](/zh/ai-tools/codex)。
