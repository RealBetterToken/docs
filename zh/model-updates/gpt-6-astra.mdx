更新日期：2026 年 9 月 5 日

BetterToken 已上架 **GPT-6 Astra**，准确的模型 ID 是 `gpt-6-astra`。OpenAI 将 Astra 定位为面向高难度端到端任务的旗舰模型，适用于复杂推理、软件工程、研究、计算机操作和文档创建。当前可用状态和 BetterToken 价格请以<a href={"{{model-plaza-url}}"}>模型广场</a>为准。

## 更新亮点

- **端到端任务**：面向跨代码、浏览器、工具和专业应用的复杂多步骤工作
- **软件工程**：OpenAI 将 Astra 定位为其目前最强的编程和 Agent 软件开发模型
- **大上下文**：OpenAI 公布的上下文窗口为 `1,050,000` tokens，最大输出为 `128,000` tokens
- **可调推理强度**：OpenAI API 支持 `low`、`medium`、`high`、`xhigh` 和 `max`
- **Responses API 工具**：OpenAI 文档列出了函数调用、结构化输出、网页搜索、文件搜索、代码解释器、计算机操作和 MCP 等工具能力

## 配置建议

- 高难度编程、研究、计算机操作或长周期 Agent 任务可优先测试 Astra。日常任务可在模型广场中与速度更快或成本更低的模型对比。
- 切换生产流量前，先用真实任务比较输出质量、延迟和 token 用量。
- 选择 **GPT 提供商**，Base URL 填写 `{{openai-base-url}}`，Model ID 填写 `gpt-6-astra`。
- 模型可能处于分阶段开放状态。BetterToken 的可用性和价格以模型广场为准。

## 快速开始

1. 创建 BetterToken API Key，或打开现有 Key 的 **Setup** 弹窗。
2. 在模型广场确认 `gpt-6-astra` 当前可用。
3. 在客户端中将 Base URL 设置为 `{{openai-base-url}}`，Model ID 设置为 `gpt-6-astra`。
4. 如果客户端没有自动刷新模型列表，请重启客户端。
5. 发送一个小型测试任务，并在 Dashboard 中确认请求记录。

## 常见问题

### GPT-6 Astra 的 Model ID 是什么？

请使用 `gpt-6-astra`。不要填写展示名称 `GPT-6 Astra`，也不要复制其他平台的模型 ID。

### BetterToken 是否支持完整的 1,050,000-token 上下文？

OpenAI 公布 GPT-6 Astra 的上下文窗口为 `1,050,000` tokens。实际可用长度还可能受客户端、请求设置和 BetterToken 当前路由限制影响。发送超长提示词前，请查看模型广场和客户端文档。

### 如何解决 Model not found？

确认 Model ID 完整填写为 `gpt-6-astra`，BetterToken API Key 可以访问该模型，已选择 **GPT 提供商**，并且 Base URL 是 `{{openai-base-url}}`。完成后重启客户端并重新测试。

### 在哪里查看当前价格？

请查看实时<a href={"{{model-plaza-url}}"}>模型广场</a>。BetterToken 价格可能与 OpenAI 官方 API 定价不同，并且会随时间调整。
