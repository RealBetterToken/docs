发布日期：2026-04-16

LLMEasy 已更新 `Claude Opus 4.7` 相关模型入口。你可以在<a href={"{{model-plaza-url}}"}>模型广场</a>查看当前可用模型 ID，并按 Claude Code 或外部工具的接入文档配置。

Anthropic 官方于 2026-04-16 发布 Claude Opus 4.7，并称其已正式可用。官方说明中，Opus 4.7 相比 Opus 4.6 在高级软件工程、复杂长任务、视觉理解和专业知识工作上都有提升。

## 更新亮点

- **高级软件工程能力增强**：Anthropic 表示 Opus 4.7 在最困难的软件工程任务上提升明显，更适合交给模型处理需要较少监督的复杂开发工作
- **长任务一致性更好**：官方强调它能更严谨、稳定地处理复杂长任务，并更主动验证输出
- **视觉能力提升**：Opus 4.7 支持更高分辨率图片输入，适合分析密集截图、复杂图表和细节较多的视觉材料
- **安全策略更新**：Anthropic 将 Opus 4.7 作为 Project Glasswing 后的首个公开模型，部署了自动识别并阻断高风险网络安全请求的保护机制
