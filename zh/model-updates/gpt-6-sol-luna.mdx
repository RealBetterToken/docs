发布日期：2026 年 9 月 22 日

GPT-6 Sol 和 GPT-6 Luna 是 OpenAI 在 Astra 之外推出的两款 GPT-6 模型。Sol 面向复杂编程与 Agent 工作流，Luna 面向目标明确的大规模重复任务。OpenAI 表示，两者相比 GPT-5.6 系列在编程、事实准确性和沟通表达上均有改进。

BetterToken 已上架 **GPT-6 Sol** 和 **GPT-6 Luna**。选择 `GPT` 提供商，Base URL 填写 `{{openai-base-url}}`，Model ID 使用 `gpt-6-sol` 或 `gpt-6-luna`。官方名称为 **Sol**，不是 `Sora`。

实时可用性和价格请以<a href={"{{model-plaza-url}}"}>模型广场</a>为准。

## 如何选择

- **`gpt-6-sol`**：适合复杂编程和 Agent 工作流。
- **`gpt-6-luna`**：适合目标明确、可重复且高并发的任务。

## 主要亮点

- **大上下文**：OpenAI 为两款模型标注了 `1,050,000` tokens 上下文窗口和最多 `128,000` tokens 输出。
- **可调推理强度**：两款模型均支持 `none`、`low`、`medium`、`high`、`xhigh` 和 `max`。
- **工作表现**：OpenAI 表示，相比 GPT-5.6 系列，编程、事实准确性和技术沟通均有改进。

## 快速接入

1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>。
2. 选择 `GPT` 提供商，Base URL 填写 `{{openai-base-url}}`。
3. 复杂 Agent 任务使用 `gpt-6-sol`；重复的大规模任务使用 `gpt-6-luna`。
4. 发送真实测试请求，比较质量、延迟和 token 用量。
