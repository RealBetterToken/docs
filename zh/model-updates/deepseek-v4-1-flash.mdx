## 快速开始

1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>，或打开现有 Key 的 **Setup** 弹窗。
2. 在模型广场确认 `deepseek-flash` 可用。
3. 选择 **DeepSeek 提供商**。
4. 按上表选择对应协议的 Base URL，并填写完整 Model ID。
5. 先发送一个小型请求，再开始较长的评估任务。

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

请求成功时，模型输出位于 `choices[0].message.content`。SDK 示例和完整请求格式请参阅 [Chat Completions API 参考](/zh/api-reference/chat-completions)。

## 常见问题

### 可以在生产环境中使用这个 Model ID 吗？

可以。请使用 `deepseek-flash`，并在模型广场确认你的 BetterToken API Key 仍可使用该模型。

### 可以将它用于 Claude Code 或 Anthropic Messages API 吗？

支持。Claude Code 或 Anthropic Messages 使用 Base URL `{{anthropic-base-url}}`，Model ID 填写 `deepseek-flash`。直接调用 Messages 时，使用 `POST /v1/messages`，并在 `x-api-key` 请求头中传入 BetterToken API Key。

### 在哪里查看当前价格？

请查看实时<a href={"{{model-plaza-url}}"}>模型广场</a>。模型可用性和价格可能变化。
