1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>，或打开现有 Key 的 **Setup** 弹窗。
2. 在模型广场确认 `deepseek-v4.1-flash-expires-on-0910` 仍然可用。
3. 选择 **DeepSeek 提供商**。
4. 将 Base URL 设置为 `{{openai-base-url}}`，并填写完整的临时 Model ID。
5. 先发送一个小型请求，再开始较长的评估任务。

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-v4.1-flash-expires-on-0910",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

请求成功时，模型输出位于 `choices[0].message.content`。SDK 示例和完整请求格式请参阅 [Chat Completions API 参考](/zh/api-reference/chat-completions)。
