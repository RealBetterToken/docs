发布日期：2026 年 9 月 22 日

Claude Opus 5.5 是 Anthropic 推出的 Claude 5.5 系列首款模型。Anthropic 表示，相比 Opus 5，它更擅长长周期编程和专业工作，在持续协作中也能给出更清晰的说明。

**Claude Opus 5.5** 已在 BetterToken 上架。选择 `Claude` 提供商，将 Base URL 设置为 `{{anthropic-base-url}}`，并填写模型 ID `claude-opus-5-5`。实时可用性和价格请以<a href={"{{model-plaza-url}}"}>模型广场</a>为准。

## 主要亮点

- **长周期编程 Agent**：适合复杂代码库改造、审计和多步骤任务。
- **高质量交付**：Anthropic 推荐它用于可直接交付的代码、复杂文档和计算机操作。
- **更清晰的沟通**：Anthropic 表示，长会话中的解释比 Opus 5 更直接、更易读。

## 快速接入

1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>。
2. 选择 `Claude` 提供商，Base URL 填写 `{{anthropic-base-url}}`。
3. Model ID 填写 `claude-opus-5-5`。
4. 先用真实任务测试，再切换生产流量。
