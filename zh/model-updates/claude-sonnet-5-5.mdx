发布日期：2026 年 9 月 28 日

Claude Sonnet 5.5 是 Anthropic 推出的 Claude 5.5 系列第二款模型。Anthropic 将它定位为处理范围明确的日常任务的更快选择，包括编程、修复 Bug，以及制作精致的文档、演示文稿和电子表格。对于更复杂、开放式的任务，可以考虑 Opus 5.5。

**Claude Sonnet 5.5** 已在 BetterToken 上架。选择 `Claude` 提供商，将 Base URL 设置为 `{{anthropic-base-url}}`，并填写模型 ID `claude-sonnet-5-5`。实时可用性和价格请以<a href={"{{model-plaza-url}}"}>模型广场</a>为准。

## 主要亮点

- **明确的编程任务**：适合范围清晰的功能实现与 Bug 修复。
- **专业内容制作**：Anthropic 特别提到它在文档、演示文稿和电子表格方面的表现。
- **长上下文**：Anthropic 标注的上下文窗口为 100 万 Token，最大输出为 12.8 万 Token。

## 从 Sonnet 5 切换前

如果你的客户端直接调用 Anthropic Messages API，请先查看[官方迁移指南](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)。Sonnet 5.5 对部分 thinking 和工具选择行为做了调整；切换模型 ID 前，建议用典型请求测试。

## 快速接入

1. <a href={"{{register-url}}"}>创建 BetterToken API Key</a>。
2. 选择 `Claude` 提供商，Base URL 填写 `{{anthropic-base-url}}`。
3. Model ID 填写 `claude-sonnet-5-5`。
4. 先用真实任务测试，再切换生产流量。

可参考 [Claude Code 接入文档](/zh/ai-tools/claude-code)和[模型选择指南](/zh/faq/model-calling/model-selection-guide)。
