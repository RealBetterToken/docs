## 简短答案

推荐计划用于奖励真实邀请。你邀请朋友注册后，对方完成首次充值，你可以获得对方首次充值金额 **10%** 的推荐奖励。

奖励以站内奖励余额形式发放，会自动用于支付后续 API 请求费用。可疑推荐会进入人工审核，审核通过后才会发放奖励。

## 推荐计划条款

| 条款 | 说明 |
| --- | --- |
| 1 | 邀请一位朋友。对方首次充值后，你将获得对方首次充值金额 **10%** 的推荐奖励。 |
| 2 | 奖励余额将自动用于支付请求费用。 |
| 3 | 可疑推荐会手动审核，审核通过后发放奖励。 |

## 如何使用推荐计划

1. 登录控制台。
2. 在账户或推荐奖励区域复制你的推荐链接。
3. 将推荐链接发送给朋友。
4. 朋友通过链接注册并完成首次充值。
5. 系统按对方首次充值金额的 **10%** 计算推荐奖励。
6. 奖励发放后，会自动用于支付你的后续请求费用。

如果朋友没有通过你的链接注册，推荐关系可能无法自动建立。分享时建议直接发送完整推荐链接，不要只发送截图。

## 奖励如何使用

奖励余额不是单独的现金提现通道。它会作为站内余额自动用于支付模型请求费用。

当你发起 API 请求时，系统会根据当前账户余额和奖励余额规则自动抵扣。你不需要在每次请求里额外指定使用奖励余额。

## 哪些情况可能需要审核

为了防止异常拉新和滥用，以下情况可能触发人工审核：

- 同一设备或网络环境下出现大量互相邀请
- 充值行为异常或疑似非真实用户
- 使用虚假账号、批量账号或自动化方式注册
- 试图通过自邀请获取奖励
- 支付、账号或请求行为存在异常关联

人工审核通过后，奖励会正常发放；如果被判断为可疑推荐，奖励可能延迟、取消或冻结。

## 常见问题

### 推荐奖励比例是多少？

推荐奖励为对方首次充值金额的 **10%**。

### 朋友首次充值后奖励会立刻到账吗？

正常推荐会按系统规则发放。如果触发风控或异常关联，奖励会进入人工审核，审核通过后再发放。

### 奖励余额可以提现吗？

奖励余额用于支付请求费用，不是现金提现通道。

### 奖励余额需要手动抵扣吗？

不需要。奖励余额会自动用于支付请求费用。

## 关于 LLMEasy

LLMEasy 的推荐计划鼓励真实用户邀请。推荐奖励用于抵扣 API 请求成本，适合团队成员、朋友或开发者社群之间分享服务。
