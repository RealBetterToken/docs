Claude Desktop 支持两种 BetterToken 接入方式。请根据 API Key 的分组选择对应标签：**Claude 分组**使用 Claude Desktop 的 Gateway；**GPT 分组**使用 CC Switch 自动配置。

<Tabs>
  <Tab title="Claude 分组">
    <Info>
      此方式使用 Claude 分组 API Key，并直接连接 `{{anthropic-base-url}}`。
    </Info>

    <Steps>
      <Step title="下载 Claude Desktop">
        通过官方链接下载最新版 Claude Desktop：

        [下载 Claude Desktop](https://claude.ai/download)
      </Step>

      <Step title="启用 developer mode">
        打开 Claude Desktop 后，在 macOS 左上角菜单中选择 **Help** → **Troubleshooting** → **Enable Developer Mode**。

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/enable-developer-mode-menu.png"
            alt="在 Claude Desktop 的 Help 菜单中选择 Enable Developer Mode。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        在确认窗口中点击 **Enable**，然后重启 Claude Desktop。

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
            alt="确认启用 Claude Desktop developer mode。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="打开第三方推理配置">
        重启后，在 macOS 菜单栏选择 **Developer** → **Configure Third-Party Inference...**。

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
            alt="在 Developer 菜单中选择 Configure Third-Party Inference。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="填写 BetterToken API 信息">
        在配置窗口中选择 **Gateway**，然后填写以下信息：

        | 字段 | 填写内容 |
        | --- | --- |
        | **Gateway base URL** | `{{anthropic-base-url}}` |
        | **Gateway API key** | 在 BetterToken 控制台的 **令牌管理** 中复制 Claude 分组 API Key |
        | **Gateway auth scheme** | `x-api-key` |

        选择 **Gateway auth scheme** 后，Claude Desktop 会自动获取 Claude 分组中可用的模型。填写完成后点击 **Apply locally**。

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-credentials.png"
            alt="在 Claude Desktop 配置 BetterToken Gateway 信息并点击 Apply locally。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="重启并通过 Gateway 进入 Claude Desktop">
        点击 **Save & Restart**。重新打开后，选择 **Continue with Gateway**。左下角显示 **Gateway** 后即可使用。

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-ready.png"
            alt="Claude Desktop 已通过 Gateway 打开并可以正常使用。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

  <Tab title="GPT 分组">
    <Info>
      此方式使用 GPT 分组 API Key。请使用 Claude Desktop 最新版本和 CC Switch `v3.16.5` 或更新版本。
    </Info>

    <Steps>
      <Step title="更新 Claude Desktop 和 CC Switch">
        - [下载 Claude Desktop](https://claude.ai/download)
        - [下载 CC Switch](https://github.com/farion1231/cc-switch/releases)
      </Step>

      <Step title="切到 Claude Desktop 并添加 provider">
        打开 CC Switch，点击顶部的 **Claude Desktop** 图标，然后点击右上角的 **+** 添加 provider。

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/cc-switch-claude-desktop-add-provider.png"
            alt="在 CC Switch 中切到 Claude Desktop，并点击右上角加号添加 provider。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="填写基础字段">
        - **Provider Name**：`BetterToken-codex`
        - **API Key**：你的 BetterToken GPT 分组 API Key
        - **API Endpoint**：`{{anthropic-base-url}}`

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-basic-fields.png"
            alt="CC Switch provider 编辑页，填写 BetterToken-codex、API Key 和 API Endpoint。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="设置模型映射">
        在 **API Format** 中选择 **OpenAI Responses API (Requires routing)**，点击 **Fetch Models**，并保留 **Declare 1M**。

        | Model role | Requested model |
        | --- | --- |
        | Sonnet | `gpt-5.6-terra` |
        | Opus | `gpt-5.6-sol` |
        | Fable | `gpt-5.6-sol` |
        | Haiku | `gpt-5.6-luna` |

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-model-mapping.png"
            alt="CC Switch 中选择 OpenAI Responses API 并配置 Sonnet、Opus、Fable 和 Haiku 的模型映射。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        模型 ID 以 <a href={"{{model-plaza-url}}"}>模型广场</a> 中当前可用的 GPT 分组模型为准。
      </Step>

      <Step title="保存、切换，并开启代理">
        保存 provider 后，将 **BetterToken-codex** 设为 **In use**，并打开左上角代理开关。

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-enable-proxy.png"
            alt="CC Switch 中 BetterToken-codex 已启用，并打开左上角代理开关。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="重启 Claude Desktop 并选择模型">
        完全退出 Claude Desktop 后重新打开。左下角显示 **Gateway** 即表示配置已生效。在输入框的模型菜单中选择所需模型，即可开始使用。

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/claude-desktop-gateway-ready.png"
            alt="Claude Desktop 重启后左下角显示 Gateway，并可在模型菜单中选择模型。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 排查建议

### Claude 分组无法连接

确认 **Gateway base URL** 为 `{{anthropic-base-url}}`，并使用 Claude 分组 API Key 和 `x-api-key`。保存配置后重启 Claude Desktop。

### GPT 分组没有显示 Gateway

确认 CC Switch 中的 **BetterToken-codex** 为 **In use**，左上角代理开关已打开。然后完全退出 Claude Desktop 后重新打开。

### GPT 分组模型列表为空或请求返回 `401`

在 CC Switch 中点击 **Fetch Models** 并保存映射，确认 API Key 来自 GPT 分组。模型 ID 以 <a href={"{{model-plaza-url}}"}>模型广场</a> 中当前可用的 GPT 分组模型为准。
