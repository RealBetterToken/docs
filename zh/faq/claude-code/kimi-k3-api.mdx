Kimi K3 可以通过 Anthropic-compatible 配置直接接入 Claude Code。填写 BetterToken API Key、Base URL `https://bettertoken.ai`，并将 Haiku、Sonnet、Opus 三个角色映射为 `kimi-k3`。

## 重点信息

| 字段 | 填写内容 |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai` |
| Model | `kimi-k3` |

## 准备工作

- 安装最新版 [Claude Code](https://docs.anthropic.com/en/docs/claude-code)。
- <a href={"{{register-url}}"}>创建 BetterToken API Key</a>，在 **Setup** 弹窗中选择 **Claude Code** 和 **Kimi** provider。
- 确认 Setup 弹窗中可用的 Model ID 为 `kimi-k3`。

## 配置 Claude Code CLI

macOS/Linux 打开 `~/.claude/settings.json`；Windows 打开 `%USERPROFILE%\\.claude\\settings.json`。添加或更新 `env`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://bettertoken.ai",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "kimi-k3",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "kimi-k3",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "kimi-k3",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "API_TIMEOUT_MS": "3000000"
  }
}
```

将 `YOUR_API_KEY` 替换为你的 BetterToken API Key。如果文件已有 `env`，在现有对象中增加字段，不要创建第二个 `env`。

## 配置 VS Code 中的 Claude Code 扩展

打开 VS Code 用户 `settings.json`，添加：

```json
{
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_BASE_URL", "value": "https://bettertoken.ai" },
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "YOUR_API_KEY" },
    { "name": "ANTHROPIC_DEFAULT_HAIKU_MODEL", "value": "kimi-k3" },
    { "name": "ANTHROPIC_DEFAULT_SONNET_MODEL", "value": "kimi-k3" },
    { "name": "ANTHROPIC_DEFAULT_OPUS_MODEL", "value": "kimi-k3" },
    { "name": "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC", "value": "1" },
    { "name": "API_TIMEOUT_MS", "value": "3000000" }
  ]
}
```

保存后执行 **Developer: Reload Window**，或完全退出并重启 VS Code。

## 验证连接

在项目目录运行：

```bash
claude
```

发送一条简短消息。能够正常返回内容，且没有认证、连接或模型错误，即表示 Kimi K3 已接入。每次修改 `settings.json` 后，都需要完全重启 Claude Code。

## 常见错误

| 错误 | 检查内容 |
| --- | --- |
| `401` | 重新将 BetterToken API Key 粘贴到 `ANTHROPIC_AUTH_TOKEN`。 |
| `404` 或 endpoint 错误 | Base URL 必须是 `https://bettertoken.ai`，不要添加 `/v1` 或 `/messages`。 |
| 模型不存在 | 三个 `ANTHROPIC_DEFAULT_*_MODEL` 都填写 Setup 弹窗中可用的 `kimi-k3`。 |
| 配置未生效 | 检查文件路径，并完全重启 Claude Code 或 VS Code。 |

## 技术说明

<Accordion title="为什么要映射三个模型角色">
  Claude Code 会请求 Haiku、Sonnet 和 Opus 三个角色。把 `kimi-k3` 映射到三个变量后，每个角色都会使用这个可用的 Model ID。Claude Code 会自行添加 Anthropic Messages 路径，因此 Base URL 后不要添加 `/v1`。
</Accordion>
