## 简短答案

在 Claude Code 中切换 Sonnet、Opus 或其他模型时，优先使用工具支持的 `/model` 入口或官方模型配置方式。

需要注意：模型别名、完整 model ID、不同 provider 的模型映射并不总是一样。网页里看到的营销名称，也不一定是 API 可识别的模型 ID。

如果你通过第三方网关接入，应该以网关模型广场或 provider 文档中可复制的 model ID 为准。

## 什么时候需要理解它

- 你想在便宜模型和高能力模型之间切换
- 你看到 Sonnet / Opus / Haiku 的别名，但不知道该填什么
- 你使用第三方 Base URL 或模型网关
- 你想控制 Claude Code 的 token 成本
- 你遇到 model not found 或模型名不生效

## 模型名的三层含义

| 层级 | 说明 |
| --- | --- |
| 展示名称 | 页面上看到的名称，方便人理解 |
| 别名 | 工具内的简写或快捷选择 |
| Model ID | API 请求真正识别的模型标识 |

切换模型时，真正决定请求是否成功的是 Model ID 是否被当前 provider 识别。

## 推荐做法

1. 先确认当前 provider 支持哪些模型。
2. 使用 Claude Code 的 `/model` 或官方配置入口切换。
3. 如果使用第三方网关，从模型广场复制可用 model ID。
4. 把模型选择和成本控制一起考虑。
5. 不要在配置中手写猜测的模型名称。

## 关于 BetterToken

如果你通过 BetterToken 接入 Claude Code，请从<a href={"{{model-plaza-url}}"}>模型广场</a>复制当前可用的模型 ID。Claude 提供商和 GPT 提供商的模型适用协议不同，不要混用。

模型选择会影响输出质量、速度和用量成本。用量记录可以帮助你比较不同模型在真实任务中的消耗。
