## Короткий ответ

Не выбирайте модель только по названию. Сначала проверьте, какой protocol и какая группа ключа нужны вашему инструменту. Затем выбирайте модель по типу задачи, качеству, скорости, размеру контекста и стоимости.

Если вы используете BetterToken, Claude Code обычно использует **группу Claude**. Codex CLI, Cursor, Cline, OpenCode, OpenClaw и другие внешние инструменты обычно используют **группу GPT**. Model ID копируйте из <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Когда это нужно

- Вы не знаете, выбрать **группу Claude** или **группу GPT**
- Вы переключаетесь между Claude Code, Codex CLI, Cursor, Cline и похожими инструментами
- Модель работает, но стоит слишком дорого, отвечает медленно или не хватает контекста
- Вам нужна более дешевая модель для пакетных задач
- Вы хотите подключить один API gateway к нескольким AI coding-инструментам

## Сначала инструмент, потом модель

Первый шаг — не сравнение рейтингов моделей. Сначала проверьте, какой protocol ожидает клиент.

| Сценарий | Рекомендуемая группа ключа | Частый Base URL |
| --- | --- | --- |
| Claude Code | Группа Claude | `{{anthropic-base-url}}` |
| Claude Desktop Gateway | Группа Claude или группа из локальной gateway-конфигурации | По настройкам gateway |
| Codex CLI | Группа GPT | `{{openai-base-url}}` |
| Cursor | Группа GPT | `{{openai-base-url}}` |
| Cline | Группа GPT | `{{openai-base-url}}` |
| OpenCode / OpenClaw | Группа GPT | `{{openai-base-url}}` |

Если protocol или группа ключа выбраны неверно, модель может существовать, но запрос завершится ошибкой `model not found`, ошибкой авторизации или неверным форматом запроса.

## Выбирайте по типу задачи

| Тип задачи | Что важнее |
| --- | --- |
| Сложный код, архитектура, долгие задачи | Качество reasoning, context window, стабильность tool calls |
| Ежедневные вопросы и легкая генерация | Скорость и стоимость |
| Пакетный перевод, классификация, summary | Цена за единицу, пропускная способность, стабильность |
| Code review и техническая документация | Понимание кода, длинный контекст, стабильный вывод |
| Исследовательские задачи | Сначала средняя по стоимости модель, затем более сильная модель для ключевых шагов |

Не отправляйте все задачи самой дорогой модели по умолчанию. Многие пакетные задачи не требуют глубокого reasoning или высокой креативности. Для них часто лучше подходят быстрые и более дешевые модели.

## Рекомендуемый порядок

1. Проверьте, поддерживает инструмент OpenAI-compatible или Anthropic-compatible API.
2. По инструменту выберите **группу Claude** или **группу GPT**.
3. Скопируйте актуальный Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a>.
4. Проверьте качество, скорость и стоимость на небольшой задаче.
5. Посмотрите usage в dashboard, прежде чем использовать модель постоянно.
6. Оставьте более сильную модель как запасной вариант для сложных задач, не ограничивайтесь одной моделью.

## Частые ошибки

- Смотреть только на отображаемое имя и не проверять Model ID.
- Использовать модель из **группы Claude** в GPT / OpenAI-compatible инструменте.
- Использовать модель из **группы GPT** в Anthropic-compatible настройке Claude Code.
- Считать, что самая новая модель подходит для любой задачи.
- Сравнивать только качество ответа и не учитывать контекст, скорость и стоимость.
- Переводить production-трафик на новую модель без малого теста.

## О BetterToken

BetterToken дает единое место для управления API Keys, балансом и usage records. Вы можете управлять model calls в одном dashboard, но каждый инструмент всё равно должен использовать поддерживаемый им protocol и группу ключа.

Короткое правило:

- Claude Code использует **группу Claude** и `{{anthropic-base-url}}`
- Codex CLI, Cursor, Cline, OpenCode и OpenClaw используют **группу GPT** и `{{openai-base-url}}`
