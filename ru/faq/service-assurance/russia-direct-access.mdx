## Короткий ответ

Региональный сайт для России рассчитан на прямой доступ из России. В обычном сценарии сайт и API endpoints доступны без VPN.

Если вы из России используете Claude Code, Codex CLI, Cursor, Cline, OpenCode, OpenClaw или другой внешний инструмент, главное — указать правильный Base URL, API Key и Model ID. Дополнительный VPN обычно не нужен.

## Рекомендуемые адреса

| Сценарий | Рекомендуемый адрес |
| --- | --- |
| Сайт и консоль | `{{anthropic-base-url}}` |
| Документация | `{{site-url}}` |
| Claude Code / Anthropic-compatible | `{{anthropic-base-url}}` |
| Codex CLI, Cursor, Cline и другие OpenAI-compatible инструменты | `{{openai-base-url}}` |

Российский региональный сайт использует домен LLMEasy. Base URL, регистрация, консоль и model plaza должны открываться через LLMEasy.

## Когда VPN не нужен

- Доступ к сайту и консоли LLMEasy
- Создание и управление API Keys
- Настройка Anthropic-compatible endpoint в Claude Code
- Настройка OpenAI-compatible endpoint в Codex CLI, Cursor, Cline, OpenCode или OpenClaw
- Просмотр документации, model plaza и usage records

VPN может отправить запросы через нестабильный маршрут. Из-за этого растет задержка, появляются ошибки TLS verification или срабатывают risk controls. Если у вашей корпоративной сети нет особых ограничений, не используйте VPN как настройку по умолчанию.

## Если сервис не открывается, сначала проверьте это

1. Проверьте домен: не путайте основной сайт и сайт документации.
2. Используйте HTTPS: адрес должен начинаться с `https://`.
3. Проверьте системное время на устройстве. Неверное время может ломать TLS certificate verification.
4. Проверьте другую сеть, например переключитесь с офисного Wi-Fi на мобильную точку доступа.
5. Проверьте, не блокирует ли запрос локальный firewall, proxy-инструмент или antivirus.
6. В настройках инструмента проверьте, что Base URL не содержит лишний путь. Например, не добавляйте `/v1` в Anthropic-compatible настройку Claude Code.

## Простые команды для проверки

Сначала можно проверить доступность сайта:

```bash
curl -I {{anthropic-base-url}}
curl -I {{site-url}}
```

Чтобы проверить OpenAI-compatible endpoint:

```bash
curl -I {{openai-base-url}}
```

`curl -I` проверяет соединение и response headers. Он не проверяет, работает ли ваш API Key. Чтобы проверить API Key, отправьте настоящий model request или используйте тест внутри инструмента.

## Частые ошибки

- Считать, что «VPN не нужен» означает отсутствие проблем в любой сети.
- Указывать для Claude Code Base URL `{{openai-base-url}}`.
- Указывать для Codex CLI, Cursor или Cline корневой адрес без `/v1`.
- Постоянно переключаться между VPN, proxy и local gateway, из-за чего реальный маршрут запроса становится непонятным.
- Проверять только сайт документации и не проверять API Base URL.

## О BetterToken

Российский региональный сервис работает на домене LLMEasy. Пользователям из России лучше использовать региональные ссылки регистрации, консоль и API Base URLs, чтобы снизить неопределенность с оплатой, доступом и маршрутизацией.
