## Короткий ответ

OpenAI-compatible API и Anthropic-compatible API — это два разных compatibility layer. Оба могут использоваться для model requests, но request formats, fields, tool semantics и ожидания клиента отличаются.

Codex CLI, Cursor, Cline, OpenCode и OpenClaw обычно используют OpenAI-compatible endpoints. Claude Code и некоторые сценарии Claude Desktop Gateway используют Anthropic-compatible endpoints.

Не выбирайте только по названию модели. Сначала смотрите, какой protocol ожидает инструмент, затем используйте соответствующий Base URL, API Key и Model ID.

## Когда это важно

- Вы видите два Base URL и не знаете, какой выбрать
- Claude Code работает, а Codex или Cursor нет
- Codex работает, а Claude Code показывает endpoint или auth errors
- Вы хотите использовать один API Key в нескольких инструментах
- Вы настраиваете API gateway, model router или local proxy

## Ключевые понятия

| Понятие | Что означает |
| --- | --- |
| OpenAI-compatible API | Endpoint, следующий OpenAI-style request conventions |
| Anthropic-compatible API | Endpoint, следующий Anthropic / Claude request conventions |
| Base URL | API root address, который использует client |
| API Key | Credential выбранного provider |
| Model ID | Model identifier, доступный в этом provider и protocol |
| Gateway | Layer для compatibility, routing, billing или observability между client и providers |

## Как выбрать

Начинайте с инструмента:

| Инструмент | Типичный protocol | Base URL в этой документации |
| --- | --- | --- |
| Claude Code | Anthropic-compatible | `{{anthropic-base-url}}` |
| Claude Desktop Gateway | Anthropic-compatible или local route | По настройке Gateway |
| Codex CLI | OpenAI-compatible / Responses | `{{openai-base-url}}` |
| Cursor | OpenAI-compatible | `{{openai-base-url}}` |
| Cline | OpenAI-compatible provider | `{{openai-base-url}}` |
| OpenCode / OpenClaw | OpenAI-compatible | `{{openai-base-url}}` |

Если инструмент ожидает OpenAI-style API, не используйте Anthropic Base URL Claude Code. Если инструмент ожидает Anthropic-style API, не используйте OpenAI-compatible `/v1` endpoint.

## Частые ошибки

- Думать, что одно имя модели можно без изменений использовать во всех protocols.
- Вставлять OpenAI-compatible Base URL в Claude Code.
- Вставлять Anthropic-compatible Base URL в Codex, Cursor или Cline.
- Считать Claude.ai или ChatGPT subscription API Key.
- Менять только API Key, оставляя несовместимые Base URL и Model ID.

## О BetterToken

BetterToken предоставляет оба варианта: Anthropic-compatible и OpenAI-compatible. API Keys, баланс и usage history можно смотреть в одном dashboard, но каждый client должен использовать protocol, который он реально поддерживает.

Простое правило: Claude Code использует Anthropic-compatible; Codex, Cursor, Cline, OpenCode и OpenClaw обычно используют OpenAI-compatible.
