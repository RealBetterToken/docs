## Короткий ответ

Cursor MCP подключает external tools и data sources к AI workflow внутри редактора. Это не model API configuration и не замена OpenAI-compatible Base URL.

В Cursor MCP setup обычно связан с `mcp.json`, project или global settings, environment variables и tool approval.

## Когда это важно

- Вы хотите, чтобы Cursor использовал external tools
- Нужна project-specific MCP server configuration
- Вы хотите отличать project MCP от global MCP
- Вы хотите понять tool approval
- Вы думаете, что MCP заменяет API Key / Base URL

## MCP vs model API

| Пункт | Cursor MCP | OpenAI-compatible API |
| --- | --- | --- |
| Роль | Connect tools, data sources, context | Connect model provider |
| Main config | `mcp.json`, server, env, approval | API Key, Base URL, Model ID |
| Main risk | Tool permissions и data access | Authentication, billing, model availability |

## Рекомендуемая практика

1. Убедитесь, что добавляете tool capability, а не model provider.
2. Выберите global или project MCP config по Cursor docs.
3. Дайте MCP server только нужные environment variables.
4. Оставляйте tool approval для tools, которые пишут файлы или обращаются к external services.
5. Отдельно отлаживайте model API setup и MCP setup.

## О BetterToken

BetterToken — model API layer. Cursor MCP — tool layer. Их можно использовать вместе, но они не заменяют друг друга.

Если цель — сменить model routing, настройте `{{openai-base-url}}` и модель из **группы ключа GPT**. Если цель — дать Cursor доступ к external tools, настройте MCP.
