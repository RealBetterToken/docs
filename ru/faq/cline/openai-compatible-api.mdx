## Короткий ответ

В Cline выберите **OpenAI Compatible**, укажите `{{openai-base-url}}` в поле **Base URL**, вставьте API Key BetterToken и введите Model ID из **группы ключа GPT**. Не используйте Anthropic-compatible адрес для Claude Code и не выбирайте официальный provider **OpenAI**.

| Поле Cline | Значение BetterToken |
| --- | --- |
| API Provider | `OpenAI Compatible` |
| Base URL | `{{openai-base-url}}` |
| API Key | Ваш API Key BetterToken |
| Model ID | Model ID из **группы ключа GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a> |

<Info>
  Эта FAQ отвечает на вопросы о значениях полей и ошибках подключения. Если нужно начать с установки, используйте [полную инструкцию по Cline](/ru/ai-tools/cline).
</Info>

## Полная настройка

<Steps>
  <Step title="Подготовьте API Key и Model ID">
    Создайте API Key, затем скопируйте актуальный Model ID из **группы ключа GPT** в <a href={"{{model-plaza-url}}"}>model plaza</a>. Введите ID без изменений и не заменяйте его отображаемым названием модели.
  </Step>
  <Step title="Откройте настройки Cline">
    Откройте панель Cline в VS Code и нажмите значок шестерёнки.
  </Step>
  <Step title="Выберите OpenAI Compatible">
    В поле **API Provider** выберите **OpenAI Compatible**. Этот provider подключает Cline к стороннему OpenAI-compatible endpoint.
  </Step>
  <Step title="Заполните четыре основных поля">
    Укажите Provider, Base URL, API Key и Model ID по таблице выше. В Base URL обязательно должен присутствовать `/v1`.

    Если отображается **Use Azure Identity Authentication**, оставьте этот параметр выключенным. BetterToken использует API Key, а не Azure Identity.
  </Step>
  <Step title="Проверьте подключение">
    Нажмите **Verify** в Cline. После успешной проверки создайте задачу и отправьте простой запрос, чтобы убедиться, что модель отвечает и tool calls работают.
  </Step>
</Steps>

## Нужно ли менять дополнительные поля?

Cline может показывать Context Window, Max Output Tokens, Image Support и Computer Use. Для первого подключения оставьте значения по умолчанию. Меняйте их только тогда, когда model plaza или описание модели явно подтверждает соответствующую возможность и ограничение.

Цены моделей могут меняться. Не полагайтесь на фиксированную цену в локальных настройках Cline; актуальные модели и цены смотрите в <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Частые ошибки

| Симптом | Что проверить | Решение |
| --- | --- | --- |
| `Invalid API Key` или `401` | Ключ скопирован полностью и принадлежит нужному аккаунту | Скопируйте Key заново, уберите пробелы по краям и не используйте официальный OpenAI Key |
| `Model Not Found` | Model ID относится к группе ключа GPT | Скопируйте доступный ID из model plaza без изменения регистра или суффикса |
| `404` или endpoint not found | В Base URL отсутствует `/v1` | Используйте `{{openai-base-url}}`, а не Anthropic-compatible адрес Claude Code |
| Тайм-аут подключения | Локальная сеть, firewall или старые proxy settings | Проверьте доступ к BetterToken в браузере, отключите неработающий proxy и повторите **Verify** |
| Применяется старая конфигурация | Сессия Cline не обновилась | Сохраните настройки, заново откройте Cline или выполните **Developer: Reload Window** |

## Для каких сценариев подходит эта настройка

Эти значения подключают Cline к моделям **группы ключа GPT** через OpenAI-compatible endpoint BetterToken. Они не меняют Cline Rules, Memory Bank, MCP или локальные разрешения инструментов.

Для Claude Code используйте Anthropic-compatible адрес без `/v1` и [инструкцию по Claude Code](/ru/ai-tools/claude-code).
