## Короткий ответ

Чтобы использовать OpenAI-compatible API в Cline, выберите provider **OpenAI Compatible**, затем заполните Base URL, API Key и Model ID.

Base URL — API endpoint provider. API Key — authentication credential. Model ID — model name или identifier, который распознает текущий provider.

## Когда это важно

- Вы хотите использовать third-party model provider в Cline
- У вас есть OpenAI-compatible `/v1` endpoint
- Нужны BYOK или custom models
- Вы видите Invalid API Key, Model Not Found или connection failures
- Вы хотите, чтобы Cline и другие external tools использовали один model routing layer

## Значение полей

| Поле | Значение |
| --- | --- |
| API Provider | Выберите `OpenAI Compatible` |
| Base URL | OpenAI-compatible endpoint от provider |
| API Key | Secret key, созданный provider |
| Model ID | Model ID, который поддерживает provider |
| Model configuration | Advanced settings: context window, output limit, prices |

## Рекомендуемые шаги

1. Выберите `OpenAI Compatible` в Cline settings.
2. Введите Base URL.
3. Введите API Key.
4. Выберите или введите Model ID.
5. Проверьте через verification flow Cline или простой запрос.

## Частые ошибки

- Смешивать official OpenAI URL с third-party API Key.
- Вставлять Anthropic-compatible URL в OpenAI-compatible provider.
- Использовать Model ID, который provider не поддерживает.
- Игнорировать context window и output limit configuration.
- Считать Cline Rules или Memory Bank API configuration.

## О BetterToken

Cline может подключаться к BetterToken через OpenAI-compatible provider. Используйте `{{openai-base-url}}` как Base URL, BetterToken key как API Key и model ID из **группы ключа GPT**.

Если у вас есть Claude Code Anthropic-compatible address, не вставляйте его в Cline OpenAI Compatible provider.
