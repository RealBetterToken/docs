title: "Как использовать Codex и другие third-party модели в Claude Desktop?"
sidebarTitle: "Third-party модели в Claude Desktop"
description: "Используйте локальный route CC Switch, чтобы запускать модели Codex group в Claude Desktop."
---

В новых версиях Claude Desktop изменился способ настройки third-party API gateways. В Gateway mode Claude Desktop строже проверяет model IDs, поэтому неофициальные model IDs, например GPT, DeepSeek или GLM, могут блокироваться.

Типичный симптом — предупреждение в верхней части страницы: `Your provider setup needs a fix Some required fields are missing or malformed. Open Setup to finish configuring it.` Одновременно selector third-party model в левом нижнем углу пуст, а Claude Desktop показывает только состояние **Legacy Model**.

<Frame>
  <img
    src="/images/claude-desktop-third-party-models/provider-setup-needs-fix.png"
    alt="Claude Desktop показывает Your provider setup needs a fix, при этом selector third-party model пуст."
    style={{ borderRadius: '0.5rem' }}
  />
</Frame>

Если вы хотите продолжать использовать Codex или другие third-party модели в Claude Desktop, маршрутизируйте запросы через CC Switch: настройте BetterToken в разделе **Claude Code** в CC Switch, затем введите local service address CC Switch в Claude Desktop Gateway.

<Info>
  Этот путь предназначен для API keys **Codex group**. Не вводите `{{openai-base-url}}` напрямую в Claude Desktop Gateway.
</Info>

## Шаги настройки

<Steps>
  <Step title="Скачайте Claude Desktop">
    Скачайте актуальное приложение Claude Desktop по официальной ссылке:

    [Download Claude for Mac](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect)

    После установки не входите в Claude account. Перейдите к следующему шагу и включите developer mode.
  </Step>

  <Step title="Включите developer mode">
    Откройте Claude Desktop, затем в macOS menu bar выберите **Help** → **Troubleshooting** → **Enable Developer Mode**.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/enable-developer-mode-menu.png"
        alt="Выбор Enable Developer Mode в меню Help приложения Claude Desktop."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    В окне подтверждения нажмите **Enable**, затем перезапустите Claude Desktop.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/developer-mode-confirm.png"
        alt="Подтверждение developer mode в Claude Desktop."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Откройте настройки third-party inference">
    После перезапуска в macOS menu bar появится меню **Developer**.

    Выберите **Developer** → **Configure Third-Party Inference...**.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/configure-third-party-inference.png"
        alt="Выбор Configure Third-Party Inference в меню Developer."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Откройте Claude Code в CC Switch и добавьте provider">
    Откройте CC Switch, переключитесь на **Claude Code** и нажмите **Add Provider**.

    <Frame>
      <img
        src="/images/cc-switch/claude-code-add-provider.png"
        alt="Страница Claude Code в CC Switch, кнопка добавления provider в правом верхнем углу."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Заполните базовые поля">
    - **Provider Name**: `BetterToken`
    - **Base URL**: `{{anthropic-base-url}}`
    - **API Key**: ваш API Key BetterToken

    Номера на скриншоте соответствуют:

    1. **Provider Name**
    2. **API Key**
    3. **Base URL**

    <Frame>
      <img
        src="/images/cc-switch/claude-code-basic-fields.png"
        alt="Страница редактирования provider в CC Switch с полями Provider Name, API Key и Base URL."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Установите API format и model mappings">
    Откройте **Advanced Options** и установите **API Format** в **OpenAI Responses API**.

    <Frame>
      <img
        src="/images/cc-switch/claude-code-api-format.png"
        alt="Advanced Options в CC Switch, API Format установлен в OpenAI Responses API."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    В **Model Mapping** нажмите **Fetch Model List**. Явно выберите значения в dropdown для **Primary Model**, **Thinking Model**, **Haiku Default Model**, **Sonnet Default Model** и **Opus Default Model**.

    <Frame>
      <img
        src="/images/cc-switch/claude-code-model-mapping.png"
        alt="Раздел model mapping в CC Switch с Fetch Model List и mappings для Primary, Thinking, Haiku, Sonnet и Opus."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Используйте model IDs из текущих моделей **Codex group** в BetterToken model plaza (`{{model-plaza-url}}`).
  </Step>

  <Step title="Сохраните, переключитесь и включите proxy">
    После сохранения вернитесь к списку providers:

    1. Установите только что сохраненный provider BetterToken как **In use**
    2. Включите **CC Switch proxy** в левом верхнем углу

    <Frame>
      <img
        src="/images/cc-switch/claude-code-enable-proxy.png"
        alt="После сохранения provider BetterToken выбран активным, а proxy toggle CC Switch включен в левом верхнем углу."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Откройте настройки CC Switch">
    Вернитесь на главный экран CC Switch и нажмите **Settings** в левом верхнем углу.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/cc-switch-settings-entry.png"
        alt="Главный экран CC Switch с выделенной кнопкой Settings в левом верхнем углу."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Проверьте routing и скопируйте service address">
    Откройте настройки **Routing**. Убедитесь, что главный routing switch и route switch **Claude** включены. Затем скопируйте **Service address** ниже.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/cc-switch-route-service.png"
        alt="Страница routing settings в CC Switch с главным route switch, Claude route switch и кнопкой копирования service address."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Введите Gateway base URL в Claude Desktop">
    Вернитесь в окно third-party inference settings Claude Desktop и выберите **Gateway**. Вставьте **Service address** из CC Switch в **Gateway base URL**, затем введите API Key BetterToken.

    Установите **Gateway auth scheme** в `bearer`.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/claude-gateway-local-route.png"
        alt="Страница Gateway settings в Claude Desktop с локальным service address из CC Switch."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Добавьте model list и примените локально">
    Добавьте модели, которые должны отображаться в **Model list**. Для каждой модели нужны и **Model ID**, и **Display name**.

    Например:

    | Model ID | Display name |
    |----------|--------------|
    | `claude-opus-4` | `Claude Opus 4` |

    После заполнения списка нажмите **Apply locally**.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/claude-model-list-codex-group.png"
        alt="Model list в Claude Desktop с заполненными Model ID и Display name, кнопка Apply locally доступна."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Подтвердите relaunch приложения">
    После записи локальной конфигурации Claude попросит перезапуск. Нажмите **Relaunch now**, чтобы новая gateway-конфигурация вступила в силу.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/relaunch-claude.png"
        alt="Claude Desktop просит relaunch, кнопка Relaunch now выделена."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Войдите через Gateway">
    После перезапуска подождите около 3 секунд, пока появится выбор способа входа.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/continue-with-gateway.png"
        alt="Claude Desktop показывает вариант Continue with Gateway."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Выберите **Continue with Gateway**. Когда Claude откроется, в левом нижнем углу появится **Cowork 3P | Gateway**, и можно начинать работу.

    <Frame>
      <img
        src="/images/claude-desktop-bettertoken-api/gateway-ready.png"
        alt="Claude Desktop готов к работе после входа через Gateway."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## Диагностика

Если вы все еще видите **Your provider setup needs a fix**, сначала проверьте:

1. Provider BetterToken в CC Switch установлен как **In use**
2. **API Format** установлен в **OpenAI Responses API**
3. В **Model Mapping** явно выбраны модели Codex group для Primary, Thinking, Haiku, Sonnet и Opus
4. **CC Switch proxy**, главный routing switch и route switch **Claude** включены
5. **Gateway base URL** в Claude Desktop использует local service address, скопированный из CC Switch
6. **Model list** содержит и **Model ID**, и **Display name** для каждой модели
