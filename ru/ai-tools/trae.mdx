При подключении BetterToken к TRAE выберите OpenAI-style provider и используйте ID модели из группы **GPT**.

## Требования

- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)

## Настройка

<Steps>
  <Step title="Откройте настройки">
    В режиме **IDE** нажмите иконку **Settings** в правом верхнем углу, чтобы открыть центр настроек.

    Также можно открыть режим **SOLO** и нажать иконку **Settings** в правом верхнем углу панели чата.
  </Step>

  <Step title="Откройте панель модели">
    В левом меню выберите **Model**, чтобы открыть панель **Model**.
  </Step>

  <Step title="Добавьте модель">
    Нажмите **+ Add model**.

    ![Панель моделей TRAE с выделенными входом в настройки, пунктом Model и кнопкой Add model.](/images/trae/add-model.png)
  </Step>

  <Step title="Заполните конфигурацию модели">
    Когда появится окно **Add model**, заполните поля так:

    | Поле | Значение |
    |------|----------|
    | Provider | `OpenAI` |
    | Model | `Custom model` |
    | Model ID | ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | API key | ваш API Key из консоли BetterToken |
    | Custom request URL | `{{chat-completions-url}}` |

    ![Окно добавления модели TRAE с выбранным OpenAI, custom model и полями model ID, API key и custom request URL.](/images/trae/model-config.png)
  </Step>

  <Step title="Сохраните и начните использовать">
    Нажмите **Confirm**, чтобы сохранить конфигурацию, затем выберите новую модель группы GPT.
  </Step>
</Steps>

<Note>
  BetterToken поддерживает TRAE только через модели группы **GPT**. Не используйте фиксированные имена Claude-моделей и не задавайте custom request URL как `{{openai-base-url}}`.
</Note>
