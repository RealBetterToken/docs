MonkeyCode — enterprise-платформа для AI-разработки. При подключении BetterToken используйте группу **GPT** с OpenAI-style протоколом.

## Требования

- Аккаунт MonkeyCode ([регистрация в MonkeyCode](https://monkeycode.ai))
- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)

## Настройка

<Steps>
  <Step title="Войдите в MonkeyCode">
    Откройте [MonkeyCode](https://monkeycode.ai) и войдите в аккаунт.
  </Step>

  <Step title="Откройте системные настройки">
    Перейдите на страницу задачи и нажмите **Settings** в правом нижнем углу.
  </Step>

  <Step title="Привяжите AI-модель">
    В разделе **AI Model** нажмите **Bind**.
  </Step>

  <Step title="Заполните конфигурацию BetterToken">

    | Поле | Значение |
    |------|----------|
    | Model API URL | `{{openai-base-url}}` |
    | API Key | ваш API Key BetterToken |
    | API format | `OpenAI` или `OpenAI Compatible` по текущему названию в UI |
    | Model name | ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Мы не нашли официального требования MonkeyCode, по которому `User-Agent` обязателен для BetterToken. Начните с `Base URL`, API key и model ID на этой странице.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Сохраните и начните использовать">
    Нажмите **Save**, затем вернитесь на главную страницу и выберите настроенную модель.
  </Step>

  <Step title="Перезапустите MonkeyCode">
    После сохранения конфигурации обновите страницу или заново откройте MonkeyCode перед использованием новой модели.
  </Step>
</Steps>

<Note>
  Если вам нужны extra headers, следуйте текущей документации MonkeyCode или требованиям вашего upstream gateway.
</Note>
