Hermes Agent — это AI-agent для локальных terminal workflows. Его можно использовать как помощника для разработки, а также комбинировать skills, MCP, scheduled tasks и subagents для более длинных автоматизированных задач.

При подключении BetterToken используйте API Key из группы **GPT** и OpenAI-compatible endpoint.

<Info>
  Эта страница описывает только подключение Hermes Agent через группу GPT. ID модели копируйте из <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Info>

## Требования

- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)
- API Key относится к группе **GPT**
- ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>
- macOS, Linux или Windows WSL2

## Установка Hermes Agent

<Tabs>
  <Tab title="macOS / Linux / WSL2">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
    ```
  </Tab>

  <Tab title="Windows">
    На Windows сначала используйте WSL2. Native PowerShell support зависит от текущей версии Hermes Agent. Если вы используете native Windows, следуйте подсказкам установщика вашей версии.
  </Tab>
</Tabs>

## Настройка

<Tabs>
  <Tab title="Интерактивная настройка">
    <Steps>
      <Step title="Запустите выбор модели">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="Выберите OpenAI или OpenAI Compatible provider">
        Выберите **OpenAI** или **OpenAI Compatible** в списке providers.
      </Step>

      <Step title="Заполните конфигурацию BetterToken">
        Введите:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: ваш API Key BetterToken
        - **Model**: ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a>
      </Step>

      <Step title="Перезапустите Hermes Agent">
        После обновления конфигурации завершите текущую сессию Hermes Agent и запустите ее снова.
      </Step>

      <Step title="Запустите Hermes Agent">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI config">
    Если вам удобнее копировать команды, запишите конфигурацию Hermes Agent напрямую.

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_BETTERTOKEN_API_KEY"
    hermes config set llm.model "YOUR_GPT_MODEL_ID"
    ```

    Замените `YOUR_BETTERTOKEN_API_KEY` на ваш API Key BetterToken, а `YOUR_GPT_MODEL_ID` — на ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Затем запустите Hermes Agent:

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="Environment variables">
    Если вы не хотите сохранять API Key в конфигурации Hermes Agent, экспортируйте его в текущем shell.

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_BETTERTOKEN_API_KEY"
    export HERMES_MODEL="YOUR_GPT_MODEL_ID"
    hermes
    ```

    Эти переменные действуют только в текущей shell-сессии. В новом терминале экспортируйте их снова или добавьте в свой shell profile.
  </Tab>
</Tabs>

## Кратко о возможностях

| Возможность | Для чего нужна |
| --- | --- |
| Terminal UI | Общение с agent прямо в терминале |
| Skills | Сохранение повторяемых workflows |
| MCP | Подключение локальных или удаленных инструментов |
| Scheduled tasks | Запуск задач по расписанию и recurring workflows |
| Subagents | Разделение сложной работы между специализированными agents |
| Message gateway | Подключение agent к дополнительным message entry points |

## Миграция с OpenClaw

Если вы уже используете OpenClaw, сначала проверьте, есть ли в вашей текущей версии Hermes Agent команда миграции. Перед изменениями запустите dry run.

```bash
hermes claw migrate --dry-run
```

После проверки результата выполните миграцию:

```bash
hermes claw migrate
```

После миграции все равно проверьте **Base URL**, API Key и model ID в Hermes Agent. Они должны соответствовать `{{openai-base-url}}`, вашему API Key BetterToken и ID модели группы GPT.

## Troubleshooting

- Если запросы не отвечают или завершаются ошибкой, проверьте, что **Base URL** равен `{{openai-base-url}}`. Обычно здесь не нужно добавлять `/chat/completions`.
- Если Hermes сообщает, что модель не существует, проверьте, что **Model** — это ID модели группы GPT из <a href={"{{model-plaza-url}}"}>model plaza</a>.
- Если возникает ошибка авторизации, проверьте лишние пробелы в API Key и убедитесь, что ключ относится к группе **GPT**.
- Если после изменения настроек Hermes все еще использует старую модель, завершите текущую сессию Hermes Agent и снова выполните `hermes`.
- BetterToken обычно не требует дополнительного `User-Agent` или custom headers. Добавляйте headers только если этого явно требует ваш custom gateway, tenant routing, observability или caching layer.

<Note>
  Не коммитьте реальные API Keys в репозиторий. Для командных конфигураций используйте environment variables или локальную конфигурацию.
</Note>
