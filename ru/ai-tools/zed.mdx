Zed поддерживает custom LLM providers. При использовании BetterToken выберите OpenAI route и вставьте ID модели из группы **GPT**.

## Требования

- Установленный Zed (см. [документацию Zed](https://zed.dev/docs))
- API Key BetterToken (<a href={"{{register-url}}"}>зарегистрироваться</a>)

## Настройка

<Steps>
  <Step title="Откройте AI panel">
    Нажмите иконку ✨ в правом нижнем углу Zed.
  </Step>

  <Step title="Откройте настройки">
    Откройте меню в панели и выберите **Settings**.
  </Step>

  <Step title="Добавьте provider">
    В **LLM Provider** нажмите **+ Add Provider** и выберите **OpenAI**.
  </Step>

  <Step title="Заполните конфигурацию BetterToken">

    | Поле | Значение |
    |------|----------|
    | Provider Name | `BetterToken` |
    | API URL | `{{openai-base-url}}` |
    | API Key | ваш API Key BetterToken |
    | Model Name | ID модели группы **GPT** из <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Добавляйте extra headers только если это явно требует официальная документация">
    Официальная документация Zed для OpenAI-compatible и custom providers фокусируется на `api_url`, `available_models` и API key. Extra `User-Agent` не указан как обязательный шаг BetterToken.

    Если вы также используете custom gateway, tenant routing, observability или кеширующий слой, добавляйте headers только по документации этого upstream-сервиса.
  </Step>

  <Step title="Сохраните provider">
    Нажмите **Save Provider**, затем выберите настроенную модель.
  </Step>

  <Step title="Перезапустите Zed">
    После сохранения provider перезапустите Zed перед выбором настроенной модели.
  </Step>
</Steps>

<Note>
  Сначала проверьте `API URL`, API key, model ID и версию инструмента. Не считайте `User-Agent` обязательной настройкой BetterToken.
</Note>
