Yingdao AI Power — no-code продукт для создания AI-приложений. Он агрегирует существующие AI-модели и дает простой набор инструментов для создания AI apps.

При подключении BetterToken к Yingdao AI Power добавьте модель `OpenAI-API-compatible` и используйте ID модели из группы **GPT**.

## Требования

- API Key BetterToken (зарегистрироваться (`{{register-url}}`))
- ID модели группы **GPT** из model plaza (`{{model-plaza-url}}`)

## Настройка

<Steps>
  <Step title="Откройте управление моделями">
    Перейдите в **Enterprise management**, затем откройте **Model management**. Найдите **OpenAI-API-compatible** и нажмите **Add model**.

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-management.png"
        alt="Страница управления моделями Yingdao AI Power с выделенным OpenAI-API-compatible и входом Add model."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Заполните конфигурацию модели">
    В окне **Authorization management: OpenAI-API-compatible** заполните поля так:

    | Поле | Значение |
    |------|----------|
    | Model type | `LLM` |
    | Model name | ID модели группы **GPT** из model plaza (`{{model-plaza-url}}`) |
    | Request URL | `{{chat-completions-url}}` |
    | API key | Выберите только ключ, соответствующий группе `Codex*` |
    | Max output token limit | `128000` |
    | Vision understanding | Выберите **Yes** |
    | Function calling | Выберите **Yes** |

    <Frame>
      <img
        src="/images/yingdao-ai-power/model-config.png"
        alt="Окно авторизации OpenAI-API-compatible в Yingdao AI Power с настройками model name, request URL, API key, max output token limit, vision understanding и function calling."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Включите vision understanding">
    Установите **Vision understanding** в **Yes**, чтобы модель можно было выбрать в компоненте **Workflow - multimodal large model**.

    <Frame>
      <img
        src="/images/yingdao-ai-power/workflow-multimodal-model.png"
        alt="Страница workflow в Yingdao AI Power, где компонент multimodal large model может выбрать OpenAI-API-compatible и добавленную модель."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Включите function calling">
    Установите **Function calling** в **Yes**, чтобы модель можно было выбрать в **Agent - Tools**.

    <Frame>
      <img
        src="/images/yingdao-ai-power/agent-tool-model.png"
        alt="Страница Agent tools в Yingdao AI Power, где в настройках модели можно выбрать OpenAI-API-compatible и добавленную модель."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Добавьте другие модели">
    Если нужно несколько моделей, повторите шаги выше. Для каждой модели используйте соответствующий ID из группы **GPT**.
  </Step>
</Steps>

<Note>
  В Yingdao AI Power поле **Request URL** должно содержать полный chat completions endpoint `{{chat-completions-url}}`. Не используйте только `{{openai-base-url}}`.
</Note>
