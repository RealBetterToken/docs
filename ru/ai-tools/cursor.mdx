При подключении BetterToken к Cursor используйте OpenAI-compatible endpoint. Внешние инструменты используют Codex group, поэтому копируйте актуальный ID модели из model plaza (`{{model-plaza-url}}`).

<Warning>
  Cursor позволяет настраивать custom models только пользователям платного advanced tier или выше. Если в вашем аккаунте или версии клиента нет опций custom model, API Key или Base URL, сначала проверьте план Cursor и версию клиента.
</Warning>

<Warning>
  **Известное ограничение:** **Override OpenAI Base URL** — глобальная настройка. Когда она включена, она влияет на все API keys, настроенные в Cursor, включая Anthropic / GPT keys для встроенных моделей Cursor. Официальное сообщество Cursor подтверждало это поведение: Base URL влияет на все API keys и модели ([обсуждение](https://forum.cursor.com/t/cursor-models-fail-when-using-byok-openai-key-with-overridden-base-url-glm-4-7/147218)).

  Если встроенные Claude / GPT модели Cursor перестали работать после включения **Override OpenAI Base URL**, выключайте **Override OpenAI Base URL**, когда не используете BetterToken. Cursor пока не поддерживает отдельный Base URL для каждой модели; эта возможность отслеживается как feature request ([feature request](https://forum.cursor.com/t/custom-base-urls-for-each-custom-model/147219)).
</Warning>

## Требования

- Установленный Cursor ([скачать Cursor](https://www.cursor.com))
- API Key BetterToken (зарегистрироваться (`{{register-url}}`))
- API Key относится к **Codex group**, и вы будете выбирать модель из той же группы

## Настройка

<Steps>
  <Step title="Откройте страницу настроек моделей">
    В Cursor нажмите **Settings** в левом нижнем углу, затем перейдите в **Models** и прокрутите до **API Keys**.

    <Frame>
      <img
        src="/images/cursor/settings-api-key.png"
        alt="Страница настроек Cursor с полями Settings, Models, API Keys, OpenAI API Key и Override OpenAI Base URL."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Введите Base URL и API Key">
    В **API Keys** заполните поля в таком порядке:

    1. Включите **Override OpenAI Base URL**
    2. Введите `{{openai-base-url}}` в поле Base URL
    3. Вставьте API Key BetterToken в **OpenAI API Key**
    4. После заполнения URL и ключа включите toggle **OpenAI API Key**

    Введите ключ до включения toggle. Так Cursor покажет dialog подтверждения авторизации.
  </Step>

  <Step title="Включите OpenAI API Key">
    В dialog подтверждения нажмите **Enable OpenAI API Key**.

    <Frame>
      <img
        src="/images/cursor/enable-openai-api-key.png"
        alt="Dialog Cursor с запросом включить собственный OpenAI API key."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Обновите список моделей и включите модели">
    В **Models** нажмите кнопку refresh справа перед выбором модели. Дождитесь завершения обновления списка.

    Выбирайте только модели из той же группы BetterToken, что и ваш API Key. С API Key Codex group выберите ID модели из **Codex group** в model plaza, затем включите toggle для этой модели.

    <Frame>
      <img
        src="/images/cursor/models-refresh-select.png"
        alt="Раздел Models в Cursor с кнопкой refresh и toggle моделей."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Вернитесь в chat и выключите Auto">
    После настройки вернитесь в chat Cursor и откройте model picker под полем ввода. Если включен **Auto**, сначала выключите **Auto**.

    <Frame>
      <img
        src="/images/cursor/chat-disable-auto.png"
        alt="Model picker в чате Cursor с toggle Auto, который нужно выключить."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>

  <Step title="Выберите модель и начните чат">
    Выберите включенную модель Codex group и начните общение.

    <Frame>
      <img
        src="/images/cursor/chat-select-model.png"
        alt="Поле ввода Cursor chat с выбранной включенной моделью."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>

## Примечания

- Не используйте ID моделей Claude group в Codex / OpenAI-compatible flow
- Не используйте жестко заданные имена Claude-моделей; берите актуальный ID модели Codex group из model plaza (`{{model-plaza-url}}`)
