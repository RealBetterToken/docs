## Что такое BetterToken?

BetterToken — это API-прокси для AI-инструментов разработки. В документации используются два режима подключения:

- **Claude Code / `ANTHROPIC_BASE_URL`**: используйте `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / внешние инструменты**: используйте `{{openai-base-url}}`

**Основные преимущества:**

- **Несколько источников**: одновременно подключены несколько поставщиков
- **Динамическая маршрутизация**: медленные или нестабильные upstream-пути обходятся автоматически
- **Фокус на ключевых сценариях**: надежность в первую очередь оптимизирована для Claude Code и экосистемы Codex
- **Два понятных режима**: выбирайте endpoint по протоколу, а не используйте один `base_url` во всех инструментах

## Два режима подключения

| Сценарий | Base URL | Примечания |
|----------|----------|------------|
| Claude Code | `{{anthropic-base-url}}` | Протокол Anthropic, без суффикса `/v1` |
| Codex / внешние инструменты | `{{openai-base-url}}` | OpenAI-совместимый протокол; внешние инструменты используют группу **GPT** |
