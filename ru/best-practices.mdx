## Храните API Key безопасно

**Используйте переменные окружения и не хардкодьте ключ.** Если записать API Key прямо в код или конфигурационный файл, его легко случайно отправить в систему контроля версий. Рекомендуемый вариант:

```bash
# Добавьте в ~/.zshrc или ~/.bashrc, чтобы переменная загружалась в каждой сессии
export BETTERTOKEN_API_KEY="your-api-key-here"
```

Для Claude Code лучше хранить секреты в поле `env` файла `settings.json`, а не раскрывать их в shell-конфигурации:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "your-api-key-here"
  }
}
```

**Периодически ротируйте API Key.** Если подозреваете утечку, сразу удалите ключ в панели управления и создайте новый.

## Задайте большой timeout

Ответы AI-моделей могут занимать время, особенно при сложных задачах reasoning. Укажите достаточно большой timeout, чтобы соединение не обрывалось раньше времени:

```json
{
  "env": {
    "API_TIMEOUT_MS": "3000000"
  }
}
```

`3000000` мс = 50 минут. Это подходит для глубокого reasoning и длинных agentic-задач.

## Очистите конфликтующие переменные окружения

Если вы раньше использовали официальные API Anthropic или OpenAI либо другой прокси-сервис, старые переменные окружения могут переопределить настройки BetterToken и незаметно отправить запросы не на тот endpoint.

Перед настройкой BetterToken проверьте и очистите:

```bash
# Проверить, существуют ли переменные
echo $ANTHROPIC_AUTH_TOKEN
echo $ANTHROPIC_BASE_URL
echo $OPENAI_API_KEY
echo $OPENAI_BASE_URL

# Очистить их
unset ANTHROPIC_AUTH_TOKEN
unset ANTHROPIC_BASE_URL
unset OPENAI_API_KEY
unset OPENAI_BASE_URL
```

## Claude Code: сначала проверьте группу API Key

С ключом `Claude_*` **не задавайте** `ANTHROPIC_MODEL`, `ANTHROPIC_SMALL_FAST_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` и другие переменные конкретных моделей. С ключом `Codex_*` добавьте сопоставления через `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` и `ANTHROPIC_DEFAULT_OPUS_MODEL`.

Не смешивайте эти два режима, иначе запросы могут попасть не в ту модель.

**Отключите необязательный трафик.** `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` уменьшает фоновые запросы Claude Code и оставляет квоту для реальных задач разработки.

**Не добавляйте `/v1` в Claude Code.** `ANTHROPIC_BASE_URL` должен быть `{{anthropic-base-url}}`.

## Используйте один API Key в нескольких инструментах

Один и тот же API Key работает в Claude Code, Codex и внешних инструментах. Квота общая, поэтому управлять доступом проще.

Но endpoint должен соответствовать протоколу:

- Claude Code / `ANTHROPIC_BASE_URL`: `{{anthropic-base-url}}`
- Codex / `OPENAI_BASE_URL` / внешние инструменты: `{{openai-base-url}}`

Если нужно отдельно отслеживать расход по проектам или командам, создайте несколько API Key в панели управления и назначьте отдельный ключ каждому инструменту или проекту.

Для внешних инструментов копируйте ID модели из **Codex group** в model plaza (`{{model-plaza-url}}`).

## Чеклист диагностики

1. **Проверьте API Key** — сверитесь с панелью управления и вставьте ключ без лишних пробелов
2. **Проверьте endpoint по протоколу** — Claude Code использует `{{anthropic-base-url}}`, Codex / внешние инструменты используют `{{openai-base-url}}`
3. **Проверьте конфликтующие env vars** — выполните `echo $ANTHROPIC_AUTH_TOKEN`, `echo $OPENAI_BASE_URL` и похожие команды
4. **Проверьте официальные требования инструмента** — для внешних инструментов сначала проверьте `Base URL`, API Key, ID модели и версию клиента; добавляйте headers только если это требует документация инструмента или ваш upstream gateway
5. **Проверьте баланс** — запросы отклоняются, когда баланс исчерпан
6. **Обратитесь в поддержку** — если предыдущие шаги не помогли
