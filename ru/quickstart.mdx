title: "Быстрый старт"
description: "За 4 шага создайте аккаунт, пополните баланс онлайн, создайте API Key и перейдите к инструкции для своего инструмента."
---

<Steps>
  <Step title="Создайте аккаунт">
    Откройте страницу регистрации BetterToken (`{{register-url}}`) и создайте аккаунт.

    После регистрации вы автоматически получите **¥5 пробного баланса**.
  </Step>
  <Step title="Пополните баланс онлайн">
    После входа откройте **Консоль** и нажмите **Пополнить** в карточке **Аккаунт**.

    <Frame>
      <img
        src="/images/quickstart/change_code.png"
        alt="Кнопка пополнения в карточке аккаунта в консоли."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    После оплаты вернитесь в консоль и проверьте, что **текущий баланс** обновился. Затем переходите к созданию API Key.
  </Step>
  <Step title="Откройте управление API Key и создайте ключ">
    Когда на балансе есть средства, нажмите **Создать API-ключ** в блоке **Ваши API-ключи**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Кнопка создания API Key в блоке Ваши API-ключи."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Откроется форма создания API Key.

    <Info>
      Название API Key показывает, для какого сценария предназначен ключ. Если выбрать правильный сценарий сразу, дальнейшая настройка будет проще.
    </Info>
  </Step>
  <Step title="Назовите группу по типу инструмента">
    В форме заполните **Название**, выберите **Группу ключа**, затем проверьте срок действия и необязательный лимит расхода.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Форма создания API Key с названием, группой ключа, сроком действия и настройками лимита расхода."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Выберите или назовите группу по инструменту, который будете подключать.

    <Warning>
      Группы, начинающиеся с `Claude`, можно использовать только с Claude Code.
    </Warning>

    <Warning>
      Группы, начинающиеся с `Codex`, можно использовать с Codex и внешними инструментами, например Cursor, Cline, Zed и Roo Code.
    </Warning>

    Используйте простой шаблон:

    ```text
    Claude-your-name
    Codex-your-name
    ```

    Например: `Claude-main` или `Codex-team`.

    После создания токена скопируйте API Key.

    <Warning>
      Берегите API Key. Храните его в переменной окружения, а не в исходном коде или конфигурационных файлах.
    </Warning>

    Начните с:

    ```bash
    export BETTERTOKEN_API_KEY="your-api-key-here"
    ```
  </Step>
  <Step title="Перейдите к инструкции для своего инструмента">
    Теперь важно помнить одно правило: сначала выберите правильную группу, затем следуйте инструкции для нужного инструмента.

    <Check>
      Если вы подключаете Claude Code, используйте группу с префиксом `Claude`, затем откройте [инструкцию для Claude Code](/ru/ai-tools/claude-code).
    </Check>

    <Check>
      Если вы подключаете Codex или любой внешний инструмент, используйте группу с префиксом `Codex`, затем откройте [инструкцию для Codex](/ru/ai-tools/codex).
    </Check>

    <Note>
      У разных инструментов отличаются `Base URL`, поля авторизации и правила выбора группы моделей. Следуйте отдельной инструкции для инструмента, а не копируйте одну настройку во все клиенты.
    </Note>
  </Step>
</Steps>
