---

<Steps>
  <Step title="Создайте аккаунт и получите пробный баланс">
    Откройте страницу регистрации BetterToken (`{{register-url}}`) и создайте аккаунт.

    После регистрации вы автоматически получите **¥5 пробного баланса**.
  </Step>
  <Step title="Активируйте код или проверьте раздел пополнения">
    После входа откройте **Wallet management** в левом меню. Если у вас есть код пополнения, активируйте его до создания токена.

    <Tabs>
      <Tab title="Активировать код">
        На странице **Wallet management** найдите блок **Redeem code**. Вставьте код и нажмите **Redeem credit**.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Страница Wallet management в панели BetterToken с выделенным пунктом меню, полем для кода и кнопкой активации."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Следуйте порядку на скриншоте:

        1. Нажмите **Wallet management** в боковом меню
        2. Вставьте код в поле ввода
        3. Нажмите **Redeem credit**
      </Tab>
      <Tab title="Пополнить аккаунт">
        Онлайн-пополнение пока не открыто.

        <Note>
          В панели может отображаться пункт **Top up**, но сейчас используйте пробный баланс или код пополнения.
        </Note>
      </Tab>
    </Tabs>
  </Step>
  <Step title="Откройте управление токенами и добавьте токен">
    Когда на балансе есть средства, откройте **Token management** в левом меню. Затем нажмите **Add token**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Панель BetterToken с выделенным пунктом Token management и кнопкой Add token."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Откроется боковая панель, где нужно задать имя группы и создать токен.

    <Info>
      Имя группы показывает, для какого сценария предназначен токен. Если выбрать правильную группу сразу, дальнейшая настройка будет проще.
    </Info>
  </Step>
  <Step title="Назовите группу по типу инструмента">
    В боковой панели задайте имя группы по инструменту, который будете подключать.

    <Warning>
      Группы, начинающиеся с `Claude`, можно использовать только с Claude Code.
    </Warning>

    <Warning>
      Группы, начинающиеся с `Codex`, можно использовать с Codex и внешними инструментами, например Cursor, Cline, Zed и Roo Code.
    </Warning>

    Используйте простой шаблон:

    ```text
    Claude-your-name
    Codex-your-name
    ```

    Например: `Claude-main` или `Codex-team`.

    После создания токена скопируйте API Key.

    <Warning>
      Берегите API Key. Храните его в переменной окружения, а не в исходном коде или конфигурационных файлах.
    </Warning>

    Начните с:

    ```bash
    export BETTERTOKEN_API_KEY="your-api-key-here"
    ```
  </Step>
  <Step title="Перейдите к инструкции для своего инструмента">
    Теперь важно помнить одно правило: сначала выберите правильную группу, затем следуйте инструкции для нужного инструмента.

    <Check>
      Если вы подключаете Claude Code, используйте группу с префиксом `Claude`, затем откройте [инструкцию для Claude Code](/ru/ai-tools/claude-code).
    </Check>

    <Check>
      Если вы подключаете Codex или любой внешний инструмент, используйте группу с префиксом `Codex`, затем откройте [инструкцию для Codex](/ru/ai-tools/codex).
    </Check>

    <Note>
      У разных инструментов отличаются `Base URL`, поля авторизации и правила выбора группы моделей. Следуйте отдельной инструкции для инструмента, а не копируйте одну настройку во все клиенты.
    </Note>
  </Step>
</Steps>
