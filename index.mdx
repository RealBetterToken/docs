## 什么是 BetterToken？

BetterToken 是一个面向开发者的 AI API 中转服务。通过聚合 12+ 家供应商，BetterToken 在你和 Anthropic / OpenAI 之间提供一层高可用路由，让你的 Claude Code、Codex 等 AI 编程工具在高峰期也能稳定运行。

**核心优势：**

- **多源供应**：同时接入 12+ 家供应商，单点故障不影响使用
- **动态路由**：实时选择最优链路，自动规避超时和限流
- **专注旗舰**：只接入 Claude 和 Codex，不铺摊子
- **简单接入**：与 OpenAI SDK / Anthropic SDK 完全兼容，改一行配置即可
