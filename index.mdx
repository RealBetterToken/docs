## 什么是 BetterToken？

BetterToken 是一个面向 AI 编程工具的 API 中转服务。当前文档按两种接入方式说明：

- **Claude Code / `ANTHROPIC_BASE_URL`**：使用 `https://www.bettertoken.ai`
- **Codex / `OPENAI_BASE_URL` / 其他外部工具**：使用 `https://www.bettertoken.ai/v1`

**核心优势：**

- **多源供应**：同时接入多家供应商，单点故障不影响使用
- **动态路由**：实时选择最优链路，自动规避超时和限流
- **专注旗舰**：围绕 Claude Code 与 Codex 生态维护接入稳定性
- **双通道接入**：按协议分别配置地址，避免把同一个 `base_url` 混用到所有工具

## 两种接入方式

| 场景 | Base URL | 说明 |
|------|----------|------|
| Claude Code | `https://www.bettertoken.ai` | 使用 Anthropic 协议，不带 `/v1` |
| Codex / 外部工具 | `https://www.bettertoken.ai/v1` | 使用 OpenAI 类协议；外部工具统一走 Codex 分组 |
