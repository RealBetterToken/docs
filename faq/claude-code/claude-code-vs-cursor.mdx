## Короткий ответ

Claude Code больше похож на terminal coding agent. Он удобен в существующих репозиториях, где агент читает код, запускает команды, меняет файлы и следует `CLAUDE.md`, permissions, hooks и MCP.

Cursor больше похож на AI IDE. Он удобен, если вы хотите completion, chat, Composer, rules, indexing и правки кода внутри редактора.

Один инструмент не полностью заменяет другой. Выбор зависит от того, что вам ближе: terminal agent workflow или editor-native AI workflow.

## Ключевые различия

| Измерение | Claude Code | Cursor |
| --- | --- | --- |
| Основной вход | Terminal / command line | AI IDE |
| Project context | `CLAUDE.md`, conversation context, tool reads | Cursor Rules, indexing, editor context |
| Permission control | Permissions, hooks, confirmation flow | Tool approval, editor permissions, rules |
| MCP | Поддерживает MCP tools | Поддерживает MCP tools |
| Model setup | Claude / Anthropic-compatible first | OpenAI-compatible, custom provider, built-in models |
| Лучше подходит для | Multi-step tasks, command execution, repo-wide changes | Editor interaction, navigation, focused edits, completion |

## Как выбрать

Используйте Claude Code, если вам удобнее попросить agent прочитать репозиторий, составить план, запустить тесты и внести набор изменений.

Используйте Cursor, если вы почти всегда работаете в редакторе и хотите, чтобы AI понимал текущий файл, выделение, индекс и project rules.

Если вы используете оба, они могут разделять model API layer, но каждому инструменту нужны свои rules и permission boundaries.

## Частые ошибки

- Думать, что Cursor Rules автоматически читаются Claude Code.
- Думать, что `CLAUDE.md` заменяет Cursor project rules.
- Сравнивать только model names, а не workflow и permissions.
- Считать MCP model API, а не tool/context extension layer.
- Игнорировать разницу между editor indexing и terminal command execution.

## О BetterToken

Если вы хотите, чтобы Claude Code и Cursor имели общий model routing и usage visibility, настройте каждый инструмент с нужным ему protocol.

Claude Code обычно использует `{{anthropic-base-url}}`. Cursor и похожие external tools обычно используют `{{openai-base-url}}`, а model IDs копируются у провайдера **GPT**.
