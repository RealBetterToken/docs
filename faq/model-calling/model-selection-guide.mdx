## Когда это нужно

- Вы переключаетесь между Claude Code, Codex CLI, Cursor, Cline и похожими инструментами
- Модель работает, но стоит слишком дорого, отвечает медленно или не хватает контекста
- Вам нужна более дешевая модель для пакетных задач
- Вы хотите подключить один API gateway к нескольким AI coding-инструментам

## Сначала инструмент, потом модель

Для Claude Code используйте `{{anthropic-base-url}}`, для Codex CLI и OpenAI-compatible инструментов — `{{openai-base-url}}`. Адрес зависит от протокола клиента.

| --- | --- |

## Выбирайте по типу задачи

| Тип задачи | Что важнее |
| --- | --- |
| Сложный код, архитектура, долгие задачи | Качество reasoning, context window, стабильность tool calls |
| Ежедневные вопросы и легкая генерация | Скорость и стоимость |
| Пакетный перевод, классификация, summary | Цена за единицу, пропускная способность, стабильность |
| Code review и техническая документация | Понимание кода, длинный контекст, стабильный вывод |
| Исследовательские задачи | Сначала средняя по стоимости модель, затем более сильная модель для ключевых шагов |

Не отправляйте все задачи самой дорогой модели по умолчанию. Многие пакетные задачи не требуют глубокого reasoning или высокой креативности. Для них часто лучше подходят быстрые и более дешевые модели.

## Рекомендуемый порядок

1. Проверьте, поддерживает инструмент OpenAI-compatible или Anthropic-compatible API.
2. Скопируйте актуальный Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a>.
3. Проверьте качество, скорость и стоимость на небольшой задаче.
4. Посмотрите usage в dashboard, прежде чем использовать модель постоянно.
5. Оставьте более сильную модель как запасной вариант для сложных задач, не ограничивайтесь одной моделью.

## Частые ошибки

- Смотреть только на отображаемое имя и не проверять Model ID.
- Считать, что самая новая модель подходит для любой задачи.
- Сравнивать только качество ответа и не учитывать контекст, скорость и стоимость.
- Переводить production-трафик на новую модель без малого теста.
