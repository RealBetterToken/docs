## Короткий ответ

Добавьте `model`, `model_context_window` и `model_auto_compact_token_limit` в начало `config.toml`, полностью перезапустите Codex и создайте новый диалог. Официальное API-окно GPT-5.6 Sol составляет 1 050 000 токенов. Конфигурация ниже задаёт для Codex бюджет в 1 000 000 токенов и запускает автоматическое сжатие истории примерно на 900 000.

<Warning>
  Эта настройка не расширяет контекст модели, которая не поддерживает миллион токенов. Фактический объём зависит от версии Codex, provider, серверных лимитов, резерва под ответ и инструменты, а также политики compaction. Ровно 1 000 000 доступных токенов не гарантируется.
</Warning>

## Постоянная настройка

Откройте пользовательский файл Codex:

| Система | Путь |
| --- | --- |
| macOS / Linux | `~/.codex/config.toml` |
| Windows | `%USERPROFILE%\.codex\config.toml` |

Добавьте строки на верхнем уровне, до любого заголовка `[section]`:

```toml
model = "gpt-5.6-sol"
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Сохраните файл, полностью закройте Codex, откройте его снова и начните новый диалог. Старые диалоги могут сохранить прежние параметры.

<Note>
  Порог `900000` оставляет запас под ответ модели, результаты инструментов и следующие сообщения.
</Note>

## Настройка только для одной CLI-сессии

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    codex -m gpt-5.6-sol \
      -c model_context_window=1000000 \
      -c model_auto_compact_token_limit=900000
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    codex -m gpt-5.6-sol `
      -c model_context_window=1000000 `
      -c model_auto_compact_token_limit=900000
    ```
  </Tab>
</Tabs>

После закрытия этой CLI-сессии временные значения перестанут действовать.

## Как проверить настройку

1. Полностью перезапустите Codex и создайте новый диалог.
2. Убедитесь, что выбрана модель `gpt-5.6-sol`.
3. Если модель недоступна, проверьте актуальный Model ID и поддержку provider в <a href={"{{model-plaza-url}}"}>model plaza</a>.
4. Если значения игнорируются, проверьте путь к файлу, верхний уровень TOML и отсутствие дубликатов.

## Почему доступный контекст может быть меньше

`model_context_window` задаёт бюджет контекста для Codex. Часть окна резервируется под ответ, инструменты и системные инструкции. Клиентские и серверные ограничения также могут уменьшить доступный объём или раньше запустить compaction. Поэтому миллион токенов — запрошенный бюджет, а не гарантированный размер каждого запроса.

## Расход и стоимость

Большой контекст помогает дольше сохранять код, вывод терминала и историю диалога, но может заметно увеличить расход входных токенов, задержку и стоимость. Для коротких задач обычно лучше оставить значение по умолчанию. Актуальные модели и условия смотрите в <a href={"{{model-plaza-url}}"}>model plaza</a>.
