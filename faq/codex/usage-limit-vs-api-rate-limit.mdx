Предупреждение о лимите Codex и ответ API `429` относятся к разным контурам. Сначала определите способ доступа. Так вы не будете повторять запрос, который не может выполниться.

## Определите способ доступа

| Что вы используете | Где действует лимит | Что проверить |
| --- | --- | --- |
| Codex с официальным входом ChatGPT/Codex | План Codex или credits | Данные usage в Codex и официальное руководство по лимитам |
| Codex с BetterToken API Key | Отдельный API workflow | HTTP-статус, body, request ID, текущий баланс и запись запроса |

<Warning>
  BetterToken API Key не продлевает и не обходит лимит официального плана Codex. Это отдельный API workflow со своим балансом и историей запросов.
</Warning>

## Если Codex показывает лимит плана

1. Сохраните состояние задачи, изменённые файлы и результаты проверок.
2. Запишите точный текст предупреждения и время.
3. Откройте официальное [руководство по usage и credits Codex](https://help.openai.com/en/articles/12642688).
4. Если вашему плану доступны credits, используйте варианты из официального интерфейса аккаунта. Иначе дождитесь сброса лимита плана.

Не вычисляйте остаток только по одному проценту. Индикаторы интерфейса могут относиться к разным периодам или ресурсам.

## Если API возвращает 429

1. Сохраните HTTP-статус, body ответа, request ID и заголовки rate limit или retry, если они есть.
2. Проверьте текущий баланс и неуспешный запрос в BetterToken Workspace.
3. Убедитесь, что Codex использует OpenAI-compatible Base URL `https://bettertoken.ai/v1` и ваш собственный BetterToken API Key.
4. Повторяйте запрос только при временном rate limit. Используйте ограниченный exponential backoff и заранее задайте число попыток.

Если ответ указывает на баланс, доступ или конфигурацию, повтор того же запроса не поможет. Сначала исправьте причину, затем отправьте один короткий тест.

## Подтвердите исправление

Отправьте короткий некритичный запрос. Проверьте ответ и запись в Dashboard: модель, статус, Token и списание должны соответствовать ожиданию.

Полная настройка описана на странице [Подключение Codex к BetterToken](/ai-tools/codex).
