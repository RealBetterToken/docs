---
title: "为什么在 Codex的 API 模式无法使用 GPT-5.5？"
sidebarTitle: "Codex API 模式使用 GPT-5.5"
description: "在 Codex CLI 自定义 API 模式中临时启用 GPT-5.5 的本地模型目录配置。"
---

截至 2026-04-24，部分 Codex CLI 版本在自定义 API 模式下可能无法直接选择 `gpt-5.5`。这是 Codex CLI 本地模型目录尚未包含该模型导致的显示和选择限制，不代表 BetterToken 的 `https://www.bettertoken.ai/v1` 端点不可用。

你可以先用完整的本地 `custom-models.json` 覆盖 Codex CLI 模型目录，再在 `~/.codex/config.toml` 中引用它。官方后续版本若已经内置支持 `gpt-5.5`，优先使用 Codex CLI 的内置方案。

<Warning>
  `model_catalog_json` 会覆盖 Codex CLI 默认模型目录。不要只保留 `gpt-5.5` 的精简条目，否则其他内置模型可能从列表里消失，且 Codex 的默认 agent 行为可能不完整。
</Warning>

## 配置步骤

<Steps>
  <Step title="创建自定义模型配置文件">
    自定义模型配置文件路径为 `~/.codex/custom-models.json`。

    <Tabs>
      <Tab title="下载 JSON 文件">
        下载完整模型目录文件：

        <a href="/custom-models-gpt-5.5.css" download="custom-models.json">下载 custom-models.json</a>

        下载后，将文件放到 Codex 配置目录，并命名为 `custom-models.json`。

        | 系统 | 目标路径 |
        |------|----------|
        | macOS / Linux | `~/.codex/custom-models.json` |
        | Windows | `C:\Users\YOUR_USER\.codex\custom-models.json` |

        <Note>
          本地预览环境下 `.json` 静态文件可能返回 404，所以下载链接使用 `.css` 文件承载 JSON 内容，并通过 `download="custom-models.json"` 保存为 JSON 文件。文件内容仍是完整 JSON。
        </Note>
      </Tab>

      <Tab title="手动创建 JSON 文件">
        在 `~/.codex/custom-models.json` 中写入完整模型目录。不要只写一个 `gpt-5.5` 条目。

        你可以从下载文件中复制完整内容。手动创建时请确认至少包含以下结构：

        ```json
        {
          "models": [
            {
              "slug": "gpt-5.5",
              "display_name": "gpt-5.5",
              "description": "Custom local catalog entry for GPT-5.5 based on gpt-5.4 metadata.",
              "base_instructions": "...",
              "model_messages": {
                "instructions_template": "...",
                "instructions_variables": {
                  "personality_default": "",
                  "personality_friendly": "...",
                  "personality_pragmatic": "..."
                }
              },
              "supports_reasoning_summaries": true,
              "support_verbosity": true,
              "context_window": 272000
            },
            {
              "slug": "gpt-5.4"
            },
            {
              "slug": "gpt-5.4-mini"
            },
            {
              "slug": "gpt-5.3-codex"
            },
            {
              "slug": "codex-auto-review"
            }
          ]
        }
        ```

        <Warning>
          上面的代码块只是结构示意，不是完整文件。完整文件需要保留 `base_instructions`、`model_messages`、reasoning、verbosity、tool、context window 等字段，以及 Codex CLI 默认模型条目。
        </Warning>
      </Tab>
    </Tabs>
  </Step>

  <Step title="在 Codex 配置中引用 JSON 文件">
    打开 Codex 主配置文件 `~/.codex/config.toml`，添加或合并以下配置。

    macOS / Linux 示例：

    ```toml
    model_catalog_json = "/Users/YOUR_USER/.codex/custom-models.json"

    [model_providers.bettertoken]
    name = "BetterToken"
    base_url = "https://www.bettertoken.ai/v1"
    env_key = "BETTERTOKEN_API_KEY"
    wire_api = "responses"
    requires_openai_auth = false
    request_max_retries = 4
    stream_max_retries = 10
    stream_idle_timeout_ms = 300000

    [profiles.bt-gpt-5-5]
    model = "gpt-5.5"
    model_provider = "bettertoken"
    model_reasoning_effort = "high"
    ```

    Windows 示例：

    ```toml
    model_catalog_json = "C:\\Users\\YOUR_USER\\.codex\\custom-models.json"
    ```

    `model_catalog_json` 使用本机绝对路径。Windows 路径写在 TOML 双引号字符串里时，建议把 `\` 写成 `\\`。
  </Step>

  <Step title="设置 BetterToken API Key">
    在终端中设置环境变量：

    ```bash
    export BETTERTOKEN_API_KEY="YOUR_API_KEY"
    ```

    如果希望每次启动终端都自动生效，将上述命令添加到 `~/.zshrc` 或 `~/.bashrc` 中。
  </Step>

  <Step title="重启并选择配置">
    修改配置文件或环境变量后，结束当前 Codex CLI 进程，并在新终端会话中启动：

    ```bash
    codex --profile bt-gpt-5-5
    ```
  </Step>
</Steps>

## 排查建议

如果仍然无法使用 `gpt-5.5`，按顺序检查：

1. `model_catalog_json` 是否是本机绝对路径
2. `custom-models.json` 是否是完整模型目录，而不是只包含 `gpt-5.5` 的精简文件
3. `base_url` 是否为 `https://www.bettertoken.ai/v1`
4. `wire_api` 是否为 `responses`
5. `BETTERTOKEN_API_KEY` 是否已在启动 Codex CLI 的同一个终端会话中生效

如果你的 Codex CLI 已经内置支持 `gpt-5.5`，可以删除 `model_catalog_json`，改回常规 [Codex CLI 接入文档](/ai-tools/codex) 中的配置方式。
