Для Claude Desktop доступны два способа подключения BetterToken. Выберите вкладку для вашей группы API Key: **Группа ключа: Claude** использует Gateway Claude Desktop, а **Группа ключа: GPT** - автоматическую настройку CC Switch.

<Tabs>
  <Tab title="Группа ключа: Claude">
    <Info>
      Для этого способа нужен API Key из группы Claude; подключение выполняется напрямую к `{{anthropic-base-url}}`.
    </Info>

    <Steps>
      <Step title="Скачайте Claude Desktop">
        Скачайте актуальную версию Claude Desktop:

        [Скачать Claude Desktop](https://claude.ai/download)
      </Step>

      <Step title="Включите developer mode">
        В Claude Desktop выберите в macOS menu bar **Help** → **Troubleshooting** → **Enable Developer Mode**.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/enable-developer-mode-menu.png"
            alt="Выбор Enable Developer Mode в меню Help приложения Claude Desktop."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Нажмите **Enable** в окне подтверждения, затем перезапустите Claude Desktop.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/developer-mode-confirm.png"
            alt="Подтверждение developer mode в Claude Desktop."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Откройте настройки third-party inference">
        После перезапуска выберите в macOS menu bar **Developer** → **Configure Third-Party Inference...**.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/configure-third-party-inference.png"
            alt="Выбор Configure Third-Party Inference в меню Developer."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Введите настройки BetterToken API">
        Выберите **Gateway**, затем введите:

        | Поле | Значение |
        | --- | --- |
        | **Gateway base URL** | `{{anthropic-base-url}}` |
        | **Gateway API key** | Скопируйте API Key из группы Claude в разделе **Token management** консоли BetterToken |
        | **Gateway auth scheme** | `x-api-key` |

        После выбора **Gateway auth scheme** Claude Desktop автоматически получит модели группы Claude. Нажмите **Apply locally**.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-credentials.png"
            alt="Настройка BetterToken Gateway в Claude Desktop и кнопка Apply locally."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Перезапустите и откройте Claude Desktop через Gateway">
        Нажмите **Save & Restart**. После перезапуска выберите **Continue with Gateway**. Надпись **Gateway** в левом нижнем углу означает, что настройка готова.

        <Frame>
          <img
            src="/images/claude-desktop-llmeasy-api/gateway-ready.png"
            alt="Claude Desktop готов к работе после открытия через Gateway."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>
    </Steps>
  </Tab>

  <Tab title="Группа ключа: GPT">
    <Info>
      Для этого способа нужен API Key из группы GPT. Используйте актуальный Claude Desktop и CC Switch `v3.16.5` или новее.
    </Info>

    <Steps>
      <Step title="Обновите Claude Desktop и CC Switch">
        - [Скачать Claude Desktop](https://claude.ai/download)
        - [Скачать CC Switch](https://github.com/farion1231/cc-switch/releases)
      </Step>

      <Step title="Переключитесь на Claude Desktop и добавьте provider">
        Откройте CC Switch. Выберите значок **Claude Desktop** в верхней панели, затем нажмите **+** в правом верхнем углу, чтобы добавить provider.

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/cc-switch-claude-desktop-add-provider.png"
            alt="В CC Switch выбран Claude Desktop; кнопка плюс в правом верхнем углу добавляет provider."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Заполните базовые поля">
        - **Provider Name**: `BetterToken-codex`
        - **API Key**: ваш API Key BetterToken из группы GPT
        - **API Endpoint**: `{{anthropic-base-url}}`

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-basic-fields.png"
            alt="Редактор provider в CC Switch с полями BetterToken-codex, API Key и API Endpoint."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Настройте model mappings">
        Установите **API Format** в **OpenAI Responses API (Requires routing)**, нажмите **Fetch Models** и оставьте включенным **Declare 1M**.

        | Model role | Requested model |
        | --- | --- |
        | Sonnet | `gpt-5.6-terra` |
        | Opus | `gpt-5.6-sol` |
        | Fable | `gpt-5.6-sol` |
        | Haiku | `gpt-5.6-luna` |

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-model-mapping.png"
            alt="В CC Switch выбран OpenAI Responses API и настроены mappings для Sonnet, Opus, Fable и Haiku."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Используйте model IDs, которые сейчас доступны в GPT Key group на <a href={"{{model-plaza-url}}"}>model plaza</a>.
      </Step>

      <Step title="Сохраните, переключитесь и включите proxy">
        Сохраните provider, установите **BetterToken-codex** как **In use**, затем включите proxy switch в левом верхнем углу.

        <Frame>
          <img
            src="/images/claude-desktop-third-party-models/provider-enable-proxy.png"
            alt="BetterToken-codex активен в CC Switch, а proxy switch в левом верхнем углу включен."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>
      </Step>

      <Step title="Перезапустите Claude Desktop и выберите модель">
        Полностью закройте Claude Desktop и откройте его снова. Надпись **Gateway** в левом нижнем углу означает, что конфигурация активна. Выберите модель в меню у поля ввода и начните работу.

        <Frame>
          <img

      </Step>

## Диагностика

### Группа ключа Claude не подключается

Проверьте, что **Gateway base URL** указан как `{{anthropic-base-url}}`, затем используйте API Key из группы Claude и `x-api-key`. Сохраните настройки и перезапустите Claude Desktop.

### Gateway не отображается для группы ключа GPT

В CC Switch убедитесь, что **BetterToken-codex** установлен как **In use**, а proxy switch включен. Полностью закройте Claude Desktop и откройте его снова.

### Список моделей GPT пуст или запросы возвращают `401`

Нажмите **Fetch Models** и сохраните mappings в CC Switch. Проверьте, что API Key относится к группе GPT. Используйте model IDs, доступные в GPT Key group на <a href={"{{model-plaza-url}}"}>model plaza</a>.
