Эта инструкция нужна только для выбора и проверки GLM в OpenCode. Для обычной настройки API Key, Base URL и `opencode.json` сначала используйте [общую инструкцию OpenCode](/ai-tools/opencode), затем вернитесь сюда с точным GLM Model ID из окна **Setup**.

## Параметры GLM

| Поле | Значение |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai/v1` |
| Model | `YOUR_GLM_MODEL_ID` |

## Подготовка GLM

- Установите [OpenCode](https://opencode.ai/).
- <a href={"{{register-url}}"}>Создайте BetterToken API Key</a>.
- В окне **Setup** выберите OpenCode и provider **GLM**, затем скопируйте доступный полный Model ID.

## Подключение GLM через /connect

Запустите OpenCode и выполните:

```text
/connect
```

Выберите **Other**, укажите provider id `bettertoken` и вставьте BetterToken API Key. Затем выберите `bettertoken/YOUR_GLM_MODEL_ID` и перезапустите OpenCode.

## Ручная настройка GLM

Откройте `~/.config/opencode/opencode.json` или проектный `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_GLM_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "https://bettertoken.ai/v1",
        "apiKey": "YOUR_API_KEY"
      },
      "models": {
        "YOUR_GLM_MODEL_ID": {
          "name": "YOUR_GLM_MODEL_ID"
        }
      }
    }
  }
}
```

Замените `YOUR_API_KEY` и `YOUR_GLM_MODEL_ID` значениями из окна Setup. Не фиксируйте Model ID из старой статьи: используйте доступное для вашего API Key значение.

## Проверка GLM

Выберите `bettertoken/YOUR_GLM_MODEL_ID` в OpenCode и отправьте короткое сообщение. Если ответ приходит без ошибки API, модель настроена. После изменения JSON полностью перезапустите OpenCode.

## Частые ошибки GLM

| Ошибка | Что проверить |
| --- | --- |
| `401` | Проверьте BetterToken API Key в `/connect` или `apiKey`. |
| `404` | В `baseURL` оставьте `https://bettertoken.ai/v1`, без `/chat/completions`. |
| Модель не найдена | Скопируйте полный GLM Model ID заново из окна Setup и используйте его одинаково в обоих местах JSON. |
| Конфигурация не применяется | Проверьте проектный `opencode.json`, который может перекрывать глобальный файл. |
