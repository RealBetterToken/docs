После настройки BetterToken Gateway в Claude Desktop следующие симптомы обычно не означают, что сам API Key недействителен:

- Cowork mode не работает
- Code mode показывает `Claude Code process exited with code 1`
- Тот же API Key работает в Claude Code CLI из терминала

Если Gateway еще не настроен, начните с [использования BetterToken API в Claude Desktop](/faq/claude-desktop-bettertoken-api).

## Сначала исправьте Cowork mode

Claude Desktop поддерживает только модели Claude. Это ограничение клиента Claude Desktop.

Проверьте, что API Key скопирован полностью и не истёк. Для этой настройки Gateway используйте `x-api-key`, сохраните изменения и перезапустите Claude Desktop.

Следуйте [инструкции Claude Desktop](/faq/claude-desktop-bettertoken-api): выберите **Gateway**, укажите Base URL `{{anthropic-base-url}}`, BetterToken API Key и **Gateway auth scheme** `x-api-key`. Нажмите **Apply locally** и полностью перезапустите Claude Desktop.

## Затем исправьте ошибки выхода Code mode

Если Cowork работает, но Code mode, вкладка `</>`, все еще показывает `Claude Code process exited with code 1`, проверьте, не использует ли Claude Desktop старую bundled Claude Code version.

**Причина**: Claude Desktop может скачивать новую Claude Code version в фоне. До завершения скачивания Code mode может fallback на старую установленную версию Claude Code. Эта старая версия может быть несовместима с third-party Gateway usage в Code mode, поэтому процесс сразу завершается.

**Как исправить**:

<Steps>
  <Step title="Подождите завершения скачивания новой Claude Code version">
    Оставьте Claude Desktop открытым на некоторое время, чтобы background update Claude Code завершился.
  </Step>

  <Step title="Полностью закройте Claude Desktop">
    Используйте **Cmd+Q**, чтобы полностью закрыть приложение. Не закрывайте только окно.
  </Step>

  <Step title="Откройте снова и начните новую Code session">
    Откройте Claude Desktop снова, затем перейдите в Code mode и начните новую сессию.
  </Step>
</Steps>

<Note>
  Если logs показывают, что Claude Desktop fallback на старую версию Claude Code, например `2.1.111`, пока новая версия, например `2.1.119`, еще не готова, дождитесь завершения скачивания новой версии и затем перезапустите приложение.
</Note>

## Краткая памятка

| Симптом | Частая причина | Исправление |
|---------|----------------|-------------|
| Cowork | Gateway auth scheme | Проверьте, что API Key скопирован полностью и не истёк. Для этой настройки Gateway используйте `x-api-key`, сохраните изменения и перезапустите Claude Desktop. |
| Code mode показывает `Claude Code process exited with code 1` | Claude Desktop fallback на старую Claude Code version | Дождитесь скачивания новой версии, полностью закройте через **Cmd+Q**, затем откройте снова |
