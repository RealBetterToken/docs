На этой странице описано, где скачать Claude Desktop, как напрямую подключить провайдер **Claude** через BetterToken и что проверить при `Claude Desktop API error 500`. Укажите API Key, `{{anthropic-base-url}}` и `x-api-key`, затем перезапустите приложение.

## Claude Desktop API error 500 и установка

Скачайте актуальную версию Claude Desktop с официального сайта, затем добавьте Gateway с Base URL `{{anthropic-base-url}}`. Если появляется `API error 500`, сначала проверьте Model ID и повторите короткий запрос после перезапуска приложения.

Для других моделей перейдите к [расширенной настройке](#расширенная-настройка). Разницу между Claude Desktop и Claude Code объясняет [отдельное сравнение](/faq/claude-code/claude-code-vs-claude-desktop), а общие правила Base URL собраны в [руководстве по адресам API](/faq/model-calling/base-url-config).

## Ключевые параметры

| Поле | Значение |
| --- | --- |
| API Key | API Key BetterToken |
| Base URL | `{{anthropic-base-url}}` |
| Model | Модель провайдера Claude |

## Подготовка

- <a href={"{{register-url}}"}>Создайте и скопируйте API Key BetterToken</a>
- Убедитесь, что API Key поддерживает модели провайдера Claude

## Установка

Установите или обновите [Claude Desktop](https://claude.ai/download) до последней версии, затем запустите приложение.

## Проверка подключения

Нажмите **Save & Restart**. После запуска выберите **Continue with Gateway** и отправьте короткое сообщение. Настройка работает, если в левом нижнем углу отображается **Gateway**, а ответ приходит без ошибок.

## Смена модели

Откройте выбор модели и укажите другую модель Claude, полученную от Gateway. Если нужной модели нет, снова откройте **Configure Third-Party Inference...**, нажмите **Apply locally** и перезапустите Claude Desktop.

## Частые ошибки

| Проблема | Решение |
| --- | --- |
| Gateway не подключается | Укажите в **Gateway base URL** точно `{{anthropic-base-url}}`, без `/v1`. |
| Запрос возвращает `401` | Скопируйте API Key BetterToken заново и проверьте, что выбрана схема `x-api-key`. |
| Claude Desktop показывает `API error 500` | Проверьте точный Model ID, полностью перезапустите Claude Desktop и повторите короткий запрос. Если ошибка сохраняется, проверьте запрос в Dashboard. |
| Модели Claude не отображаются | Убедитесь, что API Key поддерживает провайдер Claude, затем снова откройте настройки. |
| Настройка не применилась | Полностью закройте Claude Desktop, откройте его снова и выберите **Continue with Gateway**. |
