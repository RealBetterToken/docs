---
title: "快速接入"
description: "新用户用 4 步领取额度、创建令牌，并进入对应工具的接入文档。"
---

<Steps>
  <Step title="注册账号并领取体验额度">
    访问 BetterToken 注册页面 (`{{register-url}}`)，创建账号。

    注册成功后自动获得 **¥5 体验额度**，无需绑卡，按量计费，支持退款。
  </Step>
  <Step title="先兑换额度或查看充值入口">
    登录后先进入左侧的 **钱包管理**。如果你有兑换码，可以先兑换到账户余额，再继续创建令牌。

    <Tabs>
      <Tab title="使用兑换码">
        在 **钱包管理** 页面，找到 **兑换码充值** 区域，输入兑换码后点击 **兑换额度**。

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="BetterToken 控制台的钱包管理页面，左侧高亮钱包管理，底部高亮兑换码输入框和兑换额度按钮。"
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        图中对应顺序如下：

        1. 点击左侧 **钱包管理**
        2. 在 **请输入兑换码** 输入框里粘贴兑换码
        3. 点击 **兑换额度**
      </Tab>
      <Tab title="账户充值">
        当前暂未开放在线充值。

        <Note>
          你仍然会看到 **账户充值** 相关入口，但现在请优先使用体验额度或兑换码。
        </Note>
      </Tab>
    </Tabs>
  </Step>
  <Step title="进入令牌管理并添加令牌">
    有了可用额度后，在左侧点击 **令牌管理**，再点击 **添加令牌**。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="BetterToken 控制台中的令牌管理页面，左侧高亮令牌管理，顶部高亮添加令牌按钮。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    点击后会弹出一个抽屉，让你填写分组名称并创建令牌。

    <Info>
      你可以把分组名称理解成“这把令牌准备给谁用”。先分清用途，后面配置工具时会少踩很多坑。
    </Info>
  </Step>
  <Step title="按工具类型给分组命名">
    在弹出的抽屉里，优先按工具类型给分组命名。

    <Warning>
      `Claude` 开头的分组只能用于 Claude Code。
    </Warning>

    <Warning>
      `Codex` 开头的分组可以用于 Codex，也可以用于 Cursor、Cline、Zed、Roo Code 等外部工具。
    </Warning>

    推荐直接这样命名：

    ```text
    Claude-你的常用名称
    Codex-你的常用名称
    ```

    例如：`Claude-main`、`Codex-team`。

    创建完成后，复制生成的 API Key。

    <Warning>
      请妥善保存 API Key。建议将其设置为环境变量，而不是直接写入代码或配置文件。
    </Warning>

    推荐先导出为：

    ```bash
    export BETTERTOKEN_API_KEY="你的 API Key"
    ```
  </Step>
  <Step title="进入对应工具文档继续配置">
    看到这里，你只需要记住一件事：先选对分组，再看对应工具的详细接入文档。

    <Check>
      如果你准备接入 Claude Code，请使用 `Claude` 开头的分组，并继续阅读 [Claude Code 接入文档](/ai-tools/claude-code)。
    </Check>

    <Check>
      如果你准备接入 Codex 或其他外部工具，请使用 `Codex` 开头的分组，并继续阅读 [Codex 接入文档](/ai-tools/codex)。
    </Check>

    <Note>
      不同工具的 `Base URL`、认证字段和模型分组要求不一样。详细配置请以对应工具文档为准，不要把同一套配置直接复制到所有工具里。
    </Note>
  </Step>
</Steps>
