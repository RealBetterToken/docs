---
title: "快速接入"
description: "3 步确认 BetterToken 的接入方式，并完成基础验证。"
---

<Steps>
  <Step title="注册账号并领取体验额度">
    访问 [BetterToken 注册页面](https://www.bettertoken.ai/register)，创建账号。

    注册成功后自动获得 **¥7 体验额度**，无需绑卡，按量计费，支持退款。
  </Step>
  <Step title="获取 API Key">
    登录后进入控制台，创建并复制你的 API Key。

    <Warning>
      请妥善保存 API Key。建议将其设置为环境变量，而不是直接写入代码或配置文件。
    </Warning>

    推荐先导出为：

    ```bash
    export BETTERTOKEN_API_KEY="你的 API Key"
    ```
  </Step>
  <Step title="按接入方式验证（可选）">
    BetterToken 现在分为两种接入方式。不要把同一个 `base_url` 同时用于所有工具。

    <Tabs>
      <Tab title="Claude Code / Anthropic">
        适用于 Claude Code 和使用 `ANTHROPIC_BASE_URL` 的接入：

        ```bash
        export ANTHROPIC_BASE_URL="https://www.bettertoken.ai"
        export ANTHROPIC_AUTH_TOKEN="$BETTERTOKEN_API_KEY"

        curl https://www.bettertoken.ai/messages           -H "x-api-key: $BETTERTOKEN_API_KEY"           -H "anthropic-version: 2023-06-01"           -H "content-type: application/json"           -d '{
            "model": "claude-sonnet-4-6",
            "max_tokens": 1024,
            "messages": [
              {"role": "user", "content": "你好，介绍一下你自己。"}
            ]
          }'
        ```
      </Tab>
      <Tab title="Codex / OpenAI 类协议">
        适用于 Codex CLI 和其他外部工具。`base_url` 必须带 `/v1/`：

        ```bash
        export OPENAI_BASE_URL="https://www.bettertoken.ai/v1/"

        curl https://www.bettertoken.ai/v1/chat/completions           -H "Authorization: Bearer $BETTERTOKEN_API_KEY"           -H "content-type: application/json"           -d '{
            "model": "从模型广场复制的 Codex 分组模型 ID",
            "messages": [
              {"role": "user", "content": "你好，介绍一下你自己。"}
            ]
          }'
        ```

        <Note>
          外部工具统一走 Codex 分组。模型名称不要再填写 Claude 系列的固定示例，而是从模型广场复制当前可用的 Codex 分组模型 ID。
        </Note>
      </Tab>
    </Tabs>
  </Step>
</Steps>
