<Steps>
  <Step title="注册账号并领取体验额度">
    访问 [BetterToken 注册页面](https://www.bettertoken.ai/register)，创建账号。

    注册成功后自动获得 **¥7 体验额度**，无需绑卡，按量计费，支持退款。
  </Step>
  <Step title="获取 API Key">
    登录后进入控制台，创建并复制你的 API Key。

    <Warning>
      请妥善保存 API Key。建议将其设置为环境变量，而不是直接写入代码或配置文件。
    </Warning>

    推荐导出为环境变量：

    ```bash
    export BETTERTOKEN_API_KEY="你的 API Key"
    ```
  </Step>
  <Step title="测试 API 调用（可选）">
    BetterToken 与 Anthropic SDK 兼容。通过以下方式快速验证接入是否正常：

    <Tabs>
      <Tab title="Python">
        安装 Anthropic SDK：

        ```bash
        pip install anthropic
        ```

        调用 API：

        ```python
        import anthropic

        client = anthropic.Anthropic(
            base_url="https://www.BetterToken.ai/v1",
            api_key="你的 API Key",
        )

        message = client.messages.create(
            model="claude-sonnet-4-6",
            max_tokens=1024,
            messages=[
                {"role": "user", "content": "你好，介绍一下你自己。"}
            ]
        )

        print(message.content[0].text)
        ```
      </Tab>
      <Tab title="Node.js">
        安装 Anthropic SDK：

        ```bash
        npm install @anthropic-ai/sdk
        ```

        调用 API：

        ```javascript
        import Anthropic from "@anthropic-ai/sdk";

        const client = new Anthropic({
          baseURL: "https://www.BetterToken.ai/v1",
          apiKey: "你的 API Key",
        });

        const message = await client.messages.create({
          model: "claude-sonnet-4-6",
          max_tokens: 1024,
          messages: [{ role: "user", content: "你好，介绍一下你自己。" }],
        });

        console.log(message.content[0].text);
        ```
      </Tab>
      <Tab title="cURL">
        ```bash
        curl https://www.BetterToken.ai/v1/messages \
          -H "x-api-key: 你的 API Key" \
          -H "anthropic-version: 2023-06-01" \
          -H "content-type: application/json" \
          -d '{
            "model": "claude-sonnet-4-6",
            "max_tokens": 1024,
            "messages": [
              {"role": "user", "content": "你好，介绍一下你自己。"}
            ]
          }'
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
