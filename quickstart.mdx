title: "Быстрый старт"
description: "За 4 шага создайте аккаунт, пополните баланс, создайте API Key и перейдите к инструкции для своего инструмента."
---

<Steps>
  <Step title="Создайте аккаунт">
    Откройте <a href={"{{register-url}}"}>страницу регистрации BetterToken</a> и создайте аккаунт.

    После регистрации пополните баланс, затем создайте BetterToken API Key.
  </Step>
  <Step title="Пополните баланс">
    Вы можете выбрать **онлайн-пополнение** или **пополнение по промокоду**. После пополнения вернитесь в консоль и проверьте, что **текущий баланс** обновился. Затем переходите к созданию API Key.

    <Tabs>
      <Tab title="Онлайн-пополнение">
        После входа откройте **Console**. В карточке **Current balance** выберите валюту, которую хотите пополнить, и нажмите соответствующую кнопку **Top up**.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Карточка Current balance в BetterToken Console с кнопками Top up для USD и RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Следуйте подсказкам на странице оплаты. После успешной оплаты вернитесь в консоль и проверьте, что **текущий баланс** обновился.
      </Tab>
      <Tab title="Пополнение по промокоду">
        После входа откройте **Console** и нажмите **Redeem code** в левом нижнем углу карточки **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Карточка Current balance в BetterToken Console со стрелкой на кнопку Redeem code в левом нижнем углу."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Введите код в открывшемся окне и нажмите **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Окно Redeem code с полем ввода кода и кнопкой Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        После успешного применения кода вернитесь в консоль и проверьте, что **текущий баланс** обновился.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Откройте управление API Key и создайте ключ">
    Когда на балансе есть средства, нажмите **Create API key** в правом верхнем углу блока **Your API keys** в консоли.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Блок Your API keys в BetterToken Console со стрелкой на кнопку Create API key в правом верхнем углу."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Откроется форма создания API Key.

    <Info>
      Название API Key показывает, для какого сценария предназначен ключ. Если выбрать правильный сценарий сразу, дальнейшая настройка будет проще.
    </Info>
  </Step>
  <Step title="Выберите провайдера по типу инструмента">
    В форме заполните **Название**, выберите **Провайдера**, затем проверьте срок действия и необязательный лимит расхода.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Форма создания API Key с названием, provider, сроком действия и настройками лимита расхода."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Выберите провайдера по инструменту, который будете подключать.

    <Warning>
      Провайдер **Claude** рекомендуется для Claude Code.
    </Warning>

    <Warning>
      Провайдер **GPT** используется с Codex и внешними инструментами, например OpenClaw, OpenCode и Cursor.
    </Warning>

    Выберите одного из провайдеров:

    ```text
    Claude
    GPT
    ```

    После создания ключа откроется окно **API key setup**. В нем можно скопировать **API Key** и **Base URL**.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="Окно API key setup в BetterToken с API Key, Base URL, выбором инструмента и способами настройки."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Выберите способ настройки">
    В окне **API key setup** выберите нужный инструмент слева, а затем один из способов настройки.

    - **One-click Bash Configuration**: выберите инструмент и `macOS / Linux` или `Windows`, скопируйте сгенерированную команду и выполните ее в своем локальном терминале. Подходит для быстрой настройки Codex, OpenClaw или OpenCode.
    - **CC Switch integration**: нажмите **Import to CC Switch**, чтобы импортировать текущие **API Key** и **Base URL** в CC Switch. Подходит, если вы управляете несколькими инструментами и provider-настройками в одном приложении.
    - **Manual configuration**: скопируйте **API Key** и **Base URL**, затем вставьте их в настройки нужного инструмента. Подходит для Cursor, Cline, Roo Code, Zed и других клиентов.

    <Note>
      У разных инструментов отличаются поля авторизации, выбор модели и расположение конфигурационных файлов. Продолжайте по отдельной инструкции для нужного инструмента.
    </Note>
  </Step>
</Steps>
