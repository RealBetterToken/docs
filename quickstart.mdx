---
title: "快速接入"
description: "新用户用 4 步注册账号、在线充值、创建 API Key，并进入对应工具的接入文档。"
---

<Steps>
  <Step title="注册账号">
    访问 BetterToken 注册页面 (`{{register-url}}`)，创建账号。

    注册成功后自动获得 **¥5 体验额度**，无需绑卡，按量计费，支持退款。
  </Step>
  <Step title="在线充值账户">
    登录后进入 **控制台**，在 **账户** 卡片中点击 **充值**。

    <Frame>
      <img
        src="/images/quickstart/change_code.png"
        alt="控制台账户卡片中的充值入口。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    充值完成后，回到控制台确认 **当前余额** 已更新，再继续创建 API Key。
  </Step>
  <Step title="进入 API Key 管理并创建 API Key">
    有了可用额度后，在控制台的 **你的 API Key** 区域点击 **创建 API Key**。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="控制台你的 API Key 区域中的创建 API Key 按钮。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    点击后会弹出创建 API Key 表单。

    <Info>
      你可以把 API Key 名称理解成“这把 Key 准备给谁用”。先分清用途，后面配置工具时会少踩很多坑。
    </Info>
  </Step>
  <Step title="按工具类型选择分组">
    在创建表单里填写 **名称**，选择 **Key 分组**，并确认有效期和可选的额度限制。

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="创建 API Key 表单，包含名称、Key 分组、有效期和额度限制选项。"
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    按你要接入的工具选择分组。

    <Warning>
      **Claude 分组**只能用于 Claude Code。
    </Warning>

    <Warning>
      **GPT 分组**可以用于 Codex，也可以用于 OpenClaw、OpenCode、Cursor 等外部工具。
    </Warning>

    直接选择对应分组：

    ```text
    Claude
    GPT
    ```

    创建完成后，复制生成的 API Key。

    <Warning>
      请妥善保存 API Key。建议将其设置为环境变量，而不是直接写入代码或配置文件。
    </Warning>

    推荐先导出为：

    ```bash
    export BETTERTOKEN_API_KEY="你的 API Key"
    ```
  </Step>
  <Step title="进入对应工具文档继续配置">
    看到这里，你只需要记住一件事：先选对分组，再看对应工具的详细接入文档。

    <Check>
      如果你准备接入 Claude Code，请使用 **Claude 分组**，并继续阅读 [Claude Code 接入文档](/ai-tools/claude-code)。
    </Check>

    <Check>
      如果你准备接入 Codex 或其他外部工具，请使用 **GPT 分组**，并继续阅读 [Codex 接入文档](/ai-tools/codex)。
    </Check>

    <Note>
      不同工具的 `Base URL`、认证字段和模型分组要求不一样。详细配置请以对应工具文档为准，不要把同一套配置直接复制到所有工具里。
    </Note>
  </Step>
</Steps>
