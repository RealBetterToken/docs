---
title: "Быстрый старт"
description: "За 4 шага создайте аккаунт BetterToken, пополните баланс, создайте API Key и сразу откройте инструкцию для Claude Code, Codex CLI или внешнего инструмента."
---

<Steps>
  <Step title="Создайте аккаунт">
    Откройте <a href={"{{register-url}}"}>страницу регистрации BetterToken</a> и создайте аккаунт.

    После регистрации пополните баланс, затем создайте BetterToken API Key.
  </Step>
  <Step title="Пополните баланс">
    Вы можете выбрать **онлайн-пополнение** или **пополнение по промокоду**. После пополнения вернитесь в консоль и проверьте, что **текущий баланс** обновился. Затем переходите к созданию API Key.

    <Tabs>
      <Tab title="Онлайн-пополнение">
        После входа откройте **Console**. В карточке **Current balance** выберите валюту, которую хотите пополнить, и нажмите соответствующую кнопку **Top up**.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Карточка Current balance в BetterToken Console с кнопками Top up для USD и RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Следуйте подсказкам на странице оплаты. После успешной оплаты вернитесь в консоль и проверьте, что **текущий баланс** обновился.
      </Tab>
      <Tab title="Пополнение по промокоду">
        После входа откройте **Console** и нажмите **Redeem code** в левом нижнем углу карточки **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Карточка Current balance в BetterToken Console со стрелкой на кнопку Redeem code в левом нижнем углу."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Введите код в открывшемся окне и нажмите **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Окно Redeem code с полем ввода кода и кнопкой Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        После успешного применения кода вернитесь в консоль и проверьте, что **текущий баланс** обновился.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Откройте управление API Key и создайте ключ">
    Когда на балансе есть средства, нажмите **Create API key** в правом верхнем углу блока **Your API keys** в консоли.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Блок Your API keys в BetterToken Console со стрелкой на кнопку Create API key в правом верхнем углу."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    В окне **Create API Key** введите **API key name**. Если нужны срок действия или лимит расходов, раскройте **Advanced settings**. Затем нажмите **Create API Key**.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-dialog.png"
        alt="Окно Create API Key с полем API key name, разделом Advanced settings и кнопкой Create API Key."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Скопируйте данные подключения или код настройки">
    После создания ключа откройте **Set up API key**. В разделе **Connection details** скопируйте **API Key**, выберите **OpenAI** или **Anthropic** в зависимости от протокола и скопируйте соответствующий **Base URL**.

    Либо выберите инструмент или **API call** в разделе **Configuration guide** ниже, при необходимости укажите интерфейс и пример модели, затем скопируйте предложенный код. Подробные шаги доступны по ссылке **View tool documentation** или в руководствах ниже. В конце нажмите **Finish**.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup-dialog.png"
        alt="Окно Set up API key: сверху можно скопировать API Key и Base URL, снизу выбрать инструмент и код в Configuration guide."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
</Steps>
