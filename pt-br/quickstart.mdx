---
title: "Início rápido"
description: "Em 4 etapas, crie uma conta, adicione saldo, crie uma API Key e abra o guia de configuração da sua ferramenta."
---

<Steps>
  <Step title="Crie uma conta">
    Acesse a <a href={"{{register-url}}"}>página de cadastro do BetterToken</a> para criar uma conta.

    Ao se cadastrar, você recebe automaticamente **US$ 1 de crédito de teste**.
  </Step>
  <Step title="Adicione saldo à sua conta">
    Você pode usar **Recarga online** ou **Código de resgate**. Depois de adicionar saldo, volte ao console e confirme que **Current balance** foi atualizado antes de criar uma API Key.

    <Tabs>
      <Tab title="Recarga online">
        Entre na sua conta e abra o **Console**. No cartão **Current balance**, escolha a moeda que deseja adicionar e clique no botão **Top up** correspondente.

        <Frame>
          <img
            src="/images/quickstart/change_code.png"
            alt="Cartão Current balance do Console do BetterToken com botões Top up para USD e RUB."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Siga as instruções de pagamento. Quando o pagamento for concluído, volte ao console e confirme que **Current balance** foi atualizado.
      </Tab>
      <Tab title="Código de resgate">
        Entre na sua conta, abra o **Console** e clique em **Redeem code** no canto inferior esquerdo do cartão **Current balance**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-entry.png"
            alt="Cartão Current balance do Console do BetterToken com uma seta apontando para o botão Redeem code no canto inferior esquerdo."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Digite o código na caixa de diálogo e clique em **Redeem**.

        <Frame>
          <img
            src="/images/quickstart/redeem-code-form.png"
            alt="Caixa de diálogo Redeem code com o campo para o código e o botão Redeem."
            style={{ borderRadius: '0.5rem' }}
          />
        </Frame>

        Depois de resgatar o código, volte ao console e confirme que **Current balance** foi atualizado.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Abra o gerenciamento de API Key e crie uma API Key">
    Quando houver saldo disponível, clique em **Create API key** no canto superior direito da seção **Your API keys** do console.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-1.png"
        alt="Seção Your API keys do Console do BetterToken com uma seta apontando para o botão Create API key no canto superior direito."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    O formulário de criação da API Key será aberto.

    <Info>
      Use o nome da API Key para indicar sua finalidade. Escolher primeiro o caso de uso correto facilita o restante da configuração.
    </Info>
  </Step>
  <Step title="Escolha o provedor pelo tipo de ferramenta">
    No formulário, preencha **Name**, escolha o **provider** e confirme a data de expiração e o limite de gastos opcional.

    <Frame>
      <img
        src="/images/quickstart/create-api-key-form.png"
        alt="Formulário Create API Key com opções de nome, provedor, expiração e limite de gastos."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>

    Escolha o provedor de acordo com a ferramenta que você vai conectar.

    <Warning>
      O **provedor Claude** só pode ser usado com Claude Code.
    </Warning>

    <Warning>
      O **provedor GPT** pode ser usado com Codex e ferramentas externas, como OpenClaw, OpenCode e Cursor.
    </Warning>

    Escolha um destes provedores:

    ```text
    Claude
    GPT
    ```

    Depois de criar a chave, a caixa de diálogo **API key setup** será aberta. Copie a **API Key** e a **Base URL** dessa caixa.

    <Frame>
      <img
        src="/images/quickstart/api-key-setup.png"
        alt="Caixa de diálogo API key setup do BetterToken com API Key, Base URL, seleção de ferramentas e métodos de configuração."
        style={{ borderRadius: '0.5rem' }}
      />
    </Frame>
  </Step>
  <Step title="Escolha um método de configuração">
    Na caixa de diálogo **API key setup**, escolha no lado esquerdo a ferramenta que deseja conectar e selecione um método de configuração.

    - **One-click Bash Configuration**: selecione a ferramenta e `macOS / Linux` ou `Windows`, copie o comando gerado e execute-o no seu terminal local. Use esse método para configurar rapidamente Codex, OpenClaw ou OpenCode.
    - **Integração com o CC Switch**: clique em **Import to CC Switch** para importar a **API Key** e a **Base URL** atuais para o CC Switch. Use esse método ao gerenciar várias ferramentas e provedores em um único aplicativo.
    - **Configuração manual**: copie a **API Key** e a **Base URL** e cole-as no fluxo de configuração da ferramenta. Use esse método com Cursor, Cline, Roo Code, Zed e outros clientes.

    <Note>
      Cada ferramenta usa campos de autenticação, seletores de modelos e locais de arquivos de configuração diferentes. Continue no guia específico da ferramenta antes de concluir a configuração.
    </Note>
  </Step>
</Steps>
