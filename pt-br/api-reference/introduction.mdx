O BetterToken oferece as APIs OpenAI-compatible Chat Completions e Responses, além de Anthropic-compatible Messages. Escolha o formato usado pelo seu cliente.

## Escolha uma API

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/pt-br/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/pt-br/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/pt-br/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/pt-br/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/pt-br/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Conexão com Chat Completions

| Campo | Valor |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| URL completa da requisição | `{{chat-completions-url}}` |
| Método | `POST` |
| Autorização | `Bearer YOUR_API_KEY` |
| Modelo | `YOUR_MODEL_ID` |

Copie um Model ID atual do <a href={"{{model-plaza-url}}"}>model plaza</a> ou da janela **Setup** da API Key no Console.

<Warning>
  Quando uma ferramenta solicitar uma **Base URL**, informe `{{openai-base-url}}`. Use `{{chat-completions-url}}` somente quando a ferramenta pedir explicitamente a URL completa da requisição.
</Warning>

## Teste rápido

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Uma resposta bem-sucedida contém `choices[0].message.content`.
