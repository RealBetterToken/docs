`POST /v1/responses`

Use este endpoint para Codex e aplicações que usam a API OpenAI Responses.

<Note>
  Base URL: `{{openai-base-url}}`. Envie sua API Key como `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Teste no Playground

No Playground à direita, insira sua API Key, substitua `model` por um model ID atual do provider GPT quando necessário e envie a solicitação. Confirme o modelo na <a href={"{{model-plaza-url}}"}>model plaza</a> antes de testar.

<Warning>
  Use somente sua própria API Key de teste. Não coloque keys em código, capturas de tela, tickets ou repositórios Git.
</Warning>
