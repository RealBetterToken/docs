`POST /v1/messages`

Use este endpoint para Claude Code, o SDK da Anthropic e aplicações que usam a API Anthropic Messages.

<Note>
  Para um SDK, use `{{anthropic-base-url}}` como Base URL. Uma solicitação manual e o Playground usam o caminho completo `{{anthropic-base-url}}/v1/messages`.
</Note>

## Teste no Playground

No Playground à direita, insira sua API Key no campo `x-api-key`, mantenha `anthropic-version` como `claude-cli/2.0.76 (external, cli)`, escolha um modelo disponível do provider Claude e envie a solicitação.

<Warning>
  Não use `Authorization: Bearer ...` para este endpoint. Ele exige o header `x-api-key`.
</Warning>
