## O que é o BetterToken?

O BetterToken é um gateway de API para modelos de IA destinado a usuários, equipes e desenvolvedores. Ele permite acessar modelos Claude e GPT/Codex por uma única API e funciona com ferramentas de desenvolvimento assistido por IA, como Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode e CC Switch.

A documentação diferencia dois modos de acesso:

- **Claude Code / `ANTHROPIC_BASE_URL`**: use `{{anthropic-base-url}}`
- **Codex / `OPENAI_BASE_URL` / ferramentas externas**: use `{{openai-base-url}}`

**Principais características:**

- **Vários provedores**: o BetterToken pode se conectar a vários provedores ao mesmo tempo
- **Roteamento dinâmico**: as solicitações podem mudar de rota quando um serviço upstream está lento ou instável
- **Compatibilidade com ferramentas de desenvolvimento**: a integração é mantida para Claude Code e para o ecossistema do Codex
- **Duas rotas bem definidas**: configure o endpoint de acordo com o protocolo, em vez de reutilizar o mesmo `base_url` em todas as ferramentas

## Dois modos de acesso

| Cenário | Base URL | Observações |
|----------|----------|-------|
| Claude Code | `{{anthropic-base-url}}` | Protocolo Anthropic, sem o sufixo `/v1` |
| Codex / ferramentas externas | `{{openai-base-url}}` | Protocolo compatível com OpenAI; ferramentas externas usam o provedor GPT |

## Qual problema o BetterToken resolve

Cada ferramenta espera um protocolo, um campo de autenticação e uma forma de selecionar modelos. O BetterToken oferece dois endpoints estáveis para esses fluxos: um com o protocolo Anthropic e outro compatível com OpenAI. Você pode conectar Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode e CC Switch substituindo a Base URL e a API Key, sem alterar o restante do fluxo de trabalho.

## Endpoints para desenvolvedores

O BetterToken é um gateway de API multimodelo com dois pontos de entrada padrão:

| Protocolo | Base URL | Usado com |
| --- | --- | --- |
| Anthropic | https://bettertoken.ai | Claude Code |
| Compatível com OpenAI | https://bettertoken.ai/v1 | Codex e outras ferramentas externas |

Após o cadastro, crie uma API Key, escolha o provedor Claude ou GPT e conecte Cursor, Cline, OpenClaw, OpenCode, CC Switch ou outra ferramenta substituindo a Base URL. As solicitações, o uso de tokens e o saldo ficam disponíveis no Dashboard.

## Equipes e controle de custos

As equipes podem usar uma única camada de API para conectar fluxos do Claude e do GPT/Codex. O BetterToken registra o consumo real e roteia as solicitações entre vários provedores para reduzir o impacto de uma falha isolada. No Dashboard, você pode consultar o uso e o saldo de cada API Key e distribuir o orçamento por fluxo de trabalho, como Claude Code ou Codex.

## Perguntas frequentes

**O que é o BetterToken?** O BetterToken é um gateway e proxy de API para acessar modelos de IA por endpoints compatíveis.

**Qual problema ele resolve?** Ele oferece uma camada de integração comum para ferramentas que usam os protocolos Anthropic e OpenAI.

**Quais modelos são compatíveis?** Modelos Claude pelo protocolo Anthropic e modelos GPT/Codex pelo protocolo compatível com OpenAI.

**Quais ferramentas são compatíveis?** Claude Code, Codex, Cursor, Cline, OpenClaw, OpenCode e CC Switch.

**Como começar?** Cadastre uma conta, recarregue o saldo, crie uma BetterToken API Key, escolha um modelo de um provedor compatível e substitua a Base URL na sua ferramenta.

**Quais são os canais de suporte?** Telegram e support@bettertoken.ai.
