Atualizado em: 5 de setembro de 2026

A BetterToken agora oferece **GPT-6 Astra** com o Model ID exato `gpt-6-astra`. A OpenAI apresenta o Astra como seu modelo mais capaz para trabalhos complexos de ponta a ponta, incluindo raciocínio avançado, engenharia de software, pesquisa, uso do computador e criação de documentos. Consulte a disponibilidade e o preço da BetterToken na <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Principais novidades

- **Trabalho de ponta a ponta**: criado para tarefas complexas de várias etapas com código, navegadores, ferramentas e aplicativos profissionais
- **Engenharia de software**: a OpenAI posiciona o Astra como seu modelo mais forte até agora para programação e desenvolvimento agêntico
- **Contexto amplo**: a OpenAI documenta uma janela de `1.050.000` tokens e até `128.000` tokens de saída
- **Raciocínio ajustável**: a API da OpenAI aceita `low`, `medium`, `high`, `xhigh` e `max`
- **Ferramentas da Responses API**: a OpenAI documenta function calling, saídas estruturadas, pesquisa na web e em arquivos, interpretador de código, computer use e MCP

## Recomendações de configuração

- Use o Astra para programação difícil, pesquisa, computer use ou tarefas agênticas longas. Para trabalho cotidiano, compare-o com modelos mais rápidos ou econômicos na model plaza.
- Teste uma tarefa representativa antes de mudar o tráfego de produção e compare qualidade, latência e consumo de tokens.
- Selecione o **provider GPT**, use a Base URL `{{openai-base-url}}` e o Model ID exato `gpt-6-astra`.
- O acesso pode ser liberado em etapas. A model plaza é a referência para disponibilidade e preços da BetterToken.

## Início rápido

1. Crie uma BetterToken API Key ou abra a janela **Setup** de uma chave existente.
2. Confirme na model plaza que `gpt-6-astra` está disponível.
3. Configure `{{openai-base-url}}` como Base URL e `gpt-6-astra` como modelo.
4. Reinicie o cliente se a lista de modelos não for atualizada automaticamente.
5. Execute uma pequena tarefa de teste e verifique a solicitação no Dashboard.

## Perguntas frequentes

### Qual é o Model ID do GPT-6 Astra?

Use `gpt-6-astra`. Não use o nome de exibição `GPT-6 Astra` nem um ID de outra plataforma.

### A BetterToken oferece o contexto completo de 1.050.000 tokens?

A OpenAI informa uma janela de contexto de `1.050.000` tokens para o GPT-6 Astra. O limite utilizável também pode depender do cliente, das configurações da solicitação e do roteamento atual da BetterToken. Consulte a model plaza e a documentação do cliente antes de enviar prompts muito grandes.

### Como corrigir Model not found?

Confirme que o Model ID seja exatamente `gpt-6-astra`, que a BetterToken API Key tenha acesso, que o **provider GPT** esteja selecionado e que a Base URL seja `{{openai-base-url}}`. Reinicie o cliente e teste novamente.

### Onde encontro o preço atual?

Consulte a <a href={"{{model-plaza-url}}"}>model plaza</a>. O preço da BetterToken pode ser diferente do preço direto da API da OpenAI e mudar com o tempo.
