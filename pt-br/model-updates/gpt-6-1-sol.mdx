Atualizado em 30 de setembro de 2026

**GPT-6.1 Sol** é uma atualização do GPT-6 Sol. Segundo a OpenAI, o modelo melhora em programação com agentes, uso de aplicativos e trabalho profissional, aproximando-se do GPT-6 Astra em algumas avaliações. Em tarefas exigentes, compare qualidade, latência e consumo no seu próprio fluxo.

O BetterToken disponibiliza o Model ID `gpt-6.1-sol`. Consulte a disponibilidade e os preços atuais no <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Destaques

- **Código e agentes**: indicado para alterações em vários arquivos, depuração e tarefas longas de engenharia de software.
- **Aplicativos e documentos**: a OpenAI relata melhorias em relação ao GPT-6 Sol nesses trabalhos.
- **Contexto amplo**: a OpenAI informa uma janela de `1,050,000` tokens e até `128,000` tokens de saída. O cliente e a rota de conexão podem impor limites menores.
- **Raciocínio ajustável**: aceita `low`, `medium`, `high`, `xhigh` e `max`, mas não `none` nem `minimal`.

## Como conectar

1. <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a>.
2. No Codex CLI ou em outro cliente compatível com OpenAI, use `{{openai-base-url}}` como Base URL e `gpt-6.1-sol` como Model ID.
3. Se precisar chamar ferramentas, use a [Responses API](/pt-br/api-reference/responses). A OpenAI documenta Chat Completions para este modelo sem chamadas de ferramentas.
4. Teste uma tarefa representativa antes de migrar um fluxo existente.

Para Claude Code, use a Base URL do protocolo Anthropic `{{anthropic-base-url}}` e o mesmo Model ID. Consulte os guias de [Claude Code](/pt-br/ai-tools/claude-code) e [Codex CLI](/pt-br/ai-tools/codex).
