Data de lançamento: 22 de setembro de 2026

Claude Opus 5.5 é o primeiro modelo da família Claude 5.5 da Anthropic. Segundo a Anthropic, ele melhora em programação de longa duração e trabalho profissional em relação ao Opus 5, com respostas mais claras em sessões extensas.

O **Claude Opus 5.5** já está disponível no BetterToken. Selecione o provedor `Claude`, use `{{anthropic-base-url}}` como Base URL e informe `claude-opus-5-5` como Model ID. Consulte disponibilidade e preço no <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Destaques

- Alterações complexas de repositório, auditorias e tarefas agentivas longas.
- Código pronto para produção, documentos complexos e computer use.
- Comunicação mais clara em sessões longas, segundo a Anthropic, em comparação com o Opus 5.

## Conectar

1. <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a>.
2. Selecione `Claude` e Base URL `{{anthropic-base-url}}`.
3. Use `claude-opus-5-5` como Model ID.
