## Sugestões de uso

Compare o DeepSeek V4.1 Flash com outro modelo disponível em tarefas importantes para seu fluxo de trabalho:

- **Alterações de código**: atribua a mesma tarefa de repositório aos dois modelos e compare correção, qualidade das edições e acompanhamento necessário
- **Fluxos com agentes**: meça a confiabilidade com que cada modelo segue instruções de várias etapas e usa as ferramentas fornecidas pelo cliente
- **Qualidade do raciocínio**: compare tarefas difíceis de depuração, planejamento e análise com o mesmo prompt e os mesmos critérios
- **Latência e custo**: registre o tempo até o primeiro token, a duração total, o uso de tokens e o preço atual do BetterToken

Execute vários prompts representativos em vez de confiar em um único resultado. Mantenha o mesmo cliente, prompt do sistema, definições de ferramentas e configurações de amostragem para uma comparação justa.

## Início rápido

1. <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a> ou abra **Setup** para uma chave existente.
2. Confirme na model plaza se `deepseek-flash` está disponível.
3. Selecione o **provedor DeepSeek**.
4. Use a Base URL do seu protocolo na tabela acima e informe o Model ID completo.
5. Envie uma solicitação pequena antes de iniciar uma avaliação mais longa.

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "deepseek-flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the likely cause of this failing test and propose the smallest fix."
      }
    ]
  }'
```

Uma resposta bem-sucedida retorna a saída do modelo em `choices[0].message.content`. Para exemplos com SDK e o formato completo da solicitação, consulte a [referência da Chat Completions API](/pt-br/api-reference/chat-completions).

4. Confirme a entrada atual do modelo e o preço na model plaza.

## Perguntas frequentes

### Posso usar esse Model ID em produção?

Sim. Use `deepseek-flash` e confirme na model plaza que o modelo está disponível para sua BetterToken API Key.

### Posso usá-lo com Claude Code ou Anthropic Messages API?

Sim. Para Claude Code ou Anthropic Messages, use a Base URL `{{anthropic-base-url}}` e o Model ID `deepseek-flash`. Solicitações diretas de Messages usam `POST /v1/messages` com sua BetterToken API Key no cabeçalho `x-api-key`.

### Onde encontro o preço atual?

Consulte a <a href={"{{model-plaza-url}}"}>model plaza</a> em tempo real. A disponibilidade e o preço podem mudar.
