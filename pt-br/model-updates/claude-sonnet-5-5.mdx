Data de lançamento: 28 de setembro de 2026

Claude Sonnet 5.5 é o segundo modelo da família Claude 5.5 da Anthropic. A empresa o apresenta como uma opção mais rápida para tarefas cotidianas bem delimitadas, como programar, corrigir erros e criar documentos, apresentações e planilhas. Para trabalhos mais complexos e abertos, considere o Opus 5.5.

**Claude Sonnet 5.5** já está disponível na BetterToken. Defina a Base URL como `{{anthropic-base-url}}` e use `claude-sonnet-5-5` como ID do modelo. Confira disponibilidade e preço atuais na <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Destaques

- **Programação direcionada**: use para implementações bem definidas e correção de erros.
- **Conteúdo profissional**: a Anthropic destaca documentos, apresentações e planilhas.
- **Contexto longo**: a Anthropic informa uma janela de contexto de 1 milhão de tokens e até 128 mil tokens de saída.

## Antes de migrar do Sonnet 5

Se o seu cliente chama diretamente a API Messages da Anthropic, leia o [guia oficial de migração](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide) antes de trocar o ID. O Sonnet 5.5 altera alguns comportamentos de thinking e escolha de ferramentas; teste solicitações representativas primeiro.

## Como conectar

1. <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a>.
2. Use `{{anthropic-base-url}}` como Base URL.
3. Defina o ID do modelo como `claude-sonnet-5-5`.
4. Teste uma tarefa real antes de migrar o tráfego de produção.

Para configurar o cliente, consulte o [guia do Claude Code](/pt-br/ai-tools/claude-code). Compare opções no [guia de escolha de modelos](/pt-br/faq/model-calling/model-selection-guide).
