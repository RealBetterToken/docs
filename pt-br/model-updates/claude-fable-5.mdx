Data de lançamento: 9 de junho de 2026

A BetterToken atualizou a opção do modelo `Claude Fable 5`. Consulte a <a href={"{{model-plaza-url}}"}>model plaza</a> para ver o ID de modelo disponível no momento. Depois, configure-o seguindo o guia do Claude Code ou da ferramenta externa correspondente ao seu cliente.

A Anthropic apresentou oficialmente o Claude Fable 5 em 9 de junho de 2026 e o descreve como uma nova geração de inteligência para os problemas mais difíceis de conhecimento e programação. Segundo a empresa, o Fable 5 é um modelo da classe Mythos criado para trabalhos mais longos, complexos e assíncronos, especialmente agentes de longa duração, engenharia de software complexa, trabalho de conhecimento e fluxos com uso intensivo de visão.

## Destaques

- **Agentes mais eficientes em tarefas prolongadas**: a Anthropic afirma que o Fable 5 pode operar por mais tempo no Claude Code ou em uma estrutura de agentes, planejando etapas, executando e verificando o próprio trabalho
- **Mais adequado para engenharia de software complexa**: o modelo é indicado para grandes migrações, implementações complexas, sessões autônomas de vários dias e tarefas de engenharia que exigem menos supervisão direta
- **Melhor trabalho de conhecimento e visão**: o Fable 5 foi desenvolvido para análises complexas, interpretação de documentos, gráficos, tabelas, PDFs e outros materiais visuais
- **Verificação própria mais ativa**: a Anthropic destaca que o Fable 5 valida o próprio trabalho de maneira mais completa, o que ajuda quando você delega uma tarefa e analisa o resultado depois
- **Novas proteções**: para áreas sensíveis, como segurança cibernética, biologia e química, a Anthropic aplica proteções e comportamentos alternativos; algumas solicitações podem ser respondidas pelo Claude Opus 4.8

Use o nome de modelo exibido no momento na <a href={"{{model-plaza-url}}"}>model plaza</a>. Não fixe no código um nome de modelo que não apareça nessa página.
