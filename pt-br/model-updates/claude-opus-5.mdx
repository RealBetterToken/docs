Data de lançamento: 24 de julho de 2026

A BetterToken agora oferece suporte ao `claude-opus-5`. O modelo foi desenvolvido para programação complexa, fluxos prolongados com agentes e trabalhos de várias etapas em grandes bases de código. Para conectá-lo, crie uma BetterToken API Key, selecione o provedor `Claude`, use `{{anthropic-base-url}}` como Base URL e escolha `claude-opus-5` como ID de modelo.

Consulte sempre a <a href={"{{model-plaza-url}}"}>model plaza</a> para verificar a disponibilidade e os preços atuais.

## Destaques

- **Cargas de programação complexas**: a Anthropic recomenda o Opus 5 para programação avançada com agentes e trabalhos profissionais em que qualidade e confiabilidade a longo prazo são importantes
- **Contexto de até `1M tokens`**: o modelo pode trabalhar com grandes repositórios, históricos extensos e muito material de origem
- **Saída de até `128K tokens`**: isso permite grandes alterações de código, relatórios e entregas com várias etapas
- **Raciocínio adaptativo por padrão**: o modelo ajusta a profundidade do raciocínio à tarefa
- **Controle de esforço ampliado**: os níveis de esforço disponíveis são `low`, `medium`, `high`, `xhigh` e `max`

## Como conectar

1. <a href={"{{register-url}}"}>Cadastre-se e crie uma BetterToken API Key</a>. Depois, selecione o provedor `Claude`.
2. Defina a Base URL como `{{anthropic-base-url}}`.
3. Selecione `claude-opus-5` como modelo.
4. Siga o [guia de configuração do Claude Code](/pt-br/ai-tools/claude-code). Para gerenciar vários provedores, use o [guia do CC Switch](/pt-br/ai-tools/cc-switch).

Se você estiver escolhendo um modelo para uma carga de trabalho específica, compare o Opus 5 com outras opções no [guia de seleção de modelos](/pt-br/faq/model-calling/model-selection-guide).

## O que verificar ao migrar do Opus 4.8

Na maioria das configurações, basta substituir `claude-opus-4-8` por `claude-opus-5`. Revise estas duas mudanças de comportamento:

- **O raciocínio fica ativado por padrão**. Se o esforço estiver definido como `xhigh` ou `max`, desativar o raciocínio retorna um erro `400`.
- **`max_tokens` inclui o raciocínio e a saída visível**. Reserve margem suficiente para tarefas que exijam raciocínio longo e uma resposta final extensa.

<Tip>
  Comece com uma tarefa real do seu fluxo, como analisar um repositório, alterar vários arquivos ou executar uma tarefa prolongada com agente. Assim, fica mais fácil avaliar qualidade, latência e uso de tokens antes de migrar outras cargas de trabalho.
</Tip>
