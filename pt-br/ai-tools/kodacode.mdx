Para conectar o Kodacode à BetterToken, prepare uma API Key, informe a Base URL abaixo e escolha um ID de modelo atual na model plaza.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- O VS Code está instalado
- A extensão Kodacode / Koda está instalada
- O ID de modelo selecionado vem de um **provedor compatível**

## Instalação

Instale ou abra o Kodacode e continue com a configuração manual abaixo.

## Configuração manual

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Exemplo de config.yaml

Use esta estrutura completa como referência. Substitua `YOUR_API_KEY` pela sua BetterToken API Key e não envie uma API Key real ao repositório.

```yaml
name: Koda
version: 0.0.1
schema: v1
models:
  - name: Koda Models
    provider: koda-chat-models
    model: AUTODETECT
    roles:
      - agent
      - chat
      - edit
  - name: YOUR_MODEL_ID
    provider: openai
    model: YOUR_MODEL_ID
    apiKey: YOUR_API_KEY
    apiBase: {{openai-base-url}}/
    roles:
      - agent
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

<Note>
  Se você usar um modelo diferente de `YOUR_MODEL_ID`, atualize `name` e `model` para que correspondam ao ID de modelo de um provedor compatível da <a href={"{{model-plaza-url}}"}>model plaza</a>.
</Note>

## Verifique a conexão

Envie um prompt de teste curto. Se a ferramenta retornar uma resposta sem erro de autenticação ou de ID de modelo, a conexão funciona. Reinicie completamente a ferramenta depois de alterar a configuração.

## Alterne entre modelos

Abra o seletor de modelos ou altere o campo `Model` na configuração. Use o ID de modelo exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Verifique a BetterToken API Key e remova espaços no início ou no fim. |
| `404` | Verifique a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID de modelo atual da model plaza. |
| As alterações não são aplicadas | Salve a configuração e reinicie completamente a ferramenta. |


- Se a conexão falhar, confirme que **API Base** é `{{openai-base-url}}/` e mantenha a `/` final.
- Se o modelo não estiver disponível, confirme que **Model ID** vem do provedor compatível.
- Se a autenticação falhar, copie a API Key novamente e evite espaços extras ou quebras de linha.
- Se as alterações em `config.yaml` não forem aplicadas, reinicie o VS Code ou execute **Developer: Reload Window**.
- A BetterToken geralmente não exige `User-Agent` adicional nem cabeçalhos personalizados.
