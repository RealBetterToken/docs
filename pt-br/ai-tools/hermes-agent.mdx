Para conectar o Hermes Agent à BetterToken, prepare uma API Key, informe a Base URL abaixo e escolha um ID de modelo atual na model plaza.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- O ID de modelo selecionado vem de um **provedor compatível**
- macOS, Linux, Windows 10/11 ou WSL2
- Um modelo com janela de contexto mínima de 64K para uso de ferramentas

## Instalação

### Instalar o Hermes Agent

<Tabs>
  <Tab title="Desktop (macOS / Windows)">
    A Hermes recomenda o instalador Desktop no macOS e no Windows. [Baixe o Hermes Desktop](https://hermes-agent.nousresearch.com/) e execute o instalador do seu sistema.
  </Tab>

  <Tab title="Linux / macOS / WSL2">
    ```bash
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    ```

    Ao terminar, abra um novo terminal ou recarregue o shell antes de executar `hermes`.
  </Tab>

  <Tab title="Windows PowerShell">
    O Hermes Agent oferece suporte nativo ao Windows 10 e 11. Abra o PowerShell ou Windows Terminal e execute:

    ```powershell
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)
    ```

    Não são necessários privilégios de administrador. Abra uma nova janela do PowerShell após a instalação para carregar o User PATH atualizado.
  </Tab>
</Tabs>

```bash
hermes --version
hermes doctor
```

<Note>O WSL2 continua compatível, mas é opcional. Use-o quando precisar de um ambiente Linux ou do terminal incorporado do Web Dashboard.</Note>

## Configuração manual

Use a configuração interativa de modelo do Hermes Agent como caminho principal. Edite os arquivos de configuração diretamente apenas quando precisar de uma configuração manual.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Tabs>
  <Tab title="Configuração interativa">
    <Steps>
      <Step title="Execute o seletor de modelos">
        Saia de qualquer chat Hermes ativo e execute:

        ```bash
        hermes model
        ```
      </Step>

      <Step title="Escolha Custom endpoint">
        Selecione **Custom endpoint (self-hosted / VLLM / etc.)** na lista de provedores.
      </Step>

      <Step title="Preencha a configuração da BetterToken">
        Informe:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: sua BetterToken API Key
        - **Model**: um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a>

        Se o Hermes pedir o API mode, escolha OpenAI-compatible Chat Completions. Use o context length publicado para o modelo e confirme pelo menos 64K.
      </Step>

      <Step title="Inicie o Hermes Agent">
        ```bash
        hermes --tui
        ```

        Execute `hermes` para usar a interface de terminal clássica.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Arquivos de configuração">
    A configuração interativa valida e salva o endpoint. Para configurar manualmente, adicione os ajustes a `~/.hermes/config.yaml`:

    ```yaml
    model:
      default: YOUR_MODEL_ID
      provider: custom
      base_url: "{{openai-base-url}}"
    ```

    Guarde a API Key em `~/.hermes/.env`:

    ```dotenv
    OPENAI_API_KEY=YOUR_API_KEY
    ```

    No Windows nativo, esses arquivos ficam em `%LOCALAPPDATA%\hermes\`. Substitua os valores e execute `hermes doctor`.
  </Tab>
</Tabs>

### Migre do OpenClaw

Se você já usa OpenClaw, primeiro verifique se a versão atual do Hermes Agent oferece o comando de migração. Execute uma simulação antes de alterar algo.

```bash
hermes claw migrate --dry-run
```

Depois de confirmar a saída, execute a migração:

```bash
hermes claw migrate
```

Após a migração, revise a **Base URL**, a API Key e o ID de modelo do Hermes Agent. Eles devem corresponder a `{{openai-base-url}}`, à sua BetterToken API Key e a um ID de modelo de um provedor compatível.

## Verifique a conexão

Inicie `hermes --tui` ou `hermes` e envie `Reply with HERMES_OK only. Do not use tools.`. A conexão funciona quando o Hermes retorna `HERMES_OK` sem erro de autenticação, endpoint ou ID de modelo.

## Alterne entre modelos

Execute `hermes model` fora do chat para adicionar ou reconfigurar um provedor. No chat, use `/model` para alternar entre provedores e modelos já configurados.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Verifique a BetterToken API Key e remova espaços no início ou no fim. |
| `404` | Verifique a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID de modelo atual da model plaza. |
| As alterações não são aplicadas | Salve a configuração e reinicie completamente a ferramenta. |


### Solução de problemas

- Se as solicitações falharem ou não retornarem resposta, confirme que **Base URL** é exatamente `{{openai-base-url}}`. Não acrescente `/chat/completions` nesse campo.
- Se o Hermes informar que o modelo não existe, confirme que **Model** é um ID de modelo de um provedor compatível da <a href={"{{model-plaza-url}}"}>model plaza</a>.
- Se a autenticação falhar, verifique espaços copiados e confirme que o ID de modelo selecionado vem do **provedor compatível**.
- Se o Hermes continuar usando o modelo antigo após uma alteração, encerre a sessão atual do Hermes Agent e execute `hermes` novamente.
- A BetterToken geralmente não exige `User-Agent` adicional nem cabeçalhos personalizados. Adicione cabeçalhos somente quando o gateway personalizado, roteamento de tenant, observabilidade ou camada de cache exigir explicitamente.

<Note>
  Não envie API Keys reais ao repositório. Para configurações compartilhadas pela equipe, prefira variáveis de ambiente ou configuração local.
</Note>
