Para conectar o Hermes Agent à BetterToken, prepare uma API Key, informe a Base URL abaixo e escolha um ID de modelo atual na model plaza.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- O ID de modelo selecionado vem de um **provedor compatível**
- macOS, Linux, or Windows WSL2

## Configuração manual

Use a configuração interativa de modelo do Hermes Agent como caminho principal. Comandos e variáveis de ambiente continuam disponíveis como alternativas.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Tabs>
  <Tab title="Configuração interativa">
    <Steps>
      <Step title="Execute o seletor de modelos">
        ```bash
        hermes model
        ```
      </Step>

      <Step title="Escolha o provedor OpenAI ou OpenAI Compatible">
        Selecione **OpenAI** ou **OpenAI Compatible** na lista de provedores.
      </Step>

      <Step title="Preencha a configuração da BetterToken">
        Informe:

        - **Base URL**: `{{openai-base-url}}`
        - **API Key**: sua BetterToken API Key
        - **Model**: um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a>
      </Step>

      <Step title="Reinicie o Hermes Agent">
        Após atualizar a configuração, encerre a sessão atual do Hermes Agent e inicie-a novamente.
      </Step>

      <Step title="Inicie o Hermes Agent">
        ```bash
        hermes
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Configuração por CLI">
    Se preferir comandos para copiar e colar, grave a configuração do Hermes Agent diretamente.

    ```bash
    hermes config set llm.provider openai
    hermes config set llm.base_url "{{openai-base-url}}"
    hermes config set llm.api_key "YOUR_API_KEY"
    hermes config set llm.model "YOUR_MODEL_ID"
    ```

    Substitua `YOUR_API_KEY` pela sua BetterToken API Key e `YOUR_MODEL_ID` por um ID de modelo de um provedor compatível da <a href={"{{model-plaza-url}}"}>model plaza</a>.

    Depois inicie o Hermes Agent:

    ```bash
    hermes
    ```
  </Tab>

  <Tab title="Variáveis de ambiente">
    Se não quiser armazenar a API Key na configuração do Hermes Agent, exporte-a no shell atual.

    ```bash
    export OPENAI_API_BASE="{{openai-base-url}}"
    export OPENAI_API_KEY="YOUR_API_KEY"
    export HERMES_MODEL="YOUR_MODEL_ID"
    hermes
    ```

    Essas variáveis se aplicam somente à sessão atual do shell. Exporte-as novamente em um novo terminal ou adicione-as ao seu perfil de shell.
  </Tab>
</Tabs>

### Migre do OpenClaw

Se você já usa OpenClaw, primeiro verifique se a versão atual do Hermes Agent oferece o comando de migração. Execute uma simulação antes de alterar algo.

```bash
hermes claw migrate --dry-run
```

Depois de confirmar a saída, execute a migração:

```bash
hermes claw migrate
```

Após a migração, revise a **Base URL**, a API Key e o ID de modelo do Hermes Agent. Eles devem corresponder a `{{openai-base-url}}`, à sua BetterToken API Key e a um ID de modelo de um provedor compatível.

## Verifique a conexão

Envie um prompt de teste curto. Se a ferramenta retornar uma resposta sem erro de autenticação ou de ID de modelo, a conexão funciona. Reinicie completamente a ferramenta depois de alterar a configuração.

## Alterne entre modelos

Abra o seletor de modelos ou altere o campo `Model` na configuração. Use o ID de modelo exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Verifique a BetterToken API Key e remova espaços no início ou no fim. |
| `404` | Verifique a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID de modelo atual da model plaza. |
| As alterações não são aplicadas | Salve a configuração e reinicie completamente a ferramenta. |


### Solução de problemas

- Se as solicitações falharem ou não retornarem resposta, confirme que **Base URL** é exatamente `{{openai-base-url}}`. Não acrescente `/chat/completions` nesse campo.
- Se o Hermes informar que o modelo não existe, confirme que **Model** é um ID de modelo de um provedor compatível da <a href={"{{model-plaza-url}}"}>model plaza</a>.
- Se a autenticação falhar, verifique espaços copiados e confirme que o ID de modelo selecionado vem do **provedor compatível**.
- Se o Hermes continuar usando o modelo antigo após uma alteração, encerre a sessão atual do Hermes Agent e execute `hermes` novamente.
- A BetterToken geralmente não exige `User-Agent` adicional nem cabeçalhos personalizados. Adicione cabeçalhos somente quando o gateway personalizado, roteamento de tenant, observabilidade ou camada de cache exigir explicitamente.

<Note>
  Não envie API Keys reais ao repositório. Para configurações compartilhadas pela equipe, prefira variáveis de ambiente ou configuração local.
</Note>
