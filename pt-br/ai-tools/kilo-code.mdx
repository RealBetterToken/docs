Para conectar o Kilo Code à BetterToken, prepare uma API Key, informe a Base URL abaixo e escolha um ID de modelo atual na model plaza.

Você conclui a configuração em três passos: selecione um provedor compatível com OpenAI, informe a BetterToken API Key e a Base URL, e escolha um Model ID atual. Depois, envie uma primeira solicitação curta para confirmar a conexão.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- VS Code instalado

## Instalação

Se o Kilo Code já estiver instalado, vá direto para a [configuração manual](#configuração-manual) e informe sua BetterToken API Key, Base URL e Model ID.

Se ainda precisar instalar a extensão ou quiser o contexto de instalação e uso regional, consulte o [guia em inglês de instalação e API personalizada do Kilo Code](https://bettertoken.ai/en/blog/kilo-code-russia-api-setup/) e depois volte para usar os campos de configuração atuais.

## Configuração manual

Faça a configuração na interface do Kilo Code. Não é necessário editar um arquivo.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Steps>
  <Step title="Remova variáveis de ambiente conflitantes">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Abra as configurações do Kilo Code">
    Abra a interface de configurações do Kilo Code.
  </Step>

  <Step title="Configure o provedor de API">
    Preencha:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → sua BetterToken API Key
    - **Model** → um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Configure cabeçalhos extras apenas quando a documentação exigir">
    O material oficial do Kilo Code menciona cabeçalhos personalizados opcionais para provedores compatíveis com OpenAI, mas não trata `User-Agent` como requisito da BetterToken.

    Se você também usa um gateway personalizado ou uma camada de roteamento, observabilidade ou cache, adicione cabeçalhos apenas conforme a documentação oficial do serviço upstream.
  </Step>

  <Step title="Reinicie o Kilo Code">
    Depois de alterar a configuração, reinicie o VS Code ou recarregue a extensão Kilo Code para aplicar os novos valores.
  </Step>
</Steps>

<Note>
  Se precisar de cabeçalhos extras, siga a documentação atual do Kilo Code ou os requisitos do gateway upstream. Não presuma que `User-Agent` seja obrigatório para a BetterToken.
</Note>

## Teste a conexão

Envie uma primeira solicitação curta, como `Responda apenas: OK`. Se a ferramenta responder sem erro de autenticação ou de Model ID, a conexão funciona. Reinicie completamente a ferramenta após alterar a configuração. Se houver falha, vá para [Erros comuns](#erros-comuns).

## Alterne entre modelos

Abra o seletor ou altere o campo `Model` na configuração. Use o ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Confira a BetterToken API Key e remova espaços nas extremidades. |
| `404` | Confira a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID atual da model plaza. |
| Alterações não aplicadas | Salve a configuração e reinicie completamente a ferramenta. |
