## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | `YOUR_MODEL_ID` |

## Pré-requisitos

- Instale a versão mais recente do OpenClaw
- <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a>
- Copie um Model ID do <a href={"{{model-plaza-url}}"}>model plaza</a> ou da janela **Setup** da chave

## Configuração pela linha de comando

O script de configuração automática do BetterToken grava a configuração do OpenClaw. Ele requer Node.js. Se você não informar uma API Key ou um Model ID como argumento, o script solicitará esses dados.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-openclaw-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-openclaw-provider-ps1-url}}" -OutFile "$env:TEMP\install-openclaw-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-openclaw-provider.ps1"
    ```
  </Tab>
</Tabs>

Confirme se `agents.defaults.model.primary` usa o `YOUR_MODEL_ID` exibido em Setup. Depois, execute os comandos abaixo para validar a configuração e reiniciar o Gateway.

## Configuração manual

### Configurar o OpenClaw

Copie o Model ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Tabs>
  <Tab title="Responses API">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-responses",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Chat Completions">
    ```json
    {
      "models": {
        "mode": "merge",
        "providers": {
          "bettertoken": {
            "baseUrl": "{{openai-base-url}}",
            "apiKey": "YOUR_API_KEY",
            "api": "openai-completions",
            "models": [
              {
                "id": "YOUR_MODEL_ID",
                "name": "YOUR_MODEL_ID"
              }
            ]
          }
        }
      },
      "agents": {
        "defaults": {
          "model": {
            "primary": "bettertoken/YOUR_MODEL_ID"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

`openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`.

## Verificar a conexão

Execute:

```bash
openclaw config validate
openclaw gateway restart
openclaw models list
openclaw models status
```

A configuração está ativa quando a validação passa, o Gateway reinicia e `bettertoken/YOUR_MODEL_ID` aparece na lista e no status dos modelos. Se uma sessão existente ainda usar um modelo antigo, inicie uma nova sessão e verifique novamente.

## Trocar de modelo

Adicione o novo modelo a `models.providers.bettertoken.models` e altere `agents.defaults.model.primary` para `bettertoken/YOUR_MODEL_ID`. Salve, valide a configuração e reinicie o Gateway.

## Erros comuns

| Erro | Solução |
| --- | --- |
| Falha em `config validate` | Verifique as vírgulas, aspas e chaves do JSON. |
| `401` | Copie `apiKey` novamente e remova os espaços. |
| `404` | `openai-responses`: `/v1/responses`; `openai-completions`: `/v1/chat/completions`. Base URL: `{{openai-base-url}}`. |
| Modelo ausente | Confirme se ele aparece na lista de modelos do provedor e em `agents.defaults.model.primary`. |
| A sessão existente usa o modelo antigo | Execute `openclaw gateway restart` e crie uma nova sessão. |
