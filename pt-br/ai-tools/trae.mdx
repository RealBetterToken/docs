Para conectar o TRAE à BetterToken, prepare uma API Key, informe a URL de solicitação abaixo e escolha um ID de modelo atual na model plaza.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| URL completa da solicitação | `{{chat-completions-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

## Instalação

Instale ou abra o TRAE e prossiga com a configuração manual abaixo.

## Configuração manual

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| URL completa da solicitação | `{{chat-completions-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Steps>
  <Step title="Abra as configurações">
    No modo **IDE**, clique no ícone **Settings** no canto superior direito para abrir a central de configurações.

    Você também pode abrir o modo **SOLO** e clicar em **Settings** no canto superior direito do painel de chat.
  </Step>

  <Step title="Abra o painel de modelos">
    Na navegação à esquerda, escolha **Model** para abrir o painel de modelos.
  </Step>

  <Step title="Adicione um modelo">
    Clique em **+ Add model**.

    ![Painel de modelos do TRAE com a entrada de configurações, o item Model e o botão para adicionar um modelo destacados.](/images/trae/add-model.png)
  </Step>

  <Step title="Preencha a configuração do modelo">
    Quando a janela **Add model** aparecer, preencha os campos desta forma:

    | Campo | Valor |
    |-------|-------|
    | Provider | `OpenAI` |
    | Model | `Custom model` |
    | ID de modelo | um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a> |
    | API Key | sua API Key copiada do console da BetterToken |
    | Custom request URL | `{{chat-completions-url}}` |

    ![Janela Add model do TRAE com OpenAI e um modelo personalizado selecionados e campos para ID de modelo, API Key e URL personalizada.](/images/trae/model-config.png)
  </Step>

  <Step title="Salve e comece a usar">
    Clique em **Confirm** para salvar e escolha o novo modelo de um provedor compatível.
  </Step>
</Steps>

<Note>
  A BetterToken oferece suporte ao TRAE apenas com **modelos de um provedor compatível**. Não use nomes fixos de modelos Claude nem defina a URL personalizada como `{{openai-base-url}}`.
</Note>

## Teste a conexão

Envie um prompt curto. Se a ferramenta responder sem erro de autenticação ou de ID de modelo, a conexão funciona. Reinicie completamente a ferramenta após alterar a configuração.

## Alterne entre modelos

Abra o seletor ou altere o campo `Model` na configuração. Use o ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Confira a BetterToken API Key e remova espaços nas extremidades. |
| `404` | Confira a URL e não acrescente outro caminho de endpoint. |
| `model not found` | Copie um ID atual da model plaza. |
| Alterações não aplicadas | Salve a configuração e reinicie completamente a ferramenta. |
