O OpenCode se conecta ao BetterToken com `@ai-sdk/openai-compatible`. Nomeie o provedor do OpenCode como **BetterToken** ou **OpenAI Compatible**. Use esta página para a configuração geral de API Key, Base URL ou `opencode.json`. Consulte o [guia do GLM](/pt-br/faq/opencode/glm-api) ou o [guia do Kimi K3](/pt-br/faq/opencode/kimi-k3-api) ao selecionar e verificar um desses modelos. Copie o Model ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | `YOUR_MODEL_ID` |

## Pré-requisitos

- Instale a versão mais recente do OpenCode
- <a href={"{{register-url}}"}>Crie uma BetterToken API Key</a>
- Copie um Model ID do <a href={"{{model-plaza-url}}"}>model plaza</a> ou da janela **Setup** da chave

## Configuração pela linha de comando

O script de configuração automática do BetterToken cria ou atualiza o provedor BetterToken no OpenCode. Ele requer Node.js. Se você não informar uma API Key ou um Model ID como argumento, o script solicitará esses dados.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL "{{install-opencode-provider-sh-url}}" | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr "{{install-opencode-provider-ps1-url}}" -OutFile "$env:TEMP\install-opencode-provider.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\install-opencode-provider.ps1"
    ```
  </Tab>
</Tabs>

Selecione `bettertoken/YOUR_MODEL_ID` quando o script terminar. Se o OpenCode já estiver em execução, reinicie-o antes de testar.

## Configuração manual

### Opção 1: salvar as credenciais com /connect

Inicie o OpenCode e execute:

```text
/connect
```

Escolha **Other**, informe `bettertoken` como identificador do provedor e depois insira `YOUR_API_KEY`. O OpenCode armazena a credencial localmente.

### Opção 2: configurar o JSON

O arquivo global é `~/.config/opencode/opencode.json`. Um projeto pode usar `opencode.json` no diretório raiz.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/YOUR_MODEL_ID",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "{{openai-base-url}}"
      },
      "models": {
        "YOUR_MODEL_ID": {
          "name": "YOUR_MODEL_ID"
        }
      }
    }
  }
}
```

Se você não usar `/connect`, adicione `"apiKey": "YOUR_API_KEY"` em `options`. Nunca faça commit de uma configuração que contenha uma chave real.

## Verificar a conexão

Execute `opencode` em um projeto, selecione `bettertoken/YOUR_MODEL_ID` e envie uma mensagem curta. Uma resposta normal confirma a configuração. Reinicie o OpenCode depois de alterar o JSON.

## Trocar de modelo

Adicione um novo `YOUR_MODEL_ID` em `provider.bettertoken.models`, atualize o `model` de nível superior, salve e reinicie o OpenCode.

## Erros comuns

| Erro | Solução |
| --- | --- |
| `401` | Execute `/connect` novamente ou verifique `apiKey`. |
| `404` | Use somente `{{openai-base-url}}` como `baseURL`; não acrescente `/chat/completions`. |
| Modelo não encontrado | Faça o `model` de nível superior corresponder exatamente a um ID em `models`. |
| Configuração não aplicada | Verifique se o `opencode.json` do projeto substitui o arquivo global e reinicie o OpenCode. |
