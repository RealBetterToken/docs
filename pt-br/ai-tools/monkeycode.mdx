O MonkeyCode é uma ferramenta de programação assistida por IA que permite adicionar um modelo personalizado na área **AI Model**. Esta página explica apenas a conexão da interface do MonkeyCode à BetterToken por meio de API Key, Base URL e Model ID; ela não documenta uma API oficial própria do MonkeyCode. Se o problema ocorrer no Kodacode / Koda, use o [guia de configuração e erros 429 do Kodacode](/pt-br/ai-tools/kodacode). Para informações sobre o produto e downloads, consulte o [site do MonkeyCode](https://monkeycode.ai).

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- Conta MonkeyCode ([cadastre-se no MonkeyCode](https://monkeycode.ai))

## Instalação

Instale ou abra o MonkeyCode e prossiga com a configuração manual abaixo.

## Configuração manual

Faça a configuração na interface do MonkeyCode. Não é necessário editar um arquivo.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Steps>
  <Step title="Entre no MonkeyCode">
    Acesse o [MonkeyCode](https://monkeycode.ai) e entre na sua conta.
  </Step>

  <Step title="Abra as configurações do sistema">
    Acesse a página de tarefas e clique em **Settings** no canto inferior direito.
  </Step>

  <Step title="Vincule um modelo de IA">
    Na seção **AI Model**, clique em **Bind**.
  </Step>

  <Step title="Preencha a configuração da BetterToken">

    | Campo | Valor |
    |-------|-------|
    | Model API URL | `{{openai-base-url}}` |
    | API Key | sua BetterToken API Key |
    | Formato de API | `OpenAI` ou `OpenAI Compatible` (siga o rótulo atual da interface) |
    | Nome do modelo | um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a> |
  </Step>

  <Step title="Configure cabeçalhos extras apenas quando a documentação exigir">
    Não há requisito oficial do MonkeyCode que torne `User-Agent` obrigatório para a BetterToken. Comece pela `Base URL`, API Key e ID de modelo mostrados nesta página.

    Se você também usa um gateway personalizado ou uma camada de roteamento, observabilidade ou cache, adicione cabeçalhos apenas conforme a documentação oficial do serviço upstream.
  </Step>

  <Step title="Salve e comece a usar">
    Clique em **Save**. Depois, volte à página principal e selecione o modelo configurado.
  </Step>

  <Step title="Reinicie o MonkeyCode">
    Depois de salvar, atualize a página ou reabra o MonkeyCode antes de usar o novo modelo.
  </Step>
</Steps>

<Note>
  Se precisar de cabeçalhos extras, siga a documentação atual do MonkeyCode ou os requisitos do gateway upstream. Não presuma que `User-Agent` seja obrigatório para a BetterToken.
</Note>

## Teste a conexão

Envie um prompt curto. Se a ferramenta responder sem erro de autenticação ou de ID de modelo, a conexão funciona. Reinicie completamente a ferramenta após alterar a configuração.

## Alterne entre modelos

Abra o seletor ou altere o campo `Model` na configuração. Use o ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Confira a BetterToken API Key e remova espaços nas extremidades. |
| `404` | Confira a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID atual da model plaza. |
| Alterações não aplicadas | Salve a configuração e reinicie completamente a ferramenta. |
