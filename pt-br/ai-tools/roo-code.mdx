Para conectar o Roo Code à BetterToken, prepare uma API Key, informe a Base URL abaixo e escolha um ID de modelo atual na model plaza.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

## Pré-requisitos

- A versão atual da ferramenta está instalada
- Uma BetterToken API Key: <a href={"{{register-url}}"}>cadastre-se e crie uma</a>
- Um ID de modelo da <a href={"{{model-plaza-url}}"}>model plaza</a>

### Requisitos adicionais

- VS Code instalado

## Instalação

### Instalar o Roo Code

Abra o VS Code, pesquise **Roo Code** no marketplace de extensões e instale-o.

## Configuração manual

Faça a configuração na interface do Roo Code. Não é necessário editar um arquivo.

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{openai-base-url}}` |
| Modelo | Um ID atual da <a href={"{{model-plaza-url}}"}>model plaza</a> |

### Configuração

<Steps>
  <Step title="Remova variáveis de ambiente conflitantes">
    ```bash
    unset OPENAI_API_KEY
    unset OPENAI_BASE_URL
    ```
  </Step>

  <Step title="Abra as configurações do Roo Code">
    Abra o painel **Settings** do Roo Code.
  </Step>

  <Step title="Configure o provedor de API">
    Preencha:

    - **API Provider** → `OpenAI Compatible`
    - **Base URL** → `{{openai-base-url}}`
    - **API Key** → sua BetterToken API Key
    - **Model** → um **ID de modelo de um provedor compatível** copiado da <a href={"{{model-plaza-url}}"}>model plaza</a>
  </Step>

  <Step title="Configure cabeçalhos extras apenas quando a documentação exigir">
    O material oficial do Roo Code se concentra em APIs personalizadas ou compatíveis com OpenAI, mas não trata um `User-Agent` extra como requisito da BetterToken.

    Se você também usa um gateway personalizado ou uma camada de roteamento, observabilidade ou cache, adicione cabeçalhos apenas conforme a documentação oficial do serviço upstream.
  </Step>

  <Step title="Salve e comece a usar">
    Clique em **Save** e **Done**. Depois, selecione o modelo configurado.
  </Step>

  <Step title="Reinicie o Roo Code">
    Depois de salvar, reinicie o VS Code ou recarregue a extensão Roo Code antes de selecionar o modelo.
  </Step>
</Steps>

<Note>
  O provedor OpenAI Compatible do Roo Code ainda depende de chamadas de ferramentas no estilo OpenAI. Se precisar de cabeçalhos extras, siga a documentação atual do Roo Code ou os requisitos do gateway upstream. Não presuma que `User-Agent` seja obrigatório para a BetterToken.
</Note>

## Teste a conexão

Envie um prompt curto. Se a ferramenta responder sem erro de autenticação ou de ID de modelo, a conexão funciona. Reinicie completamente a ferramenta após alterar a configuração.

## Alterne entre modelos

Abra o seletor ou altere o campo `Model` na configuração. Use o ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a> e reinicie a sessão atual.

## Erros comuns

| Erro | O que verificar |
| --- | --- |
| `401` ou `Unauthorized` | Confira a BetterToken API Key e remova espaços nas extremidades. |
| `404` | Confira a Base URL e não acrescente um caminho de endpoint específico. |
| `model not found` | Copie um ID atual da model plaza. |
| Alterações não aplicadas | Salve a configuração e reinicie completamente a ferramenta. |
