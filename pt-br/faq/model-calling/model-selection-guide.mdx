## Quando você precisa destas informações

- Você alterna entre Claude Code, Codex CLI, Cursor, Cline ou ferramentas semelhantes
- Um modelo funciona, mas é caro demais, lento demais ou tem pouco contexto
- Você quer um modelo mais barato para tarefas em lote
- Você quer conectar o mesmo API gateway a várias ferramentas de programação com IA

## Escolha pelo tipo de tarefa

| Tipo de tarefa | Priorize |
| --- | --- |
| Programação complexa, arquitetura e tarefas longas | Qualidade de raciocínio, janela de contexto e estabilidade das chamadas de ferramentas |
| Perguntas diárias e geração leve | Velocidade e custo |
| Tradução, classificação e resumos em lote | Preço unitário, vazão e estabilidade |
| Revisão de código e documentação técnica | Compreensão de código, contexto longo e saída estável |
| Tarefas exploratórias | Comece com um modelo de custo médio e mude para um mais avançado nas etapas críticas |

Não envie todas as tarefas ao modelo mais caro por padrão. Muitas tarefas em lote não precisam de raciocínio profundo nem de muita criatividade. Modelos mais rápidos e baratos costumam ser mais adequados.

## Fluxo recomendado

1. Confirme se a ferramenta oferece suporte a uma API compatível com OpenAI ou Anthropic.
2. Copie o Model ID atual do <a href={"{{model-plaza-url}}"}>model plaza</a>.
3. Teste a qualidade, a velocidade e o custo com uma tarefa pequena.
4. Verifique o uso no painel antes de adotar o modelo por longo prazo.
5. Mantenha um modelo alternativo mais avançado para tarefas complexas em vez de configurar apenas um modelo.

## Erros comuns

- Observar apenas o nome exibido e não confirmar o Model ID.
- Supor que o modelo mais recente é sempre o melhor para todas as tarefas.
- Comparar apenas a qualidade da saída e ignorar o tamanho do contexto, a velocidade e o custo.
- Direcionar tráfego de produção para um novo modelo sem antes fazer um teste pequeno.
