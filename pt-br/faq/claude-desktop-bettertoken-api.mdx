O Claude Desktop aceita apenas modelos Claude. Essa é uma limitação do cliente Claude Desktop.

Copie um Model ID Claude disponível na model plaza, salve e reinicie o Claude Desktop.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `{{anthropic-base-url}}` |
| Modelo | Copie um Model ID Claude disponível na model plaza, salve e reinicie o Claude Desktop. |

## Pré-requisitos

- <a href={"{{register-url}}"}>Crie e copie uma BetterToken API Key</a>
- Copie o Model ID exato da <a href={"{{model-plaza-url}}"}>model plaza</a>.

## Separe a assinatura da cobrança da API

As solicitações do Gateway usam sua BetterToken API Key e o saldo da BetterToken. Elas não consomem nem ampliam o limite de uma assinatura Claude. Trate a assinatura e a API como caminhos separados de acesso e cobrança.

Antes de usar a configuração em trabalho real:

1. Crie uma BetterToken API Key dedicada ao Claude Desktop.
2. Envie uma mensagem de teste curta e sem dados sensíveis pelo **Gateway**.
3. Abra o Dashboard da BetterToken e confirme o modelo, o status, os Token de input, output e cache e a cobrança.
4. Revogue a Key e crie outra se ela aparecer em uma captura de tela, repositório ou log público.

## Instalação

Instale ou atualize para a versão mais recente no [site do Claude Desktop](https://claude.ai/download) e inicie o Claude Desktop.

## Teste a conexão

Clique em **Save & Restart**. Selecione **Continue with Gateway** e envie uma mensagem curta. A configuração está ativa quando **Gateway** aparece no canto inferior esquerdo e a mensagem recebe uma resposta normal.

## Alterne entre modelos

Abra o seletor de modelos e escolha outro modelo Claude retornado pelo Gateway. Se ele não aparecer, abra novamente **Configure Third-Party Inference...**, clique em **Apply locally** e reinicie o Claude Desktop.

## Erros comuns

| Problema | Correção |
| --- | --- |
| O Gateway não conecta | Use exatamente `{{anthropic-base-url}}` em **Gateway base URL**. Não acrescente `/v1`. |
| A solicitação retorna `401` | Copie a BetterToken API Key novamente e confirme que o esquema é `x-api-key`. |
| Nenhum modelo Claude aparece | Copie um Model ID Claude disponível na model plaza, salve e reinicie o Claude Desktop. |
| A configuração não é aplicada | Encerre completamente o Claude Desktop, abra-o novamente e escolha **Continue with Gateway**. |
