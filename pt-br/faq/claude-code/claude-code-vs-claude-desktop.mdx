## Resposta rápida

O Claude Code é um agente de programação que trabalha em bases de código. Ele foi criado para ler projetos, editar arquivos, executar comandos e verificar resultados.

O Claude Desktop é o aplicativo do Claude para desktop. Ele oferece uma interface gráfica para conversas, extensões, servidores MCP locais e alguns fluxos no desktop, como os recursos Cowork ou Code.

Eles podem compartilhar alguns recursos, mas são interfaces diferentes do produto. A configuração, o modelo de permissões, o comportamento do MCP e a configuração do Gateway podem variar.

## Quando isso é importante

- Você está escolhendo entre o Claude Code CLI e o Claude Desktop
- Você quer que o Claude altere um repositório
- Você está configurando o Gateway ou o MCP do Claude Desktop
- Você usa o Claude Code pelo terminal, IDE, aplicativo para desktop ou web
- Você está investigando diferenças de comportamento entre o desktop e a CLI

## Conceitos principais

| Área | Claude Code | Claude Desktop |
| --- | --- | --- |
| Função principal | Agente de programação | Aplicativo para desktop |
| Acesso comum | Terminal, IDE, desktop, web | Aplicativo para macOS ou Windows |
| Trabalho em código | Projetado para ler e editar arquivos e executar comandos | Depende dos recursos do Desktop, extensões, Cowork ou modo Code |
| Foco da configuração | Diretório do projeto, permissões, `CLAUDE.md`, provedor de API | Login, extensões do desktop, MCP, Gateway |
| Melhor uso | Alterações de código, testes, revisão, automação | Conversas, conectores no desktop, fluxos visuais |

## Escolha recomendada

Use o Claude Code quando quiser que um agente trabalhe diretamente em uma base de código. O fluxo é centrado no diretório do projeto, nas alterações de arquivos, nos comandos e na verificação.

Use o Claude Desktop quando quiser um aplicativo gráfico do Claude, extensões, servidores MCP locais ou fluxos específicos do desktop. Se você usar Code ou Cowork dentro do Desktop, verifique se está usando o comportamento integrado do Claude Code ou uma configuração separada do Claude Code CLI.

Para APIs de terceiros, siga o protocolo aceito pela interface atual. Nesta documentação, o Claude Code usa `{{anthropic-base-url}}`. Não insira diretamente o endpoint `{{openai-base-url}}`, compatível com OpenAI, em um campo de Gateway compatível com Anthropic.

## Erros comuns

- Achar que o Claude Desktop instala ou substitui automaticamente o Claude Code CLI.
- Copiar as configurações MCP do Desktop para o Claude Code ou o contrário.
- Tratar uma assinatura Claude.ai como uma API Key.
- Usar uma Base URL compatível com OpenAI em um campo de Gateway do Claude Desktop que espera tráfego compatível com Anthropic.
- Achar que os recursos do Desktop substituem as permissões, os hooks ou as políticas de comandos do Claude Code.

## Sobre a BetterToken

A BetterToken faz parte da camada de API de modelos. Ela pode fornecer endpoints compatíveis quando a ferramenta aceita uma API Key e uma Base URL personalizadas.

Ela não combina o Claude Code e o Claude Desktop em uma única configuração. Você ainda precisa seguir o protocolo, o Gateway, o MCP e o modelo de permissões da interface usada.
