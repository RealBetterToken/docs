## Resposta curta

Para alternar entre Sonnet, Opus ou outro modelo no Claude Code, use de preferência o comando `/model` compatível ou o caminho oficial de configuração de modelos.

Aliases, IDs completos e mapeamentos de provedores nem sempre são idênticos. O nome comercial exibido em uma interface web pode não ser o ID reconhecido pela API.

Se você usa um gateway de terceiros, utilize o ID de modelo exibido por ele ou pela documentação do provedor.

## Quando isso é importante

- Você quer alternar entre modelos mais econômicos e mais avançados
- Você vê aliases de Sonnet / Opus / Haiku, mas não sabe o que informar
- Você usa uma Base URL ou um gateway de modelos de terceiros
- Você quer controlar o custo de tokens do Claude Code
- A mensagem de modelo não encontrado aparece ou a seleção não entra em vigor

## Três níveis de nomes de modelo

| Nível | Significado |
| --- | --- |
| Nome de exibição | Nome legível mostrado em uma interface |
| Alias | Nome curto ou atalho dentro de uma ferramenta |
| ID de modelo | Identificador realmente reconhecido pela API |

Para que a solicitação funcione, o provedor atual precisa reconhecer o ID de modelo.

## Prática recomendada

1. Confirme quais modelos são aceitos pelo provedor atual.
2. Use `/model` no Claude Code ou o caminho oficial de configuração de modelos.
3. Se você usa um gateway de terceiros, copie o ID disponível na model plaza correspondente.
4. Avalie em conjunto a escolha do modelo e o custo.
5. Não tente adivinhar nomes de modelos.

## Sobre a BetterToken

Se você conectar o Claude Code pela BetterToken, copie o ID de modelo atual da <a href={"{{model-plaza-url}}"}>model plaza</a>. Os modelos dos provedores Claude e GPT usam protocolos diferentes; não misture as configurações.

A escolha do modelo afeta qualidade, velocidade e custo. Os registros de uso ajudam a comparar o consumo real entre modelos.
