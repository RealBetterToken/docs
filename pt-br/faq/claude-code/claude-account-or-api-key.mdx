## Resposta rápida

O Claude Code oferece mais de uma forma de autenticação. Usuários individuais costumam entrar com uma conta Claude.ai. Usuários de API ou equipes podem usar o Claude Console, provedores de nuvem ou um provedor de terceiros compatível.

Uma conta Claude.ai e uma API Key não são a mesma coisa. O login no Claude.ai é usado na experiência oficial do produto. Uma API Key autentica solicitações à API de modelos e costuma ser combinada com uma Base URL e a configuração do provedor.

Se você usa um gateway de API de terceiros, os campos importantes são API Key e Base URL. Confirme também se a ferramenta espera um protocolo compatível com Anthropic ou com OpenAI.

## Quando isso é importante

- Uma solicitação de login aparece durante a configuração do Claude Code
- Você não sabe se os planos Claude Pro ou Max fornecem uma API Key
- Você quer rotear o Claude Code por um gateway de API personalizado
- Você precisa escolher entre o login oficial e um provedor de terceiros
- Sua equipe precisa de um padrão de autenticação consistente

## Conceitos principais

| Conceito | Significado |
| --- | --- |
| Conta Claude.ai | Login oficial para as experiências do Claude |
| API do Claude Console | Acesso à API e gerenciamento de uso para desenvolvedores |
| API Key | Credencial usada nas solicitações de modelo |
| Base URL | Endpoint para o qual as solicitações são enviadas |
| Provedor | Origem da autenticação e das solicitações de modelo usada pelo Claude Code |
| Gateway de API de terceiros | Camada de compatibilidade, roteamento, cobrança ou observabilidade entre a ferramenta e os provedores de modelos |

## Fluxo de decisão recomendado

1. Se você quer apenas a experiência oficial do Claude Code e usa um plano Claude.ai, comece pelo login oficial.
2. Se você precisa de cobrança por API ou acesso gerenciado pela equipe, consulte o Claude Console ou o provedor da equipe.
3. Se você precisa de um gateway personalizado, confirme que o Claude Code aceita esse provedor e configure API Key e Base URL.
4. Se você precisa dos recursos oficiais do aplicativo e de um provedor de inferência de terceiros, decida se é necessário preservar o login oficial.

Nesta documentação, a Base URL compatível com Anthropic para o Claude Code é `{{anthropic-base-url}}`.

## Erros comuns

- Tratar uma assinatura Claude.ai como API Key.
- Colar uma credencial do ChatGPT Plus ou de outra assinatura no Claude Code.
- Copiar apenas a API Key e esquecer de alterar a Base URL.
- Colocar uma Base URL compatível com OpenAI na configuração compatível com Anthropic do Claude Code.
- Compartilhar `auth.json`, tokens de atualização ou credenciais de sessão como se fossem API Keys.

## Sobre a BetterToken

Se você escolher a opção API Key + Base URL, a BetterToken poderá fornecer o endpoint compatível e um painel para API Keys, saldo e histórico de uso.

A BetterToken não substitui o login no Claude.ai nem transforma uma assinatura Claude.ai em API Key. Ela gerencia apenas a camada de API de modelos.
