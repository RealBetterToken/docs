## Resposta rápida

O Claude Code é um agente de programação para desenvolvimento de software. Ele não é apenas uma página de chat: pode ler uma base de código, editar arquivos, executar comandos e ajudar em tarefas de desenvolvimento pelo terminal, IDE, aplicativo para desktop ou navegador.

No fluxo básico, o Claude Code lê o contexto do projeto, planeja a tarefa, aciona ferramentas, edita arquivos e executa verificações quando necessário. Ele foi criado para alterações em vários arquivos, correções de testes, revisão de código, scripts e tarefas de engenharia mais longas.

A API de modelos cuida apenas da inferência. Permissões locais, acesso a arquivos, execução de comandos, hooks e ferramentas MCP continuam sob o controle do Claude Code e da configuração do projeto.

## Quando isso é importante

- Você está instalando o Claude Code pela primeira vez
- Você quer que o Claude Code altere um repositório local
- Você quer entender por que ele lê arquivos ou usa muitos tokens
- Você pretende conectar uma API Key e uma Base URL personalizadas
- Você está escolhendo entre Claude Code, Claude Desktop, Cursor e Codex CLI

## Conceitos principais

| Conceito | Significado |
| --- | --- |
| Agente de programação | Agente voltado ao desenvolvimento que pode examinar código, usar ferramentas, editar arquivos e executar comandos |
| Diretório de trabalho | Diretório do projeto que o Claude Code pode examinar e alterar |
| Uso de ferramentas | Leitura de arquivos, pesquisa de código, edição de arquivos, comandos de shell e ações semelhantes |
| Contexto | Histórico da conversa, arquivos, regras do projeto, `CLAUDE.md` e resultados de ferramentas |
| MCP | Protocolo para adicionar ferramentas e fontes de dados; não é a API de modelos |
| `CLAUDE.md` | Arquivo de instruções do projeto que o Claude Code pode carregar como contexto |

## Fluxo recomendado

1. Inicie o Claude Code em um diretório de projeto real.
2. Peça que ele examine os arquivos relevantes antes de fazer alterações amplas.
3. Em trabalhos complexos, peça um plano antes da implementação.
4. Deixe que ele altere um pequeno conjunto de arquivos e execute a verificação relevante mais rápida.
5. Coloque regras estáveis do projeto no `CLAUDE.md` e mantenha instruções pontuais na conversa.

Se você conectar o Claude Code por um gateway de API, confirme que o endpoint é compatível com Anthropic. Nesta documentação, o Claude Code usa `{{anthropic-base-url}}`. Não use o endpoint `{{openai-base-url}}`, compatível com OpenAI, na configuração do protocolo Anthropic do Claude Code.

## Erros comuns

- Tratar o Claude Code como uma página de chat comum e esquecer que ele pode alterar arquivos locais.
- Esperar que ele entenda todo o repositório sem ler arquivos ou instruções do projeto.
- Tratar o MCP como uma API de modelos. O MCP adiciona ferramentas; API Key, Base URL e ID de modelo configuram a inferência.
- Misturar login no Claude.ai, API do Claude Console e gateways de terceiros.
- Permitir execução local ampla sem revisão, testes ou limites de comandos.

## Sobre a BetterToken

Quando o Claude Code usa uma API Key e uma Base URL personalizadas, ele pode enviar solicitações por um gateway compatível com Anthropic. A BetterToken pertence a essa camada de API e ajuda a gerenciar API Keys, saldo e histórico de uso.

A BetterToken não substitui as permissões, os controles de acesso a arquivos, os hooks, a configuração MCP nem as regras do projeto. Esses elementos continuam fazendo parte do fluxo do Claude Code.
