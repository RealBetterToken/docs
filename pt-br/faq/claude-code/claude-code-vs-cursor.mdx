## Resposta curta

O Claude Code funciona como um agente de programação no terminal. Ele é indicado para repositórios existentes, nos quais pode ler código, executar comandos, editar arquivos e seguir o `CLAUDE.md`, as permissões, os hooks e o MCP.

O Cursor funciona como uma IDE com IA. Ele é indicado quando você quer usar preenchimento automático, chat, Composer, regras, indexação e edição de código dentro do editor.

Nenhum substitui completamente o outro. A escolha depende da sua preferência por um agente no terminal ou por um fluxo de IA integrado ao editor.

## Principais diferenças

| Aspecto | Claude Code | Cursor |
| --- | --- | --- |
| Ponto de entrada principal | Terminal / linha de comando | IDE com IA |
| Contexto do projeto | `CLAUDE.md`, contexto da conversa, leituras por ferramentas | Cursor Rules, indexação, contexto do editor |
| Controle de permissões | Permissões, hooks, fluxo de confirmação | Aprovação de ferramentas, permissões do editor, regras |
| MCP | Compatível com ferramentas MCP | Compatível com ferramentas MCP |
| Configuração de modelos | Prioriza Claude / compatibilidade com Anthropic | Compatibilidade com OpenAI, provedor personalizado, modelos integrados |
| Melhor uso | Tarefas com várias etapas, execução de comandos, alterações em todo o repositório | Interação no editor, navegação, edições pontuais, preenchimento automático |

## Como escolher

Use o Claude Code se você quer pedir a um agente que examine o repositório, planeje, execute testes e faça um conjunto de alterações.

Use o Cursor se você passa a maior parte do tempo no editor e quer que a IA entenda o arquivo atual, a seleção, o índice e as regras do projeto.

Se você usar os dois, eles poderão compartilhar a mesma camada de API de modelos, mas cada ferramenta ainda precisará das próprias regras e limites de permissão.

## Erros comuns

- Achar que o Claude Code lê automaticamente as Cursor Rules.
- Achar que o `CLAUDE.md` substitui as regras de projeto do Cursor.
- Comparar apenas os nomes dos modelos, em vez dos fluxos e das permissões.
- Tratar o MCP como uma API de modelos, não como uma camada que amplia ferramentas e contexto.
- Ignorar a diferença entre a indexação do editor e a execução de comandos no terminal.

## Sobre a BetterToken

Se você quer que Claude Code e Cursor compartilhem o roteamento dos modelos e a visibilidade de uso, configure cada ferramenta com o protocolo esperado.

O Claude Code geralmente usa `{{anthropic-base-url}}`. O Cursor e ferramentas externas semelhantes normalmente usam `{{openai-base-url}}`, com os IDs de modelo copiados do **provedor GPT**.
