## Resposta curta

O Claude Desktop pode se conectar a ferramentas e fontes de dados locais por meio de servidores MCP. Declare o servidor na configuração MCP do Claude Desktop, reinicie ou atualize a conexão e verifique o status no aplicativo.

MCP não é uma API de modelos. Ele permite que o Claude Desktop acesse ferramentas ou contexto. As solicitações de modelo ainda dependem do modelo e do tipo de conta usados no Claude Desktop.

## Quando usar

- Você quer que o Claude Desktop acesse arquivos locais, bancos de dados ou ferramentas de desenvolvimento
- Você encontrou uma configuração de servidor MCP, mas não sabe onde colocá-la
- Você está comparando MCP local e MCP remoto
- Você acredita que o MCP pode substituir API Key / Base URL
- Você precisa verificar se o MCP está conectado

## MCP local versus MCP remoto

| Tipo | Significado |
| --- | --- |
| MCP local | Executa um servidor no seu computador, geralmente para ferramentas, arquivos ou ambientes de desenvolvimento locais |
| MCP remoto | Conecta-se a um serviço remoto, geralmente para ferramentas na nuvem ou serviços de equipe |
| Extensão para desktop | Formato de instalação e distribuição voltado ao desktop |

## Configuração recomendada

1. Confirme que você está conectando um servidor MCP, não um provedor de modelos.
2. Adicione a configuração MCP local ou remota conforme a documentação do Claude Desktop.
3. Reinicie ou atualize o Claude Desktop.
4. Verifique o status da conexão MCP no Claude Desktop.
5. Conceda ao servidor MCP apenas as permissões e variáveis de ambiente necessárias.

## Erros comuns

- Tratar um servidor MCP como Base URL.
- Colocar uma API Key de modelo na configuração MCP.
- Achar que o MCP altera o custo do modelo.
- Esquecer que um servidor MCP pode acessar dados locais confidenciais.
- Verificar apenas a interface do Claude Desktop quando o servidor local não está em execução.

## Sobre a BetterToken

A BetterToken gerencia o acesso à API de modelos, não servidores MCP. O MCP do Claude Desktop conecta ferramentas. Camadas de API como a BetterToken gerenciam solicitações de modelo, saldo e uso.

Se você precisar de acesso a ferramentas e roteamento unificado de modelos, configure o MCP e o acesso à API separadamente.
