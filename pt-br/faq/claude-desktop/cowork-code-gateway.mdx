Depois de configurar o Gateway da BetterToken no Claude Desktop, os sintomas abaixo geralmente não significam que a API Key seja inválida:

- O modo Cowork não funciona
- O modo Code mostra `Claude Code process exited with code 1`
- A mesma API Key funciona no Claude Code CLI pelo terminal

Se você ainda não configurou o Gateway, comece por [Usar a API da BetterToken no Claude Desktop](/pt-br/faq/claude-desktop-bettertoken-api).

## Corrija primeiro o modo Cowork

O Claude Desktop aceita apenas modelos Claude. Essa é uma limitação do cliente Claude Desktop.

Confira se a API Key está completa e não expirou. Use `x-api-key` nesta configuração Gateway, salve e reinicie o Claude Desktop.

Siga o [guia do Claude Desktop](/pt-br/faq/claude-desktop-bettertoken-api): selecione **Gateway**, use a Base URL `{{anthropic-base-url}}`, sua BetterToken API Key e **Gateway auth scheme** `x-api-key`. Clique em **Apply locally** e reinicie o Claude Desktop por completo.

## Depois, corrija os erros de encerramento do modo Code

Se o Cowork funcionar, mas o modo Code, na aba `</>`, continuar mostrando `Claude Code process exited with code 1`, verifique se o Claude Desktop ainda usa uma versão integrada mais antiga do Claude Code.

**Causa principal**: o Claude Desktop pode estar baixando uma versão mais recente do Claude Code em segundo plano. Antes do fim do download, o modo Code pode usar uma versão instalada mais antiga, que talvez não seja compatível com gateways de terceiros e encerre o processo imediatamente.

**Como corrigir**:

<Steps>
  <Step title="Aguarde o download da versão mais recente do Claude Code">
    Mantenha o Claude Desktop aberto por algum tempo para que a atualização em segundo plano seja concluída.
  </Step>

  <Step title="Encerre completamente o Claude Desktop">
    Use **Cmd+Q** para encerrar o aplicativo. Não feche apenas a janela.
  </Step>

  <Step title="Abra novamente e inicie uma nova sessão do Code">
    Abra o Claude Desktop outra vez, acesse o modo Code e inicie uma nova sessão.
  </Step>
</Steps>

<Note>
  Se os logs mostrarem que o Claude Desktop está voltando para uma versão antiga do Claude Code, como `2.1.111`, enquanto uma versão mais recente, como `2.1.119`, ainda não está pronta, aguarde o fim do download e reinicie o aplicativo.
</Note>
