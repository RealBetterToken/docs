Use o Kimi K3 no OpenCode conectando a BetterToken como provedor compatível com OpenAI. Informe sua API Key da BetterToken, o Base URL `https://bettertoken.ai/v1` e o Model ID `kimi-k3`. Para o Claude Code, use o [guia separado do Kimi K3](/pt-br/faq/claude-code/kimi-k3-api), pois o protocolo de configuração é diferente.

## Configurações principais

| Campo | Valor |
| --- | --- |
| API Key | BetterToken API Key |
| Base URL | `https://bettertoken.ai/v1` |
| Modelo | `kimi-k3` |

## Pré-requisitos

- Instale a versão mais recente do [OpenCode](https://opencode.ai/)。
- <a href={"{{register-url}}"}>Crie uma API Key da BetterToken</a>。
- No diálogo **Setup**, selecione a ferramenta e o provedor correspondentes e copie o Model ID disponível.

## Configurar com `/connect`

Inicie o OpenCode e execute:

```text
/connect
```

Escolha **Other**, informe `bettertoken` como id do provedor e cole sua API Key da BetterToken. Em seguida, selecione `bettertoken/kimi-k3` e reinicie o OpenCode.

## Configuração manual

Abra o arquivo global `~/.config/opencode/opencode.json`. Para um projeto, use `opencode.json` na raiz:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "bettertoken/kimi-k3",
  "provider": {
    "bettertoken": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "BetterToken",
      "options": {
        "baseURL": "https://bettertoken.ai/v1",
        "apiKey": "YOUR_API_KEY"
      },
      "models": {
        "kimi-k3": {
          "name": "kimi-k3"
        }
      }
    }
  }
}
```

Substitua `YOUR_API_KEY`. Não acrescente `/chat/completions` a `baseURL`; o OpenCode adiciona a rota da solicitação.

## Verificar a conexão

Selecione `bettertoken/kimi-k3` no OpenCode e envie um prompt curto. Uma resposta normal confirma a conexão. Reinicie o OpenCode após editar o JSON.

## Erros comuns

| Error | Campo |
| --- | --- |
| `401` | Execute `/connect` novamente ou verifique `apiKey`. |
| `404` | Use somente `https://bettertoken.ai/v1` em `baseURL`. |
| Model not found | O `model` superior deve ser `bettertoken/kimi-k3` e a chave em `models` deve ser `kimi-k3`. |
| Configuration is not applied | Verifique se `opencode.json` do projeto substitui o arquivo global. |
