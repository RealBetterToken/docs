# Docs market and language matrix

This internal matrix defines the current market position of each public Docs language. It is not a navigation page and is not published as documentation content.

## URL and language policy

- Russian is the default language and is served at `/`.
- English is served at `/en` and is the `x-default` destination for users whose language does not match a localized version.
- Every localized page keeps its own self-canonical and reciprocal hreflang alternate.
- Existing locale URLs remain unchanged. Do not add `/ru` or canonicalize different languages to one URL.
- Russia-specific positioning belongs on Russian pages or explicitly regional FAQ pages. English and other non-Russian homepages use global positioning.
