`POST /v1/responses`

Используйте этот endpoint для Codex и приложений, работающих с OpenAI Responses API.

<Note>
  Base URL: `{{openai-base-url}}`. Передавайте API Key через `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Тест в Playground

В Playground справа вставьте свой API Key, при необходимости замените `model` на актуальный ID из GPT Key group и отправьте запрос. Перед тестом проверьте модель в <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Warning>
  Используйте только свой тестовый API Key. Не публикуйте ключ в коде, скриншотах, тикетах или Git-репозитории.
</Warning>
