`POST /v1/chat/completions`

Используйте этот endpoint для внешних инструментов и приложений, которым нужен OpenAI-compatible Chat Completions API.

<Note>
  Base URL: `{{openai-base-url}}`. Передавайте API Key через `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Тест в Playground

В Playground справа вставьте свой API Key, укажите доступную модель из GPT Key group и заполните `messages`. Перед тестом проверьте ID модели в <a href={"{{model-plaza-url}}"}>model plaza</a>.

<Warning>
  Не добавляйте `/chat/completions` к Base URL в настройках внешнего инструмента, если сам инструмент формирует путь endpoint. В Playground полный путь уже задан.
</Warning>
