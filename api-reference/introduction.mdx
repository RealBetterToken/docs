Публичный справочник BetterToken сейчас содержит только **OpenAI-compatible Chat Completions API**. Поддержка других протоколов пока различается между каналами, поэтому Responses API и Anthropic Messages API временно не публикуются как открытые интерфейсы.

## Поддерживаемые провайдеры

| Провайдер | Статус |
| --- | --- |
| Claude | Не поддерживается |
| GPT | Ручная настройка |
| Kimi | Ручная настройка |
| GLM | Ручная настройка |

## Параметры подключения

| Поле | Значение |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Полный URL запроса | `{{chat-completions-url}}` |
| Метод | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

Скопируйте актуальный Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a> или окна **Setup** для нужного API Key в Console.

<Warning>
  Если инструмент запрашивает **Base URL**, укажите `{{openai-base-url}}`. Используйте `{{chat-completions-url}}` только тогда, когда инструмент требует полный URL запроса.
</Warning>

## Быстрая проверка

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Успешный ответ содержит `choices[0].message.content`.
