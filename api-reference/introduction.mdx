BetterToken предоставляет OpenAI-compatible Chat Completions и Responses API, а также Anthropic-compatible Messages API. Выберите формат, который использует ваш клиент.

## Выберите API

| API | POST | Auth |
| --- | --- | --- |
| [Chat Completions](/api-reference/chat-completions) | `/v1/chat/completions` | `Bearer` |
| [Responses](/api-reference/responses) | `/v1/responses` | `Bearer` |
| [Messages](/api-reference/messages) | `/v1/messages` | `x-api-key` |
| [Image generation](/api-reference/images-generations) | `/v1/images/generations` | `Bearer` |
| [Image editing](/api-reference/images-edits) | `/v1/images/edits` | `Bearer` |

## Подключение Chat Completions

| Поле | Значение |
| --- | --- |
| Base URL | `{{openai-base-url}}` |
| Полный URL запроса | `{{chat-completions-url}}` |
| Метод | `POST` |
| Authorization | `Bearer YOUR_API_KEY` |
| Model | `YOUR_MODEL_ID` |

Скопируйте актуальный Model ID из <a href={"{{model-plaza-url}}"}>model plaza</a> или окна **Setup** для нужного API Key в Console.

<Warning>
  Если инструмент запрашивает **Base URL**, укажите `{{openai-base-url}}`. Используйте `{{chat-completions-url}}` только тогда, когда инструмент требует полный URL запроса.
</Warning>

## Быстрая проверка

```bash
curl "{{chat-completions-url}}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'
```

Успешный ответ содержит `choices[0].message.content`.
