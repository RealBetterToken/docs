`POST /v1/messages`

Используйте этот endpoint для Claude Code, Anthropic SDK и приложений, работающих с Anthropic Messages API.

<Note>
  Для SDK укажите `{{anthropic-base-url}}` как Base URL. В ручном запросе и Playground используется полный путь `{{anthropic-base-url}}/v1/messages`.
</Note>

## Тест в Playground

В Playground справа вставьте свой API Key в поле `x-api-key`, оставьте `anthropic-version` равным `claude-cli/2.0.76 (external, cli)`, укажите доступную модель из Claude Key group и отправьте запрос.

<Warning>
  Для этого endpoint не используйте `Authorization: Bearer ...`. Нужен header `x-api-key`.
</Warning>
